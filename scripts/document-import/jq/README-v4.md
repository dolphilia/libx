# jq フッター表示と保存済みレビューの照合

既存定本・翻訳・全文レビューを保持し、英日マニュアル32ページの末尾出典と日本語原通知2ページの冒頭説明をdocumentContextへ移動する。原通知本文は原文のまま保持する。冒頭説明の「以下は」だけをフッターから参照できる「本文は」へ変更する。全文の内容レビューは再実施しない。

`check-content-v4.py`は固定した表示マニフェストSHA、現行36ファイル、Frontmatter、本文、注記を照合し、別の一時コピーにレビュー時の36ファイルを完全復元して未変更のv3/v2検査を実行する。検査合格は新たな意味レビューを意味しない。定本の再生成には元の固定Python依存が必要。

`check-rendered-v4.mjs`はビルド後の36ページの本文・コード・日本語フィールド・フッター34ページ・内部リンクを独立して検査する。Shikiが省略するコード末尾改行だけを表示比較で除き、内部コード文字列は一致を要求する。ビルド・ブラウザー表示・統合・公開は別証拠が必要。

公開済み84f9815bを基準に専用隔離チェックアウトで進める。ルートのAwesome作業・利用者変更を混ぜない。
