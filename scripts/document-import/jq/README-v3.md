# jq 全文レビューと実ファイルの照合

固定対象は jq 1.8.2 の jq 1.8 Manual。日本語本文16ページと原通知2ページは別工程の全文レビューを完了している。文書の条件は CC BY 3.0 Unported。原通知は原文で保持する。

```bash
pnpm --filter=apps-jq check:content
```

専用アプリの `check:content` は `check-content-v3.py` を使う。Python標準ライブラリだけで、ネットワーク・LLM・保存物への書き込みを使わない。従来の `check-content-v2.py` による英語再生成・構造検査に加え、packet内の `CONTENT_REVIEW.json`、原文JSON、日本語訳JSON、英語定本、日本語定本、アプリの英日36ファイルを照合する。全1,135項目のレビュー範囲・現行ハッシュも検査する。

packetには `canonical/`、`ja-canonical-630/`、`translations/` と固定原資料を保存する。検査対象ファイルの集合、レビューの欠落、未読の意味単位、訳文やアプリ本文の変更を検出した場合は失敗する。日本語定本は `render-ja-fields-v2.py` と `assemble-ja-v2.py` で保存訳から再生成できる。意味レビューの変更が必要な場合は、別工程で再レビューして新しい証拠を残す。

このコマンドは保存済みAIレビューと現行成果物の対応を確認するもので、意味の再レビュー、表示・統合検査、公開承認を実行しない。実行モデルの実値はツールに公開されておらず、設定上の GPT-6.1 Sol と区別して記録する。旧READMEと旧検査器は当時の証拠として維持する。
