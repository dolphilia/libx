<h1 id="page-title">Bool Class (English original)</h1>
<p>Boolean <a href="/docs/wren/v0-4-0/en/01-guide/04-values/">values</a>. There are two instances, <code>true</code> and <code>false</code>.</p>
<h2>Methods <a href="#methods" name="methods" class="header-anchor">#</a></h2>
<h3><strong>!</strong> operator <a href="#-operator" name="-operator" class="header-anchor">#</a></h3>
<p>Returns the logical complement of the value.</p>
<pre class="snippet"><code>&#10;System.print(!true) //&gt; false&#10;System.print(!false) //&gt; true&#10;</code></pre>

<h3>toString <a href="#tostring" name="tostring" class="header-anchor">#</a></h3>
<p>The string representation of the value, either <code>"true"</code> or <code>"false"</code>.</p>
