<h3 class="section" id="Less-Frequently_002dUsed-Commands"><span>3.5 使用頻度の低いコマンド</span></h3>
<p>前の節のコマンドほど頻繁には使わないかもしれませんが、これらを使えば、ごく短くても役立つ<code class="command">sed</code>スクリプトを作れます。</p>
<dl class="table">
<dt><a class="index-entry-id" id="index-Transliteration"></a>
<a id="index-y-_0028transliterate_0029-command"></a><span><code class="code">y/<var class="var">source-chars</var>/<var class="var">dest-chars</var>/</code></span></dt>
<dd><p>パターンスペースにある文字のうち、<var class="var">source-chars</var>のいずれかに一致する文字を、対応する<var class="var">dest-chars</var>の文字へ置き換えます。</p>
<p>例：「<samp class="samp">a-j</samp>」を「<samp class="samp">0-9</samp>」へ文字単位で置き換えます。</p><div class="example">
<pre class="gnu-sed-literal">$ echo hello world | sed 'y/abcdefghij/0123456789/'&#10;74llo worl3&#10;</pre></div>
<p>（一つの<code class="code">y</code>コマンド内では、<code class="code">/</code>文字をすべて同じ別の1文字へ置き換えられます。）</p>
<p><var class="var">source-chars</var>や<var class="var">dest-chars</var>のリストには、<code class="code">/</code>（またはその代わりに使った文字）、<code class="code">\</code>、改行を含められます。ただし、それぞれを<code class="code">\</code>でエスケープする必要があります。<var class="var">source-chars</var>と<var class="var">dest-chars</var>のリストの文字数は、エスケープを解いた後に<em class="emph">同じでなければなりません</em>。</p>
<p>同様の機能については、GNU coreutilsの<code class="command">tr</code>コマンドを参照してください。</p>
</dd>
<dt><code class="code">a <var class="var">text</var></code></dt>
<dd><p>行の後に<var class="var">text</var>を追加します。これは標準の<code class="code">a</code>コマンドへのGNU拡張です。詳細は以下を参照してください。</p>
<p>例：2行目の後に「<samp class="samp">hello</samp>」を追加します。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2a hello'&#10;1&#10;2&#10;hello&#10;3&#10;</pre></div>
<p><code class="code">a</code>コマンドの直後の空白は無視されます。追加するテキストは行末まで読み込まれます。</p>
</dd>
<dt><a class="index-entry-id" id="index-Appending-text-after-a-line"></a>
<a class="index-entry-id" id="index-Text_002c-appending"></a>
<a id="index-a-_0028append-text-lines_0029-command"></a><span><code class="code">a\</code></span></dt>
<dt><code class="code"><var class="var">text</var></code></dt>
<dd><p>行の後に<var class="var">text</var>を追加します。</p>
<p>例：2行目の後に「<samp class="samp">hello</samp>」を追加します（-|は表示される出力行を示します）。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2a\&#10;hello'&#10;-|1&#10;-|2&#10;-|hello&#10;-|3&#10;</pre></div>
<p><code class="code">a</code>コマンドは、このコマンドの後に続くテキストの各行をキューに入れ、現在のサイクルの最後、または次の入力行を読み込むときに出力します。最後の行以外は<code class="code">\</code>で終えます。これらのバックスラッシュは出力から取り除かれます。</p>
<a class="index-entry-id" id="index-GNU-extensions_002c-two-addresses-supported-by-most-commands"></a>
<p>GNU拡張として、このコマンドにはアドレスを二つ指定できます。</p>
<p><var class="var">text</var>内のエスケープシーケンスは処理されるので、バックスラッシュを一つ表示するには、<var class="var">text</var>内に<code class="code">\\</code>を使ってください。</p>
<p>バックスラッシュ（<code class="code">\</code>）のない最後の行の後から、コマンドの処理を再開します。次の例では「<samp class="samp">world</samp>」がその行です。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2a\&#10;hello\&#10;world&#10;3s/./X/'&#10;-|1&#10;-|2&#10;-|hello&#10;-|world&#10;-|X&#10;</pre></div>
<p>GNU拡張として、<code class="code">a</code>コマンドと<var class="var">text</var>を二つの<code class="code">-e</code>引数に分けて指定でき、スクリプトを書きやすくなります。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed -e '2a\' -e hello&#10;1&#10;2&#10;hello&#10;3&#10;&#10;$ sed -e '2a\' -e "$VAR"&#10;</pre></div>
</dd>
<dt><code class="code">i <var class="var">text</var></code></dt>
<dd><p>行の前に<var class="var">text</var>を挿入します。これは標準の<code class="code">i</code>コマンドへのGNU拡張です。詳細は以下を参照してください。</p>
<p>例：2行目の前に「<samp class="samp">hello</samp>」を挿入します。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2i hello'&#10;1&#10;hello&#10;2&#10;3&#10;</pre></div>
<p><code class="code">i</code>コマンドの直後の空白は無視されます。追加するテキストは行末まで読み込まれます。</p>
<a class="anchor" id="insert-command"></a></dd>
<dt><a class="index-entry-id" id="index-Inserting-text-before-a-line"></a>
<a class="index-entry-id" id="index-Text_002c-insertion"></a>
<a id="index-i-_0028insert-text-lines_0029-command"></a><span><code class="code">i\</code></span></dt>
<dt><code class="code"><var class="var">text</var></code></dt>
<dd><p>このコマンドの後に続くテキストの各行を、直ちに出力します。</p>
<p>例：2行目の前に「<samp class="samp">hello</samp>」を挿入します（-|は表示される出力行を示します）。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2i\&#10;hello'&#10;-|1&#10;-|hello&#10;-|2&#10;-|3&#10;</pre></div>
<a class="index-entry-id" id="index-GNU-extensions_002c-two-addresses-supported-by-most-commands-1"></a>
<p>GNU拡張として、このコマンドにはアドレスを二つ指定できます。</p>
<p><var class="var">text</var>内のエスケープシーケンスは処理されるので、バックスラッシュを一つ表示するには、<var class="var">text</var>内に<code class="code">\\</code>を使ってください。</p>
<p>バックスラッシュ（<code class="code">\</code>）のない最後の行の後から、コマンドの処理を再開します。次の例では「<samp class="samp">world</samp>」がその行です。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2i\&#10;hello\&#10;world&#10;s/./X/'&#10;-|X&#10;-|hello&#10;-|world&#10;-|X&#10;-|X&#10;</pre></div>
<p>GNU拡張として、<code class="code">i</code>コマンドと<var class="var">text</var>を二つの<code class="code">-e</code>引数に分けて指定でき、スクリプトを書きやすくなります。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed -e '2i\' -e hello&#10;1&#10;hello&#10;2&#10;3&#10;&#10;$ sed -e '2i\' -e "$VAR"&#10;</pre></div>
</dd>
<dt><code class="code">c <var class="var">text</var></code></dt>
<dd><p>行を<var class="var">text</var>に置き換えます。これは標準の<code class="code">c</code>コマンドへのGNU拡張です。詳細は以下を参照してください。</p>
<p>例：2〜9行目を単語「<samp class="samp">hello</samp>」に置き換えます。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 10 | sed '2,9c hello'&#10;1&#10;hello&#10;10&#10;</pre></div>
<p><code class="code">c</code>コマンドの直後の空白は無視されます。追加するテキストは行末まで読み込まれます。</p>
</dd>
<dt><a class="index-entry-id" id="index-Replacing-selected-lines-with-other-text"></a>
<a id="index-c-_0028change-to-text-lines_0029-command"></a><span><code class="code">c\</code></span></dt>
<dt><code class="code"><var class="var">text</var></code></dt>
<dd><p>アドレスまたはアドレス範囲に一致する行を削除し、このコマンドの後に続くテキストの各行を出力します。</p>
<p>例：2〜4行目を単語「<samp class="samp">hello</samp>」と「<samp class="samp">world</samp>」に置き換えます（-|は表示される出力行を示します）。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 5 | sed '2,4c\&#10;hello\&#10;world'&#10;-|1&#10;-|hello&#10;-|world&#10;-|5&#10;</pre></div>
<p>アドレスを指定しなければ、各行を置き換えます。</p>
<p>このコマンドの処理後は、パターンスペースが削除されているため、新しいサイクルを開始します。次の例では、<code class="code">c</code>が新しいサイクルを開始し、置き換えたテキストに置換コマンドは適用されません。</p>
<div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2c\&#10;hello&#10;s/./X/'&#10;-|X&#10;-|hello&#10;-|X&#10;</pre></div>
<p>GNU拡張として、<code class="code">c</code>コマンドと<var class="var">text</var>を二つの<code class="code">-e</code>引数に分けて指定でき、スクリプトを書きやすくなります。</p><div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed -e '2c\' -e hello&#10;1&#10;hello&#10;3&#10;&#10;$ sed -e '2c\' -e "$VAR"&#10;</pre></div>
</dd>
<dt><a class="index-entry-id" id="index-Printing-line-number"></a>
<a class="index-entry-id" id="index-Line-number_002c-printing"></a>
<a id="index-_003d-_0028print-line-number_0029-command"></a><span><code class="code">=</code></span></dt>
<dd><p>現在の入力行番号を、末尾の改行とともに表示します。</p>
<div class="example">
<pre class="gnu-sed-literal">$ printf '%s\n' aaa bbb ccc | sed =&#10;1&#10;aaa&#10;2&#10;bbb&#10;3&#10;ccc&#10;</pre></div>
<a class="index-entry-id" id="index-GNU-extensions_002c-two-addresses-supported-by-most-commands-2"></a>
<p>GNU拡張として、このコマンドにはアドレスを二つ指定できます。</p>
</dd>
<dt><a class="index-entry-id" id="index-List-pattern-space"></a>
<a class="index-entry-id" id="index-Printing-text-unambiguously"></a>
<a class="index-entry-id" id="index-Line-length_002c-setting-1"></a>
<a class="index-entry-id" id="index-GNU-extensions_002c-setting-line-length"></a>
<a id="index-l-_0028list-unambiguously_0029-command"></a><span><code class="code">l <var class="var">n</var></code></span></dt>
<dd><p>パターンスペースを曖昧さのない形式で表示します。表示不能文字と<code class="code">\</code>文字はC形式のエスケープ表記で表示し、長い行は分割して、その末尾の<code class="code">\</code>文字で分割を示します。各行の末尾は<code class="code">$</code>で示します。</p>
<p><var class="var">n</var>は折り返し幅を指定します。0（ゼロ）は長い行を折り返さないことを意味します。省略すると、コマンドラインで指定した既定値を使います。引数<var class="var">n</var>はGNU <code class="command">sed</code>拡張です。</p>
</dd>
<dt><code class="code">r <var class="var">filename</var></code></dt>
<dd>
<a class="index-entry-id" id="index-r-_0028read-file_0029-command"></a>
<a class="index-entry-id" id="index-Read-text-from-a-file"></a>
<p>ファイル<var class="var">filename</var>を読み込みます。例：</p>
<div class="example">
<pre class="gnu-sed-literal">$ seq 3 | sed '2r/etc/hostname'&#10;1&#10;2&#10;fencepost.gnu.org&#10;3&#10;</pre></div>
<a class="index-entry-id" id="index-GNU-extensions_002c-_002fdev_002fstdin-file"></a>
<p><var class="var">filename</var>の内容を読み込み待ちのキューに入れ、現在のサイクルの最後、または次の入力行を読み込むときに、出力ストリームへ挿入します。<var class="var">filename</var>を読めなければ、エラーを通知せず、空のファイルであるかのように扱います。</p>
<p>GNU <code class="command">sed</code>拡張として、ファイル名には特殊な値<samp class="file">/dev/stdin</samp>を指定でき、標準入力の内容を読み込みます。</p>
<a class="index-entry-id" id="index-GNU-extensions_002c-two-addresses-supported-by-most-commands-3"></a>
<p>GNU拡張として、このコマンドにはアドレスを二つ指定できます。その場合、アドレスで選ばれた各行で、ファイルを再度読み込んで挿入します。</p>
<p>GNU <code class="command">sed</code>拡張として、<code class="code">r</code>コマンドにはアドレス0を指定でき、入力の最初の行の<em class="emph">前</em>にファイルを挿入します。<a class="pxref" href="/docs/gnu-sed/source/v4-10/manual.html#Adding-a-header-to-multiple-files">複数ファイルへのヘッダー追加</a>を参照してください。</p>
</dd>
<dt><a class="index-entry-id" id="index-Write-to-a-file"></a>
<a class="index-entry-id" id="index-GNU-extensions_002c-_002fdev_002fstdout-file-2"></a>
<a class="index-entry-id" id="index-GNU-extensions_002c-_002fdev_002fstderr-file-1"></a>
<a id="index-w-_0028write-file_0029-command"></a><span><code class="code">w <var class="var">filename</var></code></span></dt>
<dd><p>パターンスペースを<var class="var">filename</var>へ書き込みます。GNU <code class="command">sed</code>拡張として、<var class="var">filename</var>には二つの特殊な値を指定できます。<samp class="file">/dev/stderr</samp>は結果を標準エラー出力へ、<samp class="file">/dev/stdout</samp>は標準出力へ書き込みます<a class="footnote" href="/docs/gnu-sed/v4-10/ja/01-guide/09-less-frequent-commands/#FOOT4" id="DOCF4"><sup>4</sup></a>。</p>
<p>最初の入力行を読み込む前に、ファイルを作成するか、既存ファイルを切り詰めます。同じ<var class="var">filename</var>を参照するすべての<code class="code">w</code>コマンド（置換が成功した<code class="code">s</code>コマンドの<code class="code">w</code>フラグも含みます）は、ファイルを閉じて開き直すことなく出力します。</p>
</dd>
<dt><a class="index-entry-id" id="index-Delete-first-line-from-pattern-space"></a>
<a id="index-D-_0028delete-first-line_0029-command"></a><span><code class="code">D</code></span></dt>
<dd><p>パターンスペースに改行がなければ、<code class="code">d</code>コマンドを実行した場合と同じように、通常の新しいサイクルを開始します。それ以外の場合は、最初の改行までのテキストを削除し、残ったパターンスペースを使ってサイクルを再開します。新しい入力行は読み込みません。</p>
</dd>
<dt><a class="index-entry-id" id="index-Next-input-line_002c-append-to-pattern-space"></a>
<a class="index-entry-id" id="index-Append-next-input-line-to-pattern-space"></a>
<a id="index-N-_0028append-Next-line_0029-command"></a><span><code class="code">N</code></span></dt>
<dd><p>パターンスペースに改行を追加し、その後に次の入力行を追加します。入力がもうなければ、<code class="command">sed</code>は残りのコマンドを処理せず終了します。</p>
<p><samp class="option">-z</samp>を使う場合は、改行の代わりにゼロバイト（ASCIIの「<samp class="samp">NUL</samp>」文字）を行の間に追加します。</p>
<p>既定では、<code class="command">sed</code>は「次の」入力行がなくても終了しません。これはGNU拡張で、<samp class="option">--posix</samp>で無効にできます。<a class="xref" href="/docs/gnu-sed/source/v4-10/manual.html#N_005fcommand_005flast_005fline">最終行でのNコマンド</a>を参照してください。</p>
</dd>
<dt><a class="index-entry-id" id="index-Print-first-line-from-pattern-space"></a>
<a id="index-P-_0028print-first-line_0029-command"></a><span><code class="code">P</code></span></dt>
<dd><p>パターンスペースの最初の改行までの部分を表示します。</p>
</dd>
<dt><a class="index-entry-id" id="index-Copy-pattern-space-into-hold-space"></a>
<a class="index-entry-id" id="index-Replace-hold-space-with-copy-of-pattern-space"></a>
<a class="index-entry-id" id="index-Hold-space_002c-copying-pattern-space-into"></a>
<a id="index-h-_0028hold_0029-command"></a><span><code class="code">h</code></span></dt>
<dd><p>ホールドスペースの内容をパターンスペースの内容で置き換えます。</p>
</dd>
<dt><a class="index-entry-id" id="index-Append-pattern-space-to-hold-space"></a>
<a class="index-entry-id" id="index-Hold-space_002c-appending-from-pattern-space"></a>
<a id="index-H-_0028append-Hold_0029-command"></a><span><code class="code">H</code></span></dt>
<dd><p>ホールドスペースの内容に改行を追加し、その後にパターンスペースの内容を追加します。</p>
</dd>
<dt><a class="index-entry-id" id="index-Copy-hold-space-into-pattern-space"></a>
<a class="index-entry-id" id="index-Replace-pattern-space-with-copy-of-hold-space"></a>
<a class="index-entry-id" id="index-Hold-space_002c-copy-into-pattern-space"></a>
<a id="index-g-_0028get_0029-command"></a><span><code class="code">g</code></span></dt>
<dd><p>パターンスペースの内容をホールドスペースの内容で置き換えます。</p>
</dd>
<dt><a class="index-entry-id" id="index-Append-hold-space-to-pattern-space"></a>
<a class="index-entry-id" id="index-Hold-space_002c-appending-to-pattern-space"></a>
<a id="index-G-_0028appending-Get_0029-command"></a><span><code class="code">G</code></span></dt>
<dd><p>パターンスペースの内容に改行を追加し、その後にホールドスペースの内容を追加します。</p>
</dd>
<dt><a class="index-entry-id" id="index-Exchange-hold-space-with-pattern-space"></a>
<a class="index-entry-id" id="index-Hold-space_002c-exchange-with-pattern-space"></a>
<a id="index-x-_0028eXchange_0029-command"></a><span><code class="code">x</code></span></dt>
<dd><p>ホールドスペースとパターンスペースの内容を交換します。</p>
</dd>
