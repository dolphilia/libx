<h3 class="section" id="Command_002dLine-Options-1"><span>2.2 コマンドラインオプション</span></h3>
<p><code class="command">sed</code>を起動する完全な形式は次のとおりです。</p>
<div class="example">
<pre class="gnu-sed-literal">sed OPTIONS... [SCRIPT] [INPUTFILE...]&#10;</pre></div>
<p><code class="command">sed</code>には次のコマンドラインオプションを指定できます。</p>
<dl class="table">
<dt><a class="index-entry-id" id="index-Version_002c-printing"></a>
<a id="index-_002d_002dversion"></a><span><code class="code">--version</code></span></dt>
<dd><p>実行中の<code class="command">sed</code>の版と著作権表示を出力して終了します。</p>
</dd>
<dt><a class="index-entry-id" id="index-Usage-summary_002c-printing"></a>
<a id="index-_002d_002dhelp"></a><span><code class="code">--help</code></span></dt>
<dd><p>これらのコマンドラインオプションとバグ報告先を簡潔にまとめた使用法を表示して終了します。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dquiet"></a>
<a class="index-entry-id" id="index-_002d_002dsilent"></a>
<a class="index-entry-id" id="index-Disabling-autoprint_002c-from-command-line"></a>
<a id="index-_002dn"></a><span><code class="code">-n</code></span></dt>
<dt><code class="code">--quiet</code></dt>
<dt><code class="code">--silent</code></dt>
<dd><p>既定では、<code class="command">sed</code>はスクリプトを処理する各サイクルの最後にパターンスペースを表示します（<a class="pxref" href="/docs/gnu-sed/source/v4-10/manual.html#Execution-Cycle"><code class="code">sed</code>の動作</a>を参照）。これらのオプションは自動表示を無効にし、<code class="command">sed</code>は<code class="code">p</code>コマンドで明示的に指示されたときだけ出力を生成します。</p>
</dd>
<dt><a class="index-entry-id" id="index-GNU-extensions_002c-debug"></a>
<a id="index-_002d_002ddebug"></a><span><code class="code">--debug</code></span></dt>
<dd><p>入力されたsedプログラムを正規形で表示し、プログラムの実行に注釈を付けます。</p><div class="example">
<pre class="gnu-sed-literal">$ echo 1 | sed '\%1%s21232'&#10;3&#10;&#10;$ echo 1 | sed --debug '\%1%s21232'&#10;SED PROGRAM:&#10;  /1/ s/1/3/&#10;INPUT:   'STDIN' line 1&#10;PATTERN: 1&#10;COMMAND: /1/ s/1/3/&#10;PATTERN: 3&#10;END-OF-CYCLE:&#10;3&#10;</pre></div>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dexpression"></a>
<a class="index-entry-id" id="index-Script_002c-from-command-line"></a>
<a id="index-_002de"></a><span><code class="code">-e <var class="var">script</var></code></span></dt>
<dt><code class="code">--expression=<var class="var">script</var></code></dt>
<dd><p><var class="var">script</var>にあるコマンドを、入力の処理時に実行するコマンドの集合へ追加します。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dfile"></a>
<a class="index-entry-id" id="index-Script_002c-from-a-file"></a>
<a id="index-_002df"></a><span><code class="code">-f <var class="var">script-file</var></code></span></dt>
<dt><code class="code">--file=<var class="var">script-file</var></code></dt>
<dd><p>ファイル<var class="var">script-file</var>に含まれるコマンドを、入力の処理時に実行するコマンドの集合へ追加します。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002din_002dplace"></a>
<a class="index-entry-id" id="index-In_002dplace-editing_002c-activating"></a>
<a class="index-entry-id" id="index-GNU-extensions_002c-in_002dplace-editing"></a>
<a id="index-_002di"></a><span><code class="code">-i[<var class="var">SUFFIX</var>]</code></span></dt>
<dt><code class="code">--in-place[=<var class="var">SUFFIX</var>]</code></dt>
<dd><p>このオプションはファイルを直接編集することを指定します。GNU <code class="command">sed</code>は一時ファイルを作成し、標準出力の代わりにそのファイルへ出力を送ることで、これを実現します<a class="footnote" href="/docs/gnu-sed/v4-10/ja/01-guide/03-command-line-options/#FOOT1" id="DOCF1"><sup>1</sup></a>。</p>
<p>このオプションは<samp class="option">-s</samp>を暗黙に指定します。</p>
<p>ファイルの末尾に達すると、一時ファイルを出力ファイルの元の名前へ改名します。拡張子を指定した場合は、一時ファイルを改名する前に、古いファイルの名前をその拡張子で変更し、バックアップを作成します<a class="footnote" href="/docs/gnu-sed/v4-10/ja/01-guide/03-command-line-options/#FOOT2" id="DOCF2"><sup>2</sup></a>。</p>
<a class="index-entry-id" id="index-In_002dplace-editing_002c-Perl_002dstyle-backup-file-names"></a>
<p>次の規則に従います。拡張子に<code class="code">*</code>が含まれない場合は、現在のファイル名の末尾に接尾辞として追加します。拡張子に一つ以上の<code class="code">*</code>文字が含まれる場合は、<em class="emph">各</em>アスタリスクを現在のファイル名に置き換えます。これにより、バックアップファイルに接尾辞の代わりに（または接尾辞と併せて）接頭辞を付けたり、元のファイルのバックアップを別のディレクトリに置いたりできます。ただし、そのディレクトリはすでに存在している必要があります。</p>
<p>拡張子を指定しなければ、バックアップを作らずに元のファイルを上書きします。</p>
<p><samp class="option">-i</samp>は省略可能な引数を取るため、その直後に別の短いオプションを続けないようにしてください。</p><dl class="table">
<dt><code class="code">sed -Ei '...' FILE</code></dt>
<dd><p>バックアップ用の接尾辞を付けない<samp class="option">-E -i</samp>と同じです。<samp class="file">FILE</samp>は、バックアップを作らず直接編集されます。</p>
</dd>
<dt><code class="code">sed -iE '...' FILE</code></dt>
<dd><p>これは<samp class="option">--in-place=E</samp>と同じで、<samp class="file">FILE</samp>のバックアップとして<samp class="file">FILEE</samp>を作成します。</p></dd>
</dl>
<p><samp class="option">-n</samp>と<samp class="option">-i</samp>の併用には注意してください。前者は行の自動表示を無効にし、後者はバックアップを作らずファイルを直接変更します。不用意に使い、明示的な<code class="code">p</code>コマンドも指定しなければ、出力ファイルは空になります。</p><div class="example">
<pre class="gnu-sed-literal"># WRONG USAGE: 'FILE' will be truncated.&#10;sed -ni 's/foo/bar/' FILE&#10;</pre></div>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dline_002dlength"></a>
<a class="index-entry-id" id="index-Line-length_002c-setting"></a>
<a id="index-_002dl"></a><span><code class="code">-l <var class="var">N</var></code></span></dt>
<dt><code class="code">--line-length=<var class="var">N</var></code></dt>
<dd><p><code class="code">l</code>コマンドの既定の折り返し幅を指定します。0（ゼロ）は、長い行を折り返さないことを意味します。指定しなければ70になります。</p>
</dd>
<dt><a class="index-entry-id" id="index-GNU-extensions_002c-disabling"></a>
<a id="index-_002d_002dposix"></a><span><code class="code">--posix</code></span></dt>
<dd><p>GNU <code class="command">sed</code>にはPOSIX sedへの拡張がいくつかあります。移植可能なスクリプトを書きやすくするため、このオプションは追加コマンドも含め、このマニュアルに記載されたすべての拡張を無効にします。<a class="index-entry-id" id="index-POSIXLY_005fCORRECT-behavior_002c-enabling"></a>ほとんどの拡張は、POSIXで定められた構文の範囲外にある<code class="command">sed</code>プログラムを受け付けるものですが、一部の拡張（<a class="ref" href="/docs/gnu-sed/source/v4-10/manual.html#Reporting-Bugs">バグの報告</a>で説明する<code class="command">N</code>コマンドの動作など）は実際に規格に違反します。後者の種類の拡張だけを無効にしたければ、変数<code class="code">POSIXLY_CORRECT</code>を空でない値に設定できます。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dbinary"></a>
<a id="index-_002db"></a><span><code class="code">-b</code></span></dt>
<dt><code class="code">--binary</code></dt>
<dd><p>このオプションはすべてのプラットフォームで使用できますが、OSがテキストファイルとバイナリーファイルを区別する環境でだけ効果があります。MS-DOS、Windows、Cygwinのように区別がある場合、テキストファイルの行はキャリッジリターン<em class="emph">と</em>ラインフィード文字で区切られ、<code class="command">sed</code>には末尾のCRは見えません。このオプションを指定すると、<code class="command">sed</code>は入力ファイルをバイナリーモードで開き、この特別な処理を要求せず、ラインフィードで行が終わるものとして扱います。</p>
</dd>
<dt><a id="index-_002d_002dfollow_002dsymlinks"></a><span><code class="code">--follow-symlinks</code></span></dt>
<dd><p>このオプションはシンボリックリンクをサポートするプラットフォームでだけ使用でき、<samp class="option">-i</samp>も指定した場合にだけ効果があります。その場合、コマンドラインで指定したファイルがシンボリックリンクなら、<code class="command">sed</code>はリンクをたどり、リンクの最終的な参照先を編集します。既定の動作ではシンボリックリンクを切り離すため、リンク先は変更されません。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002dr"></a>
<a class="index-entry-id" id="index-_002d_002dregexp_002dextended"></a>
<a class="index-entry-id" id="index-Extended-regular-expressions_002c-choosing"></a>
<a class="index-entry-id" id="index-GNU-extensions_002c-extended-regular-expressions"></a>
<a id="index-_002dE"></a><span><code class="code">-E</code></span></dt>
<dt><code class="code">-r</code></dt>
<dt><code class="code">--regexp-extended</code></dt>
<dd><p>基本正規表現の代わりに拡張正規表現を使います。拡張正規表現は<code class="command">egrep</code>が受け付けるもので、通常はバックスラッシュが少なくなるため、読みやすくなることがあります。かつてはGNU拡張でしたが、<samp class="option">-E</samp>はその後POSIX規格にも追加されました（http://austingroupbugs.net/view.php?id=528）。移植性を考慮する場合は<samp class="option">-E</samp>を使ってください。GNU sedは何年も前から未記載のオプションとして<samp class="option">-E</samp>を受け付けており、*BSDのsedも長年<samp class="option">-E</samp>を受け付けています。ただし、<samp class="option">-E</samp>を使ったスクリプトは、ほかの古いシステムへ移植できない可能性があります。<a class="xref" href="/docs/gnu-sed/source/v4-10/manual.html#ERE-syntax">拡張正規表現</a>を参照してください。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dseparate"></a>
<a class="index-entry-id" id="index-Working-on-separate-files"></a>
<a id="index-_002ds"></a><span><code class="code">-s</code></span></dt>
<dt><code class="code">--separate</code></dt>
<dd><p>既定では、<code class="command">sed</code>はコマンドラインで指定されたファイルを、一つの連続した長いストリームとして扱います。このGNU <code class="command">sed</code>拡張では、それぞれを別々のファイルとして扱えます。範囲アドレス（「<samp class="samp">/abc/,/def/</samp>」など）は複数のファイルにまたがれず、行番号は各ファイルの先頭を基準とし、<code class="code">$</code>は各ファイルの最終行を指し、<code class="code">R</code>コマンドが読み込むファイルは各入力ファイルの処理開始時に先頭へ戻されます。</p>
</dd>
<dt><a class="index-entry-id" id="index-Sandbox-mode"></a>
<a id="index-_002d_002dsandbox"></a><span><code class="code">--sandbox</code></span></dt>
<dd><p>サンドボックスモードでは、<code class="code">e/w/r</code>コマンドは拒否されます。これらを含むプログラムは実行されず、中止されます。サンドボックスモードでは、<code class="command">sed</code>がコマンドラインで指定された入力ファイルだけを操作し、外部プログラムを実行できないことが保証されます。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dunbuffered"></a>
<a class="index-entry-id" id="index-Unbuffered-I_002fO_002c-choosing"></a>
<a id="index-_002du"></a><span><code class="code">-u</code></span></dt>
<dt><code class="code">--unbuffered</code></dt>
<dd><p>入力と出力のバッファリングを、実用上可能な限り小さくします。「<samp class="samp">tail -f</samp>」のようなものから入力を受け取り、変換後の出力をできるだけ早く見たい場合に特に役立ちます。</p>
</dd>
<dt><a class="index-entry-id" id="index-_002d_002dnull_002ddata"></a>
<a class="index-entry-id" id="index-_002d_002dzero_002dterminated"></a>
<a id="index-_002dz"></a><span><code class="code">-z</code></span></dt>
<dt><code class="code">--null-data</code></dt>
<dt><code class="code">--zero-terminated</code></dt>
<dd><p>入力を、改行の代わりにゼロバイト（ASCIIの「<samp class="samp">NUL</samp>」文字）で終わる行の集合として扱います。「<samp class="samp">sort -z</samp>」や「<samp class="samp">find -print0</samp>」などのコマンドと併用して、任意のファイル名を処理できます。</p></dd>
</dl>
<p>コマンドラインに<samp class="option">-e</samp>、<samp class="option">-f</samp>、<samp class="option">--expression</samp>、<samp class="option">--file</samp>のどのオプションも指定されていなければ、オプションでない最初の引数を、実行する<var class="var">script</var>として扱います。</p>
<a class="index-entry-id" id="index-Files-to-be-processed-as-input"></a>
<p>上記の処理後にコマンドライン引数が残っていれば、処理する入力ファイルの名前と解釈します。<a class="index-entry-id" id="index-Standard-input_002c-processing-as-input"></a>ファイル名「<samp class="samp">-</samp>」は標準入力ストリームを表します。ファイル名を指定しなければ、標準入力を処理します。</p>
