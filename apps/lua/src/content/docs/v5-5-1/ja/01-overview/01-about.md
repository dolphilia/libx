# Lua 5.5へようこそ

## <a id="about"></a>Luaについて

Luaは、ブラジルのリオデジャネイロ・カトリカ大学[PUC-Rio](https://www.lua.org/authors.html)の[チーム](https://www.puc-rio.br/)が開発している、強力で効率的かつ軽量な、組み込み可能なスクリプト言語である。Luaは[フリーソフトウェア](/docs/lua/v5-5-1/ja/01-overview/03-license/#license)であり、世界中の[多くの製品やプロジェクト](https://www.lua.org/uses.html)で利用されている。

Luaの[公式ウェブサイト](https://www.lua.org/)では、[概要](https://www.lua.org/about.html)、[利用開始](https://www.lua.org/start.html)のヒント、更新された[ドキュメント](https://www.lua.org/docs.html)など、Luaに関する完全な情報を提供している。特に[リファレンスマニュアル](https://www.lua.org/manual/5.5/)は、このパッケージに同梱された[ローカルコピー](https://www.lua.org/manual/5.5/contents.html)とわずかに異なる場合がある。
