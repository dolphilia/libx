<tbody><tr>&#10;          <td class="memname">#define XXH_NO_LONG_LONG</td>&#10;        </tr>&#10;      </tbody></table>&#10;</div><div class="memdoc">&#10;&#10;<p>64ビットのコードを無効にする場合に定義します。 </p>&#10;<p>使用するのが <a class="el" href="/docs/xxhash/v0-8-4/ja/02-api/12-group___x_x_h32__family/" title="XXH32ファミリー">XXH32ファミリー</a> のみで、厳密なC90コンパイラーを使う場合に役立ちます。 </p>&#10;&#10;</div>&#10;</div>&#10;<a user"><dt>指定可能な選択肢：</dt><dd></dd></dl>&#10;<ul>&#10;<li><span class="tt"><a class="el" href="#ga04b48241beb7c34e5929d328cf5cc71a" を参照してください。</li>&#10;</ul>&#10;<p>方法は次の優先順位で選んでください（0 &gt; 3 &gt; 1 &gt; 2）。 </p>&#10;&#10;</div>&#10;</div>&#10;<a id="ga1e9850064fc149181cce7431f40a990a" name="ga1e9850064fc149181cce7431f40a990a"></a>&#10;<h2 class="memtitle"><span class="permalink"><a href="#ga1e9850064fc149181cce7431f40a990a">◆&nbsp;</a></span>XXH_SIZE_OPT</h2>&#10;&#10;<div </tr>&#10;      </tbody></table>&#10;</div><div class="memdoc">&#10;&#10;<p>xxHashのサイズ最適化の程度を制御します。 </p>&#10;<p>xxHashはコンパイルすると、比較的大きなバイナリーになりがちです。主な原因は、 <a class="el" href="/docs/xxhash/v0-8-4/ja/02-api/14-group___x_x_h3__family/" title="XXH3ファミリー">XXH3ファミリー</a>
