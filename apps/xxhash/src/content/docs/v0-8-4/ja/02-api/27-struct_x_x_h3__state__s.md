### 固定コードとの追加照合

- `useSeed`：原文は予約フィールドと説明していますが、固定コードは短い入力のdigestでseed版とsecret版を選ぶためにこの値を読み取ります。内部resetでは`seed != 0`で設定し、`XXH3_64bits_reset_withSecretandSeed`ではseedがゼロでも1を設定します。
- `secretLimit`：原文はsecretのサイズと説明していますが、固定コードの内部resetでは`secretSize - XXH_STRIPE_LEN`を設定します。`XXH_STRIPE_LEN`は64です。digest処理は必要な箇所でこの値に`XXH_STRIPE_LEN`を加えてsecretのサイズを得ます。

これらは固定ソースの静的照合による補足です。原文のフィールド説明を保持しています。
