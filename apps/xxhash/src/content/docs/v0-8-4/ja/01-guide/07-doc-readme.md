xxHashの仕様
=====================

このディレクトリーには、xxHashファミリーのハッシュアルゴリズムに関する文書と参照資料が含まれています。

- [xxhash_spec.md](/docs/xxhash/v0-8-4/ja/01-guide/08-doc-xxhash_spec/)は、XXH32、XXH64、XXH3の仕様を定めています。
- [xxhash.cry](/docs/xxhash/source/v0-8-4/doc/xxhash.cry.txt)は、XXH32とXXH64について、実行可能なCryptol仕様を提供しています。

これらのアルゴリズムの読みやすい実装については、学習用ライブラリ[xxhash-clean](https://github.com/easyaspi314/xxhash-clean)を参照してください。作者は[@easyaspi314](https://github.com/easyaspi314)です。このプロジェクトは可読性を優先し、本リポジトリの参照実装は速度を優先しています。
