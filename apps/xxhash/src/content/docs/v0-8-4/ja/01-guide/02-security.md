# セキュリティ方針

## サポートするバージョン

セキュリティ更新は最新リリースにだけ適用します。

## 脆弱性の報告

このプロジェクトでセキュリティ上の脆弱性を見つけた場合は、非公開で報告してください。**公開のIssueとして開示しないでください。** 非公開での報告により、公表前に報告者と協力して問題を修正する時間を確保でき、パッチのリリース前に脆弱性が悪用される可能性を減らせます。

[セキュリティアドバイザリー](https://github.com/Cyan4973/xxHash/security/advisories/new)から報告してください。

このプロジェクトは、ボランティアのチームが合理的に可能な範囲で保守しています。そのため、公表する前に、修正に取り組む期間を少なくとも90日確保してください。
