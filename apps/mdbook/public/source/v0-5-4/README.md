# mdBook 0.5.4 — Libx static edition source

This bundle provides the preferred editable sources for the complete 31-chapter English guide and unofficial Japanese translation, the full fixed upstream source archive, notices, app CSS/configuration, and the pinned shared build context. See SOURCE_COMPONENTS.json. The documentation and its adaptations are MPL-2.0; illustration/SVG and other materials retain their original separate terms and attribution. The MPL notice does not relicense unrelated Libx build code.

Edit `workspace/apps/mdbook/src/content/docs/v0-5-4/{en,ja}/01-guide/`. These are the preferred editable raw-HTML Markdown inputs, not built HTML. Keep the corresponding `public/source/v0-5-4/edited/{en,ja}/` copies synchronized when publishing changes. The stored `docs/notes/document-import/mdbook/v0-5-4/` inputs and review records describe the fixed reviewed edition; changes require updated evidence.

Build with Node 20 or later and pnpm 10.10.0:

    cd workspace
    pnpm install --frozen-lockfile
    pnpm --filter=apps-mdbook build

The app output is `apps/mdbook/dist/`; serve it under `/docs/mdbook/`. Third-party dependencies are resolved by the lock and are not claimed to be vendored in this ZIP. The current source ZIP is excluded recursively: copy this supplied ZIP to `apps/mdbook/public/source/v0-5-4/source.zip` before building to reproduce its download URL.

Regenerate the frozen Libx edition into a separate directory:

    python3 scripts/importers/import-mdbook-0.5.4.py --output=.tmp/mdbook-regenerated

This Python 3.10+ command needs no third-party Python package. It transforms the fixed mdBook 0.5.4 HTML body intermediate (which already expanded the fixed Markdown/includes/helper version strings), preserved navigation, reviewed metadata, and Japanese drafts into all 62 editable documents. It does not rebuild the original website or retranslate the Japanese prose. Complete original Markdown/helper inputs are separately preserved in the upstream archive. The intermediate provenance and SHA values are in regeneration/PAGES.json. `pnpm --filter=apps-mdbook check:content` checks regenerated bytes, source/review bindings, links and preferred sources; `check:rendered` additionally checks a built app. These checks complement the saved full semantic review and do not substitute a new review.

Libx modifications: static route/asset mapping and original SUMMARY navigation; raw-code newline/bracket encoding; complete code lines including original hidden lines; Japanese translation; source and static-edition notes in the footer; scoped SVG/code styles; static image presentation. Code editing/execution and MathJax rendering are provided by the linked original project. Original TeX, code, literal HTML examples, illustration geometry and notice text are retained. Original source limitations or technical examples are not independently audited.
