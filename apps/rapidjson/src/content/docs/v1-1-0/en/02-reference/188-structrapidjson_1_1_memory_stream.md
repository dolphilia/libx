input byte stream. </p>&#10;<p>This class is mainly for being wrapped by <a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/017-classrapidjson_1_1_encoded_input_stream/" title="Input byte stream wrapper with a statically bound encoding.">EncodedInputStream</a> or <a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/007-classrapidjson_1_1_auto_u_t_f_input_stream/" title="Input stream wrapper with dynamically bound encoding and automatic encoding detection.">AutoUTFInputStream</a>.</p>&#10;<p>It is similar to FileReadBuffer but the source is an in-memory buffer instead of a file.</p>&#10;<p>Differences between <a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/188-structrapidjson_1_1_memory_stream/" title="Represents an in-memory input byte stream.">MemoryStream</a> and <a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/148-namespacerapidjson/#a021f77051e9f85188fc2f71ff5a15ebc" title="String stream with UTF8 encoding.">StringStream</a>:</p><ol type="1">&#10;<li><a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/148-namespacerapidjson/#a021f77051e9f85188fc2f71ff5a15ebc" title="String stream with UTF8 encoding.">StringStream</a> has encoding but <a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/188-structrapidjson_1_1_memory_stream/" title="Represents an in-memory input byte stream.">MemoryStream</a> is a byte stream.</li>&#10;<li><a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/188-structrapidjson_1_1_memory_stream/" title="Represents an in-memory input byte stream.">MemoryStream</a> needs size of the source buffer and the buffer don't need to be null terminated. <a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/148-namespacerapidjson/#a021f77051e9f85188fc2f71ff5a15ebc" title="String stream with UTF8 encoding.">StringStream</a> assume null-terminated string as source.</li>&#10;<li><a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/188-structrapidjson_1_1_memory_stream/" title="Represents an in-memory input byte stream.">MemoryStream</a> supports Peek4() for encoding detection. <a class="el" href="/docs/rapidjson/v1-1-0/en/02-reference/148-namespacerapidjson/#a021f77051e9f85188fc2f71ff5a15ebc" title="String stream with UTF8
