class="doxsection"><a class="anchor" id="autotoc_md2"></a>はじめに</h2>&#10;<p>RapidJSONは、C++用のJSONパーサー・生成器です。<a href="http://rapidxml.sourceforge.net/">RapidXml</a>に着想を得ています。</p>&#10;<ul>&#10;<li>RapidJSONは<b>小さいライブラリー</b>ですが、<b>機能は完備しています</b>。SAX形式とDOM形式の両方のAPIに対応し、SAXパーサーはわずか500行ほどのコードです。</li>&#10;<li>RapidJSONは<b>高速</b>です。性能は<span class="tt">strlen()</span>に匹敵する場合があります。任意でSSE2/SSE4.2による高速化にも対応します。</li>&#10;<li>RapidJSONは<b>自己完結</b>で、<b>ヘッダーファイルだけの構成</b>です。BOOSTなどの外部ライブラリーにも、STLにも依存しません。</li>&#10;<li>RapidJSONは<b>メモリー効率に優れた設計</b>です。大半の32ビット・64ビット環境で、各JSON値は正確に16バイトを占めます（文字列のテキストを除く）。既定では高速なメモリーアロケーターを使い、解析中にパーサーがメモリーをコンパクトに確保します。</li>&#10;<li>RapidJSONは<b>Unicodeを扱いやすい設計</b>です。UTF-8、UTF-16、UTF-32（LEとBE）と、それらの検出・妥当性検証・エンコーディング変換を内部で処理します。たとえば、UTF-8ファイルを読み、DOM内のJSON文字列をRapidJSONでUTF-16へ変換できます。サロゲートと「\u0000」（ヌル文字）にも対応します。</li>&#10;</ul>&#10;<p>さらに詳しい機能は、<a class="el" href="/docs/rapidjson/v1-1-0/ja/01-guide/02-features/" title="Features">こちら</a>を参照してください。</p>&#10;<p>JSON（JavaScript Object Notation）は、軽量なデータ交換形式です。RapidJSONはRFC7159/ECMA-404に完全に準拠することを目指し、任意で緩和された構文にも対応します。JSONの詳しい情報は、次の資料で確認できます。</p><ul>&#10;<li><a href="http://json.org/">JSONの紹介</a></li>&#10;<li><a
