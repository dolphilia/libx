<div class="contents rapidjson-document">&#10;<div class="textblock"><p><a class="anchor" id="autotoc_md30"></a></p>&#10;<h1 class="doxsection"><a class="anchor" id="autotoc_md31"></a>&#10;General</h1>&#10;<ul>&#10;<li>Cross-platform<ul>&#10;<li>Compilers: Visual Studio, gcc, clang, etc.</li>&#10;<li>Architectures: x86, x64, ARM, etc.</li>&#10;<li>Operating systems: Windows, Mac OS X, Linux, iOS, Android, etc.</li>&#10;</ul>&#10;</li>&#10;<li>Easy installation<ul>&#10;<li>Header files only library. Just copy the headers to your project.</li>&#10;</ul>&#10;</li>&#10;<li>Self-contained, minimal dependences<ul>&#10;<li>No STL, BOOST, etc.</li>&#10;<li>Only included <span class="tt">&lt;cstdio&gt;</span>, <span class="tt">&lt;cstdlib&gt;</span>, <span class="tt">&lt;cstring&gt;</span>, <span class="tt">&lt;inttypes.h&gt;</span>, <span class="tt">&lt;new&gt;</span>, <span class="tt">&lt;stdint.h&gt;</span>.</li>&#10;</ul>&#10;</li>&#10;<li>Without C++ exception, RTTI</li>&#10;<li>High performance<ul>&#10;<li>Use template and inline functions to reduce function call overheads.</li>&#10;<li>Internal optimized Grisu2 and floating point parsing implementations.</li>&#10;<li>Optional SSE2/SSE4.2 support.</li>&#10;</ul>&#10;</li>&#10;</ul>&#10;<h1 class="doxsection"><a class="anchor" id="autotoc_md32"></a>&#10;Standard compliance</h1>&#10;<ul>&#10;<li>RapidJSON should be fully RFC4627/ECMA-404 compliance.</li>&#10;<li>Support JSON Pointer (RFC6901).</li>&#10;<li>Support JSON Schema Draft v4.</li>&#10;<li>Support Unicode surrogate.</li>&#10;<li>Support null character (<span class="tt">"\u0000"</span>)<ul>&#10;<li>For example, <span class="tt">["Hello\u0000World"]</span> can be parsed and handled gracefully. There is API for getting/setting lengths of string.</li>&#10;</ul>&#10;</li>&#10;<li>Support optional relaxed syntax.<ul>&#10;<li>Single line (<span class="tt">// ...</span>) and multiple line (<span class="tt">/* ... */</span>) comments (<span class="tt">kParseCommentsFlag</span>).</li>&#10;<li>Trailing commas at the end of objects and arrays (<span class="tt">-Infinity</span> as <span class="tt">double</span> values (<span class="tt">kParseNanAndInfFlag</span>)</li>&#10;</ul>&#10;</li>&#10;<li><a href="http://github.com/miloyip/rapidjson/blob/master/doc/npm.md">NPM compliant</a>.</li>&#10;</ul>&#10;<h1 class="doxsection"><a class="anchor" and in-memory representation.</li>&#10;</ul>&#10;</li>&#10;<li>Support automatic detection of encodings in input stream.</li>&#10;<li>Support transcoding between encodings internally.<ul>&#10;<li>For example, you can read a UTF-8 file and let RapidJSON transcode the JSON strings into UTF-16 in the DOM.</li>&#10;</ul>&#10;</li>&#10;<li>Support encoding validation internally.<ul>&#10;<li>For default the character types are <span class="tt">char</span> for UTF8, <span class="tt">wchar_t</span> for UTF16, <span class="tt">uint32_t</span> for UTF32.</li>&#10;</ul>&#10;</li>&#10;<li>Support Users can pick their choices according to scenarios.</li>&#10;</ul>&#10;</li>&#10;</ul>&#10;<h1 class="doxsection"><a class="anchor" id="autotoc_md35"></a>&#10;Parsing</h1>&#10;<ul>&#10;<li>Recursive
