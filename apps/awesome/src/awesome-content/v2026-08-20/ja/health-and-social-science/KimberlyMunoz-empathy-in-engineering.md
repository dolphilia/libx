## 言葉

職場でより共感的な文化を築く方法とその利点に関する記事（📰）、書籍（📚）、動画（📹）。


### ユーザーへの共感

-  [Too sensitive: About microaggressions in UX](https://medium.com/@sara_ann_marie/too-sensitive-9752a86a8382) 📰 - Medium の Sara Ann Marie が、UX における小さな綻びがどのようにユーザーを疎外するかを論じています。
- [The Fantasy and Abuse of the Manipulable User](https://modelviewculture.com/pieces/the-fantasy-and-abuse-of-the-manipulable-user) 📰 - Model View Culture の Betsy Haibel が、UX の「グレーパターン」と「ダークパターン」がウェブに広く存在することを論じています。
- [Empathy: The key to a successful software project](https://www.oreilly.com/ideas/empathy-the-key-to-a-successful-software-project) 📰 - O'Reilly の Gregory Brown が、最も重要なステークホルダーを特定し、最良の製品を構築するために質問する方法を論じています。
- [On Facebook's "Compassion Team"](http://www.nytimes.com/2016/03/13/fashion/facebook-breakup-compassion-team.html?_r=0) 📰 - The New York Times が、Facebook をより人間的にする任務を負った Facebook の「Compassion Team」を取り上げています。
- [Designing for Disaster](https://vimeo.com/148927676) 📹 - An Event Apart の Eric Meyer が、人生で最も困難だった日と、人生で最悪の日を過ごしているかもしれない人々のためにもデザインすることの重要性を語っています。
- [Design for Real Life](https://abookapart.com/products/design-for-real-life) 📚 - Eric Meyer と Sara Wachter-Boettcher によるこの本は、ストレスのかかる事例を特定し、思いやりをもってデザインする技法を紹介しています。


### 仲間への共感

- [We Invite Everyone at Etsy to Do an Engineering Rotation: Here’s why](https://codeascraft.com/2014/12/22/engineering-rotation/) 📰 - Etsy の Code as Craft ブログが、デザイナーとプロダクトマネージャーにもエンジニアリングのローテーションを経験させる理由を論じています。
- [On Empathy & Pull Requests at Slack](https://slack.engineering/on-empathy-pull-requests-979e4257d158) 📰 | [Followup](https://slack.engineering/how-about-code-reviews-2695fb10d034) 📰 - Slack Engineering ブログが、良いプルリクエストはチームメイトへの共感の表れであることを掘り下げています。
- [Blameless PostMortems and a Just Culture](https://codeascraft.com/2012/05/22/blameless-postmortems/) 📰 - Etsy の Code as Craft ブログが、非難しないポストモーテムを通じて学ぶ観点から、どのように失敗を捉えているかを論じています。
- [What Google Learned From Its Quest to Build the Perfect Team](http://www.nytimes.com/2016/02/28/magazine/what-google-learned-from-its-quest-to-build-the-perfect-team.html) 📰 - The New York Times が、Google のデータ駆動型文化が、コミュニケーションと共感を中心に据えた規範ほど良いチームを作ると発見した経緯をまとめています。
- [Difficult Conversations: How to Discuss What Matters Most](http://smile.amazon.com/gp/product/B004CR6ALA/) 📚  - Harvard Negotiation Project の Douglas Stone、Bruce Patton、Sheila Heen が、「第三の物語」を考慮する一連の技法を通じて難しい会話を扱う方法を記しています。
- [Engineering Empathy: Fostering an Inclusive Culture at our Code School](http://www.alterconf.com/talks/engineering-empathy-fostering-inclusive-culture-our-code-school) 📹 - Lateesha Thomas が、Alterconf SF 2016 において、なぜ DevBootcamp のカリキュラムに共感が含まれるのかを論じています。
- [Empathy Explainer](https://www.youtube.com/watch?v=1Evwgu369Jw) 📹 - Brené Brown による、共感とは何か、同情とどう異なるのかを説明する短いアニメーション。

### 採用における共感

- [A Guide to Empathetic Hiring Process](https://medium.com/@fox/a-guide-to-empathetic-hiring-processes-c11c7ce0cd49) 📰 - Medium の @Fox が、雇用主が求職者に親切にできるいくつかの簡単な方法を論じています。


## JavaScript

ときには、上記の戦略を実装するためにコードサンプルが必要です。

### シミュレーション
- [JS Simulation of Dyslexia](http://geon.github.io/programming/2016/03/03/dsxyliea) - 失読症の状態でテキストのまとまりを読む感覚を再現するシミュレーションです。

### ブックマークレット
- [JS Bookmarklet Simulating Colorblindness](https://github.com/Altreus/colourblind) - 任意のページを受け取り、色覚異常の状態でナビゲートする感覚を再現する JS ブックマークレットです。
- [NoCoffee: JS Bookmarklet Simulating Low Vision Scenarios](https://accessgarage.wordpress.com/2013/02/09/458/) - 任意のページを受け取り、ロービジョンの状況をシミュレートする JS ブックマークレットです。
