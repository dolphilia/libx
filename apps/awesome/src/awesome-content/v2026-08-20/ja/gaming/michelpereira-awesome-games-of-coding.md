## 言語非依存

- [Artifacts MMO](https://artifactsmmo.com/) - Artifactsは、APIで任意のプログラミング言語を使いキャラクターを制御できるサンドボックスMMORPGです。
- [Lambda Spellcrafting Academy](https://www.bittwiddlegames.com/lambda-spellcrafting-academy/) - パズルを解くために呪文を構築するビジュアルプログラミング／パズルゲーム。入門プログラミングと、いくつかのデータ構造・アルゴリズムを扱います。言語はLispに着想を得ていますが、ゲームは大半の言語に適用できるプログラミング基礎に焦点を当てます。
- [Codingame](https://www.codingame.com/home) - 学習と競技のためのプラットフォーム。さまざまなマルチプレイヤーゲームやコンテスト、最適化チャレンジ、ソロパズルを提案します。自身で貢献することもできます。言語を選び、グラフィックを楽しみましょう。
- [CodeCombat](https://codecombat.com) - ヒーローを選び、Kithgard Dungeonのオーガの巡回、溶岩穴、レーザービームをコードで進みます。レベルアップし、宝石と魔法アイテムを獲得して新しいプログラミング能力をアンロックします。このオープンソースプログラミングゲームで、数百万人のプレイヤーに加わり、完全な初心者からPython、JavaScript、CoffeeScript、Luaで高度なマルチプレイヤーAIを書くまで進みましょう。
- [Vindinium](https://www.codingame.com/multiplayer/bot-programming/vindinium) - プレイヤーは選んだプログラミング言語（多数のスターターパックのいずれかを任意で使用）でスクリプトを書き、HTTPリクエストにより16ビットヒーローを制御します。金を集め、他プレイヤーと戦い、酒場を訪れるよう導きます。
- [RealTimeBattle](http://realtimebattle.sourceforge.net) - プログラムで制御されたロボット同士が戦うプログラミングゲーム。レーダーで環境を調べ、大砲で撃って敵を破壊することが目的です。
- [Battlesnake](https://play.battlesnake.com) - クラシックゲームsnakeに基づくマルチプレイヤープログラミング競技Battlesnakeで名声と栄光を競う、世界中の開発者コミュニティに参加しましょう。必要なのはBattlesnake APIを実装するライブウェブサーバーと好みの言語だけです。食べ物を探し、ほかのBattlesnakeを避け、できるだけ長く生き残る戦いを始められます。
- [Coder One](https://www.gocoder.one) - マルチプレイヤーの「Bomberman」風ゲーム、賞金、配信される決勝戦を特徴とする年次AIプログラミング大会。パワーアップを集め爆発物を置きながら2Dグリッド世界を移動し、対戦相手を倒すAIプレイヤーを作成します。PythonまたはTypeScriptスターターキットの一つを使い、Dockerイメージの形でAIを提出します（Go、C++、Rustのコミュニティ提供スターターキットもあります）。

## Python

- [Robocode](https://github.com/turkishviking/Python-Robocode) - 他の戦車と戦うロボット戦車を開発することが目的です。ロボット戦はリアルタイムかつ画面上で実行されます。
- [Robot Rumble](https://robotrumble.org/) - 無料でオープンソースのAI競技プラットフォーム。1x1グリッドベースのアリーナで戦うロボットチームのアルゴリズムをコードし、サイトでほかの人と腕試しします。ロボットは4方向のいずれかに移動・攻撃でき、100ターン後にロボット数の多いチームが勝ちます。PythonとJavaScriptをサポートし、デスクトップベースのコマンドラインツールを備えます。

## Java

- [Robocode](https://robocode.sourceforge.io) - 他の戦車と戦うロボット戦車を開発することが目的です。ロボット戦はリアルタイムかつ画面上で実行されます。


## JavaScript

- [Programming Game](https://programming-game.com) - WebSocket経由でプレイするリアルタイム生存MMORPG。プレイ方法を示す非常にシンプルなブラウザー内[デモ](https://programming-game.com/demo)があります。
- [AdventureLand](https://adventure.land/) - Adventure Landは実験的なインディーMMORPG。誰でも最大4キャラクターをコードでき、生産的な作業の間はJavaScriptに周回を任せられます！
- [Screeps](https://screeps.com) - もうポイント・アンド・クリックはありません！ユニットを自律制御する本物のJavaScriptを書きます。いつでも、どこでも、オフライン中でも。
- [JavaScript Fight Club](https://jsfight.club) - 赤の王と青の王は戦争中です！勝者を決めるためにJavaScriptスキルが必要です。名誉と栄光のために効果的なAIをコードできますか？
- [Elevator Saga](http://play.elevatorsaga.com) - ブラウザーで直接JavaScriptを書き、効率目標に到達するようエレベーターをプログラムします。単純な「getting started」スクリプトから始め、多数の階・複数のエレベーターがあるもっと複雑な状況へ進みます。
- [Untrusted](https://alexnisnevich.github.io/untrusted) - ゲームはローグライク風のプレイ環境と、各レベルを生成するJavaScriptコードのコンソールウィンドウを提示します。ロード時は各レベルをクリアできず、JavaScriptの大半は編集をブロックされています。開かれたままの限られたツールだけを使い、次レベルへの道を開くことが課題です。
- [DeepestWorld](https://deepestworld.com/) - JavaScriptでキャラクターをコードできるブラウザーMMORPG。多数のバイオームと生物が、生きて呼吸する世界を形作る、ロード画面のない無限で永続的なオープンワールドを探索します。
- [BitBurner](https://github.com/bitburner-official/bitburner-src) - 暗いディストピア世界で、プレイヤーは正体不明のハッカーの役割を担うプログラミングベースの放置型増分RPG。ブラウザーでプレイするか、Steamでローカルにインストールできます。

## Scala

- [Robocode](https://github.com/d6y/scala-robot-dev) - Javaまたは.NETで、他の戦車と戦うロボット戦車を開発することが目的です。ロボット戦はリアルタイムかつ画面上で実行されます。
- [Scalatron](http://scalatron.github.io) - コーダーはScalaで書かれたボットプログラムを互いに戦わせます。Scalaプログラミング言語をより学びたい、またはScalaプログラミングスキルを磨きたいプログラマーグループや個人向けの教育リソースです。


## その他

- [Generals IO](http://generals.io) - 土地を拡大し敵と戦う、ペースの速い戦略ゲーム。将軍が取られると負けですが、対戦相手の将軍を捕らえると帝国全体を支配できます。
- [Robo Dojo](http://robodojo.club) - すべての競争相手を排除しようと、他のロボットを構築、破壊、破壊するロボットを作ります。
- [Corewars](http://www.corewars.org) - 2人の対戦相手がプログラムした戦士対戦士を仮想「リング」に置き、死ぬまで戦わせるゲーム。
- [TIS-100](http://www.zachtronics.com/tis-100) - SpaceChemとInfinifactoryの制作者Zachtronicsによるオープンエンドのプログラミングゲーム。破損したコードセグメントを書き直してTIS-100を修復し、その秘密を解き明かします。誰も求めていなかったアセンブリ言語プログラミングゲームです！
- [Shenzhen I/O](http://www.zachtronics.com/shenzhen-io) - マイクロコントローラー、メモリ、論理ゲートなど異なるメーカーの各種コンポーネントを使用して回路を構築し、すべての命令を条件実行できるコンパクトで強力なアセンブリ言語でコードを書きます。
- [MHRD](http://store.steampowered.com/app/576030) - ハードウェア記述言語でさまざまなハードウェア回路を設計するハードウェア設計ゲーム。設計するハードウェア回路は、完全に機能するCPU設計を作るまでより複雑になります。
- [Colobot](https://colobot.info) - ボットに乗る、飛ぶ、探す、運ぶ、補給する、破壊するようプログラムする3Dビデオゲーム。C++とJavaに似たCBOTという言語を使用します。Colobotは次第に難しくなる課題を持つチュートリアル付きキャンペーンを提供し、スキルに挑戦するシナリオもプレイできます。
- [Code Games](http://codegames.io/en) - 宇宙船の振る舞いをコードしてほかのプレイヤーと競うリアルタイムプログラミングゲーム。プログラミング言語は学びやすく、ゲームは非常に楽しいです。トーナメントの一つに登録して賞を競いましょう。
- [Mudlet](http://www.mudlet.org) - MUD（テキストのみのMMORPG）をプレイできるゲームクライアント。MudletでLuaコードを書き、MUDのプレイを支援できます。
- [CSS Diner](http://flukeout.github.io) - CSSセレクターとレイアウトの概念・使用法を教えるCSS項目配置ゲーム。食卓上の皿や弁当箱を表すHTML要素を配置するためCSSを変更します。
- [Guido van Robot](http://gvr.sourceforge.net) - 初心者にプログラミングの基礎を紹介するために設計されたプログラミング言語とフリーソフトウェアアプリケーション。GvRはWindows、Macintosh、GNU/Linuxで多様な言語で動作します！教室と家庭の両方で、人々にプログラミングの基本概念を紹介する方法として優れています。
- [CSSBattle](https://cssbattle.dev) - オンラインCSS Code Golfing戦場。世界中のプレイヤーが可能な限り小さなCSSコードで「Targets」を視覚的に再現し、リーダーボード上位を目指して競います。
- [The Command Line Murders](https://github.com/veltman/clmystery) - Terminal Cityで殺人が起き、TCPDはあなたの助けを必要としています。
- [SQL Murder Mystery](https://mystery.knightlab.com/) - SQL Murder Mysteryは、SQL概念とコマンドを学ぶ自己主導のレッスンであり、経験豊富なSQLユーザーが興味深い犯罪を解決する楽しいゲームでもあります。
- [S3 Game](http://s3game-level1.s3-website.us-east-2.amazonaws.com/) - あなたはトレジャーハンターです。タスクはできるだけ多くの秘密コードを取得し、できるだけ多くの宝箱を開けることです。
- [Learn Git Branching](https://learngitbranching.js.org/) - ウェブでGitを学びます。
- [Oh my Git](https://ohmygit.org/) - Gitの学習に関するオープンソースゲーム！
- [YouBrokeProd](https://youbrokeprod.com) - ディスクフル、DNS障害、Kubernetesクラッシュループなどを扱う対話型ターミナルシミュレーションで本番インシデントをデバッグします。
