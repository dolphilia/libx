[Reflex](https://reflex.dev)は、純粋なPythonだけでフルスタックウェブアプリケーションを構築するオープンソースフレームワークです。
開発者はPythonという一つの言語だけで、ウェブアプリのフロントエンドとバックエンドの両方を作成できます。

Reflexを使うと、HTML、CSS、JavaScriptを書かずに、小規模なデータサイエンスプロジェクトから大規模なマルチページウェブサイトまで構築できます。

## 🛠️ 例のアプリとテンプレート

完全なReflex例のリポジトリは[こちら。](https://github.com/reflex-dev/reflex-examples)

Reflex自身のウェブサイトもReflexを使って構築されています！[GitHubのコード](https://github.com/reflex-dev/reflex-web)をご覧ください。

### 公式テンプレート

- [Blank Template](https://blank-template.reflex.run) - ミニマルなテンプレート。
- [Dashboard App](https://dashboard-new.reflex.run/) - テーブルとグラフを備えるダッシュボード。
- [Sales Management](https://sales-new.reflex.run/) - 売上と顧客を管理するアプリ。
- [AI Image Generator](https://ai-image-gen.reflex.run/) - AIを使用して画像を生成するアプリ。
- [CI Template App](https://cijob.reflex.run/) - 継続的インテグレーション向けテンプレート。
- [API Admin Panel](https://api-admin-panel.reflex.run/) - API用の管理パネル。
- [NBA Statistics](https://nba-new.reflex.run/) - NBAデータのデータ可視化アプリ。
- [Customer Data App](https://customer-data-app.reflex.run/) - 顧客データを管理するアプリ。

### 長すぎないアプリのリスト

- [Translator](https://translator.reflex.run/) - 皆のための、Reflexで作られた翻訳機。

- [Traversal](https://traversal.reflex.run/) - グラフトラバーサルアプリ。
- [Quiz](https://quiz.reflex.run/) - Pythonクイズアプリ。
