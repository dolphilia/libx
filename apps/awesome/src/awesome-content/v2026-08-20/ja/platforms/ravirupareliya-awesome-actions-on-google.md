## オープンソースコード
- [Canvas Quiz](https://github.com/googlecreativelab/aog-canvas-quiz) - Google Assistant 向けのカスタム音声対応クイズゲームを作るスターターキット。
- [Interactive Canvas editor](https://github.com/actions-on-google-labs/interactive-canvas-editor-nodejs) - スマートディスプレイへ即座に読み込める Interactive Canvas Web アプリのエディター。迅速な試作を可能にします。
- [Virtual Pet](https://github.com/actions-on-google-labs/virtual-pet-game-nodejs) - interactive canvas 製。Google Assistant を通じてハムスターを飼育するゲーム。
- [Spellcast](https://github.com/actions-on-google-labs/dialogflow-spellcast-nodejs) - Google Assistant 向け実験的 Interactive Canvas ゲーム。
- Silly Name Maker [(Node.js)](https://github.com/actions-on-google/dialogflow-silly-name-maker-webhook-nodejs) [(Java)](https://github.com/actions-on-google/dialogflow-silly-name-maker-webhook-java) - Dialogflow によるパラメーターのサンプル。
- Facts about Google [(Node.js)](https://github.com/actions-on-google/dialogflow-facts-about-google-nodejs) [(Java)](https://github.com/actions-on-google/dialogflow-silly-name-maker-webhook-java) - Dialogflow による Custom Entities、Contexts、Deep Links のサンプル。
- Name Psychic [(Node.js)](https://github.com/actions-on-google/dialogflow-name-psychic-nodejs) [(Java)](https://github.com/actions-on-google/dialogflow-name-psychic-java) - Dialogflow による権限と Google Maps Static API のサンプル。
- Number Genie [(Node.js)](https://github.com/actions-on-google/dialogflow-number-genie-nodejs) [(Java)](https://github.com/actions-on-google/dialogflow-number-genie-java) - ローカライゼーションのサンプル。
- [GDG Action](https://github.com/actions-on-google/dialogflow-gdg-nodejs) - ローカライゼーション（i18n-node）、会話設計、リッチレスポンス、API 統合を示すサンプル。
- Say Number [(Node.js)](https://github.com/actions-on-google/actionssdk-say-number-nodejs) [(Java)](https://github.com/actions-on-google/actionssdk-say-number-java) - Actions on Google 向け、数字を発話する Actions SDK サンプル。
- [Smart Home sample](https://github.com/actions-on-google/smart-home-nodejs) - Actions on Google の Smart Home デバイス制御 API のサンプル。
- [PDPU Scheduler](https://github.com/nish17/scheduler) - 当日の授業・ラボを伝える PDPU 用 Google Assistant action。
- [karaoke](https://github.com/amdcaruso/karaoke) - [Amanda Cavallaro](https://github.com/amdcaruso)による、GCP、YouTube API、Actions on Google を使って独自カラオケを作る会話型アプリ。
