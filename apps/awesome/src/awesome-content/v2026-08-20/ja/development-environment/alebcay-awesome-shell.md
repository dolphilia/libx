# Awesome Shell

Shellを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## シェル

*基本となるシェルを選びます。*

* [bash](https://www.gnu.org/software/bash/) - GNU Project のシェル（Bourne Again SHell）。
* [elvish](https://elv.sh/) - 無名関数やデータ構造など、親しみやすく表現力豊かな機能を備えたシェル。
* [es](https://wryun.github.io/es-shell/) - Plan 9 の [rc](https://github.com/rakitzis/rc) シェルに基づく拡張可能なシェル。
* [fish](https://fishshell.com) - スマートで使いやすいコマンドラインシェル。
* [ion](https://github.com/redox-os/ion) - シンプルながら強力な構文を特徴とするモダンなシステムシェル。すべて Rust で書かれています。
* [ksh93](https://github.com/att/ast) - Korn Shell
* [mksh](https://github.com/MirBSD/mksh) - MirBSD Korn Shell
* [murex](https://github.com/lmorg/murex) - 使いやすさ、安全性、生産性を考慮した高度な機能（よりスマートな DevOps ツールなど）を備える、より賢いシェル・スクリプト環境。
* [ngs](https://github.com/ngs-lang/ngs) - Ops 向けに特化して作られたフル機能のスクリプト言語。REPL は開発中です。
* [nushell](https://github.com/nushell/nushell) - Rust で書かれたモダンなシェル。
* [oksh](https://github.com/ibara/oksh) - ポータブルな OpenBSD ksh。
* [osh](https://www.oilshell.org) - Oil と呼ばれる新しいモダンな Unix シェル言語を備えた Bash 互換シェル。
* [pdksh](https://cvsweb.openbsd.org/cgi-bin/cvsweb/src/bin/ksh/) - パブリックドメインの Korn シェル。
* [powershell](https://docs.microsoft.com/en-us/powershell/scripting/overview) - コマンドラインシェルとスクリプト言語で構成される、クロスプラットフォームのタスク自動化・構成管理フレームワーク。
* [shell++](https://github.com/alexst07/shell-plus-plus) - 親しみやすくモダンな関数型・オブジェクト指向シェルスクリプト言語。
* [shenv](https://github.com/shenv/shenv) - シンプルなシェルバージョン管理。
* [tcsh](https://www.tcsh.org/) - ファイル名補完とコマンドライン編集を備えた C シェル。
* [xonsh](https://xon.sh) - Python 風で BASH を意識したシェル言語・コマンドプロンプト。
* [yash](https://github.com/magicant/yash) - コマンド履歴に基づく補完・予測を組み込みでサポートする POSIX 準拠コマンドラインシェル。
* [zsh](https://www.zsh.org) - スクリプト言語を備えた強力なシェル。
