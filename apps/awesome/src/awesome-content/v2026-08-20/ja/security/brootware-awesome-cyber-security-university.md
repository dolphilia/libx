## 概要 <a id="about"></a>

Cyber Security Universityは、実践を通じた学習に重点を置く優れた無料教材の厳選リストです。

このカリキュラムは次の6部で構成されます。
1. 入門とセキュリティ前提知識
2. 無料の初級レッドチーム学習経路
3. 無料の初級ブルーチーム学習経路
4. 追加演習
5. 最新CVE
6. 最高難度の演習ルーム
課題は難易度が段階的に上がるため、順番に進めることを推奨します。すでに理解している概念があれば、途中へ移動したり一部のルームを省略したりできます。


カリキュラムを進めると、この[`README.md`](https://github.com/brootware/Cyber-Security-University/blob/main/README.md)内にレッドチーム・ブルーチーム各経路の修了バッジが見つかります。修了後はHTMLコードをコピーして下のコンテンツページへ追加できます。
