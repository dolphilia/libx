# アプリケーションセキュリティのAwesomeリスト <a id="awesome-appsec"></a> [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)

アプリケーションセキュリティを学ぶための資料を厳選したリストです。書籍、Webサイト、ブログ記事、自己評価クイズを収録しています。

[Paragon Initiative Enterprises](https://paragonie.com)が、アプリケーションセキュリティと開発者コミュニティからの貢献を受けて保守しています。将来のアプリケーションセキュリティ専門家に役立つ可能性がある[ほかのコミュニティプロジェクト](https://paragonie.com/projects)もあります。

ソフトウェアセキュリティを初めて学ぶ場合は、[A Gentle Introduction to Application Security](https://paragonie.com/blog/2015/08/gentle-introduction-application-security)が参考になります。
