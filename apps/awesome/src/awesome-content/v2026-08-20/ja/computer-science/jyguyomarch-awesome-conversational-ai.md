## 書籍と論文

- [An Annotated Reading List of Conversational AI](https://medium.com/x8-the-ai-community/a-reading-list-and-mini-survey-of-conversational-ai-32fceea97180) - 対話型 AI を取り巻くすべてのトピックについて、主に学術論文を注釈付きでまとめた一覧。2018年に作成されました。
- [Designing Bots](https://www.oreilly.com/library/view/designing-bots/9781491974810/) - 優れた対話体験と、人々の生産性を高める魅力的なボットを設計・構築する方法を示す実践ガイド。
- [Designing Voice User Interfaces](https://www.oreilly.com/library/view/designing-voice-user/9781491955406/) - モバイルアプリ、玩具、ホームアシスタントのようなデバイスのいずれを設計する場合も、この実践書は基本的な VUI 設計原則を案内し、適切な音声認識エンジンの選定を助け、VUI の性能を測定して改善する方法を示します。

## クライアント

- [Alexa](https://developer.amazon.com/) - チャットボットまたは仮想アシスタントを、Amazon のクラウドベース音声サービス Alexa のスキルとしてデプロイします。
- [LINE](https://developers.line.biz/) - チャットボットを LINE に接続し、プロトタイピングに同社のボットデザイナーを活用します。
- [Messenger](https://developers.facebook.com/docs/messenger-platform/) - Messenger 経由でチャットボットを追加し、Facebook ページの体験を強化します。
- [MS Teams](https://developer.microsoft.com/microsoft-teams) - MS Teams のボット SDK とフレームワークを活用し、チャットボットを MS Teams アプリへ変換します。
- [Slack](https://api.slack.com/) - チャットボットを Slack にデプロイし、エンドユーザーが働く場所へ届けます。
- [Telegram](https://core.telegram.org/) - Telegram Bot API を活用し、チャットボットを Telegram に簡単に接続します。
- [WhatsApp](https://developers.facebook.com/docs/whatsapp/) - WhatsApp Business Platform API を利用して、ボットと顧客を接続します。

## 対話型 UX

- [Conversation Design Institute](https://www.conversationdesigninstitute.com/) - 対話デザインに関するコース、認定資格、年次カンファレンスを提供する、（知る限り）初めての機関。
- [Creating AI Conversations Panel Series](https://www.youtube.com/playlist?list=PL_kEIZJfQ6lIALEhtaFYuIsPtzeKtJ4_h) - AI エンティティと人との個性、会話、相互作用を作り出す際の考え方、研究、プロセスを掘り下げるパネルディスカッションシリーズ。Stanford MediaX が主催しています。
- [SAP Conversational Experience Design](https://experience.sap.com/conversational-ux/) - SAP Conversational Experience Design（SAP CxD）は、エンタープライズ対話製品のためのデザイン言語です。ビジネスアプリケーションをまたいでシームレスに統合される対話製品を設計するためのガイドラインとツールを提供します。
- [Voicebot.ai](https://voicebot.ai/) - 音声技術に関する最も重要なニュース、解説、調査、分析を一か所で提供します。
- [Voiceflow](https://www.voiceflow.com/) - チームが音声・チャットアシスタントを設計、試作、公開するための会話デザインツール。

## 自然言語理解

- [Awesome Deep Learning for Natural Language Processing](https://github.com/brianspiering/awesome-dl4nlp) - 自然言語処理のためのディープラーニングに特化したリソースの厳選リスト。
- [Awesome Machine Learning](https://github.com/josephmisiti/awesome-machine-learning) - 優れた機械学習フレームワーク、ライブラリー、ソフトウェアの厳選リスト（言語別）。
- [Awesome Natural Language Generation](https://github.com/accelerated-text/awesome-nlg) - 自然言語生成に特化したリソースの厳選リスト。
- [Awesome NLP](https://github.com/keon/awesome-nlp) - 自然言語処理に特化したリソースの厳選リスト。
- [Awesome NLP with Ruby](https://github.com/arbox/nlp-with-ruby) - Ruby による自然言語処理とテキスト処理に特化したリソースの厳選リスト。
- [The NLP Index](https://index.quantumstat.com/) - 無料のオープンソースコード発見ツールである NLP Index は、3,000件を超えるコードリポジトリを収録しています。arxiv 研究論文の PDF、ConnectedPapers リンク、GitHub リポジトリを含みます。

## プラットフォーム

- [Amazon Lex](https://aws.amazon.com/lex/) - 音声とテキストを使うアプリケーション向けに対話インターフェースを構築する AWS サービス。
- [Chai](https://chai.ml/) - 開発者が Python を使ってチャットボットを構築し、Chai モバイルアプリにデプロイするためのオープンソースプラットフォーム。
- [Dasha](https://dasha.ai/) - 音声に強く焦点を置く、サービスとしての対話型 AI プラットフォーム。
- [Dialogflow](https://cloud.google.com/dialogflow) - Google による、最先端の仮想エージェントを備えた自然な対話型 AI。
- [OpenDialog](https://opendialog.ai/) - OpenDialog は対話型アプリケーションの設計、開発、デプロイを可能にします。オープンソース版と Enterprise 版を提供します。
- [Rasa](https://rasa.com/) - 大規模に仮想アシスタントを作成するためのプラットフォーム。オープンソース版と Enterprise 版を提供します。
- [SAP Conversational AI](https://cai.tools.sap/) - SAP が提供するエンドツーエンドのチャットボット構築プラットフォーム。無料の Community 版と Enterprise 版があります。
