## 一般

どこでも使える汎用アイコン。

- [Bootstrap Icons](https://github.com/twbs/icons#readme) - Bootstrap コンポーネント向けにカスタムデザイン・構築された SVG アイコン。([Website](https://icons.getbootstrap.com/))
- [Boxicons](https://github.com/atisawd/boxicons#readme) - 1,000 個以上のアイコンと 100 個以上のロゴを含むシンプルなベクターアイコンセット。([Website](https://boxicons.com/))
- [Byte Size Icons](https://github.com/danklammer/bytesize-icons#readme) - スタイルを制御できる小さな SVG アイコンセット。([Website](https://danklammer.com/bytesize-icons))
- [css.gg](https://github.com/astrit/css.gg#readme) - SVG Sprite、styled-components、NPM、API で利用できる、純粋な CSS・SVG・Figma UI アイコン。([Website](https://css.gg))
- [Eva icons](https://github.com/akveo/eva-icons#readme) - 美しく作られた 480 個以上のオープンソースアイコンパック。([Website](https://akveo.github.io/eva-icons))
- [Evil icons](https://github.com/evil-icons/evil-icons#readme) - Rails、Sprockets、Node.js、Gulp、Grunt、CDN をサポートするコードを備えたシンプルでクリーンな SVG アイコンパック。([Website](http://evil-icons.io))
- [Feather](https://github.com/feathericons/feather#readme) - シンプルで美しいオープンソースアイコン。([Website](https://feathericons.com))
- Flaticon - 無料ベクターアイコンの最大級データベース。([Website](https://flaticon.com))
- [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons#fluent-system-icons) - Microsoft による親しみやすくモダンなアイコンのコレクション。
- [Flowbite Icons](https://flowbite.com/icons/) - Tailwind CSS・Figma 向けに構築された、430 個以上のソリッド・アウトラインアイコンの無料オープンソースコレクション。
- [Font Awesome](https://github.com/FortAwesome/Font-Awesome#readme) - 象徴的な SVG、フォント、CSS ツールキット。([Website](https://fontawesome.com))
- [Heroicons](https://github.com/refactoringui/heroicons#readme) - Web プロジェクトで使える無料・高品質 SVG アイコンセット。([Website](https://heroicons.dev))
- [IconPark](https://github.com/bytedance/IconPark#readme) - 1,400 個以上の高品質アイコンへのアクセスと、アイコンをカスタマイズするためのインターフェースを提供する。([Website](https://iconpark.bytedance.com))
- ICONSVG - パスのストローク、端、結合部を簡単にカスタマイズできる SVG アイコン。([Website](https://iconsvg.xyz))
- [Ion icons](https://github.com/ionic-team/ionicons#readme) - Ionic Framework と Web アプリ全般向けのプレミアムアイコンフォント。([Website](https://ionicons.com))
- [Material design icons](https://github.com/google/material-design-icons#readme) - Google による Material Design アイコン。([Website](https://fonts.google.com/icons))
- [Octicons](https://github.com/primer/octicons#readme) - GitHub が <3 を込めて手作りした、スケーラブルなアイコンセット。([Website](https://octicons.github.com))
- [Picon](https://github.com/yne/picon#readme) - 小さな合字ベースのアイコンフォントと SVG。([Website](https://yne.fr/picon))
- [Radix Icons](https://github.com/radix-ui/icons) - WorkOS チームがデザインした、鮮明な 15×15 アイコンセット。([Website](https://www.radix-ui.com/icons/))
- [Remix Icon](https://github.com/Remix-Design/RemixIcon#readme) - デザイナー・開発者向けのオープンソース中立スタイルシステムシンボルセット。([Website](https://remixicon.com))
- Shape.so - コードとしてエクスポート可能な、カスタマイズ・アニメーション可能なアイコンとイラスト。([Website](https://shape.so))
- [Super Tiny Icons](https://github.com/edent/SuperTinyIcons#readme) - 好きな Web サイト・アプリロゴの、各 1KB 未満の極小 SVG 版。
- [Tabler Icons](https://github.com/tabler/tabler-icons) - Web プロジェクトで使える、MIT ライセンスの高品質 SVG アイコンを 3,200 個以上集めたセット。([Website](https://tabler-icons.io))
- [Teenyicons](https://github.com/teenyicons/teenyicons) - とても小さな空間にも簡単に収まり、鮮明な見た目を保つ 1,000 個以上の MIT ライセンス SVG アイコン :pinching_hand: :sparkles:。([Website](https://teenyicons.com))
- The Noun Project - 世界的なコミュニティが作成した、200 万個以上の厳選アイコン。([Website](https://thenounproject.com/))
- Tilda Icons - ランディングページなど向けの無料アイコンが満載の Web サイト。([Website](https://tilda.cc/free-icons))
- [Unicons](https://github.com/iconscout/unicons#readme) - 次のプロジェクト向けの、1,000 個以上のピクセルパーフェクトなベクターアイコンとアイコンフォント。([Website](https://iconscout.com/unicons))
- [VSCode Icons](https://github.com/microsoft/vscode-icons#readme) - Visual Studio Code で使用されるアイコンのダーク・ライト版。
- [Weather icons](https://github.com/erikflowers/weather-icons#readme) - 天気をテーマにしたアイコンと CSS。
- Zondicons - デジタルプロダクトで使える無料プレミアム SVG アイコンセット。([Website](http://www.zondicons.com))

## ロゴ

さまざまなブランド、企業、技術のロゴ。

- [Browser Logos](https://github.com/alrra/browser-logos#readme) - 高解像度の Web ブラウザーロゴ。
- [Cryptocoins](https://github.com/AllienWorks/cryptocoins#readme) - 好きな暗号通貨の完全なベクター・Web フォントアイコンパック。
- [Cryptocurrency icons](https://github.com/atomiclabs/cryptocurrency-icons#readme) - すべての主要暗号通貨とアルトコイン向けアイコンセット。([Website](http://cryptoicons.co))
- [Dev icons](https://github.com/vorillaz/devicons#readme) - 開発者のために作られた象徴的なフォント。([Website](http://vorillaz.github.io/devicons))
- [Devicon](https://github.com/devicons/devicon#readme) - 開発言語とツールを表すロゴをすべて集めることを目指す。([Website](https://devicons.github.io/devicon))
- [Simple icons](https://github.com/simple-icons/simple-icons#readme) - 人気ブランド向け無料 SVG アイコン。([Website](https://simpleicons.org/))
- [VectorLogoZone](https://github.com/VectorLogoZone/vectorlogozone#readme) - 一貫したサイズ・形式の SVG ロゴ。([Website](https://www.vectorlogo.zone/))
- [Web3 Icons](https://github.com/0xa3k5/web3icons#readme) - トークン、コイン、ネットワーク、ウォレットを含む React コンポーネントとしての Web3 アイコン。

## 特別

一般・ロゴ以外の特別なアイコン。

- [GeoIcons](https://github.com/getgeoicons/geoicons#readme) - tree-shakable な SVG コンポーネントとしての地理地図アイコン。([Website](https://geoicons.io))
- [Flag Kit](https://github.com/madebybowtie/FlagKit#readme) - アプリ・Web 向けの美しい国旗アイコン。
- [Mapsicon](https://github.com/djaiss/mapsicon#readme) - 世界中のすべての国向け無料地図コレクション。
- [IconicFonts](https://github.com/iconicFonts/iconic-fonts#readme) - グリフとして 60,000 個のアイコンを持つ、事前パッチ済みフォント 50 種以上。

## その他

### CSS のみ

CSS だけで作られた（ダウンロード不可の）アイコン。

- [cssicon](https://github.com/wentin/cssicon#readme) - 依存関係なしの純粋な CSS コードで作られた、すぐ使えるアイコンセット。([Website](https://cssicon.space))
- [icono](https://github.com/saeedalipoor/icono#readme) - 純粋 CSS・クラスベースのアイコンパック。([Website](https://saeedalipoor.github.io/icono))

### 有料

オープンソース・無料ではないものの、十分に素晴らしいもの。

- [Nucelo Icons](https://nucleoapp.com/premium-icons) - iOS、Android、Web プロジェクト向けのプレミアム SVG アイコンライブラリ。

### フレームワーク

通常は他のアイコンセットをインポートできるライブラリまたはフレームワーク。

- Iconbuddy - オープンソース SVG アイコンを閲覧するための検索エンジン。([Website](http://iconbuddy.com))
- [Iconify Deign](https://github.com/iconify/iconify#readme) - 200,000 個以上のオープンソースベクターアイコンを含む、最も人気のアイコンセットを一つにまとめたフレームワーク。([Website](https://iconify.design))
- [React Icons](https://github.com/react-icons/react-icons#reamde) - React プロジェクト向けに作られた人気アイコンセット。([Website](https://react-icons.github.io/react-icons/))
- [Unicon](https://github.com/WebRenew/unicon#readme) - 9 ライブラリから 20,000 個以上のアイコンを閲覧し、必要なものだけをコピーできる。アイコン向け shadcn/ui のようなもの。([Website](https://unicon.webrenew.com))
