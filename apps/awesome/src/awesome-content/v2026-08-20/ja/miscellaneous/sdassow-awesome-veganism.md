# Awesome Veganism [![Awesome](https://awesome.re/badge.svg)](https://github.com/sindresorhus/awesome)

> ヴィーガニズムを誰にとっても容易で身近なものにする、優れたリソース、手がかり、ヒントを集めたリスト。

[ヴィーガニズム](https://en.wikipedia.org/wiki/Veganism)は、動物由来製品を可能な限り避ける植物ベースのライフスタイルです。
このリストは、素晴らしい体験に必要な労力を最小限にするため、ヴィーガンのライフスタイルに100%沿った実用的なコンテンツを保証する、コミュニティ主導の取り組みを作ろうとするものです。

## 団体と活動

- [Animal Equality](https://animalequality.org/) - 工場畜産の状況を記録し、動物搾取を終わらせる企業キャンペーンを行う国際団体。
- [Mercy For Animals](https://mercyforanimals.org/) - 調査、企業との連携、一般教育を用いる主要な畜産動物保護団体。
- [The Humane League](https://thehumaneleague.org/) - 制度的・個人的な変革キャンペーンにより、食用に育てられる動物への虐待を終わらせる。
- [Veganuary](https://veganuary.com/) - 年間を通じてリソースとレシピを提供し、毎年1月にヴィーガンを試すよう人々を促す世界的キャンペーン。
- [Vegan Outreach](https://veganoutreach.org/) - アウトリーチプログラムとVegan Mentorプログラムを通じて何百万人にも届ける草の根活動。

## ドキュメンタリー

- [Dominion](https://www.dominionmovement.com/) - ドローン映像と隠しカメラで畜産における標準的慣行を暴く長編ドキュメンタリー。
- [Cowspiracy](https://www.cowspiracy.com/) - 畜産が地球へ与える影響を探る画期的な環境ドキュメンタリー。
- [The Game Changers](https://gamechangersmovie.com/) - 植物ベースの食事を通じ最適な栄養を探るエリート選手と科学者を追うドキュメンタリー。
- [Earthlings](http://www.nationearth.com/) - 経済的目的のための動物への人類の依存を扱う包括的ドキュメンタリー。

## アプリとツール

- [HappyCow](https://www.happycow.net/) - コミュニティのレビューと写真で世界中のヴィーガン・ベジタリアンレストランを探す。
- [abillion](https://www.abillion.com/) - レビューごとに動物福祉団体へ寄付しながら、植物ベース製品とレストランをレビューする。
- [Is It Vegan](https://github.com/hmontazeri/is-vegan) - 食品の原材料または製品がヴィーガンかを確認するオープンソースライブラリ・ツール。
