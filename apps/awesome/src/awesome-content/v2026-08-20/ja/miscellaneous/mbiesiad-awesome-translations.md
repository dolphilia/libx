# Awesome Translations [![Awesome](https://awesome.re/badge-flat.svg)](https://awesome.re)

> ある言語のテキストの意味を別の言語へ移すこと。

このリストは、翻訳に関するツール、書籍、記事、ブログ、コースなどを含みます（[t9n](https://en.wikipedia.org/wiki/Translation) - 翻訳、[l10n](https://en.wikipedia.org/wiki/Language_localisation) - ローカライゼーション、[g11n](https://en.wikipedia.org/wiki/Language_localisation#Globalisation_versus_localisation) - グローバリゼーション、[m17n](https://www.definify.com/word/multilingualization#:~:text=Noun,into%2C%20or%20for%20multiple%20languages) - 多言語化、[i18n](https://en.wikipedia.org/wiki/Language_localisation#Globalisation_versus_localisation) - 国際化、グローバリゼーションの同義語）。

## プラットフォーム

### ローカライゼーション・翻訳プラットフォーム

- [Crowdin](https://crowdin.com/) - クローズドソースのクラウドベースのローカライゼーション技術・サービス企業。
- [Inlang](https://inlang.com/) - ソフトウェア企業のためのグローバリゼーションエコシステム。
- [Transifex](https://www.transifex.com/) - 独自のWebベース翻訳プラットフォーム、グローバリゼーション管理システム（GMS）。
- [Weblate](https://weblate.org/) - コピーレフトの自由なWebベース継続的翻訳プラットフォーム。
- [SimpleLocalize](https://simplelocalize.io) - ソフトウェアプロジェクト向けのシンプルな翻訳管理。
- [Tolgee](https://tolgee.io) - ユーザーが開発中のアプリ内で直接翻訳できる、オープンソースで開発者・翻訳者に優しいプラットフォーム。
- [Localit](https://localit.io/) - シームレスなGitHub/GitLab統合、AI・人力翻訳サポート、充実した無料プランを備える、高速かつ直感的なローカライゼーションプラットフォーム。
- [Lokalise](https://lokalise.com/) - 開発者向け翻訳プラットフォーム。
- [Locize](https://locize.com/) - 独自の翻訳プラットフォーム。
- [Shipi18n](https://shipi18n.com/) - i18nextサポート、プレースホルダー保持、翻訳メモリを備えた開発者向け翻訳API。
- [LRM](https://github.com/nickprotop/LocalizationManager) - 無料の選択肢を含む複数の翻訳プロバイダーに対応し、.resxとJSON（i18next）をサポートするセルフホスト型CLI/TUIローカライゼーションマネージャー。

### プロジェクト管理

- [Zanata](http://zanata.org/) - 翻訳者、コンテンツ作成者、開発者がローカライゼーションプロジェクトを管理するためのWebベース翻訳プラットフォーム。
- [Traduora](https://github.com/traduora/traduora) - チームで翻訳ワークフローを管理するためのプラットフォーム。

### プラットフォーム固有ツール

- [GitLocalize](https://gitlocalize.com/) - GitHubリポジトリと同期し、そのコンテンツを継続的に翻訳できる強力なローカライゼーションプラットフォーム。
- [Respresso](https://respresso.io/) - ローカライゼーション、画像、色などの共同オンラインリソースマネージャー。プラットフォーム固有のファイルを生成し、ソースコードへ直接配信する。
- [PO file editor](https://pofile.net/free-po-editor) - GettextによるローカライゼーションでPOファイルを翻訳する無料ツール。

## アプリ

### 自動翻訳

- [RTranslator](https://github.com/niedev/RTranslator) - NLLBとWhisperを基盤とし、ローカルで動作するAndroid向け同時通訳アプリ。
- [Crow Translate](https://github.com/crow-translate/crow-translate) - Google、Yandex、Bing翻訳APIを使い、テキストを翻訳・読み上げできるLinux・Windows向けの簡潔で軽量な翻訳ソフト。
- [Copy Translator](https://github.com/CopyTranslator/CopyTranslator) - クリップボードへコピーされたテキストを自動で翻訳・調整するWindows、Mac、Linux向けアプリ。
- [LibreTranslate](https://github.com/uav4geo/LibreTranslate) - Argos Translateに基づく、テキスト翻訳用100%セルフホスト型Webアプリ。

### 翻訳ソフトウェア
- [OmegaT](https://omegat.org/) - Windows、macOS、Linuxで動作する無料の翻訳メモリ／CATソフトウェア。
- [Argos Translate](https://github.com/argosopentech/argos-translate) - OpenNMTに基づくPython製の完全オープンソースなオフライン翻訳アプリ。Pythonライブラリとしても使える。
- [Fink](https://inlang.com/m/tdozzpar) - ノーコード設定とリポジトリベースの運用を備えた翻訳エディター／CATソフトウェア。
- [Project Fluent](https://projectfluent.org) - ローカライゼーション向けの非対称翻訳（例: 性別によるバリエーション）。

- [i18n Ally](https://github.com/antfu/i18n-ally) - i18nに関するすべてを扱うVSCode拡張。
- [Translate](https://github.com/translate/translate) - ローカライザーの作業をより生産的に、より不便の少ないものにするために設計されたソフトウェア・ドキュメントの集合。
- [Python-i18n](https://pypi.org/project/python-i18n/) - Python国際化（i18n）パッケージ。
- [Moment.js](https://momentjs.com/) - JavaScriptで日付・時刻を解析、検証、操作、表示する。
- [WPML](https://wpml.org/) - 一つのWordPressインストールで多言語Webサイトを運用できるWordPressプラグイン。
- [FormatJS](https://formatjs.io/) - 人へ表示する数値、日付、文字列の書式設定に焦点を当てた、国際化のためのモジュール式JavaScriptライブラリ群。
- [Polyglot](https://github.com/untra/polyglot) - Jekyllブログ向けの高速で容易なオープンソース国際化プラグイン。
- [ICU - International Components for Unicode](https://icu.unicode.org/) - ソフトウェアアプリケーションへUnicode・グローバリゼーション支援を提供する、成熟し広く使われるC/C++・Javaライブラリ群。
- [Django docs - i18n](https://docs.djangoproject.com/en/4.1/topics/i18n/) - 国際化とローカライゼーションに焦点を当てたDjangoドキュメントの一部。
- [Localizejs](https://localizejs.com/) - Webサイト・アプリケーションを新しい言語へ翻訳し、翻訳ワークフローを効率化する。
- [ParaglideJS](https://inlang.com/m/gerre34r) - 同期的で型安全、軽量なi18nライブラリ。
- [sphinx-intl](https://github.com/sphinx-doc/sphinx-intl) - 翻訳と翻訳の適用を容易にするSphinxユーティリティ。

### コンピューター支援翻訳の理解
- [Computer-assisted translation](https://en.wikipedia.org/wiki/Computer-assisted_translation) - CAT（コンピューター支援翻訳）ツールは通常、実際の翻訳プロセスを特に支援するプログラムを指す。本記事は翻訳メモリソフトウェア、言語検索エンジンソフトウェア、用語管理ソフトウェア、アラインメントソフトウェア、対話型機械翻訳、拡張翻訳を説明する。

### 機械翻訳
- [Approaches to Machine Translation](http://engineering.fuoye.edu.ng/journal/index.php/engineer/article/view/26/pdf) - 機械翻訳の異なる技法を扱うレビュー論文。
- [Neural Machine Translation](https://jair.org/index.php/jair/article/view/12007/26611) - 現代NMTアーキテクチャの起源を単語・文埋め込みと、初期のエンコーダー・デコーダーネットワーク群の例まで遡るレビュー論文。分野における近年の動向の短い概観で締めくくる。
- [Awesome New Languages in Machine Translation](https://github.com/slone-nlp/awesome-new-languages-in-machine-translation) - 新しい言語（主に低リソース言語）向けMT（主にオープンソースモデル）を支援する取り組みのリスト。

## 書籍

- [Statistical Machine Translation](https://www.cambridge.org/core/books/statistical-machine-translation/94EADF9F680558E13BE759997553CDE5#fndtn-information) - NLPと統計の背景を築き、基礎から現在の研究まで展開する。最後には読者が自身の翻訳システムを構築できる。著者は[Philipp Koehn](https://en.wikipedia.org/wiki/Philipp_Koehn)。
- [Neural Machine Translation](https://www.cambridge.org/core/books/neural-machine-translation/7AAA628F88ADD64124EA008C425C0197#fndtn-information) - 機械翻訳へのこの入門書は、ニューラルネットワーク手法の基礎から最先端まで到達し、歴史的・言語学的・応用的な文脈を示す。Pythonコード例が実装の実践的な設計図を与える。著者は引き続きPhilipp Koehn。
- [Translation: An advanced resource book for students](https://www.amazon.com/Translation-advanced-resource-Routledge-Linguistics-ebook/dp/B07NPV8DSC/ref=cm_cr_arp_d_product_top?ie=UTF8) - 多様な言語学・文化的観点から翻訳の理論と実践を紹介する。著者は[Basil Hatim](https://scholar.google.com/citations?user=IVydQ-4AAAAJ&hl=en)と[Jeremy Munday](https://ahc.leeds.ac.uk/languages/staff/1006/professor-jeremy-munday)。
- [Glocalization Strategy Playbook](https://github.com/GILT-Forum/Globalization-Strategy-Playbook) - GILTフォーラムによるローカライゼーション・グローバリゼーション専門家向けガイド。
