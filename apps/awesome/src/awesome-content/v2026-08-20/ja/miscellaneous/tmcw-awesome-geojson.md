# awesome geojson [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)

あなたの作業を容易にする GeoJSON ユーティリティ。

### 操作

* [CoGran](https://github.com/berlinermorgenpost/cogran): ある GeoJSON ポリゴン集合から別の集合へ統計を再サンプリング
* [geo_assigner](https://github.com/stadt-karlsruhe/geo_assigner): 交差するすべての feature へプロパティをコピー
* [geojson-coords](https://github.com/mapbox/geojson-coords): GeoJSON から座標を抽出
* [geojson-extent](https://www.npmjs.com/package/geojson-extent): geojson features の境界ボックスを計算
* [geojson-flatten](https://github.com/tmcw/geojson-flatten): multi geometries を通常の geometries へフラット化
* [geojson-multiply](https://github.com/haoliangyu/geojson-multiply): 通常の geojson features を一つの multi geometry type feature に統合
* [geojson-js-utils](https://github.com/maxogden/geojson-js-utils): GeoJSON 操作用 JavaScript ヘルパー関数
* [geojson-merge](https://github.com/mapbox/geojson-merge): 複数の GeoJSON ファイルを一つの FeatureCollection へ統合。
* [geojson-normalize](https://github.com/mapbox/geojson-normalize): 任意の geojson object を geojson featurecollection へ正規化
* [geojson-pick](https://www.npmjs.com/package/geojson-pick): geojson featurecollection 内 features の指定プロパティ以外を削除
* [geojson-random](https://github.com/tmcw/geojson-random): ランダムな geojson points、lines、polygons を生成
* [geojson-rewind](https://github.com/mapbox/geojson-rewind): ring の巻き順を強制
* [rfc7946-to-d3](https://github.com/tyrasd/rfc7946-to-d3): rfc7946 と[d3 compatible](https://github.com/d3/d3-geo#d3-geo)規約の間で polygon の巻き順を変換。
* [geojson-summary](https://github.com/mapbox/geojson-summary): geojson ファイルの内容を平易な英語で要約
* [point-grouper](https://github.com/substack/point-grouper): geojson points を含有 polygons にグループ化
* [geojson-join](https://github.com/tmcw/geojson-join): geojson を json、dbf、csv ファイルに対して join
* [simplify-geojson](https://github.com/maxogden/simplify-geojson): JS または CLI で、geojson features・feature collections に ramer-douglas-peucker 線簡略化を適用
* [turf](https://github.com/Turfjs/turf): 空間操作・分析関数のコレクション
* [turf_dart](https://github.com/dartclub/turf_dart): Dart・Flutter 向け turf.js ポート
* [de9im](https://github.com/dpmcmlxxvi/de9im): 空間 JavaScript 操作向け高速関数のコレクション
* [winnow](https://github.com/dmfenton/winnow): JavaScript で geojson に対して SQL クエリを実行
* [geojson-id-streaming](https://github.com/andrewharvey/geojson-id-streaming): 各 Feature へ一意な id を追加
* [geojson-mesh](https://github.com/andrewharvey/geojson-mesh): GeoJSON 内 Polygons の共有境界を抽出
* [geojson-polygon-labels](https://github.com/andrewharvey/geojson-polygon-labels): GeoJSON polygons から point labels を生成
* [geojsontools](https://github.com/micolous/geojsontools): GeoJSON ファイル操作用 Python ツール
* [geojson-indoor-tools](https://github.com/armanjr/geojson-indoor-tools): 屋内 GeoJSON features 編集用 Python ツール。部屋の高さ追加、壁・ドア作成を行う
* [geojson-shave](https://github.com/ben-n93/geojson-shave): GeoJSON ファイルのサイズを削減する Python コマンドラインツール。

### エディターとビューアー

* [play.placemark.io](https://play.placemark.io/): 多くのファイル形式のインポート・エクスポートと操作をサポートする Web ベースエディター
* [geojson.io](http://geojson.io/): 多くのファイル形式のインポート・エクスポート、操作、GitHub 経由共有をサポートする Web ベースエディター
* [umap](http://umap.openstreetmap.fr/en/): サイト上の共有をサポートする Web ベースエディター
* [geojson formatter](https://formatjsononline.com/geojson-formatter): 地理データをオンラインで検証・分析
* [geojson.tools](http://geojson.tools/): HERE XYZ による Web ベースエディター
* [mapstarter](http://mapstarter.com/): GeoJSON から svg、画像、コードの生成を支援
* [gjv](https://github.com/anandthakker/gjv): GeoJSON のローカル表示と turf を使った編集を可能にする electron アプリ。オフラインで動作
* [GeoJSON editor](https://tomscholz.github.io/geojson-editor/): Google のシンプルな geojson エディターを修正した版
* [geojson2image](https://github.com/brycejohnston/geojson2image): GeoJSON から画像を生成するライブラリ
* [dropchop](http://dropchop.io/): Turf.js に基づくブラウザーベース GIS
* [Web GIS](https://drewweth.github.io/geodebugger): 地理空間データの表示、検査、操作ツール
* [img2geojson](https://caseymm.github.io/img2geojson/): Web 地図上に重ねて描画し、画像をデジタル化
* [point_ed](https://zverik.github.io/point_ed/): 地図クリックで点を追加し、GeoJSON ファイルとしてダウンロード
* [geojson.io-for-vscode](https://marketplace.visualstudio.com/items?itemName=swallow.geojson-io-for-vscode): [geojson.io](http://geojson.io/)のように VSCode で GeoJSON データを作成、編集、プレビュー
* [Vector Tile Lab](https://github.com/spider-hand/vector-tile-lab): ベクタータイルを調整する対話的サンドボックス

### 検証

* [geojsonhint](https://github.com/mapbox/geojsonhint): geojson ファイル内のエラーを検出
* [check-geojson](https://github.com/placemark/check-geojson): geojsonhint の代替
* [geojson-validation](https://www.npmjs.com/package/geojson-validation): 多くの検証関数と、単純な gjv コマンドラインツール
* [gjf](https://github.com/yazeed44/gjf): 無効な GeoJSON objects を修正するツール
* [Jest-GeoJSON](https://github.com/M-Scott-Lassiter/jest-geojson): GeoJSON データ評価向けに調整した Jest JavaScript 単体テストフレームワークの拡張 matcher 関数セット
* [antimeridian](https://github.com/gadomski/antimeridian): 対蹠子午線を横断する GeoJSON polygons を修正（Python パッケージ）
* [geojson-pydantic](https://github.com/developmentseed/geojson-pydantic): GeoJSON 向け[Pydantic](https://docs.pydantic.dev/latest/)モデル

### サービス

* [geojsonio-cli](https://github.com/mapbox/geojsonio-cli): コマンドラインから geojson features を geojson.io へ送信
* [geojsonio-extension](https://github.com/mapbox/geojsonio-extension): geojson.io で GitHub ファイルを編集する Chrome 拡張
* [geojsonlint](http://geojsonlint.com/): GeoJSON 検証用 REST インターフェイス
* [mapshaper](http://mapshaper.org/): GeoJSON・TopoJSON の簡略化・変換を行うシンプルなインターフェイス
* [koop](https://koopjs.github.io): Esri、GitHub、Socrata その他サービスを GeoJSON endpoints として再キャストするプラグイン付きサーバー
* [featureserver](https://github.com/featureserver/featureserver): オープンソースの Esri-Style Feature Server
* [geojson minify](https://open-innovations.github.io/geojson-minify/): ファイルサイズを削減する Minifier（compressor）

### 変換

* **CSV**
  * [csv2geojson](https://github.com/mapbox/csv2geojson): CSV を geojson へ変換
  * [geojson2dsv](https://github.com/tmcw/geojson2dsv): geojson を CSV・TSV へ変換
* [geojson-mapnikify](https://github.com/mapbox/geojson-mapnikify): GeoJSON objects を埋込み GeoJSON データと simplestyle-spec 由来スタイルを持つ Mapnik XML stylesheets へ変換。
* [geojson-vt](https://github.com/mapbox/geojson-vt): ブラウザー内で GeoJSON をオンザフライにベクタータイルへ分割
* [vt-geojson](https://github.com/developmentseed/vt-geojson): Mapbox ベクタータイルから GeoJSON を抽出
* [geojson2rtree](https://github.com/maxogden/geojson2rtree): geojson features 集合から静的 rtree（terraformer 使用）を生成
* [ogr2ogr](http://www.gdal.org/ogr2ogr.html): あらゆるものをあらゆるものへ変換
  * [fiona](https://github.com/toblerity/fiona): ogr 上の優れた Python インターフェイス
* [shp2json](https://github.com/substack/shp2json): shapefile zip archives をストリーミング GeoJSON へ変換
* [togeojson](https://github.com/tmcw/togeojson): GPX・KML を geojson へ変換
* [tokml](https://github.com/mapbox/tokml): GeoJSON を KML へ変換
* [topojson](https://github.com/topojson/topojson): GeoJSON と TopoJSON の相互変換、CSV からのデータ結合
* [wellknown](https://github.com/mapbox/wellknown): WKT を GeoJSON へ変換
* [betterknown](https://github.com/placemark/betterknown): WKT を GeoJSON へ変換（wellknown の後継）
* [esri2open](https://github.com/project-open-data/esri2open) はプロプライエタリな Esri 形式を GeoJSON へ変換
* [gtfs2geojson](https://github.com/tmcw/gtfs2geojson): GTFS transit data を GeoJSON へ変換
* [geoxform](https://github.com/koopjs/geoxform): 任意サイズの geojson ストリームをストリーミング CSV、Shapefile、KML などへ変換
* [supercluster](https://github.com/mapbox/supercluster): ブラウザー・Node 向け高速 GeoJSON クラスタリングライブラリ。
* **SVG**
  * [geojson2svg](https://github.com/gagan-bansal/geojson2svg): SVG viewport サイズと地図範囲を指定して GeoJSON を SVG 文字列へ変換。
  * [geojson-svgify](https://github.com/juliuste/geojson-svgify): GeoJSON geometry paths を SVG polyline elements へ変換。
  * [geojson-to-svg-cli](https://github.com/derhuerst/geojson-to-svg-cli): GeoJSON を SVG へ変換するコマンドラインツール。
  * [svg-to-geojson](https://github.com/mapbox/svg-to-geojson): SVG を地図へドラッグ＆ドロップすると GeoJSON を返します。
* [geojson2ndjson](https://www.npmjs.com/package/geojson2ndjson): GeoJSON と改行区切り GeoJSON を相互変換
* [geobuf](https://www.npmjs.com/package/geobuf/v/0.2.1): GeoJSON と GeoBuf を相互変換
* **OpenStreetMap**
  * [osmtogeojson](https://github.com/tyrasd/osmtogeojson): OpenStreetMap データを GeoJSON へ変換
  * [osm2geojson](https://github.com/rclark/osm2geojson): OSM XML を GeoJSON へ変換
  * [osm2geojson](https://github.com/aspectumapp/osm2geojson): （Python）OSM XML と Overpass XML/JSON を GeoJSON へ変換
  * [minjur](https://github.com/mapbox/minjur): 他の何よりも速く OpenStreetMap データを GeoJSON へ変換
  * [geojsontoosm](https://github.com/tyrasd/geojsontoosm): GeoJSON を OSM XML へ変換
  * [geojson2osm](https://github.com/Rub21/geojson2osm): GeoJSON を OSM XML へ変換
  * [osm-and-geojson](https://github.com/aaronlidman/osm-and-geojson): GeoJSON を OSM XML へ、OSM XML を GeoJSON へ変換
  * [geojson2osm-es6](https://github.com/DenisCarriere/geojson2osm-es6/): GeoJSON を OSM XML へ変換
  * [query-overpass](https://github.com/perliedman/query-overpass) Overpass クエリを作り、結果を GeoJSON へ変換する CLI。[osmtogeojson](https://github.com/tyrasd/osmtogeojson)に基づく
* [topojson for Python](https://github.com/mattijn/topojson): Python 内でほぼ任意の空間オブジェクトの topojson エンコード形式を作成できるライブラリ。
* [geomet](https://github.com/geomet/geomet): 一般的な地理空間データ形式向けの Pure Python 変換ライブラリ

### データ

* [natural earth](http://www.naturalearthdata.com/): 国、州、地理データ
* [geojson.xyz](http://geojson.xyz/): ホットリンク可能な Web フレンドリーサイズの natural earth データ
* [world-atlas](https://github.com/topojson/world-atlas): カスタマイズ可能に簡略化された natural earth データ版
* [geo-maps](https://github.com/simonepri/geo-maps): プログラムで生成された高品質 GeoJSON 地図。
* [openflights-geojson](https://github.com/tmcw/openflights-geojson): [openflights](http://openflights.org/)の空港・飛行機ルート
* [us-atlas](https://github.com/topojson/us-atlas): 米国 features 向け geojson・topojson
* [metro-extracts](https://mapzen.com/data/metro-extracts/): GeoJSON としての地域 OpenStreetMap データ
* [whereonearth-airport](https://github.com/straup/whereonearth-airport): すべての空港の外郭
* [whereonearth-building](https://github.com/straup/whereonearth-building/): 建物の外郭
* [whereonearth repos](https://github.com/search?q=user%3Astraup+whereonearth): Aaron Straup Cope による GeoPlanet からの他の features 出力
* [tgn-geojson](https://github.com/straup/tgn-geojson): GeoJSON としての Getty Thesaurus of Geographic Names（TGN）。
* [strava-to-geojsonio](https://github.com/taketime/strava-to-geojsonio): Strava から GeoJSON へラン・ライドをエクスポート
* [strava-geojson](https://github.com/tmcw/strava-geojson): node と[Web上](http://www.macwright.org/strava-geojson/)で _すべての_ strava データを geojson へエクスポート
* [gimme OSM](http://ustroetz.github.io/gimmeOSM/): openstreetmap id により geojson ファイルを取得
* [country-levels](https://github.com/hyperknot/country-levels-export) ISO・FIPS コードに基づく全地球 GeoJSON extracts。
* [historical-basemaps](https://github.com/aourednik/historical-basemaps): 世界規模で歴史データをマッピングする際に使う、世界の国・文化地域のジオリファレンス済み境界コレクション。
* [99boundaries](https://github.com/TimMcCauley/nintynine-boundaries): GeoJSON その他ファイル形式で任意の海上・陸上境界を生成するか、[Webから直接ダウンロード](https://99boundaries.com)
* [france-geojson](https://github.com/gregoiredavid/france-geojson): GeoJSON 形式のフランス（本土・海外県）の地域、県、郡、カントン、コミューンの外郭
* [zg3d](https://data.zagreb.hr/dataset/zg3d-2022-3d-model-gz): GeoJSON（CSV・Excel も利用可）で提供されるクロアチア・ザグレブ市の既存建物3Dモデル。

### シリアライズ

* [python-geojson](https://github.com/frewsxcv/python-geojson): geojson と python datatypes を相互シリアライズ
* [rgeo-geojson](https://github.com/rgeo/rgeo-geojson): geojson と ruby RGeo datatypes を相互シリアライズ
* [rust-geojson](https://github.com/georust/rust-geojson): geojson と rust datatypes を相互シリアライズ
* [geojson-jackson](https://github.com/opendatalab-de/geojson-jackson): GeoJSON と Java datatypes を相互シリアライズ（[Jackson](http://wiki.fasterxml.com/JacksonHome)に基づく）
* [mapbox-java](https://github.com/mapbox/mapbox-java): GeoJSON と Java datatypes を相互シリアライズ（[Gson](https://github.com/google/gson)に基づく）
* [geojson-serializer](https://github.com/ancore/geojson-serializer): annotations を持つ Java を GeoJSON としてシリアライズ

### リソース

* [RFC 7946 – The GeoJSON Format](https://tools.ietf.org/html/rfc7946): IETF による現在の GeoJSON 標準
* [GeoJSON.org](http://geojson.org/): GeoJSON 構造のすべての規則を定義した最初の仕様
* [More than you ever wanted to know about GeoJSON](http://www.macwright.org/2015/03/23/geojson-second-bite.html): より叙述的な形式で仕様の背後にある概念をレビュー。
* [geojson-invalid-geometry](https://github.com/chrieke/geojson-invalid-geometry): サンプルファイル付き GeoJSON 無効 geometry 問題の一覧。
