## ツール

#### ライブラリ
- [Chroma.js](http://gka.github.io/chroma.js/) - 色を扱うためのJavaScriptライブラリ。
- [pigment](https://github.com/satya164/pigment) - 色情報、変換、操作のライブラリ。
- [GradStop.js](https://github.com/Siddharth11/gradStop.js) - グラデーションのカラーストップを生成する。
- [Adaptive Backgrounds](https://briangonzalez.github.io/jquery.adaptive-backgrounds.js/) - 画像から主要な色を抽出し、親要素へ適用する（jQueryプラグイン）。
- [Coloor](https://github.com/krasimir/coloor) - 画像プリロードユーティリティ。
- [Color Thief](https://github.com/lokesh/color-thief) - 画像からカラーパレットを取得する。
- [Colorify.js](https://github.com/LukyVj/Colorify.js) - シンプルでカスタマイズ可能な小さなJavaScriptカラー抽出器。
- [Colofilter.css](https://github.com/LukyVj/colofilter.css) - CSSで作られたデュオトーンフィルター。
- [Polychrome](https://github.com/cdonohue/polychrome) - 色の解析と操作のための小さなライブラリ。
- [Palettable](https://github.com/jiffyclub/palettable) - Palettable（旧brewer2mpl）はPython向けカラーパレットライブラリ。
- [picocli](http://picocli.info/) - ANSIカラーとスタイルを備えたJavaコマンドラインアプリケーションを作る小さなライブラリ。
- [granim.js](https://github.com/sarcadass/granim.js) - 流動的でインタラクティブなグラデーションアニメーションを作成する。
- [tinygradient](https://github.com/mistic100/tinygradient) - 高速で小さなグラデーション操作ツール。
- [TinyColor](https://github.com/bgrins/TinyColor) - JavaScript向けの高速で小さな色操作・変換ツール。
- [Distinct Colors](https://github.com/internalfx/distinct-colors) - 視覚的に区別できる色のパレットを生成する。
- [color2k](https://github.com/ricokahler/color2k) - 色の解析・操作ライブラリ。

#### ウェブアプリ
- [Color Picker for Data](http://tristen.ca/hcl-picker/) - 彩度を一定に保ち、簡単にパレットを選ぶ。
- [Colorbrewer2](http://colorbrewer2.org/) - ヒートマップとデータ可視化用の多色相・単色相パレット。
- [Coolors](https://coolors.co/) - デザイン向けの無限のカラーパレットを生成し共有する。
- [Flat UI Colors](http://flatuicolors.com/) - UIカラ―セット。
- [Material Design Colors](http://www.materialui.co/) - Material Design Colors、Flat UI Colors、Material Design Icons。
- [Palettab](http://palettab.com/) - タブを開くたびに新しいカラーパレットとフォントの着想を得られるChrome拡張機能。
- [Paletton](http://paletton.com) - カラースキームデザイナー。
- [Adobe Color Wheel](https://color.adobe.com/) - カラーホイールで配色を作成する。
- [Drag Gradients](http://elrumordelaluz.github.io/draGGradients/) - 複数のcss3放射状グラデーションを生成・カスタマイズする。
- [SassMe](https://github.com/jimniels/sassme) - コンパイルせずリアルタイムにSASSの色関数を可視化する。
- [Colourco](http://www.colourco.de/) - 色を簡単かつ直感的に組み合わせる。
- [HSL Color Picker](http://hslpicker.com/) - HSLカラーピッカー。
- [SVG Color Filter Playground](http://kazzkiq.github.io/svg-color-filter/) - feColorMatrixの仕組みを理解する。
- [Random A11y](http://www.randoma11y.com) - アクセシビリティに配慮したランダムなパレットを生成する。
- [Save My Palette](http://savemypalette.com/) - カラーパレットを保存、共有、エクスポートする。
- [Colordot](https://color.hailpixel.com) - 人のためのカラーピッカー。
- [Material Palette](http://www.materialpalette.com/) - Material Designのカラーパレット生成器。
- [0to255](http://www.0to255.com/) - 任意の色のバリエーションを探す。
- [147 Colors](http://147colors.com/) - CSSの色名を学ぶ。
- [Shutterstock Spectrum](http://www.shutterstock.com/labs/spectrum/) - Spectrumで色から画像を検索する。
- [ColRD](http://colrd.com/) - 世界と色の着想を作り共有する。
- [Palettable](http://www.palettable.io/) - デザインの事前知識なしに美しいカラーパレットを生成する。
- [Colorgorical](http://vrl.cs.brown.edu/color) - n色のパレットを生成する。
- [Color Library](http://colorlibrary.ch/) - 自動色分解。
- [ColorFavs](http://www.colorfavs.com/) - 美しいカラーパレットと色を作成・発見する。
- [Colormind](http://www.colormind.io/) - ディープラーニングを使う配色生成器。
- [iColorpalette](https://icolorpalette.com) - 色やテーマ別にカラーパレットを作成、閲覧、エクスポート（aco、ase、svg、png、pdf）する。
- [geenes](https://geenes.app/) - 数秒でカラースケールを作成し、sketchまたはコードへエクスポートする。
- [Tints and Shades](https://maketintsandshades.com/) - 指定した16進色の色合いと濃淡を10%刻みで表示する。
- [Sorted colors](https://enes.in/sorted-colors/) - 関連する色がまとまって見えるように並べた、名前付きCSSカラー。
- [Croma](https://croma.app) - 画像と色からカラーパレットを生成する。
- [Hexcolorpedia](https://hexcolorpedia.com/) - 16進色情報、色変換、濃淡、色調、Pantone照合、膨大なカラーパレット集。
- [Atmos](https://atmos.style/) - カラーパレット作成に必要なすべて。
- [AI Color Palette Generator](https://www.loopple.com/color-palette-generator) - AI搭載パレット生成器で見事な配色を簡単に作成する。
- [Colorca](https://colorca.org/) - HSLuv色空間でデジタル製品向けのアクセシブルなカラーパレットを設計する。
- [ColorBeta](https://colorbeta.com/) - 高度なCSSグラデーション生成器。
- [Color Wheel](https://colorwheel.co/) - 1810年のJohann Wolfgang von Goetheによる図画に基づくカラーホイール。
- [RGB HEX Code](https://rgbhexcode.com/) - HTML/CSSカラーピッカーと変換器。

## カラーパレット
- [ColorHunt](http://colorhunt.co/) - すばやくプレビューできるカラーパレット。
- [Swiss Style Color Picker](http://www.swisscolors.net/) - カラーパレット集。
- [UI Gradients](http://uigradients.com/) - 美しいカラーグラデーションを厳選したコレクション。
- [Color Hex Palettes](http://www.color-hex.com/color-palettes/) - 新しいカラーパレットを発見する。
- [Color Palettes](http://colorpalettes.net/) - 家、アパート、寝室、キッチン、居間、結婚式を色のアイデアで飾る。
- [Design Seeds](http://www.design-seeds.com/) - 自然に見つかる色と、意図を持った暮らしの美学。
- [Gradients](http://thewebrocks.com/demos/gradientsio/v2.html) - 厳選されたグラデーション。
- [Colour Names](http://colours.neilorangepeel.com/) - CSSの色名リスト。
- [BrandColors](http://brandcolors.net/) - 世界最大級ブランドの公式カラーコード。
- [Branition Colors](https://branition.com/colors) - ブランディングに最適なカラーパレットを手作業で厳選したコレクション。
- [Color Lisa](http://www.colorlisa.com/) - 世界の偉大なアーティストによるカラーパレットの傑作。
- [Cohesive Colors](http://javier.xyz/cohesive-colors/) - 一貫性のある配色を作るツール。
- [Colordrop](https://colordrop.io/) - 見栄えのよいカラーパレットのコレクション。
- [ColorsWall](https://colorswall.com/) - カラーパレットを保存し、生成する場所。
- [Open Color](https://yeun.github.io/open-color/) - 2型2色覚と1型2色覚モードで検証済みの色。
- [ColorClaim](http://www.vanschneider.com/colors) - 繊細な配色。
- [WebGradients](https://webgradients.com/) - 180種類の線形グラデーションを集めた無料コレクション。
- [Dave Green's 'cubehelix' colour scheme](http://www.mrao.cam.ac.uk/~dag/CUBEHELIX/) - cubehelix配色ファミリーのリソース。
- [Color Name List](https://github.com/meodai/color-names/) - 固有の色名を厳選した巨大なリスト。
- [Realtime Colors](https://www.realtimecolors.com) - 実サイト上で色とフォントを可視化する。
- [InclusiveColors](https://www.inclusivecolors.com/) - WCAG/APCAコントラスト検査とモックアップでのライブプレビューを備えた、アクセシブルなTailwind風カラーパレットを作成する。
- [ColorMagic](https://colormagic.app) - AIでカラーパレットを生成する。任意のキーワードを入力して対応するパレットを生成する。
- [Magic Gradient](https://magicgradient.com) - AIで任意のキーワードからグラデーションを生成する。
