# Awesome Stacks

Stacksを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## 目次 <a id="contents"></a>

- [フロントエンド](#front-end)
- [フルスタック](#full-stack)
- [バックエンド](#back-end)
- [モバイル](#mobile)

Awesome Stacksは、さまざまなアプリケーションや機能を構築する技術スタックをコミュニティが選定したリストです。オープンソースで、元祖[awesomeリスト](http://awesome.re/)に着想を得ています。

各スタックには名前、説明、主要なツールと技術の一覧があり、導入を容易にするチュートリアル、スターターキット、ボイラープレートへのリンクを含む場合があります。

優れた構築方法だと思うスタックがあれば、このファイルを編集して追加してください。詳細は[CONTRIBUTING.md](https://github.com/stackshareio/awesome-stacks/blob/70c81c220f254b9ca37cc5692cb29bafac306768/CONTRIBUTING.md)を参照してください。

#### スタックを閲覧する <a id="browsing-the-stacks"></a>

スタックはREADMEと[awesomestacks.dev](https://awesomestacks.dev/)の2か所で閲覧できます。GatsbyとReactで構築されたサイトは、GitHubおよびStackShare APIからデータを取得し、README掲載ツールのロゴと指標を表示します。
