# Awesome Web Animation [![Awesome](https://awesome.re/badge.svg)](https://github.com/sindresorhus/awesome)

<a href="https://awesome-web-animation.netlify.com">
  <img src="readme_assets/header.png">

このリストには、Web アニメーション作成向けの最も有用なツール・データを収録しています。
* Canvas、SVG、テキスト、スクロールなど、ブラウザー内のあらゆるものをアニメーションさせるライブラリ。
* ブラウザー内のアニメーションに関する書籍。
* ブラウザーへエクスポートできるアニメーション用 GUI ツール。

## SVG

- [Snap.svg](https://github.com/adobe-webplatform/Snap.svg) - モダン SVG グラフィックス用 JavaScript ライブラリ。
- [Svg.js](https://github.com/svgdotjs/svg.js) - SVG を操作・アニメーションする軽量ライブラリ。
- [Vivus](https://github.com/maxwellito/vivus) - SVG の描画アニメーションを作るライブラリ。
- [Walkway](https://github.com/ConnorAtherton/walkway) - SVG 要素を簡単にアニメーションする方法。
- [Raphael](https://github.com/DmitryBaranovskiy/raphael) - JavaScript Vector Library。
- [Bonsai](https://github.com/uxebu/bonsai) - BonsaiJS はグラフィックスライブラリ・レンダラー。

## 共通

- [GSAP](https://github.com/greensock/GSAP) - JavaScript アニメーションライブラリ。
- [TweenJS](https://github.com/CreateJS/TweenJS) - シンプルで強力な JavaScript tweening／アニメーションライブラリ。CreateJS ライブラリスイートの一部。
- [Anime.js](https://github.com/juliangarnier/anime) - JavaScript アニメーションエンジン。
- [Mojs](https://github.com/mojs/mojs) - Web 向けモーショングラフィックスツールベルト。
- [Animo.js](https://github.com/ThrivingKings/animo.js) - CSS アニメーションを管理する強力で小さなツール。
- [Move.js](https://github.com/visionmedia/move.js) - CSS3 をバックエンドにする JavaScript アニメーションフレームワーク。
- [Velocity](https://github.com/julianshapiro/velocity) - 高速化された JavaScript アニメーション。
- [Animateplus](https://github.com/bendc/animateplus) - モダン Web 向け A+ アニメーションモジュール。
- [Animatic](https://github.com/lvivski/animatic) - CSS アニメーションエンジン。
- [Just Animate](https://github.com/just-animate/just-animate) - アニメーションをシンプルに。
- [Haiku Core](https://github.com/HaikuTeam/core) - Web 向け対話的 UI アニメーションエンジン。Haiku Animator のコアレンダラー。
- [Between.js](https://github.com/sasha240100/between.js) - 軽量 JavaScript（ES6）tweening エンジン。
- [Progressbar.js](https://github.com/kimmobrunfeldt/progressbar.js) - レスポンシブで洗練されたプログレスバー。
- [Bezier easing](https://github.com/gre/bezier-easing) - JavaScript アニメーション easing 向け Cubic-bezier 実装。
- [Glsl easings](https://github.com/glslify/glsl-easings) - GLSL の easing 関数。
- [ES6-tween](https://github.com/tweenjs/es6-tween) - tween.js の ES6 版。
- [Weeee.js](https://github.com/sfi0zy/weeee) - 小さな JavaScript tweening エンジン。

## CSS

- [Animate.css](https://github.com/daneden/animate.css) - クロスブラウザー CSS アニメーションライブラリ。とても簡単に使えます。
- [Motion-ui](https://github.com/foundation/motion-ui) - CSS トランジション・アニメーション作成向け強力な Sass ライブラリ。
- [Magic](https://github.com/miniMAC/magic) - 特殊効果を持つ CSS3 Animations。
- [Css-loaders](https://github.com/lukehaas/css-loaders) - CSS でアニメーションするローディングスピナーのコレクション。
- [SpinKit](https://github.com/tobiasahlin/SpinKit) - CSS でアニメーションするローディングインジケーターのコレクション。
- [Bounce.js](https://github.com/tictail/bounce.js) - 美しい CSS3 強化アニメーションをすぐに作成。

## Canvas

- [EaselJS](https://github.com/CreateJS/EaselJS) - HTML5 で高性能な対話的2Dコンテンツを構築するライブラリ。
- [Fabric.js](https://github.com/fabricjs/fabric.js) - アニメーションサポートを持つ JavaScript canvas ライブラリ。
- [Paper.js](https://github.com/paperjs/paper.js) - HTML5 Canvas を使い Scriptographer を JavaScript・ブラウザーへ移植した、ベクターグラフィックススクリプティングの万能ナイフ。
- [Konva](https://github.com/konvajs/konva) - デスクトップ・モバイルアプリ向け canvas 対話性を可能にして2d context を拡張する、HTML5 Canvas JavaScript フレームワーク。
- [Two.js](https://github.com/jonobr1/two.js) - アニメーションサポートを持つ、Web 向けレンダラー非依存の2次元描画 api。
- [Ocanvas](https://github.com/koggdal/ocanvas) - オブジェクトベース canvas 描画用 JavaScript ライブラリ。
- [Curtainsjs](https://github.com/martinlaxenaire/curtainsjs) - HTML DOM 要素を対話的テクスチャ平面に変える軽量 vanilla WebGL JavaScript ライブラリ。
- [Hover-effect](https://github.com/robin-dela/hover-effect) - ホバー時に画像を描画・アニメーションする JavaScript ライブラリ。
- [Pts.js](https://github.com/williamngan/pts) - 可視化・クリエイティブコーディングのための typescript/javascript ライブラリ。
- [tsParticles](https://github.com/matteobruni/tsparticles/) - パーティクルアニメーションを簡単に作る軽量 typescript/javascript ライブラリ。

## スクロール時アニメーション

- [AOS](https://github.com/michalsnik/aos) - スクロール時アニメーションライブラリ。
- [Laxxx](https://github.com/alexfoxy/laxxx) - スクロール時にスムーズで美しいアニメーションを作る、シンプルで軽量（minified・zipped で3kb）vanilla JavaScript プラグイン！
- [Wow](https://github.com/matthieua/WOW) - ページを下へスクロールすると CSS アニメーションを表示。
- [Scrollreveal](https://github.com/scrollreveal/scrollreveal) - 要素がビューへスクロールインする際にアニメーション。
- [ScrollMagic](https://github.com/janpaepke/ScrollMagic) - 魔法のようなスクロール対話性のための JavaScript ライブラリ。
- [Motus](https://github.com/alexcambose/motus) - スクロール時に CSS keyframes を模倣するアニメーションライブラリ。
- [Sal](https://github.com/mciastek/sal) - パフォーマンス重視の軽量スクロールアニメーションライブラリ。

## テキスト

- [Malarkey](https://github.com/yuanqing/malarkey) - vanilla JavaScript でタイプライター効果をシミュレート。
- [Typed.js](https://github.com/mattboldt/typed.js) - JavaScript Typing Animation Library。
- [Shuffle-text](https://github.com/ics-ikeda/shuffle-text) - Flash の素敵な遺産のような JavaScript テキスト効果ライブラリ。
- [Typebot](https://github.com/akzhy/typebot) - タイピングアニメーション用 JavaScript ライブラリ。
- [Blotter](https://github.com/bradley/Blotter) - Web 上で型破りなテキスト効果を描画する JavaScript API。

## React

- [Motion](https://github.com/framer/motion) - React 向けオープンソース・本番対応アニメーション・ジェスチャーライブラリ。
- [SVGR](https://github.com/gregberge/svgr) - SVG を React コンポーネントへ変換。
- [React tsParticles](https://github.com/matteobruni/tsparticles/blob/master/components/react/README.md) - *tsParticles* 用 ReactJS ラッパー
- [React spring](https://www.react-spring.io/) - 補間をサポートする React 向け、オープンソースの spring-physics ベースアニメーションライブラリ。高速で使いやすい。

## GUI ツール

- [Svgartista](https://svgartista.net/) - SVG 画像の stroke・fill プロパティをプレーン CSS コードでアニメーションする支援ツール。path、line、polyline、rect、circle、ellipse、polygon 要素で動作しますが、SVG gradients はアニメーションできません。
- [Mantra](https://jeremyckahn.github.io/mantra/) - Web アニメーション用タイムライン編集ツール。Adobe Flash・After Effects などに着想を得ています。
- [Animista](https://animista.net/) - 事前作成済み css アニメーションのコレクションを試し、調整し、実際に使うものだけを取得できる場所。
- [Cssanimate](http://cssanimate.com/) - デスクトップソフトウェアなしにブラウザー内で CSS3 keyframes animation を簡単・高速に作るツール。コーディングなしで複雑な CSS3 keyframe animation と、サイトで使える完成 css styles を作成できます。
- [Ceaser](https://matthewlein.com/tools/ceaser) - モダンブラウザーすべてで CSS transitions を使える今、それらを美しくするツール。Flash・jQuery のクラシック Penner equations の多くを含みます。cubic-bezier は大きな可能性を持つものの使いにくかった問題を解決。タッチ端末にも対応！
- [Cubic Bezier](https://cubic-bezier.com/) - Bezier curves 作成用の優れたユーティリティ。ライブラリとの曲線インポート・エクスポートで他者と共有できます。
- [Keyframer](http://alexberg.in/keyframer/) - アニメーションコンポーネントを可視化し、必要なコードを出力するツール。
- [CSS Animation Kit](http://angrytools.com/css/animation/) - 上部パネルから事前定義サンプルを選択。下には左から右へ 0%〜100% の101 keyframes を持つ @keyframes タイムラインがあります。ハイライトした keyframe はその地点にスタイルが設定済みで、新しいスタイルも追加できます。

## 書籍

### [SVG animation](https://www.amazon.com/SVG-Animations-Implementations-Responsive-Animation/dp/1491939702)

<img src="data/covers/92ZiDgAAQBAJ.jpg" width="200"/>

&nbsp;

SVG は HTTP リクエスト数が少なく、どのディスプレイでも鮮明で、極めて強力です。レスポンシブアニメーションとパフォーマンス上の利点を探るほど興味深くなります。SVG をアニメーションする際は、構図、色、実装、最適化など通常の画像特性を意識する必要がありますが、アニメーションは各要因の複雑さを飛躍的に高めます。

### [Creating Web Animations: Bringing Your UIs to Life](https://www.amazon.com/Creating-Web-Animations-Bringing-Your/dp/1491957514/)

<img src="data/covers/NK9rDgAAQBAJ.jpg" width="200"/>

&nbsp;

高速なブラウザー、より良い Web 標準サポート、強力なデバイスにより、Web は楽しく実用的で流動的、記憶に残る次世代 UI を定義します。鍵はアニメーションです。しかしアニメーション作成の学習は難しく、既存教材はアニメーションが解決する UI 問題の文脈を説明していません。この本がその役割を担います。

### [Transitions and Animations in CSS: Adding Motion with CSS](https://www.amazon.com/Transitions-Animations-CSS-Adding-Motion/dp/149192988X/)

<img src="data/covers/bx2OrgEACAAJ.png" width="200"/>

Web アプリケーションに生命・奥行きを加え、CSS トランジション・アニメーションの控えめな利用で UX を改善します。この簡潔なガイドは、ボールの現実的なバウンド、ドロップダウンの段階的な展開、ホバー時の要素への注意喚起など、ページ要素の移動・外観変更方法を教えます。

### [Designing Interface Animation: Meaningful Motion for User Experience](https://www.amazon.com/Designing-Interface-Animation-Meaningful-Experience/dp/1933820322/)

<img src="data/covers/Ano3DwAAQBAJ.jpg" width="200"/>

効果的なインターフェイスアニメーションは、フィードバック改善、方向付け支援、注意の誘導、因果関係の提示、ブランドの個性表現のため、形と機能を巧みに組み合わせます。本書は目的・スタイルのバランスを取り、ユーザー体験へシームレスに溶け込む Web アニメーションの作り方を示します。Web デザイナー、UX 専門家、フロントエンド開発者向けのモーションデザイン理論・実践の速習書です。

### [Web Animation using JavaScript: Develop & Design](https://www.amazon.com/Web-Animation-using-JavaScript-Develop/dp/0134096665)

<img src="data/covers/4Wo0BwAAQBAJ.jpg" width="200"/>

点滅するバナー広告やスクロールニュースティッカーの時代から大きく進みました。現在の iOS・Android の優れたモーションデザインは、体験を損なうのでなく劇的に改善します。今日の最良のサイト・アプリは、インターフェイスの感触・直感性を改善するためアニメーションを活用し、アニメーションのないサイトは時代遅れに見え始めています。本書は、視覚的に優れ、プログラムで保守できる方法でアニメーションを実装する技術的基盤を提供します。

### [CSS Animations and Transitions for the Modern Web](https://www.amazon.com/gp/product/0133980502/)

<img src="data/covers/848sBQAAQBAJ.png" width="200"/>

モダンな Web サイトは、ユーザビリティを高め、ユーザーを楽しませ驚かせるために多様なアニメーション効果を使います。一部は複雑なスクリプト・プログラミングを必要としますが、多くは CSS・HTML に慣れたデザイナーの手に届きます。本書は CSS3 スタイル定義で時間とともに Web ページへ動きを加える方法を示します。

### [Animation in HTML, CSS, and JavaScript](https://www.amazon.com/Animation-HTML-JavaScript-Kirupa-Chinnathambi/dp/1502548704)

<img src="data/covers/47ffoQEACAAJ.png" width="200"/>

実用的・使いやすく、とてもクールな HTML、CSS、JavaScript アニメーションを作る助けとなる本です。各章には明快な概念説明、美しい図、カラフルなコードスニペット、友人をうめかせる一行ネタが詰まっています。まず CSS のアニメーション・トランジションを学び、終盤では DOM 要素操作と canvas へのピクセル描画による JavaScript アニメーションを学びます。

### [Foundation HTML5 Animation with JavaScript](https://www.amazon.com/Foundation-HTML5-Animation-JavaScript-Lamberta/dp/1430236655/)

<img src="data/covers/RmphScK8u-gC.jpg" width="200"/>

本書は HTML5 canvas による動的スクリプトアニメーション作成に必要なすべてを扱います。関連する数学の後に、加速度、速度、easing、ばね、衝突検出、運動量保存、3D、順運動学・逆運動学などの物理概念を説明します。HTML5 に取り組む、または Flash から移行してモダンブラウザーと大多数のモバイル端末（iPhone、iPad、Android）で動く標準準拠のゲーム、アプリケーション、アニメーションを作るすべての Web 開発者向け優れたリソースです。
