## 新着

リポジトリ内の各フォントディレクトリには、垂直メトリクステーブル（`vertical_metrics.txt`）が含まれています。これらの参照テーブルのデータを新しい [`font-line` tool](https://github.com/source-foundry/font-line)と組み合わせることで、任意のフォントの行間を必要に応じて調整できます。密にしたり、そのままゆるく保ってください。

## フォントアーカイブのダウンロード

<a href="https://github.com/chrissimpkins/codeface/releases/download/font-collection/codeface-fonts.zip"><img src="https://raw.githubusercontent.com/chrissimpkins/codeface/40538ae5ffee793c98355b2c03c30130aed51932/images/non-gallery/download-button.png" style="margin-left: 100px" alt="Download All Fonts" width="125"></a>

以下のリンクをクリックして、Codeface メインおよびビットマップギャラリー収集内のすべてのフォントバイナリをダウンロードできます：

| Archive  | SHA1  | Size |
| :------------: |:---------------:| :-----:|
| [codeface-fonts.zip](https://github.com/chrissimpkins/codeface/releases/download/font-collection/codeface-fonts.zip) | `4709e7b6f63d1e2c31f7af0d56b7e1f75a846476` | 31.4 MB |
| [codeface-fonts.tar.xz](https://github.com/chrissimpkins/codeface/releases/download/font-collection/codeface-fonts.tar.xz) | `e4416c72e331d71e55fd56f2fba38cfda7672f85` | 16.5 MB |

または、次のコマンドのいずれかを使用して、`curl`を含むフォントアーカイブを取得できます：

```
$ curl -OL https://github.com/chrissimpkins/codeface/releases/download/font-collection/codeface-fonts.zip
```

```
$ curl -OL https://github.com/chrissimpkins/codeface/releases/download/font-collection/codeface-fonts.tar.xz
```
