<a id="audio-editing"></a>
## 音声編集

* [Audacity](https://github.com/audacity/audacity) - 無料のクロスプラットフォーム対応デジタルオーディオエディター
* [Ardour](http://ardour.org/) - 音声録音を重視したクロスプラットフォーム対応デジタルオーディオワークステーション
* [LMMS](https://lmms.io/) - ビート制作を重視したクロスプラットフォーム対応デジタルオーディオワークステーション
* [OpenUtau](https://github.com/stakira/openutau/) - 無料でクロスプラットフォーム対応の歌声合成フレームワーク
* [snd](https://sourceforge.net/projects/snd/) - Emacsを緩やかに手本とした音声エディター
* [Stargate DAW](https://github.com/stargatedaw/stargate/) - EDM制作向けに最適化された、クロスプラットフォーム対応の統合デジタルオーディオワークステーション／プラグイン集
* [TuneFlow](https://tuneflow.com/) - 次世代のDAWで、メロディやビート、あるいは完成した楽曲を生成できる一方で、それらを編集できる

<a id="audio-libraries"></a>
## 音声ライブラリ

* [audio.js](https://github.com/kolber/audiojs) - HTML5の&lt;audio&gt;タグを幅広い環境で使えるようにする、すぐ導入可能なJavaScriptライブラリ
* [audioFlux](https://github.com/libAudioFlux/audioFlux) - 音声および音楽の解析、特徴抽出を支援するライブラリ
* [chord-mark](https://github.com/no-chris/chord-mark) - 歌詞、コード、リズムを表すテキスト記法ChordMarkの参照実装
* [howler.js](https://github.com/goldfire/howler.js) - 現代のウェブ向けのJavaScript音声ライブラリ
* [JSyn](http://www.softsynth.com/jsyn/) - Java用の音声合成ソフトウェアAPI
* [Librosa](https://github.com/librosa/librosa) - 音楽および音声の解析を支援するPythonパッケージで、音楽情報検索システムの構築に必要な基本要素を提供
* [midi.js](https://github.com/mudcube/MIDI.js) - ウェブベースのMIDIアプリケーションを作成するためのフレームワーク
* [mxml](https://github.com/venturemedia/mxml) - MusicXMLのパースおよびレイアウトライブラリ
* [PortAudio](http://www.portaudio.com/) - 無料・オープンソースでクロスプラットフォーム対応の音声I/Oライブラリ
* [RustAudio](https://github.com/RustAudio) - Rustで書かれた無料かつ有用なオーディオ、DSP、音楽ライブラリの集積
* [Soundpipe](https://pbat.ch/proj/soundpipe.html) - Cで書かれた軽量なDSPライブラリ

<a id="audio-tools"></a>
## 音声ツール

* [Auralytics](https://github.com/WengYiNing/Auralytics) - 無料の個人用Spotify分析ツール
* [Beets](http://beets.io/) - 強力なコマンドラインベースの音楽整理および操作ツール
* [Cecilia](https://github.com/belangeo/cecilia5) - Pyoに基づいた音楽および信号処理用のグラフィカル環境
* [cyanrip](https://github.com/atomnuker/cyanrip) - 最小限の操作で一般的な音楽CDをリッピング・エンコードできるクロスプラットフォーム対応ツール
* [fre:ac](https://github.com/enzo1982/freac) - フリーのオーディオ変換ツール。オーディオCDのリップおよびタグ編集をサポート。
* [Jack](https://github.com/jack-cli-cd-ripper/jack) - コマンドラインベースのCDリップツール
* [K3b](https://github.com/KDE/k3b) - CD／DVD／Blu-rayの書き込みとリッピングに対応する多機能アプリケーション
* [Kima](https://github.com/Chevron7Locked/kima-hub) - 機械学習を活用したセルフホスト型音楽ストリーミングサーバー。ムードに基づく探索とSubsonic API対応を備える
* [Koel](https://github.com/phanan/koel) - オープンソースの個人用オーディオストリーミングサーバー
* [Lame](http://lame.sourceforge.net/) - 高品質で無料かつオープンソースのMP3エンコーダー
* [lltag](https://github.com/bgoglin/lltag) - MP3／OGG／FLACファイルのタグ付けと名前変更を自動化するコマンドラインツール
* [matchering](https://github.com/sergree/matchering) - コンテナ化されたウェブアプリケーションおよびライブラリ。自動化されたリファレンスオーディオマスタリングを提供
* [MusicBrainz](https://musicbrainz.org) - 音楽情報とメタデータを提供するオープンな百科事典。すべての項目に一意のIDを付与する
* [Rubyripper](https://github.com/bleskodev/rubyripper) - Unix系オペレーティングシステム向けの安全なデジタルオーディオ抽出アプリケーション（"cd ripper"）
* [SoX](http://sox.sourceforge.net/) - オーディオファイルの再生、変換および操作を行う無料オープンソースコマンドラインツール
* [split2flac](https://github.com/ftrvxmtrx/split2flac) - flac/ape/wv/wav + cue sheetを個別のトラックに分割
* [Whipper](https://github.com/JoeLametta/whipper) - 正確性を優先するPythonによるCD-DAリップ（cd ripper）
* [X Audio Copy](https://github.com/giorgiofranceschi/xaudiocopy) - 音楽CDをリッピングし、非可逆／可逆音声形式へエンコードするGTK／GNOMEアプリケーション

## 無料の楽譜

* [bayanguru](https://bayanguru.org/) - bayan用の高品質の楽譜をPDFで生成・公開するシステム
* [cellist/Lilypond-Sheet-Music](https://github.com/cellist/Lilypond-Sheet-Music) - LilyPondで組版した楽曲集（主に室内楽とチェロ曲）

* [IMSLP](http://imslp.org/) - Web上で最大規模のパブリックドメイン楽譜・パート譜コレクションであるInternational Music Score Library Project
* [Lavender Blue Open-Scores](https://github.com/madrisan/open-scores) - LilyPondでエンコードされたピアノ用のオープン楽譜
* [Mutopia](https://github.com/MutopiaProject/MutopiaProject) - パブリックドメインの版に基づく楽譜
* [wbsoft/lilymusic](https://github.com/wbsoft/lilymusic) - 無料ライセンスで提供される美しいLilyPond楽譜

<a id="music-programming"></a>
## 音楽プログラミング

* [Alda](https://github.com/alda-lang/alda) - 音楽家向けの音楽プログラミング言語
* [Bach: Automated Composer's Helper](http://www.bachproject.net/) - Max向けのクロスプラットフォームパッチと外部ツールセットで、コンピュータ支援作曲の豊かさをリアルタイム世界に届ける
* [Cane](https://github.com/Jackojc/cane) - ベクトルとユークリッドリズムに基づいた小さなMIDIシーケンサDSL
* [Chuck](https://github.com/ccrma/chuck) - 厳密な時間制御、並行処理、オンザフライ実行に対応する音楽プログラミング言語
* [CoffeeCollider](https://github.com/mohayonao/CoffeeCollider) - HTML5でリアルタイムオーディオ合成とアルゴリズム的作曲を行うための言語。"CoffeeScriptを書くと、SuperColliderとして処理される。"
* [Common Music](http://commonmusic.sourceforge.net/) - オープンソースの音楽作曲システム。
* [Csound](http://csound.github.io/) - ユーザーがプログラム可能で、ユーザーが拡張可能な音響処理言語およびソフトウェアシンセイザー。
* [DrumBeatRepo](https://github.com/babali42/drumbeatrepo) - ブラウザ内で、さまざまな音楽ジャンルのドラムビートを演奏できるリズムライブラリ。
* [Faust](http://faust.grame.fr/) - リアルタイム信号処理および合成に特化した関数型プログラミング言語。
* [Gwion](https://github.com/Gwion/Gwion) - 音楽作成に向けた強力な時刻制御プログラミング言語。ChucKに強くインスパイアされている。
* [IanniX](https://github.com/iannix/IanniX) - イアンニス・ケナクスの作品に基づいた、グラフィカルなオープンソースシーケンサ。
* [Inscore](http://inscore.sourceforge.net/) - インタラクティブかつ拡張された音楽スコアの設計に用いられる環境。
* [Leipzig](https://github.com/ctford/leipzig) - Overtone用の作曲ライブラリ。
* [Leiter](https://github.com/kad1kad/leiter) - スケールを生成するためのTypeScriptベースのライブラリ。
* [Midica](https://github.com/truj/midica) - MIDIプログラミング言語にデコンパイラとプレイヤーを備え、カラオケをサポート。
* [music21](http://web.mit.edu/music21/) - 計算音楽学に向けたツールキット。
* [Music Suite](http://music-suite.github.io/docs/ref/) - 一般化された音楽記号および理論をHaskellに基づいて構築した言語。
* [mutwo](https://mutwo-org.github.io/) - 記号、MIDI、またはオーディオファイルを出力し、時間ベース構造を一般化モデルで記述できるPythonライブラリ。
* [Nyquist](https://www.cs.cmu.edu/~music/nyquist/) - 音響合成および作曲を行うための言語。
* [OpenMusic](http://repmus.ircam.fr/openmusic/home) - Lispに基づく視覚プログラミング言語
* [Orca](https://github.com/hundredrabbits/Orca) - 音楽用のライブプログラミング環境
* [Overtone](https://github.com/overtone/overtone/) - シンセサイザーの設計および音楽との協働を支援するオープンソースツールキット
* [Platonic Music Engine](http://www.platonicmusicengine.com/) - Luaで書かれたオープンソースの音楽生成フレームワーク
* [Pure Data](http://puredata.info/) - 音声およびその他のマルチメディア用の視覚プログラミング言語
* [pyo](https://belangeo.github.io/pyo/) - デジタル信号処理スクリプト作成を支援するPythonモジュール
* [py-modular](http://py-modular.readthedocs.io/) - Pythonで基本的なDSP処理を扱える、モジュラーシンセシス向けの実験的プログラミング環境
* [Sardine](https://github.com/Bubobubobubobubo/sardine) - Python 3.10以降向けの音楽ライブコーディングライブラリ（MIDI/OSC/SuperCollider）
* [slippery chicken](https://github.com/mdedwards/slippery-chicken) - CLM、CMN、CM、MusicXMLおよびLilypondで楽譜、音声ファイル、および/またはMIDIファイル出力を行うためのCommon Lisp環境
* [Sonic Pi](http://sonic-pi.net/) - 教育用途に重点を置いたライブコーディングシンセサイザー
* [Sporth](https://pbat.ch/proj/sporth.html) - スタックベースの小型音声言語
* [Strudel](https://strudel.tidalcycles.org/) - ウェブ技術を用いてライブコーディングパターンを構築するJavaScriptベースの言語の実験
* [SuperCollider](http://supercollider.github.io/) - リアルタイム音声合成およびアルゴリズムベースの作曲用のプログラミング言語
* [Tidal](https://tidalcycles.org/) - ライブコーディングパターンをHaskellに基づく言語で構築
* [Topos](https://topos.live) - ウェブベースのライブコーディング環境（WebAudio / MIDI）
* [tuneflow-py](https://github.com/tuneflow/tuneflow-py/) - 次世代DAW用のPythonプラグインSDK。音楽アルゴリズムやAIモデルを、音楽制作のすべての段階にプログラム可能。
* [Unilang](https://unisonofficial.com/html/user-documentation.html?title=unison-editor) - Unisonで使用されるドメイン固有言語。

<a id="standards"></a>
## 標準

* [MEI (Music Encoding Initiative)](http://music-encoding.org/) - 音楽文書をマシン可読形式でエンコードするためのシステムを定義するオープンソースプロジェクト。
* [MusicXML](http://www.musicxml.com/) - デジタル楽譜を交換するための標準オープンフォーマット。
* [SMuFL (Standard Music Font Layout)](http://www.smufl.org/) - 音楽記号をUnicodeにマッピングするための仕様。
