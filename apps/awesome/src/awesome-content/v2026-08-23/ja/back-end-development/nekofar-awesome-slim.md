# Awesome Slim [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)


[<img src="assets/slim-logo.png" align="right" width="260" alt="Slim Framework">](https://www.slimframework.com)


> 優れた[Slim](https://www.slimframework.com)フレームワークパッケージとリソースの厳選リスト。


[Slim](https://www.slimframework.com) は、シンプルながら強力なWebアプリケーションとAPIを素早く書くのに役立つPHPマイクロフレームワークです。

## 教育

- [User Guide](https://www.slimframework.com/docs/v4/) - Slim Frameworkの公式ドキュメント。
- [Stack Overflow](https://stackoverflow.com/questions/tagged/slim) - Stack Overflow上のSlim Frameworkに関する質問。
- [Discussion Forum](https://discourse.slimframework.com) - Slim Frameworkの公式ディスカッションフォーラム。
- [Slim 4 - GraphQL](https://odan.github.io/2021/08/12/slim-graphql.html) - GraphQLを使ったモダンなHTTP APIの作成。
- [Slim 4 - ReactPHP](https://odan.github.io/2021/08/14/slim-reactphp.html) - パフォーマンスを高めるためReactPHPと組み合わせたSlim。

## ボイラープレート

- [Slim 4 MVC Skeleton](https://github.com/semhoun/slim-skeleton-mvc) - シンプルなWebアプリケーションのスケルトンプロジェクト。
- [Slim 4 Skeleton](https://github.com/adriansuter/Slim4-Skeleton) - PHP-DI、Nyholm PSR7、Twigを使用するWebアプリケーションスケルトン。
- [Slim 4 Skeleton](https://github.com/odan/slim4-skeleton) - 新しいSlim 4アプリケーションを素早くセットアップするスケルトン。
- [Slim Skeleton](https://github.com/slimphp/Slim-Skeleton) - 公式Slim Framework 4 Skeleton Application。
- [Slim 4 Starter](https://github.com/nbayramberdiyev/slim-4-starter) - 小中規模PHPアプリケーション向けの意見を持ったSlim 4スターターテンプレート。

## ミドルウェア

- [Slim Basic Auth](https://github.com/tuupola/slim-basic-auth) - PSR-7およびPSR-15 HTTP Basic Authentication Middleware。
- [Slim CSRF](https://github.com/slimphp/Slim-Csrf) - Slim FrameworkのCSRF保護ミドルウェア。
- [Slim HTTP Cache](https://github.com/slimphp/Slim-HttpCache) - Slim FrameworkのHTTPキャッシュミドルウェアおよびサービスプロバイダー。
- [Slim JWT Auth](https://github.com/tuupola/slim-jwt-auth) - PSR-7およびPSR-15 JWT Authentication Middleware。
- [Slim Minify](https://github.com/christianklisch/slim-minify) - slimで生成されるHTML出力をminifyするSlimミドルウェア。
- [Slim Session](https://github.com/bryanjhv/slim-session) - Slim Framework用のとてもシンプルなセッションミドルウェア。
- [Slim Whoops](https://github.com/zeuxisoo/php-slim-whoops) - slim framework上のPHP whoopsエラー。

## テンプレート

- [Slim Twig View](https://github.com/slimphp/Twig-View) - Twigテンプレートコンポーネントの上に構築されたSlim Frameworkビューへルパー。
- [Slim Plates](https://github.com/projek-xyz/slim-plates) - Platesテンプレートエンジンを使ってSlimアプリケーションビューをレンダリングします。
- [Slim PHP View](https://github.com/slimphp/PHP-View) - PHPビューのスクリプトをPSR-7 Responseオブジェクトへレンダリングするrendererです。

## 開発

- [Pest Slim Plugin](https://github.com/nekofar/pest-plugin-slim) - Pest用Slim Pluginはテストの基本機能を提供します。
- [Slim Test](https://github.com/nekofar/slim-test) - PHPUnitテストフレームワークの上に構築されたSlim Frameworkテストヘルパー。

## その他

- [BasePath](https://github.com/selective-php/basepath) - Slim 4用のベースパス検出器。
- [PHP-DI Slim Bridge](https://github.com/PHP-DI/Slim-Bridge) - SlimフレームワークとのPHP-DI統合。
- [Slim Config](https://github.com/DavidePastore/Slim-Config) - PHP、INI、XML、JSON、YMLファイルをサポートするファイル設定ローダー。
- [Slim Console](https://github.com/slimphp/Slim-Console) - Slim Frameworkコンソール。
- [Slim Flash](https://github.com/slimphp/Slim-Flash) - Slim Frameworkフラッシュメッセージサービスプロバイダー。
- [Slim JSON API](https://github.com/entomb/slim-json-api) - 高速なJSON APIを実装するSlim拡張。
- [Slim Validation](https://github.com/DavidePastore/Slim-Validation) - Slim Framework用のバリデーションライブラリ。
- [IntelliJ Slim](https://plugins.jetbrains.com/plugin/18751-slim) - skeletonを使用した新規プロジェクト作成を容易にするボイラープレートコードを提供します。
