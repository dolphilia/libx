# Awesome Symfony

Symfonyを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## 管理

* [AdminCrudBundle](https://github.com/MWSimple/AdminCrudBundle) - AdminCrudBundle - SensioGeneratorBundleを使用。コントローラを拡張し、ページネーター、フィルター、その他機能を追加。
* [AdmingeneratorGeneratorBundle](https://github.com/symfony2admingenerator/AdmingeneratorGeneratorBundle) - Symfony2用のアドミンジェネレーター。generator.ymlファイルを解析してクラスを生成。
* [EasyAdminBundle](https://github.com/javiereguiluz/EasyAdminBundle) - Symfonyアプリケーション向けのシンプルなアドミンジェネレーター。
* [SonataAdminBundle](https://github.com/sonata-project/SonataAdminBundle) - AdminBundle - Symfony2用の欠けているアドミンジェネレーター。
* [AdminLTEBundle](https://github.com/kevinpapst/AdminLTEBundle) - AdminLTEテンプレートに基づくアドミンテーマ。
* [Umbrella framework](https://github.com/acantepie/umbrella) - 管理画面を構築するためのアドミンコンポーネントとテーマ。
* [TablerBundle](https://github.com/kevinpapst/TablerBundle) - Tablerテンプレートに基づくアドミンテーマ。多くのTwigヘルパー（関数、フィルター、埋め込み、マクロ、インクルード）を標準で提供。
