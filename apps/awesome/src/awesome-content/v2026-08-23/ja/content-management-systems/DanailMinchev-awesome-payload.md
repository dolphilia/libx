# Awesome Payload [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> ユーザーと開発者向けの、優れた Payload リソースの厳選リスト。

[<img src="./media/payload-logo.jpg" alt="Payload" width="300" align="right" />](https://payloadcms.com/)

<p>
<a href="https://payloadcms.com/">Payload</a> は、API と管理 UI を構築するうえで最高の開発者第一の体験を提供することを目指した、無料かつオープンソースのフルスタック Next.js フレームワークおよびヘッドレス CMS です。<br />
Payload は Next.js とネイティブに統合され、Next.js アプリへ直接インストールされます。
</p>

## プラグイン

興味深いコミュニティプラグインの一覧。

- [r1tsuu / payload-enchants](https://github.com/r1tsuu/payload-enchants) - Payload 向け拡張パッケージのコレクション。
- [authsmith / payload-auth-plugin](https://github.com/authsmith/payload-auth-plugin) - Payload の認証プロセスを拡張し、OAuth と Passkey に基づく認証機能を実装するプラグイン。
- [payload-auth / payload-auth](https://github.com/payload-auth/payload-auth) - Payload とさまざまな認証プロバイダーを統合するための monorepo。
- [CrawlerCode / payload-authjs](https://github.com/CrawlerCode/payload-authjs) - Auth.js 向け Payload プラグイン。
- [ashbuilds / payload-ai](https://github.com/ashbuilds/payload-ai) - 高度な AI 機能を統合してコンテンツの作成と管理を強化する、強力な Payload AI プラグイン。
- [elliott-w / imageAspectRatios.ts](https://gist.github.com/elliott-w/19676d9373d79ee20b9195601dc45808) - Payload 画像アスペクト比プラグイン。
- [AdrianMaj / payload-lexical-typography](https://github.com/AdrianMaj/payload-lexical-typography) - lexical のタイポグラフィーオプション（文字色、フォントサイズ、文字間隔、行高、フォントファミリーなど）を拡張する Payload プラグイン。
- [rilrom / payload-bites](https://github.com/rilrom/payload-bites) - image-search、fullscreen-editor、audit-fields、soft-delete、activity-log などのさまざまな小規模 Payload v3 プラグインのコレクション。
- [shefing / payload-tools](https://github.com/shefing/payload-tools) - Payload プロジェクトを強化するために設計された強力なプラグインセット（Authorization、Authors Info、Rich-text Comments、Right Panel、Custom Version View、Cross-Collection Config、Field-type Component Override、Color Picker Field、Icon Select、Quick Filter、Reset List Viewなど）を含みます。
- [Crayonan / payload-plugin-ai-localization](https://github.com/Crayonan/payload-plugin-ai-localization) - Payload の主言語ではないローカライズフィールドに AI 駆動の「Translate」ボタンを追加します。OpenAI または他のモデルを用いて、主言語からコンテンツを自動翻訳します。
