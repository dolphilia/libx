# Awesome video game: Awesome Game Datasets

video game: Awesome Game Datasetsを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## API

APIとは、_「オペレーティングシステム、アプリケーション、その他のサービスの機能やデータへアクセスするアプリケーションを作成できるようにする、関数と手続きの集合」_です（Google）。

- [Battle.net](https://develop.battle.net/) - [Blizzard](https://www.blizzard.com)が開発したゲームのコレクション。
- [Battlefield 4 Stats](https://bf4db.com/stats) - プレイヤーの統計、順位、進化状況。
- [BoardGameGeek](https://boardgamegeek.com/wiki/page/BGG_XML_API2) - ボードゲームのデータ。
- [Counter-Strike](https://github.com/pnxenopoulos/csgo) - Counter-Strike: Global Offensive (CSGO) のデータ解析。
- [Giant Bomb](https://www.giantbomb.com/api/) - ゲームデータとプレイヤーのレビュー。
- [IGDB](https://www.igdb.com/api) - どのプラットフォームからも取得可能なゲームの一般情報。
- [Marvel Developer](https://developer.marvel.com/) - マーベルの広大なコミックコレクションに関する情報。
- [metacritc](https://www.metacritic.com/game) - ゲームのレビューと評価。
- [NEXARDA](https://www.nexarda.com/api) - ゲームと価格データ。
- [OpenCritic](https://www.opencritic.com) - ゲームレビューをまとめるサービス。
- [OpenDota](https://www.opendota.com/) - Dota 2のデータを提供するプラットフォーム。
- [PandaScore](https://pandascore.co/) - リアルタイムのeスポーツデータ。
- [PixelGamesHub AI Games Index](https://pixelgameshub.com/ai-games/index) - AIを活用したブラウザゲームのキュレーションされたインデックス（オープンJSONおよびCSVエンドポイントあり）。
- [PokéAPI](https://pokeapi.co/) - すべての世代のポケモンデータ。
- [Riot Games](https://developer.riotgames.com/) - 現在進行中のゲーム、マッチ履歴、順位統計。
- [smm-course-search](https://github.com/leomaurodesenv/smm-course-search) - Super Mario Makerゲームからコースを検索。
- [smm-course-viewer](https://github.com/leomaurodesenv/smm-course-viewer) - Super Mario Makerのセーブデータからコースを読み取る。
- [smm-maker-profile](https://github.com/leomaurodesenv/smm-maker-profile) - Super Mario Makerゲームからユーザープロフィールを取得。
- [Steam Database](https://github.com/SteamDatabase) - Steamデータを提供するツールのシリーズ。 [Website](https://steamdb.info/)。
- [Steam Spy](https://github.com/topics/steamspy) - Steamユーザーのプロフィールから得られるゲーム統計。
- [Steam Web API](https://developer.valvesoftware.com/wiki/Steam_Web_API) - Steamから提供されるクエリツール。
- [TGDB](https://github.com/TheGamesDB/TheGamesDB/) - どのプラットフォームのゲームについても一般的な情報が得られる。 [Website](https://thegamesdb.net/)。
- [vgchartzScrape](https://github.com/GregorUT/vgchartzScrape) - [VGChartz](http://www.vgchartz.com)からのクロールツール。
- [WhatoPlay](https://whatoplay.com) - ゲームレビューと評価を集計し、ゲームの発見を支援する推薦システム。
- [Xbox LIVE API](https://github.com/xboxapi) - ゲーム、アプリ、ユーザーの統計情報およびメッセージ。 [paper](https://doi.org/10.1145/1943552.1943569)。
