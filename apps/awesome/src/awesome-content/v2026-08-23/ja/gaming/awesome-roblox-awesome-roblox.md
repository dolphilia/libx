## ソフトウェア

- [Bloxstrap](https://github.com/bloxstraplabs/bloxstrap) - 多数の追加機能を備える Roblox 向け代替ブートストラッパー。
- [BTRoblox](https://github.com/AntiBoomz/BTRoblox) - Roblox Web サイトの見た目と機能を強化するブラウザー拡張。
- [Roblox Studio Mod Manager](https://github.com/MaximumADHD/Roblox-Studio-Mod-Manager) - Roblox Studio ディレクトリ内のファイルを上書きし、Roblox の開発ブランチを選択し、Fast Flags を試せる、オープンソースのカスタムブートストラッパー。
- [Vinegar](https://github.com/vinegarhq/vinegar) - Linux で Roblox Studio を実行するための、オープンソース、設定可能、高速なブートストラッパー。

## 体験

- [Price Point](https://github.com/Fizzyhex/price-point) - マーケットプレイスの価格を推測するゲーム。
- [Slither](https://github.com/littensy/slither) - 心安らぐ Catppuccin カラーパレットを用いたカジュアルゲーム。

## プラグイン

- [flipbook](https://github.com/flipbook-labs/flipbook) - UI コンポーネントをプレビューするための Storybook プラグイン。
- [Roblox-Plugins](https://github.com/MaximumADHD/Roblox-Plugins) - [MaximumADHD](https://github.com/MaximumADHD) が開発したプラグインの一覧。
- [UI Labs](https://github.com/PepeElToro41/ui-labs) - Roblox 向け Storybook プラグイン。

## モジュール

### 管理

- [Adonis](https://github.com/Epix-Incorporated/Adonis) - サーバーのモデレーション・管理システム。
- [Centurion](https://github.com/paradoxuum/centurion) - roblox-ts 向けの柔軟で拡張可能なコマンドフレームワーク。
- [Cmdr](https://github.com/evaera/Cmdr) - 開発者向け拡張可能コマンドコンソール。
- [Conch](https://github.com/alicesaidhi/conch) - シェル風のチューリング完全スクリプト言語を備える、モダンでスケーラブルな開発者コンソール。
- [Kohl's Admin](https://github.com/kohls-admin/kohls-admin) - 体験管理のオールインワンソリューション。
- [Nexus-Admin](https://github.com/TheNexusAvenger/Nexus-Admin) - 一般プレイヤー向けに作られた Roblox 管理システム。

### バックパック

- [Neobar](https://github.com/ImAvafe/NeoHotbar) - Roblox 向けモダンでカスタマイズ可能なホットバー。
- [Purse](https://github.com/ryanlua/purse) - Roblox のデフォルトバックパックを CoreGui から分離した版。
- [Satchel](https://github.com/ryanlua/satchel) - Roblox のデフォルトバックパックに代わるモダンな選択肢。

### トップバー

- [TopbarPlus](https://github.com/1ForeverHD/TopbarPlus) - 動的で直感的なトップバーアイコンを構築する。

### UI コンポーネント

- [Lydie](https://github.com/7kayoh/Lydie) - Fusion 向けの美しい UI コンポーネント。
- [OnyxUI](https://github.com/loneka/onyx-ui) - Fusion 向けの高速でカスタマイズ可能なコンポーネント。

## ライブラリ

### API ラッパー

- [noblox.js](https://github.com/noblox/noblox.js) - Roblox 向け Node.js API ラッパー。
- [Openblox](https://github.com/cameronpcampbell/openblox) - TypeScript で書かれた Roblox 向け API ラッパー。完全な型安全性、任意のキャッシュ、任意の HTTP クライアントに対応。
- [ro.py](https://github.com/ro-py/ro.py) - Roblox API 向けのモダンで非同期な Python 3 ラッパー。

### DataStore

- [DataKeep](https://github.com/noahrepublic/DataKeep) - Promise ベースの自動保存 DataStore ライブラリ。
- [DocumentService](https://github.com/anthony0br/DocumentService) - 強力でスキーマ化された Roblox データストアライブラリ。
- [Lapis](https://github.com/nezuo/lapis) - Roblox 向け DataStore 抽象化ライブラリ。
- [Lyra](https://github.com/paradoxum-games/lyra) - シンプルな API による高度なプレイヤーデータ管理。
- [ProfileStore](https://github.com/MadStudioRoblox/ProfileStore) - セッションロックを備える定期的な DataStore 保存ソリューション。

### Entity Component System

- [ECR](https://github.com/centau/ecr) - Luau 向け sparse-set ベース ECS ライブラリ。
- [Jecs](https://github.com/Ukendio/jecs) - Luau 向けの高速・移植可能な Entity Component System。
- [Matter](https://github.com/matter-ecs/matter) - Roblox 向けモダン ECS ライブラリ。
- [Planck](https://github.com/YetAnotherClown/planck) - ECS 向けの非依存スケジューラー。
- [Replecs](https://github.com/PepeElToro41/replecs) - 高速で細かく制御できる JECS レプリケーションライブラリ。

### フレームワーク

- [Flamework](https://github.com/rbxts-flamework/core) - roblox-ts 向けの拡張可能なゲームフレームワーク。
- [Prvd 'M Wrong](https://github.com/prvdmwrong/prvdmwrong) - 型安全 API、依存関係解決、優れた DX を提供するモダンな標準で構築された Roblox ゲームフレームワーク。

### ネットワーク

- [Blink](https://github.com/1Axen/blink) - ROBLOX バッファネットワーキング用の Luau 製 IDL コンパイラー。
- [ByteNet](https://github.com/ffrostfall/ByteNet) - 高度でモダンなネットワーキングライブラリ。
- [RbxNet](https://github.com/roblox-aurora/rbx-net) - 高度な多言語ネットワーキングフレームワーク。
- [Red](https://github.com/red-blox/red) - シンプル、高速、強力なネットワーキングライブラリ。
- [Zap](https://github.com/red-blox/zap) - 非常に高速なネットワーキングソリューション。

### Open Cloud

- [rbxcloud](https://github.com/Sleitnick/rbxcloud) - Roblox Open Cloud API 向け CLI・ライブラリ。

### レイキャスト

- [ZonePlus](https://github.com/1ForeverHD/ZonePlus) - 境界内のプレイヤー・パーツを効果的に判定する動的ゾーンを構築する。

### UI

- [fluid](https://github.com/ffrostfall/fluid) - Roblox 向け宣言的 UI フレームワーク。
- [Fusion](https://github.com/dphfox/Fusion) - Roblox・Luau 専用に構築されたモダンなリアクティブ UI ライブラリ。
- [Iris](https://github.com/Michael-48/Iris) - [Dear ImGui](https://github.com/ocornut/imgui) に基づく Roblox 向けイミディエイトモード GUI ライブラリ。
- [React Lua](https://github.com/jsdotlua/react-lua) - 上流 ReactJS 17.x を Lua へ包括的ながら完全ではなく翻訳したもの。
- [Vide](https://github.com/centau/vide) - UI 作成用のリアクティブ Luau ライブラリ。

### ユーティリティ

- [Janitor](https://github.com/howmanysmall/Janitor) - 接続、インスタンスなどをクリーンアップする軽量で柔軟なオブジェクト。
- [Nevermore](https://github.com/Quenty/NevermoreEngine) - Roblox での高速なゲーム開発に向けた、再利用可能で簡単に統一されたサーバー・クライアントモジュールを持つ ModuleScript ローダー。
- [RbxUtil](https://github.com/Sleitnick/RbxUtil) - Roblox 向けユーティリティモジュールのコレクション。
- [t](https://github.com/osyrisrblx/t) - Roblox 向けランタイム型チェッカー。

## ツール群

### コンパイラー

- [darklua](https://github.com/seaofvoices/darklua) - ルールを使用して Lua 5.1・Roblox Lua スクリプトを変換する。
- [Lune](https://github.com/lune-org/lune) - スタンドアロン Luau ランタイム。
- [roblox-ts](https://github.com/roblox-ts/roblox-ts) - Roblox 向け TypeScript から Luau へのコンパイラー。

### ドキュメント生成器

- [Moonwave](https://github.com/evaera/moonwave) - Lua ソースコード内のコメントからドキュメントを生成するツール。

### 言語サーバー

- [Luau Language Server](https://github.com/JohnnyMorganz/luau-lsp) - Luau 向け言語サーバー実装。
- [Roblox Luau Language Server](https://github.com/NightrainsRbx/RobloxLsp) - sumneko の Lua に基づく Roblox 向け言語サーバー。

### リンター・フォーマッター

- [selene](https://github.com/Kampfkarren/selene) - Rust で書かれた非常に高速でモダンな Lua リンター。
- [StyLua](https://github.com/JohnnyMorganz/StyLua) - 意見を持った Lua コードフォーマッター。

### Open Cloud

- [Mantle](https://github.com/blake-mealey/mantle) - Roblox 向け IaC・デプロイツール。

### パッケージマネージャー

- [pesde](https://github.com/pesde-pkg/pesde) - Luau プログラミング言語向けパッケージマネージャー。
- [Wally](https://github.com/UpliftGames/wally) - Cargo から着想を得た Roblox プロジェクト向けモダンなパッケージマネージャー。

### 同期ツール

- [Argon](https://github.com/argon-rbx/argon) - Roblox 開発向けのフル機能ツール。
- [Lync](https://github.com/Iron-Stag-Games/Lync) - ファイル同期ツール。
- [Rojo](https://github.com/rojo-rbx/rojo) - Roblox 開発者がプロフェッショナル級のソフトウェアエンジニアリングツールを使えるようにする。

### ツールチェーン管理ツール

- [Foreman](https://github.com/Roblox/foreman) - Roblox プロジェクト向けツールチェーンマネージャー。
- [Rokit](https://github.com/rojo-rbx/rokit) - 次世代の Roblox プロジェクト向けツールチェーンマネージャー。
