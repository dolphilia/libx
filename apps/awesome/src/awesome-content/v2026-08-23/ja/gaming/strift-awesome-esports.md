## ライブラリー

> ユースケース別に整理したプログラミングライブラリー。

### API とウェブサービス

- [Blizzard.js](https://github.com/benweier/blizzard.js) - Blizzard Community Platform API とやり取りするための Node.js ライブラリー。
- [Discord.js](https://github.com/discordjs/discord.js) - Discord API とやり取りするための Node.js ライブラリー。
- [HLTV](https://github.com/gigobyte/HLTV) - HLTV API とやり取りするための Node.js ライブラリー。
- [liquipediapy](https://github.com/c00kie17/liquipediapy) - Liquipedia API とやり取りするための Python ライブラリー。
- [steam](https://github.com/ValvePython/steam/) - Steam のさまざまな部分とやり取りするための Python ライブラリー。
- [Steam Community](https://github.com/DoctorMcKay/node-steamcommunity) - Steam Community ウェブサイトとやり取りするための Node.js ライブラリー。
- SteamID - Steam ID を操作するためのライブラリー。
  - [Node.js](https://github.com/DoctorMcKay/node-steamid)
  - [PHP](https://github.com/DoctorMcKay/php-steamid)
- [SteamUser](https://github.com/DoctorMcKay/node-steam-user) - Steam クライアントプロトコル経由で Steam ネットワークとやり取りするための Node.js ライブラリー。
- [Steam TOTP](https://github.com/DoctorMcKay/node-steam-totp) - Steam 形式の 2FA コードを生成するための Node.js ライブラリー。
- [valorant.js](https://github.com/liamcottle/valorant.js) - ゲームで使われる VALORANT API とやり取りするための Node.js ライブラリー。

### 認証

- [Passport-Steam](https://github.com/liamcurry/passport-steam) - Steam 向けの Node.js passport 認証戦略。

### データ解析と分析

- [awpy](https://github.com/pnxenopoulos/awpy) - CS:GO データを解析、分析、可視化するための Python ライブラリー。
- [Boxcars](https://github.com/nickbabcock/boxcars) - Rocket League リプレイを解析するための Rust ライブラリー。
- [Cassiopeia](https://github.com/meraki-analytics/cassiopeia) - Riot Games League of Legends API のデータとやり取りし、分析するための Python フレームワーク。
- [Clarity](https://github.com/skadistats/clarity) - CS:GO と Dota 2 のリプレイを解析するための Java ライブラリー。
- [demoinfocs-golang](https://github.com/markus-wa/demoinfocs-golang) - CS:GO のデモ（すなわちリプレイ）を解析・分析するための Go ライブラリー。
- [Rattletrap](https://github.com/tfausak/rattletrap) - Rocket League リプレイを解析・生成するための Haskell ライブラリー。

### チーム管理

- [LoL in-house bot](https://github.com/mrtolkien/inhouse_bot) - League of Legends のインハウスゲームにおけるロールキュー、マッチメイキング、ランキングを扱う Discord ボット。

### トーナメント管理

- [brackets-manager.js](https://github.com/Drarig29/brackets-manager.js) - トーナメントブラケットを管理するための JavaScript ライブラリー。
- [brackets-viewer.js](https://github.com/Drarig29/brackets-viewer.js) - トーナメントブラケットを表示するための JavaScript ライブラリー。

## 非公式ドキュメント

> コミュニティが保守するエディター API のドキュメント。

- [BNETDocs](https://github.com/BNETDocs/bnetdocs-web) - Blizzard と Battle.net プロトコルのためのドキュメント・ディスカッションウェブサイト。
- [Rift Explorer](https://github.com/Pupix/rift-explorer) - Riot Games LCU API の自動生成ドキュメント。
- [valorant-api-docs](https://github.com/techchrism/valorant-api-docs) - Valorant 内部 API の自動生成ドキュメント。

## アプリケーションとツール

> アプリケーションと汎用ツール群。

- [Esport Team Logos](https://github.com/lootmarket/esport-team-logos) - Esports チームロゴのデータベース。

**Counter-Strike: Global Offensive**

- [Boltobserv](https://github.com/boltgolt/boltobserv) - 観戦者向けの外部 Counter-Strike: Global Offensive レーダー。

**Dota 2**

- [Open Dota](https://github.com/odota/core) - Dota 2 eスポーツ統計のためのウェブサイト。

**League of Legends**

- [Foldy Sheet](https://github.com/chhopsky/foldysheet) - チームがプレーオフに進出できるかを判定する Python スクリプト。
- [LeagueDirector](https://github.com/RiotGames/leaguedirector) - League of Legends リプレイから動画を演出・録画するデスクトップアプリケーション。
- [LeagueStats](https://github.com/vkaelin/LeagueStats) - League of Legends サモナーの統計情報のためのウェブサイト。

## 教育
