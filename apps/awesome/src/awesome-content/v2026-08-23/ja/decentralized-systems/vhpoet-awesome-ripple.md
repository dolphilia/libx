###### ライブラリ - Ripple API と通信するライブラリ
- [ripple-libpp](https://github.com/ripple/ripple-libpp)：独立した C++ 製 RCL 互換トランザクション署名・シリアライズライブラリ
- [ripple-rest](https://github.com/ripple/ripple-rest)：Ripple Network で支払いを送信し、アカウントを監視する RESTful API
- [ripple-lib](https://github.com/ripple/ripple-lib/)：JavaScript
- [xrpl-client](https://www.npmjs.com/package/xrpl-client)：健全性検出と自動再接続を備えた JavaScript/TypeScript Node.js WebSocket クライアント
- [xrpl-accountlib](https://www.npmjs.com/package/xrpl-accountlib)：Family Seed、Mnemonic、Secret Number から署名・導出する JavaScript/TypeScript Node.js ライブラリ
- [ripple-lib-java](https://github.com/ripple/ripple-lib-java/)：Java
- [ripple-lib-ruby](https://github.com/kevinejohn/ripple-lib-rpc-ruby/)：Ruby
- [ripple-python](https://github.com/miracle2k/ripple-python/)：Python ライブラリ
- [ripple-python-lib](https://github.com/arsenlosenko/python-ripple-lib)：JSON-RPC と Data API 呼び出しの Python 実装
- [ripple-haskell](https://github.com/singpolyma/ripple-haskell/)：Haskell
- [rubblelabs/ripple](https://github.com/rubblelabs/ripple)：Ripple プロトコルと対話する Go パッケージ
- [RippleKit](https://github.com/xasos/RippleKit)：Swift
