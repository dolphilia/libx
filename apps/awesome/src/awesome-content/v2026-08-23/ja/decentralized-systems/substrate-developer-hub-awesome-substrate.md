# Awesome Substrate [![Awesome](https://awesome.re/badge-flat.svg)](https://awesome.re)

> SubstrateだけでなくPolkadotエコシステム全体を対象とする同種のリストについては、[`awesome-dot`](https://github.com/haquefardeen/awesome-dot) を参照してください。

---

> Awesomeリストとは、Substrateコミュニティが選定した優れた情報をまとめたリストです。

Substrateは、アップグレード可能でモジュール式かつ効率的なブロックチェーンを構築するためのフレームワークです。Substrateは [Rust](https://www.rust-lang.org/) で書かれたオープンソースライブラリで、[Parity Technologies](https://www.parity.io/) が保守しています。ソースコードは [GitHub](https://github.com/paritytech/substrate) で公開されています。

## テンプレート

- [Base](https://github.com/substrate-developer-hub/substrate-node-template) - 最小構成のFRAMEベースのノード。
  [upstream](https://github.com/paritytech/substrate/tree/master/bin/node-template)から派生しています。
- [Frontier](https://github.com/paritytech/frontier/tree/master/template) - EVMおよびEthereum RPCに対応したフロントエンドを有する、サブストレートノード、ハッキング用に準備済み
- [Front-End](https://github.com/substrate-developer-hub/substrate-front-end-template) - ポルカドットJS APIおよび[React](https://reactjs.org/)アプリで、サブストレートベースのチェーン向けのフロントエンドを構築
- [Parachain](https://github.com/substrate-developer-hub/substrate-parachain-template) - キュムラス対応サブストレートノード、[upstream](https://github.com/paritytech/cumulus/tree/master/parachain-template)から派生
- [`substrate-stencil`](https://github.com/kaichaosun/substrate-stencil) - ステーキングおよびガバナンス機能を備えたサブストレートノードのテンプレート
- [polkadot-js-api-ts-template](https://github.com/kianenigma/polkadot-js-api-ts-template) - `@polkadot/api`上にハッキングを開始するためのテンプレートプロジェクト
- [INK!athon](https://inkathon.xyz/) - ink!スマートコントラクトとReactフロントエンドを使用した、フルスタックdAppのボイラープレート、`useInkathon`（以下にリストされている）のhooksライブラリを[Scio Labs](https://scio.xyz)が維持
- [Subsocial Starter Kit](https://docs.subsocial.network/docs/develop/developer-quickstart) - ポルカドットエコシステム向けのWeb3ソーシャルアプリの開発用スタートキット、[Subsocial blockchain](https://subsocial.network)によって駆動

<a id="tools"></a>
## ツール

- [`offline-election`](https://github.com/paritytech/substrate-debug-kit/tree/master/offline-election) - ノミネート プローブ・オブ・ステーク 選挙を予測するツール。
- [`offchain::ipfs`](https://rs-ipfs.github.io/offchain-ipfs-manual/) - Substrate に [IPFS](https://ipfs.io/) を統合したもの。
- [`polkadot-js-bundle`](https://github.com/shawntabrizi/polkadot-js-bundle) - Polkadot{JS} ライブラリを含むスタンドアローン JS バンドル。
- [`polkadot-launch`](https://github.com/shawntabrizi/polkadot-launch) - ローカルの Polkadot テストネットを起動するためのシンプルな CLI ツール。
- [`polkadot-runtime-prom-exporter`](https://github.com/paritytech/polkadot-runtime-prom-exporter/) - Polkadot ランタイムメトリクスを出力する [Prometheus](https://prometheus.io/) エクスポートツール（Substrate 用途に調整可能）。
- [`polkadot-scripts`](https://github.com/paritytech/polkadot-scripts) - Parity が使用する Polkadot/Kusama の診断に用いるスクリプトのコレクション。
- [`polkadot-starship`](https://github.com/koute/polkadot-starship) - ローカルの Polkadot テストネットを起動する別のツールで、大きなテストネットを実行できる能力に重点を置いている。
- [`srtool-actions`](https://github.com/chevdor/srtool-actions) - GitHub Actions を使って、自らのランタイムを構築する際に `srtool` Docker イメージを簡単に使用できるようにするもの。
- [`srtool-cli`](https://github.com/chevdor/srtool-cli) - `srtool` Docker イメージの CLI フロントエンド。
- [`srtool`](https://github.com/paritytech/srtool) - ランタイムを決定的に構築するための Docker イメージ。
- [`subsee`](https://github.com/ascjones/subsee) - Substrate ノードのメタデータを JSON で確認する CLI ツール。
- [`subalfred`](https://github.com/hack-ink/subalfred) - すべての機能を内包したSubstrate開発ツールボックス。
- [`substrate-balance-calculator`](https://github.com/shawntabrizi/substrate-balance-calculator) - Substrateアカウントのバランスを分解する。
- [`substrate-balance-graph`](https://github.com/shawntabrizi/substrate-balance-graph) - Substrateアドレスのトークンバランスの時間軸グラフを作成する。
- [`substrate-graph-benchmarks`](https://github.com/shawntabrizi/substrate-graph-benchmarks) - FRAMEパレットのベンチマーク出力のグラフ化。
- [`substrate-js-utils`](https://github.com/shawntabrizi/substrate-js-utilities) - Substrate用の便利なJavaScriptユーティリティセット。Polkadot{JS} APIを使用；また [deployed as a website](https://www.shawntabrizi.com/substrate-js-utilities/)。
- [`substrate-society`](https://github.com/shawntabrizi/substrate-society) - FRAMEソサイエティパレットの基本的なフロントエンド。
- [`substrate-toml-lint`](https://github.com/shawntabrizi/substrate-toml-lint) - Substrateプロジェクトでよく見られるエラーを回避するtomlパーサーとチェックツール。
- [`subwasm`](https://github.com/chevdor/subwasm) - オフラインでランタイムWASMブロブを検証するCLIツール。情報やメタデータを表示し、ランタイムを比較できる。また、ノードからランタイムを直接取得する手助けになる。
- [`sup`](https://github.com/clearloop/sup) - Substrateノードの生成またはアップグレードに使うコマンドラインツール。
- [`scale-value`](https://github.com/paritytech/scale-value) - `serde_json`に類似したが、SCALE用のもの。SCALEエンコードされたバイトを動的に `Value`型にデコードするためのライブラリ。 `scale-info`から型情報を取得する。
- [`scale-decode`](https://github.com/paritytech/scale-decode) - visitor traitを実装することで、SCALEバイトを任意のカスタム型にデコードする。
- [Aleph.im](https://aleph.im) - Substrateチェーン向けにスケーラブルで分散型のデータベース、ファイルストレージ、計算サービス。
- [Archive](https://github.com/paritytech/substrate-archive) - Substrateチェーン向けのインデックスエンジン。
- [Dev Hub Utils](https://github.com/danforbes/substrate-devhub-utils) - _Unofficial_ Substrate開発者ハブリソースとの作業に使うユーティリティ。
- [Europa](https://github.com/patractlabs/europa) - Substrateランタイム実行環境のサンドボックス。
- [Fork Off Substrate](https://github.com/maxsam4/fork-off-substrate) - 新しいチェーンを立ち上げる際に、実行中のチェーンの状態を活用するスクリプト。
- [fudge](https://github.com/centrifuge/fudge) - Substrateデータベースへのアクセスおよび（任意の）操作を行うためのコアライブラリ。ローカルブロックの構築とインポートも含む。
- [Gantree Library](https://github.com/gantree-io/gantree-lib-nodejs) - Substrateを用いたパラチェーンネットワークを迅速に立ち上げ・停止して管理するための技術セット。
- [Halva](https://github.com/halva-suite/halva) - Substrate開発体験を向上させるためのツールチェーン。
- [Hydra](https://github.com/Joystream/hydra) - Substrateノード向けのGraphQLフレームワーク。
- [Jupiter](https://github.com/patractlabs/jupiter) - FRAME Contracts pallet および ink! 用のスマートコントラクト向けのテストネット
- [Megaclite](https://github.com/patractlabs/megaclite) - ポラドットエコシステム向けのゼロ知識ツール
- [Metadata Portal](https://nova-wallet.github.io/metadata-portal/) - 任意のネットワークの最新メタデータおよびチェーン仕様を表示するセルフホスト型ウェブページ
- [Minimark](https://github.com/kodadot/packages) - KodaDotが維持するRMRK NFT v1/v2プロトコルの実装
- [Nova Polkadot Utils](https://github.com/nova-wallet/nova-utils) - ポラドットエコシステムのクライアントアプリが複数のネットワークにマッピングするために必要な静的情報およびメタデータ
- [Polkadot Vault](https://signer.parity.io/) (以前はParity Signer) - 利用していないモバイル端末を、空気隔離型ハードウェアウォレットにリユース
- [Polkadot PANIC](https://github.com/SimplyVC/panic_polkadot) - Simply VCが開発したポラドットノード向けのモニタリングおよびアラートソリューション（多数のSubstrateチェーンに対応）
- [Polkadot Tool Index](https://wiki.polkadot.network/docs/build-tools-index) - ポラドトおよび任意のSubstrateチェーン向けの開発に利用可能なツール一覧（ブロッキングエクスプローラー、ウォレット、ネットワークモニタリングおよびレポート、クライアント、ベンチマーク、フュージング、フォーキング、SCALEコード、CLIツールなど）
- [Polkadot-JS Apps UI](https://polkadot.js.org/apps/) - Substrateベースのチェーン向けの半公式ブロックエクスプローラーおよびフロントエンド
