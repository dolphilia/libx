## パッケージ <a id="packages"></a>

### フレームワーク <a id="frameworks"></a>

- [Tone.js](https://github.com/Tonejs/Tone.js) - ブラウザ上でインタラクティブな音楽を作成するためのフレームワーク
- [Bap](https://github.com/adamrenklint/bap) - MPC60/2000をインスピレーションとして作られた、ビートを作成し、シーケンスを組み立てるためのツールキット
- [Omnitone](https://github.com/GoogleChrome/omnitone) - ウェブ向けのアンビソニックス空間音響
- [Mach1Spatial](https://github.com/Mach1Studios/m1-sdk) - ウェブ向けのベクトルベース・パンニング空間音響
- [Elementary](https://www.elementary.audio/) – ウェブ上またはネイティブアプリ向けの音声ソフトウェアを宣言的に、関数的に書くためのフレームワーク
- [React Native Audio API](https://github.com/software-mansion-labs/react-native-audio-api) - react-nativeベースのネイティブアプリ向けのWeb Audio API実装

### ライブラリ <a id="libraries"></a>

- [smoothfade](https://github.com/notthetup/smoothfade) - 2つのAudioNodeの間をスムーズにフェードさせるためのライブラリ
- [virtual-audio-graph](https://github.com/benji6/virtual-audio-graph) - Web Audio APIを宣言的に操作するためのライブラリ
- [XSound.js](https://xsound.app/) - 多機能な音声ライブラリ
- [Sound.js](https://github.com/kittykatattack/sound.js) - ゲームやインタラクティブアプリケーション向けに音響効果や音楽をロード・再生・生成するためのマイクロライブラリ
- [Meyda](https://github.com/meyda/meyda) - 多くのよく使われる音声特徴を含む音声特徴抽出ライブラリ
- [Wavesurfer.js](https://github.com/katspaugh/wavesurfer.js) - Web AudioとCanvasを用いたインタラクティブでナビゲーション可能な音声可視化
- [Audiojs](https://github.com/audiojs/audio) - PCM音声データをより簡単に保存・読み出し・書き出しできるオブジェクト
- [Tuna](https://github.com/Theodeus/tuna) - 音声効果ライブラリ
- [Rythm.js](https://okazari.github.io/Rythm.js/) - ページをダンスさせるJavaScriptライブラリ
- [Howler.js](https://github.com/goldfire/howler.js) - HTML5 Audio に備えられた包括的なライブラリ
- [Circular Audio Wave](https://github.com/kelvinau/circular-audio-wave) - Web Audio API と ECharts を使って円波形を用いた音声可視化を行う JavaScript ライブラリ
- [Wad](https://github.com/rserota/wad) - Web Audio DAW。動的な音合成に Web Audio API を使う。あなたの耳のための jQuery みたいなもの
- [p5.sound](https://p5js.org/reference/#/libraries/p5.sound) - 創造的コードライブラリ [p5.js](https://p5js.org/) に Web Audio機能を追加する拡張
- [@magenta/music](https://github.com/magenta/magenta-js/tree/master/music) - Web Audio API をいくつかの洗練された抽象化で包み、ブラウザ上で機械学習モデルを用いて音楽を生成する JavaScript ライブラリ
- [soundfont-player](https://www.npmjs.com/package/soundfont-player) - Web Audio API を使って MIDI 音を再生するサウンドフォントローダー／プレイヤー
- [html-midi-player](https://github.com/cifkao/html-midi-player) - カスタム JS コードを書かずに、MIDI の再生と可視化を簡単に行える HTML 要素。必要に応じてスクリプトやスタイルを適用可能
- [MusicXML Player](https://github.com/infojunkie/musicxml-player) - Web Audio と Web MIDI を使ってブラウザ内で MusicXML ファイルを読み込み、再生する TypeScript コンポーネント
- [waveform-path](https://github.com/jerosoler/waveform-path) - SVG に波形パスを生成するライブラリ
- [wave-audio-path-player](https://github.com/jerosoler/wave-audio-path-player) - シンプルなオーディオプレイヤー Web コンポーネントで波形をカスタマイズ可能
- [dsssp](https://github.com/NumberOneBot/dsssp) - ドラッグ＆ドロップとトランジションをサポートした、オーディオフィルタの可視化と管理を行う React コンポーネントライブラリ
- [tuning-fork](https://github.com/v-rusu/tuning-fork) - リアルタイムピッチ検出を用いた、設定可能なクライアントサイド JavaScript ライブラリ（ギターのチューニング用）

### ユーティリティ <a id="utilities"></a>

- [Audion](https://github.com/google/audion) - Chrome エクステンションで開発ツールに Web Audio パネルを追加
- [web-audio-generator](https://github.com/ISNIT0/webaudio-generator) - Web Audio コードを生成するための UI
- [Web Audio Studio](https://app.webaudio.studio) - Web Audio API からコードで生成されたグラフをリアルタイムで可視化する

### MIDI

- [midimessage](https://github.com/notthetup/midimessage) - シンプルなMIDIメッセージパーサー
- [JZZ](https://github.com/jazz-soft/JZZ) - Node.jsおよび主要なブラウザ向けのMIDIライブラリ
- [JZZ-midi-Gear](https://github.com/jazz-soft/JZZ-midi-Gear) - MIDIデバイスのモデルとメーカー情報を取得
- [WEBMIDI.js](https://webmidijs.org/) - Web MIDI APIを扱いやすくする

### アプリ <a id="apps"></a>

- [BassoonTracker](https://github.com/steffest/BassoonTracker) - JavaScriptによるMOD/XMトラッカー
- [LoopDrop App](https://github.com/mmckegg/loop-drop-app) - Web AudioおよびWeb MIDI APIを用いたMIDIループ、モジュラーシンセ、サンプラーアプリ
- [X Sound](https://xsound.app/) - XSound.jsを用いたマルチサウンドアプリケーション
- [Molgav](https://github.com/surikov/molgav) - メロディを交換するための音楽ステップシーケンサ
- [mod-synth.io](https://github.com/andrevenancio/mod-synth.io) - 自作モジュラーシンセを構築する、または異なるシンセをエミュレートする
- [GridSound](https://gridsound.github.io) - 進行中のDAW（デジタルオーディオワークステーション）
- [Learning Music](https://learningmusic.ableton.com/) - 音楽制作の基本を学ぶ
- [Super Oscillator](https://github.com/lukehorvat/super-oscillator) - ウェブ向けインタラクティブな3D音楽シンセサイザー
- [AudioNodes](https://audionodes.com) - マルチトラックミキシング、音響効果、パラメーター自動化、MIDI編集、シンセシス、クラウド制作などを備えたモジュラー音楽制作ツールセット
- [waveform-playlist](https://github.com/naomiaro/waveform-playlist) - マルチトラックWeb Audioエディタとプレイヤー。キャンバス波形プレビューを提供。カウント、フェード、複数トラックのタイムシフトを設定。オーディオトラックを録音するか、オーディオ注釈を提供。ミックスをAudioBufferまたはWAVにエクスポート！Audacityをインスピレーションにしたプロジェクト
- [SoundCycle](https://github.com/scriptify/soundcycle) - ミュージシャン向けのWeb Audioベースのループステーション。エフェクトとさまざまなループモードを備えている
- [DSP.audio Worklet Editor](https://dsp.audio/editor/) - オンラインのオーディオ・ワークレット・エディタ。スケッチや協働に使用可能。サンプラー、MIDI、アナライザを備えている。JSFiddleに似たものだが、DSP用。
- [AudioMass](https://audiomass.co/) - 無料、オープンソース、ウェブベースのオーディオと波形エディタ。
- [Csound IDE](https://ide.csound.com/) - [CSound programming language](https://en.wikipedia.org/wiki/Csound)用のウェブIDE。
- [jamhub](https://github.com/fletcherist/jamhub) - 低遅延のリモート音楽協働とジャム。
- [Web Audio Metronome](https://github.com/cwilso/metronome) - ウェブオーディオスケジューラとsetTimeoutスケジューラを使用したメトロノームアプリ。
- [EarSketch](https://earsketch.gatech.edu/landing/#/) - PythonおよびJavaScriptを音楽作成とリミックスを通じて教えるための無料教育用プログラミング環境。
- [webaudio-tinysynth](https://github.com/g200kg/webaudio-tinysynth) - JavaScript製の小型シンセサイザー。GM風の音色マップを備える。
- [web-audio-beat-detector](https://github.com/meerasndr/sample-golang-app) - ウェブオーディオAPIを使用したビート検出ツール。
- [web-audio-mixer](https://github.com/jamesfiltness/web-audio-mixer) - ウェブオーディオを用いて構築されたオーディオミキサー。
- [Audio-motion interface](https://github.com/MaxAlyokhin/audio-motion-interface) - スマートフォンの空間におけるジェスチャーを用いて音を生成するウェブシンセサイザー。
- [Topos](https://topos.raphaelforment.fr) - Monome Teletypeにインスパイアされたウェブベースのライブコーディング環境。ウェブオーディオとMIDIを使用。
- [Online Sequencer](https://onlinesequencer.net) - シンプルで使いやすいシーケンサ。機能が豊富で、ウェブオーディオAPIに基づいている。
- [Binary Synth](https://github.com/MaxAlyokhin/binary-synth) - 任意のファイルのバイナリコードから音を生成するウェブシンセサイザー。
- [dsssp-demo](https://github.com/NumberOneBot/dsssp-demo) - 7バンドEQとフィルタプリセットを備えたウェブオーディオ音楽プレイヤー。
- [SingMeter](https://www.singmeter.com/) – ブラウザベースの歌唱ツールのコレクション。ピッチ検出器と声域テストを含む。
- [Drumhaus](https://drumha.us/) – ブラウザ上で動作するドラムマシン。ステップシーケンス、パターン変化、グルーブ編集に対応。
- [All-in-One Advanced BPM Tool](https://tapbpmhub.com/) – スペースバーを押すかタップで瞬時に楽曲の速度を測定。MIDI入力、オプションのサウンドクリック、リアルタイムBPM表示機能付き。プロデューサーやDJ、リズムゲーマーにとって必須のツール。
- [synflow](https://synflow.org) - ブラウザベースのモジュラーシンセ・フローエンジン。すべてのWeb Audio APIノードと、ボコーダーやリバーブなどのWorkletをサポートし、高度なフロー自動化機能を備える。 [Github](https://github.com/k1ln/synflow)
- [Tonalux](https://tonalux.org) - Web Audio APIおよびWebAssemblyで構築された、無料のブラウザベースの音声解析ツール。リアルタイムスペクトル分析、LUFS音量計測（EBU R128）、A/B比較、ステレオ相関を提供。完全にクライアントサイドで動作。
- [mdrone](https://mdrone.org) - ブラウザ上で動作するマイクロトーンドローン楽器。

## 資料 <a id="resources"></a>

### チュートリアル <a id="tutorials"></a>

- [WebAudio School](https://github.com/mmckegg/web-audio-school) - WebAudioを学ぶためのセルフガイドワークショップシリーズ。
- [Web Audio API Understandable Reference](https://web-audio-api.firebaseapp.com/) - JavaScriptや基本的な音声原理を理解している人向けに、わかりやすく作られたリファレンス。
- [The Web Audio API: What Is It?](https://code.tutsplus.com/tutorials/the-web-audio-api-what-is-it--cms-23735) - WebAudioの基礎を学ぶ。
- [Web Audio Basics](https://github.com/kylestetz/Web-Audio-Basics) - CodePenへのリンク付きの、軽量なコードサンプルの集合。
- [Web Audio Perf](https://padenot.github.io/web-audio-perf/) - さまざまなAudioNodeのパフォーマンスと、効率的なリソース使用のための戦略（WAC2016から）。
- [Percussion Synthesis Using Web Audio](https://github.com/irritant/WAC-2016-Tutorial) - このチュートリアルでは、シンプルなパーカッション音を合成するコードを書くことで、ウェブ音声プログラミングの基礎を紹介する（WAC2016から）。
- [Browser Noise: Web Audio Tutorials](https://www.youtube.com/playlist?list=PLLgJJsrdwhPywJe2TmMzYNKHdIZ3PASbr) - Audio Programmer YouTubeチャンネルにアップロードされた、ダン・トラメートによるビデオチュートリアルのプレイリスト。
- [audio-katas](https://github.com/survivejs/audio-katas) - 自らDAWを構築しながら、重要なWeb Audio APIに触れられるセルフガイドのカタスの集合。

### 書籍 <a id="books"></a>

- [JavaScript for Sound Artists](https://www.routledge.com/JavaScript-for-Sound-Artists-Learn-to-Code-with-the-Web-Audio-API/Turner-Leonard/p/book/9781138961531) - すべての例にWeb Audioを使用した、下から上へのJavaScript／DOMコース。
- [Web Audio API](https://webaudioapi.com/book/) - デジタル音声の知識がほとんどないWeb開発者向けに設計された、ゲーム音声やインタラクティブアプリに特化したスタートアップツール。

### ニュースレター <a id="newsletters"></a>

## 更新停止 <a id="obsolete"></a>

2019年1月以降活動がない、または公式に終了したプロジェクトです。

- [Gibberish](https://github.com/gibber-cc/gibberish) - コード生成技術を用いてJIT最適化されたオーディオコールバックを生成するJavaScript DSPライブラリ
- [lissajous](https://github.com/kylestetz/lissajous) - プログラムによるオーディオパフォーマンスを実現するツール
- [SSSynthesiser.js](https://github.com/surikov/SSSynthesiser.js) - インタラクティブな音楽やサウンドエフェクトに使用するwavetableシンセイザー
- [WAAX](https://github.com/hoch/WAAX/) - ブラウザ上で音楽アプリケーションを開発する
- [Band.js](https://github.com/meenie/band.js/) リズム、複数の楽器、繰り返しセクション、複雑な拍数をサポートするウェブオーディオAPI用インターフェース
- [reverbGen](https://github.com/adelespinasse/reverbGen) - 人工リバーブインパルス応答を生成するJavaScriptライブラリ
- [TuneJS](https://github.com/abbernie/tune) - 微細音階および正則音階をサポートし、3,000以上の歴史的チューニングを提供するチューニングライブラリ
- [Beet.js](https://github.com/zya/beet.js) - ユークリッドリズムおよびポリリズムを生成するシーケンサライブラリ
- [AudioKeys](https://github.com/kylestetz/AudioKeys) - ウェブオーディオプロジェクト用のQWERTYキーボード
- [web-audio-test-api](https://github.com/mohayonao/web-audio-test-api) - CI用のウェブオーディオテストライブラリ
- [javascript-karplus-strong](https://github.com/mrahtz/javascript-karplus-strong) - Karplus–StrongギターシンセシスのJavaScript／Web Audio実装
- [osc-msg](https://github.com/mohayonao/osc-msg) - エラー対応を備えたOSCメッセージデコーダ／エンコーダ
- [Pizzicato](https://github.com/alemangui/pizzicato) - ブラウザ内で音を生成・操作するためのライブラリ
- [Mooog](https://github.com/mattlima/mooog) - jQueryやミックステーブルにインスパイアされた、AudioNodesの操作を簡易化するツール
- [envelope-generator](https://github.com/itsjoesullivan/envelope-generator) - ウェブオーディオ用のシンプルなADSR包絡生成器
- [audio contour](https://github.com/danigb/audio-contour) - 5段階のオーディオ包絡生成器
- [web-audio-recorder-js](https://github.com/higuma/web-audio-recorder-js) - ウェブオーディオAPIの音入力（AudioNodeオブジェクト）を記録し、Blobオブジェクトにエンコードするライブラリ
- [audiolet](https://github.com/oampo/Audiolet) - ブラウザ内でリアルタイムでオーディオ合成と編成を行うJavaScriptライブラリ
- [playnote](https://github.com/createbits/playnote) - ブラウザ内で複雑な音符間隔やスケールを持つ楽器を演奏可能に
- [Recorderjs](https://github.com/mattdiamond/Recorderjs) - Web Audio APIノードの出力の録音・エクスポートを行うプラグイン
- [resampler](https://github.com/notthetup/resampler) - オーディオのリサンプリングを行うユーティリティ
- [bpm-detective](https://github.com/tornqvist/bpm-detective) – 音楽やオーディオサンプルのBPMを検出
- [web-audio-utils](https://github.com/mohayonao/web-audio-utils) - ウェブオーディオAPIでよく使われるユーティリティ関数
- [web-audio-oscillators](https://github.com/lukehorvat/web-audio-oscillators) - ウェブオーディオ用のカスタムオシレーターのコレクション
- [midi-ports](https://github.com/AndrejHronco/midi-ports) - MIDIデバイスの接続を扱う際に便利なライブラリ
- [Midi Logger](http://outputchannel.com/midi-logger/) - このMIDIログはデバッグ用にブラウザにすべてのMIDI入力を表示します
- [Code Player](https://github.com/jcppman/code-player) - コードを実際に歌わせるための実験的なアプリ
- [Web Audio Modules](https://www.webaudiomodules.org/) - ウェブブラウザ向けのシンセサイザおよびオーディオエフェクトプロセッサ（APIおよび実装）
