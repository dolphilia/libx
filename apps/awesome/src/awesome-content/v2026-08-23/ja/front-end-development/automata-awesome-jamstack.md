<a id="platforms"></a>
## プラットフォーム

- [Netlify](https://netlify.com) - 現代のウェブプロジェクトを自動化する一括プラットフォーム
- [Vercel](https://vercel.com) - 構成なしのツールとワークフローを備えた、現代のウェブアプリ向けの一括サーバレスプラットフォーム
- [Layer0](https://layer0.co) - 大規模で動的なウェブサイトと、最高水準のパフォーマンスを実現するための統合CDN、EdgeJS、予測的なプリフェッチ、パフォーマンスモニタリングを備えた、ジャムスタック専用の一括プラットフォーム
- [Azure Static Web Apps](https://azure.microsoft.com/services/app-service/static/) - 統合されたCI/CDワークフロー、認証、CDNなどを備えたフルスタックサーバレスホスティング
- [Stormkit](https://stormkit.io) - 現代のJavaScriptアプリ向けの強力な一括インフラ。Gitフローとビルド、デプロイ、スケーリングをスムーズに統合します。
- [Cloud 66](https://www.cloud66.com/) - 自社のクラウドアカウントに静的ウェブサイトをビルド・デプロイします。

_For more resources about Static Web Apps see (Awesome Static Web Apps)[https://github.com/staticwebdev/awesome-azure-static-web-apps]._

<a id="no-code-platforms"></a>
## ノーコードプラットフォーム

- [Jamstack.new](https://jamstack.new) - Stackbitが提供する1クリックで新しいジャムスタックサイトを作成
- [Storipress](https://storipress.com) - 統合されたサイトビルダーとワークフロー管理を備えた、一括発行・ブログプラットフォーム
- [Draftbox](https://draftbox.co) - コーディングなしで、WordPressやGhostのブログに高速かつ安全なフロントエンドを提供。
- [Plasmic](https://www.plasmic.app/) - Reactコンポーネントやジャムスタックサイトの視覚的な構築に最適な強力なデザインツール。
- [TeleportHQ](https://teleporthq.io/) - フロントエンド設計・開発プラットフォーム。TeleportHQは、ヘッドレス静的ウェブサイトの作成と公開を即時に行える協働型フロントエンドプラットフォームです。無料コードエクスポート、3つの無料プロジェクト、無制限の協働者を提供。
- [Silex](https://www.silex.me) - 任意のヘッドレスCMSに接続可能な視覚的なウェブサイトビルダー。出力は静的HTMLとCSS。自宅サーバーで実行可能で、ロックインなし。

## 静的サイトジェネレーター

- [Gatsby](https://gatsbyjs.org) - React向けの高速な静的サイトジェネレーター
- [Next.js](https://nextjs.org/) - 静的およびサーバーレンダリングされたアプリケーション向けの軽量フレームワーク
- [Hugo](https://gohugo.io) - HugoはGoで書かれた静的サイトジェネレーターです
- [Jekyll](https://jekyllrb.com) - Jekyllはシンプルで、ブログに適した静的サイトジェネレーターであり、個人、プロジェクト、組織向けサイトに最適です
- [Hexo](https://hexo.io) - Node.jsをベースにした高速でシンプルかつ強力なブログフレームワーク
- [Metalsmith](https://metalsmith.io) - 非常にシンプルで、プラグイン可能な静的サイトジェネレーターです
- [Phenomic](https://phenomic.io/) - モジュール化されたウェブサイトコンパイラです
- [Gridsome](https://gridsome.org/) - Vueを活用した静的サイトジェネレーターで、ヘッドレスCMS、API、またはMarkdownファイルに対応したCDN対応ウェブサイトを構築できます
- [Nuxt.js](https://nuxtjs.org/) - サーバーサイドレンダリング、静的、伝統的なシングルページアプリケーション向けの多機能なVueベースのフレームワークです
- [eleventy](https://www.11ty.io/) - さまざまなテンプレートファイルをHTMLに変換するシンプルな静的サイトジェネレーターです
- [Nift](https://nift.dev) - C++で開発されたクロスプラットフォームオープンソースウェブサイトジェネレーターで、非常に高速かつ強力です
- [Astro](https://astro.build) - ほぼJavascriptを送信しないで、より高速なウェブサイトを構築できます
- [FactorJS](https://www.factorjs.org) - Viteをベースにした次世代フレームワークです
- [Mandu](https://mandujs.com) - Bun + Reactで構築されたエージェントネイティブなフルスタックフレームワーク。静的エクスポート、SSR、ファイルシステムルーティング、ランタイムのアーキテクチャガード、100以上のMCPツールを備え、AIエディタがサイトをエンドツーエンドで操作できます。
- [Bloggrify](https://bloggrify.com) - ブログ用のNuxt Contentレイヤー。テーマ、SEO、RSS、アナリティクスが事前設定済み。

_より包括的な一覧は [Jamstack generators](https://jamstack.org/generators/) を参照してください。_

- [Ghost](https://ghost.org/) - オンライン出版物向けのヘッドレスCMS。

- [CloudCannon](https://cloudcannon.com/) - ジャムスタックサイト向けのGitベースのCMS

## API

<a id="authentication"></a>
### 認証

- [Auth0](https://auth0.com/) - シングルサインオンとトークンベースの認証
- [Netlify Identity](https://www.netlify.com/docs/identity/) - [GoTrue API](https://www.gotrueapi.org) を基盤とする、一通りの認証機能を提供します。
- [Stytch](https://stytch.com) - パスワードレス認証とセッション管理のAPI。[Vercel上のサンプル](https://github.com/vercel/next.js/tree/canary/examples/auth-with-stytch)で試せます。
- [Clerk](https://clerk.com) – React、Next.js、現代ウェブ向けに設計された完全なユーザー管理UIとAPI
- [Corbado](https://www.corbado.com) – Corbadoは、数行のコードでウェブサイトやアプリにパスキーを追加することで、パスワードなし認証を実現します
- [Scalekit](https://scalekit.com) – 既存の認証システム（Auth0、Firebase、Cognitoなど）に企業向けSSO（SAML、OIDC）およびSCIMプロビジョニングを追加可能で、リライトなしで実現

<a id="comments"></a>
### コメント

- [Disqus](https://disqus.com) - ウェブサイト上のディスカッションを向上させ、ウェブ全体の会話に結びつけるグローバルコメントシステム
- [Facebook Comments](https://developers.facebook.com/docs/plugins/comments) - コメントプラグインにより、ユーザーはFacebookアカウントを使ってあなたのサイトのコンテンツにコメントできます
- [Utterances](https://utteranc.es/) - GitHubのイシューに基づく軽量コメントウィジェット。ブログコメント、WikiページなどにGitHubのイシューを使用できます

<a id="forms"></a>
### フォーム

- [Fetch Forms](https://www.fetchforms.io/) - フォームビルダーのスピードでフォームを作成し、シンプルなAPIを呼び出してアプリケーションに活用できます
- [Formcarry](https://formcarry.com) - フォームのHTMLエンドポイントを手軽に提供、強力なダッシュボード、信頼性の高いスパムブロッキング、添付ファイルのアップロード、Zapier統合を備えたフォームエンドポイント
- [Formcake](https://formcake.com) - 開発者向けフォームバックエンド：Zapier統合、ゼロ依存、シンプルなAPI、無制限のフォーム
- [Getform](https://getform.io) - デザイナーと開発者向けフォームバックエンドプラットフォーム。静的サイトのフォームエンドポイントを数分で設定し、Zapier統合とWebhooksでデータを拡張できます
- [Netlify Forms](https://www.netlify.com/docs/form-handling/) - ビルド時にHTMLファイルをデプロイ時に解析することで、組み込みのフォーム処理を実現
- [Arengu](https://www.arengu.com) - Arenguでサインアップとログインフォームを作成し、ソーシャルログインを有効にし、2FAを追加またはパスワードレスフローを使用して、APIまたは認証プロバイダーでユーザーを認証します。
- [Static Forms](https://www.staticforms.xyz/) - サーバー側コードなしでHTMLフォームを簡単に統合できます。ユーザーがフォームを提出した後、当該フォームの内容を登録済みメールアドレスに送信します。
- [Form.taxi](https://form.taxi) - HTMLフォームのエンドポイントで提出を簡単に処理。メール通知、ファイルアップロード、提出履歴の保存、GDPR対応データ処理など、豊富な機能を提供します。

<a id="e-commerce"></a>
### Eコマース

- [Astro Snipcart](https://github.com/lloydjatkinson/astro-snipcart) - Astro Snipcartは、AstroフレームワークとSnipcartプラットフォームを用いてEコマースサイトを構築できるようにする開発者向けツールです。
- [Flatmarket](https://github.com/christophercliff/flatmarket) - Flatmarketは、静的ウェブサイト向けの無料かつオープンソースのEコマースプラットフォームです。
- [GoCommerce](https://www.gocommerceapi.org) - Jamstackサイト向けのヘッドレスEコマースプラットフォーム。
- [Snipcart](https://snipcart.com/) - 開発者向けの強力なショッピングカートプラットフォーム。
- [Moltin](https://moltin.com/) - 開発者向けのEコマースAPI。
- [Trolley](https://trolley.link) - Jamstack向けに設計されたショッピングカート。
- [Shopify](https://www.shopify.co.uk/plus/solutions/headless-commerce) - ShopifyのヘッドレスEコマースソリューション。
- [Commerce.js](https://commercejs.com/) - 開発者向けのAPI中心のEコマースプラットフォーム。
- [CartQL](https://cartql.com/) - Jamstack向けに構築されたGraphQLショッピングカートおよびチェックアウトAPI。任意のフレームワークや在庫システムと連携可能です。
- [Medusa](https://medusajs.com/) - 開発者が優れたデジタルコマース体験を構築できる、オープンソースのヘッドレスコマースエンジンです。
- [Saleor](https://saleor.io/) - [オープンソース](https://github.com/saleor/saleor)で、GraphQLファーストかつ技術非依存のコマースエンジンです。

<a id="search"></a>

<a id="database"></a>
### データベース

- [GraphQL](https://graphql.org) - API用のクエリ言語と、既存データでそのクエリを実行するランタイム。
- [Graphcool](https://graph.cool) - サーバーレスGraphQLバックエンドを開発できる、オープンソースかつセルフホスト可能なBackend as a Serviceです。
- [FaunaDB](https://fauna.com) - クラウドまたはオンプレミスで、関係型NoSQLデータベースにJOIN、インデックス、マルチリージョンACIDトランザクションを備えたもの。
- [Fireproof](https://use-fireproof.com/) - ゼロ依存、オフライン対応のCRDTデータベース。ブラウザ内で実行され、任意のクラウドに接続可能。
- [Jexia DataSet](https://jexia.com) - REST APIスキーマとスキーマレスのクラウドデータストレージに内蔵されたバリデーター、関係、集計関数。
- [Tigris](https://www.tigrisdata.com) - オープンソースデータプラットフォーム。データベース、リアルタイム検索用自動検索インデックス、キャッシュ、リアルタイムのpub/subを提供。
- [Nhost](https://nhost.io) - Postgresデータベース、即時利用可能なHasura GraphQL API、認証、ストレージ、サーバーレス関数を備えた、オープンソースのBackend as a Serviceです。

<a id="file-management"></a>
### ファイル管理

- [Jexia FileSet](https://jexia.com) - アプリケーション向けREST APIファイルマネージャー。インデックスと追加機能を提供。

<a id="automation"></a>
### 自動化

- [Zapier](https://zapier.com/) - 1000以上のアプリケーションを接続するアクショントリガー。
- [DataFire](https://github.com/DataFire/DataFire) - DataFireはAPIの構築と統合を行うオープンソースフレームワーク。

<a id="serverless"></a>
## サーバーレス

- [Netlify Functions](https://www.netlify.com/docs/functions/) - NetlifyではAWSアカウントなしでLambda関数をデプロイ可能。関数管理はNetlify内で直接行える。
- [Amazon Lambda](https://aws.amazon.com/lambda/) - サーバーのプロビジョニングや管理を必要とせずコードを実行できる。
- Microsoft Azure
  - [Azure Functions](https://docs.microsoft.com/en-us/azure/azure-functions/) - サーバレスコンピューティングサービス。インフラストラクチャを明示的にプロビジョニングまたは管理する必要なしにコードをオンデマンドで実行可能。
  - [Azure Logic Apps](https://docs.microsoft.com/en-us/azure/logic-apps/) - クラウドサービスおよびオンプレミスシステム間のアプリケーションとデータを統合する自動スケーラブルなワークフローの構築を簡素化。
- Google Cloud
  - [App Engine](https://cloud.google.com/appengine/) - インフラストラクチャを完全に抽象化し、コードに集中できるサーバレスアプリケーション。
  - [Cloud Functions](https://cloud.google.com/functions/) - クラウドサービスを構築・接続するためのサーバレス環境。
  - [Cloud Datastore](https://cloud.google.com/datastore/) - 高度にスケーラブルなNoSQLデータベース。自動シャードとレプリケーションを備える。
  - [Cloud Storage](https://cloud.google.com/storage/) - 高QPS要件向けの地理的リドンダントオブジェクトストレージ。
  - [Cloud Pub/Sub](https://cloud.google.com/pubsub/) - すべてのメッセージサイズと速度に対応する地理的リドンダントリアルタイムメッセージング。
  - [Apigee](https://apigee.com/) - マルチクラウド環境向けのエンタープライズAPI管理。
  - [Endpoints](https://cloud.google.com/endpoints/) - Google Cloud上で構築されたAPI管理アプリ。
  - [Cloud Dataflow](https://cloud.google.com/dataflow/) - サーバレスストリームおよびバッチデータ処理サービス。
  - [BigQuery](https://cloud.google.com/bigquery/) - 企業向けの高度なクラウドデータウェアハウスソリューションをデプロイするためのサーバレスデータウェアハウスサービス。
  - [Cloud ML Engine](https://cloud.google.com/ml-engine/) - カスタムGoogleハードウェア（テンソルプロセッシングユニット）をベースに構築された、自動的にスケーリングされるサーバレス機械学習サービス。
- [Serverless](https://serverless.com/) - サーバレスアーキテクチャのデプロイおよび運用に用いるツールキット。
- [Cloudinary](https://cloudinary.com/) - サーバレスメディア（画像／動画）管理プラットフォーム。人気の言語ごとにSDKを提供し、Jamstackにメディアウィジェットを組み込むことで、メディア、CDN、ストレージ、変換など、簡単に管理できるようにしています。
- [imgix](https://www.imgix.com/) - サーバレス画像配信および管理サービス。imgixは、あなたの画像が保存されている場所（例：S3、GCS、ウェブフォルダ）に接続し、シンプルかつ堅牢なURLパラメータを使って、画像を変換・最適化し、知的に配信します。
- [TwicPics](https://twicpics.com/) - サーバレス画像および動画の最適化と変換サービス。TwicPicsは、あらゆるスタックに組み込み、フロントエンド開発者が完全な制御をもってリアルタイムでメディアを最適化できるようにします。

_より包括的な一覧は [Awesome Serverless](https://github.com/pmuens/awesome-serverless) を参照してください。_
