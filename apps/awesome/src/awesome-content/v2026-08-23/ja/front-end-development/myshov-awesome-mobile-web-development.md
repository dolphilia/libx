## 記事とドキュメント <a id="articles-and-documentation"></a>

- [300ms Tap Delay, Gone Away](https://developers.google.com/web/updates/2013/12/300ms-tap-delay-gone-away) - タップ時に300msの遅延を防ぐ方法

- [Faster Web App Delivery with PRPL](https://addyosmani.com/blog/the-prpl-pattern/) - パフォーマンスの高いウェブアプリケーションに必要なパターン
- [Get Started with Remote Debugging Android Devices]( https://developers.google.com/web/tools/chrome-devtools/remote-debugging/) - AndroidでChrome DevToolsを使ってウェブアプリをデバッグする
- [Guidelines For Mobile Web Development](https://www.smashingmagazine.com/guidelines-for-mobile-web-development/) - モバイルウェブ開発に関する優れた記事集
- [Hiding Videos on the Mobile Web](https://dougsillars.com/2020/01/06/hiding-videos-on-the-mbile-web/) - 動画を非表示にし、モバイルトラフィックに影響を与えない方法
- [How To Poison The Mobile User](https://www.smashingmagazine.com/2016/10/how-to-poison-the-mobile-user/) - モバイルサイトにおけるネガティブな実践についての概要

- [Measuring Network Performance in Mobile Safari](https://csswizardry.com/2021/02/measuring-network-performance-in-mobile-safari/) - Mobile Safariを使ってネットワークパフォーマンスを測定するためのアドバイス

- [Responsive Web Design – What It Is And How To Use It](https://www.smashingmagazine.com/2011/01/guidelines-for-responsive-web-design/) - レスポンシブデザインの技術の概要
- [Rules for Mobile Performance Optimization](https://queue.acm.org/detail.cfm?id=2510122) - ページ読み込みを速くするための技術の概要
- [Self-Host Your Static Assets](https://csswizardry.com/2019/05/self-host-your-static-assets/) - 静的資産を自前でホストする必要性について
- [The Impact of Web Performance](https://simplified.dev/performance/impact-of-web-performance) - パフォーマンスがビジネスにおいて重要な理由
- [The joy and challenge of developing for KaiOS](https://nolanlawson.com/2019/09/22/the-joy-and-challenge-of-developing-for-kaios/) - KaiOS向け開発を始める方法

- [Tips for making interactive elements accessible on mobile devices](https://bitsofco.de/tips-for-making-interactive-elements-accessible-on-mobile-devices/) - アクセシブルなモバイルUIを作成するためのアドバイス一覧

- [What Does A Foldable Web Actually Mean?](https://www.smashingmagazine.com/2020/02/foldable-web-meaning/) - 折りたたみスマホがウェブに与える影響についての考察
- [Who Killed My Battery](https://mobisocial.stanford.edu/papers/boneh-www2012.pdf) - ウェブサイトの消費電力に関する興味深い論文

## モバイルウェブ体験を高めるW3C仕様 <a id="specifications-from-w3c-for-enhancing-mobile-web-experience"></a>

- [Battery API](https://www.w3.org/TR/battery-status/) - バッテリーに関する情報のアクセスについて
- [Connection API](http://wicg.github.io/netinfo/) - 接続に関する情報のアクセスについて
- [Generic Sensor API](https://www.w3.org/TR/generic-sensor/) - センサーデータを公開する仕様
- [Geolocation API](https://www.w3.org/TR/geolocation-API/) - 地理位置情報のアクセスについて
- [HTML Media Capture](https://www.w3.org/TR/html-media-capture/) - ユーザーがカメラまたはマイクにアクセスできるようにする方法
- [Payment Request API](https://www.w3.org/TR/payment-request/) - 最小限の統合で支払い方法を提供する方法
- [Presentation API](https://www.w3.org/TR/presentation-api/) - プレゼンテーションディスプレイへのアクセスについて。
- [Remote Playback API](https://www.w3.org/TR/remote-playback/) - ウェブページからメディアのリモート再生を制御する際のアクセスについて。
- [Vibration API](https://www.w3.org/TR/vibration/) - ホストデバイスの振動機構へのアクセスについて。
- [Visual Viewport API](https://wicg.github.io/visual-viewport/) - スクリーンの視覚部分（オンスクリーンキーボードやピンチズーム領域外など）へのアクセスについて。
- [Wake Lock Api](https://www.w3.org/TR/wake-lock/) - ウェイクロックリクエスト（デバイスの電力節約状態から一部を防ぐ）へのアクセスについて。
- [Web Bluetooth](https://webbluetoothcg.github.io/web-bluetooth/) - Bluetooth 4を介してデバイスを発見・通信するAPIへのアクセスについて。
- [Web NFC API](https://w3c.github.io/web-nfc/) - デバイスの近場通信（NFC）機能へのアクセスについて。
- [Web Notifications](https://www.w3.org/TR/notifications/) - ユーザーへの通知を実行するAPIへのアクセスについて。

## 監査ツール <a id="auditing-tools"></a>

- [Lighthouse](https://github.com/GoogleChrome/lighthouse) - ウェブアプリケーションおよびウェブページの分析ツール。
- [Mobile-Friendly Test](https://search.google.com/test/mobile-friendly) - サイトがモバイルフレンドリーかどうかをテストするツール
- [PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights) - ページを分析し、ダウンロード速度の向上を推奨するツール
- [PageSpeed](https://www.modpagespeed.com) - 自動的にあなたのサイトを最適化するウェブサーバーのモジュール
- [Site Speed Checker](https://www.thinkwithgoogle.com/feature/mobile) - あなたのモバイルサイトのスピードを他のサイトと比較するツール
- [Test Your Mobile Speed](https://testmysite.withgoogle.com/intl/en-gb) - Googleが提供するモバイルサイトの総合的な速度検査ツール
- [Webpagetest](https://webpagetest.org) - 実際のブラウザと実際の消費者接続速度で複数の場所から実行されるウェブサイトのスピードテスト


## プラットフォーム監視 <a id="platform-monitoring"></a>

- [Can I Use](https://caniuse.com) - ブラウザにおけるさまざまなウェブ機能のサポート状況
- [Mobile Browser Market Share](http://gs.statcounter.com/browser-market-share/mobile) - さまざまなプラットフォームと国別の市場シェア
- [Standards for Web Applications on Mobile](https://www.w3.org/Mobile/mobile-web-app-state) - モバイル関連のW3C仕様の現在の状態
- [What Web Can Do Today](https://whatwebcando.today) - あなたのブラウザが実行可能なもの


## その他の便利なツールとライブラリ <a id="other-useful-tools-and-libraries"></a>

- [Browsersync](https://browsersync.io) - 時間短縮型の同期ブラウザテスト
- [Eruda](https://github.com/liriliri/eruda) - モバイルウェブブラウザ向けのコンソール
- [Interact.js](https://github.com/taye/interact.js) - モダンブラウザーでドラッグ＆ドロップ、サイズ変更、慣性、スナップを備えたマルチタッチジェスチャーを実現
- [Fastclick](https://github.com/ftlabs/fastclick) - 古いブラウザにおける300ms遅延の削除
- [Lozad.js](https://github.com/ApoorvSaxena/lozad.js) - IntersectionObserver APIを用いた、高性能で軽量かつカスタマイズ可能な遅延読み込み
- [React Dates](https://github.com/airbnb/react-dates) - ウェブ向けの、簡単に国際化可能でモバイル対応の日付選択ライブラリ
- [Screen Sizes](http://screensiz.es/phone) - すべてのポピュラーなスマートフォンの画面サイズの一覧
- [Shiny](https://github.com/rikschennink/shiny) - モバイルサイト向けの光沢反射エフェクト
- [Slideout](https://github.com/Mango/slideout) - モバイルウェブアプリ向けの独立した軽量ナビゲーションメニュー
- [Swiper](https://github.com/nolimits4web/swiper) - 最も現代的なモバイルタッチスライダー（ハードウェア加速されたトランジション付き）
- [Web Inspector Remote (Weinre)](https://www.npmjs.com/package/weinre) - 非主流ブラウザでのサイトデバッグ用のウェブインスペクタ
- [Web Starter Kit](https://github.com/google/web-starter-kit) - マルチデバイス対応サイトのワークフロー
- [Workbox](https://developers.google.com/web/tools/workbox/) - ウェブアプリにオフラインサポートを追加するためのJavaScriptライブラリ
- [WorkerDOM](https://amphtml.wordpress.com/2018/08/21/workerdom/) - Web Workers内部にDOMの完全な表現を提供するためのライブラリ
