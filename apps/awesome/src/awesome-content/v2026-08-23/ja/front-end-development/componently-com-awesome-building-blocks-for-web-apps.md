## UI要素

- [Tailwind UI](https://tailwindui.com/) - Tailwind CSSの作成者によるUIコンポーネント。
- [Webix](https://webix.com/) - 異なる方法でデータを表示するJavaScript UIライブラリとフレームワーク。
- [Highcharts](https://www.highcharts.com/) - ウェブ向けインタラクティブグラフ。
- [Webatoms](https://www.webatoms.in) - Xamarin.Forms向けJavaScriptブリッジ。
- [Creative Tim](https://www.creative-tim.com/) - React、Angular、Vue、Lavarel、HTML5向けテーマ。
- [Syncfusion](https://www.syncfusion.com/) - データ可視化コンポーネントとPDF Viewer。
- [CoreUI](https://coreui.io/pro/vue) - Vue管理テンプレート。
- [UIfort](https://uifort.com/) - すべての主要フロントエンドフレームワーク向けUIデザインシステム。
- [Semantic UI](https://semantic-ui.com/) - React、Meteor、Ember、Angular向けオープンソースUIコンポーネントライブラリ。
- [Design Revision's Shards Pro](https://designrevision.com/downloads/shards-pro) - ウェブまたはモバイルアプリ向けデザインブロック。
- [Themesberg](https://themesberg.com) - Bootstrapテンプレート、テーマ、UIキット。
- [Treact](https://treact.owaiskhan.me/) - Tailwind CSS上に構築されたランディングページ向けReactテンプレート。
- [Creative Designs Guru](https://creativedesignsguru.com) - Tailwind CSSで構築されたReact、Nextjs、Eleventy向けテーマ。

## 離脱意図ポップアップ
- [Wisepops](https://wisepops.com/) - モバイル・デスクトップ訪問者向けコンテキストポップアップ、バナー、バー。
- [Listagram](https://www.listagram.com) - メールアドレス収集のためのインタラクティブなオプトインフォーム。
- [Poptin](https://www.poptin.com) - ウェブサイトの任意の場所へ統合できるポップアップとフォーム。
- [Embedery](https://www.embedery.com) - 訪問者を惹きつけるポップアップ。

## 認証
- [Auth0](https://auth0.com/) - Angular、React、VueJSをネイティブサポートする認証管理。
- [Clerk](https://clerk.com) – React、Next.js、モダンウェブ向けに特化した完全なユーザー管理UIとAPI。
- [Firebase](https://firebase.google.com) - 認証管理を含むGoogleのPaaS。
- [Okta](https://www.okta.com/) - Angular、React、VueJSをサポートする認証・認可ソリューション。
- [Onelogin](https://www.onelogin.com/) - 企業内部アプリケーションに焦点を当てた認証。
- [Microsoft Azure Active Directory](https://azure.microsoft.com/en-us/services/active-directory/#security) - Microsoftアカウントに基づくAzureの認証管理。
- [AWS Cognito](https://aws.amazon.com/cognito/) - AWS認証管理。フロントエンド統合は[AWS Amplify](https://aws.amazon.com/de/amplify/)の一部です。

## 予約
- [Calendly](https://calendly.com/) - スタンドアロン予約ソリューション。
- [Zoho Bookings](https://www.zoho.com/bookings/) - Zoho Suiteへ統合されたオンラインスケジューラー。
- [Acuity Scheduling](https://acuityscheduling.com/) - 広範なAPIを持つ予約スケジューリング。
- [10to8](https://10to8.com/) - 無料プランに多くの機能がある予約ツール。
- [SuperSaaS](https://www.supersaas.com/) - グループスケジューリングに焦点を当てた予約スケジューリング。
- [SimplyBook.Me](https://simplybook.me/) - 独自の予約ディレクトリを持つ予約ツール。
- [OnceHub](https://www.oncehub.com/) - ScheduleOnceによるスケジューリングとInviteOnceによる会議管理。
- [YouCanBookMe](https://youcanbook.me/) - チームのためのオンラインスケジューリング。
- [OnSched](https://www.onsched.com/) - マーケットプレイス・アプリケーション向けスケジューリングAPI。
- [AppointmentPlus](https://www.appointmentplus.com/) - クーポン付き予約スケジューリング。
- [Booxi](https://www.booxi.com/) - 予約・オンラインディレクトリコンポーネント。
- [Cogsworth Scheduler](https://get.cogsworth.com/) - 強力なAPIを持つビジネス向けオンラインスケジューラー。

## 通知

- [Notific](https://notific.io/) - PHP SDKを含む通知。
- [WonderPush](https://www.wonderpush.com/) - 速度に焦点を当てた通知。
- [VWO Engage](https://vwo.com/engage/push-notifications/) - より大きなマーケティングスイートの一部としての通知。
- [Signalize](https://signalize.com/) - 有料分析アドオン付きの無料通知。

## 監視
- [Sentry](https://sentry.io/) - リリース管理を含むフルスタックエラー監視。
- [Raygun Crash Reporting](https://raygun.com/platform/crash-reporting) - Raygunスイートの一部としてのエラー監視。
- [Honeybadger](https://www.honeybadger.io/) - エラー、アップタイム、チェックイン監視。
- [Rollbar](https://rollbar.com/) - エラーを引き起こしたHTTPリクエストを再生できるエラー監視。

## 同意管理
- [Cookiefirst](https://cookiefirst.com/) - Cookie同意マネージャー。
- [usercentrics](https://usercentrics.com/) - 既存ページの一部として実装できるコンプライアンスマネージャー。
- [Sourcepoint](https://www.sourcepoint.com/) - ad blocker recoveryも含むスイートの一部としてのコンプライアンス管理。
- [PiwikPro](https://piwik.pro/gdpr-consent-manager/) - 分析ツールの一部としてのコンプライアンス管理。
- [Consent Management Provider](https://www.consentmanager.de/) - Cookie Consent向けドイツの管理ツール。
- [UniConsent](https://www.uniconsent.com/) - GDPR、CCPA、COPPA準拠の同意管理プラットフォーム。
- [TrustArc](https://trustarc.com/) - CCPA、GDPR、LGPD、900以上のグローバル規制向けプライバシー管理。
- [Cookiebot](https://www.cookiebot.com/) - Cookie追跡マネージャー。
- [iubenda](https://www.iubenda.com/) - 同意管理と利用規約ジェネレーター。
- [Civic Cookie Control](https://www.civicuk.com/cookie-control/) - 小規模なCookie・GDPRコンプライアンス製品。
- [CCM19](https://www.ccm19.de/) - ドイツのcookie consent manager。
- [CookieInformation](https://cookieinformation.com/) - ダッシュボードを介したコンプライアンスレポートに焦点を当てます。
- [CookiePro](https://www.cookiepro.com/) - プライバシー管理ソリューションの一部としてのCookie管理。
- [React Cookie Consent](https://github.com/Mastermindzh/react-cookie-consent) - Reactアプリケーション向けの小さくカスタマイズ可能なcookie consent bar。
- [React Cookie Banner](https://github.com/buildo/react-cookie-banner) - スクロールで自動的に閉じられるReact cookie banner。

## メディア
- [Mux](https://mux.com/) - ホスト済み・ライブ動画をストリーミングします。
- [Spotify web playback SDK](https://developer.spotify.com/documentation/web-playback-sdk/) - Spotify Connectの新しいプレイヤーを作成し、暗号化メディア拡張経由でブラウザー内のSpotifyの任意オーディオトラックを再生できるクライアント側JavaScriptライブラリ。

## フォーム
- [Static Forms](https://www.staticforms.xyz/) - 結果をメールへ送信するフォーム。
- [FlyingForms](https://flyingforms.io/?utm_source=github-awesome-components&utm_medium=referral&utm_campaign=awesome-list) - フォームの構築、バージョン管理、管理。
- [KirokuForms](https://kirokuforms.com/) - 手厚い無料プラン、メール通知、完全なAPIアクセスを持つドラッグ＆ドロップフォームビルダー。

## マーケティング
- [TrustPulse](https://trustpulse.com/) - ウェブサイト上で最近の購入者を表示します。

## 変更履歴
- [Beamer](https://www.getbeamer.com) - プッシュ通知と変更履歴管理の組み合わせ。
- [Changelogfy](https://changelogfy.com/) - 製品リリースノートツール。
- [Changefeed](https://changefeed.app/) - スタンドアロンページまたは埋め込み可能なウィジェットとしての変更履歴。
- [Canny's Changelog](https://canny.io/features/changelog) - 変更履歴と製品ロードマップを組み合わせます。
- [ProductFlare's Changelog](https://www.productflare.com/changelog) - 製品チームのタスク管理システムを中心とする変更履歴ウィジェット。
