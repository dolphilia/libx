# Awesome Material Design [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)

Google の [Material Design](http://www.google.com/design/spec) に基づくライブラリ、リソース、素晴らしいものの厳選リスト。

アイコン、フォント、色
==
  - [material-design-icons](https://github.com/google/material-design-icons) — Google による Material Design アイコン。
  - [material-design-iconic-font](https://github.com/zavoloklom/material-design-iconic-font) — Material Design Iconic Font と CSS ツールキット。
  - [material-design-fonticons](https://github.com/designjockey/material-design-fonticons) — Google Material Design Icon セットをフォントへ変換した Material Design Fonticons。
  - [material-colors](https://github.com/shuhei/material-colors) — コーダーが利用できる Google の Material Design カラー。
  - [material-color](https://github.com/mrmlnc/material-color) — プロジェクトで利用できる Google の Material Design に基づくカラーパレット。
  - [LESS-Material-design-colors](https://github.com/tisign/LESS-Material-design-colors) — Google Material Design の全色を含む .less ファイル。
  - [sass-material-colors](https://github.com/minusfive/sass-material-colors) — Sass/Scss プロジェクトで Google の Material Design カラーを簡単に使う方法。
  - [Google-Material-Design-Font-Icon](https://github.com/Seb-L/Google-Material-Design-Font-Icon) — Google Material Design Icon セットに基づくフォントアイコン。
  - [Material Design Icons](https://materialdesignicons.com/) — コミュニティが作成した Material Design アイコンパック。
  - [Android Asset Studio](https://romannurik.github.io/AndroidAssetStudio/) — 最終的に Android アプリケーションの res/ ディレクトリに置かれるグラフィックやその他のアセットを生成する Web ベースのツールセット。

アニメーション
==
  - JavaScript
    - [Waves](https://github.com/fians/Waves) — Google の Material Design に着想を得たクリックエフェクト。
    - [material-design-hamburger](https://github.com/swirlycheetah/material-design-hamburger) — CSS で構築した Android の Material Design ハンバーガーアニメーション。
    - [Material-Preloader](https://github.com/aarondo/Material-Preloader) — Material Design のプリローダー（inbox で見られるもの）を再現する jQuery プラグイン。
    - [Google-material-design-ripple-effect](https://github.com/ninox92/Google-material-design-ripple-effect) — リップルとフォーカスエフェクトを再現する jQuery プラグイン。
  
コンポーネント
==
  - [SVG-Morpheus](https://github.com/alexk111/SVG-Morpheus) — SVG アイコンを別のアイコンへ変形できる JavaScript ライブラリ。Material Design の Delightful Details トランジションを実装する。
  - [Material-Design-ColorPicker](https://github.com/Fraina/Material-Design-ColorPicker) — Material Design カラーピッカー。
  - [material-design-color-palette](https://github.com/zavoloklom/material-design-color-palette) — Material Design カラーパレット: LESS/CSS ツールキット。
  - [md-timepicker](https://github.com/dotlouis/md-timepicker) — Material Design の Polymer Timepicker 要素。
  - [md-date-time](https://github.com/SimeonC/md-date-time) — Google の Material Design 仕様に基づく日時ピッカー。
  - [ng-material-floating-button](https://github.com/nobitagit/ng-material-floating-button) — Angularjs ディレクティブとして実装された、アクションボタン付き Material Design フローティングメニュー。
  - [DevExtreme Reactive](https://devexpress.github.io/devextreme-reactive/react) - Material Design 向けの高性能プラグインベース React コンポーネント。


CSS
==
  - [Surface](https://github.com/mildrenben/surface) — Material Design に基づく軽量な CSS 専用フレームワーク。
  - [material-ui](https://github.com/callemall/material-ui) — Google の Material Design を実装する CSS フレームワークと React コンポーネントセット。
  - [bootstrap-material-design](https://github.com/FezVrasta/bootstrap-material-design) — Bootstrap 3 用の Material Design テーマ。
  - [materialize](https://github.com/Dogfalo/materialize) — Material Design に基づく CSS フレームワーク、Materialize。
  - [materialBootstrap](https://github.com/throrin19/materialBootstrap) — Google Material Design 向けの Twitter Bootstrap テーマ。
  - [material-playground](https://github.com/ebidel/material-playground) — Polymer の Material Design プレイグラウンド。
  - [material-framework](https://github.com/nt1m/material-framework) — 使いやすい Material Design ベースのフレームワーク。
  - [mui](https://github.com/muicss/mui) — Material Design ガイドラインに従う軽量 CSS フレームワーク。
  - [material-foundation](https://github.com/eucalyptuss/material-foundation) — Foundation for Sites の Material Design 版。
  - [Tronic247 Material](https://www.tronic247.com/material/) - jQuery と CSS に基づく Material Design フレームワーク。

JS
==
  - [AngularJS](https://github.com/angular/material) — AngularJS 向け Material Design。
  - [Angular](https://github.com/angular/material2) — Angular 向け Material Design。
  - [DevExtreme](https://js.devexpress.com) — カスタマイズ可能な Material Design 準拠テーマを備える、65 種以上のレスポンシブで機能豊富な UI コンポーネント。Angular、React、Vue、jQuery に対応。
  - [ember-paper](https://github.com/miguelcobain/ember-paper) — Ember による Material Design へのアプローチ。
  - [material-design-lite](https://github.com/google/material-design-lite/) — HTML/CSS/JS による Material Design Lite コンポーネント。
  - [MUI](https://mui.com/) — Material Design の React コンポーネントライブラリ。
  - [react-material](https://github.com/BerkeleyTrue/react-material) — React.js と React Style で書かれた Material Design コンポーネント。


SASS
==
  - [quantum-colors](https://github.com/nkpfstr/quantum-colors) — Sass プロジェクト向け Material Design カラーパレット。
  - [quantum-shadows](https://github.com/nkpfstr/quantum-shadows) — Sass プロジェクト向け Material Design ドロップシャドウ。
  - [google-material-design](https://github.com/axyz/google-material-design) — Google Material Design ガイドラインに着想を得た小さな SASS ライブラリ。


WordPress
==
  - [MaterialPress](https://github.com/alexpatin/MaterialPress) — Google の Material Design 哲学から大きな影響を受けた WordPress テーマ。
  - [materialwp](https://github.com/braginteractive/materialwp) — Material Design WordPress テーマ。
  
 WinForms
==
- [MaterialSkin](https://github.com/IgnaceMaes/MaterialSkin) — .NET WinForms、C#、VB.Net を Google の Material Design 原則に沿ってテーマ化する。

XAML
==
 - [MaterialDesignInXamlToolkit](https://github.com/ButchersBoy/MaterialDesignInXamlToolkit) — C# と VB.Net 用の、XAML と WPF における Google Material Design。

その他
==
  - [material_design_zh](https://github.com/1sters/material_design_zh) — Material Design の共同中国語翻訳。
  - [material-color-scheme](https://github.com/paradox41/material-color-scheme) — Material Design カラーパレットに基づく Sublime Text 構文テーマ。
  - [framaterial](https://github.com/Framaterial/framaterial) — Material Design プロジェクトを作成するためのフレームワーク。
  - [Material Design Templates](http://themeforest.net/tags/material%20design) — ThemeForest にあるさまざまな Material Design 風テーマとテンプレート。
  - [MaterialUp](http://www.materialup.com/) — Material Design のインスピレーションを毎日得る。
  - [Material Palette](http://www.materialpalette.com/) — 好みの色を選び、Material Design パレットを生成する。
  - [Paper Polymer Elements](https://elements.polymer-project.org/browse?package=paper-elements) — Paper 要素は Google の Material Design を実装する視覚要素のセット。
  - [ScaffoldHub.io](https://scaffoldhub.io) — オンラインモデリングツールで完全な Angular Material アプリケーションを生成する。
