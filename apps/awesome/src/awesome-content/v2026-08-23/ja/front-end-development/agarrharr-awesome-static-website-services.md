## 音声

- [SoundCloud](https://soundcloud.com/) - 埋め込み可能なプレイヤーを備える音声ホスティング。最大3時間のコンテンツは無料。
- [Mixcloud](https://www.mixcloud.com/) - 無制限アップロードと埋め込み可能なプレイヤーを備える音声ホスティング。
- [Spotify](https://www.spotify.com/) - [Spotify Play Button](https://developer.spotify.com/documentation/widgets/guides/adding-a-spotify-embed/)で任意の曲、アルバム、プレイリストを埋め込める。

## 書籍

- [Goodreads API and widgets](https://www.goodreads.com/api) - Goodreadsのあらゆるデータへアクセスできる。ウィジェットは[設定ページ](https://www.goodreads.com/user/edit)のwidgetsタブにある。
- [Open Library Open API](https://openlibrary.org/developers/api) — 追跡なしで地球最大の書籍オープンデータセットから書籍データを取得できる。

## カレンダーとスケジューリング

- [Google Calendar](http://calendar.google.com/) - 他者と共同利用できる埋め込み可能なカレンダー。
- [Booking.js](http://booking.timekit.io/) - 美しい埋め込み可能な予約ウィジェット。
- [zenplanner](http://zenplanner.com/) - 有料。フィットネス向けオンラインスケジューリング。

## 画像

- [Flickr](https://www.flickr.com/) - Yahooによるオンライン写真ホスティング。
- [Cloudinary](https://cloudinary.com/) - 画像ホスティング、加工、配信。

## 地図

- [Google Maps](http://maps.google.com/) - Google地図は簡単に埋め込める。
- [Mapbox](https://www.mapbox.com/) - 見栄えのよい埋め込み可能な地図。
- [uMap](https://umap.openstreetmap.fr/en/) - 優れた[OpenStreetMap](https://openstreetmap.org)データセットに基づくパーソナライズ地図を作成・埋め込みする。

## プレゼンテーション

- [Prezi](https://prezi.com/) - ズームと回転ができる印象的な遷移を持つオンラインプレゼンテーション。
- [Reveal.js](http://lab.hakim.se/reveal-js/) - HTMLプレゼンテーションフレームワーク。
- [Slides.com](http://slides.com/) - スライドデッキを作成、発表、共有する場所。
- [SpeakerDeck](https://speakerdeck.com/) - スライドをPDFとしてアップロードし、オンラインで共有可能なプレゼンテーションを得る。

## 動画

- [Mux](https://mux.com/) - 有料。クライアントで動画を直接再生するAPI。ライブストリームにも利用可能。
- [YouTube](https://www.youtube.com/) - 無制限アップロードの埋め込み可能動画。
- [Vimeo](https://vimeo.com/) - 有料。広告なしの埋め込み可能動画。
- [Vevo](http://www.vevo.com/) - 埋め込み可能なミュージックビデオ。
- [Wistia](http://wistia.com/) - 無料プランは動画25本まで。

### コード

- [Codepen](http://codepen.io/) - 埋め込み可能なフロントエンドコード例のプレイグラウンド。
- [JS Bin](http://jsbin.com/) - 埋め込み可能なフロントエンドコード例。
- [JSFiddle](http://jsfiddle.net/) - 埋め込み可能なフロントエンドコード例。

- [Indiepen](https://indiepen.tech/) - フロントエンドコード例を埋め込むプライバシーに優しいソリューション。

## Functions as a Service

- [1Backend](https://github.com/1backend/1backend) - 数秒でバックエンドをデプロイする。無料枠付きのオープンソース。
- [AWS Lambda](https://aws.amazon.com/lambda/) - サーバーのプロビジョニング・管理なしでコードを実行でき、使用したコンピューティング時間に対してのみ支払う。
- [Google Cloud Functions](https://cloud.google.com/functions/) - サーバーやランタイム環境の管理なしでCloudイベントに応答する、単一目的のスタンドアロン関数を作成する。
- [Webtask by Auth0](https://webtask.io/) - 単純なHTTPでサーバー上のコードを呼び出す。LambdaやGoogleよりはるかに簡単に設定できる。
- [Azure Functions](https://azure.microsoft.com/en-us/services/functions/) - Microsoft提供。Azureクラウド上でLambdaと同じ前提を持つ。
- [IronWorkers](https://www.iron.io/platform/ironworker/) - Iron.io提供。無制限スケールと単純な価格設定を持つ多言語コンテナ環境でコードを実行する。
- [IronFunctions](http://open.iron.io/) - Iron.io提供。プライベート、パブリック、ハイブリッドを問わない任意クラウド向けオープンソースサーバーレスコンピューティングプラットフォーム。
- [OpenWhisk by IBM](https://console.ng.bluemix.net/openwhisk/) - BlueMixホスティングプラットフォームの一部でオープンソース。Watson AIエコシステムと良好に連携する。
- [StackPath EdgeEngine](https://www.stackpath.com/products/edgeengine/) - 好みの言語でFunctions as a Serviceを書き、グローバルなデータセンターネットワークへデプロイする。インテリジェントルーティングや負荷分散を含むすべてのネットワークを、StackPathがプライベートバックボーン上で管理する。
- [Cloud 66](https://www.cloud66.com/) - 自身のクラウドアカウントへ静的ウェブサイトをビルド・デプロイする。 
- [Vercel](https://vercel.com/home#features) - 好みの言語でFunctions as a Serviceを書き、monorepoの一部としてデプロイできる。
- [Azure Static Web Apps](https://azure.microsoft.com/en-us/services/app-service/static/#features) - サーバーレスFunctions、認証、CDNなどを含むフルスタック静的アプリホスティング。
- [Qoddi](https://qoddi.com) - Herokuに似た開発者中心アプローチでデータストレージを含むフルスタックアプリホスティング。3アプリまで無料で使える。
- [Autocode](https://autocode.com) - 設定不要で関数を即座にスケーラブルなウェブサービスへ変換する。ブラウザー内IDE、使いやすいAPIライブラリ、シームレスな認証管理を備えるサーバーレスホスティングが利用できる。

## GraphQL

- [FaunaDB](https://fauna.com) - サーバーレスGraphQLデータベース。期限なしの無料枠があり、Netlifyアプリへ容易に含められる。

## コミュニティ

### コメント

- [Staticman](https://github.com/eduardoboucas/staticman) - ユーザー生成コンテンツを受け取り、GitHubリポジトリへデータファイルとしてアップロードするNode.jsアプリ。GitHubへのpushごとに自動デプロイすれば、ブログコメントなどの動的コンテンツを完全静的サイトの一部として持てる。
- [Disqus](https://disqus.com/) - ネストした返信、複数ログイン方式、メール通知を備える簡単に埋め込めるコメント。
- [Facebook Comments](https://developers.facebook.com/docs/plugins/comments) - Facebookによるサイト用の埋め込み可能コメント。
- [IntenseDebate Comments](http://www.intensedebate.com/) - ネストした返信、複数ログイン方式、メール通知を備える埋め込み可能コメント。
- [LiveFyre](http://web.livefyre.com/apps/comments/) - リアルタイムコメント。SEO最適化済みで、デスクトップ／モバイル双方で美しく表示される。
- [Redditjs Embed Widget](http://embed.redditjs.com/) - サイトへRedditコメントを埋め込む。投稿がなければ、ユーザーへ送信を促すリンクを表示する。
- [Muut.com](https://muut.com/) - 埋め込み可能コメント、フォーラム、プライベートメッセージング。多機能ながらサイトへ残すフットプリントは非常に小さい。
- [Gitment](https://github.com/imsun/gitment) - GitHub Issuesに基づくコメントシステム。サーバーサイド実装なしでフロントエンドから使える。
- [giscus](https://github.com/laymonage/giscus) - GitHub Discussions上に構築されたコメントウィジェット。
- [utterances](https://github.com/utterance) - GitHub issues上に構築された軽量コメントウィジェット。 

### フォーム

#### とてもシンプルなフォーム

- [Formspree](http://formspree.io/) - 静的ウェブサイトのフォームからメールを受信する。
- [elFormo](https://www.elformo.com/) - メール経由のシンプルなフォーム処理と応答取得。
- [Flipmail](http://flipmail.co/) - メール経由のシンプルなフォーム処理と応答取得。
- [MailThis](http://mailthis.to/) - 任意の添付付きメール経由のシンプルなフォーム送信。
- [Simple Form](https://getsimpleform.com/) - 任意のファイル添付、メール通知、オンライン送信表示を備えるシンプルなフォーム。
- [Brisk Forms](https://github.com/stevensona/briskforms) - メールアドレスを非公開に保ちつつ応答をメール送信する、オープンソースの無料フォーム送信サービス。
- [99 Inbound](https://www.99inbound.com) - メール／Slack通知とサードパーティアプリ統合（例: MailChimp）を持つフォームエンドポイントサービス。
- [Getform](http://getform.io/) - メールと統合機能を備えるデザイナー・開発者向けフォームバックエンドプラットフォーム。
- [HeyForm](https://heyform.net/) - 強力なオンラインフォームを作れる無料で使いやすいdrag & dropフォーム作成ツール。40以上のフィールド型、統合、分析などを含む。
- [Form.taxi](https://form.taxi/) - メール通知、ファイルアップロード、GDPR準拠データ処理でフォーム送信を簡単かつ確実に扱うバックエンド。

#### 通常のフォーム

- [Formcarry](https://formcarry.com) - 強力なダッシュボード、信頼できるスパム遮断、添付アップロード、Zapier統合を持つ、手間のないHTMLフォームエンドポイント。
- [Formcake](https://formcake.com) - 開発者向けフォームバックエンド。Zapier統合、単純なエンドポイントAPI、無制限フォーム。
- [Google Forms](https://www.google.com/forms/about/) - 結果をGoogle Sheetsへ保存し、送信時にメールを送れる。
- [FormKeep](https://formkeep.com/) - 有料。美しいウェブインターフェースでフォーム送信を表示する。スパムフィルタリングと、Gmail、Trello、Basecampなどのwebhook統合を備える。
- [123 Contact Form](http://www.123contactform.com/) - MailChimp、Salesforce、Google Driveなどのオンラインサービスへ接続する。決済処理業者との統合、セキュリティ、分析も含む。
- [FormAssembly](http://www.formassembly.com/) - 複雑な分岐ロジックや複数ページを含められる、任意種類のフォームを作成できる。
- [FormSite](https://www.formsite.com/) - 支払いとフォーム管理を備えるフォームビルダー。
- [FormStack](https://www.formstack.com/) - A/Bテスト、部分送信、分析、統合を備えるフォーム。
- [Sheetsu](https://sheetsu.com/) - データをGoogle SpreadsheetへPOST・GETする。
- [Typeform](http://www.typeform.com/) - 埋め込み可能な優れたフォーム。
- [Wufoo](http://www.wufoo.com/) - 無料または有料。フォームデザイナーで構築でき、通知、レポート、支払いを備えるフォーム。
- [Zoho](https://www.zoho.com/crm/help/web-forms/set-up-web-forms.html) - ファイルアップロードとcaptchaを備えるフォーム。
- [GitHub Issues](https://help.github.com/articles/about-issues/) - 開発者がコメント／質問を得る興味深い方法。例は[github.com/sindresorhus/ama](https://github.com/sindresorhus/ama)を参照。
- [Utterences](https://github.com/utterance/utterances) - GitHub issues上に構築された軽量コメントウィジェット。
- [FormBackend](https://www.formbackend.com) - フォームバックエンドを作成し、HTMLフォームをバックエンドへ送信する。エントリをオンライン表示し、他サービスへ接続でき、新規エントリごとにメールを受け取る。
- [Pageclip](https://pageclip.co) - HTMLフォーム向けの柔軟なサーバー／バックエンド。リアルタイムウェブUIでデータを表示するか、APIでCSV／JSON出力を得る。
- [Formester](https://www.formester.com) - 統合機能を備えるフォームとメールマーケティング（リード収集、メールキャンペーン、ニュースレター）。
- [StaticKit](https://statickit.com) - Reactをネイティブサポートする静的サイト向けモダンフォーム。
- [SheetDB](https://sheetdb.io/) - Google SpreadsheetをJSON APIへ変換する。
- [Form2Channel](https://form2channel.com/) - HTMLフォームをForm2ChannelへPOSTし、送信内容をGoogle Sheetsに保存、メール、Slack、Telegramで受け取る。登録なし、費用なし、制限なし。
- [reCAPTCHAme](https://recaptchame.com/) - reCAPTCHAとhCAPTCHAのトークン検証サービス。フォームをreCAPTCHAmeへPOSTしてスパムを避ける。静的サイト用でサーバーサイドコーディング不要。
- [Formware](https://formware.io/) - 任意のウェブサイトへ埋め込める、無制限回答付き会話型フォーム。

## 検索

セルフホスト:

- [lunr.js](http://lunrjs.com/) - ブラウザー内のシンプルな全文検索。
- [itemsjs](https://github.com/itemsapi/itemsjs) - JavaScriptによる全文・ファセット検索、ほぼ依存関係なしの検索エンジン。
- [minisearch](https://github.com/lucaong/minisearch) - ブラウザーとNode向けの小さく強力なJavaScript全文検索エンジン。
- [flexsearch](https://github.com/nextapps-de/flexsearch) - BrowserとNode.js向けの次世代全文検索ライブラリ。
- [fuse.js](https://fusejs.io/) - 依存関係ゼロの強力で軽量なあいまい検索ライブラリ。
- [static-search](https://github.com/dchest/static-search) - HTMLファイルのJSONインデックスを生成するGoプログラムと、このインデックスを検索する任意UI付きJavaScriptコンポーネント。
- [elasticlunr](http://elasticlunr.com/docs/index.html) - Lunr.jsに基づくブラウザー検索・オフライン検索向けJavaScript開発の軽量全文検索エンジン。
- [tinysearch](https://github.com/tinysearch/tinysearch) - RustとWasmで構築した静的ウェブサイト向けの小さな全文検索エンジン。
- [js-search](https://www.npmjs.com/package/js-search) - JavaScript／JSONオブジェクトのクライアントサイド検索。ES5互換でjQuery等のサードパーティライブラリ不要。
- [search-index](https://github.com/fergiemcdowall/search-index) - ブラウザーとNode.js向けの永続的でネットワーク耐性を持つ全文検索ライブラリ。
- [fuzzysearch](https://github.com/bevacqua/fuzzysearch) - JavaScriptによる小さく非常に高速なあいまい検索。
- [fuzzy](https://github.com/mattyork/fuzzy) - ブラウザーとnode用のあいまい検索／フィルター。
- [fullproof](https://reyesr.github.io/fullproof/) - ブラウザー内で高品質な全文検索を提供するJavaScriptライブラリ。
- [Jets.js](https://jets.js.org/) - ネイティブCSS検索エンジン。
- [Hulipaa](https://github.com/sambuccid/hulipaa) - 静的ウェブサイトへ追加できる、ミニマリスト検索バーUIで数千ページを扱える静的全文検索エンジン。

サードパーティ統合:

- [Google Custom Search Engine](https://cse.google.com/cse/) - カスタムGoogle Searchでサイトを検索する。
- [Algolia](https://www.algolia.com/) - 最初のキーストロークから即時かつ関連性のある結果を返すホスト型Search API。
- [CloudSh](https://cloudsh.com/) - 数行のJavaScriptでウェブサイトに強力な検索を提供する。
