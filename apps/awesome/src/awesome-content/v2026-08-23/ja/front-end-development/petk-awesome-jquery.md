## 資料

jQueryやJavaScriptを学ぶための素晴らしい学習資料、あるいはより高度な知識を学ぶためのもの。いくつかのアドバイス：jQueryに深く浸る前に、まずJavaScriptをしっかり学んでください。

* [API documentation](http://api.jquery.com/) - jQueryの公式ドキュメント
* [Code School](https://www.pluralsight.com/courses/code-school-try-jquery) - jQuery、JavaScriptライブラリの基礎を学び、ウェブページ上の要素を操作し、ユーザーとのインタラクションを向上させる
* [Codecademy jQuery track](https://www.codecademy.com/learn/learn-jquery) - jQueryを学ぶ初心者向けコース
* [Learning jQuery](https://www.learningjquery.com/) - jQuery JavaScriptライブラリのヒント、技術、チュートリアル
* [Style guides](https://contribute.jquery.org/style-guide/) - jQueryプロジェクトへの参加時に遵守すべきコードスタイルガイド
* [Tuts+](https://code.tutsplus.com/categories/jquery) - jQueryについての有用で詳細な記事
* [jQuery guide for teams](https://github.com/voorhoede/jquery-style-guide) - チーム内で一貫性を持ったjQueryコードを書くためのヒント。使いやすく、理解しやすいコードを実現します

<a id="server-side-integrations"></a>
## サーバーサイド統合

クライアントサイドのjQueryとサーバーサイド技術を統合するためのベストプラクティス。

* Node.js:
    * [Bower](https://bower.io/) - フロントエンド向けに最適化されたパッケージマネージャー。
    * [cheerio](https://cheerio.js.org/) - サーバー側の操作に使えるjQuery。HTML文字列からjQueryインスタンスを構築し、それをクエリ・操作できるようにする。AjaxおよびエフェクトAPIは実装しない。
* PHP:
    * [PHP front end setup without Node](https://www.sitepoint.com/look-ma-no-nodejs-a-php-front-end-workflow-without-node/) - BowerPHP、Mini-AssetおよびRobo.liをPHPのフロントエンドアセット構築パイプラインに組み合わせるチュートリアル。
    * [symfony-collection](https://github.com/ninsuo/symfony-collection) - Symfony2のコレクションに要素を追加・削除・移動を管理するjQueryプラグイン。
* Python:
    * [django-static-jquery](https://pypi.org/project/django-static-jquery/) - jQueryを便利なDjangoアプリとしてパッケージ化し、新規アプリケーションの開発とデプロイを早める。
* Ruby:
    * [jquery-rails](https://github.com/rails/jquery-rails) - RailsでjQueryを使う自動化を行うgem。
    * [jquery-ui-rails](https://github.com/jquery-ui-rails/jquery-ui-rails) - RailsアセットパイプラインにjQuery UIを統合。

<a id="alternatives"></a>
## 代替手段

jQuery APIの代替実装

* [cash](https://github.com/kenwheeler/cash) - 現代ブラウザ向けに小さなjQueryの代替品。すべてのAPIを含み、ajaxを意図的に除外。
* [Zepto](https://zeptojs.com/) - ajax、効果、および追加ユーティリティを含む小さなjQueryの代替品。
* [jBone](http://jbone.js.org/) - Backboneと使用できるjQueryの実装。Backboneが動作するために必要なAPIのサブセットのみをサポート。jQueryを直接使用しないが、Backboneをプロジェクトに含める場合、バイト節約に使える。
