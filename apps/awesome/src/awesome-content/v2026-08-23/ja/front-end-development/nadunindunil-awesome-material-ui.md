## リソース

Material-UI Designの公式プロジェクトとリソース。

- [Material-UI](https://material-ui.com/) - より速く容易なウェブ開発のためのReactコンポーネント。独自のデザインシステムを構築するか、Material Designから始めましょう。

## テーマ設定

テーマをカスタマイズし、ブラウザー内で変更できるユーティリティ。

- [Create Material-UI Theme](https://github.com/react-theming/create-mui-theme) - Material Design Color Toolを通じてMaterial-UIテーマを作成するオンラインツール。
- [Material-UI Theme Generator](https://cimdalli.github.io/mui-theme-generator/) - Material-UIテーマ／パレットジェネレーター。
- [Material-UI Theme Editor](https://in-your-saas.github.io/material-ui-theme-editor/) - 色を選択するだけでライブプレビュー付きのMaterial-UIアプリケーションテーマを生成するツール。

## 関連プロジェクト

Material-UI Designファミリーのプロジェクト。

- [material-ui-theme-editor](https://in-your-saas.github.io/material-ui-theme-editor/) - ライブプレビュー機能を備え、Material UIアプリケーションのテーマを生成するツール。
- [Material palette generator](https://m2.material.io/inline-tools/color/) - 公式Material Designパレットジェネレーター。選択した任意の色のパレットを生成できます。
- [Components Extra](https://github.com/alexandre-lelain/components-extra) - Footer、CookiesBanner、BackToTopボタンなど、Material-UI上に構築された「molecule」コンポーネント群を提供します。高度にカスタマイズ可能な複雑要素により、開発者はUIのマクロ部分を非常に速く構築できます。こうしたコンポーネントはサイト間で重複しがちですが、このライブラリがその問題を解決します。
- [React Admin](https://marmelab.com/react-admin/) - ES6、React、Material Designを使用し、REST／GraphQL APIの上でブラウザーで動く管理アプリケーションを構築するフロントエンドフレームワーク。
- [Material UI Snippets](https://marketplace.visualstudio.com/items?itemName=vscodeshift.material-ui-snippets) - スニペットを提供するVSCode拡張機能。
- [Material UI Codemorphs](https://marketplace.visualstudio.com/items?itemName=vscodeshift.material-ui-codemorphs) - codemodを提供するVSCode拡張機能。
- [Eslint: detect unused classes](https://github.com/jens-ox/eslint-plugin-material-ui-unused-classes) - `@mui/styles`を使う未使用スタイルクラスを検出するESLintプラグイン。

## コンポーネント

Material-UI Designで構築されたUIコンポーネントのリスト。

- [Material-UI Chip Input](https://github.com/TeamWertarbyte/material-ui-chip-input) - Angular Materialのchip inputに着想を得たMaterial-UI chip input。
- [Material-UI Password field](https://github.com/TeamWertarbyte/material-ui-password-field) - Material-UIを使用するパスワードフィールド。
- [Fullscreen Dialog](https://github.com/TeamWertarbyte/material-ui-fullscreen-dialog) - Material-UI向け全画面ダイアログ。
- [Material-UI Upload](https://github.com/corpix/material-ui-upload) - FileAPIを使用したMaterial-UI製アップロードコントロール。
- [Super Select Field](https://github.com/Sharlaan/material-ui-superselectfield) - Material-UI向け複数選択オートコンプリートドロップダウンコンポーネント。
- [Material JSON Schema Form](https://github.com/nadunindunil/material-jsonschema-form) - jsonから生成されるMaterial-UIフォーム。
- [Notistack](https://github.com/iamhosseindhv/notistack) - Material-UI向けの簡単なスナックバー（開閉状態を扱う必要がありません）。
- [Material-UI Dropzone](https://github.com/Yuvaleros/material-ui-dropzone) - react-dropzone上に構築されたMaterial-UIコンポーネント。
- [Formik-Material-UI](https://github.com/stackworx/formik-material-ui) - formikでMaterial-UIを使用するためのバインディング。
- [Redux-Form-Material-UI](https://github.com/erikras/redux-form-material-ui) - Redux FormでMaterial-UIを使いやすくするラッパーコンポーネント。
- [Final-Form-Material-UI](https://github.com/Deadly0/final-form-material-ui) - Final FormでMaterial-UIを使いやすくするラッパーコンポーネント。
- [Material-UI Auto Rotating Carousel](https://mui.wertarbyte.com/#material-auto-rotating-carousel) - Materialスタイルのカルーセル。
- [Material-UI Image](https://mui.wertarbyte.com/#material-ui-image) - ローディングアニメーション付きのMaterialスタイル画像。
- [Material-UI Flat Pagination](https://github.com/szmslab/material-ui-flat-pagination) - Material-UI向けフラットデザインのページネーションコンポーネント。
- [Dx-react-scheduler-Material-UI](https://devexpress.github.io/devextreme-reactive/react/scheduler/) - Material-UI向けスケジューラー／カレンダーコンポーネント。
- [Dx-react-chart-Material-UI](https://devexpress.github.io/devextreme-reactive/react/chart/) - 棒、線、面、散布図、円など多様な系列タイプでデータを可視化するMaterial-UI向けグラフ。
- [Material-UI Medium Blog](https://github.com/sabesansathananthan/material-ui-medium-blog) - Mediumブログを表示する拡張Material-UI Cardコンポーネント。
- [React Github Repo Cards](https://github.com/sabesansathananthan/react-github-repo-cards) - GitHubリポジトリを表示する拡張Material-UI Cardコンポーネント。
- [React molecule-components](https://github.com/alexandre-lelain/components-extra) - Material-UIに基づくReact molecule-components。
- [Material-UI NestedMenuItem](https://github.com/azmenak/material-ui-nested-menu-item) - 無限にネストしたメニューとホバーで開く機能を備える、MUIのMenuItemのドロップイン置換。
- [React-planet](https://github.com/innFactory/react-planet) - 惑星のように見える円形メニューを作成します。
- [MUI Phone Input](https://github.com/typesnippet/mui-phone-input) - 高度で非常にカスタマイズ可能なMaterial UI向け電話番号入力コンポーネント。
- [mui-treasury](https://github.com/siriwatknp/mui-treasury) - Material-UIに基づくすぐに使えるコンポーネントのコレクション。
