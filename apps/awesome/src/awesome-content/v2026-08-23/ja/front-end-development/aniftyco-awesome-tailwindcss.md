## 便利なリンク

**凡例**: 💙 公式リソース

- 💙 [Website](https://tailwindcss.com) - 公式Tailwind CSSウェブサイト。
- 💙 [Repository](https://github.com/tailwindcss/tailwindcss) - 公式Tailwind CSSリポジトリ。
- 💙 [Tailwind Plus](https://tailwindcss.com/plus) - Tailwind CSSチームによるUIブロック、テンプレート、UIキット。
- 💙 [Headless UI](https://github.com/tailwindlabs/headlessui) - 完全にスタイルなしで、完全にアクセシブルなUIコンポーネント。
- 💙 [Heroicons](https://heroicons.com/) - 美しく手作りされたSVGアイコン。
- 💙 [Play](https://play.tailwindcss.com/) - Tailwind CSS向けの高度なオンラインプレイグラウンド。
- 💙 [Discord](https://tailwindcss.com/discord) - Tailwind CSSについて他のコミュニティメンバーとつながる公式Discordサーバー。
- [Tailwind Weekly](https://tailwindweekly.com/) - Tailwind CSSに関する週刊ニュースレター。

## ツール

**凡例**: 🌍 オンラインでアクセス可能 · 🌐 ブラウザー拡張機能 · 🔼 変換またはアップグレードツール · 🔧 ジェネレーター · 🅰 型付け／強制 · 💼 外部サービス向けプラグイン／ツール／拡張機能 · 🎨 色関連 · 🚀 フレームワーク

- 💙💼 [Prettier plugin](https://github.com/tailwindlabs/prettier-plugin-tailwindcss) - Prettier向けの公式Tailwind CSSプラグイン。
- 🎨🌍🔧 [UI colors](https://uicolors.app/create) - Tailwind CSS向けカラーパレットジェネレーター。
- 🎨🌍🔧 [Tailwind Color Shades](https://javisperez.github.io/tailwindcolorshades) - Tailwind CSS向けカラーシェードジェネレーター。
- 🎨🌍🔧 [TailwindInk](https://tailwind.ink/) - Tailwind CSSパレットで学習したAIパレットジェネレーター。
- 🎨🌍🔧 [Hypercolor](https://hypercolor.dev/) - 方向オプションを持つTailwind CSSグラデーションのコレクション。
- 🎨🌍🔧 [Tints](https://www.tints.dev/) - Tailwind CSS向けカラーパレットジェネレーターとAPI。
- 🎨🌍🔧 [Fullwind CSS](https://fullwindcss.com/) - Tailwind CSSカラーパレットを追加のシェードで拡張します。
- 🎨🌍🔧 [Inclusive colors](https://www.inclusivecolors.com/) - 詳細に調整されたWCAGアクセシブルなTailwind CSSカラーパレットを作成します。
- 🎨🌍🔧 [FreeColorPalettes.co](https://freecolorpalettes.co/tints-shades) - 任意のhex色から50～950のTailwind CSSカラースケールを生成します。
- 🌍🔧 [Base-2 Rounding](https://objectivelyround.dev) - Tailwind CSS v4の括弧なし任意値向けスペーシング・サイズ値ピッカー。
- 🔼🌍 [Prefixer](https://github.vue.tailwind-prefix.cbass.dev) - Tailwindクラスのプレフィックス付与ツール。
- 🔼 [RustyWind](https://github.com/avencera/rustywind) - Tailwind CSSクラスをソートするCLIツール。
- 🔼 [Tailwind to Inline styles converter](https://github.com/vardan-arm/tailwind-to-inline) - メールテンプレート内のTailwind CSSクラスをインラインスタイルへ変換します。
- 🚀 [Maizzle](https://maizzle.com/) - Tailwind CSSによる高速なメールプロトタイピングのためのフレームワーク。
- 💼 [`@nuxtjs/tailwindcss`](https://github.com/nuxt-community/tailwindcss-module) - PurgeCSSとモダンCSS（preset env 1）を備えるNuxt.js向けTailwind CSSモジュール。
- 💼 [tailwindcss-rails](https://github.com/rails/tailwindcss-rails) - Railsのasset pipelineでTailwind CSSを使用するためのGem。
- 💼 [Config viewer](https://github.com/rogden/tailwind-config-viewer) - Tailwind CSS設定ファイルを可視化するローカルUIツール。
- 💼 [Raycast extension](https://www.raycast.com/vimtor/tailwindcss) - Raycast Launcherでクラス、ドキュメント、色を検索します。
- 💼 [NativeWind](https://www.nativewind.dev) - Tailwind CSSをスクリプト言語として使用し、React Native向けのユニバーサルスタイルシステムを作成します。
- 🌐 [Gimli Tailwind](https://chromewebstore.google.com/detail/gimli-tailwind/fojckembkmaoehhmkiomebhkcengcljl) - ブラウザー拡張機能としてのTailwind CSS向けスマートツール。
- 🌐 [CSS Variables Editor](https://www.cssvariables.com) - daisyUIとshadcn/uiの色を管理するAI駆動Chrome拡張機能。
- 🌐 [DivMagic](https://divmagic.com) - 任意のウェブ要素とスタイルをTailwind CSSコンポーネントとしてコピーします。

## プラグイン

**凡例**: 💙 公式プラグイン · 🎨 テーマ設定 · 💼 ユーティリティ · 🧩 コンポーネント · 🛑 非推奨

- 💙🧩 [Typography](https://github.com/tailwindlabs/tailwindcss-typography) - 美しいタイポグラフィのデフォルトを持つ`prose`クラスを追加します。
- 💙 [Forms](https://github.com/tailwindlabs/tailwindcss-forms) - フォーム要素へより良いデフォルトスタイルを追加します。
- 🎨 [Themer](https://github.com/RyanClementsHax/tailwindcss-themer) - CSS変数とvariantsを用いるTailwind CSSのテーマ設定サポートを追加します。
- 💼 [Bootstrap grid](https://github.com/karolis-sh/tailwind-bootstrap-grid) - Bootstrapスタイルのflexboxグリッドシステムを生成します。
- 💼 [Dot & grid backgrounds](https://github.com/TheNaubit/tailwind-dot-grid-backgrounds) - CSSだけで容易にカスタマイズ可能なグリッド・ドットパターン背景を追加する`bg-grid`と`bg-dot`クラスを追加します。
- 💼 [Leading Trim](https://github.com/stormwarning/tailwindcss-capsize) - [Capsize](https://github.com/seek-oss/capsize)を使用し、テキストの空白をトリミングするユーティリティを追加します。
- 💼 [Scrollbar Hide](https://github.com/reslear/tailwind-scrollbar-hide) - スクロールバーを視覚的に非表示にする`scrollbar-hide`クラスを追加します。
- 💼 [px to viewport](https://github.com/the-lemonboy/tailwindcss-px-to-viewport) - pxをvw／vhへ自動変換するユーティリティを追加します。
- 💼 [tailwind-hitslop](https://github.com/Jubstaaa/tailwind-hitslop) - タッチターゲットを見えない形で広げる`hit-slop`ユーティリティを追加します。React Nativeの`hitSlop`と同様です。
- 💼 [tw-fade](https://github.com/petekp/tw-fade) - スクロールを認識した端部フェードを可能にする`fade-t`／`-b`／`-x`／`-y`ユーティリティを追加します。
- 💼🧩 [Fluid](https://github.com/barvian/fluid-tailwind) - 組み込みユーティリティすべての流動的な`clamp()`版を追加します。
- 🧩 [Debug screens](https://github.com/jorenvanhee/tailwindcss-debug-screens) - 現在アクティブな画面（レスポンシブブレークポイント）を表示するコンポーネントを追加します。
