# Awesome D3

D3を扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## チャート

- [billboard.js](https://github.com/naver/billboard.js) - 再利用可能なチャートライブラリ[bar、line、area、donut、pie、step、spline]。
- [britecharts](https://github.com/britecharts/britecharts) - クライアントサイドで再利用可能なチャートライブラリ[bar、line、donut、sparkline、step]。
- [chart-parts](https://github.com/Microsoft/chart-parts) - データ可視化向けの柔軟でReactフレンドリーなGrammar of Graphics。
- [cubism](https://github.com/square/cubism) - 時系列可視化。
- [c3](https://github.com/c3js/c3) - 再利用可能なチャートライブラリ[line、spline、step、area、stacked、bar、pie、donut]。
- [dagre-d3](https://github.com/dagrejs/dagre-d3) - クライアントサイドで有向グラフをレイアウトします。
- [dc.js](https://github.com/dc-js/dc.js) - 大量データ向け。
- [d2b](https://github.com/d2bjs/d2b) - axis、pie、sankey、sunburstチャート向けライブラリ。
- [d3-bar](https://github.com/tj/d3-bar) - 棒グラフ。
- [d3-beeswarm](https://github.com/Kcnarf/d3-beeswarm) - beeswarm配置を計算するプラグイン。
- [d3-boxplot](https://github.com/akngs/d3-boxplot) - d3jsの箱ひげ図プラグイン。
- [d3-bumps-chart](https://github.com/johnwalley/d3-bumps-chart) - bumpsチャートを可視化するプラグイン。
- [d3-dag](https://github.com/erikbrinkman/d3-dag) - 有向非巡回グラフを可視化するレイアウトアルゴリズム。
- [d3-ez](https://github.com/jamesleesaunders/d3-ez) - 容易に再利用できるD3チャート・コンポーネント[bar、donut、pie、bubble、rose、heatmap]。
- [d3-flame-graph](https://github.com/spiermar/d3-flame-graph) - 階層データからフレームグラフを作成します。
- [d3-funnel](https://github.com/jakezatecky/d3-funnel) - ファネル・ピラミッドチャートライブラリ。
- [d3-gridding](https://github.com/romsson/d3-gridding) - グリッドを使うチャートモックアップ。
- [d3-heatmap](https://github.com/tj/d3-heatmap) - ヒートマップ。
- [d3-message-sequence](https://github.com/koudelka/d3-message-sequence) - 動的・静的なメッセージシーケンスチャート。
- [d3-upset](https://github.com/chuntul/d3-upset) - UpSetプロットを描く関数[upset、bar、intersections、venn、relationships]。
- [d3-x3d](https://github.com/jamesleesaunders/d3-x3d) - D3とX3Dによるデータ駆動3Dチャート[bubble、bar、surfacearea、scatterplot、area]。
- [d3fc](https://github.com/d3fc/d3fc) - インタラクティブなチャートコンポーネントのコレクション[line、bar、stacked、scatter、candlestick、ohlc]。
- [d3plus](https://github.com/alexandersimoes/d3plus) - 可視化を容易に作成する拡張ライブラリ[scatter、stacked、line、bar、pie、network、bubble、box、map]。
- [d3panels](https://github.com/kbroman/d3panels) - 連結ブラッシングによるインタラクティブなチャート[dot、scatter、line、heatmap、histogram]。
- [d3pie](https://github.com/benkeen/d3pie) - 設定可能な円グラフライブラリ・ジェネレーター。
- [D3xter](https://github.com/NathanEpstein/D3xter) - 直接的なプロット[plot、timeline、bar、histogram、pie]。
- [D4](https://github.com/heavysixer/d4) - 再利用可能なチャートDSL[bar、donut、line、scatter、stacked、waterfall]。
- [dTree](https://github.com/ErikGartner/dTree) - 家系図ライブラリ。
- [EventDrops](https://github.com/marmelab/EventDrops) - 時間ベース・イベント系列のインタラクティブ可視化。
- [metrics-graphics](https://github.com/metricsgraphics/metrics-graphics) - 時系列データの可視化に最適化[line、scatter、area]。
- [micropolar](https://github.com/biovisualize/micropolar/) - 極座標チャートライブラリ。
- [mpld3](https://github.com/mpld3/mpld3) - matplotlibグラフィックをブラウザーで動作する形へエクスポートします。
- [neo4jd3](https://github.com/eisman/neo4jd3) - Neo4jグラフ可視化。
- [nvd3](https://github.com/novus/nvd3) - 再利用可能なチャート・チャートコンポーネント[box plot、buttlet、candlestick、line、bar、pie、scatter、sparkline]。
- [oecd-simple-charts](https://github.com/oecd-cyc/oecd-simple-charts) - シンプルなチャートライブラリ[box plot、stacked bar、pearl chart]。
- [plotly.js](https://github.com/plotly/plotly.js/) - 高水準チャートライブラリ[scatter、line、bar、pie、box plot、histogram、heatmap]。
- [plottable](https://github.com/palantir/plottable) - Web向けの柔軟でインタラクティブなチャート[area、bar、line、pie、scatter、stacked]。
- [rickshaw](https://github.com/shutterstock/rickshaw) - インタラクティブなリアルタイムグラフを作るツールキット[line、scatter、bar]。
- [taucharts](https://github.com/TargetProcess/tauCharts) - デザインと柔軟性に重点を置くチャート[line、bar、area、stacked]。
- [vega](https://github.com/vega/vega) - 可視化の文法。
- [vega-lite](https://github.com/vega/vega-lite) - インタラクティブグラフィックの高水準文法。
- [vega-lite-api](https://github.com/vega/vega-lite-api) - Vega-Lite向けJavaScript API。
- [venn.js](https://github.com/benfred/venn.js) - 面積比例のVenn・Euler図。
- [visavail](https://github.com/flrs/visavail) - 時間データの可用性可視化。
- [vizabi](https://github.com/vizabi/vizabi) - 視覚的データ探索ツールを構築するフレームワーク[bubble、map、line、bar、sankey、donut]。
- [WebCola](https://github.com/tgdwyer/WebCola) - グラフ可視化・探索向けレイアウト。
- [xkcdgraphs](https://github.com/imkevinxu/xkcdgraphs) - xkcdスタイルのグラフ[line]。

- [semiotic](https://github.com/nteract/semiotic) - ReactとD3を組み合わせたデータ可視化フレームワーク[scatter、line、area]。
- [victory](https://github.com/FormidableLabs/victory) - 可視化構築用の構成可能なReactコンポーネント[area、bar、candlestick、pie、line、scatter、voronoi]。
- [vx](https://github.com/hshoff/vx) - React向け可視化コンポーネント[bar、line、scatter、stacked、area、pattern、heatmap、pie、radial、map、geo]。
- [Vs](https://github.com/GopherJ/Vs) - Vue.js向け宣言的可視化コンポーネント[bar、line、area、pie、donut、stacked、sankey、timeline]。
- [v-chart-plugin](https://github.com/ignoreintuition/v-chart-plugin) - Vue.jsコンポーネント内に保存したデータへチャートを容易にバインドします。

## 地図

- [d3-composite-projections](https://github.com/rveciana/d3-composite-projections) - 国の離れた領土をまとめて表示する投影法。
- [datamaps](https://github.com/markmarkoh/datamaps) - 1ファイルで提供するカスタマイズ可能な地図可視化。
- [d3-topogram](https://github.com/shawnbot/topogram) - TopoJSONに基づく連続面積カルトグラム。
- [d3-exploder](https://github.com/bsouthga/d3-exploder) - 地理的フィーチャーを容易に移動・リサイズできます。
- [d3-geo-polygon](https://github.com/d3/d3-geo-polygon) - 球面多角形向けクリッピング・幾何演算。
- [d3-geo-projection](https://github.com/d3/d3-geo-projection) - 拡張地理投影。
- [d3-geo-scale-bar](https://github.com/HarryStevens/d3-geo-scale-bar) - 投影地理空間データ用の自動スケールバーを表示します。
- [d3-geo-voronoi](https://github.com/Fil/d3-geo-voronoi) - 球面向けVoronoi図・Delaunay三角分割。
- [d3-geomap](https://github.com/yaph/d3-geomap) - 地理地図を作成するライブラリ。
- [d3.geo2rect](https://github.com/sebastian-meier/d3.geo2rect) - GeoJSONポリゴンを矩形へモーフィングします。
- [d3-inertia](https://github.com/Fil/d3-inertia) - マウス移動を慣性付きで継続するd3-drag拡張。
- [mapmap.js](https://github.com/floledermann/mapmap.js) - インタラクティブ主題図向けのデータ駆動API。
- [maptable](https://github.com/Packet-Clearing-House/maptable) - データセットを視覚コンポーネント群（Map、Filters、Table）へ変換します。
- [simple-map-d3](https://github.com/MinnPost/simple-map-d3) - 容易なコロプレススタイル地図。
- [spam](https://github.com/newsappsio/spam) - D3とCanvasを使って地図を容易に作成します。
