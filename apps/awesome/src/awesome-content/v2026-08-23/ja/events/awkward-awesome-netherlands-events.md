## ロッテルダム
- [Makersclub](http://makersclubrdam.com/) - 隔月開催の、議題を設けない気軽な交流会。
- [EuRuKo](https://euruko2018.org/) - Ruby に関する年次ヨーロッパカンファレンス（2019 年）。
- [NodeSchool](http://www.meetup.com/nodeschool-rotterdam/) - Node.js を学ぶ月例ミートアップ。
- [Crowdsource](http://rdamsenieuwe.nl/thema/crowd-force) - スタートアップ向けのアイデアをクラウドソーシング。

## アムステルダム
- [Makersclub](http://makersclubams.com/) - 隔月開催の、議題を設けない気軽な交流会。
- [Hackers & Founders](https://www.meetup.com/Hackers-and-Founders-Amsterdam-NL/) - Cafe De Doffer で開催される月例ミートアップ。
- [The Next Web Conference](https://thenextweb.com/conference) - 最大規模の技術カンファレンス（5 月 18・19 日）。
- [AMSxTech](http://amsxtech.com/) - コミュニティ主導のカンファレンス（3 月 31 日）と月例ミートアップ。
- [FunctionConf](https://functionconf.io/) - サーバーレスアーキテクチャに関するカンファレンス（6 月 15・16 日）。
- [Amsterdam-rb](https://www.meetup.com/amsterdam-rb/) - 大規模イベントを頻繁に開催する活発な Ruby ミートアップ。
- [Amsterdam-Elixir](https://www.meetup.com/Amsterdam-Elixir) - 月例の Elixir ミートアップ。
- [Amsterdam-Rust](https://www.meetup.com/Rust-Amsterdam) - Rust をテーマにした月例ミートアップとワークショップ。
- [Lead Developers Amsterdam](https://www.meetup.com/Lead-Developers-Amsterdam) - リード開発者、テックリード、チャプターリード、リード職を目指すシニアエンジニア向け。
- [DevOps Day Amsterdam](https://www.devopsdays.org/events/2019-amsterdam/welcome/) - 開発、運用、QA、情報セキュリティ、マネジメント、リーダーシップ。
- [React Amsterdam](https://react.amsterdam) - React Amsterdam は、React 全般を扱う[ミートアップグループ](https://www.meetup.com/React-Amsterdam/)および終日カンファレンス（4 月 21 日）です。

## ユトレヒト
- [The Kick 030](http://www.thekick030.nl) - クリエイティブ産業についての講演を行う隔月イベント。
- [Creative Show-off](http://creativeshowoff.nl) - ビールを飲みながらアイデアやビジネスを発表。

## 各地
- [CocoaHeads](https://www.meetup.com/CocoaHeadsNL/) - iOS と MacOS 開発に関する月例ミートアップ。
- [CoderDojo](https://coderdojo.nl) - 7〜17 歳の子どもがコーディングを学ぶ月例ワークショップ。
- [Design by Fire Café](https://www.designbyfire.nl) - インタラクションデザインに関するカンファレンスと集会。
