# Awesome Qlik [![Awesome](https://awesome.re/badge.svg)](https://awesome.re) [<img src="https://webapps.qlik.com/WarsawMarathon/qlik.jpg" width="250" align="right" alt="Qlik ロゴ">](https://qlik.com)

> 優れた [Qlik](https://qlik.com) のガイド、ブログ、拡張機能、その他のリソースを厳選したリストです。

Qlik は、データ可視化、分析、レポート作成のソリューションを提供する[主要な](https://www.qlik.com/us/gartner-magic-quadrant-business-intelligence)ビジネスインテリジェンスプラットフォームです。同じエンジン上で動作する主力製品には、ガイド付き分析向けの [QlikView](https://www.qlik.com/us/products/qlikview) と、セルフサービス BI 向けの [Qlik Sense](https://www.qlik.com/us/products/qlik-sense) があります。

## コミュニティリソースとブログ

- [Living QlikView](http://livingqlikview.com/) - Aaron Couron によるブログ。詳細な記事、技術的なヒントやコツ、QlikView と Qlik Sense の活用に役立つサードパーティ製アプリケーションやリソースのレビューを掲載。
- [Qlik Community](https://community.qlik.com) - Qlik プラットフォームの製品フォーラム、リソース、サービス、イベント、グループ、ブログ。
- [QlikCentral](https://qlikcentral.com/) - Richard Pearce が QlikView と Qlik Sense で培った知見や技術例を共有するブログ。
- [QlikFix](http://www.qlikfix.com) - Barry Harmsen による QlikView と Qlik Sense のヒント、コツ、チュートリアル専門ブログ。
- [QlikView Cookbook](https://qlikviewcookbook.com/) - Rob Wunderlich による QlikView 開発者向けの技術的なハウツーブログ。
- [Qlik Tips](https://www.qliktips.com) - Stephen Redmond による Qlik 全般のブログ。
- [Quick Intelligence](https://www.quickintelligence.co.uk/blog/) - Steve Dark 率いる熟練 Qlik 開発者チームが、Qlik Sense と QlikView の利用上のヒントを紹介するブログ。
- Reddit のサブレディット：
  - [/r/Qlik](https://www.reddit.com/r/qlik/) - Qlik に関するサブレディット。
  - [/r/QlikSense](https://www.reddit.com/r/qliksense/) - Qlik Sense に関するサブレディット。
  - [/r/QlikView](https://www.reddit.com/r/qlikview/) - QlikView に関するサブレディット。
