### [Learning Go: An Idiomatic Approach to Real-World Go Programming, 2nd Edition](https://amzn.to/4ceJWWQ)

*最終更新日*: **2024**
*著者*: **Jon Bodner**

<a href="https://amzn.to/4ceJWWQ"><img src="https://raw.githubusercontent.com/dariubs/GoBooks/663df50585267768595a41f69c1c1d959c8a7650/gobooks/covers/learning-go.jpg" width="120px"/></a>

Goは急速にウェブサービスの開発に最も好まれる言語となっている。他のプログラミング言語を経験した開発者にGoの文法を教えるチュートリアルはたくさんあるが、それだけでは不十分である。Goの慣習（idioms）を教えないため、開発者はGoの文脈に合わないパターンを再構築してしまう。この実用的なガイドは、明確でGoらしいコードを書くために必要な基本的な知識を提供する。

あなたの経験レベルに関わらず、Go開発者としての思考方法を学べる。著者Jon Bodnerは、経験のあるGo開発者が採用した設計パターンを紹介し、それらのパターンを使う理由を検討する。この更新版では、Goのジェネリクスサポートが言語全体にどのように組み込まれているかを示す。

この書籍は、あなたに以下のことをサポートします：

- Write idiomatic code in Go and design a Go project
- Understand the reasons behind Go's design decisions
- Set up a Go development environment for a solo developer or team
- Learn how and when to use reflection, unsafe, and cgo
- Discover how Go's features allow the language to run efficiently
- Know which Go features you should use sparingly or not at all
- Use Go's tools to improve performance, optimize memory usage, and reduce garbage collection
- Learn how to use Go's advanced development tools
