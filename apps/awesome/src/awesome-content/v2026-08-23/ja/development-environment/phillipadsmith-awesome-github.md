# Awesome GitHub

GitHubを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## GitHubを初めて使う人向けの情報
- [Code School's Try Git](https://try.github.io/levels/1/challenges/1) - GitHubを可能にする技術の一つであるGitをより深く理解したい人に最適な出発点。GitHubアカウントは不要です。
- [Git-it](https://github.com/jlord/git-it) -- :computer: :mortar_board: GitとGitHubを学ぶためのワークショップ。
- [On-Demand GitHub Training](https://services.github.com/on-demand/) - GitHubのTrainingチーム自身が作成・維持する、自分のペースで進める対話的なプロジェクト。
- [Bingo Board](https://github.com/muan/bingo-board) -- プルリクエストを送ってビンゴ:boom:を遊ぶ。
- [Writing on GitHub](https://help.github.com/articles/writing-on-github/) - ソフトウェア開発だけでなくGitHubを使うためのGitHub公式ガイド。
- [GitHubGuides](https://www.youtube.com/user/GitHubGuides) - YouTube上のGitHub Training & Guides。
- [GitHub Pages](https://pages.github.com/) - あなたとあなたのプロジェクトのためのウェブサイト。
GitHubリポジトリから直接ホストされます。編集してpushするだけで変更が反映されます。
- GitHubが魔法をかけられるファイル形式:
  - [GeoJSON/TopoJSON](https://github.com/blog/1528-there-s-a-map-for-that) - GeoJSONファイルをリポジトリへ追加すると即座に[地図をレンダリング](https://github.com/benbalter/dc-maps/blob/master/maps/embassies.geojson)。
  - [iPython/Jupyter](https://github.com/blog/1995-github-jupyter-notebooks-3) - GitHubはブラウザーで`ipynb`ファイルもレンダリングします。[可能性は無限です](https://github.com/ipython/ipython/wiki/A-gallery-of-interesting-IPython-Notebooks)。
  - [PDF](https://github.com/blog/1974-pdf-viewing) - ブラウザーでPDFを表示。
  - [STL files](https://github.com/blog/1465-stl-file-viewing) - ブラウザー内で驚くべき3D表示。
  - [CSV](https://github.com/blog/1601-see-your-csvs) - データジャーナリストや市民データ愛好者に朗報。ブラウザーでカンマ区切り値を扱えます。
  - [SVG](https://github.com/blog/1902-svg-viewing-diffing) - ブラウザーでスケーラブルベクターグラフィックスを表示できるだけでなく、版間の差分を視覚的に確認できます。（実際には[ほとんどの画像ファイルで可能です](https://github.com/blog/817-behold-image-view-modes)。）
  - [PSD](https://github.com/blog/1845-psd-viewing-diffing) - SVGと同じ考え方をPhotoshopファイルに適用します。
- [GitHub Government Community](https://github.com/government/welcome) - [government community](https://government.github.com/)へ参加するための情報。オープンソース、オープンデータ、オープンガバメントを進めるベストプラクティスを共有する協働コミュニティです。
- [Classroom for GitHub](https://classroom.github.com) - GitHub上でのコース課題。
- [MOOC in Spanish](https://miriadax.net/web/gitmooc) - マドリード工科大学によるスペイン語の入門MOOC。

## GitHubに既に慣れた人向けのリソース

- [GitHub Cheat Sheet](https://github.com/tiimgreen/github-cheat-sheet) - このリストでGitHubの知識を試せます。
- [GitHub Universe](http://githubuniverse.com/) - GitHubが紹介する、優れたソフトウェアを構築、協働、デプロイするための丸2日間。2015年10月1・2日、サンフランシスコ。
- [GitHub Desktop](https://desktop.github.com/) - デスクトップからのシンプルな協働。
- [Atom](https://github.com/blog/2031-announcing-atom-1-0) - GitHubがエディターも作っていることを知っていますか。執筆、コーディングなどに使えます。
- [Electron](http://electron.atom.io/) - ウェブ技術でクロスプラットフォームのデスクトップアプリを構築。
- [GitHub Buttons](https://ghbtns.com/) - ホットリンク可能なGitHubスター、フォーク、フォローボタンでリポジトリの成功を紹介。
- [Resume](http://resume.github.io/) - GitHubを使って生成する履歴書。
- [Speaker Deck](https://speakerdeck.com/) - GitHubによる、雑然としないプレゼンテーション共有。
- [Blocks](http://bl.ocks.org/) - GitHub Gistでホストしたコード例のシンプルなビューアー。（紹介は[こちら](http://bost.ocks.org/mike/block/)）
- [Block Builder](http://blockbuilder.org/) - D3.jsの例をすばやく作成、編集、フォーク。
- [GitHub Template Guidelines](https://github.com/cezaraugusto/github-template-guidelines) - GitHubプロジェクト向けテンプレートファイルを作るためのガイドライン。

## GitHubパワーユーザー向けのヒント、コツ、ツール、アドオン

- [Pull Dog](https://github.com/apps/pull-dog) - プルリクエスト向け自動テスト環境。
- [GitHub Integrations Directory](https://github.com/integrations) - お気に入りのツールをGitHubと使う。
- [GitHub Cheat Sheet](https://github.com/tiimgreen/github-cheat-sheet) - このリストでGitHubの知識を試せます。（非常に優れたリソースなので二度挙げる価値があります。）
- [A collection of awesome browser extensions for GitHub.](https://github.com/stefanbuck/awesome-browser-extensions-for-github) - リンクの名前がすべてを語っています。
- [Gitter](https://gitter.im/) - GitHub向けチャット。無制限のパブリックルームと一対一チャットを無料で提供。
- [Zenhub](https://www.zenhub.com/) - かんばんボードなどを含むGitHub内のプロジェクト管理。
- [HuBoard](https://huboard.com/) - GitHub issue向けの即時プロジェクト管理（無料プランはありませんが、[オープンソース](https://github.com/huboard/huboard-web)のようです）。
- [Overv.io](https://overv.io/) - GitHubを愛するチーム向けアジャイルプロジェクト管理。かんばんボードなどを提供。
- [Penflip](https://www.penflip.com/) - GitLab（GitHubに類似）を利用する共同執筆とバージョン管理。
- [Gitbook](https://www.gitbook.com/) - アイデアから完成した洗練された書籍へ導くモダンな出版ツールチェーン。
- [Prose](http://prose.io/#about) - [CMSなしウェブサイト](https://developmentseed.org/blog/2012/07/27/build-cms-free-websites/)向けの、美しくシンプルなコンテンツ制作環境。GitHub上のコンテンツを管理するウェブベースのインターフェースです。
- [Redliner](https://github.com/benbalter/redliner) - GitHubに不慣れな人との文書の見消し編集を容易にするツール。
- [Gatekeeper](https://github.com/prose/gatekeeper) - クライアント側アプリケーションでGitHub OAuthを扱えるようにします。
- [github-secret-keeper](https://github.com/HenrikJoreteg/github-secret-keeper) - 複数のサーバーレスアプリケーションでGitHubログインを有効にするマイクロサービス。
- [Hub](https://github.com/github/hub) - gitをラップして、GitHubでの作業を容易にする追加機能とコマンドを提供するコマンドラインツール。
- [Ghizmo](https://github.com/jlevy/ghizmo) - すべてのAPIへアクセスできるGitHub向けコマンドライン。
- [cli-github](https://github.com/harshasrinivas/cli-github) - コマンドライン内でGitHubをきれいに扱うツール。
- [GitHub Dark](https://github.com/StylishThemes/Github-Dark) - GitHub向けの洗練されたダークテーマ。
- [github-issues-import](https://github.com/IQAndreas/github-issues-import) - issueとプルリクエストを一つのGitHubリポジトリから別のリポジトリへインポートできるPythonスクリプト。
- [Github-Auto-Issue-Creator](https://github.com/Ricky54326/Github-Auto-Issue-Creator) - GitHubリポジトリをローカル検索してTODO文のissueを自動作成し、追跡し続けるPythonスクリプト。
- [Problem Child](https://github.com/benbalter/problem_child) - 認証済み・匿名の利用者が標準ウェブフォームからGitHub issue（およびプルリクエスト）を作成できます。
- [gitify](http://gitify.io/) - すべてのGitHub通知をメニューへ表示。
- [HubPress](https://github.com/HubPress/hubpress.io) - GitHub上でブログを構築するウェブアプリケーション。
- [TinyPress](https://github.com/kehers/tinypress) - GitHub上でブログを公開する最も簡単な方法。
- [Issue and Pull Request Template Generator](https://www.talater.com/open-source-templates/) - CthulhuとLewis Carrollの助けを借りて、プロジェクト向けにカスタマイズしたテンプレートを生成。
- [Noteit](https://github.com/Krukov/noteit) - GitHub Gistを使いCLIでメモを管理。
- [Zappr](https://github.com/zalando/zappr) - プルリクエスト承認のボトルネックを除き、開発チームがコンプライアンス要件を無理なく守れる無料・オープンソースGitHub統合。
- [Migrating to Git LFS](http://vooban.com/en/tips-articles-geek-stuff/migrating-to-git-lfs-for-developing-deep-learning-applications-with-large-files/) - Gitプロジェクトの巨大ファイルを容易に管理。データサイエンスプロジェクトに有用です。
- [Gitential.com](https://gitential.com) - プロジェクト、チーム、リポジトリ、個々の開発者のコーディング時間、生産性、効率を測定・可視化。
- [Octotree](https://www.octotree.io/) - GitHubのコード閲覧とプルリクエストレビューを改善するブラウザー拡張。Chrome、Firefox、Opera、Safariで利用可能。
- [FeatHub](https://feathub.com/) - GitHub向け機能投票。
- [multi-gitter](https://github.com/lindell/multi-gitter) - 複数のリポジトリを一括更新。
