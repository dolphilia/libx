# Awesome Imba [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome) [![GitHub contributors](https://img.shields.io/github/contributors/koolamusic/awesome-imba)](#contributors)

> 優れたImbaのフレームワーク、ライブラリ、ソフトウェア、リソースを集めたリスト。

ImbaはRubyとPythonに着想を得たプログラミング言語で、組み込みのトランスパイラとwebpack loaderにより、高性能で読みやすいJavaScriptへコンパイルされます。

#### ツールキットとフレームワーク

- [Start Imba](https://github.com/athif23/start-imba) - Create React AppとVue CLIに着想を得た、Imbaプロジェクトをブートストラップするツール。
- [Hello World Imba](https://github.com/imba/hello-world-imba) - 公式のImba「Hello World」例。GitHubテンプレートとしても使える。
- [Imba Router](https://github.com/somebee/imba-router) - Imba向けの実験的なルーター。
- [UXA](https://github.com/somebee/uxa) - Imba向けの実験的なフレームワーク。
- [Parcel Plugin Imba](https://github.com/imba/parcel-plugin-imba) - Imbaファイルの処理を有効にする[Parcel Bundler](https://parceljs.org/)プラグイン。
- [Material Imba](https://github.com/nathanjohnson320/material-imba) - Imbaで書かれたMaterial Designコンポーネント。
- [Imba Inertia Adapter](https://github.com/haikyuu/imba-inertia-adapter) - Imba用の[Inertia](https://inertiajs.com)アダプター。
- [Formidable](https://www.formidablejs.org/) - 迅速なAPI開発のためのImbaフレームワーク。
- [Imba Shell](https://github.com/donaldp/imba-shell) - Imba向けの対話式デバッガーとREPL。

#### エディタープラグインとIDE

- [Atom](http://github.com/somebee/language-imba) - Atom向けのImbaプラグイン。
- [Sublime Text](http://github.com/somebee/sublime-imba) - Sublime向けのImbaプラグイン。
- [VSCode](http://github.com/somebee/vscode-imba) - VSCode向けのImbaプラグイン。


#### ガイドとチュートリアル

- [Official Guide](https://imba.io/guides)
- [Imba more depth Guide](https://imba.github.io/imba-guide/)
- [Hello World Imba Tutorial](https://github.com/jiggneshhgohel/hello-world-imba-tutorial) - Node.js、Imba、Webpackで「Hello World」アプリを作る手順を詳述したチュートリアル。
- [Why is Imba so fast?](https://scrimba.com/p/pJkZsB/c6B9rAM) - Imbaが高速な理由と仕組みを学び、実際に試せる。
- [Quick introduction to Imba Router](https://scrimba.com/playlist/pMvYcg) - Imbaでimba-routerがどのように動くかを学ぶ。
- [Creating a todo-list app in Imba](https://scrimba.com/p/pDzDSZ/cRvRMSB) - Imbaでより速く、より簡単にアプリを作成する方法を学ぶ。


#### 記事

- [An Intro to Imba: the JavaScript-compatible language for lightning fast DOM updates - freeCodeCamp](https://medium.freecodecamp.org/introduction-to-imba-the-alternative-to-javascript-e2aa1e3d1769)
- [New JavaScript-based Web Language Challenges React - ADTMag](https://adtmag.com/articles/2016/01/14/imba-web-language.aspx)


## Imbaで構築

#### 実世界のアプリ

- [Scrimba](http://scrimba.com) - 対話型スクリーンキャスティングプラットフォームScrimba.comは、フロントエンドとバックエンドの両方がImbaで書かれている。
- [Iceland Fish Auction Market](https://rsf.is) - アイスランドの魚市場向けウェブサイト。
- [GitSpeak](https://gitspeak.com) - 開発者向けのプロジェクト管理ツール。


#### ツール

- [html2imba](https://github.com/konsumer/html2imba) - [view online](http://konsumer.js.org/html2imba/) - HTMLをImbaタグソースへ変換するツール。
- [JSON pretty printer](https://github.com/taw/imba-json-beautifier) - [view online](https://taw.github.io/imba-json-beautifier) - JSON整形ツール。
- [Monoalphabetic Cipher Decoder](https://github.com/taw/imba-monoalphabetic) - [view online](https://taw.github.io/imba-monoalphabetic) - 単一換字暗号のデコーダー。
- [RegExp Explorer](https://github.com/taw/imba-regexp-explorer) - [view online](https://taw.github.io/imba-regexp-explorer) - 正規表現ツール。


#### アプリ／ウェブサイト

- [Imba Todo MVC](https://github.com/somebee/todomvc-imba) - Imba TodoMVCの例。
- [Other Todo MVC](https://github.com/shapkarin/imba-todo) - [view online](https://shapkarin.github.io/imba-todo/) - [tastejs/todomvc](https://github.com/tastejs/todomvc)のルールに従うTodoMVC実装。
- [Simple Todo](https://github.com/taw/imba-todo-list) - [view online](https://taw.github.io/imba-todo-list) - より基本的なTodoリストアプリ。
- [Imba Realworld App](https://github.com/cartonalexandre/imba-realworld-example-app) - [view online](https://imba-realworld-example-app.netlify.com/) - [RealWorld](https://github.com/gothinkster/realworld)の仕様とAPIに従う、本格的なフルスタックアプリケーションを実演するために作成されたプロジェクト。
- [Imba HackerNews Clone](https://github.com/SamirHodzic/imba-capacitor-hn) - Hacker Newsクローンの構築にImbaとCapacitorを使う実例。
- [2048 Game](https://github.com/taw/imba-2048) - [view online](https://taw.github.io/imba-2048) - 2048ゲーム。
- [Calculator](https://github.com/taw/imba-calculator) - [view online](https://taw.github.io/imba-calculator) - 電卓。
- [Emoji Memory Game](https://github.com/taw/imba-emoji-memory) - [view online](https://taw.github.io/imba-emoji-memory) - メモリーゲーム。
- [Eyes](https://github.com/taw/imba-eyes) - [view online](https://taw.github.io/imba-eyes) - クールなインタラクションを備えたウェブサイト。
- [Fifteen Puzzle](https://github.com/taw/imba-fifteen) - [view online](https://taw.github.io/imba-fifteen) - 15パズル。
- [Game of Life](https://github.com/taw/imba-game-of-life) - [view online](https://taw.github.io/imba-game-of-life) - ライフゲーム。
- [Matrix Rain](https://github.com/taw/imba-matrix-rain) - [view online](https://taw.github.io/imba-matrix-rain) - マトリックス風の雨のアニメーション。
- [Quote Machine](https://github.com/taw/imba-quote-machine) - [view online](https://taw.github.io/imba-quote-machine) - ランダムな引用を生成するアプリ。
- [ROT-N](https://github.com/taw/imba-rotn) - [view online](https://taw.github.io/imba-rotn) - ROT-Nアプリ。
- [Snake Game](https://github.com/taw/imba-snake) - [view online](https://taw.github.io/imba-snake) - スネークゲーム。
- [Weather App](https://github.com/taw/imba-weather) - [view online](https://taw.github.io/imba-weather) - 天気アプリ。
- [Top Down Shooter](https://github.com/CassianoSF/imba-top-down-shooter) - [view online](https://cassianosf.github.io/imba-top-down-shooter/dist/index.html) - 2Dゾンビシューティングゲーム。
- [Ping CRM](https://github.com/haikyuu/perfect-stack) - ログイン、アカウント、組織、連絡先の管理を備えたCRUDアプリ。Inertia、Edgedb、Imbaで構築。
