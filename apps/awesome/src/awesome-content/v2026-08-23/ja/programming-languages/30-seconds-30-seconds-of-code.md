# 30 seconds of code

> 開発スキルを一段高めるコーディング記事

* すべての記事を見るには、[ウェブサイト](https://30secondsofcode.org)を訪れてください。
* 名前、タグ、言語、説明を使って、ニーズに合う記事やコレクションを検索できます。
* 全[記事](https://30secondsofcode.org/snippets/p/1)、またはトピック別の[コレクション](https://30secondsofcode.org/collections/p/1)を閲覧できます。
* 各カードをクリックすると、コードスニペット、解説、使用例を含む記事全体を表示できます。
* このプロジェクトを気に入ったら、スターを付けてください。大きな励みになります。

## 貢献したい方へ

* 現在、新規コンテンツの提供は受け付けていません。
* ただし、[Issue を作成](https://github.com/Chalarangelo/30-seconds-of-code/issues/new).
