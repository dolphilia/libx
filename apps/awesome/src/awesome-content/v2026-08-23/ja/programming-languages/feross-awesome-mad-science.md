# Awesome Mad Science

Mad Scienceを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## ピアツーピア
- [peerwiki](https://www.npmjs.com/package/peerwiki) - BitTorrent 上に Wikipedia 全体を配置
- [simple-peer](https://www.npmjs.com/package/simple-peer) - ブラウザーで動画・音声・データを P2P 送信（WebRTC 使用）
- [torrent-docker](https://www.npmjs.com/package/torrent-docker) - BitTorrent 経由でリモート Docker イメージをリアルタイム起動
- [torrent-mount](https://www.npmjs.com/package/torrent-mount) - Torrent をファイルシステムとしてマウント
- [webtorrent](https://www.npmjs.com/package/webtorrent) - Node とブラウザー向けのストリーミング Torrent クライアント

## Browserify
- [brfs](https://www.npmjs.com/package/brfs) - `fs.readFileSync()` 呼び出しをインラインの静的アセットへ変換
- [browser field spec](https://gist.github.com/defunctzombie/4339901) - モジュールをブラウザー向けにバンドルするとき、特定のファイルやモジュールを置換
- [browserify](https://npmjs.org/package/browserify) - ブラウザーで `require()` を使用
- [glslify](https://github.com/stackgl/glslify) - npm モジュールを WebGL シェーダーへコンパイル
- [webworkify](https://www.npmjs.com/package/webworkify) - Browserify 向けの合成可能な Web Worker

## ファイル
- [file-type](https://www.npmjs.com/package/file-type) - マジックナンバーを検査してファイルの内容種別を検出
- [fuse4js](https://www.npmjs.com/package/fuse4js) - JavaScript でファイルシステムドライバーを記述

## 幾何学
- [alpha-shape](https://www.npmjs.com/package/alpha-shape) - 任意次元のアルファシェイプ（「凹」包を想定）
- [box-intersect](https://www.npmjs.com/package/box-intersect) - 任意次元の直方体交差を高速検出
- [convex-hull](https://www.npmjs.com/package/convex-hull) - 堅牢な任意次元の凸包
- [delaunay-triangulate](https://www.npmjs.com/package/delaunay-triangulate) - 堅牢な任意次元のドロネー三角形分割
- [surface-nets](https://www.npmjs.com/package/surface-nets) - 任意次元のレベル集合を抽出
- [voronoi-diagram](https://www.npmjs.com/package/voronoi-diagram) - 任意次元のボロノイ図
- [voxelize](https://www.npmjs.com/package/voxelize) - メッシュをボクセル化

## ハードウェア
- [cylon](https://www.npmjs.com/package/cylon) - Node からロボットやデバイスなどを制御

## 画像
- [indico.io](https://www.npmjs.com/package/indico.io) - 顔の感情認識と顔特徴の抽出
- [trackingjs](https://trackingjs.com/) - ウェブ上のコンピュータービジョン

## 音声
- [doppler](https://github.com/DanielRapp/doppler) - マイクとスピーカーだけを使い、ドップラー効果で動きを検出
- [speak.js](https://github.com/mattytemple/speak-js) - ウェブ上のテキスト読み上げ

## ストリーム
- [strip-html](https://www.npmjs.com/package/strip-html) - ストリームから HTML を除去

## テキスト
- [diff](https://www.npmjs.com/package/diff) - テキストの差分を表示
- [franc](https://www.npmjs.com/package/franc) - テキストの言語を検出
- [indico.io](https://www.npmjs.com/package/indico.io) - 政治的感情分析
- [node-tesseract](https://www.npmjs.com/package/node-tesseract) - Tesseract OCR パッケージのシンプルなラッパー
- [normit](https://www.npmjs.com/package/normit) - Google でテキストを翻訳して読み上げ
- [ocrad.js](https://www.npmjs.com/package/ocrad.js) - Emscripten を介して JavaScript で OCR
- [pullquoter](https://www.npmjs.com/package/pullquoter) - 記事から興味深い引用を抽出
- [sbd](https://www.npmjs.com/package/sbd) - テキストを文に分割
- [sentiment](https://www.npmjs.com/package/sentiment) - 基本的な感情分析

## ターミナル
- [minimist](https://www.npmjs.com/package/minimist) - シンプルな引数パーサー
- [progress](https://www.npmjs.com/package/progress) - シンプルなターミナル進捗バーを作成
- [terminal-menu](https://www.npmjs.com/package/terminal-menu) - レトロなターミナルメニューを作成
- [vantage.js](https://github.com/dthree/vantage) - Node 向け CLI + SSH + REPL
- [cash](https://github.com/dthree/cash) - 純粋な ES6 によるクロスプラットフォームの Linux コマンド

## 仮想マシン
- [jsemu](https://github.com/fcambus/jsemu) - JavaScript で書かれたエミュレーターのリスト
- [jslinux](https://www.npmjs.com/package/jslinux) - Linux を実行する JavaScript 製 x86 エミュレーター
- [jvm](https://www.npmjs.com/package/node-jvm) - 純粋な Node.js 製 Java 仮想マシン
- [doppio](https://github.com/plasma-umass/doppio) - TypeScript で書かれ、活発に更新されている Node.js 上の JVM

## その他
- [bell.js](https://www.npmjs.com/package/bell.js) - 周期的な時系列の異常をリアルタイム検出。
- [bitcoinjs-lib](https://www.npmjs.com/package/bitcoinjs-lib) - Node とブラウザー向け Bitcoin クライアント
- [fastparallel](https://www.npmjs.com/package/fastparallel) - オーバーヘッドなしの並列関数呼び出し
- [google-distance](https://www.npmjs.com/package/google-distance) - Google Maps API を使い、地球上の2地点間の移動距離を計算
- [qr-image](https://www.npmjs.com/package/qr-image) - QR コードを生成

## メタプログラミング

- [notevil](https://www.npmjs.com/package/notevil) - JavaScript 製 JavaScript インタープリター。信頼できないコードを安全に実行するのに便利。
