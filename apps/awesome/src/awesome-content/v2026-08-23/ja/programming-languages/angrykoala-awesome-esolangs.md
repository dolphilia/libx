# Awesome Esolangs [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

<img src="logo_piet.png" align="right">

優れた難解プログラミング言語、リソース、関連プロジェクトを集めたリスト。


> 「難解プログラミング言語、またはesolangとは、実用のためではなく、奇妙な考えを実験したり、プログラミングを困難にしたり、あるいは冗談として設計されたコンピュータプログラミング言語である。」  
> ***esolang.org***

## 言語

* [><>](https://esolangs.org/wiki/fish) - リフレクションをサポートする、スタックベースの2次元言語。
* [1+](https://esolangs.org/wiki/1%2B) - 命令セットが極めて限定されているにもかかわらず、驚くほど使いやすい言語。
* [78](https://github.com/oatmealine/78) - 数字の7と8を中心にした、単一文字コマンド言語。
* [ajsone](https://www.quaxio.com/ajsone) - 完全にJSONで定義される言語。
* [AlmostBinary](https://github.com/wsdt/AlmostBinary) - バイナリでコードを書き、あらゆるプラットフォームで実行する。
* [ArnoldC](http://lhartikk.github.io/ArnoldC) - Arnold Schwarzeneggerの最高のワンライナーに基づく。
* [Befunge](https://esolangs.org/wiki/Befunge) - 二次元言語。
* [Benedictum](https://github.com/Beneking102/benedictum) - ソースコードが祈りのように読める、ラテン語テーマのBrainfuck派生言語。
* [Brackets](https://github.com/kvbc/brackets) - 括弧でできた言語。とにかくたくさんの括弧。
* [Brainfuck](https://esolangs.org/wiki/Brainfuck) - 8つの単一文字コマンドだけを使うミニマリスト言語。
* [C Flat](https://github.com/NicksterSand/Cflat) - 表記よりも音に焦点を置き、創造の自由を念頭に置いた音楽言語。
* [CellTail](https://github.com/mousetail/celltail) - 1次元セル・オートマトンに基づく言語。複雑なパターンマッチング構文をサポートする。
* [Charcoal](https://github.com/somebody1234/Charcoal) - ASCIIアートをスケッチするための簡潔な言語。
* [Chef](http://www.dangermouse.net/esoteric/chef.html) - 料理のレシピのように見えるプログラム。
* [Chicken](https://esolangs.org/wiki/Chicken) - 有効な記号は'chicken'のみ。
* [ChuckScript](https://github.com/angrykoala/chuckscript) - コードが単一の数値となる、単項演算ベースの言語。
* [COW](https://esolangs.org/wiki/COW) - 12種類の*moos*を命令として使うBrainfuckの変種。
* [DNA#](https://esolangs.org/wiki/DNA-Sharp) - DNAの構造に基づく言語。
* [Dots](https://github.com/josconno/dots) - "."記号だけを使うチューリング完全な言語。
* [Electra](https://github.com/DolphyWind/Electra-Lang) - 電気技師のように書くコード。
* [Emojicode](http://www.emojicode.org) - 絵文字で構成された本格的なプログラミング言語。
* [Enterprise™](https://github.com/joaomilho/Enterprise) - 不必要に静的型付けされた非決定性言語。
* [False](http://strlen.com/false-language) - 最小限の実装を持つ、強く難読化された言語。
* [Fetlang](https://github.com/Property404/fetlang) - ソースコードが下手に書かれたフェティッシュなエロティカのように見えるよう設計されている。
* [FlipJump](https://github.com/tomhea/flip-jump) - 1つの命令: ビットを反転し、ジャンプする。最も単純なOISC。
* [Folders](https://github.com/rottytooth/Folders) - フォルダーで書かれたコード。
* [FreakC](https://github.com/FreakC-Foundation/FreakC) - NSFWコンテンツとミームを含む本格的なプログラミング言語。
* [Fugue](https://esolangs.org/wiki/Fugue) - ソースコードとしての音楽。
* [Golfscript](http://www.golfscript.com/golfscript) - 可能な限り少ないキーストロークで問題を解くことを目指す、スタック指向言語。
* [Haifu](http://www.dangermouse.net/esoteric/haifu.html) - 東洋哲学の中核的な価値観を念頭に置いて設計されている。
* [INTERCAL](http://www.catb.org/~esr/intercal) - 他の言語と完全に異なることを意図したパロディ言語。
* [Japt](https://github.com/ETHproductions/japt) - ゴルフ向けに縮小したJavaScript。
* [Jelly](https://github.com/DennisMitchell/jellylanguage) - Jに基づくゴルフ言語。
* [JellyScript](https://github.com/nguyenphuminh/Jellyscript) - おいしいゼリーを備えたBrainfuckベースの言語。
* [JSFuck](https://github.com/aemkei/jsfuck) - JavaScriptの原子的構成要素に基づく難解プログラミングスタイル。
* [Lazy K](https://tromp.github.io/cl/lazy-k.html) - 余分な機能を持たない、最小限でチューリング完全な純粋関数型言語。
* [legit](https://morr.cc/legit) - 内容ではなくgitリポジトリのグラフだけで完全に定義されるプログラム。
* [LolCode](http://lolcode.org) - lolcatミームの表現に基づくキーワードを持つ言語。
* [Malbolge](https://esolangs.org/wiki/Malbolge) - 地獄の第8層にちなんで名付けられ、可能な限りプログラミングが困難になるよう設計されている。
* [Mindfck](https://github.com/angrykoala/mindfck) - Brainfuckへトランスパイルする高水準言語。
* [Monicelli](https://github.com/esseks/monicelli) - イタリア語風の意味のない言葉を使ったプログラミング。
* [Ni](https://github.com/DeybisMelendez/ni) - より有用な命令を持つBrainfuckベースの言語。
* [Omgrofl](https://esolangs.org/wiki/Omgrofl) - インターネットスラングに似た構文。
* [Ook!](http://www.dangermouse.net/esoteric/ook.html) - コマンドにオランウータンの言葉を用いるBrainfuckベースの言語。
* [Orca](https://hundredrabbits.itch.io/orca) - 手続き型オーディオシーケンサーをすばやく作るためのライブコーディング環境。
* [Piet](http://www.dangermouse.net/esoteric/piet.html) - 色をコードとして用いる抽象画のように見えるプログラムの言語。Piet Mondrianに由来する。
* [RASEL](https://github.com/Nakilon/rasel) - プログラム空間と浮動小数点精度に制限がなく、スタックへの多少のランダムアクセスを備えたFungeoid。
* [reMorse](http://esolangs.org/wiki/reMorse) - モールス信号風の言語。
* [Rockstar](https://github.com/dylanbeattie/rockstar) - 歌詞でもあるコンピュータプログラムを作成するために設計されている。
* [Shakespeare](http://shakespearelang.sourceforge.net) - コードがシェイクスピア劇のように見える言語。
* [Schoenberg](https://tomeraberba.ch/schoenberg) - MIDIの難解プログラミング言語。
* [Spooky](https://spookylang.com) - 最も怖いプログラミング言語。:jack_o_lantern: :skull:。
* [Suzy](https://github.com/gvx/suzy) - Befungeに着想を得た3D言語。
* [Technologic](https://esolangs.org/wiki/Technologic) - プログラムがDaft Punkの曲Technologicの歌詞のように見える言語。
* [Thue](https://github.com/jcolag/Thue) - semi-Thue文法の非決定的文字列書き換えに基づく*Matrioshka*言語。
* [Tru](https://github.com/sungwoncho/tru) - 接頭辞自由な括弧を持つスタックベースの言語。
* [Turtle](https://github.com/TypeMonkey/Turtle) - メモリ用途に長期ストレージを使用する。
* [Unary](https://esolangs.org/wiki/Unary) - すべてのコマンドが0であるBrainfuckベースの言語。
* [Unary Except Every Zero Is Replaced with the Title of This Programming Language or, Alternately, Is Replaced with the Smallest Counter-Example to the Goldbach Conjecture. Compilers and Interpreters Only Have to Implement the Former Option](https://esolangs.org/wiki/Unary_Except_Every_Zero_Is_Replaced_with_the_Title_of_This_Programming_Language_or,_Alternately,_Is_Replaced_with_the_Smallest_Counter-Example_to_the_Goldbach_Conjecture._Compilers_and_Interpreters_Only_Have_to_Implement_the_Former_Option) - すべてのゼロを、説明中のプログラミング言語のタイトルに置き換えるUnaryの派生言語。
* [Unlambda](http://www.madore.org/~david/programs/unlambda) - 難読化された関数型プログラミング。
* [Velato](http://velato.net) - MIDIファイルをソースとして使う言語。プログラムは音符のピッチと順序で定義される。
* [Vigil](https://github.com/munificent/vigil) - プログラム仕様を満たせないコードを許さないことについて、本当に警戒しているのはVigilだけ。
* [Watson](https://github.com/genkami/watson) - スタックベースでチューリング不完全な設定ファイル。
* [文言 (Wenyan)](http://wenyan-lang.lingdong.works) - 古典中国文学の文法と文体に密接に従う。
* [Whenever](http://www.dangermouse.net/esoteric/whenever.html) - 好きなときに好きなことをする言語。
* [Whitespace](http://web.archive.org/web/20150623025348/http://compsoc.dur.ac.uk/whitespace) - 空白文字（スペース、タブ、改行）だけを使用する。
* [WordLang](https://github.com/WilliamRagstad/WordLang) - 出力を生み出す、意味に似た文法に基づく言語。
* [Z](https://esolangs.org/wiki/Z) - 文字zだけを使用する。
* [ZOMBIE](https://www.dangermouse.net/esoteric/zombie.html) - ネクロマンサー向けに設計された、本質的に邪悪なマルチスレッド言語。

## アルゴリズム

* [πfs](https://github.com/philipl/pifs) - Piベースのストレージシステム。pi内で一致する列を検索してデータを保存する。
* [Stacksort](https://gkoberger.github.io/stacksort) - Stack Overflowで答えを検索し、ソートされるまでコードスニペットを実行してリストをソートする。

## その他

* [asmbf](https://github.com/kspalaiologos/asmbf) - 唯一真のbrainfuckアセンブラツールキット。
* [CSS-only-chat](https://github.com/kkuchta/css-only-chat) - フロントエンドで一切JSを使わない、本当に怪物級の非同期ウェブチャット。
* [FizzBuzzEnterpriseEdition](https://github.com/EnterpriseQualityCoding/FizzBuzzEnterpriseEdition) - 最も厳格なエンタープライズ標準のもとで実装されたシンプルなFizzBuzzゲーム。
* [MalbolgeLisp](https://github.com/kspalaiologos/malbolge-lisp) - Malbolge Unshackledで書かれたLispインタープリター。
* [NoCode](https://github.com/kelseyhightower/nocode) - 安全で信頼できるアプリケーション。何も書かず、どこにもデプロイしない。
* [Petrovich](http://www.dangermouse.net/esoteric/petrovich.html) - ランダムな行動と報酬／罰に基づくオペレーティングシステムの概念。
* [vapor.js](https://github.com/madrobby/vapor.js) - 世界で最小かつ最速のJavaScriptライブラリ。

* [Six programming paradigms that will change how you think about coding](http://www.ybrikman.com/writing/2014/04/09/six-programming-paradigms-that-will) - 一般的には適用されない、異なるプログラミングパラダイムを説明するYevgeniy Brikmanの投稿。
* [The Fun (and Madness) of Esoteric Programming Languages](https://tomassetti.me/discovering-arcane-world-esoteric-programming-languages) - 例を交えた難解言語への率直な入門。
* [On the Turing Completeness Of MS PowerPoint](http://www.andrew.cmu.edu/user/twildenh/PowerPointTM/Paper.pdf) - PowerPoint上のチューリングマシン。
