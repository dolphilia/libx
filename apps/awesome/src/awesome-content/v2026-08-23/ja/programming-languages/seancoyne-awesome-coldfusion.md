# Awesome ColdFusion

ColdFusionを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## エンジン

* [Adobe ColdFusion](http://www.adobe.com/products/coldfusion-family.html)
* [Lucee](http://lucee.org/) - 無料でオープンソースの CFML エンジンです。

## アプリケーションフレームワーク

* [CFWheels](https://cfwheels.org) - Ruby on Rails に着想を得たオープンソース CFML フレームワークです。
* [ColdBox](http://www.coldbox.org) - エンタープライズ ColdFusion MVC 開発プラットフォームです。
* [FarCry](http://www.farcrycore.org) - CFML 開発者が独自のコンテンツソリューションを迅速に構築できる Web アプリケーションフレームワークです。
* [FW/1 - Framework One](https://github.com/framework-one/fw1) - 設定より規約を重視する軽量 MVC アプリケーションフレームワークです。

## テスト

* [CFSelenium](https://github.com/teamcfadvance/CFSelenium) - ColdFusion 用のネイティブ Selenium RC バインディングです。
* [MockBox](https://testbox.ortusbooks.com/mocking/mockbox) - ColdFusion の Mock／Stub フレームワークです。
* [MXUnit](https://github.com/mxunit/mxunit) - xUnit スタイルの単体テストフレームワークです。
* [mxunit-watch](https://github.com/atuttle/mxunit-watch) - ディレクトリのファイル変更（.cfc、.cfm、.xml）を監視して MXUnit テストスイート全体を実行し、結果をコンソールへ表示します。
* [TestBox](https://github.com/Ortus-Solutions/TestBox) - BDD スタイルの単体テストフレームワークです。

## 依存性注入

* [ColdSpring](https://github.com/coldspringframework/coldspring1) - CFC の設定と依存関係を簡単に管理できます。人気の Java 用 Spring フレームワークの力を ColdFusion にもたらします。
* [DI/1 - Inject One](https://github.com/framework-one/di1) - 設定より規約を重視する非常に軽量な依存性注入（制御の反転）フレームワークです。
* [Wirebox](https://wirebox.ortusbooks.com/) - エンタープライズ依存性注入フレームワークです。

## CMS

* [CONTENS CMS](http://www.contens.com/) - プロフェッショナル向けコンテンツ管理です。
* [ContentBox](https://github.com/Ortus-Solutions/ContentBox) - 強力なモジュール式コンテンツ管理エンジンです。
* [FarCry CMS](https://github.com/farcrycore/plugin-farcrycms)
* [Mura](https://www.murasoftware.com/)
* [Preside CMS](https://github.com/pixl8/Preside-CMS) - Railo 言語向けのオープンソース CMS です。
* [Slatwall](https://www.slatwallcommerce.com/) - オープンソースのコマースプラットフォームです。

## NoSQL

* [CFArango](https://github.com/dajester2013/CFArango) - ColdFusion 用 ArangoDB クライアントです。
* [CFCouchbase](https://github.com/Ortus-Solutions/cfcouchbase-sdk) - ColdFusion 用 Couchbase NoSQL・キャッシュクライアントラッパーです。
* [cfmongodb](https://github.com/marcesher/cfmongodb) - ColdFusion 用 MongoDB クライアントラッパーです。

## REST

* [ColdBox REST](https://coldbox.ortusbooks.com/digging-deeper/recipes/building-rest-apis) - ネイティブな REST ルーティングとレンダリング機能です。
* [FW/1 REST](https://github.com/framework-one/fw1/wiki/Developing-Applications-Manual#controllers-for-rest-apis) - ネイティブな REST ルーティングとレンダリング機能です。
* [Taffy](http://taffy.io) - ColdFusion と Railo 用の REST Web Service フレームワークです。
* [CFWheels RESTful](https://guides.cfwheels.org/docs/routing) - 規約に沿った RESTful かつリソース指向のリクエスト処理を推奨します。

## その他のライブラリ

* [CacheBox](https://cachebox.ortusbooks.com/) - エンタープライズ ColdFusion キャッシュエンジン、Aggregator、API です。
* [cfbackport](https://github.com/misterdai/cfbackport) - 新しいバージョンの ColdFusion に含まれる機能をバックポートします。
* [cfpayment](https://github.com/ghidinelli/cfpayment) - 電子商取引アプリの組み立てを容易にする ColdFusion 決済処理ライブラリです。クレジットカードへの課金がかつてないほど簡単になります。Ruby の ActiveMerchant に着想を得ています。
* [BugLogHQ](https://github.com/oarevalo/BugLogHQ) - 例外追跡です。
* [JavaLoader](https://github.com/markmandel/JavaLoader) - ColdFusion アプリケーション内での Java の使用、開発、統合を容易にするために構築されたライブラリです。
* [LogBox](https://logbox.ortusbooks.com/) - エンタープライズ ColdFusion ロギングライブラリです。
* [Moment.cfc](https://github.com/AlumnIQ/momentcfc) - Moment.js に着想を得た CFML 用日時操作ライブラリです（直接の移植ではありません）。
* [Mustache.cfc](https://github.com/rip747/Mustache.cfc) - ColdFusion 用の [{{ mustache }}](http://mustache.github.io) です。
* [UnderscoreCF](https://github.com/russplaysguitar/UnderscoreCF) - UnderscoreJS の ColdFusion 移植版である関数型プログラミングライブラリです。

## エディター

* [Sublime Text 3 用 CFML パッケージ](https://github.com/jcberquist/sublimetext-cfml) - [Sublime Text 3](http://www.sublimetext.com) の CFML 構文強調表示、関数・タグ補完です。
* [Visual Studio Code 用 CFML 拡張](https://marketplace.visualstudio.com/items?itemName=KamasamaK.vscode-cfml) - [VSCode](https://code.visualstudio.com/) 用 CFML 言語拡張です。
* [Atom 用 CFML 言語](https://github.com/atuttle/atom-language-cfml) - [Atom](https://atom.io/) 用 CFML 言語プラグインです。
* [Adobe ColdFusion Builder 3](http://www.adobe.com/products/coldfusion-builder.html) - Adobe の Eclipse ベース ColdFusion IDE です。
* [IntelliJ IDEA](http://www.jetbrains.com/idea/) - Java IDE です。[プラグイン](https://github.com/JetBrains/intellij-plugins/tree/master/CFML)で CFML に対応します。
* [cfbrackets](http://cfbrackets.org) - [Brackets Code Editor](http://brackets.io/) に ColdFusion Markup Language（CFML）対応を追加します。
* [CFEclipse](http://cfeclipse.org) - [Eclipse](http://www.eclipse.org/) 用 CFML プラグインです。
* [TextMate](https://github.com/textmate/coldfusion.tmbundle) - [TextMate](http://macromates.com) の ColdFusion 対応です。

## ツール

* [CommandBox](https://www.ortussolutions.com/products/commandbox) - ColdFusion（CFML）の CLI、パッケージマネージャー、REPL などです。
* [Unofficial Updater](http://www.uu-2.info/) - ColdFusion Hotfix のインストールを支援するユーティリティです。

* [ColdFusion Koans](https://github.com/nodoherty/ColdFusion-Koans) - ユーザーが値を埋めて通過させる単体テスト群です。
* [ColdFusion UI the Right Way](https://github.com/cfjedimaster/ColdFusion-UI-the-Right-Way) - バックエンドに ColdFusion を使って UI を実装する方法を示す記事一覧です。
* [Learn CF in a Week](http://www.learncfinaweek.com) - ColdFusion 開発者になるために必要な基本を1週間で教えるコミュニティ主導の研修プログラムです。
* [Try ColdFusion](http://trycf.com/) - CFML のリアルタイム対話型学習ツールです。
