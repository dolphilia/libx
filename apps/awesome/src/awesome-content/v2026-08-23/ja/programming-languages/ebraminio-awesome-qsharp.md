## チュートリアル
- [Quantum Katas](https://github.com/Microsoft/QuantumKatas/) - Q# と量子コンピューティングを学ぶプログラミング演習。
- [Quantum Kata Notebooks](https://mybinder.org/v2/gh/Microsoft/QuantumKatas/master?filepath=index.ipynb) - Q# プログラミングと量子コンピューティングを自分のペースで学べるオンラインチュートリアル。
- [Quantum Development Kit を使って最初の Q# プログラムを作成](https://docs.microsoft.com/en-us/learn/modules/qsharp-create-first-quantum-development-kit/) - Microsoft Learn モジュール。
- [Deutsch-Jozsa アルゴリズム](https://github.com/Microsoft/GHC18-IntroToQuantumComputing/) - Grace Hopper Celebration 2018 と Hopper x1 Seattle 2019 で行われた、自習形式の「量子コンピューティング入門」ワークショップ資料。
- [量子パーセプトロン](https://github.com/Microsoft/MLADS2018-QuantumML) - MLADS 2018 で行われた、自習形式の「量子機械学習入門」ワークショップ資料。
- [量子分類](https://github.com/microsoft/MLADS2020-QuantumClassification) - MLADS 2020 で行われた、自習形式の「量子分類入門」ラボ資料。
- [Microsoft QDK による量子コンピューティング](https://www.manning.com/liveprojectseries/quantum-computing-with-microsoft-qdk) - Q# と Microsoft QDK を使った各種プロトコルやアルゴリズムの実装を案内する Manning liveProject シリーズ。
