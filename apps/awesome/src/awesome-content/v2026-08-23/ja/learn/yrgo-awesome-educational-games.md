## アートとデザイン

- [Canon Explains Exposure](http://www.canonoutsideofauto.ca/) - 写真に適切な量の光を与える方法を学びます。
- [Can't Unsee](https://cantunsee.space/) - 細部への注意により多くのコインを獲得するゲーム。
- [Font Memory Game](https://betterwebtype.com/font-memory-game) - さまざまなフォントスタイルを認識することは、タイポグラフィーで最も難しい部分の一つです。
- [Method of Action](https://method.ac/) - デザイン原則を教えるゲームのコレクション。
  - [The Bézier Game](https://bezier.method.ac/) - ベジェ曲線
  - [Color](https://color.method.ac/) - 色
  - [Shape Type](https://shape.method.ac/) - 文字形状
  - [Kern Type](https://type.method.ac/) - カーニング
- [Pixactly](http://pixact.ly/) - 知識を問うピクセルテスト。
- [The Boolean Game](https://boolean.method.ac/) - Sketch、Figma、その他のベクターエディターでブール演算を使う方法を学びます。

## CSS

- [CSS Diner](https://flukeout.github.io/) - CSS セレクターを学ぶのに役立つ小さなゲーム。
- [CSS Grid Garden](http://cssgridgarden.com/) - CSS grid レイアウトを学ぶゲーム。
- [Flexbox Defense](http://www.flexboxdefense.com/) - 他のタワーディフェンスゲームと違い、CSS を使ってタワーを配置します！
- [Flexbox Froggy](http://flexboxfroggy.com/) - CSS flexbox を学ぶゲーム。
- [Flexbox with Webflow](https://www.flexboxgame.com/) - コードを書かずに、28のインタラクティブレベルで flexbox を学び習得します。

## エディター

- [Open Vim](https://www.openvim.com/) - インタラクティブな Vim チュートリアル。
- [Vim Adventures](https://vim-adventures.com/) - ゲームをプレイしながら Vim を学びます。
- [Vim Genius](http://vimgenius.com/) - Vim Genius で速度を高め、筋肉記憶を改善します。

## 言語

- [Drops](https://languagedrops.com/) - 楽しいゲームプレイで、選んだ言語の役立つ単語とフレーズを学びます。
- [Duolingo](https://www.duolingo.com/) - スペイン語、フランス語、その他の言語を無料で学びます。

## 数学とコンピューターサイエンス

- [Alligator Eggs!](http://worrydream.com/#!/AlligatorEggs) - ラムダ計算を教える、子ども向けの紙とペンを使うゲーム。
- [CS Unplugged](https://csunplugged.org/en/) - コンピューターを使わずにコンピューターサイエンスの概念を教える、教室活動のコレクション。
- [Finitris](http://www.postcrashgames.com/finitris/) - 正規表現の実行に何が使われるかを確認します。
- [Guess The Correlation](http://guessthecorrelation.com/) - 散布図の二つの変数がどの程度相関しているかを推測します。

## 音楽

- [Learning Music](https://learningmusic.ableton.com) - Ableton のインタラクティブウェブサイトを通じ、音楽の基礎を探求します。
- [Learning Synths](https://learningsynths.ableton.com/) - シンセサイザー（または synth）の使い方の基本を学びます。
- [Pianu](https://pianu.com) - ブラウザー内でピアノの弾き方を学びます。

## プログラミング

- [BOX-256](http://box-256.com/) - 架空の CPU をアセンブリでプログラムしてグラフィックを出力します。
- [Bashcrawl](https://gitlab.com/slackermedia/bashcrawl) - シンプルなテキストアドベンチャーをプレイして Linux コマンドを学びます。
- [Clips the Game](https://md5crypt.github.io/clipsgame/) - clips ルールエンジンに基づく難度の高いロジックゲーム。
- [Code Avengers](https://www.codeavengers.com/) - 楽しく効果的な方法で、ウェブサイト、アプリ、ゲームの構築を学びます。
- [Code School](https://www.pluralsight.com/codeschool ) - ブラウザーでくつろぎながらコーディングを学びます。
- [Code.org](https://code.org/) - すべての学校のすべての生徒が、コンピューターサイエンスを学ぶ機会を持つべきです。
- [Codecademy](https://www.codecademy.com/) - インタラクティブに、無料でコーディングを学びます。
- [CodeCombat](https://codecombat.com/) - プログラミング学習のための最も魅力的なコーディングゲーム。
- [CodinGame](https://www.codingame.com/start) - 最もホットなプログラミングトピックを使って遊べる、チャレンジベースのトレーニングプラットフォーム。
- [Cube Composer](https://david-peter.de/cube-composer/) - 関数型プログラミングに着想を得たパズルゲーム。
- [Deadlock Empire](https://deadlockempire.github.io/) - 並行処理でパズルを解きます。
- [Free Code Camp](https://www.freecodecamp.org/) - コーディング学習を支援するオープンソースコミュニティ。
- [Learn Git Branching](https://learngitbranching.js.org/) - ブランチを重視するインタラクティブ Git チュートリアル。
- [Mimo](https://getmimo.com/) - モバイルで開発者になる方法を学びます。
- [Programming Games Wiki](http://programminggames.org/) - 長年にわたるプログラミングゲームのカタログ。
- [RegexOne](https://regexone.com/lesson/introduction_abcs) - シンプルでインタラクティブな演習により正規表現を学びます。
- [ReturnTrue](https://alf.nu/ReturnTrue) - ブール値について学ぶゲーム。勝つには true を返します。
- [Screeps](https://screeps.com/) - プログラマーのための世界初の MMO 戦略サンドボックスゲーム。
- [SQL Murder Mystery](https://mystery.knightlab.com/) - データベーススキルを練習しながら犯罪を解決します。
- [Swift Playgrounds](https://www.apple.com/swift/playgrounds/) - とても楽しい方法で iPad 上のコーディングを学びます。
- [Untrusted](https://alexnisnevich.github.io/untrusted/) - JavaScript アドベンチャーゲームをプレイしながら学びます。
- [WarriorJS](https://github.com/olistic/warriorjs) - JavaScript を使い、戦士に高い塔を登らせ、モンスターと戦い、捕虜を救出するようプログラムします。
- [Web Audio School](https://mmckegg.github.io/web-audio-school/) - インタラクティブな WebAudio チュートリアル。
- [XSS game](https://xss-game.appspot.com) - ブラウザーでコードを実行するよう人をだますことに関するゲーム。
