## 開発プロジェクト <a id="development-projects"></a>
#### API <a id="apis"></a>
- [PokeAPI](https://github.com/PokeAPI/pokeapi/) - Pokémon向けRESTful API (http://pokeapi.co/)。
- [pgoapi](https://github.com/tejado/pgoapi) - Pokémon GO APIライブラリ／デモ。
- [pokemon-API](https://github.com/Purukitto/pokemon-api) - PokémonのデータをJSON形式で返す、初心者にも扱いやすいAPIエンドポイント (https://app.pokemon-api.xyz)。
- [Pokemon-GO-node-api](https://github.com/Armax/Pokemon-GO-node-api) - Pokémon GO APIのNode.jsライブラリ。
- [Pokemon-Go-Rocket-API](https://github.com/FeroxRev/Pokemon-Go-Rocket-API) - C#によるPokémon GOのクライアントAPIライブラリ。
- [Pokemon GO Java API](https://github.com/Grover-c13/PokeGOAPI-Java) - Java向けPokémon GO API。
- [Pokemon Name API](https://github.com/sindresorhus/pokemon) - Pokémonの名前一覧をJSONで取得。
- [PokemonGO-Pokedex](https://github.com/Biuni/PokemonGO-Pokedex) - JSON形式のPokémon GO図鑑。
- [PokeTypes](https://github.com/fbosch/poke-types) - Pokémonのタイプ、弱点、強みを取得。
- [TCGdex](https://github.com/tcgdex/cards-database) - 多言語対応のPokémon TCG API。
- [Kotlin-Pokedex](https://github.com/mrcsxsiq/Kotlin-Pokedex) - Kotlinで構築されたPokédexアプリ。
- [graphql-pokemon](https://github.com/lucasbento/graphql-pokemon) - GraphQLでPokémonの情報を取得。

#### アプリ <a id="apps"></a>
- [Pokemon-Showdown](https://github.com/Zarel/Pokemon-Showdown) - Pokémon対戦シミュレーター。
- [iPokeMon](https://github.com/Kjuly/iPokeMon) - 位置情報サービスを使う、iOS向けのPokémon風ゲーム。
- [pokemon-online](https://github.com/po-devs/pokemon-online) - オンラインPokémon対戦シミュレーター。
- [Shuffle-Move](https://github.com/Loreinator/Shuffle-Move) - ゲーム「Pokémon Shuffle」で次の最善手を特定して表示するプログラム。
- [pokecry](https://github.com/fent/pokecry) - 鳴き声からPokémonを当てます。
- [Pokedex](https://github.com/skydoves/Pokedex) - Dagger、Hilt、Motion、Coroutines、Flow、Jetpackを使ったAndroid Pokédex。
- [Who's That Pokémon?](https://github.com/serena2341/whos-that-pokemon) - シルエットからPokémonを当てます。

#### Bot <a id="bots"></a>
- [Pokemon Go Bot](https://github.com/Hrithikd/Pokemon-Go-Bot-Working-Hack-API) - PokéStopを回ってPokémonを捕獲するPokémon GO Bot。
- [slack-pokemon](https://github.com/rvinluan/slack-pokemon) - SlackでPokémon対戦を行うBot。
- [PokeSlack](https://github.com/timwah/pokeslack) - 近くにいるPokémonを通知します。
- [TwitchPlaysPokemon](https://github.com/sunshinekitty/TwitchPlaysPokemon) - Twitch Plays Pokémonを再現するBot。
- [PokemonGo-Bot](https://github.com/PokemonGoF/PokemonGo-Bot) - コミュニティと作るPokémon GO Botスクリプト。
- [Poketrainer](https://github.com/j-e-k/poketrainer) - 高速で機能豊富なPython製Bot。
- [PokeBot](https://github.com/akbaryahya/PokeBot) - Pokémonのスピードランを自動化するマシン。
- [PokemonGoBot](https://github.com/jabbink/PokemonGoBot) - Pokémon GOをプレイするBot。
- [Bot Builder for PokemonGoBot](https://github.com/shilch/pogobot-builder) - Pokémon GO Botを簡単にビルドします。
- [PokeBuddy](https://github.com/finndev/PokeBuddy) - Pokémon GO Bot。

#### その他 <a id="miscellaneous"></a>
- [alfred-pokedex](https://github.com/vutran/alfred-pokedex) - Pokémonの情報を検索するAlfred 3ワークフロー。
- [hyper-pokemon](https://github.com/hyper-pokemon/hyper-pokemon) - Hyperターミナル専用に作られた素晴らしいPokémonテーマ。
- [Pokemon-Go-Controller](https://github.com/kahopoon/Pokemon-Go-Controller) - Pokémon GOを安全に、または利用できない地域からプレイします。
- [pokecrystal](https://github.com/pret/pokecrystal) - Pokémon Crystalの逆アセンブル。
- [x-pokemon](https://github.com/passy/x-pokemon) - Pokémonを表示するWeb Component。
- [pokered](https://github.com/pret/pokered) - Pokémon Red／Blueの逆アセンブル。
- [pokemon-reverse-engineering-tools](https://github.com/pret/pokemon-reverse-engineering-tools) - Pokémon RedとPokémon Crystalのコンパイル・逆アセンブル用ツール。
- [pokemon-go-mitm-node](https://github.com/rastapasta/pokemon-go-mitm-node) - Pokémon GOのMITMプロキシ。
- [PokeMMO](https://github.com/maierfelix/PokeMMO) - リアルタイムエディターを備えたWebGL Pokémon MMOエンジン。
- [pogo-optimizer](https://github.com/justinleewells/pogo-optimizer) - 個体値と、どのPokémonをアメにすべきか判断するための情報を表示します。
- [PoGoTools](https://github.com/nelsyeung/PoGoTools) - 個体値の取得、Pokémonの転送・進化、アイテムの廃棄に使うCLIツール群。
- [slack-pokemon-emoji](https://github.com/fraserxu/slack-pokemon-emoji) - すべてのPokémonをSlack絵文字としてアップロードするツール。
- [slack-emoji-pokemon](https://github.com/Templarian/slack-emoji-pokemon) - Slack向けPokémon絵文字のリスト。
- [PokemonGO-IV-Renamer](https://github.com/Boren/PokemonGO-IV-Renamer) - Pokémonの名前を個体値へ自動的に変更。
- [pokemongo-genymotion](https://github.com/jlobos/pokemongo-genymotion) - Genymotion端末からPokémon GOをプレイ。
- [pokemongo-game-master](https://github.com/BrunnerLivio/pokemongo-game-master) - Pokémon GO Game Masterの各バージョンを集めたコレクション。
- [Pokemon-Terminal](https://github.com/LazoCoder/Pokemon-Terminal) - iTerm2向けPokémonターミナルテーマ。
- [pokemon-cli](https://github.com/sindresorhus/pokemon-cli) - Pokémonの名前を取得するCLI。
- [pokesprite](https://github.com/msikma/pokesprite) - 特別な色違い版を含む、Pokémon本編ゲームのスプライトデータベース。
- [PokéPalettes](https://github.com/BarryMode/pokepalettes) - Pokémonを表現する16ビットパレット（Pokémon GOのモデルを基にしています）。
- [PokemonRedExperiments](https://github.com/PWhiddy/PokemonRedExperiments) - 強化学習でPokémon Redをプレイ。
