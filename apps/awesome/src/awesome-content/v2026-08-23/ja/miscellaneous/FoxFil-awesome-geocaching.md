> Geocaching に関連してインターネット上で利用できる素材の厳選リスト。

[Geocaching](https://en.wikipedia.org/wiki/Geocaching) は、参加者が全地球測位システムの受信機またはモバイルデバイス、その他のナビゲーション技術を使い、世界中の座標で示された特定の場所にあるジオキャッシュまたはキャッシュと呼ばれる容器を隠したり探したりする、屋外レクリエーション活動です。

貢献を歓迎します。まず [contribution guidelines](https://github.com/FoxFil/awesome-geocaching/blob/81fca0108e668af88c5b8861e1e466e7ba7d00f6/contributing.md) をお読みください。

## ウェブサイト

- [Geocaching.com](https://www.geocaching.com/) - 国際的な公式ウェブサイト。
- [Shop Geocaching](https://shop.geocaching.com/) - キャッシュ用コンテナ、トラッカブル、ウェアラブルなどを購入できる公式 Geocaching ショップ。    
- [Project-GC](https://project-gc.com/) - Geocaching アカウントに関する多数の統計情報を提供するウェブサイト。
- [GeoCheck](https://geocheck.org/) - ジオキャッシュ用の座標チェッカー。
- [Certitude](https://certitudes.org/) - Geocaching パズルの解答を検証するためのツール。
- [Geocaching.su](https://geocaching.su/) - 旧ソビエト諸国における Geocaching のためのウェブサイト。
- [Geocaching Toolbox](https://www.geocachingtoolbox.com/) - 主にパズルを解くことと座標を扱うことを目的とした、ジオキャッシャー向けの多数のツール。
- [My Geocaching Profile](https://mygeocachingprofile.com/) - Geocaching での達成内容の詳細なプロフィールを作るウェブサイト。
- [CacheSleuth](https://www.cachesleuth.com/) - Geocaching 向けの便利なツール（主にテキストデコーダー）を数多く備えたウェブサイト。
- [LonelyCache](https://www.lonelycache.com/) - 長年見つかっていないジオキャッシュの一覧を提供するウェブサイト。
- [GC Wizard Web View](https://gcwizard.net/) - GC Wizard アプリのウェブビュー。
- [SolvedJigidi](https://solvedjigidi.com/) - 解決済み Jigidi ジオキャッシュのデータベース。
- [Webwigo](https://www.webwigo.net/) - Wherigo ジオキャッシュを仮想的にプレイするためのウェブサイト。
- [The A-Team Caching - Souvenirs](https://thea-team.net/souvenir) - すべての記念品に関する情報を掲載したウェブサイト。
- [Log Them All!](https://www.logthemall.org/) - コードを一つのリストに入力するだけで、複数のトラッカブルを一度にログ記録できるウェブサイト。


## アプリ

- [Geocaching®](https://www.geocaching.com/play/mobile) - Geocaching の公式アプリ。
- [Wherigo](https://apps.apple.com/us/app/wherigo/id1538051913) - `[iOS]` Wherigo ジオキャッシュをプレイするための公式アプリ。
- [WhereYouGo](https://play.google.com/store/apps/details?id=menion.android.whereyougo&pcampaignid=web_share) - `[Android]` Whereigo ジオキャッシュをプレイするためのオープンソースの非公式アプリ。
- [c:geo](https://play.google.com/store/apps/details?id=cgeo.geocaching) - `[Android]` Geocaching 用として最も人気のある無料の非公式アプリ。公式アプリにはない多数のツールを備えています。
- [Cachly](https://www.cachly.com/) - `[iOS]` Geocaching 用の有料非公式アプリ。公式アプリにはない多数のツールを備えています。
- [GC Wizard](https://blog.gcwizard.net/about/) - Android と iOS 向けのオープンソースツールコレクション。現地での謎解きやパズルを支援するオフラインツールを Geocacher に提供するために作られました。
- [Geocaching Buddy](https://gcbuddy.com/) - マルチキャッシュを解く際に、発見した手がかりに基づいてウェイポイントの式を再計算する有料の Geocaching アプリ。
- [TBScan](https://tbscan.com/) - カメラをコードに向けるだけでトラッカブルを発見できるアプリ。
- [Raccoon](https://apps.apple.com/us/app/raccoon-geocaching-tool/id424398764) - `[iOS]` マルチキャッシュやミステリーキャッシュを支援する Geocaching アプリ。
- [Geocaching4Locus](https://geocaching4locus.eu/) - `[Android]` Geocaching.com サイトからキャッシュを直接ダウンロードしてインポートできる Locus map アドオン。
- [GeoGet](https://www.geoget.cz/doku.php/start) - `[Windows]` 最終ウェイポイントの管理、ジオキャッシュへのノートやウェイポイントの追加、GeoGet との間でのジオキャッシュのインポート／エクスポートを行えるジオキャッシュマネージャー。
- [GSAK (Geocaching Swiss Army Knife)](https://gsak.net/index.php/) - `[Windows]` ジオキャッシュとウェイポイントを管理するデスクトップアプリ。
- [CacheStats](https://logicweave.com/) - `[Windows]` Geocaching の統計情報を表示するアプリケーション。
- [Caching on Kai](https://caching-on-kai.com/) - `[KaiOS]` KaiOS ユーザー向けの Geocaching アプリ。
- [Cacher](https://apps.garmin.com/apps/624aed67-b068-45b4-92af-cbc1885b7e1d) - `[Garmin]` Geocaching 用の Garmin 腕時計アプリ。


## その他
- [pycaching](https://pypi.org/project/pycaching) - Geocaching.com ウェブサイトを扱うための Python 3 インターフェース。
- [Geocaching.com Friends Logs](https://github.com/rfsbraz/Geocaching.com-Friends-Logs) - 各キャッシュ一覧ページの上部に友人のログを表示するブラウザー拡張機能。
- [GC little helper II](https://github.com/2Abendsegler/GClh/tree/collector) - Geocaching ウェブサイトの機能を強化・拡張する強力なツール。
