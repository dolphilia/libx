## Android開発 <a id="android-development"></a>

*Android向けのボイラープレートとテンプレート*

- [Android Bootstrap](https://github.com/AndroidBootstrap/android-bootstrap) 多数の優れたオープンソースツールとフレームワークを含むテンプレート／ブートストラップ／ボイラープレートアプリケーション。
- [Android Material Drawer Template](https://github.com/kanytu/android-material-drawer-template) Android用のナビゲーションドロワー付きのマテリアルデザインテンプレート。
- [material-design-icons-adt-template](https://github.com/intrications/material-design-icons-adt-template) Android Studio / Eclipse ADT用のマテリアルデザインアイコンリソーステンプレート。
- [AndroidKickststarter](https://github.com/e-biz/androidkickstartr) 開発をスムーズに進めるフレームワークで、コード作成に集中できます。
- [Android Annotations](https://github.com/excilys/androidannotations) 高速なAndroid開発。簡単な保守性。
- [Android Cookbook Examples](https://github.com/IanDarwin/Android-Cookbook-Examples) O'Reilly Android Cookbookからのコード例を集めたものです。
- [Android Basic Samples](https://github.com/playgameservices/android-basic-samples) 主にゲーム向けのサンプルです。
- [Android Webview Sample App](https://github.com/tscolari/android-webview-sample-app) Webviewサンプルアプリ
- [Android Quickstart](https://github.com/googledrive/android-quickstart) Android用のGoogle Drive APIのクイックスタートアプリ。
- [Beginning Android Resources](https://github.com/codepath/android_guides/wiki/Beginning-Android-Resources) Androidガイド。
- [Universal Music Player](https://github.com/googlesamples/android-UniversalMusicPlayer) Googleが提供するサンプルアプリで、複数のフォームファクターに対応したオーディオメディアアプリの実装方法と、Android端末、タブレット、自動車、ウェア、キャストデバイスでの一貫したユーザー体験を提供する方法を示しています。
- [Android Architecture Blueprints](https://github.com/googlesamples/android-architecture) 基本的なモデル・ビュー・プレゼンターアーキテクチャを示し、さまざまなTODOアプリの実装例を紹介しています。

- [Mega Boilerplate](https://github.com/sahat/megaboilerplate) Node.js、静的サイト、Electronアプリに対応するフルスタック・ボイラープレート生成ツール。

    - [Yeoman Node Generator](https://github.com/yeoman/generator-node) イオマンズノードジェネレーター

    - [Hackathon Starter](https://github.com/sahat/hackathon-starter) Node.jsウェブアプリケーション用のボイラープレート
    - [Node/Backbone Web App Boilerplate](https://github.com/skaapgif/webapp-boilerplate) Node、Express、MongoDBバックエンドとBackbone Marionette、Jade、Require.jsフロントエンドを備えたウェブアプリケーション用のボイラープレート
    - [Nodebootstrap](http://nodebootstrap.io/) Node/Express.js向けの非侵襲的なスケルトンプロジェクト（事前設定済みのベストプラクティス）。
    - [Vue-Express-Mongo Boilerplate](https://github.com/icebob/vue-express-mongo-boilerplate) - Express、Mongo、VueJSを用いたフルスタックJSウェブアプリケーションのボイラープレート)
    - [Node-Express-Mongoose Boilerplate](https://github.com/hagopj13/node-express-mongoose-boilerplate) - Node.js、Express、Mongooseを用いて本番対応RESTful APIを構築するためのボイラープレート
    - [Handlebars-Express Boilerplate](https://github.com/MohamedMoustafaNUIG/NodeExpressHbsScaffold) - ExpressとHandlebarsビューエンジンをセットアップしたJSウェブアプリケーションのボイラープレート

- [AngularJS](#angular-js)
    - [ng-boilerplate](https://github.com/ngbp/ngbp) AngularJSプロジェクト用の意見を反映したスタートアップツール
    - [Yeoman Angular Generator](https://github.com/yeoman/generator-angular)
    - [Angular Laravel CouchDB](https://github.com/melvin0008/laravel-angular) Angular Laravel CouchDBボイラープレート
- [ReactJS](#react-js)
    - [React Typescript npm boilerplate](https://github.com/Sivakumar00/react-typescript-npm-boilerplate) Rollup.js、Storybook、Jest単体テスト、Tree-shaking、Airbnb ESLintルールを用いたReact TypeScript npmコンポーネントのボイラープレート
    - [React Boilerplate](https://github.com/petehunt/react-boilerplate) React npm パッケージを作成するためのテンプレート
    - [React Boilerplate](https://github.com/rackt/react-boilerplate) React ルーターと Webpack を備えた React テンプレート
    - [React Transform Boilerplate](https://github.com/gaearon/react-transform-boilerplate) ホットリロードが可能な React コンポーネントとモジュール・コンポーネントレベルのエラーハンドリングを備えた新しい Webpack テンプレート
    - [Library Boilerplate](https://github.com/gaearon/library-boilerplate) ESLint、Mocha、Babel、Webpack および Webpack Dev Server と React Hot Loader を使用した React ライブラリ向けの意見を反映したテンプレート
    - [React NPM Component Starter](https://github.com/yogaboll/react-npm-component-starter) NPM 用の React コンポーネントを作成するための最小限のテンプレート
    - [React Isomorphic Starterkit](https://github.com/RickWong/react-isomorphic-starterkit) サーバーサイドReactレンダリングを備えた多機能な同型スタートキット
    - [Coffee React Quickstart ](https://github.com/KyleAMathews/coffee-react-quickstart) Coffeescript、Gulp、Webpack、React-Router を使用して React シングルページアプリケーションを構築するためのクイックスタート
    - [Flask React Boilerplate](https://github.com/alexkuz/flask-react-boilerplate) Flask と React テンプレート
    - [Boilerplate Webpack React](https://github.com/tcoopman/boilerplate-webpack-react) Webpack、Gulp および Stylus を使用した Reactjs テンプレートプロジェクト
    - [React JS Hot loader Boilerplates](https://github.com/gaearon/react-hot-loader/tree/master/docs#starter-kits) React Hot Loader スターター・キット
    - [React Redux minimal](https://github.com/flexdinesh/react-redux-boilerplate) すべてのベストプラクティスを備えた最小限の React-Redux テンプレート
    - [React Redux Universal Hot Example](https://github.com/erikras/react-redux-universal-hot-example) Express、React、Redux、Webpack、React-Transform を使用したユニバーサルウェブアプリケーション用のスタートキット
    - [post3ree-boilerplate](https://github.com/hex22a/post3ree-boilerplate) React、Redux、RethinkDB、Express + PostCSS を使用したユニバーサルアプリケーション用のテンプレート
- [HyperApp](#hyperapp)
    - [hyperapp-boilerplate](https://github.com/tzellman/hyperapp-boilerplate) 生産環境に適した Hyperapp アプリケーションを作成する方法を示すテンプレート
- [Backbone](#backbone)
    - [Backbone Boilerplates](https://github.com/addyosmani/backbone-boilerplates) Addy Osmani による Backbone テンプレート
    - [Yeoman Backbone Generator](https://github.com/yeoman/generator-backbone) Backbone向けのYeomanジェネレーター
    - [benm](https://github.com/shorttompkins/benm) Backbone.js、ExpressJS、Node.js、MongoDBを用いたウェブアプリのボイラープレート
- [Jquery](#jquery)
    - [Generator Jquery Boilerplate](https://github.com/jquery-boilerplate/generator-jquery-boilerplate) jQueryボイラープレート向けのYeomanジェネレーター
- [Polymer](#polymer)

    - [Polymer Seed Element](https://github.com/PolymerElements/seed-element) 独自の再利用可能なPolymerエレメントを作成する出発点

    - [WhiteStormJS - React/Redux - three.js - TypeScript boilerplate](https://github.com/WhitestormJS/whitestorm-typescript-boilerplate) 現代技術を用いて3Dアプリケーションを作成するためのスタートキット

## Python

*Python向けのボイラープレートとテンプレート*
- [BeautyNet](https://github.com/cms-flash/beauty-net) PyTorch向けの研究プロジェクトテンプレート
- [Django Hackathon Starter](https://github.com/DrkSephy/django-hackathon-starter) Djangoウェブアプリ向けのボイラープレート。さまざまなソーシャルログインと、複数の一般的なAPI例を提供。
- [CookieCutter](https://github.com/audreyr/cookiecutter#python) Audreyによる各種Pythonテンプレートの一覧
- [bootstrapy](https://github.com/kirang89/bootstrapy) ブートストラップされたPythonアプリ。コードの書くことに集中できるようにする。
- [Fbone](https://github.com/imwilsonxu/fbone) Fbone (Flask bone)は、Flask（Pythonのマイクロフレームワーク）テンプレート/Bootstrap/ボイラープレートアプリケーションです。
- [hasura/hello-python-flask](https://hasura.io/hub/project/hasura/hello-python-flask) 3分でデプロイ可能で、即時使用可能なデータベース、認証、ファイルAPIを備えたボイラープレートFlaskアプリケーションです。
- [Flask-Bootstrap](https://github.com/esbullington/flask-bootstrap) SQLAlchemy、認証、Bootstrapフロントエンドを統合したFlaskアプリケーションテンプレートです。
- [Flask Boilerplate](https://github.com/melvin0008/FlaskBoilerplate) 非常にシンプルなFlaskボイラープレートでフォルダ構成が備わっています。
- [Flask Foundation](https://github.com/JackStouffer/Flask-Foundation) ベストプラクティスに基づいたアプリケーションです。
- [GoogleAppEngine Webapp2 Boilerplate](https://github.com/coto/gae-boilerplate) Google App Engine上でPython Webapp2用の完全なボイラープレートです
- [Flask Appengine Template](https://github.com/kamalgill/flask-appengine-template) Flask App engineテンプレート
- [Django Starter Template](https://github.com/fasouto/django-starter-template) Django向けの使いやすいプロジェクトテンプレートでベストプラクティスを採用しています。
- [gae-init](http://gae-init.appspot.com) Flask、RESTful、Bootstrap、その他多くの魅力的な機能を備えたGoogle App Engineベースのアプリケーションです。
- [CherryPy + Mako + Formish + OOOP boilerplate](https://github.com/kdeldycke/cherrypy_mako_formish_ooop_boilerplate) OpenERPコンテンツのウェブ配信をターゲットとしています。
