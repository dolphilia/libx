## 電卓アプリ：

### Android
- [HiPER Scientific Calculator](https://play.google.com/store/apps/details?id=cz.hipercalc&hl=en) - 計算履歴やテーマなど多数の機能を備えた高度な関数電卓。
- [Calculator ++](https://play.google.com/store/apps/details?id=org.solovyev.android.calculator&hl=en) - 現代的な Google Material Design インターフェースを備えた関数電卓。
- [Google Calculator](https://play.google.com/store/apps/details?id=com.google.android.calculator&hl=en) - Google の公式電卓。
- [Samsung Calculator](https://play.google.com/store/apps/details?id=com.sec.android.app.popupcalculator&hl=en) - Samsung の新しい公式電卓。
- [Photomath（カメラ電卓）](https://play.google.com/store/apps/details?id=com.microblink.photomath&hl=en) - カメラを使って数学の問題を計算。
- [RealCalc](https://play.google.com/store/apps/details?id=uk.co.nickfines.RealCalc&hl=en) - 本物らしいインターフェースを備えた関数電卓。
- [a41cv](https://play.google.com/store/apps/details?id=dk.andsen.hp41&hl=en) - 古典的な [HP-41CV](http://www.hpmuseum.org/hp41.htm) 電卓の優れたエミュレーション。
- [Wabbitemu](https://play.google.com/store/apps/details?id=com.Revsoft.Wabbitemu&hl=en) - 端末上で Texas Instruments のグラフ電卓をエミュレート。
- [Droid48（ソース）](https://github.com/shagr4th/droid48/tree/master/app/src/main)、[Droid48（アプリ）](https://play.google.com/store/apps/details?id=org.ab.x48) - 優れた HP48GX/SX エミュレーター x48 の Android 移植版
- [Scalar](https://scalarmath.org/) - 標準的な電卓の簡潔さとスクリプトの柔軟性を組み合わせた、強力な数学エンジン兼数学スクリプト言語。

### Windows
- [Windows Calculator](https://github.com/Microsoft/calculator) - Windows に付属するシンプルながら強力な電卓
- [HiPER Scientific Calculator（Windows版）](http://hiperdevelopment.wixsite.com/hipercalc) - 多数の機能を備えた高度な関数電卓。
- [in-line calculator（AutoHotkey Calculator）](https://github.com/davebrny/in-line-calculator) - 入力中の行を離れずに基本的な計算を行える、インターフェースを持たない Windows 向け電卓。
- [Windows 10 で使う旧 Windows 7/8 Calculator](https://winaero.com/download.php?view.1795) - Windows 10 で旧 Windows 7/8 電卓を使えるようにします。
- [GraphCal](http://www.graphcalc.com/) - 独自機能を備えたプロ向け電卓。

### Mac
- [Numi](https://numi.io/) - 単位やタイムゾーンの変換など優れた機能を備えた美しい電卓。
- [Soulver 3](https://soulver.app/) - 電卓を内蔵したスマートなメモ帳。
- [Calculator + ƒ](https://www.phnsft.com/products/calculator/) - Mac 向けの強力で拡張可能な電卓。

### Linux
- [Galculator](https://github.com/galculator/galculator) - GTK 2 / GTK 3 ベースの関数電卓。
- [KCalc](https://github.com/KDE/kcalc) - 一見しただけでは分からないほど多くの数学関数を提供する電卓。
- [x48](https://github.com/gwenhael-le-moine/x48) - 史上最高の技術者向け電卓の一つ、HP48GX/SX をエミュレート。

### クロスプラットフォーム
- [Parsify Desktop](https://parsify.app) - 21世紀向けの拡張可能な電卓。
- [Simple Electron Calculator](https://github.com/DCKT/electron-calculator) - Electron 製の基本的なクロスプラットフォーム電卓。
- [elcalc](https://github.com/xxczaki/elcalc) - シンプルで美しいインターフェースを備えた電卓。
- [Material Design Calculator](https://github.com/lirios/calculator) - クロスプラットフォームの Material Design 電卓。
- [SpeedCrunch](http://www.speedcrunch.org/) - 高速でキーボード中心のUIを備えた高精度関数電卓。
- [Liri Calculator](https://liri.io/apps/calculator/) - 現代的な電卓に期待されるすべての機能を備えた、クロスプラットフォームの Material Design 電卓。
- [mdlt](https://github.com/metadelta/mdlt) - すばやい計算のためのコマンドラインユーティリティ。
- [calc](https://github.com/alfredxing/calc) - Go で書かれたシンプル、高速、直感的なコマンドライン電卓。
- [J# Calculator Barebones](https://github.com/KrzysztofSzewczyk/JSharpCalculator) - J# で書かれた非常にシンプルな電卓。J# 初心者が拡張しながら学ぶプログラムとして作成。
- [Qalculate!](https://qalculate.github.io/) - 単位・通貨変換を含むクロスプラットフォーム関数電卓。

### ウェブ
- [Wolfram|Alpha](https://www.wolframalpha.com/) - 計算知識エンジン。
- [Web 2.0 Scientific Calculator](http://web2.0calc.com/) - 学校や大学で役立つ基本・高度な数学関数を提供するオンライン電卓。
- [Calculator.js](https://material-calculator.netlify.com/) - 美しい Google Material Design インターフェースを備えたオープンソースのウェブ電卓。
- [Notepad Calculator](http://notepadcalculator.com/) - 使いやすく独自のメモ帳インターフェースを備えた電卓。
- [Calculator.net](http://www.calculator.net/) - さまざまな電卓の大規模コレクション。
- [Clcalc.net](https://clcalc.net/) - 数学、科学、プログラミング関数などを備えた、オープンソースでコマンドライン形式の任意精度電卓。
- [Desmos](https://www.desmos.com/) - 電卓、試験などを含む数学関連のオンラインツール群。
- [Geogebra](https://www.geogebra.org/) - グラフ、幾何学、3D などの無料オンライン数学ツール。対話型グラフ電卓を含みます。
