## アーキテクチャの例
A good ARCHITECTURE.md file helps developers understand how and where to make changes, whether they are new to a project or not.

Diagrams, source code maps, and discussing invariants and design decisions are essential.

This can also be a dedicated section of your README.md files.
- [esbuild](https://github.com/evanw/esbuild/blob/main/docs/architecture.md) - グラフィックの良好な活用により、視覚化やプロジェクト構造を表現。プロジェクトの重要な原則のリストを含む。
- [Flutter Engine](https://github.com/flutter/flutter/blob/master/docs/about/The-Engine-architecture.md) - 高レベルの図を用いてスタックとその部分を示す。主なプロセスを説明。プラットフォームの不変性を説明。
- [GitLab](https://gitlab.com/gitlab-org/charts/gitlab/-/tree/master/doc/architecture) - 設計決定を明確に指摘。
- [Linux cryptography](https://github.com/torvalds/linux/blob/master/Documentation/crypto/architecture.rst) - 異なる種類のコンポーネントを呼び出し、検索可能な領域を提供し、各コンポーネントの不変性を指摘し、構造を図で説明する。
- [Neovim](https://github.com/neovim/neovim/blob/master/src/nvim/README.md) - 主なプロセス／ライフサイクルを説明する。
- [Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh/wiki/Design) - 初期化プロセスを説明し、環境要件を指摘する。
- [Redis](https://github.com/redis/redis/blob/unstable/README.md) - 良いソースコードマップ。重要なファイルの概要。コード内にドキュメントコメントを適切に活用している。
- [Tauri](https://github.com/tauri-apps/tauri/blob/dev/ARCHITECTURE.md) - 良好なソースコードマップで、アーキテクチャの考慮事項を議論し、重要な依存関係を指摘している。
- [VS Code](https://github.com/microsoft/vscode/wiki/Source-Code-Organization) - 高レベルの図を適切に活用。ソースコードの組織構造を説明している。

## GIFの作成

READMEにアニメーションGIFを埋め込むと、プロジェクトの動作をすぐに示して読者の目を引けます。プロジェクト用のGIFを手早く作成できるプログラムを紹介します。

- [Gifski](https://github.com/sindresorhus/Gifski#readme) - **無料** - 他のものよりも鮮やかな色を提供しながら、サイズは小さく保つ。
- [Giphy Capture](https://giphy.com/apps/giphycapture) - **無料** - giphy.com へのアップロードが簡単だが、やや不快な UX を持つ。
- [LICEcap](https://www.cockos.com/licecap/) - **無料** - より直感的ではないが、機能が豊富。
- [ScreenToGif](https://github.com/NickeManarin/ScreenToGif/) - **無料** - オープンソース。カスタマイズ可能なUIと編集しやすいGIFを備え、簡単に使い始められます。
- [terminalizer](https://github.com/faressoft/terminalizer) - **無料** - テーマを記録し、アニメーション GIF またはウェブプレイヤーを生成・共有できる。
- [ttystudio](https://github.com/chjj/ttystudio#readme) - **無料** - コマンドラインツール向け。ターミナルからGIFを記録できます。
- [vhs](https://github.com/charmbracelet/vhs) - **無料** - シンプルなスクリプト言語で、美しいターミナルGIFを生成します。
