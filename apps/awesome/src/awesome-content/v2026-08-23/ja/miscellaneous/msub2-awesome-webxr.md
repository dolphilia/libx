## 注目プロジェクト

*印象的で注目すべき WebXR プロジェクト。*

- [Hello WebXR](https://msub2.github.io/hello-webxr/) - WebXR 1.0 API の公開を記念して作られ、WebXR で可能なことの一部を紹介。
  - 元のドメインでアクセスできなくなったため、作者自身のフォーク上にある体験のミラーへリンクしています。
- [Moonrider](https://moonrider.xyz/) - Supermedium 製の Beat Saber に似たリズムゲーム。
- [Plockle](https://plockle.com/) - 40以上のレベルを持つ空間ブロックパズルゲーム。
- [Castle Builder](https://castle.needle.tools/) - 独自の Unity-to-three.js パイプラインを利用する、協調型・クロスプラットフォームの城づくりゲーム。
- [Prehistoric Domain](https://www.prehistoricdomain.com/) - 複数の恐竜展示と今後の追加予定を持つ、ブラウザー内の Jurassic Park 風体験。
- [Above Par-adowski WebXR Mini Golf](https://aboveparadowski.com/) - Paradowski Creative が設計した、独自で変化に富む環境に9ホールを配置した WebXR ミニゴルフゲーム。
- [Yolopia](https://www.yolopia.com/) - フロー、ボクシング、ポーズマッチングを組み合わせたリズムゲーム。
- [f60](https://heyvr.io/game/f60) - ソ連の刑務所を舞台とするクロスプラットフォーム WebXR 脱出ゲームシリーズ。
- [The Escape Artist](https://esc.art/) - 創作過程に関する包括的な物語を持つ、アーティストの心の中を舞台にした Paradowski Creative の受賞歴ある脱出ゲーム。
- [NeoFables](https://neofables.com/) - GenAI を使う動的生成 VR ストーリーテリング体験。2024 Polys Immersive Awards の「Game of the Year」「Experience of the Year」にノミネートされ、Meta が紹介した最初の GenAI VR 体験。
- [XRSH](https://xrsh.isvery.ninja) - VR 内シェルでライブスクリプト、パッケージ、プロトタイピングを可能にする、WebXR 内で実行される Linux 仮想マシン。[[repo]](https://codeberg.org/xrsh/xrsh)

## アート

*芸術的制作に焦点を当てたプロジェクト。*

- [Brushwork VR](https://brushworkvr.com/) - 仮想キャンバス、パレット、色混合などによる絵画制作の過程をシミュレートする VR アプリ。
- [Silk Brush](https://msub2.github.io/silk-brush/) - 将来の拡張を予定する Tilt Brush の WebXR 移植。
- [VARTISTE](https://vartiste.xyz/) - 2D 描画・画像編集と3Dモデルテクスチャリングのための VR アプリ。

## オーディオ

*オーディオ・オーディオビジュアル体験に焦点を当てたプロジェクト。*

- [Fathom VR](https://www.letsfathom.com/vr) - 関連アーティストのクラウドを空間オーディオで検索・探索できる、音楽発見アプリ Fathom の WebXR 版。
- [TRACK](https://demos.littleworkshop.fr/track) - [Little Workshop](https://www.littleworkshop.fr/)が開発した、没入型オーディオビジュアル体験を通るリニアなライド。

## アバター

*没入型体験で3Dアバターを作成・利用するためのリソース。*

- [Exokit Avatars](https://github.com/exokitxr/avatars) - 複数形式のヒューマノイドアバターを読み込み、腕・脚 IK、viseme による顔アニメーションなどを備える Web ベースアバターシステム。元リポジトリは保守されていませんが、より最新のフォークは[こちら](https://github.com/msub2/avatars)です。
- [VRoid](https://vroid.com/en) - 高い互換性を持つ .vrm 形式へエクスポートできるアニメ調3Dアバターを作成。

## 開発

*WebXR コンテンツを可能にするツール。完全な一覧は別の WebXR Creation Tools リストを、詳細な一覧は[awesome-webxr-development](https://github.com/Pico-Developer/awesome-webxr-development)リストを参照。*

### エンジン

- [Godot](https://godotengine.org/) - バージョン3.2.4以降で WebXR をサポートするクロスプラットフォーム・オープンソースエンジン。
  - [Official Documentation](https://docs.godotengine.org/en/stable/classes/class_webxrinterface.html)

- [Needle](https://needle.tools/) - Blender と Unity 用のエンジン・エクスポーター。
  - [Official Documentation](https://engine.needle.tools/docs/)
 
- [Onirix Studio](https://www.onirix.com/) - ブラウザーで Web AR 体験を作るノーコードエディター。対象端末・ブラウザーに互換性がない場合は WebXR 機能をエミュレート。

- [PlayCanvas](https://playcanvas.com/) - WebXR コンテンツ、モバイルブラウザー、協調編集などをサポートするブラウザーベース WebGL エンジン。
  - [Official Documentation](https://developer.playcanvas.com/en/)

- [Rogue Engine](https://rogueengine.io/) - Three.js と TypeScript に基づく HTML5 ゲームエンジン。
  - [Official Documentation](https://rogueengine.io/docs/manual/getting-started/installation/) 
  
- [Unity](https://unity.com/) - コミュニティパッケージにより WebXR 向けエクスポートを可能にする、非常に人気の高いゲームエンジン。
  - [WebXR Export](https://github.com/De-Panther/unity-webxr-export) - [De-Panther](https://github.com/De-Panther/)によるエクスポーター
  - [SimpleWebXR](https://github.com/Rufus31415/Simple-WebXR-Unity) - [Rufus31415](https://github.com/Rufus31415)によるエクスポーター

- [Wonderland Engine](https://wonderlandengine.com/) - WebXR アプリケーションの構築専用に設計された開発プラットフォーム。
  - [Official Documentation](https://wonderlandengine.com/documentation/)

### フレームワークとライブラリ

- [A-Frame](https://aframe.io/) - three.js 上に構築された宣言的 HTML とカスタム JavaScript コンポーネントで VR 体験を作成。
  - [Official Documentation](https://aframe.io/docs/)

- [Babylon.js](https://www.babylonjs.com/) - 強力かつ機能豊富なレンダリングエンジンをパッケージ化した JavaScript フレームワーク。
  - [Official Documentation](https://doc.babylonjs.com/)

- [JanusWeb](https://github.com/jbaicoianu/janusweb) - ソーシャル VR 体験を作れる JanusVR のブラウザー内実装。

- [JSAR-DOM](https://github.com/m-creativelab/jsar-runtime) Babylon.js 上の XR アプリケーション向け WHATWG DOM、CSSOM、WebXR の TypeScript 再実装。

- [p5.xr](https://p5xr.org/) - 没入型 p5 スケッチを作れる p5.js ライブラリ用アドオン。

- [react-three-fiber](https://github.com/pmndrs/react-three-fiber) - three.js 向け React レンダラー。WebXR 固有の追加フック・コンポーネントは[React XR](https://github.com/pmndrs/react-xr)でも利用できます。

- [reactylon](https://www.reactylon.com/) - Babylon.js と React 上に構築された、3D/XR 体験作成向け強力なマルチプラットフォームフレームワーク。
  - [Official Documentation](https://www.reactylon.com/docs)

- [three.js](https://threejs.org/) - 多くの既存 WebXR 体験とツールを支える、WebGL で3Dコンテンツを描画する JavaScript ライブラリ。
  - [Official Documentation](https://threejs.org/docs/index.html#manual/en/introduction/Creating-a-scene)

- [Threlte](https://threlte.xyz/) - three.js 向け Svelte レンダラー・コンポーネントライブラリ。WebXR 固有のフック・コンポーネントは[`@threlte/xr` package](https://threlte.xyz/docs/reference/xr/getting-started)で利用可能。

- [X3DOM](https://x3dom.org) - X3D シーンを HTML5/DOM 要素として統合・操作するフレームワーク。
  - [Official Documentation](https://doc.x3dom.org/)

### その他

- [Verge3D](https://www.soft8soft.com/verge3d/) - 3Dアーティストがシーンをエクスポートし、容易に没入型 Web 体験を作るためのツールキット。
  - [Official Documentation](https://www.soft8soft.com/support-documentation/)
- [XR Fragments](https://xrfragment.org) - 既存メタデータに基づき URL で任意の3Dモデルを制御する小さな仕様。すべての3Dエディター・ビューアーを使ったハイパーリンク WebXR ストーリーテリングを促進。[[repo]](https://codeberg.org/coderofsalvation/xrfragment)

## 収益化

*従来の Google Ads などの Web 広告プラットフォーム、および Web3XR に属する暗号資産以外で WebXR コンテンツを収益化する方法。*

- [Borellion](https://www.borellion.com/) - XR 内で貸し出し可能なバナースペースのマーケットプレイス。主要な WebXR 制作ツールの多くと統合可能。

## ソーシャルスペース

*ユーザーが集まり、協働するソーシャルスペースの作成に焦点を当てたプロジェクト。*

- [Dreamwave](https://dreamwave.tech/) - スケーラブルなバーチャルイベントをホストする Web ベースプラットフォーム。Secret Sky 2021 のバーチャル音楽フェスティバルを支えました。
- [FRAME](https://framevr.io/) - バーチャル空間で容易に3D協働を可能にするプラットフォーム。
- [Hubs](https://hubsfoundation.org/) - 当初 Mozilla が作成した、ユーザーのバーチャルな集まりと協働を可能にするコミュニティ所有プラットフォーム。
- [w3dge](https://w3dge.io/) - AI 統合を備えた集会・バーチャルショーケース向けプラットフォーム。
