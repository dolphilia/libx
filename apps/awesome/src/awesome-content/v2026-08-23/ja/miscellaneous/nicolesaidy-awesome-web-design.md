## ブログとニュース <a id="blog--news"></a>
* [Web Designer News](http://webdesignernews.com): デザイナー向けに厳選された優れた記事。
* [Marvel Blog](http://blog.marvelapp.com): Marvelチームによる最新ニュース、資料、考察。
* [The Next Web](http://thenextweb.com/section/creative/): 世界のテクノロジー、ビジネス、文化に関するニュース。
* [Medium](https://medium.com/tag/web-design): 大小さまざまなアイデアへ独自の視点を寄せる読者と執筆者のコミュニティ。
* [Creative Bloq](http://www.creativebloq.com/): アートとデザインの着想。
* [Smashing Magazine](http://smashingmagazine.com): プロのWebデザイナーと開発者向け。
* [Sitepoint](https://www.sitepoint.com/design-ux/): Web開発者とデザイナーが、素晴らしいインターネット上のものを作る情熱を共有する場。
* [Designer News](https://www.designernews.co/): デザインコミュニティが集う場所。
* [Reddit Web Design](https://www.reddit.com/r/web_design/): デザイナーが有用な投稿を寄せ、質問し、議論へ参加できる場所。
* [Morning Reader](https://morningreader.com): テクノロジー速報。
* [Google design](https://www.youtube.com/channel/UClKO7be7O9cUGL94PHnAeOA): Googleデザインについてデザイナー向け動画を公開するYouTubeチャンネル。

## 着想 <a id="inspiration"></a>
* [Awwwards](http://awwwards.com): 優れたWebデザインのトレンド。
* [One Page Love](http://onepagelove.com): 優れたシングルページWebサイトを紹介するデザインギャラリー。
* [Inspired UI](http://inspired-ui.com/): モバイルアプリのデザインパターン。
* [Behance](http://behance.net): クリエイティブ作品を公開・発見できます。
* [Dribbble](http://dribbble.com): デザイナーが作品を見せ合う場所。
* [Product Hunt](http://producthunt.com): 次のお気に入りを発見する場所。
* [UI Movement](https://uimovement.com): 優れたUIデザインの着想を毎日紹介。
* [Pttrns](http://pttrns.com/): デザインパターン、資料、着想を集めた上質なコレクション。

## 配色 <a id="colors"></a>
* [Brandcolors](https://brandcolors.net/): 世界的な大手ブランドの公式カラー。
* [Adobe Color CC](https://color.adobe.com/): カラーホイールで配色を作成したり、Kulerコミュニティの数千種類の組み合わせを閲覧したりできます。
* [Paletton](http://paletton.com): 調和する色の組み合わせを作るデザイナー向けツール。
* [Coolors](https://coolors.co/): デザイン用カラーパレットを無限に生成。
* [Lol Colors](http://www.lolcolors.com/): 厳選されたカラーパレットの着想。
* [Colordot](https://color.hailpixel.com/): 人のためのカラーピッカー。
* [Gradients.io](http://www.gradients.io/): デザイナーと開発者向けに厳選されたグラデーション。
* [UI Gradients](http://uigradients.com/): 美しいカラーグラデーション。
* [Colorzilla](http://colorzilla.com): スポイト、カラーピッカー、グラデーション生成器。

## タイポグラフィ <a id="typography"></a>
* [Google Web Fonts](http://fonts.google.com): オープンソースのデザイナー向けWebフォントを、直感的で充実したディレクトリとして提供。
* [Font Face Ninja Browser Extension](http://fontface.ninja/): 閲覧中のWebサイトでフォント名を知りたいときに、Ninjaが見つけてくれます。
* [Fontpair](http://fontpair.co): 美しいGoogle Fontsの組み合わせとペア。
* [Type Anything](https://typeanything.io/): 優れたフォントの組み合わせを作成。
* [Type Scale](http://type-scale.com/): プロジェクトに適したタイプスケールをプレビューして選択。
* [WhatTheFont](https://www.myfonts.com/WhatTheFont/): 画像で見かけたフォントに最も近いものを探します。
* [Typewolf](https://www.typewolf.com/): Webタイポグラフィの包括的な情報、代替フォントの提案、実際の使用例へのリンク。
* [Typ.io](http://typ.io/): 実在するWebサイトから得られるタイポグラフィの着想。

## アイコン <a id="icons"></a>
* [Flat Icon](http://flaticon.com): 数千点の無料フラットアイコン。
* [Font Awesome](http://fontawesome.io): アイコンフォントとCSSツールキット。
* [Icon Finder](http://iconfinder.com): 100万点の無料・有料アイコン。
* [The Noun Project](https://thenounproject.com/): あらゆるもののアイコン。
* [Favicon Generator](http://www.favicon-generator.org/): faviconとアプリアイコンの生成器。
* [Freepik](http://freepik.com): さまざまな形式の無料ベクター素材。
* [Vecteezy](http://vecteezy.com): 無料のベクターアート、ベクターグラフィックス、Illustrator背景などのコレクション。
* [Material Icons](https://material.io/icons/): Googleによる無料で利用可能なMaterial Designアイコン。
* [Ionicons](http://ionicons.com/): Ionic Framework向けの高品質なアイコンフォント。

## 画像 <a id="images"></a>
* [Pexels](https://pexels.com): 優れた無料ストック写真を一か所に集約。
* [Unsplash.it](http://unsplash.it): 美しい画像ギャラリーを使ったプレースホルダー。
* [Pixabay](https://pixabay.com/): 商用利用も無料の高品質な写真とイラスト。
* [Placehold.it](http://placehold.it): すばやく簡単に使える画像プレースホルダーサービス。
* [Imgur](http://imgur.com): インターネット上の素晴らしい画像。
* [Flickr](https://www.flickr.com): あらゆる写真のための場所。

## ガイドライン <a id="guidelines"></a>
* [iOS Human Interface Guidelines](https://developer.apple.com/ios/human-interface-guidelines/): 美しく魅力的なiOSアプリを設計するために必要な情報を網羅。
* [Google Material Design](https://material.google.com/): Googleブランドのデザイン、コンポーネント、資料を詳しく解説。
* [Laws of UX](https://lawsofux.com/): UI構築時にデザイナーが考慮できる格言と原則のコレクション。
* [Ultimate Guide](https://www.moveoapps.com/ultimate-guide-to-mobile-app-design-principles): アプリを輝かせるモバイルアプリ設計原則の完全ガイド。
* [GoodUI](http://www.goodui.org/): UIを改善する5つの方法。

## デザインツール <a id="design-tools"></a>
* [Sketch](http://sketchapp.com): Mac向けの軽量なデジタルデザインソフトウェア。
* [Figma](http://figma.com): 共同作業に対応したインターフェースデザインツール。
* [Adobe XD](https://www.adobe.com/products/experience-design.html): プロトタイピングとワイヤーフレーム作成のツール。
* [inVision Studio](https://www.invisionapp.com/studio): 高速なプロトタイピング、アニメーション、組み込みデザインシステム、共同作業。
* [Canva](http://canva.com): 驚くほど簡単なグラフィックデザインソフトウェア。
* [Framer X](https://framer.com/): インタラクションデザインとUXデザインのソフトウェア。

## プロトタイプツール <a id="prototype-tools"></a>
* [Zeplin](https://zeplin.io/): デザイナーと開発者のための優れた共同作業ツール。
* [Avocode](https://avocode.com/): すべてのデザイナーと開発者に開かれたワークスペース。
* [inVision](https://www.invisionapp.com/): 世界をリードするプロトタイピング、共同作業、ワークフローのプラットフォーム。
* [Justinmind](http://justinmind.com): Web・モバイルアプリのプロトタイプをすばやく作り、円滑に伝達できます。
* [Marvel App](https://marvelapp.com/): デザイナー向けの無料モバイル・Webプロトタイピング。
* [Atomic.io](https://atomic.io/): ブラウザ内で使える無料のインタラクティブデザインツール。
* [Flinto](https://www.flinto.com/): インタラクティブでアニメーション付きのデザインプロトタイプを作るアプリ。

## チュートリアル <a id="tutorials"></a>
* [Treehouse](https://teamtreehouse.com/tracks/web-design): 手頃な価格の技術教育をあらゆる場所の人々へ届けます。
* [Tuts Plus Web Design Tutorials](http://webdesign.tutsplus.com/): 無料のWebデザイン・開発チュートリアル。
* [Springboard](https://www.springboard.com): 目標達成とキャリア向上を支援するために設計された個別学習方式。
* [Learn Sketch](https://www.sketchapp.com/learn/): 学習開始を助ける短い動画と価値ある資料集。
* [Adobe XD Guide](https://www.xdguru.com/adobe-xd-guide/): XD初心者と現役ユーザー向けの1万2千語に及ぶ包括的なガイド。

## 生産性 <a id="productivity"></a>
* [Pomodoro](http://tomato-timer.com): 仕事や勉強をより生産的にする便利な時間管理手法。
* [Toggl](http://toggl.com): 職場の生産性を高めるタイムトラッカー。
* [Trello](http://trello.com): 楽しく柔軟で手応えのある方法でプロジェクトを整理し、優先順位を付けます。
* [RescueTime](https://www.rescuetime.com): 日々の習慣を理解し、集中力と生産性を高めるのに役立ちます。
* [Qbserve](https://qotoqot.com/qbserve/): 自動時間追跡、請求書作成、リアルタイムの生産性フィードバック。
* [Paste](http://pasteapp.me/): Mac向けの賢いクリップボード履歴マネージャー。
* [Sip](http://sipapp.io/): Mac向けカラーピッカー。
* [Timing](https://timingapp.com/): Mac向けの自動時間・生産性追跡。
* [Taskade](https://taskade.com/): チーム向けの共同タスクリストとアウトライン。
