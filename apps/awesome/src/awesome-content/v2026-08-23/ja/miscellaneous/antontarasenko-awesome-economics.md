## 学習 <a id="studying"></a>

### 講座 <a id="courses"></a>

* [MIT OCW Economics](http://ocw.mit.edu/courses/economics/) - 経済学の主要分野すべてを扱う100以上の講座。履修要件、推奨教科書、講義スライド、課題を含む。学部・大学院課程に対応。
* [edX Economics](https://www.edx.org/course/subject/economics-finance) - 入門的な話題で、履修要件は少ない。
* [Khan Academy: Economics](https://www.khanacademy.org/economics-finance-domain) - 基礎的な話題。

### 有用な資料 <a id="useful-materials"></a>

* [Academic Search](https://cse.google.com/cse/publicurl?cx=002720237717066476899:e55ib8o11ka) - `.edu`などの教育ドメインを横断検索。これらの資料は広いインターネットより信頼性が高い。
* [Foundational Equations of Economics](http://economics.stackexchange.com/questions/35/what-are-the-foundational-equations-of-economics) - 「経済学者のように考える」ことを支える原則を示す方程式。大学院教科書がその背景を説明する。
* [IGM Economic Experts Panel](http://www.igmchicago.org/igm-economic-experts-panel) - 第一線の経済学者が政策関連の問題を考察。一部の回答には有用な詳細が含まれる。
* [AEA Resources for Economists](http://rfe.org/) - American Economic Associationが管理する有用なリンク集。

## 研究 <a id="research"></a>

### ポータル <a id="portals"></a>

* [RePEc](http://repec.org/) - 経済研究者向けWebサービス。参考文献、ブログ集約、新しいワーキングペーパー、ソフトウェアを提供。
* [Federal Reserve Bank of St. Louis: Web Services](https://research.stlouisfed.org/resources.html) - 役立つサービスの一覧。

### 論文とワーキングペーパー <a id="articles-and-working-papers"></a>

* [IDEAS RePEc](https://ideas.repec.org/) - 最大規模の経済学出版物データベース（200万件）。Googleでは``site:ideas.repec.org <search term>``で論文を検索しやすい。以下に挙げる情報源を索引化。
* [NBER](http://nber.org/papers.html) - 主要研究者によるワーキングペーパー。多くは査読付き学術誌へ掲載される。
* [SSRN Economics](http://ssrn.com/en/index.cfm/ern/) - ワーキングペーパー。学術誌出版物は含まない。
* [Google Scholar](http://scholar.google.com/) - 学術文献全般を検索。著者ページと被引用数を提供。経済学の文献だけを探すならIDEASの方が強力。

### データ <a id="data"></a>

データセット

* [FRED2](https://research.stlouisfed.org/fred2/) - 80の情報源から38万件の主にマクロ時系列を収録。Excel、Stata、Rなどへデータを取り込むプラグインに対応。モバイルアプリもある。
* [World Bank Data](http://data.worldbank.org/) - 国際的なマクロ時系列。データ取込プラグインあり。
* [IMF Data](http://www.imf.org/en/Data) - マクロデータの標準的な参照先。
* [Quandl](https://www.quandl.com/) - 複数の情報源から金融・経済データを集約。一部のデータ提供者はこのサービスでデータを販売。統計ソフトウェアとの統合に優れる。
* [MEDevEcon](https://sites.google.com/site/medevecon/devecondata) - 開発経済学関連データ。
* [Monetary Economics: Data Sources](https://sites.google.com/site/davesmant/various/data-sets-sources) - マクロデータ情報源の概要。
* [OFFSTATS](http://www.offstats.auckland.ac.nz/) - 国・主題別の公式データ情報源へのリンク。

検索

* [International Open Government Dataset Search](https://logd.tw.rpi.edu//node/9903) - 100万件以上の政府データセット。動作時は[このように](http://web.archive.org/web/20140815054106/http://logd.tw.rpi.edu/node/9903)表示される。それ以外では403エラーになる。
* [Dataset Search Engine](https://cse.google.com/cse/publicurl?cx=002720237717066476899:v2wv26idk7m) - ここで紹介するものを含む200のデータ情報源を横断するGoogleベースの検索。[検索演算子](http://www.googleguide.com/advanced_operators_reference.html)も使用可能。
* [StackExchange Open Data](http://opendata.stackexchange.com/) - 探しているデータが見つからなければ、ここで質問できる。
* [Reddit /r/datasets](https://www.reddit.com/r/datasets) - データセットを依頼できるもう一つの場所。

### ソフトウェア <a id="software"></a>

執筆

* [LaTeX](https://www.latex-project.org/) - 数学と参考文献をWordやLibreOfficeより適切に扱えるため、経済学者はLaTeXを使う。定期的に執筆するなら学ぶ価値がある。
  - [Beamer](https://www.ctan.org/pkg/beamer?lang=en) - プレゼンテーション用LaTeXクラス。
  - [TikZ](http://www.texample.net/tikz/examples/) - グラフ描画用拡張。[手引き](http://cremeronline.com/LaTeX/minimaltikz.pdf)と[マニュアル](http://www.texample.net/media/pgf/builds/pgfmanualCVS2012-11-04.pdf)がある。
* [LyX](http://www.lyx.org/) - 無料でシンプルなLaTeXエディター。
* [Zotero](https://www.zotero.org/) - 参考文献管理。RePEcからライブラリへ論文を取り込むZoteroブラウザープラグインと、文献を簡単に引用するZotero-LyXプラグインも導入するとよい。
* [Git](https://git-scm.com/downloads) - バージョン管理システム。数か月前の変更を戻す場合や他の著者と協働する場合に便利。DropBoxにもバージョン管理はあるが、Gitの方が明示的。[短い入門](http://rogerdudler.github.io/git-guide/)がある。簡単な操作を好むなら[GitHub Desktop](https://desktop.github.com/)も利用できる。
* [Mendeley](https://www.mendeley.com) - 参考文献管理。Mac、Windows、iPad、スマートフォンなど、複数プラットフォーム間の同期に対応。

計算

* [Stata](http://www.stata.com/) - 経済学の統計計算における業界標準。無料の代替：
  - [IPython](http://ipython.org/) - Pythonベースの環境。statsmodels、SciPy、NumPy、pandasなどの無料パッケージで計量経済分析を行う。
  - [RStudio](https://www.rstudio.com/) - Rベースの環境。Rは統計学者の標準言語であり、Rのリポジトリには他言語では利用できない専門ライブラリが多い。
* [Matlab](http://www.mathworks.com/products/matlab/) - 経済学のモデリングと数値最適化における業界標準。無料の代替：
  - [Octave](https://www.gnu.org/software/octave/)
  - [Julia](https://julialang.org/) - 高性能数値解析と計算科学の需要に応えるため設計された高水準動的プログラミング言語。
* [Mathematica](https://www.wolfram.com/mathematica/) - 記号計算。無料の代替：
  - [Sage](http://www.sagemath.org/)
* [Julia](https://julialang.org/) - オープンソースの科学計算ソフトウェア。

共有

* [GitHub](https://github.com/) - コードとデータのリポジトリ。研究をここで公開することは一般的ではないが、大学のホームページやDropBoxなどの代替手段より便利。
  - [GitHub Pages](https://pages.github.com/) - シンプルな静的Webサイト。
  - [GitHub LFS](https://git-lfs.github.com/) - 大容量ファイルストレージ。
* [IPython Notebooks](http://ipython.org/) - LaTeXやWordに代わる対話型ツール。Notebookの見た目は[data-science-ipython-notebooks](https://github.com/donnemartin/data-science-ipython-notebooks)と[ギャラリー](https://github.com/ipython/ipython/wiki/A-gallery-of-interesting-IPython-Notebooks)の例を参照。

レビュー

* [Most common programs used by Economists](http://economics.stackexchange.com/questions/5853/most-common-programs-used-by-economists) - コミュニティが管理する一般的なソフトウェア一覧。
* [Software for Researchers: New Data and Applications](https://antontarasenko.com/2016/01/14/software-for-research/) - 上述のソフトウェアなどを扱う。

## 議論 <a id="discussions"></a>

* ブログ - 経済学者に最も一般的な自己表現の形。主要なブログ集約サイト：
  - [EconAcademics.org](http://econacademics.org/)
  - [Economist's View](http://economistsview.typepad.com/) - Mark Thoma
  - [Grasping Reality](http://delong.typepad.com/) - Brad DeLong
  - [Marginal Revolution](http://marginalrevolution.com/) - Tyler CowenとAlex Tabarrok
  - [VOX CEPR](http://www.voxeu.org/) - CEPR会員
* [Economics Blog Search](https://cse.google.com/cse/publicurl?cx=002720237717066476899:i_zfef5fawa) - 上述のブログを対象とするGoogleベースの検索サービス。
* [AEA Blog Directory](https://www.aeaweb.org/rfe/showCat.php?cat_id=96) - 主要な経済学ブログ一覧。
* [StackExchange Economics](http://economics.stackexchange.com/) - 質問と回答を投稿できるQ&Aサイト。
* Reddit - 人気のニュース集約サイト。経済学関連の区分も多数ある。例：
  - [/r/GoodEconomics/](https://www.reddit.com/r/GoodEconomics/) - 経済問題に関する厳選記事。
  - [/r/EconPapers/](https://www.reddit.com/r/EconPapers/) - 経済学論文を議論。
* Discord - 人気のチャットプラットフォーム。
  - [Academic Economics](https://discord.gg/n9V7hjNtPV) - 経済学を議論し、演習でメンバーを支援するルームを備えたコミュニティ。

### プロジェクト <a id="projects"></a>
