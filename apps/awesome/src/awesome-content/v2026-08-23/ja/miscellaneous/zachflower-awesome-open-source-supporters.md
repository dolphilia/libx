# Awesome Open Source Supporters [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)

## タグ

### `requires-approval`

多くの企業は GitHub、Bitbucket、GitLab の公開リポジトリー機能を利用してプロジェクトのオープンソース状態を判断しますが、より多くの検証を必要とする企業もあります。このような企業には `requires-approval` タグが付けられ、オープンソース向けの特典を利用するには申請手続きが必要であることを示します。

### `non-commercial`

一部の企業は製品をオープンソース向けに提供しますが、非商用プロジェクトに限られます。このような企業には `non-commercial` タグが付けられます。
