## プロジェクト

*Vorpal を使って構築された優れたプロジェクトとアプリケーション。*

- [Cash](https://github.com/dthree/cash) - 不便さを取り除いたクロスプラットフォームの Linux コマンド。
- [Raptor](https://developer.mozilla.org/en-US/Firefox_OS/Automated_testing/Raptor) - Firefox 開発者向けの性能テスト CLI。
- [iTunes-remote](https://github.com/mischah/itunes-remote/) - CLI から iTunes を操作。
- [phunt](https://github.com/Kristories/phunt) - CLI から [Product Hunt](https://www.producthunt.com/) にアクセス。*ご想像どおり、Product Hunt でトレンド入りしました。*
- [trelew](https://github.com/websitesfortrello/trelew) - CLI から [Trello](https://trello.com/) にアクセス。
- [wat](https://github.com/dthree/wat) - あらゆる言語、プラットフォーム、ライブラリに対してコミュニティが作るドキュメント。
- [metronome](https://github.com/AljoschaMeyer/metronome-cli) - CLI 上で動作するリアルタイムのメトロノーム。
- [fastack](https://github.com/fastack/cli) - クライアントサイドアプリの開発を容易にする設定不要のツール。
- [cbcluster](https://www.npmjs.com/package/cbcluster) - Couchbase Server クラスター向け CLI。
- [quotr](https://github.com/andrerpena/quotr) - 株価を表示。
- [Vantage](https://github.com/dthree/vantage) - 稼働中の Node アプリ向けの `CLI` + `SSH` + `REPL`。
- [birdknife](https://github.com/vanita5/birdknife) - 高機能な [Twitter](https://twitter.com/) CLI。
- [tv-remote-cli](https://github.com/Glavin001/tv-remote-cli) - スマートテレビを遠隔操作する CLI。
- [launch](https://github.com/NewSpring/meteor-launch) - App Store、TestFlight、Hockey、Google Play などへの Meteor ビルドを自動化
- [lifxsh](https://github.com/ristomatti/lifxsh) - [LIFX](http://www.lifx.com) スマートライトを操作する対話型シェル。

## 拡張機能

*拡張機能は、プログラムから、または実行中に Vorpal の機能を追加します。*

#### POSIX 実装

- [less](https://github.com/vorpaljs/vorpal-less) - `less` コマンドの実装。
- [grep](https://github.com/vorpaljs/vorpal-grep) - `grep` コマンドの実装。

#### 開発ツール

- [repl](https://github.com/vorpaljs/vorpal-repl) - アプリのコンテキスト内にある REPL へ CLI を移行。
- [tour](https://github.com/vorpaljs/vorpal-tour) - Vorpal アプリ向けの対話型ツアーを構築。
- [watch](https://github.com/vantagejs/vantage-watch) - 稼働中の Vorpal 拡張機能をリアルタイムで更新。
- [log](https://github.com/AljoschaMeyer/vorpal-log) - 高度なロギングユーティリティ。
- [set-or-print](https://github.com/AljoschaMeyer/vorpal-setorprint) - コマンドで引数を簡単に設定・取得。

#### リアルタイム

- [use](https://github.com/vorpaljs/vorpal-use) - アプリの実行中に Vorpal 拡張機能をインポート。

#### 娯楽

- [hacker-news](https://github.com/vorpaljs/vorpal-hacker-news) - Hacker News で話題の上位項目を取得。

#### ツールボックス
- [rc](https://github.com/subk/vorpal-rc) - シンプルな .rc ファイル対応。
- [comment](https://github.com/subk/vorpal-comment) - Bash のようなコメントに対応。
- [as-default](https://github.com/ialpert/vorpal-as-default) - 特定のタスクを指定せず実行した場合に Vorpal タスクを起動。
