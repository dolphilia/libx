## 初心者向け

### YouTube プレイリスト
* [Khan Academy Algorithms](https://www.khanacademy.org/computing/computer-science/algorithms) - Tomas Cormen と Devin Balkcom が担当するアルゴリズム講座。
* FreeCodeCamp のアルゴリズムとデータ構造：[5時間版](https://www.youtube.com/watch?v=8hly31xKli0)、[49時間版](https://youtu.be/xwI5OBEnsZU?si=W3CduIEmUehJERHk) - 驚くようなアニメーションを使った、初心者向けの完全なアルゴリズムとデータ構造のチュートリアル。

### 書籍
* [Real World Algorithms: A Beginner's Guide](https://mitpress.mit.edu/books/real-world-algorithms) - 高度な数学やコンピューターサイエンスの予備知識がない読者向けのアルゴリズム入門。
* [Levitin. Introduction to Algorithms](https://www.amazon.com/Introduction-Design-Analysis-Algorithms-3rd/dp/0132316811) - パズル形式でアルゴリズムを非常に分かりやすく解説。プログラミング経験は不要です。

### 対話型学習と可視化
* [VisuAlgo](http://visualgo.net) - アニメーションでデータ構造とアルゴリズムを可視化。
* [See Algorithms](https://see-algorithms.com/) – アルゴリズムを可視化し、ユーザーが独自のグラフや二分木を作成・共有できます。
* [Recursive](https://recursive.oilater.com/en) - 呼び出し木、変数追跡、行の強調表示を使ってコード実行を段階的に可視化。Python と JavaScript/TypeScript に対応。

## プログラミングコンテスト

### ウェブサイト
* [CP-Algorithms](https://cp-algorithms.com/) - 競技プログラミング分野で特によく使われるアルゴリズムとデータ構造。

### 書籍
- [Steven Halim の Competitive Programming](https://cpbook.net/)

### コンテストサイト
* [HackerEarth](https://www.hackerearth.com/) - 初心者にも取り組みやすいチュートリアル。
* [Code Chef](https://www.codechef.com/contests) - 初心者にも取り組みやすい問題。
* [Codeforces](http://codeforces.com/) - 難度の高い問題。
* [TopCoder](https://www.topcoder.com/) - 技術企業がスポンサー。
* [Leet Code](https://leetcode.com/) - 面接問題。
* [UVA](https://uva.onlinejudge.org/) - 過去の ACM-ICPC 地区予選と世界大会の問題を収録。
* [ProjectEuler](https://projecteuler.net/) - 数学を重視した問題。

### ブログ
* [競技プログラミングの Awesome リスト！](https://codeforces.com/blog/entry/23054) - リソース、書籍、アルゴリズムを網羅した優れたブログ。
* [Algorithms Weekly](https://petr-mitrichev.blogspot.com/) - Petr Mitrichev による主に Java を扱う良質なブログ。
* [Tanuj Khattar によるアルゴリズムチュートリアル](https://tanujkhattar.wordpress.com/) - Tanuj Khattar による優れたブログ。興味深いデータ構造のチュートリアルと演習問題を収録。

## 理論と基礎

### 書籍
* [Introduction to Algorithms](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/) - 誰にでも薦められる定番の古典。
* [The Art of Computer Programming](http://www-cs-faculty.stanford.edu/~uno/taocp.html) - Knuth の古典。
* [The Algorithm Design Manual](http://www.algorist.com/) - 読みやすく、実世界の例が豊富。

### オンライン講座
* [MIT - 6-006](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/video_galleries/lecture-videos/) - アルゴリズムを分かりやすく解説。
* [MIT - 6-046j](https://ocw.mit.edu/courses/6-046j-introduction-to-algorithms-sma-5503-fall-2005/video_galleries/video-lectures/) - 前項と似ていますが、異なるアルゴリズムを扱います。
* [MIT - 6-00sc](http://ocw.mit.edu/courses/electrical-engineering-and-computer-science/6-00sc-introduction-to-computer-science-and-programming-spring-2011/index.htm) - 分かりやすく説明されたアルゴリズム入門。

### YouTube プレイリスト
* [Tim Roughgarden. Algorithms Illuminated](https://www.algorithmsilluminated.org/) - コンピューターサイエンスの先駆者 Tim Roughgarden が、自著を補完する講義動画とスライドを提供。

## 本番システム

* [Performance Engineering of Software Systems. MIT OCW](https://ocw.mit.edu/courses/6-172-performance-engineering-of-software-systems-fall-2018/) - 拡張可能で高性能なソフトウェアシステムを構築する、実践的なプロジェクト型入門。性能分析、高性能化のアルゴリズム技法、命令レベルの最適化、キャッシュ最適化を扱います。
* [Misra と Patel による Cloud and Distributed Computing: Algorithms and Systems](https://www.wileyindia.com/cloud-and-distributed-computing-algorithms-and-systems.html) - クラウドコンピューティングの内部構造と、分散システムの概念がクラウド内部でどう機能するかを解説。

## データベース

* [PostgreSQL Query Optimization: The Ultimate Guide to Building Efficient Queries](https://www.oreilly.com/library/view/postgresql-query-optimization/9781484268858/) - クエリの種類と、インデックスや特定の結合アルゴリズムなど各種類に適した最適化手法を紹介。

## 専門トピック

* [Fabulous Adventures in Data Structures and Algorithms](https://www.manning.com/books/fabulous-adventures-in-data-structures-and-algorithms) - イミュータブルなスタック、キュー、両端キューなどのデータ構造や、Hughes リストのような珍しい構造など、あまり知られていないアルゴリズム手法を解説。
