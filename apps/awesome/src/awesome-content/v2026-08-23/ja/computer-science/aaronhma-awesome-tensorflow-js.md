- [公式ドキュメント](https://www.tensorflow.org/js/guide)
- [APIリファレンス](https://js.tensorflow.org/api/latest/)


### 📝 チュートリアル <a id="tutorials"></a>

- [TensorFlow.js gallery](https://github.com/tensorflow/tfjs/blob/master/GALLERY.md) - TensorFlow.jsのプロジェクト、チュートリアル、動画などを集めたギャラリー。
- [Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course/) - Googleによる、テンポが速く実践的な機械学習入門。
- [Google Codelabs](https://codelabs.developers.google.com/) - ガイド付きチュートリアルで実際にコードを書く体験を提供するGoogle Developers Codelabs。
- [Beginning ML with TensorFlow.js](https://academy.infinite.red/p/beginning-machine-learning-with-tensorflow-js) - Web開発者がTF.jsを学び始めるための完全なオンラインコース。
- [Effective TensorFlow.js](https://effectivemachinelearning.com/TensorFlow.js) - TensorFlow.jsのチュートリアルとベストプラクティス。


### 🤖 モデル／プロジェクト <a id="modelsprojects"></a>

- [TensorFlow.jsリポジトリの公式tfjsモデル](https://github.com/tensorflow/tfjs-models) - TensorFlow.js向けの事前学習済みモデル。
- [TensorFlow.jsサイトの公式tfjsモデル](https://www.tensorflow.org/js/models) - あらゆるプロジェクトですぐに利用できる事前学習済みTensorFlow.jsモデルを探せます。
- [NPMの@tensorflow-models](https://www.npmjs.com/search?q=%40tensorflow-models) - NPMで公開されているTensorFlow.js向けのさまざまな事前学習済みモデル。
- [公式tfjsサンプルリポジトリ](https://github.com/tensorflow/tfjs-examples) - TensorFlow.jsで構築されたサンプル。
- [公式tfjsデモサイト](https://www.tensorflow.org/js/demos) - TensorFlow.jsで構築されたサンプルとライブデモ。


### 📎 論文 <a id="papers"></a>

- [TensorFlow.js: Machine Learning for the Web and Beyond](https://arxiv.org/abs/1901.05350) - TensorFlow.jsの設計、API、実装を説明し、影響力のあるユースケースを紹介する論文。
- [JSDoop and TensorFlow.js: Volunteer Distributed Web Browser-Based Neural Network Training](https://arxiv.org/abs/1910.07402) - 分散したWebブラウザでのニューラルネットワーク訓練が実現可能かつ正確で、高いスケーラビリティを持ち、興味深い研究領域であることを実験結果で示しています。


### 🎥 動画 <a id="videos"></a>

- [公式TensorFlow.js動画シリーズ](https://www.youtube.com/playlist?reload=9&list=PLs6AluHXaQnjeI6jzDkpKXvbPj31i4GgF) - TensorFlowエコシステムの更新を中心に扱うYouTubeコンテンツ。
- [TensorFlow.js: ML for the web and beyond](https://youtu.be/iH9CS-QYmZs) - TensorFlow Dev Summit 2020。
- [Rock Paper Scissors!](https://www.youtube.com/watch?v=y4pfTQJaUJU) - 自分のマシンでじゃんけんを学習させ、Webカメラで結果を確認します。
- [Color Blind Tensors](https://www.youtube.com/watch?v=X55m9eS5UFU) - 画像テンソルを操作して色覚特性を再現するライブコーディング。


### 📚 書籍 <a id="books"></a>

- [Deep Learning with JavaScript](https://www.manning.com/books/deep-learning-with-javascript) - Shanqing Cai、Stanley Bileschi、Eric D. Nielsen、Francois Cholletによる、ブラウザで直接動く深層学習モデルをTensorFlow.jsで構築する方法を学び、深層学習の基礎から、既存モデルの転移学習向け再訓練や画像生成などの高度な概念まで扱う書籍。

- [Hands-On Machine Learning with TensorFlow.js](https://www.amazon.com/Hands-Machine-Learning-TensorFlow-js-applications/dp/1838821732) - Kai Sasakiによる、TensorFlow.jsライブラリを使ってWeb技術と統合した機械学習アプリケーションを構築するためのガイド。

- [Learning Tensorflow.js: Powerful Machine Learning in JavaScript](https://amzn.to/3dR3vpY) - 著者の[Gant Laborde](https://github.com/gantman)が、データサイエンティスト、エンジニア、Web開発者、学生、研究者を含む幅広い技術者向けに、TensorFlow.jsの基礎を実践的かつ一気通貫で解説します。

- [Practical TensorFlow.js](https://www.apress.com/gp/book/9781484262726) - Juan De Dios Santos RiveraによるWebアプリ開発での深層学習。

- [Practical Machine Learning in JavaScript](https://www.apress.com/gp/book/9781484264171) - Charlie GerardによるWeb開発者向けTensorFlow.js。

### 🤩 TensorFlow.js採用事例 <a id="powered-by-tensorflowjs"></a>

- [Handwritten Digit Classification](https://github.com/aaronhma/ngconf-2020) - [NgConf 2020](https://www.ng-conf.org/)の講演「**A Journey into the World of Machine Learning with TensorFlow.js**」向けショーケースプロジェクト。
- [NSFWJS - Indecent Content Checker](https://github.com/infinitered/nsfwjs) - クライアントまたはサーバーで画像に不適切な内容が含まれるかを確認する扱いやすいライブラリ。
- [Pose Animator](https://pose-animator-demo.firebaseapp.com/camera.html) - モーションキャプチャーにより、ブラウザ上でSVGキャラクターを動かすツール。
- [LipSync](https://lipsync.withyoutube.com/) - お気に入りの曲に合わせてリップシンクを楽しめる、遊び心のあるインタラクティブなWeb体験。
- [BodyPix](https://storage.googleapis.com/tfjs-models/demos/body-pix/index.html) - ブラウザでリアルタイムに人物と身体部位をセグメンテーションします。


## 🔨 ツール <a id="tools"></a>

### ライブラリ <a id="libraries"></a>

- [TensorFlow.js](https://github.com/tensorflow/tfjs) - 機械学習モデルの訓練とデプロイに対応する、WebGLで高速化されたJavaScriptライブラリ。
- [ml5.js](https://ml5js.org/) - Web向けの親しみやすい機械学習。
- [face-api.js](https://github.com/justadudewhohacks/face-api.js) - TensorFlow.jsを利用し、ブラウザとNode.jsで顔検出と顔認識を行うJavaScript API。
- [handtrack.js](https://github.com/victordibia/handtrack.js/) - ブラウザ上で直接、リアルタイムの手検出（境界ボックス）を試作するためのライブラリ。
- [magenta.js](https://magenta.tensorflow.org/get-started/#magenta-js) - ブラウザ上の機械知能による音楽とアートの生成。
- [Danfo.js](https://danfo.jsdata.org/) - 構造化データの操作と処理に使える、高性能で直感的かつ扱いやすいデータ構造（Pandasに着想を得ています）。


### ツール／ユーティリティ <a id="toolsutilities"></a>

- [Glitch](https://glitch.com/@TensorFlowJS) - ブラウザ内でフルスタックWebアプリをすばやく無料構築できます（TensorFlow.jsテンプレート）。
- [CodePen](https://codepen.io) - *bit.ly/codepen-tfjs* フロントエンドコードを構築、テスト、発見するのに最適な場所（TensorFlow.jsテンプレート）。
- [TensorFlow Playground](https://playground.tensorflow.org) - ブラウザ上ですぐにニューラルネットワークを試せます。
- [AiJS](https://aijs.rocks/) - AIを活用した刺激的なJavaScriptアプリを厳選したコレクション。
- [Teachable Machine](https://teachablemachine.withgoogle.com/) - 自分の画像、音声、ポーズをコンピューターに認識させる訓練ができます。
- [TensorPlayground.com](https://www.tensorplayground.com/1.0.0/) - ブラウザ上でテンソルを直接記述、変更、表示し、そのコードをほかの人と共有できます。
