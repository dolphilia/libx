## TypeDB を使用するオープンソースプロジェクト

- [`TypeDB Studio - IDE for TypeDB`](https://github.com/vaticle/typedb-studio) - TypeDB Studio は、ナレッジエンジニアリングを行うための TypeDB 向け統合開発環境です。
- [`Blitz-ORM`](https://github.com/Blitzapps/blitz-orm) - Blitz-ORM は TypeScript で書かれ、TypeDB と互換性のあるオブジェクトリレーショナルマッパーです。
- [`go-typeql`](https://github.com/CaliLuke/go-typeql) - 型安全な CRUD、クエリ構築、マイグレーション、コード生成を備えた TypeDB 3.x 向け Go ORM。
- [`skills`](https://github.com/typedb/typedb-skills) - エージェントワークフロー向けの TypeDB スキルを含む、エージェントスキルのコレクション。
- [`TypeDB-ML`](https://github.com/vaticle/typedb-ml) - TypeDB-ML は、TypeDB でグラフアルゴリズムと機械学習を可能にするツールを提供します。
- [`TypeDB Loader`](https://github.com/typedb-osi/typedb-loader) - 大規模にデータを TypeDB へ読み込むためのオープンソースデータ移行ツール。
- [`TypeDB OSI - Cyber Threat Intelligence`](https://github.com/typedb-osi/typedb-cti) - TypeDB CTI は、脅威インテリジェンスの専門家が分散した CTI 情報を一つのデータベースに集約し、サイバー脅威について新たな洞察を得られるオープンソース脅威インテリジェンスプラットフォームです。
- [`TypeDB OSI - Biomedical Knowledge Graph`](https://github.com/typedb-osi/typedb-bio) - TypeDB Bio は、生物医学研究者が相互接続され異種混在する生物医学データを一か所で直感的にクエリできる、オープンソースの生物医学ナレッジグラフです。
- [`Source++`](https://github.com/sourceplusplus/Assistant) - ランタイム認識・コンテキスト認識機能を備えたオープンソース自動プログラミングアシスタント。
- [`Rasa`](https://github.com/RasaHQ/rasa) - テキストおよび音声による会話を自動化するオープンソース機械学習フレームワーク。
- [`TypeBridge`](https://github.com/ds1sqe/type-bridge) - TypeDB の型システムと整合する属性ベース API を備えた、モダンで Python 的な TypeDB 向け ORM。
