> 優れた Adafruit IO のガイド、ハードウェア、動画、ライブラリ、フレームワーク、リソースを厳選したリストです。

[Adafruit IO は、プロジェクトをインターネットへ接続する最も簡単な方法です](https://io.adafruit.com)。好みのデバイスとプログラミング言語（多数のライブラリがあります）を使ってプロジェクトを簡単に Adafruit IO へ接続し、インターネット経由で制御・監視できます。Adafruit IO に保存したデータは、管理・制御する権利を持つ_あなた自身_のものです。いつでもすべてダウンロードでき、私たちが別の企業へ販売・提供することはありません。モノのインターネットを始めるのに最適です！

## コード

- [Adafruit IO HTTP API ドキュメント](https://io.adafruit.com/api/docs/#adafruit-io-http-api) - HTTP を扱える任意のプログラミング言語や環境から Adafruit IO のデータへアクセスできます。
- [Adafruit IO MQTT API ドキュメント](https://io.adafruit.com/api/docs/mqtt.html#adafruit-io-mqtt-api) - 任意の MQTT クライアントから Adafruit IO のデータへアクセスできます。
- [Adafruit IO MQTT API クックブック](https://io.adafruit.com/api/docs/cookbook.html#adafruit-io-api-cookbook) - 過去に役立った Adafruit IO API 関連のレシピ。
- [Adafruit IO Arduino ライブラリ](https://github.com/adafruit/Adafruit_IO_Arduino) - Adafruit IO 向け Arduino クライアント。
- [Adafruit IO CircuitPython ライブラリ](https://github.com/adafruit/Adafruit_CircuitPython_AdafruitIO) - Adafruit IO 向け CircuitPython クライアント。
- [Adafruit IO Python ライブラリ](https://github.com/adafruit/Adafruit_IO_Python) - Adafruit IO 向け Python クライアント。
- [Adafruit IO Ruby ライブラリ](https://github.com/adafruit/io-client-ruby) - Adafruit IO 向け Ruby クライアント。
- [Adafruit IO Node.js ライブラリ](https://github.com/adafruit/adafruit-io-node) - Node.js 用 Adafruit IO クライアント、ローカルサーバー、TLS トンネル。
- [Adafruit IO Go ライブラリ](https://github.com/adafruit/io-client-go) - Adafruit IO 向け Go クライアント。
