## OSイメージ

- [Alpine Linux](https://wiki.alpinelinux.org/wiki/Raspberry_Pi) - セキュリティに配慮した、軽量なLinuxディストリビューション。musl libcとbusyboxに基づく。
- [Anthias](https://anthias.screenly.io/) - 世界で最も人気のあるオープンソースデジタルサインプロジェクト。
- [Arch Linux ARM](https://archlinuxarm.org/) - 軽量で柔軟なLinuxディストリビューション。シンプルを維持しようとする。
- [Armbian](https://www.armbian.com/rpi4b/) - 単一ボードコンピュータ（SBC）向けの基本的なオペレーティングシステムプラットフォームで、他のプロジェクトが信頼して構築できるもの。
- [balenaOS](https://www.balena.io/os/) - 信頼性に重点を置き、実際の運用環境で検証された、エッジデバイスにDockerコンテナを実行できるオープンソースOS。
- [BerryBoot](http://www.berryterminal.com/doku.php/berryboot) - ブートローダー／ユニバーサルOSインストーラーで、VNCおよびHDMI-CECに対応。
- [chilipie-kiosk](https://github.com/futurice/chilipie-kiosk) - フルスクリーンのChromeに直接起動するイメージで、ダッシュボードやビルドモニタに最適。 ![Supports Raspberry Pi 2+](https://raw.githubusercontent.com/thibmaek/awesome-raspberry-pi/8e140f45f5b1f33c57ea1f5d945cd8af0e32c88e/media/badges/rpi-2+.png)
- [Channels DVR Server](https://getchannels.com/raspberry-pi/) - Channels DVRサーバー用のカスタムイメージで、完全なホームDVRシステムを提供。
- [Debian](https://raspi.debian.net) - ラズベリーパイ向けの非公式Debianイメージ（Debian開発者によって維持）。
- [DietPi](https://github.com/Fourdee/DietPi) - 2GBのSDカードに収まる最小限のイメージで、多数の設定項目とスクリプトを提供。
- [DroneBridge](https://github.com/seeul8er/DroneBridge) - WifiBroadcast拡張により、DJI Lightbridgeや類似システムへの実用的な代替案を提供。 ![Supports Raspberry Pi 3](https://raw.githubusercontent.com/thibmaek/awesome-raspberry-pi/8e140f45f5b1f33c57ea1f5d945cd8af0e32c88e/media/badges/rpi-3.png)
- [EZ-WifiBroadcast](https://github.com/bortek/EZ-WifiBroadcast/wiki) - 安価で使いやすい無線デジタルHD動画送信。 ![Supports Raspberry Pi 3](https://raw.githubusercontent.com/thibmaek/awesome-raspberry-pi/8e140f45f5b1f33c57ea1f5d945cd8af0e32c88e/media/badges/rpi-3.png) ![Supports Raspberry Pi Zero](https://raw.githubusercontent.com/thibmaek/awesome-raspberry-pi/8e140f45f5b1f33c57ea1f5d945cd8af0e32c88e/media/badges/rpi-0.png)
- [Fedora](https://fedoraproject.org/wiki/Raspberry_Pi#Preparing_the_SD_card) - ラズベリーパイ向けに構築されたFedora Linuxディストリビューション。 ![Supports Raspberry Pi 2+](https://raw.githubusercontent.com/thibmaek/awesome-raspberry-pi/8e140f45f5b1f33c57ea1f5d945cd8af0e32c88e/media/badges/rpi-2+.png)
- [FreeBSD](https://wiki.freebsd.org/arm/Raspberry%20Pi) - FreeBSDは、現代のサーバー、デスクトップ、エッジプラットフォームを駆動する高度なコンピュータOS。

## ツール

- [Alpha](https://github.com/farjump/raspberry-pi) - GDBを使用して、このシステムレベルのGDBサーバーで、裸金属プログラムをリモートでロード、デバッグ、テスト
- [ApplePi Baker](https://www.tweaking4all.com/hardware/raspberry-pi/applepi-baker-v2/) - macOSアプリでSDカードへのイメージのインストール／バックアップ／復元を簡単に実行
- [Armbian Imager](https://imager.armbian.com) - オープンソースの画像ツールでアームビアンOSのインストールを容易にします
- [Atlas toolkit](https://github.com/epeios-q37/atlas-python) - 非常に軽量で、WebアプリケーションをPythonで1ページで作成できるツールキット。これにより、Webサーバーをインストールしなくても、RPiを制御できます
- [balenaEtcher](https://www.balena.io/etcher/) - エンドユーザーにとって簡単で、開発者にとって拡張性のあるSDカード焼入れアプリ。すべてのプラットフォームで動作します
- [n01d-forge](https://github.com/bad-antics/n01d-forge) - Rustによるネイティブイメージ焼入れツールで、LUKS/VeraCrypt暗号化をサポート。Raspberry Pi用の安全な起動可能なSDカードを作成に最適です
- [Drago](https://seashell.github.io/drago) - Wireguardネットワーク向けの柔軟な設定マネージャー。複数のRaspberry Piを結ぶ安全なオーバーレイを構築に最適です
- [Embedible](https://embedible.io/) - AIが、あなたの電子機器のアイデアを実際に動くRaspberry Pi Picoプロジェクトに変換します
- [Hardened Kernel Builder for RPi](https://github.com/tschaffter/raspberry-pi-kernel-hardened) - 1コマンドでRaspberry Pi用のLinuxカーネルをクロスコンパイル。強化されたセキュリティを実現します
- [HealthyPi](https://github.com/Protocentral/protocentral-healthypi-v3) - ECG、呼吸、脈拍酸素測定などの重要な健康モニタリングを含むHAT。オプションで血圧および体表面温度センシングもサポートしています。 ![Supports Raspberry Pi 2+](https://raw.githubusercontent.com/thibmaek/awesome-raspberry-pi/8e140f45f5b1f33c57ea1f5d945cd8af0e32c88e/media/badges/rpi-2+.png)
- [iotwifi](https://github.com/cjimti/iotwifi) - 8MBでWifi AP＋クライアント管理。Wifiクライアントおよびステーションモードを同時に制御できるREST APIを備えています。 [Docker Container](https://hub.docker.com/r/cjimti/iotwifi/), with REST API for controlling wifi client and station modes simultaneously. ![Supports Raspberry Pi 3](https://raw.githubusercontent.com/thibmaek/awesome-raspberry-pi/8e140f45f5b1f33c57ea1f5d945cd8af0e32c88e/media/badges/rpi-3.png)
- [ndm](https://github.com/gitbls/ndm) - DNSおよびDHCPサーバーを簡単に管理できるコマンドラインツールです
- [Orangetool](https://github.com/Moduland/Orangetool) - Pythonによるシングルボードコンピュータの制御機能です
- [OSMC Installer](https://osmc.tv/download/) - OSMCをさまざまなプラットフォームにダウンロード・インストールできるGUIベースのユーティリティです
- [Pi Temperature Exporter](https://github.com/s-nagaev/pi-temperature-exporter) - Prometheusの消費に向けたCPUおよびGPU温度エクスポートツールです
- [pi-gen](https://github.com/RPi-Distro/pi-gen) - raspberrypi.orgのRaspbianイメージを作成するためのツール。特定のパッケージをインストールしたカスタムイメージを作成するなど、さまざまな用途に活用できます
- [Raspberry Pi GPIO Pinout](https://raspberry.tips/en/raspberry-pi-gpio-pinout) - すべての40GPIOピンについて、BCM番号、機能、電圧仕様、HATオーバーレイを含むインタラクティブピンアウトリファレンス。Pi 5（RP1コントローラー）向けに更新されています

### Swiftプログラミング

- [BuildSwiftOnARM](https://github.com/uraimo/buildSwiftOnARM) - Raspberry Piまたは他のARMボード上でSwiftを構築するための必要なすべての情報（Swift 4.1.3に更新）.
- [Compile Swift for Raspberry Pi by Visual Studio Code](https://medium.com/@programmingpassion/compile-swift-for-raspberry-pi-by-visual-studio-code-3f303e32d34e) - Visual Studio CodeでRaspberry Piコードのコンパイル設定を手軽に共有するチュートリアル.
- [Compile Swift for Raspberry Pi by Xcode](https://medium.com/@programmingpassion/compile-swift-for-raspberry-pi-by-xcode-406ac26b63ec) - XcodeでRaspberry Piコードのコンパイル設定を手軽に共有するチュートリアル.
- [Setup Swift environment on Raspbian](https://medium.com/@programmingpassion/set-up-swift-environment-on-raspberry-pi-part-2-2-56f7f33b00d) - Raspbian stretch (lite)上でSwift環境を構築するための簡易ガイド.
- [SwiftyGPIO](https://github.com/uraimo/SwiftyGPIO) - Linux/ARMボード向けのハードウェアプロジェクト用Swiftライブラリ（GPIO/SPI/I2C/PWM/UART/1Wireに対応）.
- [Swish](https://github.com/thomaspaulmann/Swish) - Xcode上でリモートマシンでSwiftプロジェクトを構築する方法
