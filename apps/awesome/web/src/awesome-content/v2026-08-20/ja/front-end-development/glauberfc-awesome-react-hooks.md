## 拡張・ライブラリ

- [redux-react-hook](https://github.com/facebookincubator/redux-react-hook) - Redux ストアから state と dispatch にアクセスするための React Hook。
- [react-use](https://github.com/streamich/react-use) - 必須の React Hooks のコレクション。
- [The Platform](https://github.com/palmerhq/the-platform) - よくある状況に使える、React Hooks と Suspense 対応 React 要素に変換したブラウザー API。
- [eslint-plugin-react-hooks](https://www.npmjs.com/package/eslint-plugin-react-hooks) - よくある誤りを避けるため Hooks のルールを強制するプラグイン。
- [react-hooks-lib](https://github.com/beizhedenglong/react-hooks-lib) - 再利用可能な React Hooks のセット。
- [use-immer](https://github.com/mweststrate/use-immer) - state を操作するために immer を React hook として使うフック。
- [react-hanger](https://github.com/kitze/react-hanger) - React 16.7 向けの便利な hooks の小さなコレクション。
- [react-firebase-hooks](https://github.com/csfrequency/react-firebase-hooks) - Firebase 向けの再利用可能な React Hooks のセット。
- [react-intersection-visible-hook](https://github.com/AvraamMavridis/react-intersection-visible-hook) - IntersectionVisible Observer に基づき、関数コンポーネントの可視性を追跡する React hook。
- [use-timer](https://github.com/thibaultboursier/use-timer) - タイマーを扱うためのシンプルな React hook。
- [react-native-hooks](https://github.com/react-native-community/react-native-hooks) - ステートレスな React コンポーネントで使える React Hooks に変換した React Native API。
- [react-with-hooks](https://github.com/yesmeck/react-with-hooks) - 提案されている React Hooks API の Ponyfill。
- [react-hooks-screen-type](https://github.com/pankod/react-hooks-screen-type) - Bootstrap 4 グリッド向けの画面サイズタイプ判定。
- [use-http](https://github.com/alex-cory/react-usefetch) - アイソモーフィックな HTTP リクエストを行う React hooks。
- [react-fetch-hook](https://github.com/ilyalesik/react-fetch-hook) - Fetch API を便利に使うための React hook。
- [storeon](https://github.com/storeon/storeon) - 173 バイトの hook ベース状態マネージャー。
- [react-hook-form](https://github.com/bluebill1049/react-hook-form) - 使いやすいバリデーション機能を持つ、高性能で柔軟かつ拡張可能なフォーム。
