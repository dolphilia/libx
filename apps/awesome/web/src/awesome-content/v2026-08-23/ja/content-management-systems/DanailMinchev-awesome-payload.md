# Awesome Payload

[Payload](https://payloadcms.com/)は、Next.jsと標準で統合され、Next.jsアプリへ直接インストールしてAPIや管理画面を作る、無料でオープンソースのフルスタックNext.jsフレームワーク兼ヘッドレスCMSです。公式資料、チュートリアル、実装例、テンプレート、認証・コンテンツ編集・翻訳などのコミュニティプラグインを探せます。

## プラグイン

Payloadの機能を拡張するコミュニティプラグイン。

- [r1tsuu / payload-enchants](https://github.com/r1tsuu/payload-enchants) — Payloadの機能を拡張するパッケージ集。

- [authsmith / payload-auth-plugin](https://github.com/authsmith/payload-auth-plugin) — Payloadの認証処理を拡張し、OAuthとパスキーによる認証を追加するプラグイン。

- [payload-auth / payload-auth](https://github.com/payload-auth/payload-auth) — Payloadとさまざまな認証プロバイダーを連携させるモノレポ。

- [CrawlerCode / payload-authjs](https://github.com/CrawlerCode/payload-authjs) — Auth.js用のPayloadプラグイン。

- [ashbuilds / payload-ai](https://github.com/ashbuilds/payload-ai) — コンテンツの作成と管理を支援するAI機能を組み込むプラグイン。

- [elliott-w / imageAspectRatios.ts](https://gist.github.com/elliott-w/19676d9373d79ee20b9195601dc45808) — 画像のアスペクト比を扱うPayloadプラグイン。

- [AdrianMaj / payload-lexical-typography](https://github.com/AdrianMaj/payload-lexical-typography) — Lexicalの文字色、フォントサイズ、文字間隔、行高、フォントファミリーなどの設定を拡張するプラグイン。

- [rilrom / payload-bites](https://github.com/rilrom/payload-bites) — image-search、fullscreen-editor、audit-fields、soft-delete、activity-logなど、Payload v3用の小規模なプラグイン集。

- [shefing / payload-tools](https://github.com/shefing/payload-tools) — 認可、著者情報、リッチテキストのコメント、右パネル、独自のバージョン表示、コレクション間の設定、フィールド型コンポーネントの上書き、カラーピッカーフィールド、アイコン選択、クイックフィルター、一覧表示のリセットなどを提供するプラグイン集。

- [Crayonan / payload-plugin-ai-localization](https://github.com/Crayonan/payload-plugin-ai-localization) — 主言語以外のローカライズ対象フィールドに、AIによる「翻訳」ボタンを追加。OpenAIなどのモデルを使い、主言語の内容を自動翻訳。
