# Awesome Terraform

[Terraform](https://www.terraform.io/)はAPIを宣言的な設定ファイルにまとめ、チームで共有・編集・レビュー・版管理できるインフラコードを作成します。固定原文では、本番インフラを安全かつ予測可能に作成・変更・改善するオープンソースツールとして紹介されています。このリストでは、公式資料、学習教材、モジュールとプロバイダー、レジストリ、テスト・自動化ツール、セルフホスト型・マネージド型のTerraformプラットフォームを探せます。
