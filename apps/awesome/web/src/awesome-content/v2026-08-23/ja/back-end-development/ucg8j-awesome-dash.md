# Awesome Dash

[Dash](https://plot.ly/products/dash/)はFlask、Plotly.js、React.jsを基盤とするPythonフレームワークです。データ可視化アプリと柔軟にカスタマイズできるUIを、Pythonだけで記述できます。デプロイ方法、チュートリアル、コンポーネントライブラリ、アプリ例、ギャラリー、講演、チートシート、コミュニティを紹介し、説明や統計は固定した上流版に基づいています。

## デプロイ <a id="deployment"></a>

- [Ploomber Cloud](https://ploomber.io) - コミュニティプランで無料デプロイが可能。

## コンポーネントライブラリ <a id="component-libraries"></a>

- [Dash PDF](https://github.com/ploomber/dash-pdf) - PDFをインライン表示。
- [Dash MUI](https://github.com/ploomber/dash-mui) - Material UIコンポーネント。
- [Dash React Simple Maps](https://github.com/ploomber/dash-react-simple-maps) - 対話的な地図を作成。
- [Dash Mosaic](https://github.com/ploomber/mosaic-python#dash-mosaic) - [Mosaic](https://github.com/uwdata/mosaic)のグラフを表示。
- [Dash Tabler Icons](https://github.com/ploomber/dash-tabler-icons) - Dashアプリ向けのアイコン。
- [Dash React Syntax Highlighter](https://github.com/ploomber/dash-react-syntax-highlighter) - コピーボタン付きのコードスニペットを表示。
- [Dash Canvas Components](https://dash.plotly.com/canvas) - Dashを使った画像のアノテーションと画像処理のためのモジュール。
- [Awesome React Components](https://github.com/brillout/awesome-react-components) - Dashコンポーネントとしてラップする候補となるReact.jsコンポーネントの一覧。
- [Awesome React](https://github.com/enaqx/awesome-react) - React.jsコンポーネント開発の参考資料。
- [Dash Core Components](https://github.com/plotly/dash-core-components)
- [Dash Cytoscape Component](https://dash.plotly.com/cytoscape) - 容易にカスタマイズでき、高性能で対話的なWeb上のネットワークを作成するグラフ可視化コンポーネント。
- [Dash DataTable Component](https://dash.plotly.com/datatable) - 多様なスタイル設定、条件付き書式、編集、並べ替え、フィルタリングなどに対応する対話的なテーブル。
- [Dash DAQ Components](https://dash.plotly.com/dash-daq) - データ取得と制御をDashアプリケーションに統合しやすくするコントロール群。
- [Dash HTML Components](https://github.com/plotly/dash-html-components)
- [mydcc](https://github.com/jimmybow/mydcc) - Dash Core Componentsの拡張。
- [sd-material-ui](https://github.com/StratoDem/sd-material-ui) - StratoDem AnalyticsによるDash向けmaterial-uiコンポーネントの実装。
- [sd-range-slider](https://github.com/StratoDem/sd-range-slider) - Dash用の範囲スライダーコンポーネント。
- [dj-plotly-dash](https://github.com/pikhovkin/dj-plotly-dash) - Django向けのPlotly Dashフォーク。
- [dash-flexbox-grid](https://github.com/pikhovkin/dash-flexbox-grid) - Plotly Dash向けのreact-flexbox-gridラッパー。
- [dash-color-picker](https://github.com/vivekvs1/dash-color-picker) - react-colorのラッパー。
- [dash-dual-listbox](https://github.com/vivekvs1/dash-dual-listbox) - react-duallistのラッパー。
- [dash-bootstrap-components](https://dash-bootstrap-components.opensource.faculty.ai/) - Dash向けのBootstrapコンポーネント。
- [dash-uploader](https://github.com/np-8/dash-uploader) - Dash向けのアップロードコンポーネント。大きなデータファイルに対応。
- [Dash Mantine Components](https://github.com/snehilvj/dash-mantine-components) - Mantine React Componentsライブラリに基づく40超のDashコンポーネント。
- [plotly-resampler](https://github.com/predict-idlab/plotly-resampler) - データのダウンサンプリング（集約）を追加して大規模データセットの可視化を可能にする、plotlyの図のラッパー。
- [dash-vega-components](https://github.com/altair-viz/dash-vega-components) - Vega-Altair、Vega-Lite、Vegaのグラフ向けDashコンポーネント。

## アプリ例 <a id="app-examples"></a>

- [Oil and Gas Explorer](https://dash.gallery/dash-oil-and-gas/) - 相互に連動する可視化で石油・ガス生産の時間変化を探索。[ソースコード](https://github.com/plotly/dash-oil-and-gas-demo)。
- [Uber Rides](https://dash.gallery/dash-uber-rides-demo/) - 2014年のニューヨーク市のUber乗車をすべて表示。バックエンドでPandasが0.5ギガのデータファイルをフィルタリング。[ソースコード](https://github.com/plotly/dash-sample-apps/tree/main/apps/dash-uber-rides-demo)。
- [Drug Discovery](https://dash.gallery/dash-drug-discovery/) - グラフ上の点にポインターを合わせると薬剤の説明を表示。[ソースコード](https://github.com/plotly/dash-sample-apps/tree/main/apps/dash-drug-discovery)。
- [Live Wind Streaming](https://dash.gallery/dash-wind-streaming/) - SQLデータベースを継続的に照会し、風速・風向のライブグラフを表示。[ソースコード](https://github.com/plotly/dash-sample-apps/tree/main/apps/dash-wind-streaming)。
- [3D Yield Curve](https://dash.gallery/dash-yield-curve/) - NYTimesの[A 3-D View of a Chart That Predicts The Economic Future: The Yield Curve](https://www.nytimes.com/interactive/2015/03/19/upshot/3d-yield-curve-economic-growth.html)を基にしたアプリ。[ソースコード](https://github.com/plotly/dash-sample-apps/tree/main/apps/dash-yield-curve)。
- [Visualize Earthquakes with Plotly Dash](https://dash-earthquakes-production-45eyyotfta-ey.a.run.app/) - DashのUIと地理空間分析を示す例。[基本的なユニットテスト](https://github.com/jackdbd/dash-earthquakes/tree/master/tests)を収録。[ソースコード](https://github.com/jackdbd/dash-earthquakes)。
- [GutenSearch](https://gutensearch.com/) - Project Gutenbergの書籍を検索。[ソースコード](https://github.com/cordb/gutensearch)。
