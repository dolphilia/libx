# Awesome Reflex

[Reflex](https://reflex.dev)は、ウェブアプリのフロントエンドとバックエンドをPythonだけで構築するオープンソースフレームワークです。HTML、CSS、JavaScriptを書かずに、小規模なデータサイエンスのアプリから大規模な複数ページのウェブサイトまで作成できます。このリストでは、公式テンプレートとアプリ例、ドキュメントと教材、コンポーネントライブラリ、データベース・認証ツール、コミュニティの案内を探せます。

[Reflexの完全なアプリ例](https://github.com/reflex-dev/reflex-examples)を専用リポジトリで確認できます。

Reflex自身のウェブサイトもReflexで構築されています。[ソースコード](https://github.com/reflex-dev/reflex-web)を確認できます。
