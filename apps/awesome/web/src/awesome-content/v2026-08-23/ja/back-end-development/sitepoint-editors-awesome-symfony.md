# Awesome Symfony

[Symfony](http://symfony.com)の管理画面、フォーム、ストレージ、認証、API、アプリケーション開発に使うバンドルやツールを探せます。認定資格の学習資料、コミュニティ、書籍、設定レシピも収録しています。対応版とメンテナンス状況の説明は、固定した上流スナップショットに基づきます。

## 管理 <a id="administration"></a>

* [AdminCrudBundle](https://github.com/MWSimple/AdminCrudBundle) - SensioGeneratorBundleを使用し、コントローラーをページネーター、フィルターなどの機能で拡張。
* [AdmingeneratorGeneratorBundle](https://github.com/symfony2admingenerator/AdmingeneratorGeneratorBundle) - generator.ymlファイルを解析してクラスを生成するSymfony2用の管理画面ジェネレーター。
* [EasyAdminBundle](https://github.com/javiereguiluz/EasyAdminBundle) - Symfonyアプリケーション用のシンプルな管理画面ジェネレーター。
* [SonataAdminBundle](https://github.com/sonata-project/SonataAdminBundle) - Symfony2用の管理画面ジェネレーター。
* [AdminLTEBundle](https://github.com/kevinpapst/AdminLTEBundle) - AdminLTEテンプレートに基づく管理画面テーマ。
* [Umbrella framework](https://github.com/acantepie/umbrella) - 管理画面を構築するためのコンポーネントとテーマ。
* [TablerBundle](https://github.com/kevinpapst/TablerBundle) - Tablerテンプレートに基づく管理画面テーマ。関数、フィルター、埋め込み、マクロ、インクルード用のTwigヘルパーを提供。
