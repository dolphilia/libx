## パッケージとミドルウェア

* [Lumen Cors](https://github.com/vluzrmos/lumen-cors) - Lumen向けのシンプルなCORS機能。

* [Alternative Lumen Cors](https://github.com/palanik/lumen-cors) - Lumenマイクロフレームワーク向けCORSミドルウェア。

* [Phpspec Lumen](https://github.com/pmartelletti/phpspec-lumen) - phpspecでLumenアプリをテスト。

* [Understand Lumen](https://github.com/understand/understand-lumen) - Understand.io向けのLaravel Lumenサービスプロバイダー。

* [Badge Poser](https://github.com/vluzrmos/laravel-badge-poser) - Lumen向けバッジ生成ツール。

* [Cors Illuminate](https://github.com/neomerx/cors-illuminate) - LaravelとLumenのCORS（オリジン間リソース共有）対応。

* [Jwt Artisan](https://github.com/generationtux/jwt-artisan) - LaravelとLumen向けJWT認証。

* [Facebook SDK](https://github.com/SammyK/LaravelFacebookSdk) - LaravelとLumen向けFacebook SDK。

* [Lumen Generators](https://github.com/webNeat/lumen-generators) - LumenとLaravel 5向けの生成ツール集。

* [Dingo API](https://github.com/dingo/api) - Laravel と Lumen フレームワーク向け RESTful API パッケージ。

* [Lumen Tinker](https://github.com/vluzrmos/lumen-tinker) - Lumenフレームワーク向けの対話型シェル。

* [Lumen Maintenance Mode](https://github.com/rdehnhardt/lumen-maintenance-mode) - Lumenアプリケーションのメンテナンスモードを定義。

* [Lumen Vendor Publish](https://github.com/laravelista/lumen-vendor-publish) - Lumen フレームワーク向け vendor publish コマンド。

* [Lumen Make](https://github.com/michaelbonds/lumen-make) - Laravel の make コマンドの大半を Lumen へ移植。

* [Lumen File Manager](https://github.com/nordsoftware/lumen-file-manager) - Lumen PHP フレームワーク向けファイルマネージャーモジュール。

* [Lumen 5.2 HTTP Basic Auth Guard](https://github.com/arubacao/http-basic-auth-guard) - Lumen 5.2でBasic認証を再び利用可能に。

* [Larasupport](https://github.com/irazasyed/larasupport) - Lumen に Laravel パッケージ対応とその他のヘルパーを追加。

* [REST API With Lumen](https://github.com/hasib32/rest-api-with-lumen) - Lumen マイクロフレームワーク向け RESTful API ボイラープレート。

* [Lumen Passport](https://github.com/dusterio/lumen-passport) - Laravel Passport を Lumen で動作させます。
