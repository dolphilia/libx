#### ガイドライン

* 追加するものがリストにまだ存在しないことを確認する
* 追加項目ごとに個別のプルリクエストを作成する
* 次の形式を使う：`* [Name](https://github.com/unicodeveloper/awesome-lumen/blob/57a97d14a97bde105c10276aa6628592e818b707/Link) - Description if needed`
* セクションの先頭や途中ではなく、末尾へ追加する
* 綴りと文法を確認する
* カテゴリーの作成や改善は自由
* 行末に空白がないことを確認する
* 最後に、それが素晴らしいものであることを確認する！
