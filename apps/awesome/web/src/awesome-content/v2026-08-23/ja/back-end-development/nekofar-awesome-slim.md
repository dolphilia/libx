# Awesome Slim

[Slim](https://www.slimframework.com)は、WebアプリケーションやAPIを作るためのPHPマイクロフレームワークです。Slim 4向けの資料を含む学習資料、アプリケーションのひな形、ミドルウェア、ビューのレンダラー、テスト補助機能などを探せます。

## 学習資料<a id="教育"></a>

- [ユーザーガイド](https://www.slimframework.com/docs/v4/) — Slim Frameworkの公式ドキュメント。

- [Stack Overflow](https://stackoverflow.com/questions/tagged/slim) — Stack Overflow上のSlim Frameworkに関する質問。

- [ディスカッションフォーラム](https://discourse.slimframework.com) — Slim Frameworkの公式ディスカッションフォーラム。

- [Slim 4 - GraphQL](https://odan.github.io/2021/08/12/slim-graphql.html) — GraphQLを使ったHTTP APIの作成。

- [Slim 4 - ReactPHP](https://odan.github.io/2021/08/14/slim-reactphp.html) — 性能向上を目的にSlimとReactPHPを組み合わせる方法を説明した資料。

## ボイラープレート

- [Slim 4 MVC Skeleton](https://github.com/semhoun/slim-skeleton-mvc) — シンプルなWebアプリケーションのひな形。

- [Slim 4 Skeleton](https://github.com/adriansuter/Slim4-Skeleton) — PHP-DI、Nyholm PSR7、Twigを使うWebアプリケーションのひな形。

- [Slim 4 Skeleton](https://github.com/odan/slim4-skeleton) — 新しいSlim 4アプリケーションを立ち上げるためのひな形。

- [Slim Skeleton](https://github.com/slimphp/Slim-Skeleton) — Slim Framework 4の公式アプリケーションひな形。

- [Slim 4 Starter](https://github.com/nbayramberdiyev/slim-4-starter) — 小中規模のPHPアプリケーション向けに、設計方針を定めたSlim 4のスターターテンプレート。

## ミドルウェア

- [Slim Basic Auth](https://github.com/tuupola/slim-basic-auth) — PSR-7とPSR-15に対応するHTTP Basic認証のミドルウェア。

- [Slim CSRF](https://github.com/slimphp/Slim-Csrf) — Slim Framework用のCSRF対策ミドルウェア。

- [Slim HTTP Cache](https://github.com/slimphp/Slim-HttpCache) — Slim Framework用のHTTPキャッシュミドルウェアとサービスプロバイダー。

- [Slim JWT Auth](https://github.com/tuupola/slim-jwt-auth) — PSR-7とPSR-15に対応するJWT認証のミドルウェア。

- [Slim Minify](https://github.com/christianklisch/slim-minify) — Slimが生成するHTML出力を圧縮。

- [Slim Session](https://github.com/bryanjhv/slim-session) — Slim Framework用のシンプルなセッションミドルウェア。

- [Slim Whoops](https://github.com/zeuxisoo/php-slim-whoops) — Slim Framework向けのPHP Whoopsによるエラー表示。

## テンプレート

- [Slim Twig View](https://github.com/slimphp/Twig-View) — Twigを使ったSlim Framework用のビュー補助機能。

- [Slim Plates](https://github.com/projek-xyz/slim-plates) — Platesテンプレートエンジンを使ってSlimアプリケーションのビューをレンダリング。

- [Slim PHP View](https://github.com/slimphp/PHP-View) — PHPビューのスクリプトをレンダリングし、その結果をPSR-7 Responseオブジェクトに格納。

## 開発

- [Slim Test](https://github.com/nekofar/slim-test) — PHPUnitを使ったSlim Framework用のテスト補助機能。
