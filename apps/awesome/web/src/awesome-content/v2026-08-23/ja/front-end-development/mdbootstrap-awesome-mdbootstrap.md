# Awesome MDBootstrap

[MDBootstrap](https://github.com/mdbootstrap/mdb-ui-kit)は、ウェブページ作成に使えるレスポンシブなテンプレート、レイアウト、コンポーネント、ウィジェットを提供します。UIキット、デザイン生成ツール、データグリッド、CLIとホスティング、TW Elementsの連携資料、教材を探せるほか、[公式サイト](https://mdbootstrap.com)も参照できます。

## <a id="resources"></a>リソース

MDBootstrap公式のプロジェクトとリソースです。固定原文ではUIキットを無料版とPro版に分類しています。

### 無料

- [MDB Standard Free](https://mdbootstrap.com/docs/standard/) - ダウンロード無料のオープンソースBootstrap 5 UIキット。
- [MDB Angular Free](https://mdbootstrap.com/docs/angular/) - Material Designを備えたBootstrap 5・Angular 11向け無料UIキット。
- [MDB React Free](https://mdbootstrap.com/docs/react/) - Material Designを備えたBootstrap 5・React 17向け無料UIキット。
- [MDB Vue Free](https://mdbootstrap.com/docs/vue/) - Material Designを備えたBootstrap 5・Vue 3向け無料UIキット。

### Pro

- [MDB Standard Pro](https://mdbootstrap.com/docs/standard/pro/) - Bootstrap 5向けプレミアムUIキット。原文では5,000以上のプレミアムコンポーネント、数千のテンプレート、プラグイン、デザインブロックを永続利用できると記載。
- [MDB Angular Pro](https://mdbootstrap.com/docs/angular/pro/) - Angular対応Bootstrap 5向けMaterial Design。
- [MDB React Pro](https://mdbootstrap.com/docs/react/pro/) - React対応Bootstrap 5向けMaterial Design。
- [MDB Vue Pro](https://mdbootstrap.com/docs/vue/pro/) - Vue対応Bootstrap 5向けMaterial Design。

- [フッター生成ツール](https://mdbootstrap.com/docs/standard/tools/builders/footer/) - 著作権表記、ボタン、フォーム、リンク、色、サイズをカスタマイズしたBootstrapフッターを作成。
- [ナビゲーションバー生成ツール](https://mdbootstrap.com/docs/standard/tools/builders/navbar/) - 色、ブランド、アイコン、フォーム、配置をカスタマイズしたBootstrapナビゲーションバーを作成。

## <a id="data-grid"></a>データグリッド

プロジェクトの機能を拡張するテーブルコンポーネントです。

- [GetDataDen](https://getdataden.com/) - カスタマイズ可能なデータグリッド。
- [データ構造](https://getdataden.com/docs/grid/features/data-loader/#client-side-data-example) - 各列のソート、幅、リサイズ、フィールドを設定。各行の値を、`field`が指定キー値と等しい列へ対応付け。
- [列のドラッグ](https://getdataden.com/docs/grid/features/drag-and-drop/#basic-section) - クリック、ドラッグ、ドロップでデータグリッドの列を並べ替え。
- [ページネーション](https://getdataden.com/docs/grid/features/pagination/#basic-section) - 大規模なデータセットを移動するページネーション操作の例。
- [列検索](https://getdataden.com/docs/grid/features/filtering/header-filters/#basic-section) - 列検索でDataDenグリッド内の情報を検索。
- [セルの書式設定](https://getdataden.com/docs/grid/layout/custom-css/#cell-formatting-section) - 色、フォント、スタイルでセルの外観を調整し、重要な情報を強調。
- [コンパクト版](https://getdataden.com/docs/grid/layout/custom-css/) - CSSでデータグリッドの色、フォント、レイアウトをブランドや好みに合わせて調整。
