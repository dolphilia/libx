# Awesome Inertia.js<a id="awesome-logo-of-awesome-inertiajs-repository"></a>

[Inertia.js](https://inertiajs.com/)は、従来のサーバー側ルーティングとコントローラーでシングルページアプリケーションを作るためのツールです。クライアント側・サーバー側のアダプター、Reactフック、Laravelとの連携、スターターキット、エディター用ツール、公式ドキュメントやコミュニティを探せます。

## フック<a id="hooks"></a>

- [useApi](https://github.com/offload-project/inertiajs-use-api) — Inertia.jsアプリからJSON APIエンドポイントを呼び出すReactフック。必要に応じて結果をページのpropsへ渡せる。
