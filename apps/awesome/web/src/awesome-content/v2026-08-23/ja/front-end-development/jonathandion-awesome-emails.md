# Awesome Emails

HTML・Reactメールの制作に使うフレームワーク、レスポンシブテンプレート、HTML・CSSの対応資料をまとめています。配信サービス、セルフホスト型メールサーバー、分析・テストツール、デザイン例、学習資料も探せます。

## <a id="frameworks"></a>フレームワーク

### React

- [React Email](https://react.email/) - ReactとTypeScriptでメールを作成するための、スタイル未設定のコンポーネント。
- [Mailing](https://www.mailing.run/) - Reactでメールを作成し、どこからでも送信。
- [JSX-email](https://jsx.email/) - 原説明ではJSX Mailと呼ばれる、Reactでメールテンプレートを作成するフレームワーク。

### <a id="misc"></a>その他

- [MJML](https://mjml.io) - レスポンシブメールのコーディングを簡単にするマークアップ言語。
- [Foundation for Emails](https://github.com/zurb/foundation-emails) - レスポンシブHTMLメールを作成。原説明では、Outlookを含むあらゆるデバイスとクライアントへの対応をうたう。
- [Email Framework](http://emailframe.work/) - レスポンシブHTMLメールを作成するフレームワーク。
- [HEML](https://heml.io) - レスポンシブメールを作成するオープンソースのマークアップ言語。
- [Acorn](https://docs.thememountain.com/acorn/) - 黄金比のタイポグラフィグリッドに基づくレスポンシブメールフレームワーク。
- [Pine](https://docs.thememountain.com/pine/) - 12列のグリッドを使うレスポンシブメールフレームワーク。
- [Maizzle](https://maizzle.com) - Tailwind CSSでHTMLメールを素早く構築。

## <a id="tools"></a>ツール

- [Can I Email](https://www.caniemail.com/) - メールクライアントのHTMLとCSSへの対応表。
- [Topol](https://topol.io/) - レスポンシブHTMLメールを作成。原説明では、1分で作成できるとうたう。
- [MJML Desktop App](https://mjmlio.github.io/mjml-app/) - MJML公式デスクトップアプリ。
- [Rollover](http://freshinbox.com/tools/rollover/) - 受信者が画像にカーソルを合わせると別の画像を表示する、ロールオーバー画像のコードを生成。
- [Bulletproof Email Buttons](http://buttons.cm/) - VMLとCSSによるプログレッシブエンハンスメントを使ってボタンを設計。
- [Bulletproof Background Images](http://backgrounds.cm/) - VMLとCSSを使ってHTMLメールの背景画像を作成。
- [Stripo.email](https://stripo.email/) - HTMLの知識なしでレスポンシブなテンプレートを作成できる、オンラインのドラッグ＆ドロップ・HTMLメールビルダー。
- [MySigMail Card](https://mysigmail.com/card/) - 無料のドラッグ＆ドロップ式メールテンプレートビルダー。
- [TestSubject](http://zurb.com/playground/testsubject) - 主要なモバイル端末でのメール件名の表示をテスト。
- [MailSpice analytics](https://mailspice.com) - メールキャンペーンの分析アドオン。原説明では、すべてのメールサービスプロバイダー（ESP）で動作するとされる。
- [Alter.email](https://alter.email/) - CSSのインライン化・未使用CSSの削除、テキストの整理、タグへの属性追加、URLへの追跡パラメーター追加、HTMLメールの圧縮と整形を行う無料ツール。
- [Sensitive Subjects](https://sensitivesubjects.com/) - 原説明では、恥ずかしい件名の送信を避けるためのものとして紹介される。
- [Detergent](https://detergent.io) - HTMLに貼り付けるテキストを準備するツール。PSDファイルに由来することがある[ETX](https://www.fileformat.info/info/unicode/char/0003/index.htm)などの不可視Unicode文字を除去し、£を`&pound;`に変換するなどの特殊文字のエンコードと、タイポグラフィの改善を行う。
- [EmailComb](http://emailcomb.com/) - メール向けの未使用CSS除去ツール。構文解析を行わないため、ESPのテンプレートタグを含む混在したソースにも対応。CSSの難読化と、HTML CrushによるHTML/CSSの圧縮も可能。
- [HTML Crush](https://htmlcrush.com/) - メール向けHTML圧縮ツール。各行を500文字以内にし（原説明ではベストプラクティスとされる）、Outlookの条件付きタグを考慮し、ESPのテンプレートタグを含む混在したソースに対応。改行を変更せず、インデントだけを除去することも可能。
- [Tabifier](https://tools.arantius.com/tabifier) - HTML Crushとは逆に、HTMLファイルのインデントを整えるツール。ESPのテンプレートタグを含む混在した入力にも対応。
- [Email Link Builder](https://email-link-builder.samcarlton.com/) - 宛先・件名・本文などをあらかじめ設定したメールの下書きを開くmailtoリンクを作成。
- [email-verifier](https://github.com/AfterShip/email-verifier) - メールを送信せずにメールアドレスを検証するツール。
- [DevMail](https://devmail.email/) - ソフトウェア開発者向けのメールサンドボックス。開発・ステージング・QA・CI環境からのメールを捕捉。
- [Disposable Email Check API](https://open.kickbox.com/) - 使い捨てのメールアドレスかどうかを調べる無料API。登録不要。

- [ForwardMX](https://forwardmx.net) - 自分のドメイン向けのプレミアムメール転送サービス。
