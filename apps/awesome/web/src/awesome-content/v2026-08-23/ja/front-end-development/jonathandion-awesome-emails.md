## フレームワーク

<a id="react"></a>
### React

- [React Email](https://react.email/) - ReactとTypeScriptを使用して美しいメールを作成するための、高品質な未スタイルコンポーネントのコレクション。
- [Mailing](https://www.mailing.run/) - Reactでメールを作成し、どこからでも送信可能。
- [JSX-email](https://jsx.email/) - JSX Mailは、Reactを用いてメールテンプレートを作成するメールフレームワーク。

<a id="misc"></a>
### その他

- [MJML](https://mjml.io) - MJMLは、レスポンシブメールのコーディングを楽にするためのマークアップ言語。
- [Foundation for Emails](https://github.com/zurb/foundation-emails) - あらゆるデバイスおよびクライアントで動作するレスポンシブHTMLメールを迅速に作成。Outlookにも対応。
- [Email Framework](http://emailframe.work/) - レスポンシブHTMLメールを作成するためのHTMLメールフレームワーク。
- [HEML](https://heml.io) - HEMLは、レスポンシブメールを作成するためのオープンソースマークアップ言語。
- [Acorn](https://docs.thememountain.com/acorn/) - 黄金比のタイポグラフィグリッドに基づくレスポンシブメールフレームワーク。
- [Pine](https://docs.thememountain.com/pine/) - 12コラムのグリッド、レスポンシブメールフレームワーク。
- [Maizzle](https://maizzle.com) - Tailwind CSSを使ってHTMLメールを迅速に構築。

<a id="tools"></a>
## ツール

- [Can I Email](https://www.caniemail.com/) - HTMLおよびCSSにおけるメールでのサポートテーブルを提供します.
- [Topol](https://topol.io/) - 1分で素晴らしいレスポンシブHTMLメールを作成できます.
- [MJML Desktop App](https://mjmlio.github.io/mjml-app/) - MJML公式のデスクトップアプリ.
- [Rollover](http://freshinbox.com/tools/rollover/) - メール受信者が画像上をマウスで移動させたときに別の画像を表示するロールオーバー画像のコードを生成します.
- [Bulletproof Email Buttons](http://buttons.cm/) - プログレッシブに強化されたVMLとCSSを使って美しいボタンを設計できます.
- [Bulletproof Background Images](http://backgrounds.cm/) - VMLとCSSの助けを借りて、HTMLメールに安定した背景画像を作成できます.
- [Stripo.email](https://stripo.email/) - HTMLメールビルダーをオンラインでドラッグ＆ドロップで使用し、HTMLスキルなしでプロフェッショナルでレスポンシブなメールテンプレートを迅速に作成できます.
- [MySigMail Card](https://mysigmail.com/card/) - 無料のドラッグ＆ドロップビルダーで、直感的に非常に速くメールテンプレートを作成できます.
- [TestSubject](http://zurb.com/playground/testsubject) - あなたのメールの件名が最も人気のあるモバイルデバイスでどのように表示されるかをテストできます.
- [MailSpice analytics](https://mailspice.com) - すべてのメールサービスに適用可能なメール分析拡張機能で、すべてのメールキャンペーンについて深い洞察を提供します（すべてのESPと対応）.
- [Alter.email](https://alter.email/) - 無料のツールで、CSSをインライン化し、使われていないCSSを削除し、テキストを整理し、タグに追加属性を付加し、URLトラッキングパラメータを追加し、最小化し、さらにはHTMLメールを美しく整えます.
- [Sensitive Subjects](https://sensitivesubjects.com/) - 恥ずかしい件名を送らないでください！
- [Detergent](https://detergent.io) - HTMLに貼り付けるためのテキストを準備するツール：不可視Unicode文字（例：[ETX](https://www.fileformat.info/info/unicode/char/0003/index.htm) がPSDファイルから来ることもあります）を削除し、特別な文字（例：£を`&pound;`に変換）をエンコードし、タイプグラフィックを改善します.
- [EmailComb](http://emailcomb.com/) - メールに適した使われていないCSS削除ツールで、パースせずに混合ソース（あなたのESPテンプレートタグを含む）を受け入れます。追加機能：CSSの醸成（HTML Crushによって提供）とHTML/CSSの最小化。
- [HTML Crush](https://htmlcrush.com/) - メールに適したHTML最小化ツール：行を500文字に制限（ベストプラクティス）、Outlookの条件付きタグを尊重し、ESPテンプレートタグを含む複数ソースに対応。必要に応じて、インデントのみを削除（改行は変更しない）。
- [Tabifier](https://tools.arantius.com/tabifier) - HTML Crushの逆機能——HTMLファイル内のインデントを整えるツール。ESPテンプレートタグを含む複数ソースに対応。
- [Email Link Builder](https://email-link-builder.samcarlton.com/) - メールアドレスにリンクを生成し、受信者、件名、本文などを事前に埋め込み、メールのドラフトを開く。
- [email-verifier](https://github.com/AfterShip/email-verifier) - メールの検証を行うツールだが、メールを送信せずに済む。
- [DevMail](https://devmail.email/) - ソフトウェア開発者向けのメールサンドボックス。開発、ステージング、品質保証、CI環境から送信されたメールをキャプチャ。
- [Disposable Email Check API](https://open.kickbox.com/) - メールアドレスが一時的なものかどうかをチェックする無料API。登録不要。

## 学習資料

- [Responsive HTML Email Design](https://frontendmasters.com/courses/responsive-email/) - Justine JordanとJason Rodriguezによるレスポンシブメールコース。
- [Mastering HTML Email](http://webdesign.tutsplus.com/series/mastering-html-email--webdesign-17696) - このチュートリアルシリーズは、基礎から学び、開発手法、ワークフロー、デザインアプローチを探索します。
- [Building Responsive Email Templates with Ink](https://scotch.io/tutorials/building-responsive-email-templates-with-ink) - Inkでレスポンシブメールテンプレートを構築する。
- [Litmus learning](https://litmus.com/community/learning) - Litmusの学習リソース。
