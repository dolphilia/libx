# Awesome Ant Design

Ant Designは、Reactによる実装を備えたUIデザイン言語です。原文では、Ant FinancialのExperience Technology Departmentによって改善が重ねられたものとされ、ミドルウェア製品のUI仕様を統一し、設計の違いと実装に伴う不要な費用を減らして、設計とフロントエンド開発に余力を生むことを目指すと説明されています。このリストでは、公式資料、記事、ツール、テーマ、UIコンポーネント、アプリケーション、雛形に加え、Angular、Vue.js、Blazorなどのフレームワーク向け実装を探せます。

- [Ant Design Pro](http://pro.ant.design/) - そのまま利用できる企業向けアプリケーションのUIソリューション。
- [Ant Design Mobile](http://mobile.ant.design/) - 設定可能なモバイルUI仕様とReactによる実装。

## ツール <a id="tools"></a>

Ant Designを使ったアプリケーション構築を支援するツールとユーティリティです。

- [Antd Init](https://github.com/ant-design/antd-init) - Ant Designのボイラープレート生成ツール。デモ専用で、dva-cliの使用を案内。
- [Dva Cli](https://github.com/dvajs/dva-cli) - [Dva.js](https://github.com/dvajs/dva)に基づくAnt Designプロジェクトを作成するツール。
  Dva.jsはReduxとReactを基盤とし、[Elm](http://elm-lang.org)と[Choo](https://github.com/yoshuawuyts/choo)に着想を得た軽量フロントエンドフレームワーク。
- [Antd Tools](https://github.com/ant-tool) - Ant Designのドキュメント作成、コンポーネント作成、ビルドなどに使うツール。
- [Antd Tools Docs](http://ant-tool.github.io/) - Ant Toolsのドキュメント。
- [iConfig Ant Design](https://github.com/hutxs/iconfig-antd) - 便利な変換処理を使って新しいプロジェクトを迅速に立ち上げるためのボイラープレート。
- [vscode-antd-rush](https://github.com/fi3ework/vscode-antd-rush) - VS CodeでAnt Designの利用を支援するツール。
- [Antd Snippets for VS Code](https://marketplace.visualstudio.com/items?itemName=bang.antd-snippets)
- [Generator Antd Pro](https://github.com/codetrial/generator-antd-pro) - Ant Design Proアプリケーションを簡単に構築するためのツール。
- [formik-antd](https://github.com/jannikbuschke/formik-antd) - 広く使われるフォーム状態管理ライブラリFormik向けの宣言的なバインディング。
- [Zaku](https://github.com/limichange/zaku) - ページを作成してantdのコードを生成するためのJSXベースのUIエディター。
- [Antd-Pro-Generator for VS Code](https://github.com/garrett12138/antd-pro-generator) - Swagger2.0またはOpenApi3.xのドキュメントからAnt Design Pro用のService/Mock/Modelを生成。
- [Ruyi Design Assistant](https://www.figma.com/community/plugin/1192146318523533547/) - FigmaでReactコンポーネントライブラリ（Ant Design）とデザイントークンを使い、コンポーネントのコードを取得するためのツール。原文では、本番利用に適したコードを取得できると説明。

## 関連プロジェクト <a id="related-projects"></a>

Ant Designファミリーの関連プロジェクトです。

- [Ant Design X](https://github.com/ant-design/x) - AIを使ったインターフェース向けのReact UIライブラリ@ant-design/x。チャットコンポーネントとAPIサービスとの連携を提供。
- [Ant Design Web3](https://github.com/ant-design/ant-design-web3) - 暗号資産ウォレット接続などのWeb3 UIコンポーネントとWeb3アイコンを備えた、dApp向けのReactコンポーネント。Ethereum、Solana、Bitcoin、TON、Suiなどのチェーンに対応。
- [Grammar of Graphics](https://g2.alipay.com/) - 大規模データから意味に基づくグラフを生成するための、純粋なJavaScriptツール。多様なチャートを作るためのグラフィック構文と、統合された統計ツールを提供。[詳しく読む](https://github.com/antvis/feedback)。
- [Ant Visualization](https://antv.alipay.com/) - 数年にわたる可視化の取り組みで得られたパターンを共有するデータ可視化仕様。AntVはデータ、設計仕様、チャートの利用規則を扱う。[詳しく読む](https://github.com/antvis/feedback)。
- [Ant Motion](http://motion.ant.design/) - Reactで実装され、Ant Designの視覚的な仕様に従うモーションデザインのソリューション。
- [Ant UX](http://ux.ant.design/) - [Omnigraffle](https://www.omnigroup.com/omnigraffle)、[Sketch](https://www.sketchapp.com/)、[Axure](http://www.axure.com/)でUX設計用のサイトマップテンプレートを作るためのライブラリ。製品のページ間の関係を定義し、改善して、確定する作業を支援。

## JavaScript以外のライブラリ <a id="non-javascript-libraries"></a>

JavaScript以外の言語向けのAnt Designライブラリです。JavaScriptにコンパイルするClojureScriptのライブラリも含みます。

- [Antizer](https://github.com/priornix/antizer) - [ClojureScript](https://clojurescript.org/)向けのAnt Designライブラリ。ClojureScriptはJavaScriptへクロスコンパイルする、不変性を備えた関数型言語。
- [syn-antd](https://gitlab.com/synqrinus/syn-antd) - [ClojureScript](https://clojurescript.org/)と[Reagent](https://github.com/reagent-project/reagent)向けのAnt Designラッパー。[shadow-cljs](http://shadow-cljs.org/)を使い、ツリーシェイキングに対応。他のClojureScriptライブラリと同様にJavaScriptへクロスコンパイルされる。
