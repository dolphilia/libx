# Awesome WebAudio

[Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)を使うブラウザーでの音声処理、音楽制作、学習のための資料です。フレームワーク、ライブラリ、開発ツール、MIDI、アプリ、教材、書籍、ニュースレター、コミュニティのほか、固定原文で更新停止に分類されたプロジェクトを探せます。各説明や状態の記載は、その原文に基づきます。

## <a id="packages"></a>パッケージ

### <a id="frameworks"></a>フレームワーク

- [Tone.js](https://github.com/Tonejs/Tone.js) - ブラウザーでインタラクティブな音楽を作るためのフレームワーク。
- [Bap](https://github.com/adamrenklint/bap) - 往年のMPC60/2000に着想を得た、ビート作成とシーケンス構成のためのツールキット。
- [Omnitone](https://github.com/GoogleChrome/omnitone) - ウェブ向けのアンビソニックスによる空間音響。
- [Mach1Spatial](https://github.com/Mach1Studios/m1-sdk) - ウェブ向けの、ベクトルに基づくパンニングによる空間音響。
- [Elementary](https://www.elementary.audio/) - ウェブやネイティブアプリ向けの音声ソフトウェアを書くための、宣言的・関数的なフレームワーク。
- [React Native Audio API](https://github.com/software-mansion-labs/react-native-audio-api) - React Nativeを基にした、ネイティブアプリ向けのWeb Audio API実装。

### <a id="libraries"></a>ライブラリ

- [smoothfade](https://github.com/notthetup/smoothfade) - 2つのAudioNodeの間を滑らかにフェードさせるライブラリ。
- [virtual-audio-graph](https://github.com/benji6/virtual-audio-graph) - Web Audio APIを宣言的に操作するライブラリ。
- [XSound.js](https://xsound.app/) - フルスタックの音声ライブラリ。
- [Sound.js](https://github.com/kittykatattack/sound.js) - ゲームやインタラクティブなアプリ向けに、効果音や音楽を読み込み・再生・生成する小型ライブラリ。
- [Meyda](https://github.com/meyda/meyda) - 広く使われるさまざまな音声特徴量を含む、音声特徴量抽出ライブラリ。
- [Wavesurfer.js](https://github.com/katspaugh/wavesurfer.js) - Web AudioとCanvasによる、対話的に移動できる音声の可視化。
- [Audiojs](https://github.com/audiojs/audio) - PCM音声データの保存・読み出し・書き込みを容易にするオブジェクト。
- [Tuna](https://github.com/Theodeus/tuna) - 音響効果のライブラリ。
- [Rythm.js](https://okazari.github.io/Rythm.js/) - ページを踊らせるJavaScriptライブラリ。
- [Howler.js](https://github.com/goldfire/howler.js) - HTML5 Audioへのフォールバックを備えた包括的なライブラリ。
- [Circular Audio Wave](https://github.com/kelvinau/circular-audio-wave) - Web Audio APIとEChartsを使い、円形の波形で音声を可視化するJavaScriptライブラリ。
- [Wad](https://github.com/rserota/wad) - Web AudioによるDAW。Web Audio APIで音を動的に合成し、耳のためのjQueryのように使えると紹介されています。
- [p5.sound](https://p5js.org/reference/#/libraries/p5.sound) - クリエイティブコーディング用ライブラリ[p5.js](https://p5js.org/)にWeb Audio機能を追加する拡張。
- [@magenta/music](https://github.com/magenta/magenta-js/tree/master/music) - Web Audio APIの抽象化を通じて、ブラウザーで機械学習モデルを使い、音楽を生成するJavaScriptライブラリ。
- [soundfont-player](https://www.npmjs.com/package/soundfont-player) - Web Audio APIでMIDIの音を再生する、サウンドフォントの読み込み・再生用ライブラリ。
- [html-midi-player](https://github.com/cifkao/html-midi-player) - 独自のJavaScriptを書かずにMIDIを簡単に再生・可視化できるHTML要素。必要に応じてスクリプトやスタイルも適用できます。
- [MusicXML Player](https://github.com/infojunkie/musicxml-player) - Web AudioとWeb MIDIを使い、ブラウザーでMusicXMLファイルを読み込み・再生するTypeScriptの部品。
- [waveform-path](https://github.com/jerosoler/waveform-path) - SVGの波形パスを生成するライブラリ。
- [wave-audio-path-player](https://github.com/jerosoler/wave-audio-path-player) - 波形でカスタマイズできる、シンプルな音声プレイヤーのウェブコンポーネント。
- [dsssp](https://github.com/NumberOneBot/dsssp) - ドラッグ＆ドロップとトランジションに対応する、音声フィルターの可視化・管理用Reactコンポーネントライブラリ。
- [tuning-fork](https://github.com/v-rusu/tuning-fork) - リアルタイムの音高検出を使う、設定可能なギター調律用のクライアント側JavaScriptライブラリ。

### <a id="utilities"></a>ユーティリティ

- [Audion](https://github.com/google/audion) - 開発者ツールにWeb Audioパネルを追加するChrome拡張機能。
- [web-audio-generator](https://github.com/ISNIT0/webaudio-generator) - Web Audioのコードを生成するためのUI。
- [Web Audio Studio](https://app.webaudio.studio) - コードから生成したWeb Audio APIのグラフをリアルタイムに可視化するツール。

### MIDI

- [midimessage](https://github.com/notthetup/midimessage) - シンプルなMIDIメッセージの解析器。
- [JZZ](https://github.com/jazz-soft/JZZ) - Node.jsと主要なすべてのブラウザー向けのMIDIライブラリ。
- [JZZ-midi-Gear](https://github.com/jazz-soft/JZZ-midi-Gear) - MIDI機器のモデルと製造元を取得する機能。
- [WEBMIDI.js](https://webmidijs.org/) - Web MIDI APIを扱いやすくするライブラリ。

### <a id="apps"></a>アプリ

- [BassoonTracker](https://github.com/steffest/BassoonTracker) - JavaScript製のMOD/XMトラッカー。
- [LoopDrop App](https://github.com/mmckegg/loop-drop-app) - Web Audio APIとWeb MIDI APIで作られた、MIDIルーパー・モジュラーシンセサイザー・サンプラーのアプリ。
- [X Sound](https://xsound.app/) - XSound.jsを使うマルチサウンドアプリ。
- [Molgav](https://github.com/surikov/molgav) - メロディを交換するための音楽用ステップシーケンサー。
- [mod-synth.io](https://github.com/andrevenancio/mod-synth.io) - 自分のモジュラーシンセサイザーを作ったり、さまざまなシンセサイザーを再現したりするツール。
- [GridSound](https://gridsound.github.io) - 固定原文で開発中とされるDAW（デジタルオーディオワークステーション）。
- [Learning Music](https://learningmusic.ableton.com/) - 音楽制作の基本を学ぶ教材。
- [Super Oscillator](https://github.com/lukehorvat/super-oscillator) - ウェブ向けの、対話的に操作できる3D音楽シンセサイザー。
- [AudioNodes](https://audionodes.com) - マルチトラックの音声ミキシング、音響効果、パラメーターの自動化、MIDI編集、音声合成、クラウドでの制作などを備えるモジュール式の音声制作ツール群。
- [waveform-playlist](https://github.com/naomiaro/waveform-playlist) - Canvasの波形プレビューを備えるマルチトラックのWeb Audioエディター兼プレイヤー。キューポイントやフェードを設定し、複数トラックの時間位置をずらせます。音声トラックの録音や音声への注釈に対応し、ミックスをAudioBufferまたはWAVへ出力できます。Audacityに着想を得たプロジェクト。
- [SoundCycle](https://github.com/scriptify/soundcycle) - エフェクトとさまざまなループモードを備える、音楽家向けのWeb Audioによるループステーション。
- [DSP.audio Worklet Editor](https://dsp.audio/editor/) - 試作と共同作業のためのオンラインAudio Workletエディター。サンプラー、MIDI、解析器を備え、DSP向けのJSFiddleのように使えます。
- [AudioMass](https://audiomass.co/) - 固定原文で無料・オープンソースとされる、ウェブ上の音声・波形エディター。
- [Csound IDE](https://ide.csound.com/) - [CSoundプログラミング言語](https://en.wikipedia.org/wiki/Csound)向けのウェブIDE。
- [jamhub](https://github.com/fletcherist/jamhub) - 低遅延の遠隔音楽共同制作とジャムセッション。
- [Web Audio Metronome](https://github.com/cwilso/metronome) - Web AudioのスケジューラーとsetTimeoutのスケジューラーを使うメトロノームアプリ。
- [EarSketch](https://earsketch.gatech.edu/landing/#/) - 音楽の作曲とリミックスを通じてPythonとJavaScriptを教える、固定原文で無料とされる教育用プログラミング環境。
- [webaudio-tinysynth](https://github.com/g200kg/webaudio-tinysynth) - GM風の音色マップを備える、小型のJavaScript製シンセサイザー。
- [web-audio-beat-detector](https://github.com/meerasndr/sample-golang-app) - Web Audio APIを使うビート検出ツール。
- [web-audio-mixer](https://github.com/jamesfiltness/web-audio-mixer) - Web Audioで作られた音声ミキサー。
- [Audio-motion interface](https://github.com/MaxAlyokhin/audio-motion-interface) - 空間内でのスマートフォンのジェスチャーから音を生成するウェブシンセサイザー。
- [Topos](https://topos.raphaelforment.fr) - Monome Teletypeに着想を得た、ウェブ上のライブコーディング環境。Web AudioとMIDIを使います。
- [Online Sequencer](https://onlinesequencer.net) - Web Audio APIを基にした、シンプルで使いやすく多機能なシーケンサー。
- [Binary Synth](https://github.com/MaxAlyokhin/binary-synth) - 任意のファイルのバイナリコードから音を生成するウェブシンセサイザー。
- [dsssp-demo](https://github.com/NumberOneBot/dsssp-demo) - 7バンドのEQとフィルターのプリセットを備えるWeb Audio音楽プレイヤー。
- [SingMeter](https://www.singmeter.com/) - 音高検出器と声域テストを含む、ブラウザー上の歌唱ツール集。
- [Drumhaus](https://drumha.us/) - ステップシーケンス、パターンの変化、グルーブ編集を備える、ブラウザー上のドラムマシン。
- [All-in-One Advanced BPM Tool](https://tapbpmhub.com/) - タップやスペースバーで楽曲の速さを即座に測るツール。MIDI入力、任意のクリック音、リアルタイムのBPM可視化を備え、音楽制作者・DJ・リズムゲームのプレイヤー向けに紹介されています。
- [synflow](https://synflow.org) [Github](https://github.com/k1ln/synflow) - ブラウザー上のモジュラーシンセサイザー用フローエンジン。すべてのWeb Audio APIノードに加え、ボコーダーやリバーブなどのWorklet、高度なフローの自動化を備えます。
- [Tonalux](https://tonalux.org) - 固定原文で無料とされる、ブラウザー上の音声解析ツール群。リアルタイムのスペクトル解析、LUFSラウドネス計測（EBU R128）、A/B参照比較、ステレオ相関を備えます。Web Audio APIとWebAssemblyで作られ、すべてクライアント側で動作します。
- [mdrone](https://mdrone.org) - ブラウザーで動作する微分音のドローン楽器。

- [reverbGen](https://github.com/adelespinasse/reverbGen) - 人工的なリバーブのインパルス応答を生成するJavaScriptライブラリ。
- [TuneJS](https://github.com/abbernie/tune) - 微分音と純正律の音階を扱う調律ライブラリ。3,000を超える歴史的な調律に対応します。

- [Pizzicato](https://github.com/alemangui/pizzicato) - ブラウザーでの音の生成・操作を簡単にすることを目指すライブラリ。

- [envelope-generator](https://github.com/itsjoesullivan/envelope-generator) - ウェブ音声向けのシンプルなADSRエンベロープ生成器。

- [audiolet](https://github.com/oampo/Audiolet) - ブラウザー内でリアルタイムに音声を合成・作曲するJavaScriptライブラリ。
