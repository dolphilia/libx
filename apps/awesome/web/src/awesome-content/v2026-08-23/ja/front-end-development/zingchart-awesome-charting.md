# Awesome Charting

JavaScriptのチャートライブラリーとデータ可視化の資料を探せます。商用、無料・オープンソース、無料、フレームワーク別に分類しています。原文が収録時点で用途に適し開発が活発と考えたライブラリーを対象としており、互換性・容量・保守状況の記述も原文時点の情報です。

## 商用ライブラリ

* [amCharts](https://www.amcharts.com/) - 従来型チャート、株価チャート、地図向けの3種類のライブラリー。手描き風テーマオプションを備える。
* [AnyChart](http://www.anychart.com/) - さまざまな種類のデータをグラフ化する製品セット。特別な Oracle Apex 統合オプションがある。
* [CanvasJS](http://canvasjs.com/) - 原文ではファイルサイズが小さいと説明され、対象を絞った種類のチャートを提供するライブラリー。他の商用ライブラリーとは異なる外観の既定テーマ。
* [FusionCharts](http://www.fusioncharts.com/) - 原文では地図機能が充実していると説明されるチャートライブラリー。
* [Highcharts](http://www.highcharts.com/) - さまざまな用途向けチャートライブラリ群。原文ではIE6までの互換性を確保できる場合があると記載。
* [JSCharting](https://JSCharting.com/) - 従来型チャート、地図、株価、ガント、グリッド、組織図を一つのパッケージに含む統合チャートライブラリスイート。
* [Kendo UI](https://www.telerik.com/kendo-ui) - Angular、React、Vue 向けネイティブ UI コンポーネントを利用できるプレミアムチャートライブラリ。
* [ZingChart](http://www.zingchart.com) - スタイルをカスタマイズできるモジュール式ライブラリー。原文では、他のライブラリーが扱えない大規模データセットを描画でき、新機能も頻繁に追加されると説明。

## 無料・オープンソースライブラリ

* [apexcharts.js](https://github.com/apexcharts/apexcharts.js) - シンプルな API を持つ JavaScript チャートライブラリ。
* [Billboard.js](https://naver.github.io/billboard.js/) - D3 のリリースをより密に追跡する C3 のフォーク。
* [C3.js](http://c3js.org/) - D3 ベースの再利用可能なチャートライブラリ。
* [Chart.js](http://www.chartjs.org/) - 基本的な種類のチャートを含むライブラリー。原文の容量表記は11kb。
* [Charts.css](https://chartscss.org/) - CSS データ可視化フレームワーク。
* [Chartist](https://gionkunz.github.io/chartist-js/) - SVG を使ってチャートを描画し、CSS でスタイルするシンプル・軽量チャートライブラリ。
* [Chartkick](https://github.com/ankane/chartkick) - Ruby の一行で JavaScript チャートを作る。
* [D3.js](https://d3js.org/) - データに基づくドキュメント操作により SVG でチャートを描画できる。
* [dc.js](https://dc-js.github.io/dc.js/) - [crossfilter](http://square.github.io/crossfilter/) をサポートする D3 ライブラリ。
* [dygraphs](https://github.com/danvk/dygraphs) - 対話的にズーム可能な時系列チャート。
* [ECharts](https://github.com/ecomfe/echarts) - ブラウザー向けチャート・可視化ライブラリー。
* [EJSChart](https://github.com/EmpriseCorporation/EJSCharts) - 原文ではエンタープライズ対応と説明されるチャートライブラリー。
* [Graphosaurus](https://github.com/frewsxcv/graphosaurus) - WebGL（three.js）搭載の 3D グラフビューアー。
* [lightweight-charts](https://github.com/tradingview/lightweight-charts) - HTML5 canvas で構築した金融向け軽量チャート。
* [Morris.js](http://morrisjs.github.io/morris.js) - 折れ線、棒、面積、ドーナツチャートを描画するシンプルな API。
* [Plotly](https://github.com/plotly/plotly.js) - d3 と stack.gl 上に構築され、基本チャートと SVG 地図を作成できる。
* [Plottable](https://github.com/palantir/plottable) - OOP スタイル構文でチャートを構築するライブラリ。
* [QuickChart](https://github.com/typpo/quickchart) - 静的チャート画像を描画する Web API。
* [rgraph](http://www.rgraph.net/) - Google Sheets インポート機能を持つ 2D/3D JavaScript チャート。
* [sigma.js](https://github.com/jacomyal/sigma.js) - canvas 上に構築したグラフ・ネットワーク図ライブラリ。
* [Smoothie Charts](https://github.com/joewalnes/smoothie) - リアルタイムストリーミングデータ向け JavaScript チャート。
* [TauCharts](https://www.taucharts.com/) - 開発者が DSL を用いデータを記述できる独自構文。ファセット作成機能も持つ。
* [μPlot](https://github.com/leeoniya/uPlot) - 時系列、折れ線、面積、OHLC、棒グラフ向けのチャート。原文では圧縮後25 KB未満で高速と説明。
* [uvCharts](https://github.com/imaginea/uvCharts) - d3.js で構築した JavaScript チャートライブラリ。
* [vis.js](http://visjs.org/) - ネットワーク図、ラベル付きの説明的タイムライン、3D グラフを備える。
* [reaviz](https://reaviz.io) - React 向けモジュール式チャートコンポーネントライブラリ。
* [reaflow](https://reaflow.dev) - 静的・対話型エディター構築向けモジュール式図表エンジン。

## 無料ライブラリ

* [Google Charts](https://developers.google.com/chart/) - 地図、アニメーション機能、豊富なドキュメント、利用者コミュニティのフォーラム。

## フレームワーク固有ライブラリ

### Angular

* [Angular-Chart](http://jtblin.github.io/angular-chart.js) - 折れ線、棒、面積、ドーナツチャートを描画するシンプルな API。
* [n3-charts](https://github.com/n3-charts/line-chart) - AngularJS で書かれ、D3 でチャートを描画する使いやすいライブラリ。
* [Angular-scale](https://github.com/kirillstepkin/scale) - 折れ線チャート作成用のシンプル・軽量ライブラリ。

### Ember

* [Ember Charts](http://addepar.github.io/ember-charts/#/overview) - Ember.js プロジェクトですぐ使える 5 種類の基本チャート型。

### jQuery

* [Flot](http://www.flotcharts.org/) - jQuery 向け JavaScript チャートライブラリ。有用なチャート型を含むが、原文では活発な開発が停止している可能性があると記載。
* [jqPlot](http://www.jqplot.com) - チャート描画用オープンソース jQuery プラグイン。一般的な機能を多く含むが、機能の命名規則が異なる場合がある。
* [jqxChart](http://www.jqwidgets.com/jquery-widgets-documentation/documentation/jqxchart/jquery-chart-getting-started.htm) - SVG、Canvas、VML で描画する豊富なチャート型。
* [JQuery-linechart](https://github.com/kirillstepkin/jquery-linechart) - 折れ線チャート作成用のシンプル・軽量ライブラリ。

### Lit-html

* [lit-line](https://github.com/apinet/lit-line) - lit-htmlを基盤にした、対話的で完全にレスポンシブな折れ線チャートのWebコンポーネント。原文では高速・小型と説明。

### React

* [nivo](https://github.com/plouc/nivo) - D3 上に構築された、データ可視化アプリを容易に構築する React コンポーネント。
* [react-vis](https://github.com/uber/react-vis) - Uber による合成可能な可視化システム。
* [vx](https://vx-demo.now.sh/) - d3 上に構築された、再利用可能な低レベル可視化コンポーネントのコレクション。
* [Potion](http://numberpicture.com/build) - React・D3 によるアニメーション可視化構築用の低レベル構成要素。
* [react-chart-js](https://github.com/jerairrest/react-chartjs-2) - Chart.js 用 React ラッパー。
* [react-d3](https://github.com/esbullington/react-d3) - SVG マークアップ生成に React、パス値計算に d3 を利用するチャートライブラリ。
* [react-muze](https://github.com/chartshq/react-muze) - [muze](https://muzejs.org/)（WebAssembly を使いブラウザーで探索的データ可視化を作成する無料ライブラリ）向け React ラッパー。
* [react-vis](https://github.com/uber-common/react-vis) - 一般的なデータ可視化チャートを描画する React コンポーネントのコレクション。
* [recharts](http://recharts.org) - React・D3 で構築されたチャートライブラリー。
* [Victory](https://github.com/FormidableLabs/victory) - 対話的データ可視化構築向けの合成可能な React コンポーネントコレクション。

## データ可視化リソース

* [Dataviz Catalogue](http://datavizcatalogue.com) - チャートの種類を選ぶためのカタログ。Severino Ribecca のプロジェクト。
* [Evergreen Data](http://stephanieevergreen.com) - より効果的にデータを提示するための情報・見解。
* [Flowing Data](http://flowingdata.com) - 原文で元New York Times所属と紹介されるNathan Yauによる、地図、可視化、統計、デザインのリソース。
* [Junk Charts](http://junkcharts.typepad.com) - 原文でColumbia大学教授と紹介されるデータ可視化評論家Kaiser Fungが可視化を分解し、問題点を特定して改善法を推奨する。
* [The Functional Art](http://www.thefunctionalart.com) - データ可視化の著者・教授Aberto Cairoの、データ可視化トレンド・ベストプラクティスに関するブログ。
* [Visualizing Data](http://www.visualisingdata.com) - データ可視化コンサルタント Andy Kirk がグラフ化・可視化の例、リソース、参考資料を集める。
* [Well Formed Data](http://well-formed-data.net/archives/1210/little-boxes) - 原文で元World Economic Forum所属と紹介されるMoritz Stefanerによる情報可視化・デザインの考察。
