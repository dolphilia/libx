# Awesome Design Systems

企業のデザインシステムや、UIデザイン、デザイントークン、コンポーネント開発、ドキュメント、アクセシビリティ、テストのツールを探せます。開発者とデザイナーによる構築・協働・保守を扱う記事、書籍、講演も収録しています。

## <a id="design-systems"></a>デザインシステム

デザインシステムは、再利用可能なコンポーネントとルールを継続的に整える仕組みです。プロダクト開発で共有する基準となり、一貫性と作業効率を支えます。

### <a id="design-systems-of-some-known-companies"></a>主な企業のデザインシステム

- [Atlassian Design Guidelines](https://atlassian.design/) - 明快で美しい体験を作るためのエンドツーエンドのデザイン言語。
- [Firefox Photon Design System](https://design.firefox.com/photon) - 認識しやすく楽しいFirefoxの製品・機能をより速くリリースする。
- [GitHub Primer](https://primer.style/) - コミュニティが自身のプロジェクトを設計・構築できるようにオープンソース化したもの。
- [GitLab Design System - Pajamas](https://design.gitlab.com/) - GitLabを支えるリソース、コンポーネント、デザインガイドライン。
- [Google Material Design](https://material.io/design) - Material Designで直感的で美しいプロダクトを作る。
- [IBM Carbon](https://www.carbondesignsystem.com/) - プロダクトと体験のためのIBMのオープンソースデザインシステム。
- [Shopify Polaris](https://polaris.shopify.com/) - Shopifyのすべての販売者向け体験を作るための協働を支援するデザインシステム。

その他のデザインシステムは[こちら](https://github.com/alexpate/awesome-design-systems)を参照。

## <a id="ui-design-tools"></a>UIデザインツール

### <a id="design-tools"></a>デザインツール

- [Figma](https://www.figma.com/) - チームが最初から最後まで、より良いデザインを作成、テスト、出荷するのを支援する（クロスプラットフォーム）。
- [InVision](https://www.invisionapp.com/) - デジタルプロダクトデザインプラットフォーム。支援する体験を世界最高水準とする説明は原リストによるもの。
- [Sketch](https://www.sketch.com/) - 初期アイデアから最終アートワークまで扱うデザインツールキット（macOS向け）。
- [AdobeXD](https://www.adobe.com/products/xd.html) - 実物に近いデザイン、ワイヤーフレーム、アニメーション、プロトタイプ、共同作業などを扱うUI/UXデザインツール。
- [Marvel](https://marvelapp.com/) - 共同作業でアイデアをデジタルプロダクトにするためのデザインプラットフォーム。
- [UXPin](https://www.uxpin.com/) - UX/UIプロジェクト全体を一つのツールで設計・管理する。
- [Penpot](https://penpot.app) - 分野横断チーム向けのオープンソースのデザイン・プロトタイピングプラットフォーム。原リストでは、この種の初のプラットフォームと説明。
- [Lunacy](https://icons8.com/lunacy) - オフラインモード、組み込みアセット（アイコン、イラスト、写真）、リアルタイムコラボレーションを備える無料グラフィックデザインツール。Sketch・Figmaの代替（macOS、Windows、Linux）。

[デザインツールのプラグイン一覧](https://github.com/LisaDziuba/Awesome-Design-Tools/blob/master/Awesome-Design-Plugins.md)も参照。

### <a id="integrations"></a>連携

- [Abstract](https://www.abstract.com/) - デザインの共同作業（macOSのSketch・XD向け）。
- [Avocode](https://avocode.com/) - デザインファイルの共有、変更の議論、Webサイト・モバイルアプリ・ニュースレターのコーディングを速くする。
- [InVision Design System Manager](https://www.invisionapp.com/design-system-manager) - デザインとコード化済みコンポーネントを一元管理し、大規模でも創造的で一貫したデザインを可能にする。
- [Zeplin](https://zeplin.io/) - 開発者を念頭に置いた、デザインの共有・整理・共同作業。

### <a id="accessibility-a11y"></a>アクセシビリティ（a11y）

- [Accessibility for developers](https://www.invisionapp.com/inside-design/accessibility-for-developers/) - 開発者がWebサイトのアクセシビリティ改善・徹底に役立てられる5つの簡単な方法。
- [Stark](https://www.getstark.co/) - ブランド構想からプロダクト完成まで、アクセシビリティを考慮した設計を可能にする。コントラストチェッカー、色覚特性シミュレーション、配色提案を提供する。
- [The A11Y Project](https://a11yproject.com/) - Webアクセシビリティを容易にするためのコミュニティ主導の取り組み。[リソース](https://a11yproject.com/resources/)節を参照。
- [InclusiveColors palette creator](https://www.inclusivecolors.com/) - カスタムのTailwind風カラーパレットを作成し、CSS/Figma/Adobeへ書き出す。WCAGコントラストチェックを通過するという説明は原リストによるもの。
- [Nutilz Color Shades Generator](https://nutilz.com/color-shades-generator) - 任意の16進カラーから50〜950の色調・濃淡スケールを生成し、CSS変数、SCSS、Tailwind設定として書き出す。

## <a id="design-tokens"></a>デザイントークン

- [DesignTokens.dev](https://www.designtokens.dev/) - インフラ管理なしでデザイントークンをリリースする。
- [Diez](https://diez.org/) - コードベース、ネイティブプラットフォーム、チーム間で共有できる視覚スタイルを表現する、無料・オープンソースの開発者ツールキット。
- [Design Tokens Validator](https://animaapp.github.io/design-token-validator-site/) - Design Token Community Group仕様に対してデザイントークンを検証する。

- [Zeplin JSON export tokens](https://extensions.zeplin.io/berk/zeplin-json-extension) - トークンをJSON形式で生成するZeplin用デザイントークン拡張。

### <a id="tools"></a>ツール

- [CSS Variable Generator](https://alltoolsverse.com/tools/css-variable-generator/) - ライト・ダークテーマの組を持つスコープ付きCSSカスタムプロパティを生成し、SCSS、Less、JSONのデザイントークンとして書き出す。
- [Figmagic](https://github.com/mikaelvesavuori/figmagic) - Figma文書からデザイントークンを生成し、グラフィックをエクスポートし、デザイントークン駆動のReactコンポーネントを抽出する。
- [Style Dictionary](https://github.com/amzn/style-dictionary) - デザイントークンにより一度スタイルを定義し、任意のプラットフォーム・言語で使用する。
- [Superposition](https://superposition.design/) - Webサイトからデザイントークンを抽出してコードやデザインツールで使う。すでにあるデザインシステムを活用する。
- [Theo](https://github.com/salesforce-ux/theo) - デザイントークンを変換・整形するための抽象化。

## <a id="pattern-library"></a>パターンライブラリ

### <a id="styleguides-and-documentation"></a>スタイルガイドとドキュメント

- [Stencil](https://stenciljs.com/) - 再利用可能でスケーラブルなデザインシステムを構築するツールチェーン。
- [Zeroheight](https://zeroheight.com/) - 継続的に更新するスタイルガイドを作り、デザインシステムの資料を一か所に文書化する。[詳細](https://medium.com/zeroheight/zeroheight-3-0-b6643c347596)。

### <a id="develop-isolated-components"></a>分離コンポーネントの開発

- [Backlight](https://backlight.dev/) - コードでデザインシステムを構築し、コンポーネントを管理する共同作業プラットフォーム。すぐに始めるための仕組みと共同作業ツールを提供。
- [Pattern Lab](https://patternlab.io/) - アトミックデザインの原則を使い、チームが熟慮されたパターン駆動のUIを構築するのを支援する。
- [React Styleguidist](https://react-styleguidist.js.org/) - 継続的に更新するスタイルガイドを備えた、Reactコンポーネントを単独で開発する環境。
- [Storybook](https://storybook.js.org/) - React、Vue、Angular向けにUIコンポーネントを単独で開発し、UI開発を整理するオープンソースツール。
- [Styled System](https://styled-system.com/) - Reactコンポーネントへスタイルpropsを追加し、グローバルテーマオブジェクトに基づいてスタイルを制御できるユーティリティ関数群。

### <a id="storybook-addons"></a>Storybookアドオン

- [Accessibility](https://github.com/storybookjs/storybook/tree/master/addons/a11y) - コンポーネントのWebアクセシビリティ標準準拠をテストする。
- [Actions](https://github.com/storybookjs/storybook/tree/master/addons/actions) - 対話要素でアクションが行われた際にUIフィードバックを得る。
- [Backgrounds](https://github.com/storybookjs/storybook/tree/master/addons/backgrounds) - 背景を切り替え、異なる設定でコンポーネントを表示する。
- [Console](https://github.com/storybookjs/storybook-addon-console) - ログ、エラー、警告などのコンソール出力をStorybookに表示する。
- [Docs](https://github.com/storybookjs/storybook/tree/master/addons/docs) - コンポーネントの使用法とプロパティをMarkdownで文書化する。
- [Knobs](https://github.com/storybookjs/storybook/tree/master/addons/knobs) - StorybookのUIからコンポーネントの入力を動的に操作する。
- [Links](https://github.com/storybookjs/storybook/tree/master/addons/links) - ストーリーを結び、UIコンポーネントのデモとプロトタイプを作る。
- [Source](https://github.com/storybookjs/storybook/tree/master/addons/storysource) - ストーリーのソースコードを表示して動作を確認し、アプリへ貼り付ける。
- [Storyshots](https://github.com/storybookjs/storybook/tree/master/addons/storyshots) - Jestで各ストーリーのコードスナップショットを自動取得する。
- [Viewport](https://github.com/storybookjs/storybook/tree/master/addons/viewport) - Storybookのビューポートサイズと向きを調整してレスポンシブコンポーネントを構築する。

Storybookの詳細は[こちら](https://github.com/lauthieb/awesome-storybook)を参照。

## <a id="testing"></a>テスト

### <a id="unit--regression-test"></a>ユニット・リグレッションテスト
