# Awesome Hydrogen

Hydrogenは、ヘッドレスコマースのためのShopifyのオープンソース技術基盤です。公式ドキュメント、導入ガイド、ツール、コミュニティ、実装例、アプリ連携、記事、ポッドキャスト、講演、ストアフロントの事例を探せます。

## 公式リソース

- [ドキュメント](https://shopify.dev/docs/custom-storefronts/hydrogen)

- [Hydrogen React](https://shopify.dev/docs/custom-storefronts/hydrogen-react)

- [GitHub](https://github.com/Shopify/hydrogen)

## 導入<a id="開始方法"></a>

- [クイックスタート](https://shopify.dev/docs/custom-storefronts/hydrogen/getting-started/quickstart) — ローカルでHydrogenアプリを作成。

- [チュートリアル](https://shopify.dev/docs/custom-storefronts/hydrogen/building) — 「Hello World」から、Shopifyのカスタムストアフロントを一通り構築するまで。
