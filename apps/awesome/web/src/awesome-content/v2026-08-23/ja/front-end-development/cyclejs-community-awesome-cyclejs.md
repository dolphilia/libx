# Awesome Cycle.js

Cycle.jsの学習資料と実装例に加え、コマンドラインツール、ドライバー、ユーティリティ、開発用の雛形、テスト・デバッグツール、コンポーネント、コミュニティのチャットを紹介します。リアクティブプログラミング、ストリーム、Model-View-Intent（MVI）アーキテクチャに関する資料も含みます。プロジェクトの機能やイベント情報は、固定原文の記載時点に基づきます。

* [jeysal/pretty-format-snabbdom](https://github.com/jeysal/pretty-format-snabbdom) - [pretty-format](https://github.com/facebook/jest/tree/master/packages/pretty-format)（[Jest](https://facebook.github.io/jest/)のスナップショット用）のプラグイン。snabbdomのVNodeのスナップショットを、React要素と同様に見やすく表示します。
### デバッグ<a id="debugging"></a>

* [cyclejs/cycle-time-travel](https://github.com/cyclejs/cycle-time-travel) - Cycle.jsアプリケーション向けタイムトラベルデバッガー。時間軸をドラッグして過去の状態を確認できるストリーム可視化を表示します
### コンポーネント<a id="components"></a>

* [erykpiast/autocompleted-select](https://github.com/erykpiast/autocompleted-select) - RxJSとVirtualDOMに基づく、自動補完付きの選択欄を提供するWeb Component
* [enten/cyclejs-calendar](https://github.com/enten/cyclejs-calendar) - Cycle.js向けカレンダーコンポーネント。[オンラインデモ](http://enten.github.io/cyclejs-calendar/example)
* [mciparelli/cyclejs-gravatar](https://github.com/mciparelli/cyclejs-gravatar) - Cycle.jsでGravatarプロフィール画像を描画するコンポーネント
* [tommy-the-runner/cyclejs-ace-editor](https://github.com/tommy-the-runner/cyclejs-ace-editor) - [brace](https://github.com/thlorenz/brace)を使用したCycle.jsとAce Editorの統合。[サンプル](https://tommy-the-runner.github.io/cyclejs-ace-editor/)
* [raquelxmoss/cycle-color-picker](https://github.com/raquelxmoss/cycle-color-picker) - Cycle.js向けカラーピッカーコンポーネント。[サンプル](https://raquelxmoss.github.io/cycle-color-picker)
* [cyclejs-community/cycle-svg-pan-and-zoom](https://github.com/cyclejs-community/cycle-svg-pan-and-zoom) - Cycle.js向けの、Google MapsのようにSVGを移動・拡大縮小できるコンポーネント
