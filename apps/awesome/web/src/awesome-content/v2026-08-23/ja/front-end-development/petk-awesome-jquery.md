# Awesome jQuery

[jQuery](http://jquery.com/)は、HTML文書内の要素の探索・操作、イベント処理、アニメーション、Ajaxを、ブラウザー間で共通のAPIから扱う[JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)ライブラリです。学習資料、UIプラグイン、モバイル向けツール、テストライブラリ、サーバー連携に加え、コミュニティ、APIの代替実装、関連リストを紹介します。

## <a id="resources"></a>資料

jQueryとJavaScriptの学習資料で、高度な内容も含みます。jQueryを詳しく学ぶ前に、JavaScriptを十分に学んでおきましょう。

* [APIドキュメント](http://api.jquery.com/) - jQueryの公式ドキュメント
* [Code School](https://www.pluralsight.com/courses/code-school-try-jquery) - jQueryの基礎を学び、ウェブページの要素を変更してユーザーとのインタラクションを改善するコース
* [CodecademyのjQueryコース](https://www.codecademy.com/learn/learn-jquery) - jQueryを学ぶ初心者向けコース
* [Learning jQuery](https://www.learningjquery.com/) - jQueryライブラリのヒント、技法、チュートリアル
* [コードスタイルガイド](https://contribute.jquery.org/style-guide/) - jQueryプロジェクトへの貢献時に使うコードスタイルガイド

## <a id="server-side-integrations"></a>サーバーサイド統合

クライアント側のjQueryとサーバー側の技術を連携させるための資料です。

* Node.js:
    * [Bower](https://bower.io/) - フロントエンド向けに最適化されたパッケージマネージャー
    * [cheerio](https://cheerio.js.org/) - jQuery風にサーバー側でHTMLを操作。HTML文字列からインスタンスを作成し、要素を検索・操作する。AjaxとエフェクトのAPIは実装しない
* PHP:
    * [Nodeを使わないPHPのフロントエンド環境構築](https://www.sitepoint.com/look-ma-no-nodejs-a-php-front-end-workflow-without-node/) - BowerPHP、Mini-AssetおよびRobo.liをPHPのフロントエンドアセット構築パイプラインに組み合わせるチュートリアル
    * [symfony-collection](https://github.com/ninsuo/symfony-collection) - Symfony2のコレクションの要素を追加・削除・移動するjQueryプラグイン
* Python:
    * [django-static-jquery](https://pypi.org/project/django-static-jquery/) - アプリケーションの準備やデプロイを支援する、Djangoアプリとしてパッケージ化したjQuery
* Ruby:
    * [jquery-rails](https://github.com/rails/jquery-rails) - RailsでjQueryを使う自動化を行うgem
    * [jquery-ui-rails](https://github.com/jquery-ui-rails/jquery-ui-rails) - RailsアセットパイプラインにjQuery UIを統合

## <a id="alternatives"></a>代替手段

jQuery APIの代替実装です。

* [cash](https://github.com/kenwheeler/cash) - 現代のブラウザー向けjQuery代替実装。固定原文ではAjaxを除くすべてのAPIを備えるとされている
* [Zepto](https://zeptojs.com/) - Ajax、エフェクト、追加ユーティリティを含むjQuery代替実装
* [jBone](http://jbone.js.org/) - Backboneと組み合わせて使うjQuery実装。Backboneの動作に必要なAPIのみ対応。jQueryを直接使わずBackboneを利用するプロジェクトでは、サイズを抑えられる
