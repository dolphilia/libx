# Awesome Material-UI

[Material-UI](https://material-ui.com/)は、Googleの[Material Design](https://material.io/design/introduction/)に沿ったReactコンポーネントライブラリーです。公式資料、記事、テーマ設定や開発用のツール、関連プロジェクト、コンポーネント、アプリケーション、開発のひな形を探せます。

## リソース

Material-UI Designの公式プロジェクトとリソース。

- [Material-UI](https://material-ui.com/) - 独自のデザインシステムを構築するか、Material Designを基盤に使うためのReactコンポーネント。

## テーマ設定

テーマをカスタマイズし、ブラウザー内で変更できるユーティリティ。

- [Create Material-UI Theme](https://github.com/react-theming/create-mui-theme) - Material Design Color Toolを通じてMaterial-UIテーマを作成するオンラインツール。
- [Material-UI Theme Generator](https://cimdalli.github.io/mui-theme-generator/) - Material-UIテーマ／パレットジェネレーター。
- [Material-UI Theme Editor](https://in-your-saas.github.io/material-ui-theme-editor/) - 色を選択するだけでライブプレビュー付きのMaterial-UIアプリケーションテーマを生成するツール。

## 関連プロジェクト

Material-UI Designファミリーのプロジェクト。

- [material-ui-theme-editor](https://in-your-saas.github.io/material-ui-theme-editor/) - ライブプレビュー機能を備え、Material UIアプリケーションのテーマを生成するツール。
- [Material palette generator](https://m2.material.io/inline-tools/color/) - 公式Material Designパレットジェネレーター。選択した任意の色のパレットを生成できます。
- [Components Extra](https://github.com/alexandre-lelain/components-extra) - Footer、CookiesBanner、BackToTopなど、Material-UIを基盤にしたカスタマイズ可能な「molecule」コンポーネント群。UIの大きな部分を構成する複雑な要素を提供し、サイトごとの実装の重複に対応。
- [React Admin](https://marmelab.com/react-admin/) - ES6、React、Material Designを使用し、REST／GraphQL APIの上でブラウザーで動く管理アプリケーションを構築するフロントエンドフレームワーク。
- [Material UI Snippets](https://marketplace.visualstudio.com/items?itemName=vscodeshift.material-ui-snippets) - スニペットを提供するVSCode拡張機能。
- [Material UI Codemorphs](https://marketplace.visualstudio.com/items?itemName=vscodeshift.material-ui-codemorphs) - codemodを提供するVSCode拡張機能。
- [ESLint：未使用クラスの検出](https://github.com/jens-ox/eslint-plugin-material-ui-unused-classes) - `@mui/styles`を使う未使用スタイルクラスを検出するESLintプラグイン。
