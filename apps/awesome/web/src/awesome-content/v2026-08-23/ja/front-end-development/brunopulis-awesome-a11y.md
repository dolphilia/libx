# Awesome Accessibility

アクセシビリティの資料を、ツール、記事・動画、書籍、講座、求人、W3C仕様などの分野別に探せます。以下のリンクは、このスナップショットに記録されたコミットの元のリポジトリ内にある分野別ファイルを開きます。

## 収録条件

元のリストは[Overlay Fact Sheet](https://overlayfactsheet.com/en/)の方針に沿い、アクセシビリティのオーバーレイツールやオーバーレイを利用する解決策を収録対象から除外しています。
