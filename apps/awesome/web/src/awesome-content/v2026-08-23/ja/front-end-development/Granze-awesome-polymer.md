## <a id="公式-element"></a>公式要素
* [要素カタログ](https://www.webcomponents.org/collection/Polymer/elements)
 * [Iron](https://www.webcomponents.org/collection/PolymerElements/iron-elements) 視覚的・非視覚的なユーティリティ要素集。
 * [Paper](https://www.webcomponents.org/collection/PolymerElements/paper-elements) GoogleのMaterial Designを実装する視覚的な要素集。
 * [Google Web Components](https://www.webcomponents.org/collection/GoogleWebComponents/google-web-components)
 * [Gold](https://www.webcomponents.org/collection/PolymerElements/gold-elements) 購入手続きなど、電子商取引の用途向けの要素。
 * [Platinum](https://www.webcomponents.org/collection/PolymerElements/platinum-elements) プッシュ通知やオフライン対応などを備え、Webページを本格的なWebアプリにする要素。
 * [Molecules](https://www.webcomponents.org/collection/PolymerElements/molecules) ほかのJavaScriptライブラリをラップする要素。
 * [App](https://www.webcomponents.org/collection/PolymerElements/app-elements) モジュール式のカスタム要素から完全なWebアプリを構築するための要素。
 * [Data](https://www.webcomponents.org/collection/PolymerElements/data-elements) データ・ストレージ関連の要素集。
 * [Layout](https://www.webcomponents.org/collection/PolymerElements/layout-elements) レイアウト関連の要素集。
 * [Neon（原リストでは旧式と記載）](https://elements.polymer-project.org/browse?package=neon-elements) 特殊効果を実装する要素。

## ツール
* [App Toolbox](https://www.polymer-project.org/2.0/toolbox/) App Toolbox。
* [Polyserve](https://github.com/polymerlabs/polyserve) Bowerコンポーネントをローカルで使うためのシンプルなWebサーバー。
* [Polybuild](https://github.com/PolymerLabs/polybuild) Polymer アプリ向けのオールインワンのビルドツール。
* [Polyup](https://github.com/PolymerLabs/polyup) Polymer v0.5 から1.0への移行を支援するツール。
* [Polylint](https://github.com/PolymerLabs/polylint) コードのエラーを検出。
* [Polygit](http://polygit.org/) Magic Serverは、HTML Importsの自然な重複排除機能と互換性のある方法で、GitHubから（```cdn.rawgit.com```経由で）ファイルを直接配信。
* [Polydev](https://github.com/PolymerLabs/polydev) 開発者ツールの拡張機能。
* [Polymer Ready](https://chrome.google.com/webstore/detail/polymer-ready/aaifiopbmiecbpladpjaoemohhfjcbdk) Polymerやカスタムコンポーネントを検出すると、アドレスバーにアイコンを表示。
* [Vulcanize](https://github.com/Polymer/vulcanize) HTML Imports と Web Components のビルドツール。
* [Crisper](https://github.com/PolymerLabs/crisper) CSPに準拠するため、HTMLファイルからインラインスクリプトを分離。
* [Atom エディター用スニペット](https://atom.io/packages/polymer-snippets)
* [Sublime Text エディター用スニペット](https://packagecontrol.io/packages/Polymer%20%26%20Web%20Component%20Snippets)
* [Synthesis](https://github.com/meteorwebcomponents/synthesis) PolymerをMeteor.jsの表示層として利用。
* [MWC-Layout](https://github.com/meteorwebcomponents/layout) Polymerコンポーネントのレンダリングを制御。
* [WC-Loader](https://github.com/aruntk/wc-loader) – Web Components用のwebpackローダー。
* [Polymer Webpack Loader](https://github.com/webpack-contrib/polymer-webpack-loader) – Polymer用のwebpackローダー。
* [Polymer CDN](https://github.com/download/polymer-cdn) – Polymerコンポーネント用の非公式CDN。
* [lit-html](https://github.com/Polymer/lit-html) JavaScriptのテンプレートリテラルによるHTMLテンプレート。

## テスト
* [Web Components Tester](https://github.com/Polymer/web-component-tester) Web Componentsのテストを支援。
* [Web Components Tester Istanbul](https://github.com/thedeeno/web-component-tester-istanbul) web-component-tester 用 Istanbul カバレッジプラグイン。
* [test-fixture](https://github.com/PolymerElements/test-fixture) テストスイートのDOMを一貫してリセットする処理を簡素化する要素。
* [iron-test-helpers](https://github.com/PolymerElements/iron-test-helpers) テストを容易にするユーティリティクラス。
