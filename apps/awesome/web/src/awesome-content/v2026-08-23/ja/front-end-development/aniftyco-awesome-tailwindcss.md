# Awesome Tailwind CSS<a id="awesome-tailwindcss"></a>

ユーティリティファーストのCSSフレームワークである[Tailwind CSS](https://tailwindcss.com)の資料をまとめています。エディター拡張機能、ツール、UIライブラリ、テンプレート、プラグインを収録しています。

## 便利なリンク<a id="useful-links"></a>

- [公式サイト](https://tailwindcss.com) - Tailwind CSSの公式サイト。
- [公式リポジトリ](https://github.com/tailwindcss/tailwindcss) - Tailwind CSSの公式リポジトリ。
- [Tailwind Plus](https://tailwindcss.com/plus) - Tailwind CSSチームによる公式のUIブロック、テンプレート、UIキット。
- [Headless UI](https://github.com/tailwindlabs/headlessui) - スタイルを持たない公式UIコンポーネント。原リストでは完全なアクセシビリティを備えると紹介されています。
- [Heroicons](https://heroicons.com/) - 手作業で制作された公式SVGアイコン。
- [Play](https://play.tailwindcss.com/) - Tailwind CSSを試せる公式のオンライン環境。
- [Discord](https://tailwindcss.com/discord) - Tailwind CSSコミュニティの公式Discordサーバー。
- [Tailwind Weekly](https://tailwindweekly.com/) - Tailwind CSSに関する週刊ニュースレター。

## IDE拡張機能<a id="ide-extensions"></a>

- [Intellisense for Code](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) - Visual Studio CodeでIntelliSenseを提供する公式拡張機能。
- [Emacs向けLSP対応](https://github.com/merrickluo/lsp-tailwindcss) - EmacsでIntelliSenseを提供します。

## ツール<a id="tools"></a>

原リストのツール分類は、オンライン、ブラウザー拡張機能、変換・アップグレード、生成ツール、型付け・制約の適用、外部サービス向けツール、色関連、フレームワークです。各項目に付いていた分類を以下に文字で示しています。

- [Prettier plugin](https://github.com/tailwindlabs/prettier-plugin-tailwindcss) - Prettier向けの公式Tailwind CSSプラグイン。 分類: 外部サービス向けツール。
- [UI colors](https://uicolors.app/create) - Tailwind CSS向けのカラーパレット生成ツール。 分類: 色関連、オンライン、生成ツール。
- [Tailwind Color Shades](https://javisperez.github.io/tailwindcolorshades) - Tailwind CSS向けの色の濃淡を生成します。 分類: 色関連、オンライン、生成ツール。
- [TailwindInk](https://tailwind.ink/) - Tailwind CSSのパレットで学習したAIによるパレット生成ツール。 分類: 色関連、オンライン、生成ツール。
- [Hypercolor](https://hypercolor.dev/) - 方向を指定できるTailwind CSSのグラデーション集。 分類: 色関連、オンライン、生成ツール。
- [Tints](https://www.tints.dev/) - Tailwind CSS向けのカラーパレット生成ツールとAPI。 分類: 色関連、オンライン、生成ツール。
- [Fullwind CSS](https://fullwindcss.com/) - Tailwind CSSのカラーパレットに色の濃淡を追加します。 分類: 色関連、オンライン、生成ツール。
- [Inclusive colors](https://www.inclusivecolors.com/) - Tailwind CSSのカラーパレットを細かく調整して作成します。原リストではWCAGのアクセシビリティ要件に対応すると紹介されています。 分類: 色関連、オンライン、生成ツール。
- [FreeColorPalettes.co](https://freecolorpalettes.co/tints-shades) - 任意の16進数の色から、50～950のTailwind CSSカラースケールを生成します。 分類: 色関連、オンライン、生成ツール。
- [Base-2 Rounding](https://objectivelyround.dev) - Tailwind CSS v4の括弧を使わない任意値に対し、間隔とサイズの値を選ぶツール。 分類: オンライン、生成ツール。
- [Prefixer](https://github.vue.tailwind-prefix.cbass.dev) - Tailwind CSSのクラスに接頭辞を付けます。 分類: 変換・アップグレード、オンライン。
- [RustyWind](https://github.com/avencera/rustywind) - Tailwind CSSのクラスを並べ替えるCLIツール。 原リストの分類: 変換・アップグレード。
- [Tailwind to Inline styles converter](https://github.com/vardan-arm/tailwind-to-inline) - メールテンプレートのTailwind CSSクラスをインラインスタイルに変換します。 分類: 変換・アップグレード。
- [Maizzle](https://maizzle.com/) - Tailwind CSSでメールの試作品を作るフレームワーク。 分類: フレームワーク。
- [`@nuxtjs/tailwindcss`](https://github.com/nuxt-community/tailwindcss-module) - PurgeCSSとpreset env 1によるモダンCSSを備えた、Nuxt.js向けTailwind CSSモジュール。 分類: 外部サービス向けツール。
- [tailwindcss-rails](https://github.com/rails/tailwindcss-rails) - RailsのアセットパイプラインでTailwind CSSを使用するためのGem。 分類: 外部サービス向けツール。
- [Config viewer](https://github.com/rogden/tailwind-config-viewer) - Tailwind CSSの設定ファイルを可視化するローカルUI。 分類: 外部サービス向けツール。
- [Raycast extension](https://www.raycast.com/vimtor/tailwindcss) - Raycast Launcherでクラス、ドキュメント、色を検索します。 分類: 外部サービス向けツール。
- [NativeWind](https://www.nativewind.dev) - Tailwind CSSをスクリプト言語として使い、React Nativeで共通のスタイルシステムを構築します。 分類: 外部サービス向けツール。
- [Gimli Tailwind](https://chromewebstore.google.com/detail/gimli-tailwind/fojckembkmaoehhmkiomebhkcengcljl) - Tailwind CSS向けツールを提供するブラウザー拡張機能。 分類: ブラウザー拡張機能。
- [CSS Variables Editor](https://www.cssvariables.com) - daisyUIとshadcn/uiの色を管理する、AIを使用したChrome拡張機能。 分類: ブラウザー拡張機能。
- [DivMagic](https://divmagic.com) - ウェブの要素とそのスタイルをTailwind CSSコンポーネントとしてコピーします。 分類: ブラウザー拡張機能。

## プラグイン<a id="plugins"></a>

原リストのプラグイン分類は、公式プラグイン、テーマ設定、ユーティリティ、コンポーネント、非推奨です。各項目に付いていた分類を以下に文字で示しています。

- [Typography](https://github.com/tailwindlabs/tailwindcss-typography) - タイポグラフィの既定スタイルを持つ`prose`クラスを追加する公式プラグイン。 分類: コンポーネント。
- [Forms](https://github.com/tailwindlabs/tailwindcss-forms) - フォーム要素に既定スタイルを追加する公式プラグイン。
- [Themer](https://github.com/RyanClementsHax/tailwindcss-themer) - CSS変数とバリアントを使ってテーマ機能を追加します。 分類: テーマ設定。
- [Bootstrap grid](https://github.com/karolis-sh/tailwind-bootstrap-grid) - Bootstrap形式のflexboxグリッドシステムを生成します。 分類: ユーティリティ。
- [Dot & grid backgrounds](https://github.com/TheNaubit/tailwind-dot-grid-backgrounds) - CSSでカスタマイズ可能なグリッド背景とドット背景のために、`bg-grid`と`bg-dot`クラスを追加します。 分類: ユーティリティ。
- [Leading Trim](https://github.com/stormwarning/tailwindcss-capsize) - [Capsize](https://github.com/seek-oss/capsize)を使って、テキストの周囲の余白を取り除きます。 分類: ユーティリティ。
- [Scrollbar Hide](https://github.com/reslear/tailwind-scrollbar-hide) - スクロールバーを視覚的に非表示にする`scrollbar-hide`クラスを追加します。 分類: ユーティリティ。
- [px to viewport](https://github.com/the-lemonboy/tailwindcss-px-to-viewport) - pxをvw / vhへ自動変換します。 分類: ユーティリティ。
- [tailwind-hitslop](https://github.com/Jubstaaa/tailwind-hitslop) - 見た目を変えずにタッチ操作の対象領域を広げる`hit-slop`ユーティリティを追加します。React Nativeの`hitSlop`と同様です。 分類: ユーティリティ。
- [tw-fade](https://github.com/petekp/tw-fade) - スクロールの状態に応じて端をフェードさせる`fade-t`/`-b`/`-x`/`-y`ユーティリティを追加します。 分類: ユーティリティ。
- [Fluid](https://github.com/barvian/fluid-tailwind) - すべての組み込みユーティリティに、`clamp()`で滑らかに値が変化する版を追加します。 分類: ユーティリティ、コンポーネント。
- [Debug screens](https://github.com/jorenvanhee/tailwindcss-debug-screens) - 現在有効なレスポンシブブレークポイントを表示します。 分類: コンポーネント。
