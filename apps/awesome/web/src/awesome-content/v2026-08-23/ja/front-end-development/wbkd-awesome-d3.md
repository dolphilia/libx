# Awesome D3

[D3.js](http://d3js.org)のチャート・地図・データ可視化に使うライブラリ、プラグイン、ユーティリティを探せます。チュートリアル、学習資料、概念の解説は対象外で、原文では別の[学習資料一覧](https://github.com/mbostock/d3/wiki/Tutorials)を案内しています。

インタラクティブな[D3 Discovery](https://d3-discovery.net/)ツールでも一覧を探索できます。

## チャート <a id="charts"></a>

- [billboard.js](https://github.com/naver/billboard.js) - 再利用可能なチャートライブラリ。棒・折れ線・面・ドーナツ・円・階段・スプラインの各グラフ。
- [britecharts](https://github.com/britecharts/britecharts) - クライアント側で再利用できるチャートライブラリ。棒・折れ線・ドーナツ・スパークライン・階段の各グラフ。
- [chart-parts](https://github.com/Microsoft/chart-parts) - データ可視化のための柔軟なグラフィックス文法。Reactとの親和性を重視。
- [cubism](https://github.com/square/cubism) - 時系列データの可視化。
- [c3](https://github.com/c3js/c3) - 再利用可能なチャートライブラリ。折れ線・スプライン・階段・面・積み上げ・棒・円・ドーナツの各グラフ。
- [dagre-d3](https://github.com/dagrejs/dagre-d3) - クライアント側で有向グラフをレイアウト。
- [dc.js](https://github.com/dc-js/dc.js) - 大量のデータ向け。
- [d2b](https://github.com/d2bjs/d2b) - 軸付きグラフ、円グラフ、サンキーダイアグラム、サンバースト図のライブラリ。
- [d3-bar](https://github.com/tj/d3-bar) - 棒グラフ。
- [d3-beeswarm](https://github.com/Kcnarf/d3-beeswarm) - ビースウォーム配置を計算するプラグイン。
- [d3-boxplot](https://github.com/akngs/d3-boxplot) - D3.jsの箱ひげ図プラグイン。
- [d3-bumps-chart](https://github.com/johnwalley/d3-bumps-chart) - バンプチャートを可視化するプラグイン。
- [d3-dag](https://github.com/erikbrinkman/d3-dag) - 有向非巡回グラフを可視化するレイアウトアルゴリズム。
- [d3-ez](https://github.com/jamesleesaunders/d3-ez) - 容易に再利用できるD3チャートとコンポーネント。棒・ドーナツ・円・バブル・ローズの各グラフとヒートマップ。
- [d3-flame-graph](https://github.com/spiermar/d3-flame-graph) - 階層データからフレームグラフ（flame graph）を作成。
- [d3-funnel](https://github.com/jakezatecky/d3-funnel) - ファネルチャートとピラミッドチャートのライブラリ。
- [d3-gridding](https://github.com/romsson/d3-gridding) - グリッドを使ったチャートのモックアップ。
- [d3-heatmap](https://github.com/tj/d3-heatmap) - ヒートマップ。
- [d3-message-sequence](https://github.com/koudelka/d3-message-sequence) - 動的・静的なメッセージシーケンス図。
- [d3-upset](https://github.com/chuntul/d3-upset) - UpSetプロットを描く関数。UpSet・棒グラフ、集合の共通部分、ベン図、関係の表示。
- [d3-x3d](https://github.com/jamesleesaunders/d3-x3d) - D3とX3Dによるデータ駆動の3Dチャート。バブル・棒・曲面・散布・面の各グラフ。
- [d3fc](https://github.com/d3fc/d3fc) - インタラクティブなチャートコンポーネント集。折れ線・棒・積み上げ・散布・ローソク足・OHLCの各グラフ。
- [d3plus](https://github.com/alexandersimoes/d3plus) - 可視化を容易に作成する拡張ライブラリ。散布・積み上げ・折れ線・棒・円・ネットワーク・バブル・箱ひげの各図と地図。
- [d3panels](https://github.com/kbroman/d3panels) - 複数の図を連動させて選択するブラッシングに対応したインタラクティブなチャート。ドットプロット・散布図・折れ線グラフ・ヒートマップ・ヒストグラム。
- [d3pie](https://github.com/benkeen/d3pie) - 設定可能な円グラフライブラリとジェネレーター。
- [D3xter](https://github.com/NathanEpstein/D3xter) - 簡単に使えるプロット。一般的なプロット、タイムライン、棒グラフ、ヒストグラム、円グラフ。
- [D4](https://github.com/heavysixer/d4) - 再利用可能なチャート用DSL。棒・ドーナツ・折れ線・散布・積み上げ・ウォーターフォールの各グラフ。
- [dTree](https://github.com/ErikGartner/dTree) - 家系図ライブラリ。
- [EventDrops](https://github.com/marmelab/EventDrops) - 時間・イベント系列のインタラクティブな可視化。
- [metrics-graphics](https://github.com/metricsgraphics/metrics-graphics) - 時系列データの可視化に最適化。折れ線グラフ・散布図・面グラフ。
- [micropolar](https://github.com/biovisualize/micropolar/) - 極座標チャートのライブラリ。
- [mpld3](https://github.com/mpld3/mpld3) - matplotlibの図をブラウザーで動作する形へエクスポート。
- [neo4jd3](https://github.com/eisman/neo4jd3) - Neo4jグラフの可視化。
- [nvd3](https://github.com/novus/nvd3) - 再利用可能なチャートとコンポーネント。箱ひげ・ブレット・ローソク足・折れ線・棒・円・散布・スパークラインの各グラフ。
- [oecd-simple-charts](https://github.com/oecd-cyc/oecd-simple-charts) - シンプルなチャートライブラリ。箱ひげ図・積み上げ棒グラフ・パールチャート。
- [plotly.js](https://github.com/plotly/plotly.js/) - 高水準のチャートライブラリ。散布・折れ線・棒・円・箱ひげの各グラフ、ヒストグラム、ヒートマップ。
- [plottable](https://github.com/palantir/plottable) - Web向けの柔軟でインタラクティブなチャート。面・棒・折れ線・円・散布・積み上げの各グラフ。
- [rickshaw](https://github.com/shutterstock/rickshaw) - インタラクティブなリアルタイムグラフを作るツールキット。折れ線グラフ・散布図・棒グラフ。
- [taucharts](https://github.com/TargetProcess/tauCharts) - デザインと柔軟性を重視したチャート。折れ線・棒・面・積み上げの各グラフ。
- [vega](https://github.com/vega/vega) - 可視化の文法。
- [vega-lite](https://github.com/vega/vega-lite) - インタラクティブなグラフィックスの高水準文法。
- [vega-lite-api](https://github.com/vega/vega-lite-api) - Vega-LiteのJavaScript API。
- [venn.js](https://github.com/benfred/venn.js) - 面積が値に比例するベン図とオイラー図。
- [visavail](https://github.com/flrs/visavail) - 時間経過に沿ったデータの利用可能状況を可視化。
- [vizabi](https://github.com/vizabi/vizabi) - 視覚的なデータ探索ツールを構築するフレームワーク。バブルグラフ・地図・折れ線グラフ・棒グラフ・サンキーダイアグラム・ドーナツグラフ。
- [WebCola](https://github.com/tgdwyer/WebCola) - グラフの可視化・探索向けレイアウト。
- [xkcdgraphs](https://github.com/imkevinxu/xkcdgraphs) - xkcd風のグラフ。折れ線グラフ。

- [vx](https://github.com/hshoff/vx) - React向け可視化コンポーネント。棒・折れ線・散布・積み上げ・面・円・放射状の各図、パターン、ヒートマップ、地図、地理情報。

- [v-chart-plugin](https://github.com/ignoreintuition/v-chart-plugin) - Vue.jsコンポーネントに保存したデータへチャートを容易にバインド。


## 地図 <a id="maps"></a>

- [d3-geo-polygon](https://github.com/d3/d3-geo-polygon) - 球面多角形のクリッピングと幾何演算。
- [d3-geo-projection](https://github.com/d3/d3-geo-projection) - 地理投影法の拡張。

- [d3-geo-voronoi](https://github.com/Fil/d3-geo-voronoi) - 球面のボロノイ図とドロネー三角分割。
- [d3-geomap](https://github.com/yaph/d3-geomap) - 地図を作成するライブラリ。

- [d3-inertia](https://github.com/Fil/d3-inertia) - マウスの移動を慣性付きで継続するd3-drag拡張。
- [mapmap.js](https://github.com/floledermann/mapmap.js) - インタラクティブな主題図のためのデータ駆動API。
- [maptable](https://github.com/Packet-Clearing-House/maptable) - データセットを地図・フィルター・表の視覚コンポーネント群へ変換。
- [simple-map-d3](https://github.com/MinnPost/simple-map-d3) - 簡単に使えるコロプレス地図。
- [spam](https://github.com/newsappsio/spam) - D3とCanvasを使って地図を容易に作成。
