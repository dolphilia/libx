# Awesome CSS Frameworks

CSSのリセット・正規化、クラスレスのスタイル設定、汎用UI、Material Design、ユーティリティベースの設計向けのフレームワークを探せます。レトロなUI、印刷、メール、放射状UI向けのものも収録し、容量や保守状況の分類は固定原文に従っています。React・Vue・Angular向けの別資料は[UIコンポーネントライブラリー](https://frontaid.ch/web/ui/libraries.html)を参照してください。

## ベース／リセット／正規化

- [**modern-normalize**](https://github.com/sindresorhus/modern-normalize) - ブラウザーの既定スタイルを正規化。
  [リポジトリ](https://github.com/sindresorhus/modern-normalize)
  | #CSS

- [**ress**](https://github.com/filipelinhares/ress) - モダンなCSSリセット。
  [リポジトリ](https://github.com/filipelinhares/ress)
  | #CSS

- [**Natural Selection**](https://github.com/frontaid/natural-selection) - 原文でベストプラクティスとされるCSSセレクター集。
  | #CSS

## クラスレス

  [リポジトリ](https://github.com/andybrewer/mvp/)

  [デモ](https://oxal.org/projects/sakura/demo/)、
  [リポジトリ](https://github.com/oxalorg/sakura)
  | #SCSS

  [デモ](https://simplecss.org/demo)、
  [ドキュメント](https://github.com/kevquirk/simple.css/wiki)、

## 開発停滞<a id="開発停止"></a>

固定原文で、約1年以上にわたり実質的な開発がないか、公式に非推奨となったものとして分類されたフレームワークです。参考や着想のために保持しています。この分類は現在の状況を示すものではありません。
