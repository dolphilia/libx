# Awesome Mobile Web Development

モバイル向けのウェブサイトやウェブアプリを作るための資料です。性能、アクセシビリティ、入力、画面、消費電力、オフライン対応に関する記事・書籍・仕様・講演のほか、監査ツール、プラットフォームの動向を調べる資料、ライブラリを探せます。

## <a id="specifications-from-w3c-for-enhancing-mobile-web-experience"></a>モバイルウェブ体験を高めるW3C仕様

- [Battery API](https://www.w3.org/TR/battery-status/) - バッテリー情報へのアクセス。
- [Connection API](http://wicg.github.io/netinfo/) - 接続情報へのアクセス。
- [Generic Sensor API](https://www.w3.org/TR/generic-sensor/) - センサーデータを提供する仕様。
- [Geolocation API](https://www.w3.org/TR/geolocation-API/) - 位置情報へのアクセス。
- [HTML Media Capture](https://www.w3.org/TR/html-media-capture/) - ユーザーによるカメラやマイクへのアクセス。
- [Payment Request API](https://www.w3.org/TR/payment-request/) - 最小限の組み込みで使える支払い方法。
- [Presentation API](https://www.w3.org/TR/presentation-api/) - プレゼンテーション用ディスプレイへのアクセス。
- [Remote Playback API](https://www.w3.org/TR/remote-playback/) - ウェブページからメディアのリモート再生を制御する方法。
- [Vibration API](https://www.w3.org/TR/vibration/) - 端末の振動機構へのアクセス。
- [Visual Viewport API](https://wicg.github.io/visual-viewport/) - 画面上のキーボードやピンチズームで拡大した範囲の外側などを除いた、画面の可視領域へのアクセス。
- [Wake Lock Api](https://www.w3.org/TR/wake-lock/) - デバイスの一部の機能が省電力状態に入るのを防ぐWake Lockリクエストへのアクセス。
- [Web Bluetooth](https://webbluetoothcg.github.io/web-bluetooth/) - Bluetooth 4を使ってデバイスを検出し、通信するAPI。
- [Web NFC API](https://w3c.github.io/web-nfc/) - デバイスの近距離無線通信（NFC）機能へのアクセス。
- [Web Notifications](https://www.w3.org/TR/notifications/) - 利用者に通知を送るAPI。

## <a id="auditing-tools"></a>監査ツール

- [Lighthouse](https://github.com/GoogleChrome/lighthouse) - ウェブアプリとウェブページの分析ツール。
- [Mobile-Friendly Test](https://search.google.com/test/mobile-friendly) - サイトがモバイルに対応しているかをテストするツール。
- [PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights) - ページを分析し、ダウンロード速度を改善するための提案を行うツール。
- [PageSpeed](https://www.modpagespeed.com) - サイトを自動で最適化するウェブサーバーモジュール。
- [Site Speed Checker](https://www.thinkwithgoogle.com/feature/mobile) - モバイルサイトの速度を他のサイトと比較するツール。
- [Test Your Mobile Speed](https://testmysite.withgoogle.com/intl/en-gb) - モバイルサイトの速度を総合的に検査するGoogleのツール。
- [Webpagetest](https://webpagetest.org) - 実際のブラウザーと利用者の実際の回線速度で、複数の地域から行うウェブサイトの速度テスト。

## <a id="platform-monitoring"></a>プラットフォーム監視

- [Can I Use](https://caniuse.com) - ブラウザーによる各種ウェブ機能への対応状況。
- [Mobile Browser Market Share](http://gs.statcounter.com/browser-market-share/mobile) - 各種プラットフォームや国別の市場シェア。
- [Standards for Web Applications on Mobile](https://www.w3.org/Mobile/mobile-web-app-state) - モバイル関連のW3C仕様の状況を示す資料。
- [What Web Can Do Today](https://whatwebcando.today) - 利用中のブラウザーで使える機能。

## <a id="other-useful-tools-and-libraries"></a>その他の便利なツールとライブラリ

- [Browsersync](https://browsersync.io) - 同期したブラウザーテストで時間を短縮するツール。
- [Eruda](https://github.com/liriliri/eruda) - モバイルウェブブラウザー向けのコンソール。
- [Interact.js](https://github.com/taye/interact.js) - モダンブラウザーでのドラッグ＆ドロップ、サイズ変更、慣性とスナップを備えたマルチタッチジェスチャー。
- [Fastclick](https://github.com/ftlabs/fastclick) - 古いブラウザーにおける300msの遅延を解消するライブラリ。
- [Lozad.js](https://github.com/ApoorvSaxena/lozad.js) - IntersectionObserver APIを使う、高性能で軽量、設定可能な遅延読み込みライブラリ。
- [React Dates](https://github.com/airbnb/react-dates) - 国際化しやすく、モバイルに対応するウェブ向けの日付選択用Reactライブラリ。
- [Screen Sizes](http://screensiz.es/phone) - 人気のあるスマートフォン全機種の画面サイズの一覧。
- [Shiny](https://github.com/rikschennink/shiny) - モバイルウェブサイト向けの光沢のある反射エフェクト。
- [Slideout](https://github.com/Mango/slideout) - モバイルウェブアプリ向けの独立した軽量ナビゲーションメニュー。
- [Swiper](https://github.com/nolimits4web/swiper) - ハードウェアで加速する画面遷移を備えたモバイル向けタッチスライダー。原文では最も現代的と説明。
- [Web Inspector Remote (Weinre)](https://www.npmjs.com/package/weinre) - 主流以外のブラウザーでサイトをデバッグするウェブインスペクター。
- [Web Starter Kit](https://github.com/google/web-starter-kit) - 複数のデバイスに対応するウェブサイトのためのワークフロー。
- [Workbox](https://developers.google.com/web/tools/workbox/) - ウェブアプリにオフライン対応を追加するJavaScriptライブラリ。
- [WorkerDOM](https://amphtml.wordpress.com/2018/08/21/workerdom/) - Web Workers内でDOM全体を表現するライブラリ。
