# Awesome flexbox

CSS Flexible Box Layout（Flexbox）の資料をまとめています。W3C仕様、学習資料、ブラウザー互換性、ツール、ライブラリ、実装例、講座から探せます。説明と対応状況は固定原文に沿っています。「原文の注目項目」は、元のリストの推奨印`:metal:`を文字で表したものです。

原文で参照されている関連リスト: [Awesome Web Components](https://github.com/obetomuniz/awesome-webcomponents)と[Awesome SVG](https://github.com/willianjusten/awesome-svg)。
