# Awesome Canvas

HTML CanvasではJavaScriptでグラフィックスを描画できます。アニメーションやゲームのデモ、描画ライブラリ、講演、書籍、実験を共有する開発者、チュートリアルを紹介します。

## Canvas

### <a id="definition"></a>定義

[Mozilla Developer Network](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API)は、HTML5で追加されたHTMLの&lt;canvas>要素を、JavaScriptで描画するための要素と説明しています。グラフ、写真の合成、アニメーション、リアルタイムの動画処理や描画などに使えます。

## <a id="libraries"></a>ライブラリ

### <a id="to-draw-using-canvas"></a>Canvasで描画するためのライブラリ

- [Akihabara](http://www.kesiev.com/akihabara/) - JavaScriptとcanvasタグでピクセルベースのゲームを作るHTML5ゲームライブラリ
- [CanvasKit](https://skia.org/docs/user/modules/canvaskit/) - SkiaのCanvas APIをWebAssemblyへコンパイルし、ウェブアプリ向けに高性能な2Dグラフィックス描画を提供
- [Chart.js](https://github.com/chartjs/Chart.js) - HTML5 Canvasで動的なグラフを作成する軽量JavaScriptライブラリ
- [ChemDoodle](http://web.chemdoodle.com/) - Canvasで一般的な化学の処理やさまざまな分子表示を行う、オープンソースの化学・ケモインフォマティクス用ツールキット
- [d3](https://github.com/d3/d3) - D3.jsは、ウェブ標準のSVG、Canvas、HTMLを使うデータ可視化用JavaScriptライブラリ
- [EaselJS](https://createjs.com/easeljs) - ゲーム、ジェネラティブアートなどのグラフィックスにHTML5 Canvasを使うJavaScriptライブラリ。HTML5によるインタラクティブなコンテンツ作成用のモジュール式ライブラリ・ツール群CreateJSの一部で、各ツールは組み合わせても独立しても利用可能
- [fabric.js](http://fabricjs.com) - Canvas上のインタラクティブなオブジェクトモデルと、SVGからCanvas・CanvasからSVGへのパーサーを提供
- [iio.js](https://github.com/iioinc/iio.js) - HTML5 Canvasアプリの作成とデプロイを速めるJavaScriptライブラリ
- [isomerjs](http://jdan.github.io/isomer/) - HTML5 Canvas向けの等角投影グラフィックスライブラリ
- [Javascript-Voronoi](https://github.com/gorhill/Javascript-Voronoi) - Voronoiセルを計算するFortuneのアルゴリズムのJavaScript実装
- [Konva](https://github.com/konvajs/konva) - 2Dコンテキストを拡張し、デスクトップ・モバイルアプリのCanvas操作を可能にするHTML5 Canvas用JavaScriptフレームワーク
- [Origami.js](https://github.com/raphamorim/origami.js) - Canvas APIのインターフェースを再設計するJavaScriptライブラリ
- [p5.js](https://p5js.org) - グラフィックスやインタラクティブな表現を作る、クライアント側のJavaScriptライブラリ
- [Paper.js](https://github.com/paperjs/paper.js) - ScriptographerをJavaScriptとブラウザーへ移植し、HTML5 Canvasを利用
- [Pencil.js](https://pencil.js.org/) - オブジェクト指向の構文とさまざまな機能を備えた、モジュール式JavaScriptライブラリ
- [Pixi.js](http://www.pixijs.com) - WebGLを使うHTML5の2D描画エンジン。Canvasへのフォールバックに対応
- [Processingjs](http://ejohn.org/blog/processingjs/) - データ可視化用プログラミング言語
    - [概要](http://ejohn.org/blog/overview-of-processing/)
    - [91の基本デモ](http://ejohn.org/apps/processing.js/examples/basic/)
- [Proton](https://github.com/a-jie/Proton) - さまざまな効果を作成する軽量JavaScriptパーティクルエンジン
- [Pts.js](https://ptsjs.org) - 可視化とクリエイティブコーディング向けのJavaScriptライブラリ
- [Rough.js](https://roughjs.com/) - スケッチ風・手描き風に描画するグラフィックスライブラリ
- [Scrawl-canvas](https://scrawl-v8.rikweb.org.uk/) - レスポンシブでアクセシブルかつインタラクティブな複数の&lt;canvas>要素をウェブページへ追加
- [Sketch](https://github.com/soulwire/sketch.js) - 複数プラットフォームに対応するJavaScriptクリエイティブコーディングフレームワーク
- [Three.js](http://threejs.org/) - ブラウザーでWebGLによる3D描画を行うJavaScriptライブラリ。固定原文には[WebGLの代わりにCanvasで描画する方法](http://threejs.org/docs/#Reference/Renderers/CanvasRenderer)へのリンクも記載
    - [入門](http://threejs.org/docs/#Manual/Introduction/Creating_a_scene)
    - [実例](http://threejs.org/examples/)
- [textmode.js](https://github.com/humanbydefinition/textmode.js) - ブラウザーでリアルタイムのASCII・テキストモードグラフィックスを扱う、軽量でフレームワークに依存しないクリエイティブコーディングライブラリ
- [tsParticles](https://particles.matteobruni.it/) - 軽量なパーティクルアニメーションライブラリ。ReactJS、VueJS、Angularなど、よく使われるJavaScriptフレームワーク向けの、そのまま使えるコンポーネントを含む
- [Visualize](https://github.com/filamentgroup/jQuery-Visualize) - 表形式のデータからHTML Canvasでグラフを作成するjQueryプラグイン
- [zDog](https://github.com/metafizzy/zdog) - CanvasとSVG向けの、平面的で丸みを帯びたデザイナー向け擬似3Dエンジン
- [ZIM](https://zimjs.com/) - 初心者から専門家まで、JavaScriptで創作を行うための汎用Canvasフレームワーク
- [zrender](https://github.com/ecomfe/zrender) - 固定原文で育成段階とされるApache EChartsに、2D描画を提供する軽量Canvasライブラリ

### <a id="for-other-purposes-but-still-use-canvas"></a>その他の目的でCanvasを使うもの
