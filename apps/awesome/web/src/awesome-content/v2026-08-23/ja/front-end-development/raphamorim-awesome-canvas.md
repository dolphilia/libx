## Canvas

<a id="definition"></a>
### 定義

「HTML5で追加されたHTMLの&lt;canvas>要素は、JavaScriptによるスクリプティングでグラフィックスを描画できます。グラフの描画、写真の合成、アニメーションの作成、さらにはリアルタイムの動画処理やレンダリングにも利用できます。」— [Mozilla Developer Network](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API)

## ライブラリ

<a id="to-draw-using-canvas"></a>
### Canvasで描画するためのライブラリ

- [Akihabara](http://www.kesiev.com/akihabara/) はJavaScriptとキャンバスタグを使用してピクセルベースのゲームを作成するためのHTML5ゲームライブラリ
- [CanvasKit](https://skia.org/docs/user/modules/canvaskit/) はSkiaのキャンバスAPIをWebAssemblyにコンパイルし、ウェブアプリケーション向けに高性能な2Dグラフィックスレンダリングを提供します
- [Chart.js](https://github.com/chartjs/Chart.js) はHTML5キャンバス要素を使用して動的で視覚的に魅力的なチャートを作成するための軽量JavaScriptライブラリ
- [ChemDoodle](http://web.chemdoodle.com/) はオープンソースの化学および化学情報学ツールキットで、キャンバスを使用して一般的な化学関連タスクを解決し、分子をさまざまな方法で表示します
- [d3](https://github.com/d3/d3) （またはD3.js）はウェブ標準を使用してデータを可視化するJavaScriptライブラリです。D3はSVG、キャンバス、HTMLを使用してデータを生き生きと表現するためのツールです
- [EaselJS](https://createjs.com/easeljs) はHTML5キャンバス要素の操作を容易にするJavaScriptライブラリです。ゲーム、生成芸術、その他の高度にグラフィカルな体験を作成に有効です。EaselJSはCreateJSの一部であり、モジュールライブラリとツールが協力または独立して、オープンウェブ技術を用いた豊かなインタラクティブコンテンツを実現します
- [fabric.js](http://fabricjs.com) はキャンバス要素上のインタラクティブオブジェクトモデルを提供し、SVGからキャンバス（およびキャンバスからSVG）へのパーサーも備えています
- [iio.js](https://github.com/iioinc/iio.js) - HTML5 Canvasアプリケーションの作成とデプロイを速くするJavaScriptライブラリ
- [isomerjs](http://jdan.github.io/isomer/) - HTML5キャンバス向けの等角グラフィックスライブラリ
- [Javascript-Voronoi](https://github.com/gorhill/Javascript-Voronoi) - FortuneのアルゴリズムをJavaScriptで実装したVoronoiセル計算ライブラリ
- [Konva](https://github.com/konvajs/konva) - Konva.jsはHTML5キャンバスのJavaScriptフレームワークで、デスクトップおよびモバイルアプリケーションにおけるキャンバスのインタラクティブ性を拡張
- [Origami.js](https://github.com/raphamorim/origami.js) - キャンバスAPIインターフェースをリデザインするJavaScriptライブラリ
- [p5.js](https://p5js.org) - p5.jsは、グラフィックおよびインタラクティブ体験を作成するためのJavaScriptクライアントサイドライブラリ
- [Paper.js](https://github.com/paperjs/paper.js) - ScriptographerをJavaScriptおよびブラウザに移植したHTML5キャンバスベースの実装
- [Pencil.js](https://pencil.js.org/) - 明確なOOP構文と多くの機能を備えた、とてもモジュラリなJavaScriptライブラリ
- [Pixi.js](http://www.pixijs.com) - WebGLを用いた高速HTML5 2Dレンダリングエンジン（キャンバスフォールバックあり）
- [Processingjs](http://ejohn.org/blog/processingjs/) データ可視化用のプログラミング言語
    - [Overview](http://ejohn.org/blog/overview-of-processing/)
    - [91 basic demos](http://ejohn.org/apps/processing.js/examples/basic/)
- [Proton](https://github.com/a-jie/Proton) 軽量かつ強力なJavaScript粒子エンジン。これにより、無数の魅力的な効果を簡単に作成できます
- [Pts.js](https://ptsjs.org) - Ptsは、可視化とクリエイティブコーディングを行うためのJavaScriptライブラリ
- [Rough.js](https://roughjs.com/) - Rough.jsは、スケッチ風、手書きのようなスタイルで描画できるグラフィックスライブラリ
- [Scrawl-canvas](https://scrawl-v8.rikweb.org.uk/) - ウェブページに複数のレスポンシブでアクセシブルかつインタラクティブな&lt;canvas&gt;要素を簡単に追加
- [Sketch](https://github.com/soulwire/sketch.js) - マルチプラットフォーム対応のJavaScriptクリエイティブコーディングフレームワーク
- [Three.js](http://threejs.org/) WebGLによるブラウザー上の3D表示を実現するJavaScriptライブラリ。[WebGLの代わりにCanvasでレンダリング](http://threejs.org/docs/#Reference/Renderers/CanvasRenderer)することもできます
    - [Introduction](http://threejs.org/docs/#Manual/Introduction/Creating_a_scene)
    - [Some amazing examples](http://threejs.org/examples/)
- [textmode.js](https://github.com/humanbydefinition/textmode.js) ブラウザ上でリアルタイムのASCIIおよびテキストモードグラフィックスを扱うための軽量かつフレームワークに依存しないクリエイティブコーディングライブラリです
- [tsParticles](https://particles.matteobruni.it/) よく使われるJavaScriptフレームワーク（ReactJS、VueJS、Angularなど）に即時対応する、簡単な粒子アニメーションを作成できる軽量ライブラリです
- [Visualize](https://github.com/filamentgroup/jQuery-Visualize) JQueryプラグインで、HTMLキャンバス要素を使ってテーブルデータからチャートやグラフを作成します
- [zDog](https://github.com/metafizzy/zdog) - キャンバスとSVGに最適化された、フラットで丸みを帯びたデザイナー向けの擬似3Dエンジン
- [ZIM](https://zimjs.com/) - ZIMは、シンプルで強力なJavaScriptを用いた一般向けキャンバスフレームワークで、初心者からプロまで誰でも創造性をコードで表現できます
- [zrender](https://github.com/ecomfe/zrender) - Apache EChartsを内部で支える、軽量な2D描画ライブラリ
