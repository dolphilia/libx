# Awesome Web Animation

Webアニメーションは、ブラウザーのインターフェイスやグラフィックスに動きを加える技術です。SVG、CSS、Canvas、スクロール、テキスト、React向けのライブラリ、ブラウザー用アニメーションを作成・出力するGUIツール、書籍、動画を紹介します。

## SVG

- [Snap.svg](https://github.com/adobe-webplatform/Snap.svg) - SVGグラフィックス用のJavaScriptライブラリ。
- [Svg.js](https://github.com/svgdotjs/svg.js) - SVGの操作とアニメーションに使う軽量ライブラリ。
- [Vivus](https://github.com/maxwellito/vivus) - SVGの描画アニメーションを作るライブラリ。
- [Walkway](https://github.com/ConnorAtherton/walkway) - SVG要素をアニメーションさせるライブラリ。
- [Raphael](https://github.com/DmitryBaranovskiy/raphael) - JavaScriptのベクターグラフィックスライブラリ。
- [Bonsai](https://github.com/uxebu/bonsai) - グラフィックスライブラリとレンダラー。

## 共通

- [GSAP](https://github.com/greensock/GSAP) - JavaScriptのアニメーションライブラリ。
- [TweenJS](https://github.com/CreateJS/TweenJS) - CreateJSのライブラリ群に含まれる、JavaScriptの中間補間・アニメーションライブラリ。
- [Anime.js](https://github.com/juliangarnier/anime) - JavaScriptのアニメーションエンジン。
- [Mojs](https://github.com/mojs/mojs) - Web向けのモーショングラフィックスツール群。
- [Animo.js](https://github.com/ThrivingKings/animo.js) - CSSアニメーションを管理する小さなツール。
- [Move.js](https://github.com/visionmedia/move.js) - CSS3を利用するJavaScriptのアニメーションフレームワーク。
- [Velocity](https://github.com/julianshapiro/velocity) - JavaScriptアニメーションを高速化するライブラリ。
- [Animateplus](https://github.com/bendc/animateplus) - Web向けのアニメーションモジュール。
- [Animatic](https://github.com/lvivski/animatic) - CSSアニメーションエンジン。
- [Just Animate](https://github.com/just-animate/just-animate) - アニメーションの作成を簡単にするライブラリ。
- [Haiku Core](https://github.com/HaikuTeam/core) - Web向けの対話的なUIアニメーションエンジンで、Haiku Animatorのコアレンダラー。
- [Between.js](https://github.com/sasha240100/between.js) - JavaScript（ES6）の軽量な中間補間エンジン。
- [Progressbar.js](https://github.com/kimmobrunfeldt/progressbar.js) - 画面サイズに対応するプログレスバーのライブラリ。
- [Bezier easing](https://github.com/gre/bezier-easing) - JavaScriptアニメーションのイージングに使う3次ベジェ曲線の実装。
- [Glsl easings](https://github.com/glslify/glsl-easings) - GLSLのイージング関数。
- [ES6-tween](https://github.com/tweenjs/es6-tween) - tween.jsのES6版。
- [Weeee.js](https://github.com/sfi0zy/weeee) - JavaScriptの小さな中間補間エンジン。

## CSS

- [Animate.css](https://github.com/daneden/animate.css) - 複数のブラウザーに対応するCSSアニメーションライブラリ。
- [Motion-ui](https://github.com/foundation/motion-ui) - CSSのトランジションとアニメーションを作成するSassライブラリ。
- [Magic](https://github.com/miniMAC/magic) - 特殊効果を持つCSS3アニメーション。
- [Css-loaders](https://github.com/lukehaas/css-loaders) - CSSで動く読み込み中のスピナー集。
- [SpinKit](https://github.com/tobiasahlin/SpinKit) - CSSで動く読み込み中の表示部品集。
- [Bounce.js](https://github.com/tictail/bounce.js) - CSS3アニメーションを作成するツール。

## Canvas

- [EaselJS](https://github.com/CreateJS/EaselJS) - HTML5で高性能な対話的2Dコンテンツを作るライブラリ。
- [Fabric.js](https://github.com/fabricjs/fabric.js) - アニメーションに対応するJavaScriptのCanvasライブラリ。
- [Paper.js](https://github.com/paperjs/paper.js) - ScriptographerをHTML5 CanvasでJavaScriptとブラウザー向けに移植した、ベクターグラフィックスのスクリプト処理ライブラリ。
- [Konva](https://github.com/konvajs/konva) - 2D描画コンテキストを拡張し、デスクトップ・モバイルアプリに対話性を加えるHTML5 CanvasのJavaScriptフレームワーク。
- [Two.js](https://github.com/jonobr1/two.js) - アニメーションに対応し、レンダラーに依存しないWeb向けの2D描画API。
- [Ocanvas](https://github.com/koggdal/ocanvas) - オブジェクトを使ってCanvasに描画するJavaScriptライブラリ。
- [Curtainsjs](https://github.com/martinlaxenaire/curtainsjs) - HTML DOM要素を対話的なテクスチャ付き平面に変える、追加フレームワークを使わないJavaScriptの軽量WebGLライブラリ。
- [Hover-effect](https://github.com/robin-dela/hover-effect) - ホバー時に画像を描画・アニメーションさせるJavaScriptライブラリ。
- [Pts.js](https://github.com/williamngan/pts) - 可視化とクリエイティブコーディング用のTypeScript/JavaScriptライブラリ。
- [tsParticles](https://github.com/matteobruni/tsparticles/) - パーティクルアニメーションを作成するTypeScript/JavaScriptの軽量ライブラリ。

## スクロール時アニメーション

- [AOS](https://github.com/michalsnik/aos) - スクロール時のアニメーション用ライブラリ。
- [Laxxx](https://github.com/alexfoxy/laxxx) - 追加フレームワークを使わず、スクロール時に滑らかなアニメーションを作るJavaScriptの小さな軽量プラグイン。固定原文の説明では、コードの縮小と圧縮後のサイズは3kb。
- [Wow](https://github.com/matthieua/WOW) - ページを下へスクロールするとCSSアニメーションを表示する。
- [Scrollreveal](https://github.com/scrollreveal/scrollreveal) - 要素がスクロールで表示領域に入ったときにアニメーションさせる。
- [ScrollMagic](https://github.com/janpaepke/ScrollMagic) - スクロールに連動する操作用のJavaScriptライブラリ。
- [Motus](https://github.com/alexcambose/motus) - スクロール中にCSSキーフレームを模した動きを作るアニメーションライブラリ。
- [Sal](https://github.com/mciastek/sal) - 性能を重視した軽量なスクロールアニメーションライブラリ。

## テキスト

- [Malarkey](https://github.com/yuanqing/malarkey) - 追加フレームワークを使わないJavaScriptでタイプライター効果を作る。
- [Typed.js](https://github.com/mattboldt/typed.js) - 文字入力のアニメーション用JavaScriptライブラリ。
- [Shuffle-text](https://github.com/ics-ikeda/shuffle-text) - Flashの効果に着想を得たJavaScriptのテキスト効果ライブラリ。
- [Typebot](https://github.com/akzhy/typebot) - 文字入力のアニメーション用JavaScriptライブラリ。
- [Blotter](https://github.com/bradley/Blotter) - Web上で独特なテキスト効果を描画するJavaScript API。

## React

- [Motion](https://github.com/framer/motion) - React向けのオープンソースのアニメーション・ジェスチャーライブラリ。固定原文では本番利用に対応すると説明されている。
- [SVGR](https://github.com/gregberge/svgr) - SVGをReactコンポーネントに変換する。
- [React tsParticles](https://github.com/matteobruni/tsparticles/blob/master/components/react/README.md) - tsParticles用のReactJSラッパー。
- [React spring](https://www.react-spring.io/) - ばねの物理に基づき、補間に対応するReact向けのオープンソースアニメーションライブラリ。固定原文は速度と使いやすさを特徴として挙げている。

## GUI ツール

- [Svgartista](https://svgartista.net/) - 通常のCSSでSVGの輪郭線（stroke）と塗りつぶし（fill）のプロパティをアニメーションさせるツール。原文ではpath、line、polyline、rect、circle、ellipse、polygon要素での動作を想定しているが、SVGのグラデーションはアニメーションできない。
- [Mantra](https://jeremyckahn.github.io/mantra/) - Adobe FlashとAfter Effectsに着想を得たWebアニメーション用のタイムライン編集ツール。
- [Animista](https://animista.net/) - 用意されたCSSアニメーションを試して調整し、必要なものを取り出すツール。
- [Cssanimate](http://cssanimate.com/) - コーディングやデスクトップソフトウェアを使わずに、複雑なCSS3キーフレームアニメーションを作り、サイト用のCSSスタイルを取得するブラウザーツール。
- [Ceaser](https://matthewlein.com/tools/ceaser) - ease-inやease-outなどの既定の選択肢に加え、3次ベジェ曲線でCSSトランジションのイージングを調整するツール。FlashやjQueryで知られる従来のPennerの式の多くを含み、タッチ端末にも対応する。
- [Cubic Bezier](https://cubic-bezier.com/) - ベジェ曲線を作成し、ライブラリとのインポート・エクスポートで他者と共有するツール。
- [Keyframer](http://alexberg.in/keyframer/) - アニメーションの構成要素を可視化し、必要なコードを生成するツール。
- [CSS Animation Kit](http://angrytools.com/css/animation/) - 上部パネルで用意されたサンプルを選び、その下の@keyframesタイムラインを編集するツール。タイムラインには左から右へ0%から100%まで101キーフレームが並ぶ。強調表示されたキーフレームにはスタイルが割り当てられており、選択した位置に新しいスタイルを追加できる。

## 書籍

### [SVG animation](https://www.amazon.com/SVG-Animations-Implementations-Responsive-Animation/dp/1491939702)

レスポンシブなアニメーションと性能を含め、SVGアニメーションを扱うガイド。原文の紹介ではHTTPリクエストの削減と各種ディスプレイでの鮮明な描画を挙げ、アニメーションによって構図、色、実装、最適化が複雑になる点を説明している。

### [Creating Web Animations: Bringing Your UIs to Life](https://www.amazon.com/Creating-Web-Animations-Bringing-Your/dp/1491957514/)

Web UIのアニメーションの作成方法と、それが解決するインターフェイス上の問題を扱う書籍。原文の紹介では、ブラウザーの高速化、Web標準への対応改善、端末の性能向上を背景に、実用的で滑らか、楽しく記憶に残るインターフェイスを目指している。

### [Transitions and Animations in CSS: Adding Motion with CSS](https://www.amazon.com/Transitions-Animations-CSS-Adding-Motion/dp/149192988X/)

CSSトランジションとアニメーションでページ要素を動かしたり外観を変えたりし、Webアプリケーションに動きと奥行きを加えてユーザー体験を改善するための簡潔なガイド。例として、現実的に跳ねるボール、徐々に開くドロップダウンメニュー、ホバー時に要素へ注意を向ける動きを扱う。

### [Designing Interface Animation: Meaningful Motion for User Experience](https://www.amazon.com/Designing-Interface-Animation-Meaningful-Experience/dp/1933820322/)

形と機能を組み合わせ、目的と表現のバランスを取りながら、動きをユーザー体験に組み込むWebインターフェイスアニメーションのガイド。フィードバック、現在位置の把握、注意の誘導、因果関係の提示、ブランドの個性の表現をアニメーションで改善する。Webデザイナー、UXの専門家、フロントエンド開発者向けに、モーションデザインの理論と実践を短期間で学ぶための内容。

### [Web Animation using JavaScript: Develop & Design](https://www.amazon.com/Web-Animation-using-JavaScript-Develop/dp/0134096665)

視覚的に効果があり、保守しやすいWebアニメーションを実装するための技術的基礎を扱う。原文では、点滅するバナー広告や流れるニュース表示とiOS・Androidのモーションデザインを対比し、サイトやアプリの操作感と直感的な分かりやすさをアニメーションで改善する方法を説明している。

### [CSS Animations and Transitions for the Modern Web](https://www.amazon.com/gp/product/0133980502/)

CSSとHTMLに慣れたデザイナーが、CSS3のスタイル定義を使って時間の経過に伴う動きをWebページに加えるためのガイド。使いやすさを改善し、ユーザーを楽しませたり驚かせたりする効果を扱い、CSSで実現できるものと複雑なスクリプトやプログラミングが必要なものを区別している。

### [Animation in HTML, CSS, and JavaScript](https://www.amazon.com/Animation-HTML-JavaScript-Kirupa-Chinnathambi/dp/1502548704)

HTML、CSS、JavaScriptで実用的なアニメーションを作るためのガイド。概念の解説、図、コード例を含む。CSSのアニメーションとトランジションから始め、DOM操作やCanvasへのピクセル描画によるJavaScriptアニメーションへ進む。

### [Foundation HTML5 Animation with JavaScript](https://www.amazon.com/Foundation-HTML5-Animation-JavaScript-Lamberta/dp/1430236655/)

HTML5 Canvasを使ったスクリプトによるアニメーションのガイド。必要な数学と、加速度、速度、イージング、ばね、衝突検出、運動量保存、3D、順運動学・逆運動学などの物理を扱う。HTML5で開発する人や、Flashから標準準拠のゲーム・アプリ・アニメーションへ移行する人が対象。固定原文の紹介では、モダンブラウザーと大多数のモバイル端末（iPhone、iPad、Android端末を含む）への対応を述べているが、現在の互換性を保証する記述ではない。
