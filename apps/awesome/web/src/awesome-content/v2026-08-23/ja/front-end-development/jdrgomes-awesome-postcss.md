# Awesome PostCSS

PostCSSの記事、ガイド、プラグイン、公式資料を主題別の索引から探せます。コミュニティのプロフィールも収録しています。PostCSSはCSSのパーサーとプラグインのための仕組みを提供し、CSSの解析、構文・スタイルの検査、アセット処理、最適化、フォールバックの作成などの変換を行えます。CSSを[抽象構文木（AST）](https://en.wikipedia.org/wiki/Abstract_syntax_tree)へ解析し、一連のプラグインを適用して、結果を文字列へ戻します。
