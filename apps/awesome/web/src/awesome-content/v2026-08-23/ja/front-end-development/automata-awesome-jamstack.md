# Awesome Jamstack

Jamstackは、クライアント側のJavaScript、再利用可能なAPI、事前に生成したマークアップを基盤とするウェブ開発の構成です。資料、コミュニティ、ホスティング、静的サイトジェネレーター、CMS、API、サーバーレスサービス、サイト事例、動画、記事、ポッドキャスト、書籍を収録しています。

関連リスト: [Awesome Static Generators](https://github.com/myles/awesome-static-generators)。

## プラットフォーム<a id="platforms"></a>

- [Netlify](https://netlify.com) - ウェブプロジェクトを自動化するプラットフォーム。
- [Vercel](https://vercel.com) - 設定を必要としないツールとワークフローを備えた、ウェブアプリ向けのサーバーレスプラットフォーム。
- [Layer0](https://layer0.co) - 大規模で動的なウェブサイト向けのJamstackプラットフォーム。統合CDN、EdgeJS、予測プリフェッチ、性能監視を備えています。
- [Azure Static Web Apps](https://azure.microsoft.com/services/app-service/static/) - CI/CDワークフロー、認証、CDNなどを統合した、フルスタックのサーバーレスホスティング。
- [Stormkit](https://stormkit.io) - Gitワークフローと連携し、JavaScriptアプリのビルド、デプロイ、スケーリングを行うインフラ。
- [Cloud 66](https://www.cloud66.com/) - 利用者自身のクラウドアカウントで静的ウェブサイトをビルド・デプロイします。

Static Web Appsの関連資料は[Awesome Static Web Apps](https://github.com/staticwebdev/awesome-azure-static-web-apps)を参照してください。

## ノーコードプラットフォーム<a id="no-code-platforms"></a>

- [Jamstack.new](https://jamstack.new) - Stackbitによる、1クリックでJamstackサイトを作成するサービス。
- [Storipress](https://storipress.com) - サイトビルダーとワークフロー管理を統合した、出版・ブログ用プラットフォーム。
- [Draftbox](https://draftbox.co) - コードを書かずに使える、WordPressやGhostのブログ向けフロントエンド。原リストでは高速で安全と紹介されています。
- [Plasmic](https://www.plasmic.app/) - ReactコンポーネントやJamstackサイトを視覚的に構築するデザインツール。
- [TeleportHQ](https://teleporthq.io/) - ヘッドレスの静的ウェブサイトを作成・公開する、共同作業向けフロントエンド設計・開発プラットフォーム。原リストではコードの無料エクスポート、無料プロジェクト3件、人数制限のない共同作業を挙げています。
- [Silex](https://www.silex.me) - 静的HTMLとCSSを出力する、視覚的なウェブサイトビルダー。任意のヘッドレスCMSと接続でき、セルフホストに対応します。原リストではロックインを避けられると紹介されています。

## 静的サイトジェネレーター<a id="static-site-generators"></a>

- [Gatsby](https://gatsbyjs.org) - React向け静的サイトジェネレーター。
- [Next.js](https://nextjs.org/) - 静的サイトとサーバーでレンダリングするアプリケーション向けの軽量フレームワーク。
- [Hugo](https://gohugo.io) - Goで書かれた静的サイトジェネレーター。
- [Jekyll](https://jekyllrb.com) - 個人、プロジェクト、組織のサイト向けに、ブログ機能を備えた静的サイトジェネレーター。
- [Hexo](https://hexo.io) - Node.jsを使用するブログフレームワーク。
- [Metalsmith](https://metalsmith.io) - プラグインに対応する静的サイトジェネレーター。
- [Phenomic](https://phenomic.io/) - モジュール構成のウェブサイトコンパイラー。
- [Gridsome](https://gridsome.org/) - ヘッドレスCMS、API、Markdownファイルを使ってCDN配信に対応したサイトを構築する、Vueベースの静的サイトジェネレーター。
- [Nuxt.js](https://nuxtjs.org/) - サーバーサイドレンダリング、静的サイト、従来型のシングルページアプリケーションに対応するVueベースのフレームワーク。
- [eleventy](https://www.11ty.io/) - 各種テンプレートファイルをHTMLに変換する静的サイトジェネレーター。
- [Nift](https://nift.dev) - C++で開発された、クロスプラットフォーム対応のオープンソースのウェブサイトジェネレーター。
- [Astro](https://astro.build) - 配信するJavaScriptを少量、またはほぼゼロに抑えてウェブサイトを構築します。
- [FactorJS](https://www.factorjs.org) - Viteを使用するフレームワーク。
- [Mandu](https://mandujs.com) - BunとReactを使用する、エージェントによる操作を前提としたフルスタックフレームワーク。静的エクスポート、SSR、ファイルシステムルーティング、実行時のアーキテクチャ検査、100件以上のMCPツールを備え、AIエディターがサイト全体を操作できます。
- [Bloggrify](https://bloggrify.com) - ブログ向けのNuxt Contentレイヤー。テーマ、SEO、RSS、アナリティクスが事前設定されています。

静的サイトジェネレーターの詳しい一覧は[Jamstackの静的サイトジェネレーター一覧](https://jamstack.org/generators/)を参照してください。

## API

### 認証<a id="authentication"></a>

- [Auth0](https://auth0.com/) - シングルサインオンとトークンベースの認証。
- [Netlify Identity](https://www.netlify.com/docs/identity/) - [GoTrue API](https://www.gotrueapi.org)を基盤とする認証機能一式。
- [Stytch](https://stytch.com) - パスワードレス認証とセッション管理のAPI。[Vercelのサンプル](https://github.com/vercel/next.js/tree/canary/examples/auth-with-stytch)で試せます。
- [Clerk](https://clerk.com) - React、Next.js、ウェブアプリ向けに設計されたユーザー管理UIとAPI。
- [Corbado](https://www.corbado.com) - ウェブサイトやアプリにパスキーを追加し、パスワードレス認証を実現します。原リストでは数行のコードで導入できると紹介されています。
- [Scalekit](https://scalekit.com) - Auth0、Firebase、Cognitoなど既存の認証システムを書き直さずに、企業向けSSO（SAML、OIDC）とSCIMプロビジョニングを追加します。

### コメント<a id="comments"></a>

- [Disqus](https://disqus.com) - ウェブサイトの議論と、ウェブ全体の会話に対応するコメントシステム。
- [Facebook Comments](https://developers.facebook.com/docs/plugins/comments) - Facebookアカウントでサイトのコンテンツにコメントできるプラグイン。
- [Utterances](https://utteranc.es/) - GitHubのIssueを使った軽量コメントウィジェット。ブログのコメントやWikiなどに利用できます。

### フォーム<a id="forms"></a>

- [Fetch Forms](https://www.fetchforms.io/) - API経由でアプリケーションからフォームを利用できるフォームビルダー。
- [Formcarry](https://formcarry.com) - ダッシュボード、スパム対策、添付ファイルのアップロード、Zapier連携を備えたHTMLフォーム用エンドポイント。
- [Formcake](https://formcake.com) - Zapier連携、依存関係不要の構成、API、数の制限のないフォームを備えた開発者向けフォームバックエンド。
- [Getform](https://getform.io) - 静的サイト用エンドポイント、Zapier連携、Webhookを備えた、デザイナーと開発者向けフォームバックエンド。
- [Netlify Forms](https://www.netlify.com/docs/form-handling/) - デプロイ時のビルドでHTMLファイルを解析して行う、組み込みのフォーム処理。
- [Arengu](https://www.arengu.com) - 登録・ログインフォームを構築し、ソーシャルログイン、2FA、パスワードレス認証フローを追加できます。利用者のAPIや認証プロバイダーで認証します。
- [Static Forms](https://www.staticforms.xyz/) - サーバー側のコードを使わずにHTMLフォームを組み込み、送信内容を登録済みメールアドレスへ送ります。
- [Form.taxi](https://form.taxi) - メール通知、ファイルアップロード、送信履歴を備えたHTMLフォーム用エンドポイント。原リストではデータ処理がGDPRに準拠すると紹介されています。

### 電子商取引<a id="eコマース"></a><a id="e-commerce"></a>

- [Astro Snipcart](https://github.com/lloydjatkinson/astro-snipcart) - AstroとSnipcartで電子商取引サイトを構築できます。
- [Flatmarket](https://github.com/christophercliff/flatmarket) - 静的ウェブサイト向けの、無料でオープンソースの電子商取引プラットフォーム。
- [GoCommerce](https://www.gocommerceapi.org) - Jamstackサイト向けのヘッドレス電子商取引サービス。
- [Snipcart](https://snipcart.com/) - 開発者向けショッピングカートプラットフォーム。
- [Moltin](https://moltin.com/) - 開発者向け電子商取引API。
- [Trolley](https://trolley.link) - Jamstack向けに設計されたショッピングカート。
- [Shopify](https://www.shopify.co.uk/plus/solutions/headless-commerce) - Shopifyのヘッドレス電子商取引ソリューション。
- [Commerce.js](https://commercejs.com/) - 開発者向けのAPI中心の電子商取引プラットフォーム。
- [CartQL](https://cartql.com/) - 任意のフレームワークや在庫システムと連携できる、Jamstack向けGraphQLショッピングカート・チェックアウトAPI。
- [Medusa](https://medusajs.com/) - オープンソースのヘッドレス電子商取引エンジン。
- [Saleor](https://saleor.io/) - [オープンソース](https://github.com/saleor/saleor)で、GraphQLを中心に据えた、特定技術に依存しない電子商取引エンジン。

### 検索<a id="search"></a>

- [Algolia](https://www.algolia.com/) - アプリケーションやサービスに検索機能を追加するプラットフォーム。
- [Lunr](https://lunrjs.com/) - フロントエンドの検索。
- [CloudSh](https://cloudsh.com/) - 原リストではJavaScriptの数行で実装できると紹介されている検索機能。

### データベース<a id="database"></a>

- [GraphQL](https://graphql.org) - API用のクエリ言語と、既存のデータに対してクエリを実行するランタイム。
- [Graphcool](https://graph.cool) - サーバーレスGraphQLバックエンドを開発する、オープンソースでセルフホスト可能なBackend as a Service。
- [FaunaDB](https://fauna.com) - クラウドやオンプレミスで利用でき、結合、インデックス、複数リージョンにまたがるACIDトランザクションを備えたリレーショナルNoSQLデータベース。
- [Fireproof](https://use-fireproof.com/) - 依存関係不要でオフラインにも対応するCRDTデータベース。ブラウザーで実行され、任意のクラウドと接続できます。
- [Jexia DataSet](https://jexia.com) - スキーマを使用する方式とスキーマレス方式に対応したREST APIクラウドデータストレージ。検証、リレーション、集計関数を備えています。
- [Tigris](https://www.tigrisdata.com) - データベース、リアルタイム検索用の自動インデックス、キャッシュ、リアルタイムのpub/subを備えた、オープンソースのデータプラットフォーム。
- [Nhost](https://nhost.io) - Postgresデータベース、即時利用できるHasura GraphQL API、認証、ストレージ、サーバーレス関数を備えた、オープンソースのBackend as a Service。

### ファイル管理<a id="file-management"></a>

- [Jexia FileSet](https://jexia.com) - インデックスなどの機能を備えた、アプリケーション向けREST APIファイルマネージャー。

### 自動化<a id="automation"></a>

- [Zapier](https://zapier.com/) - 1000件以上のアプリを接続し、アクションを実行します。
- [DataFire](https://github.com/DataFire/DataFire) - APIの構築と統合を行うオープンソースフレームワーク。

## サーバーレス<a id="serverless"></a>

- [Netlify Functions](https://www.netlify.com/docs/functions/) - AWSアカウントを用意せずにLambda関数をデプロイでき、関数をNetlify内で管理できます。
- [Amazon Lambda](https://aws.amazon.com/lambda/) - サーバーの用意や管理をせずにコードを実行できます。
- Microsoft Azure
  - [Azure Functions](https://docs.microsoft.com/en-us/azure/azure-functions/) - インフラを明示的に用意・管理せずに、必要に応じてコードを実行するサーバーレス計算サービス。
  - [Azure Logic Apps](https://docs.microsoft.com/en-us/azure/logic-apps/) - クラウドサービスとオンプレミスのシステムをまたぐアプリ・データの連携について、自動化され拡張可能なワークフローを構築します。
- Google Cloud
  - [App Engine](https://cloud.google.com/appengine/) - インフラを抽象化し、コードに集中できるサーバーレスアプリケーション基盤。
  - [Cloud Functions](https://cloud.google.com/functions/) - クラウドサービスを構築・接続するためのサーバーレス環境。
  - [Cloud Datastore](https://cloud.google.com/datastore/) - 自動シャーディングとレプリケーションに対応する、拡張性の高いNoSQLデータベース。
  - [Cloud Storage](https://cloud.google.com/storage/) - 高いQPSを必要とする用途向けに、複数の地域で冗長化されたオブジェクトストレージ。
  - [Cloud Pub/Sub](https://cloud.google.com/pubsub/) - さまざまなメッセージサイズと配信速度に対応する、複数の地域で冗長化されたリアルタイムメッセージング。
  - [Apigee](https://apigee.com/) - マルチクラウド環境向けの企業用API管理。
  - [Endpoints](https://cloud.google.com/endpoints/) - Google Cloud上で構築されたAPI管理アプリケーション。
  - [Cloud Dataflow](https://cloud.google.com/dataflow/) - ストリーム処理とバッチ処理に対応するサーバーレスのデータ処理サービス。
  - [BigQuery](https://cloud.google.com/bigquery/) - 企業向けのクラウドデータウェアハウスを構築するサーバーレスサービス。
  - [Cloud ML Engine](https://cloud.google.com/ml-engine/) - Google独自のハードウェア（Tensor Processing Units）を使用し、自動スケーリングに対応するサーバーレス機械学習サービス。
- [Serverless](https://serverless.com/) - サーバーレス構成のデプロイと運用を行うツールキット。
- [Cloudinary](https://cloudinary.com/) - 画像・動画向けサーバーレスメディア管理プラットフォーム。広く使われる言語のSDKとJamstack向けメディアウィジェットを提供し、メディア、CDN、ストレージ、変換を管理できます。
- [imgix](https://www.imgix.com/) - サーバーレスの画像配信・管理サービス。S3、GCS、ウェブフォルダーなどの画像保存先と接続し、URLパラメーターを使って画像を変換、最適化、配信します。
- [TwicPics](https://twicpics.com/) - サーバーレスの画像・動画最適化・変換サービス。任意の技術構成に組み込み、フロントエンド開発者が制御してメディアをリアルタイムで最適化できます。

サーバーレスの詳しい一覧は[Awesome Serverless](https://github.com/pmuens/awesome-serverless)を参照してください。
