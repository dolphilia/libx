# Awesome Material Design

Googleの[Material Design](http://www.google.com/design/spec)に基づくライブラリ、アイコン、色を扱うツール、コンポーネント、テーマを、プラットフォームや資料の種類ごとに探せます。説明、数量、プラットフォーム名、URLは記録された原文のスナップショットに基づきます。

## アイコン・フォント・色

- [material-design-icons](https://github.com/google/material-design-icons) — GoogleによるMaterial Designのアイコン。

- [material-design-iconic-font](https://github.com/zavoloklom/material-design-iconic-font) — Material DesignのアイコンフォントとCSSツールキット。

- [material-design-fonticons](https://github.com/designjockey/material-design-fonticons) — GoogleのMaterial Designアイコンセットをフォントへ変換したもの。

- [material-colors](https://github.com/shuhei/material-colors) — GoogleのMaterial Designの色をコードで利用できるようにしたもの。

- [material-color](https://github.com/mrmlnc/material-color) — プロジェクトで使える、GoogleのMaterial Designに基づくカラーパレット。

- [LESS-Material-design-colors](https://github.com/tisign/LESS-Material-design-colors) — GoogleのMaterial Designの全色を収録した.lessファイル。

- [sass-material-colors](https://github.com/minusfive/sass-material-colors) — Sass/ScssプロジェクトでGoogleのMaterial Designの色を手軽に使うためのもの。

- [Google-Material-Design-Font-Icon](https://github.com/Seb-L/Google-Material-Design-Font-Icon) — GoogleのMaterial Designアイコンセットに基づくアイコンフォント。

- [Material Design Icons](https://materialdesignicons.com/) — コミュニティが制作したMaterial Designのアイコン集。

- [Android Asset Studio](https://romannurik.github.io/AndroidAssetStudio/) — Androidアプリのres/ディレクトリへ配置するグラフィックなどのアセットを生成するウェブツール集。

## アニメーション

### JavaScript

- [Waves](https://github.com/fians/Waves) — GoogleのMaterial Designに着想を得たクリック時のエフェクト。

- [material-design-hamburger](https://github.com/swirlycheetah/material-design-hamburger) — AndroidのMaterial DesignのハンバーガーメニューのアニメーションをCSSで実装したもの。

- [Material-Preloader](https://github.com/aarondo/Material-Preloader) — inboxで見られるMaterial Designのプリローダーを再現するjQueryプラグイン。

- [Google-material-design-ripple-effect](https://github.com/ninox92/Google-material-design-ripple-effect) — 波紋とフォーカスのエフェクトを再現するjQueryプラグイン。

## コンポーネント

- [SVG-Morpheus](https://github.com/alexk111/SVG-Morpheus) — SVGアイコンを別のアイコンへ変形させるJavaScriptライブラリ。Material DesignのDelightful Detailsのトランジションを実装。

- [Material-Design-ColorPicker](https://github.com/Fraina/Material-Design-ColorPicker) — Material Designのカラーピッカー。

- [material-design-color-palette](https://github.com/zavoloklom/material-design-color-palette) — Material Designのカラーパレットを扱うLESS/CSSツールキット。

- [md-timepicker](https://github.com/dotlouis/md-timepicker) — Material Designの時刻選択用Polymer要素。

- [md-date-time](https://github.com/SimeonC/md-date-time) — GoogleのMaterial Design仕様に基づく日時選択コンポーネント。

- [ng-material-floating-button](https://github.com/nobitagit/ng-material-floating-button) — アクションボタンを備えたMaterial Designのフローティングメニュー。AngularJSディレクティブとして実装。

- [DevExtreme Reactive](https://devexpress.github.io/devextreme-reactive/react) — Material Design向けのプラグイン方式のReactコンポーネント。原文では高性能と説明されている。

## CSS

- [Surface](https://github.com/mildrenben/surface) — Material Designに基づく、CSSだけで構成された軽量フレームワーク。

- [material-ui](https://github.com/callemall/material-ui) — GoogleのMaterial Designを実装するCSSフレームワークとReactコンポーネント集。

- [bootstrap-material-design](https://github.com/FezVrasta/bootstrap-material-design) — Bootstrap 3向けのMaterial Designテーマ。

- [materialize](https://github.com/Dogfalo/materialize) — Material Designに基づくCSSフレームワーク。

- [materialBootstrap](https://github.com/throrin19/materialBootstrap) — GoogleのMaterial Designに基づくTwitter Bootstrapテーマ。

- [material-playground](https://github.com/ebidel/material-playground) — PolymerでMaterial Designを試すための環境。

- [material-framework](https://github.com/nt1m/material-framework) — 原文で使いやすいと説明される、Material Designに基づくフレームワーク。

- [mui](https://github.com/muicss/mui) — Material Designのガイドラインに沿った軽量CSSフレームワーク。

- [material-foundation](https://github.com/eucalyptuss/material-foundation) — Foundation for SitesのMaterial Design版。

- [Tronic247 Material](https://www.tronic247.com/material/) — jQueryとCSSに基づくMaterial Designフレームワーク。

## JavaScript

- [Angular](https://github.com/angular/material2) — Angular向けのMaterial Design。

- [DevExtreme](https://js.devexpress.com) — 原文では、レスポンシブ対応で機能の揃ったUIコンポーネントを65以上収録し、Material Designに準拠するテーマをカスタマイズできると説明されている。Angular・React・Vue・jQuery向け。

- [react-material](https://github.com/BerkeleyTrue/react-material) — React.jsとReact Styleで実装されたMaterial Designコンポーネント。
