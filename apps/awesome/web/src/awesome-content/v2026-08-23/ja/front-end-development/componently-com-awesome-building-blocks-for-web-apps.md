# Awesome Building Blocks for Web Apps

このリストは、すべての機能を自作する代わりに、Webアプリケーションへ組み込める独立した機能やサービスを集めています。UI要素、認証、予約、通知、通信、監視、コンテンツ管理、同意管理、メディア、フォーム、マーケティング、検索、機能フラグ、関連リストを紹介します。

## UI要素 <a id="ui-elements"></a>

- [Tailwind UI](https://tailwindui.com/) - Tailwind CSSの作成者によるUIコンポーネント。
- [Webix](https://webix.com/) - さまざまな形式でデータを表示するJavaScript UIライブラリとフレームワーク。
- [Highcharts](https://www.highcharts.com/) - ウェブ向けインタラクティブグラフ。
- [Webatoms](https://www.webatoms.in) - Xamarin.Forms向けJavaScriptブリッジ。
- [Creative Tim](https://www.creative-tim.com/) - React、Angular、Vue、Laravel、HTML5向けテーマ。
- [Syncfusion](https://www.syncfusion.com/) - データ可視化コンポーネントとPDFビューアー。
- [CoreUI](https://coreui.io/pro/vue) - Vue向けの管理画面テンプレート。
- [UIfort](https://uifort.com/) - 原文では、主要なフロントエンドフレームワークすべてに対応すると説明されているUIデザインシステム。
- [Semantic UI](https://semantic-ui.com/) - React、Meteor、Ember、Angular向けオープンソースUIコンポーネントライブラリ。
- [Design Revision's Shards Pro](https://designrevision.com/downloads/shards-pro) - ウェブまたはモバイルアプリ向けデザインブロック。
- [Themesberg](https://themesberg.com) - Bootstrapテンプレート、テーマ、UIキット。
- [Treact](https://treact.owaiskhan.me/) - Tailwind CSS上に構築されたランディングページ向けReactテンプレート。
- [Creative Designs Guru](https://creativedesignsguru.com) - Tailwind CSSで構築されたReact、Next.js、Eleventy向けテーマ。

## 離脱時のポップアップ <a id="離脱意図ポップアップ"></a> <a id="exit-intent-popup"></a>
- [Wisepops](https://wisepops.com/) - モバイル・デスクトップ訪問者向けコンテキストポップアップ、バナー、バー。
- [Listagram](https://www.listagram.com) - 同意を得てメールアドレスを収集するためのインタラクティブなフォーム。
- [Poptin](https://www.poptin.com) - ウェブサイトの任意の場所へ統合できるポップアップとフォーム。
- [Embedery](https://www.embedery.com) - 訪問者を惹きつけるポップアップ。

## 認証 <a id="auth"></a>
- [Auth0](https://auth0.com/) - Angular、React、VueJSをネイティブサポートする認証管理。
- [Clerk](https://clerk.com) – React、Next.jsなどのWebアプリケーション向けユーザー管理UIとAPI。
- [Firebase](https://firebase.google.com) - 認証管理を含むGoogleのPaaS。
- [Okta](https://www.okta.com/) - Angular、React、VueJSをサポートする認証・認可ソリューション。
- [Onelogin](https://www.onelogin.com/) - 企業内部アプリケーションに焦点を当てた認証。
- [Microsoft Azure Active Directory](https://azure.microsoft.com/en-us/services/active-directory/#security) - Microsoftアカウントに基づくAzureの認証管理。
- [AWS Cognito](https://aws.amazon.com/cognito/) - AWS認証管理。フロントエンド統合は[AWS Amplify](https://aws.amazon.com/de/amplify/)の一部です。

## 予約 <a id="booking"></a>
- [Calendly](https://calendly.com/) - スタンドアロン予約ソリューション。
- [Zoho Bookings](https://www.zoho.com/bookings/) - Zoho Suiteへ統合されたオンラインスケジューラー。
- [Acuity Scheduling](https://acuityscheduling.com/) - 広範なAPIを備える予約のスケジュール管理。
- [10to8](https://10to8.com/) - 原文では、無料プランに多くの機能があると説明されている予約ツール。
- [SuperSaaS](https://www.supersaas.com/) - グループの予定調整を重視した予約のスケジュール管理。
- [SimplyBook.Me](https://simplybook.me/) - 独自の予約ディレクトリを持つ予約ツール。
- [OnceHub](https://www.oncehub.com/) - ScheduleOnceによるスケジューリングとInviteOnceによる会議管理。
- [YouCanBookMe](https://youcanbook.me/) - チームのためのオンラインスケジューリング。
- [OnSched](https://www.onsched.com/) - マーケットプレイス・アプリケーション向けスケジューリングAPI。
- [AppointmentPlus](https://www.appointmentplus.com/) - クーポン機能を備える予約のスケジュール管理。
- [Booxi](https://www.booxi.com/) - 予約・オンラインディレクトリコンポーネント。
- [Cogsworth Scheduler](https://get.cogsworth.com/) - APIを備えるビジネス向けオンラインスケジューラー。

## 同意管理 <a id="consent-management"></a>
- [Cookiefirst](https://cookiefirst.com/) - Cookie同意マネージャー。
- [usercentrics](https://usercentrics.com/) - 既存ページの一部として実装できるコンプライアンスマネージャー。
- [Sourcepoint](https://www.sourcepoint.com/) - 広告ブロックで非表示になった広告の復元も含むスイートの一部としてのコンプライアンス管理。
- [PiwikPro](https://piwik.pro/gdpr-consent-manager/) - 分析ツールの一部としてのコンプライアンス管理。
- [Consent Management Provider](https://www.consentmanager.de/) - Cookieの同意を管理するドイツのツール。
- [UniConsent](https://www.uniconsent.com/) - 原文では、GDPR、CCPA、COPPAへの対応を支援すると説明されている同意管理プラットフォーム。
- [TrustArc](https://trustarc.com/) - 原文では、CCPA、GDPR、LGPDに加えて、世界の900を超える規制を対象とすると説明されているプライバシー管理。
- [Cookiebot](https://www.cookiebot.com/) - Cookie追跡マネージャー。
- [iubenda](https://www.iubenda.com/) - 同意管理と利用規約ジェネレーター。
- [Civic Cookie Control](https://www.civicuk.com/cookie-control/) - 原文では小規模と説明されている、CookieとGDPRの要件への対応を支援する製品。
- [CCM19](https://www.ccm19.de/) - ドイツのCookie同意管理ツール。
- [CookieInformation](https://cookieinformation.com/) - ダッシュボードによるコンプライアンス報告を重視。
- [CookiePro](https://www.cookiepro.com/) - プライバシー管理ソリューションの一部としてのCookie管理。
- [React Cookie Consent](https://github.com/Mastermindzh/react-cookie-consent) - Reactアプリケーション向けの小型でカスタマイズ可能なCookie同意バー。
- [React Cookie Banner](https://github.com/buildo/react-cookie-banner) - スクロールで自動的に閉じられるReact向けCookieバナー。
