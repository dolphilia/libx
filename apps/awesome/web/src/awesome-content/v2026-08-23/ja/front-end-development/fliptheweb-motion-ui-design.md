# Awesome Motion UI Design

モーションデザインでは、アニメーションや画面遷移を使ってUIの変化を自然に見せます。ユーザーインターフェースのモーションデザインについて、参考作品、記事、プロトタイプやアニメーションの制作ソフト、CSS・JavaScript・SVGライブラリを探せます。アニメーションの性能、講演・動画、ニュースレター・ポッドキャスト、各プラットフォームのガイドライン、書籍も収録しています。

## <a id="software"></a>ソフトウェア
UIアニメーションの制作ソフトを、技術と出力形式（動画、プロトタイプ、コードなど）別に整理しています。チュートリアルやプラグインへのリンクも掲載しています。

### <a id="video-gif-presentation"></a>動画、GIF、プレゼンテーション
* [Adobe After Effects](https://www.adobe.com/products/aftereffects.htm) – 映画、テレビ、動画、Web向けのモーショングラフィックスと視覚効果を設計・出力する、アニメーションと合成用アプリ：
  * [Using After Effects for UI Animation Prototypes](https://www.youtube.com/watch?v=w67z1YhPFKM&feature=youtu.be) (動画)。
  * [UIアニメーションのチュートリアル](https://uxinmotion.net/)。
  * [How to Use After Effects for Web Animation Prototypes](http://webdesign.tutsplus.com/tutorials/how-to-use-after-effects-for-web-animation-prototypes--cms-21451) (動画)。
  * [MtMograph summits](http://mtmograph.com/summits/) (動画)。
  * [After Effects CC Essential Training on Lynda](http://www.lynda.com/After-Effects-tutorials/After-Effects-CC-Essential-Training/122431-2.html) (動画)。
  * [BodyMovin](https://github.com/bodymovin/bodymovin) – AEからSVG/canvasへの変換ツール。
  * [Squall](http://www.marcuseckert.com/squall/) – AEからiOSへの変換ツール。
* [Apple Motion](https://www.apple.com/sg/final-cut-pro/motion/) – モーショングラフィックスの作成・編集、動画・映画のタイトル作成、視覚効果用の2D/3D合成を行うmacOSアプリ。
* [Adobe Photoshop](http://www.adobe.com/sea/products/photoshop.html) – GIF形式のUIアニメーションも制作できるラスター画像編集ツール。
* [Adobe Flash](http://www.adobe.com/products/flash.html) – ベクターグラフィックス、アニメーション、ゲームなどを作成するソフトウェア。
* [Apple Keynote](https://www.apple.com/ru/mac/keynote/) – プレゼンテーションや、完成形に近いアニメーション・プロトタイプを制作するmacOSアプリ：
	* [How To Prototype UI Animations In Keynote](http://www.smashingmagazine.com/2015/08/animating-in-keynote/)。

### <a id="visual-programming"></a>ビジュアルプログラミング

  * [The 4 Minute Guide to Quartz Composer](https://vimeo.com/88468610) (動画)。
  * [Introducing Origami for QC](https://medium.com/the-year-of-the-looking-glass/introducing-origami-for-quartz-composer-f1173d0bd181)。
  * [Origami Studio](https://origami.design/) – FacebookによるUI制作ツール。
* [Principle For Mac](http://principleformac.com/) – アニメーションを備えたインタラクティブなUIを制作するmacOSアプリ。
* [Floid](https://floid.io/) – Web・iOS・Androidなど、さまざまなプラットフォームやデバイス向けのインタラクションを設計するmacOSツール。

### <a id="html-css-and-javascript"></a>HTML、CSS、JavaScript
* [Framer](https://www.framer.com/) – アニメーションおよびインタラクティブUIのプロトタイピングに使うツール。
  * [Your first prototype with framer](https://medium.com/@kennycheny/creating-your-first-prototype-with-framer-c39221da7668)。
* [Tumult Hype](http://tumult.com/hype/) – HTML/CSSサイト、バナー、プレゼンテーションなどを制作するmacOSアプリ。
* [Adobe Animate](https://www.adobe.com/products/animate.html) – HTML/CSSサイト、バナー、プレゼンテーションなどを作成するアプリ：
  * [Prototyping UI Animation](https://medium.com/the-thinkmill/prototyping-ui-animation-2fe08e3a7932)。
* [Google web designer](https://www.google.com/webdesigner/) – HTMLベースのデザインとモーショングラフィックス。
* [Animatron](http://animatron.com/) – アニメーション、バナー、インフォグラフィックを制作するWebアプリ。
* [SpiritJS](https://spiritapp.io/) – Web向けアニメーションツール（原リストでは開発中と記載）。
* 任意のHTML/CSSエディターと、以下の[ライブラリ](#libraries)を組み合わせて利用。

アニメーションの構想には、紙とペンも使えます。

* [Mantra](http://jeremyckahn.github.io/mantra/) – キーフレームアニメーションを作成するツール。

### JavaScript
* [GreenSock](http://greensock.com/) – Web向けのアニメーションツール。
* [Velocity.js](http://velocityjs.org/) – JavaScriptによる高速アニメーション。
* [Impulse](http://impulse.luster.io/) – モバイルウェブ向けの高パフォーマンスインタラクション。
* [AniJS](http://anijs.github.io/) – データ属性で宣言するアニメーション。
* [Snabbt.js](http://daniel-lundin.github.io/snabbt.js/) – 最小構成のJavaScriptアニメーションライブラリ。
* [Processing.js](http://processingjs.org/) – Processingの視覚プログラミング言語向けJavaScriptライブラリ。
* [Dynamics.js](http://dynamicsjs.com/) – 物理的な動きに基づくアニメーションを制作するJavaScriptライブラリ。
* [Mo.js](https://github.com/mojs/mojs) – ウェブ向けのモーショングラフィックスツールセット。
* [AnimateTransition](http://rapid-application-development-js.github.io/AnimateTransition/) – ブロックとポップアップのトランジション用ライブラリ。
* [Animate Plus](https://github.com/bendc/animateplus) – 軽量なCSS・SVGアニメーションライブラリ（gzip圧縮で3KB）。原リストでは当時のブラウザーを対象とし、性能が高く、特にモバイルに適すると説明。
* [Gravitas.js](https://github.com/iamralpht/gravitas.js) – JavaScriptによる物理シミュレーション。
* [Popmotion](https://popmotion.io/) – ユーザーインタラクションを制作するJavaScriptモーションエンジン。
* [anime.js](http://animejs.com/) - 軽量なJavaScriptアニメーションライブラリ
* [useAnimations](https://useanimations.com/) - マイクロアニメーションアイコンライブラリ

### SVG
* [SnapSVG](http://snapsvg.io/) — jQueryでDOMを操作するようにSVGを扱えることを目指したAPIを備えるJavaScriptライブラリ。
	* [How to Manipulate and Animate SVG With Snap.svg](http://webdesign.tutsplus.com/articles/how-to-manipulate-and-animate-svg-with-snapsvg--cms-21323)
* [BonsaiJS](https://bonsaijs.org/) – 扱いやすいグラフィックスAPIとSVGレンダラーを備える軽量ライブラリ。
* [Vivus.js](http://maxwellito.github.io/vivus/) – 描画の過程を見せるようにSVGをアニメーション化。
* [Walkway.js](http://connoratherton.com/walkway) – 線、パス、ポリライン要素で構成されたSVG画像のアニメーション。
* [Transformicons](http://www.transformicons.com/) – SVGとCSSによるアニメーション付きアイコン、シンボル、ボタン。
