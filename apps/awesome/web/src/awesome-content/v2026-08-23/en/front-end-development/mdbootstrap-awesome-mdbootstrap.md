# Awesome MDBootstrap

[MDBootstrap](https://github.com/mdbootstrap/mdb-ui-kit) provides responsive page templates, layouts, components, and widgets for building web pages. Explore its UI kits, design generators, data grids, CLI and hosting tools, TW Elements integrations, and learning resources; see the [official website](https://mdbootstrap.com) as well.

## Resources

Official projects and resources of MDBootstrap. The fixed source groups the UI kits into Free and Pro editions.

### Free

- [MDB Standard Free](https://mdbootstrap.com/docs/standard/) - Free to download, open-source Bootstrap 5 UI kit.
- [MDB Angular Free](https://mdbootstrap.com/docs/angular/) - Free UI kit for Bootstrap 5 and Angular 11 with Material Design.
- [MDB React Free](https://mdbootstrap.com/docs/react/) - Free UI kit for Bootstrap 5 and React 17 with Material Design.
- [MDB Vue Free](https://mdbootstrap.com/docs/vue/) - Free UI kit for Bootstrap 5 and Vue 3 with Material Design.

### Pro

- [MDB Standard Pro](https://mdbootstrap.com/docs/standard/pro/) - Premium UI kit for Bootstrap 5. The source lists lifetime usage of 5,000+ premium components, thousands of templates, plugins, and design blocks.
- [MDB Angular Pro](https://mdbootstrap.com/docs/angular/pro/) - Material Design for Bootstrap 5 with Angular.
- [MDB React Pro](https://mdbootstrap.com/docs/react/pro/) - Material Design for Bootstrap 5 with React.
- [MDB Vue Pro](https://mdbootstrap.com/docs/vue/pro/) - Material Design for Bootstrap 5 with Vue.

## Data Grid

Table components for extending a project’s functionality.

- [GetDataDen](https://getdataden.com/) - Customizable data grid.
- [Advanced data structure](https://getdataden.com/docs/grid/features/data-loader/#client-side-data-example) - Customize each column’s sort, width, resize, and field settings. Match values from each row to a column whose `field` equals the given key value.
- [Draggable columns](https://getdataden.com/docs/grid/features/drag-and-drop/#basic-section) - Rearrange data-grid columns by clicking, dragging, and dropping.
- [Pagination](https://getdataden.com/docs/grid/features/pagination/#basic-section) - Example of pagination controls for navigating large datasets.
- [Column search](https://getdataden.com/docs/grid/features/filtering/header-filters/#basic-section) - Find information in DataDen grids with column search.
- [Cell formatting](https://getdataden.com/docs/grid/layout/custom-css/#cell-formatting-section) - Adjust cell appearance with colors, fonts, and styles, including highlighting key insights.
- [Compact version](https://getdataden.com/docs/grid/layout/custom-css/) - Customize data-grid colors, fonts, and layouts with CSS to match your brand or preferences.
