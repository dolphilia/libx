# Awesome PostCSS

Browse PostCSS articles, guides, plugins, and official resources through topic indexes. The list also includes community profiles. PostCSS provides a CSS parser and a framework for plugins that analyse, lint, handle assets, optimise, create fallbacks, and otherwise transform CSS. It parses CSS into an [abstract syntax tree (AST)](https://en.wikipedia.org/wiki/Abstract_syntax_tree), applies a sequence of plugins, and converts the result back into a string.
