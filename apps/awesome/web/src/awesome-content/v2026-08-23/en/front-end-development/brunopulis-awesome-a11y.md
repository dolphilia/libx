# Awesome Accessibility

Browse accessibility resources by topic, including tools, articles and videos, books, courses, jobs, and W3C specifications. The links below open the topic files in the original repository at this snapshot’s recorded commit.

## List scope

The original list excludes accessibility overlay tools and other solutions based on overlays, following the [Overlay Fact Sheet](https://overlayfactsheet.com/en/).
