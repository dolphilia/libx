# Awesome Emails

Build HTML and React emails with frameworks, responsive templates, and HTML/CSS support references. This list also covers delivery services, self-hosted mail servers, analytics, testing tools, design examples, and learning resources.

## Frameworks

### React

- [React Email](https://react.email/) - Unstyled components for creating emails with React and TypeScript.
- [Mailing](https://www.mailing.run/) - Build emails in React, send from anywhere.
- [JSX-email](https://jsx.email/) - JSX Mail is an email framework that uses React to create email templates.

### Misc

- [MJML](https://mjml.io) - MJML is a markup language designed to reduce the pain of coding a responsive email.
- [Foundation for Emails](https://github.com/zurb/foundation-emails) - Create responsive HTML emails; the original description claims compatibility with any device and client, including Outlook.
- [Email Framework](http://emailframe.work/) - The HTML email framework developed to help you build responsive HTML email.
- [HEML](https://heml.io) - HEML is an open source markup language for building responsive email.
- [Acorn](https://docs.thememountain.com/acorn/) - A responsive email framework based on a golden ratio typography grid.
- [Pine](https://docs.thememountain.com/pine/) - A 12 column grid, responsive email framework.
- [Maizzle](https://maizzle.com) - Quickly build HTML emails with Tailwind CSS.

## Tools

- [Can I Email](https://www.caniemail.com/) - HTML and CSS support tables for email clients.
- [Topol](https://topol.io/) - Create responsive HTML emails; the original description advertises creation in a minute.
- [MJML Desktop App](https://mjmlio.github.io/mjml-app/) - MJML official desktop app.
- [Rollover](http://freshinbox.com/tools/rollover/) - Generates code for a Rollover Image that displays an alternative image when the email recipient hovers the cursor over the image.
- [Bulletproof Email Buttons](http://buttons.cm/) - Design buttons with progressive enhancement using VML and CSS.
- [Bulletproof Background Images](http://backgrounds.cm/) - Create background images for HTML emails using VML and CSS.
- [Stripo.email](https://stripo.email/) - Online drag-and-drop and HTML email builder for responsive templates without requiring HTML skills.
- [MySigMail Card](https://mysigmail.com/card/) - Free drag-and-drop email template builder.
- [TestSubject](http://zurb.com/playground/testsubject) - Test how email subject lines appear on popular mobile devices.
- [MailSpice analytics](https://mailspice.com) - Email campaign analytics add-on described in the original list as working with all email service providers (ESPs).
- [Alter.email](https://alter.email/) - A free tool to help you inline CSS, remove unused CSS, clean up your text, add extra attributes to tags, add URL tracking parameters, minify, and even prettify HTML email.
- [Sensitive Subjects](https://sensitivesubjects.com/) - Described in the original list as helping avoid embarrassing subject lines.
- [Detergent](https://detergent.io) - A tool to prepare the text for pasting into HTML: removes invisible Unicode characters (like [ETX](https://www.fileformat.info/info/unicode/char/0003/index.htm) which can come from PSD files), encodes special characters (like turning £ into `&pound;`) and improves typography.
- [EmailComb](http://emailcomb.com/) - Email-friendly unused CSS removal tool which does not parse and thus accepts mixed sources, including your ESP templating tags. Extras: CSS uglification and HTML/CSS minification (powered by HTML Crush).
- [HTML Crush](https://htmlcrush.com/) - Email-friendly HTML minifier that limits lines to 500 characters (described in the original list as a best practice), respects Outlook conditional tags, and accepts mixed sources including ESP templating tags. It can also remove only indentation, leaving line breaks unchanged.
- [Tabifier](https://tools.arantius.com/tabifier) - Indentation formatter for HTML files, as a counterpart to HTML Crush. Accepts mixed input sources, including ESP templating tags.
- [Email Link Builder](https://email-link-builder.samcarlton.com/) - Create mailto links that open email drafts with prefilled recipients, subject, body, and other fields.
- [email-verifier](https://github.com/AfterShip/email-verifier) - A tool for email verification without sending any emails.
- [DevMail](https://devmail.email/) - An email sandbox for software developers. Capture emails from your dev, staging, QA, or CI environment.
- [Disposable Email Check API](https://open.kickbox.com/) - A free API for checking if an email address is disposable. No sign up required.
