# Awesome jQuery

[jQuery](http://jquery.com/) is a [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) library for HTML document traversal and manipulation, event handling, animation, and Ajax through an API that works across browsers. This list covers learning resources, UI plugins, mobile tools, testing libraries, and server integrations, alongside community links, alternative API implementations, and related lists.

## Alternatives

Alternative implementations of the jQuery API.

* [cash](https://github.com/kenwheeler/cash) - jQuery alternative for modern browsers. The recorded source describes it as including all API except Ajax.
* [Zepto](https://zeptojs.com/) - jQuery alternative with Ajax, effects, and additional utilities.
* [jBone](http://jbone.js.org/) - jQuery implementation to use with Backbone. Supports only subset of API which is required for Backbone to work. Can be a byte-saver if you don't intend to use jQuery directly, but have Backbone in your project.
