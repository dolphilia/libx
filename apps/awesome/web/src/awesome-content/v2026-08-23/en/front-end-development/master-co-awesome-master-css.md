# Awesome Master CSS

[Master CSS](https://css.master.co) is a virtual CSS language with enhanced syntax for building UIs and design systems using only HTML. It generates CSS rules from class names; the source describes building UIs with less code and using its JIT in production. Find documentation, IDE extensions, tools, plugins, community resources, learning materials, examples, and articles.
