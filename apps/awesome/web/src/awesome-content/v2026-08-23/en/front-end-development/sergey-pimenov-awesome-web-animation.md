# Awesome Web Animation

Web animation brings motion to browser interfaces and graphics. This list covers libraries for SVG, CSS, Canvas, scrolling, text, and React; GUI tools for creating and exporting animations for the browser; and books and videos about browser animation.

## SVG

- [Snap.svg](https://github.com/adobe-webplatform/Snap.svg) - A JavaScript library for SVG graphics.
- [Svg.js](https://github.com/svgdotjs/svg.js) - A lightweight library for manipulating and animating SVG.
- [Vivus](https://github.com/maxwellito/vivus) - A library for drawing animations in SVG.
- [Walkway](https://github.com/ConnorAtherton/walkway) - A library for animating SVG elements.
- [Raphael](https://github.com/DmitryBaranovskiy/raphael) - A JavaScript vector graphics library.
- [Bonsai](https://github.com/uxebu/bonsai) - A graphics library and renderer.

## Common

- [GSAP](https://github.com/greensock/GSAP) - A JavaScript animation library.
- [TweenJS](https://github.com/CreateJS/TweenJS) - A JavaScript tweening and animation library in the CreateJS suite.
- [Anime.js](https://github.com/juliangarnier/anime) - A JavaScript animation engine.
- [Mojs](https://github.com/mojs/mojs) - A motion graphics toolkit for the web.
- [Animo.js](https://github.com/ThrivingKings/animo.js) - A small tool for managing CSS animations.
- [Move.js](https://github.com/visionmedia/move.js) - A JavaScript animation framework backed by CSS3.
- [Velocity](https://github.com/julianshapiro/velocity) - A library for accelerated JavaScript animation.
- [Animateplus](https://github.com/bendc/animateplus) - An animation module for the web.
- [Animatic](https://github.com/lvivski/animatic) - A CSS animation engine.
- [Just Animate](https://github.com/just-animate/just-animate) - A library for simplifying animation.
- [Haiku Core](https://github.com/HaikuTeam/core) - An interactive UI animation engine for the web and the core renderer for Haiku Animator.
- [Between.js](https://github.com/sasha240100/between.js) - A lightweight JavaScript (ES6) tweening engine.
- [Progressbar.js](https://github.com/kimmobrunfeldt/progressbar.js) - A library for responsive progress bars.
- [Bezier easing](https://github.com/gre/bezier-easing) - A cubic Bézier implementation for JavaScript animation easing.
- [Glsl easings](https://github.com/glslify/glsl-easings) - Easing functions in GLSL.
- [ES6-tween](https://github.com/tweenjs/es6-tween) - An ES6 version of tween.js.
- [Weeee.js](https://github.com/sfi0zy/weeee) - A small JavaScript tweening engine.

## CSS

- [Animate.css](https://github.com/daneden/animate.css) - A cross-browser CSS animation library.
- [Motion-ui](https://github.com/foundation/motion-ui) - A Sass library for creating CSS transitions and animations.
- [Magic](https://github.com/miniMAC/magic) - CSS3 animations with special effects.
- [Css-loaders](https://github.com/lukehaas/css-loaders) - A collection of loading spinners animated with CSS.
- [SpinKit](https://github.com/tobiasahlin/SpinKit) - A collection of loading indicators animated with CSS.
- [Bounce.js](https://github.com/tictail/bounce.js) - A tool for creating CSS3 animations.

## Canvas

- [EaselJS](https://github.com/CreateJS/EaselJS) - A library for building high-performance interactive 2D content in HTML5.
- [Fabric.js](https://github.com/fabricjs/fabric.js) - A JavaScript Canvas library with animation support.
- [Paper.js](https://github.com/paperjs/paper.js) - A vector graphics scripting library: a port of Scriptographer to JavaScript and the browser using HTML5 Canvas.
- [Konva](https://github.com/konvajs/konva) - An HTML5 Canvas JavaScript framework that extends the 2D context with interactivity for desktop and mobile applications.
- [Two.js](https://github.com/jonobr1/two.js) - A renderer-independent 2D drawing API for the web with animation support.
- [Ocanvas](https://github.com/koggdal/ocanvas) - A JavaScript library for object-based Canvas drawing.
- [Curtainsjs](https://github.com/martinlaxenaire/curtainsjs) - A lightweight WebGL library in plain JavaScript that turns HTML DOM elements into interactive textured planes.
- [Hover-effect](https://github.com/robin-dela/hover-effect) - A JavaScript library for drawing and animating images on hover.
- [Pts.js](https://github.com/williamngan/pts) - A TypeScript/JavaScript library for visualization and creative coding.
- [tsParticles](https://github.com/matteobruni/tsparticles/) - A lightweight TypeScript/JavaScript library for creating particle animations.

## Animate on scroll

- [AOS](https://github.com/michalsnik/aos) - A library for animation on scroll.
- [Laxxx](https://github.com/alexfoxy/laxxx) - A small, lightweight plugin in plain JavaScript for smooth animations on scroll. The fixed source description gives a size of 3kb when minified and zipped.
- [Wow](https://github.com/matthieua/WOW) - Reveals CSS animations as the user scrolls down a page.
- [Scrollreveal](https://github.com/scrollreveal/scrollreveal) - Animates elements as they scroll into view.
- [ScrollMagic](https://github.com/janpaepke/ScrollMagic) - A JavaScript library for scroll interactions.
- [Motus](https://github.com/alexcambose/motus) - An animation library that mimics CSS keyframes during scrolling.
- [Sal](https://github.com/mciastek/sal) - A lightweight scroll animation library focused on performance.

## Text

- [Malarkey](https://github.com/yuanqing/malarkey) - A typewriter effect in plain JavaScript.
- [Typed.js](https://github.com/mattboldt/typed.js) - A JavaScript library for typing animations.
- [Shuffle-text](https://github.com/ics-ikeda/shuffle-text) - A JavaScript text effects library inspired by Flash effects.
- [Typebot](https://github.com/akzhy/typebot) - A JavaScript library for typing animations.
- [Blotter](https://github.com/bradley/Blotter) - A JavaScript API for drawing unconventional text effects on the web.

## React

- [Motion](https://github.com/framer/motion) - An open-source animation and gesture library for React, described in the fixed source as production-ready.
- [SVGR](https://github.com/gregberge/svgr) - Transforms SVGs into React components.
- [React tsParticles](https://github.com/matteobruni/tsparticles/blob/master/components/react/README.md) - A ReactJS wrapper for tsParticles.
- [React spring](https://www.react-spring.io/) - An open-source animation library for React based on spring physics, with interpolation support. The fixed description emphasizes speed and ease of use.

## GUI tools

- [Svgartista](https://svgartista.net/) - A tool for animating SVG stroke and fill properties with plain CSS. The source expects it to work with path, line, polyline, rect, circle, ellipse, and polygon elements; it cannot animate SVG gradients.
- [Mantra](https://jeremyckahn.github.io/mantra/) - A timeline editor for web animations inspired by Adobe Flash and After Effects.
- [Animista](https://animista.net/) - A tool for trying and adjusting predefined CSS animations and exporting the ones needed.
- [Cssanimate](http://cssanimate.com/) - A browser tool for creating complex CSS3 keyframe animations without coding or desktop software, and obtaining CSS styles for use on a website.
- [Ceaser](https://matthewlein.com/tools/ceaser) - A tool for adjusting CSS transition easing through cubic Bézier curves, going beyond default options such as ease-in and ease-out. Includes most of the classic Penner equations familiar from Flash and jQuery and supports touch devices.
- [Cubic Bezier](https://cubic-bezier.com/) - A tool for creating Bézier curves and importing and exporting curves to and from a library to share with others.
- [Keyframer](http://alexberg.in/keyframer/) - A tool for visualizing animation components and generating the required code.
- [CSS Animation Kit](http://angrytools.com/css/animation/) - A tool for selecting predefined samples from the top panel and editing the @keyframes timeline below them. The timeline runs left to right through 101 keyframes, from 0% to 100%. Highlighted keyframes have styles assigned; new styles can be added at a selected point.

## Books

### [SVG animation](https://www.amazon.com/SVG-Animations-Implementations-Responsive-Animation/dp/1491939702)

A guide to animating SVG, including responsive animation and performance. The source description highlights reduced HTTP requests and crisp rendering across displays, and explains how animation adds complexity to composition, color, implementation, and optimization.

### [Creating Web Animations: Bringing Your UIs to Life](https://www.amazon.com/Creating-Web-Animations-Bringing-Your/dp/1491957514/)

A book about creating web UI animations and understanding the interface problems they address. Its source description places this work in the context of faster browsers, improved web standards support, and more powerful devices, aiming for interfaces that are practical, fluid, engaging, and memorable.

### [Transitions and Animations in CSS: Adding Motion with CSS](https://www.amazon.com/Transitions-Animations-CSS-Adding-Motion/dp/149192988X/)

A concise guide to using CSS transitions and animations to move page elements or change their appearance, adding motion and depth to web applications and improving the user experience. Examples include a realistically bouncing ball, a gradually expanding drop-down menu, and drawing attention to an element on hover.

### [Designing Interface Animation: Meaningful Motion for User Experience](https://www.amazon.com/Designing-Interface-Animation-Meaningful-Experience/dp/1933820322/)

A guide to combining form and function and balancing purpose and style in web interface animation, while integrating motion into the user experience. Uses animation to improve feedback, orientation, attention, and causality, and to express a brand’s personality. Provides a crash course in motion design theory and practice for web designers, UX professionals, and front-end developers.

### [Web Animation using JavaScript: Develop & Design](https://www.amazon.com/Web-Animation-using-JavaScript-Develop/dp/0134096665)

A technical foundation for visually effective, maintainable web animation. The source contrasts flashing banner ads and scrolling news tickers with iOS and Android motion design, and discusses using animation to improve the feel and intuitiveness of website and application interfaces.

### [CSS Animations and Transitions for the Modern Web](https://www.amazon.com/gp/product/0133980502/)

A guide for designers familiar with CSS and HTML to adding motion to web pages over time through CSS3 style definitions. Discusses effects that improve usability or delight and surprise users, while distinguishing effects accessible through CSS from those requiring more complex scripting or programming.

### [Animation in HTML, CSS, and JavaScript](https://www.amazon.com/Animation-HTML-JavaScript-Kirupa-Chinnathambi/dp/1502548704)

A guide to creating practical animations in HTML, CSS, and JavaScript, with explained concepts, illustrated diagrams, and code examples. Starts with CSS animations and transitions, then covers JavaScript animation through DOM manipulation and drawing pixels on Canvas.

### [Foundation HTML5 Animation with JavaScript](https://www.amazon.com/Foundation-HTML5-Animation-JavaScript-Lamberta/dp/1430236655/)

A guide to scripted animation with HTML5 Canvas, covering the relevant mathematics and physics: acceleration, velocity, easing, springs, collision detection, conservation of momentum, 3D, and forward and inverse kinematics. Intended for HTML5 web developers and those moving from Flash to standards-compliant games, applications, and animations. Its fixed source description states support for modern browsers and most mobile devices, including iPhones, iPads, and Android devices; this is not a current compatibility guarantee.
