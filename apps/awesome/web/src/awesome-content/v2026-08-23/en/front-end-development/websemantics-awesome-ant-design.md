# Awesome Ant Design

Ant Design is a UI design language with a React implementation. The source describes it as refined by Ant Financial’s Experience Technology Department to standardize interfaces for middleware projects, reduce unnecessary costs from design differences and implementation, and free up design and front-end development resources. This list covers official resources, articles, tools, themes, UI components, applications, starters, and implementations for Angular, Vue.js, Blazor, and other frameworks.

## Resources

Projects and resources listed by the source as official Ant Design resources.

- [Ant Design](http://ant.design/) - An enterprise UI design language and React implementation.
- [Ant Design Pro](http://pro.ant.design/) - An out-of-the-box UI solution for enterprise applications.
- [Ant Design Mobile](http://mobile.ant.design/) - Configurable Mobile UI specification and React-based implementation.
- [Ant Design of React](http://react-component.github.io/badgeboard/) - Ready-to-use UI components based on React.
- [Ant Design SVG Icons](http://leungwensen.github.io/svg-icon/#ant) - Project to transform regular icon fonts into SVG format, supporting Ant Design icon fonts.
