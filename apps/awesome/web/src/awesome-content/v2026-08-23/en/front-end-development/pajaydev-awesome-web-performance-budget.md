# Awesome Web Performance Budget

A web performance budget sets limits on measures that affect a site’s speed and user experience. Designers and developers should keep those measures within the budget. Find articles, measurement tools, build checks, bundle and website analyzers, learning resources, and case studies for setting and maintaining those limits. Descriptions and status claims reflect the fixed source.

## Build Tools to set up performance budget

- [Bundle Size](https://github.com/siddharthkp/bundlesize) - Keep your bundle size in check.
- [Webpack Perf Budget](https://webpack.js.org/configuration/performance/) - Performance budget configuration for projects using Webpack.
- [Lighthouse](https://web.dev/use-lighthouse-for-performance-budgets/) - How to set up a performance budget using [lighthouse](https://developers.google.com/web/tools/lighthouse) and automate checks using [Lighthouse bot](https://web.dev/using-lighthouse-bot-to-set-a-performance-budget/).
- [Grunt-perfbudget](https://github.com/tkadlec/grunt-perfbudget) - A Grunt task for performance budgeting.
- [Size Limit](https://github.com/ai/size-limit) - Calculate the actual cost of running a JavaScript app or library and show an error in a pull request when it exceeds a limit.
- [Size Plugin](https://github.com/GoogleChromeLabs/size-plugin) - Track compressed Webpack asset sizes over time.
- [Performance Budget Builder](https://github.com/GoogleChromeLabs/pr-bot) - The linked pr-bot compares pull requests with their base and uses plugins to report differences, including file sizes, to GitHub.
- [Progressive Web Metrics](https://github.com/paulirish/pwmetrics) - A CLI tool and library for gathering performance metrics with Lighthouse.
- [rollup-plugin-size-snapshot](https://github.com/TrySound/rollup-plugin-size-snapshot) - A Rollup plugin that records bundle, minified, and gzip-compressed sizes and checks tree-shaking.
- [ImportCost - VS Extension](https://marketplace.visualstudio.com/items?itemName=wix.vscode-import-cost) - An extension that displays imported package sizes inline in the VS Code editor.

## Bundle Analyzers

- [Bundlephobia](https://bundlephobia.com/) - Find the cost of adding an npm package to your bundle.
- [bundle-buddy](https://bundle-buddy.firebaseapp.com/) - Find source code duplication across JavaScript chunks and splits.
- [webpack-bundle-analyzer](https://github.com/webpack-contrib/webpack-bundle-analyzer) - A Webpack plugin and CLI utility that displays bundle contents as an interactive, zoomable treemap.
- [Disc](http://hughsk.io/disc/) - Visualize the module tree of Browserify project bundles and locate sources of bloat.
- [lasso-analyzer](https://github.com/ajay2507/lasso-analyzer) - Analyze and visualize project bundles created by Lasso.
- [Rollup Visualizer](https://github.com/btd/rollup-plugin-visualizer) - Visualize and analyze your Rollup bundle to see which modules take up space.
- [Parcel plugin Visualizer](https://github.com/gregtillbrook/parcel-plugin-bundle-visualiser) - A Parcel bundler plugin for visualizing bundle contents.
- [CSS Analyzer](https://github.com/macbre/analyze-css) - Analyze CSS selector complexity and performance.
