# Awesome Canvas

HTML Canvas supports graphics drawn with JavaScript. This list includes animation and game demos, drawing libraries, talks, books, developers sharing experiments, and tutorials.

## Canvas

### Definition

According to [Mozilla Developer Network](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API), HTML5 introduced the HTML &lt;canvas> element for drawing with JavaScript. Its uses include graphs, photo composition, animation, and real-time video processing or rendering.

## Libraries

### To draw using canvas

- [Akihabara](http://www.kesiev.com/akihabara/) - An HTML5 game library for pixel-based games using JavaScript and the canvas tag.
- [CanvasKit](https://skia.org/docs/user/modules/canvaskit/) - Skia's Canvas API compiled to WebAssembly for high-performance 2D graphics rendering in web applications.
- [Chart.js](https://github.com/chartjs/Chart.js) - A lightweight JavaScript library for dynamic charts using HTML5 Canvas.
- [ChemDoodle](http://web.chemdoodle.com/) - An open-source chemistry and cheminformatics toolkit using Canvas for common chemistry tasks and varied molecular displays.
- [d3](https://github.com/d3/d3) - D3.js is a JavaScript library for data visualization using web standards: SVG, Canvas, and HTML.
- [EaselJS](https://createjs.com/easeljs) - A JavaScript library for working with HTML5 Canvas in games, generative art, and other graphical experiences. Part of CreateJS, whose modular libraries and tools work together or independently to create interactive content with HTML5.
- [fabric.js](http://fabricjs.com) - An interactive object model on top of Canvas, with parsers from SVG to Canvas and from Canvas to SVG.
- [iio.js](https://github.com/iioinc/iio.js) - A JavaScript library that helps speed up the creation and deployment of HTML5 Canvas applications.
- [isomerjs](http://jdan.github.io/isomer/) - An isometric graphics library for HTML5 Canvas.
- [Javascript-Voronoi](https://github.com/gorhill/Javascript-Voronoi) - A JavaScript implementation of Fortune's algorithm for computing Voronoi cells.
- [Konva](https://github.com/konvajs/konva) - An HTML5 Canvas JavaScript framework extending the 2D context with Canvas interaction for desktop and mobile applications.
- [Origami.js](https://github.com/raphamorim/origami.js) - A JavaScript library redesigning the Canvas API interface.
- [p5.js](https://p5js.org) - A client-side JavaScript library for graphic and interactive experiences.
- [Paper.js](https://github.com/paperjs/paper.js) - Scriptographer ported to JavaScript and the browser, using HTML5 Canvas.
- [Pencil.js](https://pencil.js.org/) - A modular JavaScript library with object-oriented syntax and a range of features.
- [Pixi.js](http://www.pixijs.com) - An HTML5 2D rendering engine using WebGL with a Canvas fallback.
- [Processingjs](http://ejohn.org/blog/processingjs/) - A data visualization programming language.
    - [Overview](http://ejohn.org/blog/overview-of-processing/)
    - [91 basic demos](http://ejohn.org/apps/processing.js/examples/basic/)
- [Proton](https://github.com/a-jie/Proton) - A lightweight JavaScript particle engine for creating varied effects.
- [Pts.js](https://ptsjs.org) - A JavaScript library for visualization and creative coding.
- [Rough.js](https://roughjs.com/) - A graphics library for drawing in a sketchy, hand-drawn style.
- [Scrawl-canvas](https://scrawl-v8.rikweb.org.uk/) - Adds multiple responsive, accessible, and interactive &lt;canvas> elements to a web page.
- [Sketch](https://github.com/soulwire/sketch.js) - A cross-platform JavaScript creative coding framework.
- [Three.js](http://threejs.org/) - A JavaScript library for WebGL-based 3D in the browser. The fixed source also links to [Canvas rendering instead of WebGL](http://threejs.org/docs/#Reference/Renderers/CanvasRenderer).
    - [Introduction](http://threejs.org/docs/#Manual/Introduction/Creating_a_scene)
    - [Examples](http://threejs.org/examples/)
- [textmode.js](https://github.com/humanbydefinition/textmode.js) - A lightweight, framework-agnostic creative coding library for real-time ASCII and textmode graphics in the browser.
- [tsParticles](https://particles.matteobruni.it/) - A lightweight particle animation library with ready-to-use components for common JavaScript frameworks, including ReactJS, VueJS, and Angular.
- [Visualize](https://github.com/filamentgroup/jQuery-Visualize) - A jQuery plugin creating charts and graphs from tabular data with HTML Canvas.
- [zDog](https://github.com/metafizzy/zdog) - A flat, rounded, designer-friendly pseudo-3D engine for Canvas and SVG.
- [ZIM](https://zimjs.com/) - A general Canvas framework using JavaScript for creative coding, for beginners and professionals.
- [zrender](https://github.com/ecomfe/zrender) - A lightweight Canvas library providing 2D drawing for Apache ECharts (described as incubating in the fixed source).

### For other purposes, but still use canvas

- [React Canvas](https://github.com/Flipboard/react-canvas) - High-performance &lt;canvas> rendering for React components.
