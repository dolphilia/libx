# Awesome Material-UI

[Material-UI](https://material-ui.com/) is a React component library that follows Google’s [Material Design](https://material.io/design/introduction/). Find official resources, articles, tools for themes and development, related projects, components, applications, and starter projects.

## Resources

Official projects and resources of Material-UI Design.

- [Material-UI](https://material-ui.com/) - React components for building your own design system or starting with Material Design.

- [How to autogenerate forms in React and Material-UI with MSON](https://medium.com/free-code-camp/how-to-autogenerate-forms-in-react-and-material-ui-with-mson-5771b1b7e739) - A guide to automatically generate forms using JSON in Material-UI.

## Theming

Utilities for customizing themes and changing them in the browser.

- [Create Material-UI Theme](https://github.com/react-theming/create-mui-theme) - Online tool for creating Material-UI themes via Material Design Color Tool.
- [Material-UI Theme Generator](https://cimdalli.github.io/mui-theme-generator/) - Material-UI theme/palette generator.
- [Material-UI Theme Editor](https://in-your-saas.github.io/material-ui-theme-editor/) - A tool to generate themes for your Material-UI applications by just selecting the colors and having a live preview.

## Related Projects

Material-UI Design family of projects.

- [Components Extra](https://github.com/alexandre-lelain/components-extra) - Customizable Material-UI "molecule" components, including Footer, CookiesBanner, BackToTop, and other complex elements for larger UI sections. The library addresses duplication of these components across sites.
