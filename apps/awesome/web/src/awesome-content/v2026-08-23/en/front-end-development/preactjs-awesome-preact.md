# Awesome Preact

[Preact](https://github.com/developit/preact) provides components and a virtual DOM. The fixed source describes it as a 3kb React alternative with the same ES6 API. This list covers its development tools, starter projects, routing, components, libraries, testing utilities, articles, and example applications, alongside community resources and related libraries. The [Preact website](https://preactjs.com) provides project information.
