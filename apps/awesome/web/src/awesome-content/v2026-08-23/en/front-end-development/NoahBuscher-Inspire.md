# Awesome Inspire

Resources for designing and building modern web frontends, from layout inspiration and visual assets to editors, collaboration tools, backends, testing, and further reading. Prices and platform restrictions reflect the fixed source.

## Concept<a id="these-sites-are-good-to-get-a-general-idea-of-possible-layouts-and-style-paths-to-take"></a>

Explore possible layouts and style directions.

* [Awwwards](http://www.awwwards.com/) - Websites in various styles.
* [CodeMyUI](https://codemyui.com/) - CSS/JavaScript snippets for UI effects.
* [CodePen](http://codepen.io/) - Central repository of user submitted code concepts/snippets. Useful for experiments.
* [Codrops](https://tympanus.net/codrops/) - Web design/development blog that publishes articles/tutorials about web trends.
* [CodyHouse](https://codyhouse.co/) - Tutorials and a showcase of UI elements.
* [CSS Winner](http://www.csswinner.com/) - Reviewed list of websites.
* [Designer News](https://www.designernews.co/) - Design and development links from the web.
* [Dribbble](https://dribbble.com/) - Snaps of icons, doodles, sites, and more shared by people.
* [Httpster](http://httpster.net/) - A curated list of websites.
* [Landings](https://landings.dev/) - Find landing pages for design inspiration based on your preferences.
* [OnePageLove](https://onepagelove.com/) - Inspiration for one-page and general website design.
* [SaaS Pages](https://saaspages.xyz) - An inspection of Netlify's page made especially to bring you inspiration.
* [Siiimple](https://siiimple.com/) - Another list of sites, but on the much simpler side.
* [SiteInspire](http://www.siteinspire.com/) - Get inspired.
* [TheBestDesigns](https://www.thebestdesigns.com/) - General list of hand picked sites from across the web.

## Creation<a id="these-sites-are-good-for-building-a-basic-framework-for-the-site"></a>

Build the basic framework of a website.

* Colors
  * [ColorsWall](https://colorswall.com/) - Place to store your color palettes.
  * [Coolors](https://coolors.co/) - Color scheme generator described by the source as fast.
  * [Kuler](https://color.adobe.com/) - Easily create or view a custom color swatch for your site.
  * [uiGradients](https://uigradients.com/) - Gradient generator.
  * [Spectral](http://jxnblk.com/Spectral/) - Minimal color swatch creation.
* Fonts
  * [Google Fonts](https://www.google.com/fonts) - Tons of free, easy to use webfonts.
* Frameworks
  * [Bootstrap](http://getbootstrap.com) - Framework for building modern websites and web apps.
    * [Bootswatch](http://bootswatch.com) - A list of free themes for Bootstrap.
* Icons
  * [Icon Scout](https://iconscout.com) - Icons, illustrations, and stock photos in one place.
  * [Iconmonstr](http://iconmonstr.com) - A collection of free, simple icons.
  * [Ionicons](http://ionicons.com) - Another collection of free icons.
* Images
  * [AllTheFreeStock](http://allthefreestock.com/) - Free stock images, videos, sounds, and icons in one location.
  * [TheStocks.im](http://thestocks.im) - A collection of stock photo websites.
  * [Unsplash](https://unsplash.com) - Free stock photos.
* Resources
  * [CSS3 Animation Cheat Sheet](http://www.justinaguilar.com/animations/) - A collection of CSS3 animation snippets.
  * [MDN](https://developer.mozilla.org) - Documentation for HTML, CSS, JS, etc
  * [User Inter Faces](http://uifaces.com) - Get ipsum images for user images.
  * [YMNNJQ](http://youmightnotneedjquery.com) - See jQuery functions in natural JS. No libraries.

## Tools<a id="every-painter-needs-a-brush-well-most-do"></a>

Design, edit, and transfer files with these tools.

* Design Tools
  * [Figma](https://figma.com) - Web-based vector graphics editor
  * [Sketch](https://sketchapp.com) [macOS only] - A professional vector graphics editor
* IDEs
  * [DevSession](https://devsession.js.org/) - Open a collaborative online IDE from a local directory.
* [FileZilla](https://filezilla-project.org) - For those who fear FTP in the terminal
* [Hyper](https://hyper.is) - Extensible command-line interface
* [Taskade](https://www.taskade.com/) [macOS only] - Create task lists and outlines.
* Text Editors
  * [Atom](https://atom.io) - A hackable text editor for the 21st century.
  * [Brackets](http://brackets.io/) - Modern, open source editor with live preview.
  * [Nova](https://nova.app) [macOS only] - Native text editor.
  * [Sublime Text](https://www.sublimetext.com) - Text editor for developers.
    * Themes
      * [Flatron](https://github.com/noahbuscher/Flatron) - Flat, purple theme.
      * [Predawn](https://github.com/jamiewilson/predawn) - Dark interface and syntax theme.
  * [VSCode](https://code.visualstudio.com/) - Free text editor
* [WinSCP](http://winscp.net) - Upload files to a MEAN stack or VPS server.

## Backends<a id="every-awesome-web-app-needs-an-awesome-backend"></a>

Backend services for web applications.

* [Auth0](https://auth0.com/) - Authentication, done for you.
* [DigitalOcean](https://www.digitalocean.com/) - VPS hosting company described by the source as inexpensive.
* [Firebase](https://www.firebase.com) - A real-time front-end database for your sites.
* [Hasura](https://hasura.io) - Platform for quickly building and deploying app backends.
* [Heroku](https://www.heroku.com) - Cloud application platform; very easy to scale.

## Testing<a id="before-you-launch-these-are-good-tools-to-make-sure-your-site-is-ready-for-stardom"></a>

Check a website before launch.

* [Browserling](https://www.browserling.com/) - Cross-browser test your website.
* [Checkbot](https://www.checkbot.io) - Browser extension that tests your website follows 50+ SEO, speed and security best practices.
* [CodePen](http://codepen.io) - A free web editor in your browser.
* [Hurl.it](https://www.hurl.it/) - Make HTTP requests in the browser.
* [Localtunnel](http://localtunnel.me) - Open localhost ports to the world.
* [Placehold](http://placehold.it) - Generate custom placeholder images of any size.
* [Postman](https://www.getpostman.com/) - A tool to make HTTP requests, generate mock servers and make API documentation.
* [WooRank](https://www.woorank.com/) - A review tool for SEO elements, W3 validation, and numerous other variables. Free basic service.
* [Yslow](http://yslow.org) - Tool for analyzing and finding fixes for multiple causes of slow site loading.
