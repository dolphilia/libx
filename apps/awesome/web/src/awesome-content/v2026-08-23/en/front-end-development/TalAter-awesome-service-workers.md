# Awesome Service Workers

Explore browser service workers for progressive web apps, offline operation, caching, and push notifications. Find introductory guides, specifications, browser support references, libraries, videos, case studies, and related technologies.

## Must Reads

- [Building Progressive Web Apps - O'Reilly](https://pwabook.com/oreillyasw) — A hands-on guide and reference for service workers, caching strategies, push notifications, and other progressive web app features.

- [Introduction to Service Worker](http://www.html5rocks.com/en/tutorials/service-worker/introduction/) — An introductory tutorial on service workers.

- [Offline Web Applications Using IndexedDB & Service Worker](https://www.udacity.com/course/offline-web-applications--ud899) — Udacity course introducing service workers and IndexedDB.

- [Service Workers Explained](https://github.com/slightlyoff/ServiceWorker/blob/master/explainer.md) — Service workers explained by [Alex Russell](https://github.com/slightlyoff).

## Learning Resources

- [Building Offline Sites with ServiceWorkers and UpUp](https://dev.opera.com/articles/offline-with-upup-service-workers/) — Introduction to service workers and using UpUp to add offline functionality; the source describes doing so in minutes.

- [Introduction to Service Worker](http://www.html5rocks.com/en/tutorials/service-worker/introduction/)

- [Service Workers 101](https://github.com/delapuente/service-workers-101) — Infographic summarizing key parts of the service workers API.

- [ServiceWorker Cookbook by Mozilla](https://serviceworke.rs/) — Recipes for different service worker use cases.

- [The copy & paste guide to your first Service Worker](https://remysharp.com/2016/03/22/the-copy--paste-guide-to-your-first-service-worker) — A short introduction by [Remy Sharp](https://github.com/remy).

- [The offline cookbook](https://jakearchibald.com/2014/offline-cookbook/) — Service worker patterns by Jake Archibald.

- [Designing Offline-First Web Apps](http://alistapart.com/article/offline-first) — Design and UX considerations for different connectivity states.

## Reference

- [Background Sync Spec](https://wicg.github.io/BackgroundSync/spec/) — Background Sync specification, described as a work in progress in the source.

- [Service Workers - W3C Specification](https://www.w3.org/TR/service-workers/) — Official service workers specification.

## Browser Support

- [Can I Use - Service Workers](http://caniuse.com/#feat=serviceworkers) — Browser support table for the ServiceWorker API.

- [Jake Archibald - Is Service Worker ready?](https://jakearchibald.github.io/isserviceworkerready/) — ServiceWorker support status in different browsers.

## Libraries and Tools

- [UpUp](http://upup.rocks/) — Service worker library that the source describes as providing complete offline functionality for a site in one line of code.

- [sw-toolbox](https://github.com/GoogleChrome/sw-toolbox/) — Helpers for implementing common runtime caching patterns.

- [Manifest Generator](https://brucelawson.github.io/manifest/) — Generates a web app manifest; the source describes the manifest as required for push notifications and installable web apps.

- [sw-precache](https://github.com/GoogleChrome/sw-precache/) — Generates a service worker to cache local App Shell resources.

- [sw-offline-google-analytics](https://developers.google.com/web/updates/2016/07/offline-google-analytics) — Helper library that retries offline Google Analytics requests when a connection becomes available.

- [Workbox](https://developers.google.com/web/tools/workbox/) — Libraries and Node modules for caching assets and using features for progressive web apps.

## Videos

- [Instant Loading: Building offline-first Progressive Web Apps - Google I/O 2016](https://youtu.be/cmGr0RszHc8) — Overview of common technologies and techniques for building progressive web apps.

- [Offline Web Applications Using IndexedDB & Service Worker](https://www.udacity.com/course/offline-web-applications--ud899) — Udacity course for exploring service workers in depth, described as free in the source.

- [Instant Loading with Service Workers (Chrome Dev Summit 2015)](https://www.youtube.com/watch?v=jCKZDTtUA2A) — How to structure a web app to optimize loading for first-time and returning visitors, with service worker libraries that reduce boilerplate code.

## Case Studies

- [Service Workers in Production](https://developers.google.com/web/showcase/case-study/service-workers-iowa) — Case study of how the Google I/O 2015 web app was built.

- [Measuring the Real-world Performance Impact of Service Workers](https://developers.google.com/web/showcase/2016/service-worker-perf) — Examines proactive asset caching and the expected substantial loading improvement for returning visitors when all necessary resources are cached, including how to measure the effect for real users.
