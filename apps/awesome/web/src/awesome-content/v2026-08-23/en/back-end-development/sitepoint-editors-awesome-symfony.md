# Awesome Symfony

Explore [Symfony](http://symfony.com) bundles and tools for administration, forms, storage, authentication, APIs and application development. This list also includes certification materials, community channels, books and configuration recipes. Compatibility and maintenance descriptions reflect the fixed upstream snapshot.

## Administration

* [AdminCrudBundle](https://github.com/MWSimple/AdminCrudBundle) - Uses SensioGeneratorBundle and extends the controller with a paginator, filters and other features.
* [AdmingeneratorGeneratorBundle](https://github.com/symfony2admingenerator/AdmingeneratorGeneratorBundle) - Admin generator for Symfony2 that parses generator.yml files to build classes.
* [EasyAdminBundle](https://github.com/javiereguiluz/EasyAdminBundle) - Simple admin generator for Symfony applications.
* [SonataAdminBundle](https://github.com/sonata-project/SonataAdminBundle) - Admin generator for Symfony2.
* [AdminLTEBundle](https://github.com/kevinpapst/AdminLTEBundle) - Admin theme based on the AdminLTE Template.
* [Umbrella framework](https://github.com/acantepie/umbrella) - Admin components and theme to create administration backends.
* [TablerBundle](https://github.com/kevinpapst/TablerBundle) - Admin theme based on the Tabler template, with Twig helpers for functions, filters, embeds, macros and includes.
