# Awesome Reflex

[Reflex](https://reflex.dev) is an open-source framework for building a web app's frontend and backend entirely in Python, without writing HTML, CSS, or JavaScript. Projects can range from small data science apps to large, multi-page websites. This list covers official templates and example apps, documentation and learning materials, component libraries, database and authentication tools, and community channels.

## Example Apps and Templates <a id="️-example-apps-and-templates"></a>

[Complete Reflex examples](https://github.com/reflex-dev/reflex-examples) are available in a dedicated repository.

The Reflex website is itself built with Reflex; see its [source code](https://github.com/reflex-dev/reflex-web).
