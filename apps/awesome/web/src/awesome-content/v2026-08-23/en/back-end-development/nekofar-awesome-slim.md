# Awesome Slim

[Slim](https://www.slimframework.com) is a PHP microframework for building web applications and APIs. Find learning materials, application skeletons, middleware, view renderers, testing helpers, and other packages, including resources for Slim 4.

## Learning materials<a id="educational"></a>

- [User Guide](https://www.slimframework.com/docs/v4/) — The official Slim Framework documentation.

- [Stack Overflow](https://stackoverflow.com/questions/tagged/slim) — Slim Framework questions on Stack Overflow.

- [Discussion Forum](https://discourse.slimframework.com) — The official Slim Framework discussion forum.

- [Slim 4 - GraphQL](https://odan.github.io/2021/08/12/slim-graphql.html) — Create HTTP APIs using GraphQL.

- [Slim 4 - ReactPHP](https://odan.github.io/2021/08/14/slim-reactphp.html) — Combine Slim with ReactPHP to improve performance, as described by the source.

## Boilerplate

- [Slim 4 MVC Skeleton](https://github.com/semhoun/slim-skeleton-mvc) — A simple web application skeleton.

- [Slim 4 Skeleton](https://github.com/adriansuter/Slim4-Skeleton) — A web application skeleton using PHP-DI, Nyholm PSR7, and Twig.

- [Slim 4 Skeleton](https://github.com/odan/slim4-skeleton) — A skeleton for setting up a new Slim 4 application.

- [Slim Skeleton](https://github.com/slimphp/Slim-Skeleton) — The official Slim Framework 4 skeleton application.

- [Slim 4 Starter](https://github.com/nbayramberdiyev/slim-4-starter) — An opinionated Slim 4 starter template for small to medium PHP applications.

## Middlewares

- [Slim Basic Auth](https://github.com/tuupola/slim-basic-auth) — HTTP Basic authentication middleware supporting PSR-7 and PSR-15.

- [Slim CSRF](https://github.com/slimphp/Slim-Csrf) — CSRF protection middleware for Slim Framework.

- [Slim HTTP Cache](https://github.com/slimphp/Slim-HttpCache) — HTTP cache middleware and a service provider for Slim Framework.

- [Slim JWT Auth](https://github.com/tuupola/slim-jwt-auth) — JWT authentication middleware supporting PSR-7 and PSR-15.

- [Slim Minify](https://github.com/christianklisch/slim-minify) — Minify HTML output generated by Slim.

- [Slim Session](https://github.com/bryanjhv/slim-session) — Simple session middleware for Slim Framework.

- [Slim Whoops](https://github.com/zeuxisoo/php-slim-whoops) — PHP Whoops error reporting for Slim Framework.

## Templating

- [Slim Twig View](https://github.com/slimphp/Twig-View) — A Slim Framework view helper built on Twig.

- [Slim Plates](https://github.com/projek-xyz/slim-plates) — Render Slim application views with the Plates template engine.

- [Slim PHP View](https://github.com/slimphp/PHP-View) — Render PHP view scripts into a PSR-7 Response object.

## Development

- [Pest Slim Plugin](https://github.com/nekofar/pest-plugin-slim) — A Pest plugin providing basic functionality for testing Slim.

- [Slim Test](https://github.com/nekofar/slim-test) — A Slim Framework test helper built on PHPUnit.

## Miscellaneous

- [BasePath](https://github.com/selective-php/basepath) — A base path detector for Slim 4.

- [PHP-DI Slim Bridge](https://github.com/PHP-DI/Slim-Bridge) — PHP-DI integration with Slim Framework.

- [Slim Config](https://github.com/DavidePastore/Slim-Config) — A configuration loader supporting PHP, INI, XML, JSON, and YML files.

- [Slim Console](https://github.com/slimphp/Slim-Console) — A console for Slim Framework.

- [Slim Flash](https://github.com/slimphp/Slim-Flash) — A flash messages service provider for Slim Framework.

- [Slim JSON API](https://github.com/entomb/slim-json-api) — An extension for implementing JSON APIs, described by the source as fast.

- [Slim Validation](https://github.com/DavidePastore/Slim-Validation) — A validation library for Slim Framework.

- [IntelliJ Slim](https://plugins.jetbrains.com/plugin/18751-slim) — Boilerplate code for creating new projects from a skeleton.
