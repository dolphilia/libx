# Awesome Vapor

[Vapor](https://vapor.codes) is a server-side Swift framework for building back-end applications. This list includes libraries for authentication, databases, storage, email and other integrations, along with development tools, services, learning materials and example projects.

Vapor 3 and Vapor 4 labels preserve the version assignments in the recorded source; they do not establish current compatibility.

## How to use

The recorded source links to separate lists for [Vapor 3](https://github.com/Cellane/awesome-vapor/blob/filtered/vapor-3.md) and [Vapor 4](https://github.com/Cellane/awesome-vapor/blob/filtered/vapor-4.md) on the `filtered` branch. It also points to archived content in the `legacy` folder.

## Libraries

- [API Error Middleware](https://github.com/skelpo/APIErrorMiddleware) (Vapor 3) – Vapor middleware for converting thrown errors to JSON responses.
- [APNS](https://github.com/vapor-community/apns) (Vapor 3) – Vapor APNS for iOS.
- [Bugsnag](https://github.com/nodes-vapor/bugsnag) (Vapor 3) – Report errors with Bugsnag.
- [CouchDB Client](https://github.com/makoni/couchdb-vapor) (Vapor 3) – Simple CouchDB client for Vapor.
- [CrudRouter](https://github.com/twof/VaporCRUDRouter) (Vapor 3) – Automatic RESTful CRUD router generation for any Fluent model.
- [CSRF](https://github.com/vapor-community/CSRF) (Vapor 3) – A package to add protection to Vapor against CSRF attacks.
- [CSV Framework](https://github.com/skelpo/CSV) (Vapor 3) – A simple framework to read and write CSV files.
- [Ferno](https://github.com/vapor-community/ferno) (Vapor 3) – Vapor Firebase Realtime database provider.
- [Flash](https://github.com/nodes-vapor/flash) (Vapor 3) – Flash messages between views.
- [FluentQuery](https://github.com/MihaelIsaev/FluentQuery) (Vapor 3) – Build complex raw SQL queries while still using Swift keypaths.
- [Gatekeeper](https://github.com/nodes-vapor/gatekeeper) (Vapor 3) – Rate limiting middleware for Vapor.
- [Google Cloud Provider](https://github.com/vapor-community/google-cloud-provider) (Vapor 3) – Interact with Google Cloud Platform APIs from your Vapor project.
- [Guardian](https://github.com/Jinxiansen/Guardian) (Vapor 3) – Rate-limiting middleware.
- [Imperial](https://github.com/vapor-community/Imperial) (Vapor 3) – Federated authentication with OAuth providers.
- [JWT Keychain](https://github.com/nodes-vapor/jwt-keychain) (Vapor 3) – Easily scaffold a keychain using JWT for Vapor.
- [JWT Middleware](https://github.com/skelpo/JWTMiddleware) (Vapor 3) – Middleware to authenticate and authorize requests in Vapor.
- [Leaf Error Middleware](https://github.com/brokenhandsio/leaf-error-middleware) (Vapor 3) – Serve up custom 404 and server error pages for your Vapor app.
- [Leaf Markdown](https://github.com/vapor-community/leaf-markdown) (Vapor 3) – Markdown renderer for Vapor.
- [Lingo Vapor](https://github.com/vapor-community/Lingo-Vapor) (Vapor 3) – Vapor provider for Lingo – the Swift localization library.
- [Local Storage](https://github.com/gperdomor/local-storage) (Vapor 3) – Storage driver using local filesystem.
- [MailCore](https://github.com/LiveUI/MailCore) (Vapor 3) – Sending e-mails via SMTP, MailGun and SendGrid.
- [Meow](https://github.com/OpenKitten/Meow) (Vapor 3) – An alternative codable ORM for MongoDB.
- [MongoKitten](https://github.com/OpenKitten/MongoKitten) (Vapor 3) – MongoDB driver in Swift.
- [Pagination](https://github.com/vapor-community/pagination) (Vapor 3) – Simple Vapor 3 Pagination.
- [Paginator](https://github.com/nodes-vapor/paginator) (Vapor 3) – Query pagination for Vapor and Fluent.
- [S3](https://github.com/LiveUI/S3) (Vapor 3) – Library for accessing the Amazon S3 service (and compatible) with support for most commonly used operations.
- [S3 Storage](https://github.com/anthonycastelli/s3-storage) (Vapor 3) – Library for simple access to the Amazon S3 service.
- [Sanitize](https://github.com/gperdomor/sanitize) (Vapor 3) – Model extraction from Vapor JSON requests.
- [SendGrid Provider](https://github.com/vapor-community/sendgrid-provider) (Vapor 3) – SendGrid-powered mail backend for Vapor.
- [SimpleFileLogger](https://github.com/hallee/vapor-simple-file-logger) (Vapor 3) – A simple file logging provider for Vapor.
- [Slugify](https://github.com/nodes-vapor/slugify) (Vapor 3) – Convenience for sluggifying your strings.
- [Storage](https://github.com/nodes-vapor/storage) (Vapor 3) – Eases the use of multiple storage and CDN services.
- [Stripe Provider](https://github.com/vapor-community/stripe-provider) (Vapor 3) – Stripe Provider for Vapor.
- [Submissions](https://github.com/nodes-vapor/submissions) (Vapor 3) – Conveniences for creating forms and validating (form) submissions.
- [Sugar](https://github.com/nodes-vapor/sugar) (Vapor 3) – A package of sugar for Vapor.
- [SwifQL](https://github.com/MihaelIsaev/SwifQL) (Vapor 3) – Easily build flexible and type-safe SQL with pure Swift.
- [SwiftyBeaver Provider](https://github.com/vapor-community/swiftybeaver-provider) (Vapor 3) – SwiftyBeaver logging provider for Vapor, the server-side Swift web framework.
- [Telesign Provider](https://github.com/vapor-community/telesign-provider) (Vapor 3) – A Telesign provider for Vapor.
- [Vapor Mailgun Service](https://github.com/vapor-community/VaporMailgunService) (Vapor 3) – A service to be used with Vapor to send emails.
- [Vapor reCAPTCHA](https://github.com/gotranseo/vapor-recaptcha) (Vapor 3) – Validate Google reCAPTCHAs using Vapor.
- [Vapor Request Storage](https://github.com/skelpo/vapor-request-storage) (Vapor 3) – A replacement for `request.storage` which was available in Vapor 1 & 2.
- [Vapor Security Headers](https://github.com/brokenhandsio/VaporSecurityHeaders) (Vapor 3) – Strengthen security headers for Vapor.
- [Vapor Test Tools](https://github.com/LiveUI/VaporTestTools) (Vapor 3) – Helper for testing endpoints in Vapor 3.
- [VaporExt](https://github.com/vapor-community/vapor-ext) (Vapor 3) – A collection of Swift extensions for a wide range of Vapor data types and classes.
- [WKHTMLTOPDF](https://github.com/MihaelIsaev/wkhtmltopdf) (Vapor 3) – Build PDF files from Leaf templates or web pages through the `wkhtmltopdf` CLI tool.
- [XMLCoding](https://github.com/LiveUI/XMLCoding) (Vapor 3) – XML encoder and decoder.
