# Awesome Open Hardware

自動化、製造、コンシューマー機器、開発ボード、科学機器のオープンソースハードウェアプロジェクトを探せます。オープンハードウェアを作り、学ぶための講演、論文、会議、プラットフォーム、ポッドキャスト、書籍、研修プログラムに加え、参考文献と関連リストも紹介しています。

## プロジェクト <a id="projects"></a>

### 自動化、製造、ロボティクス <a id="automation-manufacturing-and-robotics"></a>

* [FarmBot](https://farm.bot/pages/open-source) - 野菜を育てる自動園芸機械。
* [Hacker Fab](https://docs.hackerfab.org/home) - 集積回路を製作するためのナノ加工ツール。
* [JPL Open Source Rover](https://github.com/nasa-jpl/open-source-rover) - 自作できる、6輪のオープンソースローバー。
* [Mekanika](https://www.mekanika.io/) - メイカー向けのツールと機械。
* [Millennium Machines](https://www.millennium-machines.com/) - 卓上CNCフライス盤の設計に取り組むプロジェクト。
* [Open Source Ecology](https://www.opensourceecology.org/) - オープンソースの産業機械。
* [Opulo](https://docs.opulo.io/) - ピックアンドプレースマシンを開発するプロジェクト。
* [Precious Plastic](https://www.preciousplastic.com/) - プラスチックのリサイクルをできる限り簡単にするツール。
* [Prusa3D](https://www.prusa3d.com/) - 自らの成果物をオンラインでオープンに公開する3Dプリンターメーカー。
* [RepRap](https://reprap.org/wiki/RepRap) - 汎用の自己複製製造機械。原文では人類初と紹介されている。
* [VORON Design](https://www.vorondesign.com/) - 原文で「妥協のない設計」と紹介されている3Dプリンターの設計。
* [WikiHouse](https://www.wikihouse.cc/) - デジタル設計によるオープンな住宅。

### コンシューマー機器 <a id="consumer-devices"></a>

* [freeDSP](https://freedsp.github.io) - オーディオ用デジタル信号プロセッサーの製品群。
* [Input Labs](https://inputlabs.io) - ジャイロセンサーを備えたビデオゲームコントローラー。
* [Mutable Instruments](https://mutable-instruments.net/) - Eurorackの定番。
* [PiKVM](https://pikvm.org/) - Raspberry Piを使ったDIY IP-KVM。原文では低価格と説明されている。
* [PiSpot Show](https://github.com/GeiserX/PiSpot-Show) - HDMIディスプレイを、自動更新するWi-Fi利用券のキオスク端末として動かすRaspberry Pi機器。リアルタイムの天気情報も表示する。
* [PiSpot Watch](https://github.com/GeiserX/PiSpot-Watch) - 必要に応じてWi-Fi利用券コードを生成する、電子ペーパーディスプレイを備えた手首装着型のRaspberry Pi Zeroスマートウォッチ。
* [SlimeVR](https://slimevr.dev) - バーチャルリアリティとモーションキャプチャ向けの全身トラッキングセンサー。
* [Winterbloom](https://winterbloom.com) - Eurorackモジュール。Theaによるブログの設計解説もある。

### 開発ボード <a id="development-boards"></a>

* [Arduino](https://www.arduino.cc/) - 電子工作プラットフォーム。
* [OpenMV](https://github.com/openmv/openmv) - マシンビジョンプラットフォーム。原文では低価格と説明されている。
* [pic0rick](https://github.com/kelu124/pic0rick/) - パルスエコー方式の超音波画像化ハードウェア向けRaspberry Pi Picoプラットフォーム。

### 科学機器 <a id="scientific-instruments"></a>

* [Biohack Academy](https://assets.waag.org/biohackacademy) - インキュベーター、サーマルサイクラー、遠心分離機、顕微鏡などのバイオテクノロジー用ハードウェア。
* [GaudiLab](http://www.gaudi.ch/GaudiLabs/?page_id=19) - 生物学研究室向けのハードウェアプロジェクト。
* [mesoSPIM](http://mesospim.org/) - 透明化した組織を撮像するためのライトシート顕微鏡。
* [Open Gamma Detector](https://github.com/Open-Gamma-Project/Open-Gamma-Detector) - 改造可能なガンマ線分光計。原文では低価格と説明されている。
* [OpenBCI](https://openbci.com/) - ブレイン・コンピューター・インターフェース。
* [OpenFlexure](https://openflexure.org/) - 精密な機械式ステージを備えた3Dプリント製顕微鏡。
* [OpenSPIM](https://openspim.org/) - 三次元（3D）顕微鏡のオープンアクセスプラットフォーム。
* [openUC2](https://github.com/openUC2/UC2-GIT) - モジュール式の顕微鏡ツールボックス。
* [SafeCast](https://safecast.org/) - 環境の測定結果をパブリックドメインで提供する。

## 会議 <a id="conferences"></a>

* [FOSDEM](https://fosdem.org) - 原文で、ブリュッセルで毎年開催されると紹介されているオープンソースイベント。
* [Open Hardware Summit](https://oshwa.org/events/) - 原文で年次開催と紹介されている、オープンハードウェアの会議。
* [Open Sauce](https://opensauce.com/) - 科学技術を扱うコンベンション。原文では年次開催とされ、日程は7月17〜19日と記されているが、年の指定はない。
* [Maker Faire](https://makerfaire.com/) - 地域ごとに開催されるメイカームーブメントの祭典。
* [Hackaday Supercon](https://hackaday.io/superconference/) - ハードウェアハッキングと詳しい技術ワークショップの会議。原文では年次開催と紹介されている。
* [KiCon](https://kicon.kicad.org/) - オープンソースEDAのKiCadに関する会議。原文では、さまざまな地域で毎年開催されると紹介されている。
* [RISC-V Summits](https://riscv.org/community/risc-v-summits/) - RISC-V Internationalが主催するサミット。原文では、さまざまな地域で毎年開催されると紹介されている。
* [World RISC-V Days](https://riscv.org/world-risc-v-days/) - 世界各地のRISC-Vコミュニティが自主的に開催する、日程をそろえた世界規模のイベント。
* [Latch-Up](https://fossi-foundation.org/latch-up) - フリーかつオープンソースのシリコンを扱う3日間の会議。原文では、北米で毎年春に開催されると紹介されている。
* [ORConf](https://fossi-foundation.org/orconf) - フリーかつオープンソースのシリコンを扱う、もう一つの3日間の会議。原文では、欧州で毎年秋に開催されると紹介されている。

## プラットフォーム <a id="platforms"></a>

* [Open Hardware Repository](https://ohwr.org/about) - 実験物理施設の電子機器設計者が、オープンハードウェアの設計で協力するための場。
* [Open Hardware Observatory](https://en.oho.wiki/wiki/Home) - 持続可能なオープンハードウェアのための自由な設計図。
* [Instructables](https://www.instructables.com/circuits/projects) - 創作物を探求、記録、共有できる場。
* [Hackaday.io](https://hackaday.io/) - 共同ハードウェア開発コミュニティ。原文では世界最大と紹介されている。
* [Hackster.io](https://www.hackster.io/about) - 開発者同士をつなぐプラットフォーム。
* [Openhardware.io](https://www.openhardware.io/about) - オープンハードウェアのプロジェクトを追跡する。
* [Openhardware.science](https://openhardware.science/) - 原文で、2025年までにオープンサイエンスハードウェアを広く普及させることを目標とする取り組みとして紹介されている。
* [Openlifescience](https://openlifesci.org/) - 研究分野でオープンサイエンスのアンバサダーを育てるプログラム。
* [Thingiverse](https://www.thingiverse.com/) - 3Dプリント、レーザー切断、CNCフライス加工向けのハードウェア設計を共有し、共同で作るプラットフォーム。
* [Kitspace.org](https://kitspace.org) - 電子工作プロジェクトを作り、共有する場。

* [Wikipedia](https://en.wikipedia.org/wiki/Open-source_hardware) - オープンソースハードウェアに関する一般情報。
