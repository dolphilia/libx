# Awesome Blockchain AI

分散化、改変できない記録、スマートコントラクトを利用してAI・機械学習システムを構築するブロックチェーンプロジェクトをまとめています。アルゴリズム、データ、計算、金融、医療、自律エージェントの各分野と、背景を学ぶ読み物や学術研究を探せます。機能、目標、評価や主張の記述は固定原文に基づきます。

## AIアルゴリズムのためのブロックチェーン <a id="blockchains-for-ai-algorithms"></a> <a id="ai-アルゴリズムのためのブロックチェーン"></a>

- [SingularityNET](https://singularitynet.io/) - Ethereumブロックチェーン上の分散AI プラットフォームで、各ブロックチェーンノードが AIアルゴリズムをバックアップします。
- [Intuition Fabric](https://intuitionfabric.com) - InterPlanetary File System（IPFS）に保存し、Ethereumブロックチェーン経由でアクセスするディープラーニングモデルのネットワークを通じて、AIへのアクセスを民主化することを目指しています。
- [OpenMined](https://openmined.org/) - データと知能を分散所有するためのオープンソース技術の構築に取り組むコミュニティです。OpenMined を使うと、AIは直接アクセスすることのないデータで学習できます。
- [Raven Protocol](https://www.ravenprotocol.com/) - 中央管理者に依存しない分散型のディープラーニング学習プロトコルです。
- [Thought Network](https://thought.live/) - Thoughtのブロックチェーン対応Fabricは、あらゆるデータにAIを組み込みます。原文では、これがアプリケーションを根本から変え、データを柔軟で活用可能かつ本質的に安全なものにすると説明されています。
- [MATRIX AI](https://www.matrix.io/) - Matrix AI Networkは、AIとブロックチェーンを組み合わせ、ブロックチェーン技術の開発と普及を妨げる主要課題に対処するパブリックチェーン。原文では、ブロックチェーンを活用した分散コンピューティング基盤により、AI分野の変革と民主化を進めるものと紹介されています。
- [Cortex Labs](https://www.cortexlabs.ai/) - AIプログラムをオンチェーンで実行できる仮想マシンを備えた、分散AI プラットフォームです。
- [Fetch.ai](https://fetch.ai/) - 分散台帳に基づく分散型機械学習プラットフォームで、世界中のあらゆるデータを基に、安全な共有、接続、取引を可能にします。
- [Oraichain](https://orai.io/) - 原文で、新興Web3、スケーラブルなDapp、分散AI向けの世界初のインテリジェントで安全なソリューションと紹介されています。
- [Bittensor](https://bittensor.com/) - 分散型のブロックチェーンベース機械学習ネットワークを動かすオープンソースプロトコルです。[関連資料](https://taostats.io/links/)
- [Alethea AI](https://alethea.ai/) - 生成AIとブロックチェーンが交わる領域で活動する研究開発スタジオです。
- [Vanna Labs](https://www.vannalabs.ai/) - 分散アプリケーションを支えるため、ネイティブでシームレス、トラストレスな AI/ML 推論をオンチェーンで実行できる Ethereum L2ロールアップです。

### AIアルゴリズム向けブロックチェーンプロジェクト <a id="blockchain-projects-for-ai-algorithms"></a> <a id="ai-アルゴリズム向けブロックチェーンプロジェクト"></a>
- [Danku](https://github.com/algorithmiaio/danku) - Ethereumなどの公開ブロックチェーン上で MLモデルを評価・購入するためのブロックチェーンベースのプロトコルです。[ブログ記事](https://algorithmia.com/research/ml-models-on-blockchain)
- [Decentralized & Collaborative AI on Blockchain](https://github.com/microsoft/0xDeCA10B) - 0xDeCA10B は、スマートコントラクト上で公開機械学習モデルをホスト・学習するためのフレームワークです。高品質な学習データを促すインセンティブ機構を備えつつ、モデルを予測に無料で利用できるようにします。[ブログ記事](https://www.microsoft.com/en-us/research/blog/leveraging-blockchain-to-make-machine-learning-models-more-accessible/)

## データのためのブロックチェーン <a id="blockchains-for-data"></a>

- [Ocean Protocol](https://oceanprotocol.com/) - データの共有と収益化を可能にする分散型データ交換プロトコル。原文では、全参加者の制御可能性、監査可能性、透明性、コンプライアンスを保証すると説明されています。ネットワークはメタデータ（誰が何を所有するか）、データ自体へのリンクなどを保存します。

## 計算のためのブロックチェーン <a id="blockchains-for-computation"></a>

- [TrueBit](https://truebit.io/) - Ethereumスマートコントラクトの計算能力を強化します。
- [DeepBrain Chain](https://www.deepbrainchain.org/) - AI技術を開発する企業に処理能力を提供する分散型 AI コンピューティングプラットフォームです。
- [Nunet](https://www.nunet.io/) - 世界中で独立所有されている計算デバイスの余剰能力を、動的な計算資源市場へ統合するグローバル分散コンピューティングフレームワークです。
- [Phala Network](https://phala.network/) - Web3 開発向けの分散型オフチェーン計算基盤です。

## 金融AI のためのブロックチェーン <a id="blockchains-for-ai-in-finance"></a> <a id="金融-ai-のためのブロックチェーン"></a>

- [Numerai](https://numer.ai/) - 暗号化データを扱う機械学習モデルを構築し、そのモデルへの確信を示すため暗号資産をステークする匿名データサイエンティストのネットワークによって運営されるヘッジファンドです。
- [Cindicator](https://cindicator.com/) - 金融・暗号資産指標のクラウドソーシング型予測エンジンです。
- [Erasure](https://erasure.xxx/) - 金融予測のための分散型プロトコル兼データ市場です。

## 医療AI のためのブロックチェーン <a id="blockchains-for-ai-in-medicine"></a> <a id="医療-ai-のためのブロックチェーン"></a>

- [doc.ai](https://doc.ai/about) - AIを利用して、ブロックチェーン上で精密医療を分散化することを目指しています。
- [BurstIQ](https://www.burstiq.com/) - データの所有権と同意をきめ細かく管理できる医療データ市場。原文では、独自ブロックチェーンのオンチェーンストレージにより、HIPAA、GDPRなどの規制に準拠できると説明されています。

## 自律エージェントのためのブロックチェーン <a id="blockchains-for-autonomous-agents"></a>

- [Hashgraph Online (HOL)](https://hol.org/) - Hedera Hashgraph 上に構築された汎用エージェントレジストリです。ERC-8004 標準と HCS-14 Universal Agent ID（UAID）を使い、AIエージェントにブロックチェーンベースの ID を提供します。x402 プロトコルによるエージェントの発見、検証、自律的な商取引を可能にします。
- [AgentFund](https://github.com/RioBot-Grind/agentfund) - Base ブロックチェーン上の自律AIエージェント向け分散型クラウドファンディング基盤で、AIプロジェクトや共同作業に対し、マイルストーンに基づくエスクロー資金提供を可能にします。
