# Awesome Waves

[Waves](https://wavesprotocol.org/)は、Web 3.0アプリケーションや分散型ソリューション向けのオープンソースのブロックチェーン基盤と開発ツール群です。Rideの学習資料、ウォレットとエクスプローラー、TestnetとStagenet、言語別ライブラリ、ツール、Waves上のプロジェクト、開発者コミュニティを紹介します。

## プレイグラウンド

### テストネット

固定原文では、TestnetはMainnetと同じ設定・ノード版を使う安定したネットワークと説明されています。テスト用の無料Wavesトークンを入手できます。

- [エクスプローラー](https://wavesexplorer.com/testnet) - 公式Testnetエクスプローラー。少量の無料Wavesトークンを入手できる[フォーセット](https://wavesexplorer.com/testnet/faucet)を提供。
- [ノードAPI](https://nodes-testnet.wavesnodes.com/) - TestnetノードのAPI。
- [データサービス](https://api-test.wavesplatform.com/v0/docs/) - Testnet用の公式データサービス。

### ステージネット

Stagenetは、公式Waves製品のリリース候補をMainnetやTestnetへ提供する前に検証するための、不安定なネットワークです。テスト用の無料Wavesトークンも入手でき、サービスやdAppと次期リリースとの互換性確認などに使えます。

- [エクスプローラー](https://wavesexplorer.com/stagenet) - 公式エクスプローラー。少量の無料Wavesトークンを入手できる[フォーセット](https://wavesexplorer.com/stagenet/faucet)を提供。
- [ノードAPI](https://nodes-stagenet.wavesnodes.com/) - Waves NodeのSwagger REST API。
- [IDE](https://stagenet.waves-ide.com) - Stagenet上でRideスマートコントラクトを作成するオンラインIDE。

### Docker イメージ

- [WavesNode](https://hub.docker.com/r/wavesplatform/wavesnode) - Waves PlatformノードのDockerイメージ。公式・独自のあらゆるネットワークに対応。
- [K8s by loxal](https://hub.docker.com/r/loxal/waves-node) - Kubernetesクラスター内で、起動後に個別操作を要しない`StatefulSet`として実行するためのコンテナー。
- [waves-private-node](https://hub.docker.com/r/wavesplatform/waves-private-node) - 非公開のローカルWavesノード。独立したノードを起動し、スマートコントラクト開発や各種実験に使用。
- [explorer](https://hub.docker.com/r/wavesplatform/explorer) - 自分のノード用のWaves Explorer。
