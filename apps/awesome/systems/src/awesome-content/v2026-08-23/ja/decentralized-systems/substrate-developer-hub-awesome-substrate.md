# Awesome Substrate

Substrateは、アップグレード可能でモジュール化された効率的なブロックチェーンを構築するための、オープンソースの[Rust](https://www.rust-lang.org/)フレームワークです。[Parity Technologies](https://www.parity.io/)が保守し、ソースコードを[GitHub](https://github.com/paritytech/substrate)で公開しています。開発資料、テンプレート、FRAMEパレット、クライアントライブラリ、ツール、SCALEコーデックの実装を探せます。

Polkadotエコシステム全体を対象とする、より広い範囲のリストは[awesome-dot](https://github.com/haquefardeen/awesome-dot)を参照してください。

## テンプレート <a id="templates"></a>

- [Base](https://github.com/substrate-developer-hub/substrate-node-template) - 最小構成のFRAMEベースのノード。[上流実装](https://github.com/paritytech/substrate/tree/master/bin/node-template)から派生。
- [Frontier](https://github.com/paritytech/frontier/tree/master/template) - Frontierを組み込み、EVMおよびEthereum RPCに対応した、開発を始められるSubstrateノード。
- [Front-End](https://github.com/substrate-developer-hub/substrate-front-end-template) - Substrateベースのチェーン向けフロントエンドを構築するためのPolkadot-JS APIと[React](https://reactjs.org/)アプリ。
- [Parachain](https://github.com/substrate-developer-hub/substrate-parachain-template) - Cumulusを組み込んだSubstrateノード。[上流実装](https://github.com/paritytech/cumulus/tree/master/parachain-template)から派生。
- [`substrate-stencil`](https://github.com/kaichaosun/substrate-stencil) - ステーキングとガバナンスの機能を備えたSubstrateノードのテンプレート。
- [polkadot-js-api-ts-template](https://github.com/kianenigma/polkadot-js-api-ts-template) - `@polkadot/api`を使った開発を始めるためのテンプレートプロジェクト。
- [INK!athon](https://inkathon.xyz/) - ink!スマートコントラクトとReactフロントエンドを備えたフルスタックdAppのひな形。後述の`useInkathon`フックライブラリを利用し、[Scio Labs](https://scio.xyz)が保守。
- [Subsocial Starter Kit](https://docs.subsocial.network/docs/develop/developer-quickstart) - PolkadotエコシステムのWeb3ソーシャルアプリ向けスターターキット。[Subsocialブロックチェーン](https://subsocial.network)を利用。

## ツール <a id="tools"></a>

- [`offline-election`](https://github.com/paritytech/substrate-debug-kit/tree/master/offline-election) - Nominated Proof-of-Stake（NPoS）の選挙結果を予測するツール。
- [`offchain::ipfs`](https://rs-ipfs.github.io/offchain-ipfs-manual/) - Substrate に [IPFS](https://ipfs.io/) を統合したもの。
- [`polkadot-js-bundle`](https://github.com/shawntabrizi/polkadot-js-bundle) - Polkadot{JS} ライブラリを含むスタンドアローン JS バンドル。
- [`polkadot-launch`](https://github.com/shawntabrizi/polkadot-launch) - ローカルの Polkadot テストネットを起動するためのシンプルな CLI ツール。
- [`polkadot-runtime-prom-exporter`](https://github.com/paritytech/polkadot-runtime-prom-exporter/) - Polkadotランタイムのメトリクスを出力する[Prometheus](https://prometheus.io/)エクスポーター。Substrate向けに変更可能。
- [`polkadot-scripts`](https://github.com/paritytech/polkadot-scripts) - Parity が使用する Polkadot/Kusama の診断に用いるスクリプトのコレクション。
- [`polkadot-starship`](https://github.com/koute/polkadot-starship) - 大規模なテストネットの実行を重視した、ローカルPolkadotテストネットの起動ツール。
- [`srtool-actions`](https://github.com/chevdor/srtool-actions) - 独自ランタイムのビルドで`srtool` Dockerイメージを利用するためのGitHub Actions。
- [`srtool-cli`](https://github.com/chevdor/srtool-cli) - `srtool` Docker イメージの CLI フロントエンド。
- [`srtool`](https://github.com/paritytech/srtool) - 同じ入力から同じランタイムをビルドするためのDockerイメージ。
- [`subsee`](https://github.com/ascjones/subsee) - Substrate ノードのメタデータを JSON で確認する CLI ツール。
- [`subalfred`](https://github.com/hack-ink/subalfred) - Substrate開発の各種機能をまとめたツールボックス。
- [`substrate-balance-calculator`](https://github.com/shawntabrizi/substrate-balance-calculator) - Substrateアカウントの残高の内訳を表示。
- [`substrate-balance-graph`](https://github.com/shawntabrizi/substrate-balance-graph) - Substrateアドレスのトークン残高の推移をグラフ化。
- [`substrate-graph-benchmarks`](https://github.com/shawntabrizi/substrate-graph-benchmarks) - FRAMEパレットのベンチマーク出力のグラフ化。
- [`substrate-js-utils`](https://github.com/shawntabrizi/substrate-js-utilities) - Polkadot{JS} APIを利用するSubstrate向けJavaScriptユーティリティ集。[Webサイト版](https://www.shawntabrizi.com/substrate-js-utilities/)も利用できる。
- [`substrate-society`](https://github.com/shawntabrizi/substrate-society) - FRAME Societyパレット向けの基本的なフロントエンド。
- [`substrate-toml-lint`](https://github.com/shawntabrizi/substrate-toml-lint) - Substrateプロジェクトでよく見られるエラーを回避するtomlパーサーとチェックツール。
- [`subwasm`](https://github.com/chevdor/subwasm) - ランタイムのWASMバイナリをオフラインで調査するCLI。情報とメタデータの表示、ランタイム間の比較、ノードからの直接取得が可能。
- [`sup`](https://github.com/clearloop/sup) - Substrateノードの生成またはアップグレードに使うコマンドラインツール。
- [`scale-value`](https://github.com/paritytech/scale-value) - SCALE向けの`serde_json`に相当するライブラリ。任意のSCALEエンコード済みバイト列を動的な`Value`にデコードし、型情報は`scale-info`から取得。
- [`scale-decode`](https://github.com/paritytech/scale-decode) - ビジタートレイトを実装し、SCALEのバイト列を任意のカスタム型にデコード。
- [Aleph.im](https://aleph.im) - Substrateチェーンなどに対応する、スケーラブルで分散型のデータベース、ファイルストレージ、計算サービス。
- [Archive](https://github.com/paritytech/substrate-archive) - Substrateチェーン向けのインデックスエンジン。
- [Dev Hub Utils](https://github.com/danforbes/substrate-devhub-utils) - 公式Substrate Developer Hubの資料を扱うための非公式ユーティリティ。
- [Europa](https://github.com/patractlabs/europa) - Substrateランタイム実行環境のサンドボックス。
- [Fork Off Substrate](https://github.com/maxsam4/fork-off-substrate) - 新しいチェーンを立ち上げる際に、実行中のチェーンの状態を活用するスクリプト。
