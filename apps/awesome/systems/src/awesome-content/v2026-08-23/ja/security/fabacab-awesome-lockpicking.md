# コンテスト、会議、イベント

* [Chaos Communications Congress (CCC)](https://www.ccc.de/) - CCCはドイツのロックピッキング選手権を開催します。
* [DEF CON](https://defcon.org/) - ロックスポーツコンテストを特徴とし、多くのロックピッカーに人気の年次infosec業界会議。
* [Hackers On Planet Earth (HOPE)](https://hope.net/) - ロックスポーツの競技や物理セキュリティに関する発表を特徴とすることが多い年次会議。
* [OzSecCon](https://ozseccon.com/) - オーストラリアの物理セキュリティに焦点を当てたオープンコミュニティイベント。ロックピッキングと手錠回避コンテストを開催します。
* [LockCon](https://toool.nl/LockCon) - 評価の高いロックスポーツ組織の会員を対象とする、年次・招待制の錠に関する国際会議。

# ホビープロジェクト

* [3D Printed Lock Picks](http://blog.shop.23b.org/2014/11/3d-printed-lock-picks.html) - 弱いながらも最低数回の使用に耐えるプラスチック素材のロックピックを印刷します。([さらに多くのデジタルモデルを探す](https://www.yeggi.com/q/lockpick/)。)
* [DIY Lock Pick Set from a Windshield Wiper](http://www.itstactical.com/skillcom/lock-picking/how-to-make-a-diy-lock-pick-set-from-a-windshield-wiper/) - ワイパーからカスタムロックピックとテンションレンチを作る図解ガイド。
* [How to Make a Set of Lockpicks! (using street sweeper bristles)](https://www.instructables.com/id/How-to-Make-a-set-of-Lockpicks/) - 捨てられた道路清掃車の毛を、両面ターンツールとピックの素材として使う手順。
* [Making Tension Wrenches/Turning Tools From Old Windshield Wiper Blades](https://www.instructables.com/id/Making-Tension-WrenchesTurning-Tools-From-Old-Wind/) - 古いワイパーをさまざまなロックピックとターンツールのスタイルに変える手順。
* [Under Door Tool Kit Instructions](https://web.archive.org/web/20170719053154/http://enterthecore.net/files/CORE_Instructions-Under_Door.pdf) - 一般的なホームセンターで入手できる材料を使い、ドア下ツール（「lever opening」／「Mule」）を構築する短いガイド。
* [Lock Dice](http://schuylertowne.com/blog/lockpicking-with-dice) - このサイコロベースのロックスポーツゲームでは、駆け出しの錠メーカーとして、仲間に対して設計をテストします。

# ロックピッキングのハウツーガイド

* [Art of Lockpicking](https://art-of-lockpicking.com/) - 錠をピッキングする過程を詳述するアニメーション付き教育ウェブサイト。
* [Beginner's Guide to Security Pins](https://web.archive.org/web/20171210065243/http://www.ninjacache.com:80/secpins_intro) - 南京錠のピッキングに慣れた初心者を、より複雑な錠の理解へ導く短い記事。
* [BosnianBill's Lock Picking for Beginners](https://www.youtube.com/playlist?list=PLTSWkYxuSlkXiSBwk3Hvbvx71sg-MH61s) - 第一原理から特定の錠の技術まで順番に並べた、選りすぐりの教育動画のYouTubeプレイリスト。
* [CIA Lock Picking Field Operative Training Manual](https://archive.org/details/CIA_Lock_Picking_Field_Operative_Training_Manual) - 大多数のピン・ウェハータンブラー錠をピッキングするための用語、ツール使用、技術を扱うガイドブック。
* [Deviant Ollam's Lockpicking Video Presentations and Advisories](http://deviating.net/lockpicking/videos.html) - 世界的に有名な専門家による、全スキルレベル向けphysec講演とロックスポーツ助言のコレクション。
* [Easy Pickings - Mini Lockpicking Manual](http://index-of.es/Lockpicking/Easy%20Pickings%20-%20Mini%20Lockpicking%20Manual.pdf) - 各種入門レベルの錠をピッキングする方法を図で示す、広く配布された初心者マニュアル。
* [MIT Lock Picking Guide](https://webunraveling.com/public/mit-lock-picking-guide/index.php) - Ted the Toolによる有名な入門テキスト。
* [Lock Picking: Detail Overkill](https://web.archive.org/web/20170730120626/http://ninjacache.com/data/uploads/lockpicking-detail-overkill.pdf) - 「基礎以上を求める人」のための非常に徹底したガイド。
* [LockLab's Lock Picking Course](https://locklab.com/locklab-university/lock-picking-course-2/) - 基本的なテンショニングから特殊な錠の技術までを扱う完全な開始から終了までのコース。
* [Locksport International Guide to Lock Picking](https://web.archive.org/web/20070222144748/http://locksport.com:80/LSIGuide/lsiguide.pdf) - 写真と吹き出しを用いる、漫画本スタイルのロックスポーツ入門書。

# ロックスポーツの協会と組織

* [Fraternal Order of Lock Sport (FOOLS)](http://www.bloomingtonfools.org/) - インディアナ州ブルーミントンと周辺地域に奉仕するために設立されたロックピッキングクラブ。
* [The Open Organization Of Lockpickers (TOOOL)](https://toool.org/) - 国、地域、地元の支部を持つ世界的なロックピッカー協会。
* [Locksport International](http://locksport.com) - 新しいロックスポーツクラブやグループの立ち上げを支援するロックピッカーの国際協会。
* [Sportsfreunde der Sperrtechnik - Deutschland e.V.](https://blog.ssdev.org/) - ドイツのロックピッキングスポーツクラブ。ドイツのロックピッキング選手権を開催し、錠のピッキング方法に関するワークショップを提供します。

* [Lockpick Extreme](https://lockpickextreme.com/) - イヤリングなど、頑丈なツールとしても機能するジュエリーを特徴とする[ロックピッキングアクセサリー](https://lockpickextreme.com/product-category/accessories/)で注目される販売者。
* [Peterson Locksmith Tools / Peterson Manufacturing, Inc.](https://www.thinkpeterson.com/) - 精密ロックピッキングツールとアクセサリーのメーカー。top-of-keywayのターンツールは有名ですが高価です（自作できます）。
* [Safe Ventures, Inc.](http://safeventures.com/) - 有料トレーニングコースも提供する金庫開錠ツールの販売者。
* [Security Snobs](https://securitysnobs.com/) - 多数の高セキュリティ、コレクター向け、カットアウェイ錠を扱い、錠前技術についての情報ページも保守する販売者。
* [Southern Ordinance / Exit 10, Inc.](https://www.southord.com/) - SouthOrd®はロックピックとプロ向け鍵屋ツールのメーカー。個別交換用ピックは1.50米ドルから。
* [Southern Specialities](http://www.lockpicktools.com/) - 多数のロックピッキングセット、ピックガンなどの販売者。
* [Sparrows Lock Picks](https://www.sparrowslockpicks.com/) - 専門的で品質の高いロックピックツールのメーカー。[King Pin](http://www.sparrowslockpicks.com/product_p/t1.htm)ピニングツイーザーは特に便利です。
* [Spooxe](http://spooxe.com/) - ロックピッキングツール、ツールケース、錠を扱うドイツの販売者。
