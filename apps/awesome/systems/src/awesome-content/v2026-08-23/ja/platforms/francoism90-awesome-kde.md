## アプリケーション

ヒント: よく使われる KDE コミュニティアプリの概要は[公式サイト](https://apps.kde.org/)に掲載されています。

### インターネットとネットワーク

- [Akregator](https://apps.kde.org/akregator/) - ニュースサイト、ブログ、その他の RSS/Atom 対応ウェブサイトを購読できます 📌。
- [Falkon](https://www.falkon.org/) - QtWebEngine ベースのクロスプラットフォームウェブブラウザー 📌。
- [Firefox KDE](https://build.opensuse.org/package/show/mozilla:Factory/MozillaFirefox) - OpenSUSE パッチにより KDE との統合を改善した、mozilla.org のスタンドアロンウェブブラウザー。
- [GSConnect](https://extensions.gnome.org/extension/1319/gsconnect/) - Nautilus、Chrome、Firefox との統合を備え、特に GNOME Shell 向けに実装された完全な KDE Connect。
- [KDE Connect](https://kdeconnect.kde.org/) - デスクトップで電話の通知を受け取り、電話からデスクトップを操作するなど、すべてのデバイス間で通信するプロジェクト 📌。
- [KGet](https://apps.kde.org/kget/) - 多機能で使いやすいダウンロードマネージャー 📌。
- [KMail](https://apps.kde.org/kmail2/) - KDE の統合個人情報マネージャーである Kontact のメールコンポーネント 📌。
- [KNetworkManager](https://userbase.kde.org/KNetworkManager) - バックエンドの NetworkManager ソフトウェア用 KDE クライアント 📌。
- [Konqueror](https://konqueror.org/) - KHTML レンダリングエンジン（および任意で Webkit）を使い、HTML5、JavaScript、CSS3 などの最新ウェブ標準をサポートします 📌。
- [Konversation](https://konversation.kde.org/) - KDE プラットフォーム上に構築された、使いやすい Internet Relay Chat (IRC) クライアント 📌。
- [KRDC](https://apps.kde.org/krdc/) - 互換サーバーを稼働する別マシンのデスクトップセッションを表示・操作できるクライアントアプリケーション (VNC & RDP) 📌。
- [KTorrent](https://apps.kde.org/ktorrent/) - BitTorrent プロトコルでファイルをダウンロードできる BitTorrent アプリケーション 📌。
- [NeoChat](https://apps.kde.org/neochat/) - KDE 向け Matrix ネットワーククライアント 📌。
- [Otter Browser](https://otter-browser.org/) - Qt5 を用い、クラシックな Opera (12.x) UI の優れた点の再現を目指すブラウザー。
- [Plasma-browser-integration](https://userbase.kde.org/Plasma-browser-integration) - [Firefox](https://addons.mozilla.org/en-US/firefox/addon/plasma-integration/)、[Chrome](https://chrome.google.com/webstore/detail/plasma-integration/cimiefiiaegbelhefglklhhakcgmhkai)、Chromium ベースのブラウザーをデスクトップと連携させる新機能群 📌。
- [qBittorrent](https://www.qbittorrent.org/) - Qt ツールキットと libtorrent-rasterbar を基盤に C++ でプログラムされた高機能 BitTorrent クライアント。
- [Qt WebBrowser](http://doc.qt.io/QtWebBrowser/) - Qt と Qt WebEngine の機能で開発された組み込みデバイス向けブラウザー。
- [Smb4K](https://apps.kde.org/en/smb4k) - 高度なネットワーク近傍ブラウザーおよび Samba 共有マウントユーティリティ 📌。
- [Tokodon](https://apps.kde.org/pt-br/tokodon/) - Fediverse コミュニティとやり取りできる Mastodon クライアント 📌。 

### グラフィックスと画像

- [digiKam](https://www.digikam.org/) - オープンソースの力を活用したプロフェッショナルな写真管理 📌。
- [Gwenview](https://apps.kde.org/gwenview/) - KDE による高速で使いやすい画像ビューアー 📌。
- [KColorChooser](https://apps.kde.org/kcolorchooser/) - 画面またはパレットから色を選ぶシンプルなアプリケーション 📌。
- [KolourPaint](https://apps.kde.org/kolourpaint/) - ラスター画像をすばやく作成するシンプルなペイントプログラム。レタッチツールや簡単な画像編集作業に役立ちます 📌。
- [Krita](https://apps.kde.org/krita/) - コンセプトアーティスト、イラストレーター、マット・テクスチャアーティスト、VFX 業界向けに設計されたペイントツール 📌。
- [Okular](https://apps.kde.org/okular/) - 汎用ドキュメントビューアー 📌。
- [Spectacle](https://apps.kde.org/spectacle/) - デスクトップのスクリーンショットを撮影するアプリケーション 📌。

### マルチメディア

- [Amarok](https://amarok.kde.org/) - 直感的なインターフェースを備えた Linux、Unix、Windows 向けの強力な音楽プレーヤー 📌。
- [Elisa](https://elisa.kde.org/) - シンプルで快適な使い心地を目指して KDE コミュニティが開発した音楽プレーヤー 📌。

- [KCast](https://github.com/Agundur-KDE/KCast) - 動画ファイルまたは YouTube URL を Chromecast デバイスへキャストする Plasma 6 ウィジェット。
- [Kdenlive](https://www.kdenlive.org/) - MLT ビデオフレームワークを用いる Linux 向けノンリニア動画エディター。
- [KMix](https://apps.kde.org/kmix/) - サウンドチャンネルミキサーと音量コントロール 📌。
- [KWave](https://apps.kde.org/kwave/) - KDE Frameworks 5 上に構築されたサウンドエディター 📌。
- [SMPlayer](https://www.smplayer.info/) - ほぼすべての動画・音声形式を再生できる組み込みコーデック付きメディアプレーヤー。
- [VLC](https://www.videolan.org/vlc/) - ほとんどのマルチメディアファイルとさまざまなストリーミングプロトコルを再生できる、自由・オープンソースのクロスプラットフォームマルチメディアプレーヤーおよびフレームワーク。

- [Kraft](https://volle-kraft-voraus.de/) - 小規模事業での請求書などの文書処理を簡素化します。

### システム管理

- [Discover](https://apps.kde.org/discover/) - アプリ・アドオンのインストールや更新に端末が最適な解決策ではないユーザーとディストリビューション向け 📌。
- [Dolphin](https://apps.kde.org/dolphin/) - KDE デスクトップに含まれるファイルマネージャー 📌。
- [KDiskFree](https://apps.kde.org/kdf/) - 利用可能なファイルデバイス（ハードドライブパーティション、ドライブなど）と、その容量・空き容量・種類・マウントポイントを表示します 📌。
- [KInfoCenter](https://userbase.kde.org/KInfoCenter) - コンピューターシステムの詳細情報を提供するユーティリティ 📌。
- [Konsole](https://apps.kde.org/konsole/) - KDE デスクトップに含まれる端末エミュレーター 📌。
- [Krusader](https://krusader.org/) - KDE 向けの高度なツインパネル（コマンダー形式）ファイルマネージャー 📌。
- [KSystemLog](https://apps.kde.org/ksystemlog/) - システムログビューアーツール 📌。
- [Kup](https://apps.kde.org/kup/) - KDE の Plasma デスクトップ向けバックアップスケジューラー 📌。
- [Sweeper](https://apps.kde.org/sweeper/) - ユーザーがシステムに残した不要な痕跡を消去し、未使用の一時ファイルを削除してディスク容量を回復します 📌。
- [Yakuake](https://apps.kde.org/yakuake/) - KDE の Konsole 技術を基盤にしたドロップダウン型端末エミュレーター 📌。

### ユーティリティとツール

- [Android File Transfer](https://whoozle.github.io/android-file-transfer-linux/) - 最小限の UI を備えた信頼性の高い MTP クライアント。
- [Ark](https://apps.kde.org/ark/) - アーカイブツール 📌。
- [dictee](https://github.com/rcspam/dictee) - KDE Plasma 6 プラズモイド、PyQt6 セットアップウィザード、トレイアイコンを備えるプッシュ・ツー・トーク音声入力。4 つの ASR バックエンド（Parakeet、Vosk、Whisper、Canary）、後処理パイプライン、翻訳を備えます。100% ローカル、25 以上の言語に対応。
- [fancontrol-gui](https://github.com/Maldela/fancontrol-gui) - lm_sensors の一部である fancontrol 向け GUI。
- [KDE Wallet Manager](https://invent.kde.org/utilities/kwalletmanager/) - KDE システム上のパスワードを管理します。KDE Wallet サブシステムは、KDE Wallet と統合するすべてのアプリケーションのアクセスおよびパスワード管理を可能にします 📌。
- [KeePassXC](https://keepassxc.org/) - Keepass パスワードマネージャーのクロスプラットフォームなコミュニティ主導ポート。
- [KFind](https://apps.kde.org/kfind/) - KRunner またはメニューから起動するスタンドアロンの検索ツール。Konqueror の「Tools」メニューの「Find File」にも統合されています 📌。
- [KRename](https://apps.kde.org/krename/) - 複数ファイルの名前を変更するユーティリティ 📌。
- [KWin-lowlatency](https://github.com/tildearrow/kwin-lowlatency) - KDE で利用される人気の KWin コンポジターのレイテンシーとスタッタリングを低減する試み。
- [KWinFT](https://gitlab.com/kwinft/kwinft) - Wayland コンポジターおよび X11 ウィンドウマネージャー。
- [LocalTranslate](https://github.com/terslang/LocalTranslate) - Firefox の[ニューラル翻訳モデル](https://github.com/mozilla/firefox-translations-models)を利用する Qt Quick 製オフライン翻訳アプリ。
- [QOwnNotes](https://www.qownnotes.org/) - クラウド統合、ウェブ・モバイル対応を備えるノートアプリ。
- [QtPass](https://qtpass.org/) - [pass](https://www.passwordstore.org/) 向けマルチプラットフォーム GUI。
- [Wacom GUI](https://github.com/tb2097/wacom-gui) - KDE 向け Python/PyQt Wacom GUI。
- [Yin-Yang](https://github.com/daehruoydeef/Yin-Yang) - Linux 向け自動ナイトモード。
