# Awesome Windows

Windows向けの開発、メディア、通信、作業効率化、セキュリティ、システム管理のアプリとツールをまとめています。オープンソース・有料の表示は固定原文に従い、無印は無料または非公開ソースを意味しません。機能・提供状況・料金・評価は原文時点の記述です。

上流の管理者は「vibecoded」と呼ぶツールを除外し、「awesome」という選定基準を満たすことを求めています。
