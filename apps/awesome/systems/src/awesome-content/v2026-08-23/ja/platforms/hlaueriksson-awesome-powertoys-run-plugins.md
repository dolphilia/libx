## プラグイン

- [GEmojiSharp](https://github.com/hlaueriksson/GEmojiSharp#gemojisharppowertoysrun) - GitHub 絵文字を検索・コピーします。
- [Everything](https://github.com/lin-ycv/EverythingPowerToys) - Everything を使いファイルとフォルダーを即座に見つけます。
- [PowerTranslator](https://github.com/N0I0C0K/PowerTranslator) - Youdao Translation を使いテキストを翻訳します。
- [WinGet](https://github.com/bostrot/PowerToysRunPluginWinget) - WinGet を使い Windows パッケージをインストール・管理します。
- [Lorem](https://github.com/dxn-9/prun-lorem) - lorem ipsum テキストを生成します。
- [TOTP](https://github.com/KawaiiZapic/PowertoysRunTOTP) - 時間ベースの二要素認証コードをコピーします。
- [Scoop](https://github.com/Quriz/PowerToysRunScoop) - Scoop を使い Windows パッケージをインストール・管理します。
- [InputTyper](https://github.com/CoreyHayward/PowerToys-Run-InputTyper) - キーボードから送られたようにテキストを入力します。
- [CurrencyConverter](https://github.com/Advaith3600/PowerToys-Run-Currency-Converter) - 最新の為替レートで通常通貨と暗号通貨を換算します。
- [EdgeFavorite](https://github.com/davidegiacometti/PowerToys-Run-EdgeFavorite) - Microsoft Edge のお気に入りを開きます。
- [GitKraken](https://github.com/davidegiacometti/PowerToys-Run-GitKraken) - GitKraken リポジトリを開きます。
- [VisualStudio](https://github.com/davidegiacometti/PowerToys-Run-VisualStudio) - Visual Studio の最近のソリューションを開きます。
- [ClipboardManager](https://github.com/CoreyHayward/PowerToys-Run-ClipboardManager) - クリップボード履歴から検索・貼り付けを行います。
- [GitHubRepo](https://github.com/8LWXpg/PowerToysRun-GitHubRepo) - GitHub リポジトリを開きます。
- [ProcessKiller](https://github.com/8LWXpg/PowerToysRun-ProcessKiller) - Windows プロセスを終了します。
- [WebSearchShortcut](https://github.com/Daydreamer-riri/PowerToys-Run-WebSearchShortcut) - あらかじめ定義した検索エンジンで検索します。
- [UnicodeInput](https://github.com/nathancartlidge/powertoys-run-unicode) - Agda 風の短縮表記で Unicode 文字を検索・コピーします。
- [Timer](https://github.com/CoreyHayward/PowerToys-Run-Timer) - タイマーを設定・管理します。
- [HexInspector](https://github.com/NaroZeol/PowerHexInspector) - 数値を基数間で変換します。
- [LocalLLM](https://github.com/Darkdriller/PowerToys-Run-LocalLLm) - Ollama を使いローカル LLM モデルをクエリします。
- [JohnnyDecimal](https://github.com/seguri/PowerToys-Run-JohnnyDecimal) - JohnnyDecimal システムを操作します。
- [BrowserFavorite](https://github.com/Der-Penz/PowerToys-Run-BrowserFavorite) - ブラウザーのブックマークをすばやく開きます。
- [Universal Search Suggestions](https://github.com/Fefedu973/PowerToys-Run-Universal-Search-Suggestions-Plugin/) - 何かを入力した際に検索候補を追加します。
- [Bang](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#bang) - DuckDuckGo !Bang でウェブサイトを検索します。
- [DenCode](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#dencode) - エンコードとデコード。
- [Dice](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#dice) - ロールプレイング用サイコロローラー。
- [Need](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#need) - 重要情報のキー・バリューストア。
- [Twitch](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#twitch) - Twitch のストリームを閲覧、検索、表示します。
- [SVGL](https://github.com/SameerJS6/powertoys-svgl) - svgl 経由で SVG ロゴを閲覧、検索、コピーします。
- [QuickNotes](https://github.com/ruslanlap/CommunityPowerToysRunPlugin-QuickNotes) - ノートを作成、管理、検索します。
- [SpeedTest](https://github.com/ruslanlap/PowerToysRun-SpeedTest) - インターネット接続速度をテストします。
- [VideoDownloader](https://github.com/ruslanlap/PowerToysRun-VideoDownloader) - さまざまなプラットフォームから動画をダウンロードします。
- [Definition](https://github.com/ruslanlap/PowerToysRun-Definition) - 単語の定義、発音、類義語を検索します。
- [RandomGen](https://github.com/ruslanlap/PowerToysRun-RandomGen) - さまざまな種類のランダムデータを生成します。
- [Hotkeys](https://github.com/ruslanlap/PowerToysRun-Hotkeys) - さまざまなアプリケーションのキーボードショートカットを検索・コピーします。
- [TemplateRunner](https://github.com/Heck-R/PowerToys.Run.Plugin.TemplateRunner) - シンプルなコマンドとスクリプトをミニプラグインとして使います。
