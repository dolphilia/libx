# Awesome PowerToys Run Plugins<a id="目次"></a><a id="貢献"></a>

[PowerToys Run](https://learn.microsoft.com/en-us/windows/powertoys/run)は、プラグインで拡張できるWindows向けのオープンソースのクイックランチャーです。コミュニティ製プラグイン、インストール用ツール、開発資料、手順を解説した記事を探せます。機能説明は固定原文の記載に基づきます。

## 公式 <a id="official"></a>

- [公式サイト](https://learn.microsoft.com/en-us/windows/powertoys/run)
- [リポジトリ](https://github.com/microsoft/PowerToys)
- [Microsoft Store](https://apps.microsoft.com/detail/xp89dcgq3k6vld)

## インストール <a id="installation"></a>

コミュニティプラグインをインストールする前に、[セキュリティ方針](https://github.com/hlaueriksson/awesome-powertoys-run-plugins/blob/d8108fdfad591844cc30dd56bcbe0a47d023148f/security.md)をお読みください。

下記のコミュニティプラグインは[Install](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugin.Install)プラグイン経由でインストールできます。

- [Community.PowerToys.Run.Plugin.Install](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugin.Install) - このリストに掲載されたコミュニティ製PowerToys Runプラグインをインストール。

## プラグイン <a id="plugins"></a>

- [GEmojiSharp](https://github.com/hlaueriksson/GEmojiSharp#gemojisharppowertoysrun) - GitHubの絵文字を検索・コピー。
- [Everything](https://github.com/lin-ycv/EverythingPowerToys) - Everythingを使い、ファイルとフォルダーを即座に検索。
- [PowerTranslator](https://github.com/N0I0C0K/PowerTranslator) - Youdao Translationを使いテキストを翻訳。
- [WinGet](https://github.com/bostrot/PowerToysRunPluginWinget) - WinGetを使いWindowsパッケージをインストール・管理。
- [Lorem](https://github.com/dxn-9/prun-lorem) - lorem ipsumのダミーテキストを生成。
- [TOTP](https://github.com/KawaiiZapic/PowertoysRunTOTP) - 時間ベースの二要素認証コードをコピー。
- [Scoop](https://github.com/Quriz/PowerToysRunScoop) - Scoopを使いWindowsパッケージをインストール・管理。
- [InputTyper](https://github.com/CoreyHayward/PowerToys-Run-InputTyper) - キーボードで入力するようにテキストを入力。
- [CurrencyConverter](https://github.com/Advaith3600/PowerToys-Run-Currency-Converter) - 最新の為替レートで法定通貨と暗号通貨を換算。
- [EdgeFavorite](https://github.com/davidegiacometti/PowerToys-Run-EdgeFavorite) - Microsoft Edgeのお気に入りを開く。
- [GitKraken](https://github.com/davidegiacometti/PowerToys-Run-GitKraken) - GitKrakenのリポジトリを開く。
- [VisualStudio](https://github.com/davidegiacometti/PowerToys-Run-VisualStudio) - Visual Studioで最近使ったソリューションを開く。
- [ClipboardManager](https://github.com/CoreyHayward/PowerToys-Run-ClipboardManager) - クリップボードの履歴を検索し、貼り付け。
- [GitHubRepo](https://github.com/8LWXpg/PowerToysRun-GitHubRepo) - GitHubリポジトリを開く。
- [ProcessKiller](https://github.com/8LWXpg/PowerToysRun-ProcessKiller) - Windowsのプロセスを終了。
- [WebSearchShortcut](https://github.com/Daydreamer-riri/PowerToys-Run-WebSearchShortcut) - あらかじめ定義された検索エンジンで検索。
- [UnicodeInput](https://github.com/nathancartlidge/powertoys-run-unicode) - Agda風の短縮表記でUnicode文字を検索・コピー。
- [Timer](https://github.com/CoreyHayward/PowerToys-Run-Timer) - タイマーを設定・管理。
- [HexInspector](https://github.com/NaroZeol/PowerHexInspector) - 数値を異なる基数の表記へ変換。
- [LocalLLM](https://github.com/Darkdriller/PowerToys-Run-LocalLLm) - Ollamaを使いローカルLLMモデルに問い合わせ。
- [JohnnyDecimal](https://github.com/seguri/PowerToys-Run-JohnnyDecimal) - JohnnyDecimalの整理体系をたどる。
- [BrowserFavorite](https://github.com/Der-Penz/PowerToys-Run-BrowserFavorite) - ブラウザーのブックマークをすばやく開く。
- [Universal Search Suggestions](https://github.com/Fefedu973/PowerToys-Run-Universal-Search-Suggestions-Plugin/) - 入力時に検索候補を表示。
- [Bang](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#bang) - DuckDuckGoの!Bangsでウェブサイトを検索。
- [DenCode](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#dencode) - エンコードとデコード。
- [Dice](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#dice) - ロールプレイング用のサイコロを振る。
- [Need](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#need) - 重要な情報を保存するキーバリューストア。
- [Twitch](https://github.com/hlaueriksson/Community.PowerToys.Run.Plugins#twitch) - Twitchの配信を閲覧・検索・視聴。
- [SVGL](https://github.com/SameerJS6/powertoys-svgl) - svglを使いSVGロゴを閲覧・検索・コピー。
- [QuickNotes](https://github.com/ruslanlap/CommunityPowerToysRunPlugin-QuickNotes) - メモを作成・管理・検索。
- [SpeedTest](https://github.com/ruslanlap/PowerToysRun-SpeedTest) - インターネット接続の速度を測定。
- [VideoDownloader](https://github.com/ruslanlap/PowerToysRun-VideoDownloader) - さまざまなプラットフォームの動画をダウンロード。
- [Definition](https://github.com/ruslanlap/PowerToysRun-Definition) - 単語の定義・発音表記・類義語を調べる。
- [RandomGen](https://github.com/ruslanlap/PowerToysRun-RandomGen) - さまざまな種類のランダムなデータを生成。
- [Hotkeys](https://github.com/ruslanlap/PowerToysRun-Hotkeys) - 各種アプリケーションのキーボードショートカットを検索・コピー。
- [TemplateRunner](https://github.com/Heck-R/PowerToys.Run.Plugin.TemplateRunner) - 簡単なコマンドやスクリプトを小さなプラグインとして使用。
