# Awesome AWS

AWSのSDK、コマンドライン・IDEツール、オープンソースのプロジェクトを言語やサービス別に探せます。ガイド、書籍、トレーニング、コミュニティの情報源、過去の統計、サービスの付録も掲載しています。

各リポジトリのスター数は、固定原文が記録した下限値（100以上、200以上、500以上、1000以上、2000以上）を示します。現在の件数や品質を保証するものではありません。原文には[リポジトリの選定条件](https://github.com/donnemartin/awesome-aws/blob/master/CONTRIBUTING.md#a-note-on-repo-awsomeness)も記されています。

### <a id="compute-services"></a>コンピューティングサービス

* [Auto Scaling](https://aws.amazon.com/autoscaling/) - ポリシー、スケジュール、ヘルスチェックに基づいてEC2インスタンスの起動または終了を実行する
* [Batch](https://aws.amazon.com/batch/) - 大規模なバッチジョブを実行する
* [Blox](https://blox.github.io/) - ECS上でカスタムスケジューラを構築するためのオープンソースプロジェクトである
* [EC2 Container Service (ECS)](https://aws.amazon.com/ecs/) - EC2インスタンス上でDockerコンテナをサポートする
* [EC2 Systems Manager](https://aws.amazon.com/ec2/systems-manager/) - EC2およびオンプレミスシステムの簡単な設定と管理を実現する
* [Elastic Beanstalk](https://aws.amazon.com/elasticbeanstalk/) - クラウド上でのアプリケーションの迅速なデプロイと管理を提供する
* [Elastic Compute Cloud (EC2)](http://aws.amazon.com/ec2/) - Xenを使用したスケーラブルな仮想プライベートサーバーを提供する
* [Elastic GPUs](https://aws.amazon.com/ec2/Elastic-GPUs/) - EC2インスタンスに低コストのGPUを接続し、グラフィックスアクセラレーションを実現する
