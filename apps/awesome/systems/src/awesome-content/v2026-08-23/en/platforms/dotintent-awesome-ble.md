# Awesome BLE

Bluetooth Low Energy (BLE) is a low-power wireless protocol for exchanging data in IoT, wearables and other battery-powered devices. Find protocol guides, libraries and tools for mobile, web and embedded development, hardware resources, security references and case studies.

## Documentation

Protocol documentation, introductions and development guides for Bluetooth Low Energy (BLE).

- [Android Bluetooth Low Energy](https://developer.android.com/guide/topics/connectivity/bluetooth/ble-overview) - Overview of BLE on Android.
- [Developing a Bluetooth Low Energy Application by TI](https://software-dl.ti.com/lprf/simplelink_cc2640r2_sdk/1.35.00.33/exports/docs/ble5stack/ble_user_guide/html/ble-stack/index.html) - A TI guide to developing a BLE application.
- [Getting Started with Bluetooth Low Energy (BLE)](https://learn.adafruit.com/introduction-to-bluetooth-low-energy) - A guide to getting started with Bluetooth Low Energy development.
- [Intro to Bluetooth Generic Attribute Profile (GATT)](https://www.bluetooth.com/bluetooth-resources/intro-to-bluetooth-gap-gatt/) - An introduction to GATT.
- [Intro to Bluetooth Low Energy](https://www.bluetooth.com/bluetooth-resources/intro-to-bluetooth-low-energy/) - An introduction to BLE basics.
- [IoT for Beginners](https://microsoft.github.io/IoT-For-Beginners/#/) - A 12-week, 24-lesson curriculum on IoT basics from Microsoft Azure Cloud Advocates.
- [nRF51 SDK](https://www.nordicsemi.com/Software-and-tools/Software/nRF5-SDK) - An SDK for developing Bluetooth Low Energy applications on Nordic Semiconductor’s nRF51 series of chips.
- [RN4870/71 Bluetooth Low Energy Module User's Guide](https://www.microchip.com/wwwproducts/en/RN4870) - A user guide for the RN4870/71 Bluetooth Low Energy module from Microchip.
- [Wikipedia Bluetooth Low Energy](https://en.wikipedia.org/wiki/Bluetooth_Low_Energy) - The Wikipedia page for Bluetooth Low Energy (BLE).

## Library

Libraries and frameworks for integrating BLE into mobile applications, embedded systems and IoT devices.

- [bluepy](https://github.com/IanHarvey/bluepy) - A Python interface for Bluetooth LE on Linux.
- [Bluetooth](https://github.com/PureSwift/Bluetooth) - A multiplatform Swift package with multiple libraries supporting Bluetooth SIG specifications.
- [bluez](http://www.bluez.org/) - The official Linux Bluetooth protocol stack.
- [bumble](https://github.com/google/bumble) - A Bluetooth stack written entirely in Python.
- [pygatt](https://github.com/peplin/pygatt) - A Python library for interacting with BLE devices.
- [SimpleBLE](https://github.com/OpenBluetoothToolbox/SimpleBLE) - A C/C++/Python/Rust Bluetooth LE library for macOS, iOS, Windows and Linux.
- [Moddable](https://github.com/Moddable-OpenSource/moddable) - JavaScript libraries and tools for microcontroller development, including BLE functionality.

## iOS

iOS libraries, tools and resources for developing BLE applications on Apple devices.

- [AsyncBluetooth](https://github.com/manolofdez/AsyncBluetooth) - A small library that adds concurrency to CoreBluetooth APIs.
- [CombineCoreBluetooth](https://github.com/StarryInternet/CombineCoreBluetooth) - A library bridging Apple’s CoreBluetooth and Combine frameworks.
- [iOS DFU Library](https://github.com/NordicSemiconductor/IOS-DFU-Library) - A DFU application for flashing new firmware on the development kit (DK).
- [Rx Bluetooth Kit](https://github.com/Polidea/RxBluetoothKit) - A Bluetooth library for interacting with BLE devices using RxSwift.
- [Swifty Sensors](https://github.com/codeinversion/sensors-swift) - A Bluetooth LE sensor manager for iOS and macOS.
- [SpeziBluetooth](https://github.com/StanfordSpezi/SpeziBluetooth) - Connect and communicate with Bluetooth devices using modern programming paradigms.

## Android

Android libraries, tools and resources for integrating BLE into applications.

- [Android BluetoothGatt Sample](https://github.com/android/connectivity-samples/tree/main/BluetoothLeGatt) - An example application demonstrating the BluetoothGatt API on Android.
- [android-BluetoothChat](https://github.com/googlesamples/android-BluetoothChat) - An Android Bluetooth chat application.
- [FastBle](https://github.com/Jasonchenlijian/FastBle) - An Android Bluetooth Low Energy (BLE) development framework.
- [Nordic Semiconductor BLE SDK for Android](https://github.com/NordicSemiconductor/Android-BLE-Library) - The official Bluetooth Low Energy SDK from Nordic Semiconductor for Android development.
- [RxAndroidBle](https://github.com/dariuszseweryn/RxAndroidBle) - An Android Bluetooth Low Energy (BLE) library with an RxJava3 interface.
- [SmartGattLib](https://github.com/movisens/SmartGattLib) - A Java library for working with Bluetooth SMART devices (also called Bluetooth Low Energy in Bluetooth 4.0). It provides all UUIDs of the adopted GATT specification and a way to interpret characteristics such as Heart Rate and BatteryLevel.

## Tool

Development and testing tools for BLE applications, including analyzers, debuggers and simulators.

- [Bettercap](https://github.com/bettercap/bettercap) - An extensible, portable framework for security researchers to test BLE security.
- [nRF Connect](https://github.com/NordicSemiconductor/pc-nrfconnect-core) - An application framework for developing, testing and provisioning devices based on Nordic Semiconductor chips.
- [BLE Simulator](https://play.google.com/store/apps/details?id=com.withintent.ble.simulator&hl=en) - A mobile app that can clone BLE devices and script their interactions, for debugging and rapid prototyping.
- [PacketLogger](https://www.bluetooth.com/blog/a-new-way-to-debug-iosbluetooth-applications/) - A macOS tool to capture BLE packets and HCI logs from iOS devices for debugging Bluetooth communication and protocol issues.
