# Awesome Robotic Tooling

Tools for professional robotics development in C++ and Python, including ROS, autonomous driving, and aerospace. The list covers open and free software and hardware tools for requirements, architecture, development, simulation, sensing, planning, control, and deployment, helping developers find and reuse existing tools.
