## 教育 <a id="education"></a>

### 入門 <a id="entry-point"></a>
- [learn](https://learn.adacore.com/) - インタラクティブな学習プラットフォームで、AdaとSPARKのプログラミング言語を学ぶためのもの。
- [ada-lang-io](https://ada-lang.io) - Adaのコミュニティサイト。
- [celebrating-ada](https://www.celebratingada.com/) - Adaの歴史における重要な出来事。
- [ada-logo-editor](https://ada-lang-io.github.io/ada-logo-editor/) - Adaの「ホライズン」ロゴ作成サイト。

## コンパイラー <a id="compilers"></a>

### オープンソース <a id="open-source"></a>

#### GPL（リンク例外あり） <a id="commercial--open-source"></a>

- [fsf-gnat](https://github.com/alire-project/GNAT-FSF-builds/releases) - GNU Compiler Collectionの一部を構成するFree Software Foundation製Adaコンパイラー。Ada 2022、2012、2005、95、83の全バージョンに対応する。

#### MIT <a id="commercial--closed-source"></a>

- [hac](https://github.com/zertovitch/hac) - HAC Adaコンパイラ - 小規模で高速な、完全にAdaで構成されたAdaコンパイラ
- [byron](https://github.com/OneWingedShark/Byron) - Adaコンパイラ、ツールチェーン、IDEシステムを構築するコミュニティプロジェクト

#### Apache License <a id="online"></a>

- [augusta](https://github.com/pchapin/augusta) - Scalaで書かれ、LLVMをターゲットとするAdaコンパイラー。

### 商用／オープンソース <a id="edit"></a>

- [gnat-pro](https://www.adacore.com/gnatpro) - GNAT Pro製品ラインは、Ada、C、C++向けに包括的なツールセット（IDE、デバッガー、ライブラリ、動的および静的解析ツール）を提供している.

### 商用／クローズドソース <a id="integrated-development-editors"></a>

- [janus-ada](http://www.rrsoftware.com/html/prodinf/janus95/j-ada95.htm) - Ada 83、Ada 95、Ada 2、Ada 2012の各バージョンにおける言語の主要機能をサポートするコンパイラ
- [object-ada](https://www.ptc.com/en/products/developer-tools/objectada) - PTC ObjectAdaは、ネイティブおよびクロス開発ツールおよびランタイム環境を構成する広範なファミリです
- [apex-ada](https://www.ptc.com/en/products/developer-tools/apexada) - PTC ApexAdaは、Adaおよび混合Ada/C/C++アプリケーション向けに業界で最も人気のある開発環境の一つです
- [greenhills-ada](https://www.ghs.com/products/ada_optimizing_compilers.html) - グリーンヒルズソフトウェアは、リアルタイムターゲット向けに業界初の完全に検証されたAdaクロスコンパイラファミリを提供しています

### オンライン <a id="editors"></a>
- [tutorials-point-ada-compiler](https://www.tutorialspoint.com/compile_ada_online.php) - CodingGroundエンジンに基づくオンラインコンパイラ
- [jdoodle-ada-compiler](https://www.jdoodle.com/execute-ada-online) - 複数バージョンのGNATをテストできるオンラインコンパイラ
- [compiler-explorer](https://godbolt.org/) - ウェブブラウザからGNAT FSFコンパイラをインタラクティブに実行し、アセンブリとのインタラクションを提供します

#### GPL（リンク例外なし） <a id="text-modes"></a>

- [gnat-ce (discontinued)](https://github.com/AdaCore/gnat-community-archives) - GNAT Community版。フリーソフトウェア開発者、ホビイスト、学生向けのAdaCore GNATで、ランタイムライブラリはリンク例外なしのGPLv3。Ada 2012のみに対応する。

## デプロイ <a id="os-and-kernels"></a>

### ビルドとパッケージ <a id="games"></a>
- [alire](https://github.com/alire-project/alire) - 即時使用可能なAdaライブラリのカタログおよびコマンドラインツール（alr）を提供し、それらを自プロジェクトに取り込むことができます。これはRustのcargoまたはOCamlのopamに類似した役割を果たすことを目指しています
- [alr2appimage](https://github.com/mgrojo/alr2appimage) - Alireのパッケージから自動的にAppImage実行ファイルを作成するツール
