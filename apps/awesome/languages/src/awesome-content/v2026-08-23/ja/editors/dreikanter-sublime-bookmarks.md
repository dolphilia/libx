<a id="extensions"></a>
## 拡張機能

現在も開発され、Sublime Text 3をサポートしているプロジェクトだけを掲載しています。

<a id="general-purpose"></a>
### 汎用

- [All Autocomplete](https://github.com/alienhard/SublimeAllAutocomplete) — デフォルトの自動補完をすべて開いているファイルにマッチを検索できるように拡張します
- [ApplySyntax](https://github.com/facelessuser/ApplySyntax) — ファイルの構文を検出・適用できるプラグインです。たとえば、.rb拡張子のファイルは通常Rubyファイルですが、Railsプロジェクト内に存在する場合、RSpecのspecファイル、Cucumberのステップファイル、Ruby on Railsファイル（コントローラー、モデルなど）または単純なRubyファイルになる可能性があります
- [EditorConfig](https://github.com/sindresorhus/editorconfig-sublime) — .editorconfigのサポート
- [File Navigator](https://github.com/csch0/SublimeText-File-Navigator) — キーボードに優しいファイルナビゲーターとマネージャー
- [FindKeyConflicts](https://github.com/skuroda/FindKeyConflicts) — 競合するキーマップを検出
- [GitGutter](https://github.com/jisaacks/GitGutter) — ガターにGitの差分を表示できるプラグイン
- [GitSavvy](https://packagecontrol.io/packages/GitSavvy) — gitおよびGitHubとの統合
- [Glue](https://github.com/chrissimpkins/glue) — Sublime Text 2および3用のマルチプラットフォームかつ拡張可能なプラグインで、あなたの好きなエディタをシェルに接続します
- [LSP](https://packagecontrol.io/packages/LSP) — Sublime Text 3におけるLanguage Server Protocolのサポートにより、IDE機能を提供します
- [Origami](https://github.com/SublimeText/Origami) — ウィンドウを好きなように分割！新しいパネルを作成、パネルを削除、パネル間でビューを移動または複製できます
- [PackageResourceViewer](https://github.com/skuroda/PackageResourceViewer) — Sublimeパッケージのリソースを表示・編集できます。拡張機能やテーマ開発に役立ちます
- [PlainTasks](https://packagecontrol.io/packages/PlainTasks) — 独自の設計方針を持つToDoリスト
- [Sidebar Enhancements](https://github.com/titoBouzout/SideBarEnhancements) — ファイルとフォルダのサイドバーの操作に強化を提供します
- [StyleToken](https://github.com/vcharnahrebel/style-token) — 特定のテキストを異なる色でハイライトできる機能（Notepad++の"Style token"機能に類似）
- [Sublime Alignment](https://github.com/wbond/sublime_alignment) — マルチラインおよび複数選択を整列するためのシンプルなキーバインディング
- [Sublime Worksheet](https://github.com/jcartledge/sublime-worksheet) — JavaScript、PHP、Rubyなどに向けたインラインREPL
- [SublimeFileBrowser](https://github.com/aziz/SublimeFileBrowser) - サイドバーを捨て、キーボードを使って通常のタブでファイルを閲覧しましょう。プロのように！また、[Dired](https://en.wikipedia.org/wiki/Dired)はSTが提供する強力なテキスト編集機能を使ってディレクトリ構造を変更できます。
- [SublimeLinter](https://github.com/SublimeLinter/SublimeLinter3) — コードのlintを行うフレームワークを提供するプラグイン。言語を問わず、よりクリーンでバグの少ないコードを書くのに役立ちます。利用者には高い柔軟性と使いやすさを、linter作者には実装の簡潔さを提供するよう設計されています。
- [SublimeREPL](https://github.com/wuub/SublimeREPL) — ST2内でインタープリタを実行（Clojure、CoffeeScript、F#、Groovy、Haskell、Lua、MozRepl、NodeJS、Python、R、Ruby、Scala、シェルまたは自分で設定可能）。
- [Sync Settings](https://github.com/mfuentesg/SyncSettings) - Sublime Textの設定をクロスプラットフォームで同期するためのソリューション
- [Synesthesia](https://github.com/dariusf/synesthesia) — テキストを美しく色付けするプラグイン。
- [Trailing Spaces](https://github.com/SublimeText/TrailingSpaces) — 末尾のスペースをハイライトし、一瞬で削除します。

<a id="javascript-profile"></a>
### JavaScript向け構成

- [Bump](https://github.com/yavorsky/Bump) — パッケージ.jsonの依存関係を最新に保つプラグイン。パッケージをマウスオーバーした際に、npmやyarnの最新バージョンをすっきりと表示するツールを提供
- [CoffeeScript](https://github.com/Xavura/CoffeeScript-Sublime-Plugin) — シンタックスハイライトとチェック、コマンド、ショートカット、スニペット、コンパイルなど
- [JavaScript Enhancements](https://github.com/pichillilorenzo/JavaScriptEnhancements) — スマートJavaScript自動補完、リアルタイムエラー、JavaScriptプロジェクトの作成・開発・管理（Cordova、Ionic、Reactなど）に関する多くの機能を提供するプラグイン。内部で [Flow](https://github.com/facebook/flow)（FacebookのJavaScript静的型チェックツール）を使用
- [JsFormat](https://github.com/jdc0589/JsFormat) — JavaScriptフォーマットプラグイン。 http://jsbeautifier.org のコマンドライン／Pythonモジュール版JavaScriptフォーマッターを使い、JavaScript／JSONファイル全体または選択範囲を整形
- [TernJS](https://github.com/ternjs/tern_for_sublime) — JavaScript型推論エンジンの統合

### テーマ

- [Ayu](https://github.com/dempfi/ayu) — 明るい色のシンプルテーマで、ダーク、ミラージュ、ライトの3種類あり、長時間の快適な作業に最適。
- [Ciapre](https://github.com/vinhnx/Ciapre.tmTheme/) - Sublime Text／TextMate用の目にも優しい色のスケーム。
- [Cobalt2](https://github.com/wesbos/cobalt2) — 完全機能のSublime Textブルースケーム。
- [Comfort](https://github.com/devanshdalal/Comfort) — Sublime Textに最適なテーマ。
- [Cyanide](https://github.com/lefoy/cyanide-theme) — 極めてシンプルなダークテーマ。
- [Flatland](https://github.com/thinkpixellab/flatland) — Sublime Text 2＆3用のシンプルテーマと、それに付随する色のスケーム。Sodaから派生しており、カスタムテーマ開発のスタート地点として最適。
- [Material theme](https://github.com/equinusocio/material-theme) — このテーマはMaterial Designの視覚言語を提供。http://equinsuocha.io/material-theme
- [Predawn](https://github.com/jamiewilson/predawn) — Sublime TextおよびAtom用のダークインターフェースと文法テーマ。http://jamiewilson.io/predawn
- [Soda](http://buymeasoda.github.io/soda-theme/) — ダークとライトのカスタムUIテーマ
- [Spacegray](http://kkga.github.io/spacegray/) — Sublime Text 2/3用のカスタムUIテーマセット。ハイプとミニマリズムがテーマ。さまざまな味わいのバリエーションと、対応するBase16カラーパレットが用意されています。 http://kkga.github.io/spacegray
