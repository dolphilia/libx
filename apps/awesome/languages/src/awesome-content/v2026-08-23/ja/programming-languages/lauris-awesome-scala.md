<a id="books"></a>
## 書籍
* [Essential Scala](https://underscore.io/books/essential-scala/) ノエル・ウェルシュとデイブ・グーレルによる - 実務経験のある開発者が初めてScalaに触れるための本
* [Functional and Reactive Domain Modeling](https://www.manning.com/books/functional-and-reactive-domain-modeling) デバシシュ・ゴーシュによる
* [Functional Programming for Mortals](https://leanpub.com/fpmortals/read) サム・ハリディーによる
* [Functional Programming in Scala](https://www.manning.com/books/functional-programming-in-scala) パウル・チウサノとルナービャンソンによる
* [Functional Programming, Simplified (Scala edition)](https://alvinalexander.com/scala/fp-book/learning-functional-programming-in-scala/) アルビン・アレクサンダーによる
* [Get Programming with Scala](https://www.manning.com/books/get-programming-with-scala) ダニエラ・スフレゴラによる - Scalaに関するチュートリアル中心の導入
* [Practical FP in Scala: A hands-on approach](https://leanpub.com/pfp-scala) ガブリエル・ボルペによる
* [Programming in Scala](https://www.artima.com/shop/programming_in_scala_4ed) マーティン・オーデルスキー、レクス・スプーン、ビル・ベンナーズによる
* [Pure functional HTTP APIs in Scala](https://leanpub.com/pfhais) ジェンス・グレースルによる
* [Reactive Programming with Scala and Akka](https://www.amazon.com/Reactive-Programming-Scala-Akka/dp/1783984341) - 反応型プログラミングの概念を用いて、複数ノードで実行される分散システムを構築
* [Scala Cookbook](http://scalacookbook.com) アルビン・アレクサンダーによる
* [Scala for the Impatient](https://horstmann.com/scala/) カイ・ホルストマンによる - Scalaのほとんどの機能を短く、わかりやすく解説
* [Scala With Cats](https://underscore.io/books/scala-with-cats/) ノエル・ウェルシュとデイブ・グーレルによる - モダン関数型プログラミングの技術を用いて、システムアーキテクチャと設計を学ぶ [Cats](https://typelevel.org/cats/)
* [The Type Astronaut's Guide to Shapeless](https://underscore.io/books/shapeless-guide/) デイブ・グーレルによる
* [Zionomicon](https://www.zionomicon.com) ジョン・A・デ・ゴースとアダム・フレーザーによる - ZIOを用いて、スケーラブルで型安全かつ並列処理可能なアプリケーションの開発の「暗黒の技術」をマスター
