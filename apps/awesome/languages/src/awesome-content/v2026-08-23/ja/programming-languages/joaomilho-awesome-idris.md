### プロジェクト

* [GitHub でトレンドの Idris リポジトリ](https://github.com/trending/idris)
* [iridium](https://github.com/puffnfresh/iridium) - X11 を抽象化し、Idris で設定する xmonad。
* [lightyear](https://github.com/ziman/lightyear) - Idris 向けパーサーコンビネーター。
* [quantities](https://github.com/timjb/quantities) Idris で型安全な物理計算と単位変換を行います。
* [idris-type-providers](https://github.com/david-christiansen/idris-type-providers) - Idris 向け Type Provider ライブラリ。
* [IdrisScript](https://github.com/idris-hackers/IdrisScript) - 安全でない JavaScript の世界とやり取りする FFI バインディング。
* [idris-containers](https://github.com/jfdm/idris-containers) - Idris 言語で使う各種データ構造。
* [IdrisSqlite](https://github.com/david-christiansen/IdrisSqlite) - SQLite の副作用を伴うバインディング。
* [idris-http](https://github.com/uwap/idris-http) - Idris 向け HTTP ライブラリ。
* [RingIdris](https://github.com/FranckS/RingIdris) - Idris 向け環ソルバー。
* [specdris](https://github.com/pheymann/specdris) - Idris 向けテストフレームワーク。
* [idris-config](https://github.com/jfdm/idris-config) - Idris で書かれた各種設定ファイルのパーサー。
* [probability](https://github.com/BlackBrane/probability) - Idris における確率的計算。
* [idris-protobuf](https://github.com/google/idris-protobuf) - Idris による Protocol Buffers の部分実装。
* [idris-free](https://github.com/idris-hackers/idris-free) - Free Monad と、それを扱う便利な構造。
* [idris-ct](https://github.com/statebox/idris-ct) - 形式検証された圏論ライブラリ
* [typedefs](https://github.com/typedefs/typedefs) - プログラミング言語に依存しない代数的データ型定義言語

### バックエンド

* [idris-jvm](https://github.com/mmhelloworld/idris-jvm) - Idris 向け JVM バイトコードバックエンド。
* [idris-llvm](https://github.com/idris-hackers/idris-llvm) - LLVM バックエンド。
* [idris-erlang](https://github.com/lenary/idris-erlang) - Erlang バックエンド。
* [idris-malfunction](https://github.com/stedolan/idris-malfunction) - 実験的な Malfunction（OCaml 内部表現）バックエンド。
