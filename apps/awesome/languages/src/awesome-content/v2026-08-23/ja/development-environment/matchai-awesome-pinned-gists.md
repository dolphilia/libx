## GitHub

より詳細な GitHub ユーザーデータをピン留め Gist に表示します。

- [activity-box](https://github.com/JasonEtco/activity-box) - ピン留め Gist を更新して、GitHub ユーザーの最新アクティビティを表示します。
  - [github-activity-box](https://github.com/maxchang3/github-activity-box) - activity-box を TypeScript で書き直したものです。GitHub Actions と簡単に統合できるよう npm で公開されており、型安全性とカスタマイズ性を改善し、GraphQL API を使って指定ユーザーが作成した Issue と PR を取得します。
- [github-stats-box](https://github.com/bokub/github-stats-box) - ピン留め Gist を更新して、GitHub の統計を表示します。
- [lang-box](https://github.com/inokawa/lang-box) - ピン留め Gist を更新して、GitHub で最近コミットした言語を表示します。
  - [recent-languages-box](https://github.com/liby/recent-languages-box) - lang-box を TypeScript + Bun で書き直したもので、ピン留め Gist を最近の GitHub コミットの言語統計で更新します。型安全性とカスタマイズ性を改善し、より科学的な手法で言語を並べ替えます。
  - [github-lang-box](https://github.com/maxchang3/github-lang-box) - lang-box を TypeScript で書き直したものです。GitHub Actions と簡単に統合できるよう npm で公開されており、型安全性とカスタマイズ性を改善し、プライベートリポジトリにもアクセスできます。
- [productive-box](https://github.com/maxam2017/productive-box) - ピン留め Gist を更新して、1 日のうち最も生産性の高い時間帯を表示します。

## ユーザー定義

ユーザー定義の内容（GitHub Action の入力パラメーターなどで設定）から得たデータをピン留め Gist に表示します。

- [date-box](https://github.com/kf-liu/date-box) - ピン留め Gist を更新して、記念日とカウントダウンの日数（または時間）を表示します。

- [image2grid](https://github.com/kiwamizamurai/image2grid) - GitHub README 向けのグリッド状の画像・GIF を生成します。
