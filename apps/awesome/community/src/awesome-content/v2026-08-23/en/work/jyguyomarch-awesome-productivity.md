# Awesome Productivity

Explore productivity methods through websites and books, alongside tools for file, note, task, habit, password, and knowledge management. The list also covers workflow automation and screen capture.

## Websites

- [12+ Tips and Tricks to Work Faster in Microsoft Outlook](https://lifehacker.com/12-tips-and-tricks-to-work-faster-in-microsoft-outlook-1540483009) - Tips for managing Outlook and moving closer to Inbox Zero.
- [Advanced GTD with Remember The Milk](https://blog.rememberthemilk.com/post/116665489183/guest-post-advanced-gtd-with-remember-the-milk) - A tutorial on how to implement GTD with Remember the Milk.
- [Inbox Zero](https://www.43folders.com/izero) - Rigorous approach to email management aimed at keeping the inbox (almost) empty at all times.
- [Lifehacker](https://lifehacker.com/) - Blog with tips, tricks, and downloads for getting things done.
- [Pomodoro Technique](http://pomodorotechnique.com/) - Divide tasks into 25-minute sessions to get more done in less time.
- [r/Productivity](https://www.reddit.com/r/productivity/) - Productivity subreddit.
- [Rid Your Desktop of Clutter with This Simple Trio of Icons](https://lifehacker.com/5901487/rid-your-desktop-of-clutter-with-this-simple-trio-of-icons) - A desktop organization trick that the source author describes as useful over several years.
- [ShortLib](https://shortlib.netlify.app/) - Collection of hundreds of shortcuts for Windows, Mac and Linux.
- [The Bullet Journal](https://bulletjournal.com/) - A pen-and-paper method for using a notebook as a productivity tool.
- [Zen Habits](https://zenhabits.net/) - Blog by Leo Babauta with topics such as simplifying life.
- [Productive Fish](https://productive.fish/) - Articles on productivity, effective study, and well-being.

## Books

- [Deep Work: Rules for Focused Success in a Distracted World](https://www.calnewport.com/books/deep-work/) - Deep work is the ability to focus without distraction on a cognitively demanding task.
- [Getting Things Done](https://gettingthingsdone.com/store/product.php?productid=17035&cat=3&page) - A simple time-management method.
- [The 5 Choices](https://www.simonandschuster.com/books/The-5-Choices/Kory-Kogon/9781476711829) - A productivity methodology covering prioritization, scheduling, technology, and energy management.

## Tools and Apps

### File Management

- [Box](https://www.box.com) - Cloud storage for business customers.
- [Dropbox](https://www.dropbox.com) - A simple, versatile cloud storage solution.
- [Google Drive](https://www.google.ca/drive/) - Cloud storage solution deeply integrated in the Google ecosystem.
- [Mega](https://mega.nz/) - Cloud storage described in the fixed source as offering 50G from the start and a high level of security.
- [Nextcloud](https://nextcloud.com) - The self-hosted productivity platform that keeps you in control.
- [OneDrive](https://onedrive.live.com) - Cloud storage for Windows users.
- [pCloud](https://www.pcloud.com/) - A cloud storage solution with a strong focus on security.
- [Clipboard](https://getclipboard.app) - Easy-to-use local solution for saving files, folders, or text like a scratchpad.

### Note Management

- [Evernote](https://evernote.com/) - A note management tool described in the source as a second brain for remembering information.
- [Google Keep](https://www.google.com/keep/) - A simple note management system tightly integrated with Google products.
- [Inkdrop](https://www.inkdrop.info/) - A cross-platform note taking application for Markdown lovers.
- [Joplin](https://joplinapp.org/) - A note taking and to-do application with synchronization capabilities.
- [Notion](https://www.notion.so/) - An all-in-one very customizable workspace for notes, tasks, wikis and lists.
- [Yana](https://yana.js.org) - A note-taking app with nested documents, full-text search, a rich-text editor, a code snippet editor, and more.
- [OneNote](https://www.onenote.com/) - A note management solution described in the source as best suited to Windows users.
- [Preserver](https://github.com/hsbalar/preserver) - Notes organizer desktop application based on Electron.
- [Simplenote](https://simplenote.com/) - A lightweight, clean, free notes app, listed in the fixed source as available for iOS, Android, Mac, Windows, Linux, and the web.
- [Standard Notes](https://standardnotes.org/) - A simple and private notes application.
- [WorkFlowy](https://workflowy.com/) - Outlining application for nested bulleted lists.

### Task Management

- [Airtable](https://airtable.com/) - Mix of spreadsheet and database to help organize work.
- [Amazing Marvin](https://www.amazingmarvin.com/) - Incorporates behavioral psychology principles to help overcome procrastination, feel in control, and finish a to-do list.
- [Any.do](https://www.any.do/) - A simple interface with many features, described in the fixed source as a favorite to-do list manager at [Lifehacker](https://lifehacker.com/5924093/five-best-to-do-list-managers).
- [GitHub Projects](https://github.com/features/project-management/) - A GitHub feature that connects project management to code.
- [Hitask](https://hitask.com) - Project and task management for teams.
- [KanbanFlow](https://kanbanflow.com) - Kanban method task board with Pomodoro technique.
- [Microsoft To Do](https://todo.microsoft.com/tasks/) - Microsoft cloud-based task management application based on Wunderlist technology.
- [OmniFocus](https://www.omnigroup.com/omnifocus) - A task manager based on Getting Things Done for macOS and iOS.
- [Paymo](https://www.paymoapp.com/) - Manage tasks, create team schedules, track work time, and bill clients from one platform to help keep a team aligned and engaged.
- [Pomolectron](https://github.com/amitmerchant1990/pomolectron) - A Pomodoro app for the menu bar or system tray.
- [Remember the Milk](https://www.rememberthemilk.com) - Manage tags for to-dos and location-based tasks.
- [Taskade](https://taskade.com) - Simple and collaborative task lists for teams.
- [Taskwarrior](https://taskwarrior.org/) - An open-source command-line task manager described in the source as flexible, fast, efficient, and unobtrusive.
- [Timely](https://memory.ai/timely) - Automatic time tracking for projects and teams without manual timers or note-taking.
- [Timing](https://timingapp.com/) - Automatic time and productivity tracking for Mac to help stay on track and avoid losing billable hours when billing hourly.
- [Tinido](https://tinido.com/) - A simple task management app that shows completed tasks in a contribution graph like a GitHub profile to help provide insights.
- [Todo.txt](http://todotxt.com/) - A task management technique that uses a single `.txt` file.
- [Todoist](https://todoist.com/) - A cross-platform productivity tool.
- [Topydo](https://github.com/topydo/topydo) - A to-do list application using the todo.txt format, positioned between todo.txt CLI and Taskwarrior.
- [Trello](https://trello.com) - Kanban method task board.
- [Tweek](https://tweek.so) - A simple to-do list and weekly task management tool.
- [VivifyScrum](https://www.vivifyscrum.com) - An agile project management app for teams, with customizable Scrum and Kanban boards.
- [Bordio](https://bordio.com/) - Daily planner for managing tasks and events on one board.
- [OpenProject](https://www.openproject.org/) - An on premise open source project management solution that comes with a free community version as well as an enterprise version.

### Habit Trackers

- [Emoji Log](https://emojilog.rosano.ca) - An emoji-based tracker for arbitrary things that does not use streaks.
- [Everyday](https://everyday.app/) - Form new habits by doing things every day.
- [Habitica](https://habitica.com) - Complete your real life daily goals in a role play game (previously called _HabitRPG_).
- [HabitBull](https://www.habitbull.com/) - Premium habit tracker.
- [Loop Habit Tracker](https://github.com/iSoron/uhabits) - An Android app for creating and maintaining good habits.
- [Waka Time](https://wakatime.com/) - An open-source plugin for tracking time spent coding.
- [Conjure](https://conjure.so) - Habits, goals and time tracking platform with rules engine, data layer, API, dashboards and more (Web, Desktop, iOS, Android).

### Task Automation

- [AutoIt](https://www.autoitscript.com/) - Small tool for Windows to automate the Windows GUI, but it can also be used for other purposes.
- [Awesome AutoHotKey](https://github.com/ahkscript/awesome-AutoHotkey) - AutoHotKey is a free, open-source macro-creation and automation software for Windows that allows users to automate repetitive tasks.
- [IFTTT](https://ifttt.com) - Create chains of conditional statements, called recipes, between web services to automate work and improve productivity.
- [n8n](https://n8n.io) - Workflow automation for connecting web services with a self-hosting option, described as open source in the fixed source.
- [Qbserve](https://qotoqot.com/qbserve/) - Mac time tracking automation: freelance project tracking, timesheets, invoicing & real-time productivity feedback.
- [Parabola](https://parabola.io) - Drag and drop tool to build custom reports, workflows, and integrations to automate your manual processes.
- [Tasker](https://tasker.dinglisch.net/) - An Android app for context-sensitive custom tasks, such as automatically turning on Wi-Fi when arriving home.
- [Zapier](https://zapier.com/) - Automation tool that allows you to connect hundreds of web services and create automations between the processes.

### Password Manager

- [Bitwarden](https://bitwarden.com) - A free password manager for storing, syncing, and generating passwords online or through native apps.
- [KeePass](https://keepass.info/) - A free, open source, light-weight password manager with auto-type, browser and plugin support.
- [LastPass](https://lastpass.com) - A freemium password manager that stores encrypted passwords online.
- [NordPass](https://nordpass.com/) - A freemium password manager from the NordVPN team, described in the fixed source as storing unlimited passwords and providing access anywhere through apps on all platforms.

### Knowledge Management

- [Obsidian.md](https://obsidian.md/) - A knowledge base tool that works on local Markdown files. It allows you to create links between different notes.
- [Scribe](https://scribehow.com/) - Automatically create step-by-step guides for any process by pressing “record”; the guides include screenshots of your actions and can be shared with colleagues, customers, and friends.
- [Logseq](https://logseq.com/) - A privacy-first, open-source knowledge base working with local plain-text Markdown and Org-mode files for writing, organizing, and sharing thoughts, keeping a to-do list, and building a digital garden.

### Screen Capture

- [ShareX](https://getsharex.com/) - Screen capture, file sharing and productivity tool.
- [Replayable](https://replayable.io) - Rewind your screen. Playback and share exactly what happened with Replayable's desktop replay buffer.
- [CleanShot](https://cleanshot.com/) - A premium screen capture and recording tool for macOS with built-in annotation and text recognition.
