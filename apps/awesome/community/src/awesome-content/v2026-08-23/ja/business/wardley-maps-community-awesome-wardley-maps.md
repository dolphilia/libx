# Awesome Wardley Maps Community Hub

[Wardley Mapping](https://en.wikipedia.org/wiki/Wardley_map)は、ユーザーのニーズ、構成要素、依存関係や特性を可視化する手法です。環境を把握し、今後の変化を見越して仮定を変えたシナリオを比較し、方向性や行動を選ぶために使います。このページでは、入門資料、書籍、講座、実践例、研究論文、マッピングアプリ、開発ツール、テンプレートに加え、コミュニティ、イベント、ワークショップを探せます。

## アプリ <a id="apps"></a>

### マッピング<a id="mapping"></a>

- [OnlineWardleyMaps](https://github.com/damonsk/onlinewardleymaps) - オープンソースのオンラインマッピングツール。[ホスト版](https://onlinewardleymaps.com/)と[文書「Wardley Maps as Code」](https://docs.onlinewardleymaps.com/)
- [Wardley Maps for Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=damonsk.vscode-wardley-maps) - Visual Studio Code内でWardley Mapsを表示・編集する拡張機能。OnlineWardleyMaps.comのエンジンを使用。[文書「Wardley Maps as Code」](https://docs.onlinewardleymaps.com/)
- [Wardley Maps for Obsidian.md](https://github.com/damonsk/obsidian-wardley-maps) - Obsidian.md内でWardley Mapsを表示・編集するコミュニティプラグイン。OnlineWardleyMaps.comのエンジンを使用。[文書「Wardley Maps as Code」](https://docs.onlinewardleymaps.com/)
- [Wardley Maps for Jupyter Notebooks (ipywardley)](https://github.com/anjackson/ipywardley) - Jupyter NotebookでWardley Mapsを生成するプラグイン
- [MapScript](https://observablehq.com/collection/@ajbouh/mapscript) - Observableを基盤とするため、同サービスの[利用規約](https://observablehq.com/terms-of-service)を参照。[機能の要望](https://mapscript.canny.io/feature-requests)と[ホスト版](https://mapscript.org)
- [Go-Wardley](https://github.com/DavidGamba/go-wardley) - HCLベースのマップ記述ファイルからWardley MapsをSVG形式で生成
- [Mapkeep](https://mapkeep.com/) - マップの共同編集と無料のホスティング。[YouTubeチャンネル](https://www.youtube.com/@mapkeep)と[ニュース・更新情報のブログ](https://blog.mapkeep.com/)
- [Glamorous Toolkit](https://gtoolkit.com) - Wardley Mapsを知識管理や多言語ノートブックと組み合わせられる、用途に合わせて作り変えられるプログラマブルな環境
- [Excalidraw](https://excalidraw.com) - 手描き風の図やマップを作成するオンライン作図ツール。キーボードショートカット「0」でライブラリを開き、「Wardley Maps Symbols」を追加
- [Flowchart fun](https://flowchart.fun) - 会話や会議の場で価値連鎖を作成するための、テキストベースのフローチャートツール
- [wardleyToGo](https://owulveryck.github.io/wardleyToGo/demo/) - map-as-codeのSDKと、map-as-dataを表現する高水準言語（`wtg`）。マップをCIに組み込むツールと、マップを設計するオンラインデモを提供
- [Map](https://map.tranquil.systems) - 独自の`wmap`構文でWardley Mapsを作成するmacOSのネイティブアプリ（Apple Silicon限定）。GPLv3。`wmap`ファイルを画像としてプレビューするQuickLookプラグインと、共同編集のための共有機能を搭載
- [Map for Linux](https://map.tranquil.systems/map-for-linux) - `wmap`構文でWardley Mapsを作成するGTK4のLinuxアプリ。AGPLv3
- [wmap](https://map.tranquil.systems/cli) - `wmap`形式のマップをPNGまたはSVGへ変換するコマンドラインツール

- [tree-sitter-wmap](https://git.sr.ht/~rbdr/tree-sitter-wmap) - Tree-sitterを使った`wmap`構文パーサー。構文強調表示を提供するNeovimプラグインを同梱

- [wmap-parser-rust](https://crates.io/crates/wmap-parser) - `wmap`構文のWardley Maps用Rustパーサー
- [wmap-parser-c](https://git.sr.ht/~rbdr/wmap-parser-c) - `wmap`構文のWardley Maps用ANSI Cパーサー（原文では高性能と記載）
- [wmap-renderer-canvas](https://www.npmjs.com/package/wmap-renderer-canvas) - `wmap`構文のWardley Mapsをcanvas要素に描画するJavaScriptレンダラー。ブラウザーまたはNode.jsで利用可能
- [wmap-renderer-svg](https://www.npmjs.com/package/wmap-renderer-svg) - `wmap`構文のWardley MapsをSVGへ描画するブラウザー専用レンダラー
- [wmap-renderer-rust](https://crates.io/crates/wmap-renderer) - `wmap`構文のWardley MapsからCairoのサーフェス、SVG、PNGを生成するRustレンダラー
