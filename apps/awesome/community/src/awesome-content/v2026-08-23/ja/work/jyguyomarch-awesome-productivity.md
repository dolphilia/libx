# Awesome Productivity

ウェブサイトや書籍を通じて生産性を高める方法を探せます。ファイル・ノート・タスク・習慣・パスワード・知識を管理するツールに加え、作業の自動化や画面キャプチャのツールも紹介しています。

## <a id="websites"></a>ウェブサイト
- [12+ Tips and Tricks to Work Faster in Microsoft Outlook](https://lifehacker.com/12-tips-and-tricks-to-work-faster-in-microsoft-outlook-1540483009) - Outlookを管理し、Inbox Zeroに近づくためのヒント。
- [Advanced GTD with Remember The Milk](https://blog.rememberthemilk.com/post/116665489183/guest-post-advanced-gtd-with-remember-the-milk) - Remember the MilkでGTDを実践するためのチュートリアル。
- [Inbox Zero](https://www.43folders.com/izero) - 受信トレイを常に（ほぼ）空に保つことを目指す厳密なメール管理手法。
- [Lifehacker](https://lifehacker.com/) - 物事を終わらせるためのヒント、コツ、ダウンロードを紹介するブログ。
- [Pomodoro Technique](http://pomodorotechnique.com/) - タスクを25分の作業時間に分け、より短い時間で多くを終える手法。
- [r/Productivity](https://www.reddit.com/r/productivity/) - 生産性向上を扱うRedditのコミュニティ。
- [Rid Your Desktop of Clutter with This Simple Trio of Icons](https://lifehacker.com/5901487/rid-your-desktop-of-clutter-with-this-simple-trio-of-icons) - 原文の著者が数年にわたり役立ったと述べるデスクトップ整理のコツ。
- [ShortLib](https://shortlib.netlify.app/) - Windows、Mac、Linux向けの数百のショートカット集。
- [The Bullet Journal](https://bulletjournal.com/) - ノートを生産性向上のツールとして使う、ペンと紙による手法。
- [Zen Habits](https://zenhabits.net/) - 生活をシンプルにすることなどを扱うLeo Babautaのブログ。
- [Productive Fish](https://productive.fish/) - 生産性、効果的な学習、ウェルビーイングを扱う記事。

## <a id="books"></a>書籍
- [Deep Work: Rules for Focused Success in a Distracted World](https://www.calnewport.com/books/deep-work/) - Deep workとは、認知的な負荷の高い作業に、気を散らされず集中する能力。
- [Getting Things Done](https://gettingthingsdone.com/store/product.php?productid=17035&cat=3&page) - シンプルな時間管理手法。
- [The 5 Choices](https://www.simonandschuster.com/books/The-5-Choices/Kory-Kogon/9781476711829) - 優先順位付け、予定、技術、エネルギーの管理を扱う生産性向上手法。

## <a id="tools-and-apps"></a>ツールとアプリ
### <a id="file-management"></a>ファイル管理
- [Box](https://www.box.com) - 企業顧客向けのクラウドストレージ。
- [Dropbox](https://www.dropbox.com) - シンプルで多用途なクラウドストレージ。
- [Google Drive](https://www.google.ca/drive/) - Googleのエコシステムに深く統合されたクラウドストレージ。
- [Mega](https://mega.nz/) - 固定原文で、開始時から50Gの容量があり、高い安全性を備えると説明されているクラウドストレージ。
- [Nextcloud](https://nextcloud.com) - 利用者が管理権を保てるセルフホスト型の生産性向上プラットフォーム。
- [OneDrive](https://onedrive.live.com) - Windows利用者向けのクラウドストレージ。
- [pCloud](https://www.pcloud.com/) - セキュリティを重視するクラウドストレージ。
- [Clipboard](https://getclipboard.app) - ファイル、フォルダー、テキストをメモ帳のように保存できる、使いやすいローカルツール。

### <a id="note-management"></a>ノート管理
- [Evernote](https://evernote.com/) - 原文で、情報を記憶するための「第二の脳」と表現されているノート管理ツール。
- [Google Keep](https://www.google.com/keep/) - Google製品と密接に統合されたシンプルなノート管理システム。
- [Inkdrop](https://www.inkdrop.info/) - Markdown愛好者向けのクロスプラットフォームなノートアプリ。
- [Joplin](https://joplinapp.org/) - 同期機能を備えるノート・To-Doアプリ。
- [Notion](https://www.notion.so/) - ノート、タスク、Wiki、リスト向けの、高度にカスタマイズできるオールインワンのワークスペース。
- [Yana](https://yana.js.org) - 入れ子構造の文書、全文検索、リッチテキストエディター、コードスニペットエディターなどを備えるノートアプリ。
- [OneNote](https://www.onenote.com/) - 原文でWindows利用者に最適と説明されているノート管理ツール。
- [Preserver](https://github.com/hsbalar/preserver) - Electronに基づくノート整理用のデスクトップアプリ。
- [Simplenote](https://simplenote.com/) - 軽量でシンプルな無料ノートアプリ。固定原文ではiOS、Android、Mac、Windows、Linux、ウェブに対応すると記載。
- [Standard Notes](https://standardnotes.org/) - シンプルでプライバシーを重視するノートアプリ。
- [WorkFlowy](https://workflowy.com/) - 入れ子構造の箇条書きリストを作るアウトラインアプリ。

### <a id="task-management"></a>タスク管理
- [Airtable](https://airtable.com/) - 仕事の整理に役立つ、スプレッドシートとデータベースを組み合わせたツール。
- [Amazing Marvin](https://www.amazingmarvin.com/) - 行動心理学の原則を取り入れ、先延ばしを克服し、自分で管理できているという感覚を得て、To-Doリストを完了させるためのツール。
- [Any.do](https://www.any.do/) - シンプルなインターフェースに多くの機能を備えるツール。固定原文では[Lifehacker](https://lifehacker.com/5924093/five-best-to-do-list-managers)のお気に入りのTo-Doリスト管理ツールと紹介。
- [GitHub Projects](https://github.com/features/project-management/) - プロジェクト管理をコードに結び付けるGitHubの機能。
- [Hitask](https://hitask.com) - チーム向けのプロジェクト・タスク管理。
- [KanbanFlow](https://kanbanflow.com) - ポモドーロ・テクニックを備える、かんばん方式のタスクボード。
- [Microsoft To Do](https://todo.microsoft.com/tasks/) - Wunderlistの技術に基づくMicrosoftのクラウド型タスク管理アプリ。
- [OmniFocus](https://www.omnigroup.com/omnifocus) - Getting Things Doneに基づく、macOS・iOS向けのタスク管理ツール。
- [Paymo](https://www.paymoapp.com/) - タスク管理、チームの予定作成、作業時間の記録、顧客への請求を一つのプラットフォームで行い、チームの足並みと積極的な参加を支えるツール。
- [Pomolectron](https://github.com/amitmerchant1990/pomolectron) - メニューバーやシステムトレイ向けのポモドーロアプリ。
- [Remember the Milk](https://www.rememberthemilk.com) - To-Doのタグや場所に基づくタスクを管理。
- [Taskade](https://taskade.com) - チームで共同利用できるシンプルなタスクリスト。
- [Taskwarrior](https://taskwarrior.org/) - オープンソースのコマンドラインタスク管理ツール。原文では柔軟、高速、効率的で、作業の邪魔にならないと説明。
- [Timely](https://memory.ai/timely) - 手動タイマーやメモなしでプロジェクトとチームの作業時間を自動記録するソフトウェア。
- [Timing](https://timingapp.com/) - Mac向けの時間・生産性の自動記録ツール。作業を予定どおり進め、時間単位の課金で請求可能な時間の記録漏れを防ぐためのもの。
- [Tinido](https://tinido.com/) - 完了したタスクをGitHubプロフィールのようなコントリビューショングラフで表示し、気づきを得るためのシンプルなタスク管理アプリ。
- [Todo.txt](http://todotxt.com/) - 単一の`.txt`ファイルでタスクを管理する手法。
- [Todoist](https://todoist.com/) - クロスプラットフォームの生産性向上ツール。
- [Topydo](https://github.com/topydo/topydo) - todo.txt CLIとTaskwarriorの中間に位置付けられる、todo.txt形式のTo-Doリストアプリ。
- [Trello](https://trello.com) - かんばん方式のタスクボード。
- [Tweek](https://tweek.so) - シンプルなTo-Doリストと週間タスク管理のツール。
- [VivifyScrum](https://www.vivifyscrum.com) - チーム向けのアジャイルなプロジェクト管理アプリ。カスタマイズ可能なScrum・かんばんボードを提供。
- [Bordio](https://bordio.com/) - タスクとイベントを一つのボードで管理するデイリープランナー。
- [OpenProject](https://www.openproject.org/) - 無料コミュニティ版とエンタープライズ版を備える、オンプレミスのオープンソースプロジェクト管理ツール。

### <a id="habit-trackers"></a>習慣トラッカー
- [Emoji Log](https://emojilog.rosano.ca) - 連続実行日数を使わず、任意の事柄を記録できる絵文字ベースのトラッカー。
- [Everyday](https://everyday.app/) - 毎日の実行によって新しい習慣を身に付けるためのツール。
- [Habitica](https://habitica.com) - 現実世界の日々の目標をロールプレイゲームで達成するためのツール（旧称HabitRPG）。
- [HabitBull](https://www.habitbull.com/) - プレミアム習慣トラッカー。
- [Loop Habit Tracker](https://github.com/iSoron/uhabits) - 良い習慣を身に付けて維持するAndroidアプリ。
- [Waka Time](https://wakatime.com/) - コーディングに費やした時間を記録するオープンソースのプラグイン。
- [Conjure](https://conjure.so) - ルールエンジン、データ層、API、ダッシュボードなどを備える習慣・目標・時間記録のプラットフォーム（ウェブ、デスクトップ、iOS、Android）。

### <a id="task-automation"></a>タスク自動化
- [AutoIt](https://www.autoitscript.com/) - Windows GUIを自動化する小さなWindows用ツール。ほかの目的にも利用可能。
- [Awesome AutoHotKey](https://github.com/ahkscript/awesome-AutoHotkey) - Windowsで反復作業を自動化できる、無料・オープンソースのマクロ作成・自動化ソフトウェアAutoHotKey。
- [IFTTT](https://ifttt.com) - ウェブサービス間でrecipesと呼ばれる条件文の連鎖を作り、作業の自動化と生産性向上に使うツール。
- [n8n](https://n8n.io) - ウェブサービスを接続するワークフロー自動化ツール。セルフホストも選べ、固定原文ではオープンソースと記載。
- [Qbserve](https://qotoqot.com/qbserve/) - Macでの時間記録の自動化。フリーランスのプロジェクト記録、タイムシート、請求書、リアルタイムの生産性フィードバックに対応。
- [Parabola](https://parabola.io) - 手作業を自動化するカスタムレポート、ワークフロー、連携をドラッグ＆ドロップで構築するツール。
- [Tasker](https://tasker.dinglisch.net/) - 状況に応じた独自のタスクを実行できるAndroidアプリ。例えば帰宅時にWi-Fiを自動で有効化。
- [Zapier](https://zapier.com/) - 数百のウェブサービスを接続し、プロセス間の処理を自動化するツール。

### <a id="password-manager"></a>パスワードマネージャー
- [Bitwarden](https://bitwarden.com) - オンラインやネイティブアプリでパスワードを保存、同期、生成できる無料のパスワード管理ツール。
- [KeePass](https://keepass.info/) - 自動入力、ブラウザー、プラグインに対応する、無料・オープンソースの軽量パスワード管理ツール。
- [LastPass](https://lastpass.com) - 暗号化されたパスワードをオンラインに保存するフリーミアムのパスワード管理ツール。
- [NordPass](https://nordpass.com/) - NordVPNチームが開発したフリーミアムのパスワード管理ツール。固定原文では、パスワードを無制限に保存し、すべてのプラットフォームのアプリから場所を問わずアクセスできると説明。

### <a id="knowledge-management"></a>ナレッジ管理
- [Obsidian.md](https://obsidian.md/) - ローカルのMarkdownファイルで動くナレッジベースツール。異なるノート同士をリンク可能。
- [Scribe](https://scribehow.com/) - 任意の作業について、「record」を押すと、操作に基づくスクリーンショット付きの手順ガイドを自動作成し、同僚、顧客、友人と共有できるツール。
- [Logseq](https://logseq.com/) - ローカルのプレーンテキストのMarkdown・Org-modeファイルで動く、プライバシーを重視したオープンソースのナレッジベース。考えを書き、整理・共有したり、To-Doリストを維持したり、デジタルガーデンを作ったりするためのもの。

### <a id="screen-capture"></a>画面キャプチャ
- [ShareX](https://getsharex.com/) - 画面キャプチャ、ファイル共有、生産性向上のツール。
- [Replayable](https://replayable.io) - デスクトップのリプレイバッファーを使い、画面上で起きたことを巻き戻して正確に再生・共有するツール。
- [CleanShot](https://cleanshot.com/) - 注釈とテキスト認識を内蔵した、macOS向けのプレミアム画面キャプチャ・録画ツール。
