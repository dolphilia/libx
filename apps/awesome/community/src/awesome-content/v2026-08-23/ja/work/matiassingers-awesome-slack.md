# Awesome Slack

Slackのアプリやライブラリの一覧、サイドバーテーマの閲覧ツール、ボット・メッセージ・連携機能の開発に使える言語別ライブラリとSDKを紹介します。タスク管理、報告、ログ送信、ゲームなどに使えるオープンソースのアプリも探せます。

## リスト <a id="pencil--リスト"></a>
- [コミュニティ製ライブラリ](https://api.slack.com/community) - Slackがまとめたコミュニティ製オープンソースライブラリの一覧
- [Slack App Directory](https://slack.com/apps) - 一般公開されている Slack アプリの公式ディレクトリ
- [Slack Emojis](https://emoji.gg) - Slack 向けカスタム絵文字の非公式ディレクトリ

## テーマ <a id="art--テーマ"></a>

- [Slack Themes](http://slackthemes.net/) - Slackのサイドバーテーマを閲覧するツール

## ライブラリとSDK <a id="hammer_and_wrench--ライブラリと-sdk"></a>

### C&#35;

- [margiebot](https://github.com/jammerware/margiebot) - Slackボットの開発を速く、簡単で楽しいものにするために設計された.NETライブラリ（原文の説明）
- [Slack.Webhooks](https://github.com/nerdfury/Slack.Webhooks) - SlackのWebhookを扱いやすくするライブラリ
- [SlackAPI](https://github.com/Inumedia/SlackAPI) - C# で書かれた Slack API のサードパーティ実装

### Erlang

- [slacker](https://github.com/julienXX/slacker) - Erlang 製 Slack REST API ラッパー

### Go

- [webhook](https://github.com/adnanh/webhook) - Slack からの HTTP Webhook リクエストに応じてコマンドを簡単に実行

### Java

- [java-slack-sdk](https://github.com/slackapi/java-slack-sdk) - Slack アプリを構築する Slack 公式 Java フレームワーク
- [simple-slack-api](https://github.com/Ullink/simple-slack-api) - Java 製 Slack クライアントライブラリ

### JavaScript/TypeScript

- [bolt-js](https://github.com/slackapi/bolt-js) - Slack アプリを構築する Slack 公式 JavaScript フレームワーク
- [jsx-slack](https://github.com/yhatt/jsx-slack) - JSXからSlack Block Kitの表示領域向けのJSONオブジェクトを構築
- [node-slack-sdk](https://github.com/slackapi/node-slack-sdk) - Slack 公式 Node.js SDK
- [slack-block-builder](https://github.com/raycharius/slack-block-builder) - SwiftUI に着想を得た宣言的構文で Slack Block Kit UI を構築する軽量 Node.js ライブラリ

### PHP

- [SlackBundle](https://github.com/DZunke/SlackBundle) - Symfony2 向け SlackBundle
- [slack-php-app-framework](https://github.com/slack-php/slack-php-app-framework) - Slackアプリを開発するPHPフレームワーク。原文では堅牢とされる
- [slack-php-block-kit](https://github.com/jeremeamia/slack-block-kit) - PHPでSlack Block Kitのメッセージやモーダルを組み立てる、メソッド呼び出しを連鎖できるインターフェース
- [slack-php-socket-mode](https://github.com/slack-php/slack-php-socket-mode) - [slack-php-app-framework](https://github.com/slack-php/slack-php-app-framework) 向け Socket Mode 実装
- [slack-php-slick](https://github.com/slack-php/slack-php-slick) - PHP で Slack アプリを構築する依存関係のないマイクロフレームワーク

### PowerShell

- [PSSlack](https://github.com/RamblingCookieMonster/PSSlack) - Slackとのシンプルな連携に使うPowerShellモジュール

### Python

- [blockkit](https://github.com/imryche/blockkit) - PythonでBlock Kitのインターフェースを構築。原文では素早く構築する方法として紹介
- [bolt-python](https://github.com/slackapi/bolt-python) - Slack アプリを構築する Slack 公式 Python フレームワーク
- [django-slack](https://github.com/lamby/django-slack) - テンプレートエンジンでメッセージを生成する Django 向け Slack 統合
- [django-slack-oauth](https://github.com/izdi/django-slack-oauth) - Django 向け Slack OAuth モジュール
- [python-slack-events-api](https://github.com/slackapi/python-slack-events-api) - Python 向け Slack Events API アダプター
- [python-slack-sdk](https://github.com/slackapi/python-slack-sdk) - Slack 公式 Python SDK
- [slackblocks](https://github.com/nicklambourne/slackblocks) - Slack Block Kit メッセージを構築する Python API
- [slack-php-api](https://github.com/jolicode/slack-php-api) - 公式OpenAPI仕様に基づくPHPのSlackクライアント。固定原文ではPythonの分類に掲載
- [slacker-cli](https://github.com/juanpabloaj/slacker-cli) - コマンドラインから Slack へメッセージを送信
- [slashbot](https://github.com/ebrassell/slashbot) - AWS Lambda 関数を使ってスラッシュコマンドを簡単に作成
- [boltworks](https://github.com/YSaxon/boltworks) - SlackのBoltフレームワークの拡張。展開可能なGUI、より扱いやすいコールバック、機能の充実したCLI

### R

- [slackr](https://github.com/hrbrmstr/slackr) - R から Slack のチャンネルやユーザーへ Webhook API メッセージを送るパッケージ

### Ruby

- [slack-notifier](https://github.com/stevenosloan/slack-notifier) - Slack へ投稿するシンプルなラッパー
- [slack-notify](https://github.com/sosedoff/slack-notify) - Slack へ通知を送信
- [slack-poster](https://github.com/rikas/slack-poster) - Webhook を使って Slack へメッセージを投稿するシンプルな Gem
- [slack-ruby-block-kit](https://github.com/CGA1123/slack-ruby-block-kit) - Slack Block Kit の Ruby ラッパー
- [slack-ruby-bot](https://github.com/dblock/slack-ruby-bot) - RubyでSlackボットを作成。原文では最も簡単な方法とされる
- [slack-ruby-bot-server](https://github.com/slack-ruby/slack-ruby-bot-server) - Slack アプリケーションを構築する Ruby ライブラリ
- [slack-ruby-client](https://github.com/dblock/slack-ruby-client) - Slack Web API と RealTime Messaging API 向け Ruby クライアント

### Rust

- [slack-morphism-rust](https://github.com/abdolence/slack-morphism-rust) - Rust向けの非同期Slack APIクライアント。原文ではモダンなクライアントとして紹介

### Scala

- [slack-scala-client](https://github.com/gilbertw1/slack-scala-client) - Web API と RTM API 向け Scala Slack クライアント

### Swift

- [SwiftBlocksUI](https://github.com/SwiftBlocksUI/SwiftBlocksUI/) - SwiftUI のような宣言的スタイルで作る対話型 Slack メッセージとモーダル

## オープンソースのSlackアプリと連携 <a id="gear--オープンソースの-slack-アプリと統合"></a>

### JavaScript/TypeScript

### PHP

- [monolog](https://github.com/Seldaek/monolog) - ログを Slack へ送信

### Python

- [slackbot](https://github.com/lins05/slackbot) - Slack 向けチャットボット
- [slacker-cli](https://github.com/juanpabloaj/slacker-cli) - コマンドラインから Slack へメッセージを送信
- [tasks-app](https://github.com/slackapi/tasks-app) - Slack が作成したシンプルなタスク管理アプリ
- [wee-slack](https://github.com/rawdigits/wee-slack) - Slack 向け WeeChat プラグイン

### Ruby

- [slack-gamebot](https://github.com/dblock/slack-gamebot) - Slack 向けゲームボット
- [snarkov](https://github.com/gesteves/snarkov) - Sinatra ベースの Slack 向けマルコフボット
- [tickbot](https://github.com/barryf/tickbot) - チームの作業時間の記録を促すシンプルなリマインダー
- [trebekbot](https://github.com/gesteves/trebekbot) - Slack 向け Jeopardy! ボット
