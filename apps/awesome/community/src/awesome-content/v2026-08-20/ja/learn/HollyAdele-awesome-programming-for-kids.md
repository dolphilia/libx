# Awesome Programming for Kids

Programming for Kidsを扱う資料や関連プロジェクトをまとめたAwesomeリストです。

## 目次
* [文字を読める前](#pre-literate)
* [小学校低学年](#lower-elementary)
* [小学校高学年](#upper-elementary)

## 文字を読める前
* [Scratch Jr.](https://www.scratchjr.org/) - 幼い子どもに、インタラクティブな物語やゲームを視覚的にコーディングする方法を教えるアプリ。タブレット向けの Scratch ウェブサイト簡略版です。
* [The Foos](https://itunes.apple.com/app/id923441570) - コマンド、パラメーター、ループ、条件分岐の概念を教える、読み書き前の子ども向けの楽しい iPad ゲーム。
* [Code-a-pillar](https://www.fisher-price.com/en-us/product/think-learn-code-a-pillar-twist-gfp25) - 指示を与える一連のセグメントをつなげることでプログラムできる、歩き、歌うイモムシのおもちゃ。

## 小学校低学年
* [Scratch](https://scratch.mit.edu/) - Scratch は MIT が作った、初心者向けの人気の視覚的プログラミング言語です。Scratch ウェブサイトは、子どもがインタラクティブな物語を作り、互いに共有するためのプラットフォームです。
* [Hopscotch](https://www.gethopscotch.com/) - Hopscotch は Scratch のようなコードブロックエディターですが、iOS アプリです。デバイスの傾きや振動に反応するコードをプログラムできます。
* [Evo from Ozobot](https://ozoblockly.com/editor?lang=en&robot=evo&mode=2) - Evo は、移動、発光、音を出すことのできる小型ロボットです。走行中の色も検出します。たどる線の色に基づいてコマンドに従えます。または、Scratch のようなコードブロックエディターでプログラムできます。ロボットを画面上の点滅するドットにかざすと、ウェブサイトが光の点滅によってプログラムをロボットへ読み込みます。
* [Lightbot](https://lightbot.com/) - コマンド、ループ、条件分岐でパズルを解きます。Lightbot、lightbot Jr、モバイルアプリ、デスクトップウェブサイトで利用できます。
* [Code.org](https://studio.code.org/) - 子ども向けのインタラクティブなコーディングゲームとコースを備えたウェブサイト。幅広い年齢とスキルレベルを対象とします。
* [Code Master](https://www.thinkfun.com/products/code-master/) - 問題解決能力とプログラミングロジックの理解を養う、夢中になれるボードゲーム。基本から始まり、非常に高度な内容へ進みます。
* [Cargo Bot](https://itunes.apple.com/us/app/cargo-bot/id519690804?mt=8) - コマンド、ループ、条件文で制約のある問題を解く iPad アプリ。Lightbot より難しいパズルです。
* [Python Turtle](https://github.com/PythonTurtle/PythonTurtle) original（1986-2021）のシンプルな「Python-Turtle」モデル。
* [Code Monkey](https://app.codemonkey.com/users/sign_up/student/age) - Python 系のコードを学ぶための、より多くのグラフィックを備えています。（高度なレベルは無料ではありません）


## 小学校高学年
* [tinkercad.com](https://www.tinkercad.com/things?type=codeblocks&view_mode=default) - TinkerCAD は子ども向けの無料 3D CAD モデリングソフトウェアです。ユーザーは Scratch のようなコードブロックを使って形状を操作することもできます。
* [DIY.org](https://diy.org/skills) - 子どもがあらゆることを学べるオンラインコミュニティ。掲載されるプログラミングスキルは、App Dev、Backend Dev、Frontend Dev、Game Dev、Graphic Designer、Open Sourcerer、Scratcher、Sys Admin、Web Designer です。
* [Code Combat](https://codecombat.com/) - JavaScript または Python を使い、ヒーローに英雄的なタスクを競わせます。ユーザーが新しいメソッドを学ぶたびに、ヒーローは新しい武器またはスキルを得ます。
* [Web Design for Kids](https://webdesign.tutsplus.com/series/web-design-for-kids--cms-823) - HTML と CSS によるウェブサイトのデザインと構築の基礎を子どもに教えるチュートリアルシリーズ。
* [Finch Robot](https://www.birdbraintechnologies.com/finch2/) - 複数のプログラミング言語をサポートする、コンピューターサイエンス教育向けに設計された小型ロボット。
* [Secret Coders](http://www.secret-coders.com/buy-the-books/) - Logo を通じてプログラミング概念を教える、魅力的な書籍シリーズ。
* [Khan Academy - Computer Programming](https://www.khanacademy.org/computing/computer-programming) - Khan Academy による、インタラクティブな課題付きウェブベースのプログラミングレッスンシリーズ。アニメーション、ゲーム開発、ウェブプログラミングなどのトピックを教えます。ユーザーは質問を投稿でき、コミュニティがすぐに回答します。
* [Bitsbox](https://bitsbox.com/) - 子どもにコーディングを教える月額ボックス購読サービス。
* [CS Unplugged](http://csunplugged.org/) - カード、ひも、クレヨン、たくさん走り回ることを使った魅力的なゲームとパズルを通じ、コンピューターサイエンスを教える無料学習活動のコレクション。
* [Lauren Ipsum](http://laurenipsum.org/) - プログラミングの文脈で問題解決の概念を教える本。サンプル章をオンラインで利用できます。
* [Lego Mindstorms](http://www.lego.com/en-us/mindstorms/?domainredir=mindstorms.lego.com) - Lego によるロボティクスキット。
* [Ruby Warrior](https://www.bloc.io/ruby-warrior#/) - Ruby プログラミングを教える、クールな音楽付きのオンラインチュートリアルゲーム。
* [Swift Playgrounds](http://www.apple.com/swift/playgrounds/) - Swift を学ぶための Apple の楽しい iPad アプリ。
* [Microsoft MakeCode](https://www.microsoft.com/en-us/makecode) - ゲーム開発、minecraft の mod 作成、ハードウェアハッキングなどのオンライン環境を含む、子ども向け教育ツール群。
* [Sphereo](https://sphero.com/products/mini-at-home-learning-kit) - 付属アプリ内のブロックプログラミング言語でプログラムできる球形ロボット。
* [KODU Game Lab](https://www.kodugamelab.com/) - Kodu を使うと、子どもはシンプルな視覚的プログラミング言語を通じ、PC と Xbox で 3D ゲームを作れます。
* [CodeKidz](https://codekidz.ai/) - Python、JavaScript、C/C++、ゲーム開発、機械学習、生成 AI などを含む、AI チューターとゲーム化コンテンツを通じて学びます。
