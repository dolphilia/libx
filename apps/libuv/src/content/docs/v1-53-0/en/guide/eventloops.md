You can also embed libuv’s&#10;event loop into another event loop based library – imagine a Qt based UI, and&#10;Qt’s event loop driving a libuv backend which does intensive system level&#10;tasks.</p>&#10;<section id="stopping-an-event-loop">&#10;<h2>Stopping an event loop<a class="headerlink" href="#stopping-an-event-loop" title="Permalink to this heading">¶</a></h2>&#10;<p><code class="docutils literal notranslate"><span class="pre">uv_stop()</span></code> can be used to stop an event loop.
