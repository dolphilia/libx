href="#uv-async-t-async-handle" title="この見出しへの固定リンク">¶</a></h1>&#10;<p>Asyncハンドルを使うと、別のスレッドからイベントループを「起こし」、コールバックを呼び出させることができます。</p>&#10;<div class="admonition note">&#10;<p title="uv&#95;async&#95;send"><code class="xref c c-func docutils literal notranslate"><span class="pre">uv&#95;async&#95;send()</span></code></a>より前に行われたすべてのメモリアクセス（読み取りと書き込み）は、そのコールバックから可視になります。</p>&#10;</div>&#10;<div class="admonition warning">&#10;<p class="admonition-title">警告</p>&#10;<p>libuvは<a class="reference internal" href="#c.uv&#95;async&#95;send" title="uv&#95;async&#95;send"><code class="xref c c-func docutils literal notranslate"><span class="pre">uv&#95;async&#95;send()</span></code></a>の呼び出しをまとめます。つまり、呼び出すたびに必ずコールバックが実行されるわけではありません。たとえば、コールバックが呼び出される前に<a class="reference internal" href="#c.uv&#95;async&#95;send" class="reference internal" href="#c.uv&#95;async&#95;send" title="uv&#95;async&#95;send"><code class="xref c c-func docutils literal notranslate"><span class="pre">uv&#95;async&#95;send()</span></code></a>を再び呼び出すと、コールバックも再び呼び出されます。ただし、逐次一貫性があるため、そのコールバックで読み書きする値は、もう一方のスレッドが読み書きした値と常に同じか、それより新しい値になります。</p>&#10;</div>&#10;<div class="versionchanged">&#10;<p><span class="versionmodified changed">バージョン1.53.0で変更: </span><a class="reference internal" href="#c.uv&#95;async&#95;send" title="uv&#95;async&#95;send"><code class="xref c c-func docutils literal notranslate"><span class="pre">uv&#95;async&#95;send()</span></code></a>と<a class="reference internal" href="#c.uv&#95;async&#95;cb" title="uv&#95;async&#95;cb"><code class="xref c c-type docutils literal notranslate"><span class="pre">uv&#95;async&#95;cb</span></code></a>は逐次一貫性を持ちます。これより前のバージョンでは、libuvが呼び出しをまとめる可能性のある場合、正しい動作のために、その前に完全な<cite>seq&#95;cst</cite>フェンスが必要になると考えられます。</p>&#10;</div>&#10;<section
