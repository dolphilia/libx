class="reference internal" href="/docs/libuv/v1-53-0/ja/reference/tcp/#c.uv&#95;tcp&#95;t" title="uv&#95;tcp&#95;t"><code class="xref c c-type docutils literal notranslate"><span docutils literal notranslate"><span class="pre">uv&#95;udp&#95;t</span></code></a>などの実装の方が、次の型よりも高速で、規模を拡大しやすいためです: <a class="reference internal" href="#c.uv&#95;poll&#95;t" title="uv&#95;poll&#95;t"><code class="xref c c-type docutils literal notranslate"><span
