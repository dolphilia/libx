<p>This module provides a simple, fast pseudo-random number generator.</p>
<p>It is an optional module. You can omit it from your application by setting the
preprocessor constant <code>WREN_OPT_RANDOM</code> to <code>0</code>.</p>
<p>It contains a single class:</p>
<ul>
<li><a href="/docs/wren-trial/v0-4-0/en/docs/modules/random/random/">Random</a></li>
</ul>
