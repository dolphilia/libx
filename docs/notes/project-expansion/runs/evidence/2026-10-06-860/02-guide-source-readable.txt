16 [p] In the examples above we already used the ⟦CODE0⟧ function in order to get
the length of the string. This function works like ⟦CODE1⟧ of the libc
except that:

17 [li] It runs in constant time since the length is stored in the prefix of SDS strings, so calling ⟦CODE0⟧ is not expensive even when called with very large strings.

18 [li] The function is binary safe like any other SDS string function, so the length is the true length of the string regardless of the content, there is no problem if the string includes null term characters in the middle.
