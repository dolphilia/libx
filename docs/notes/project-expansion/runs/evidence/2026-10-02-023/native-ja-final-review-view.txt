6: # ネイティブアクセス
10: ## 説明
12: **ネイティブアクセス関数を使用することは、自分が何をしているか、およびその使用によって生じた問題をどう修正するかを理解していると表明することです。理解していない場合は使用すべきではありません。**
14: glfw3native.h をインクルードする前に、ウィンドウシステム API マクロを 0 個以上、コンテキスト作成 API マクロを 0 個以上定義できます。
16: 選択するバックエンドは、ライブラリのコンパイル対象と一致していなければなりません。一致しない場合はリンク時エラーになります。
18: 利用可能なウィンドウ API マクロは次のとおりです。
20: - `GLFW_EXPOSE_NATIVE_WIN32`
21: - `GLFW_EXPOSE_NATIVE_COCOA`
22: - `GLFW_EXPOSE_NATIVE_X11`
23: - `GLFW_EXPOSE_NATIVE_WAYLAND`
25: 利用可能なコンテキスト API マクロは次のとおりです。
27: - `GLFW_EXPOSE_NATIVE_WGL`
28: - `GLFW_EXPOSE_NATIVE_NSGL`
29: - `GLFW_EXPOSE_NATIVE_GLX`
30: - `GLFW_EXPOSE_NATIVE_EGL`
31: - `GLFW_EXPOSE_NATIVE_OSMESA`
33: これらのマクロは、宣言するネイティブアクセス関数と、インクルードするプラットフォーム固有ヘッダーを選択します。どれを定義すべきかは、必然的にプラットフォーム固有となる利用側のコードで処理します。
35: プラットフォーム固有ヘッダーをインクルードしたくない場合は、glfw3native.h ヘッダーをインクルードする前に `GLFW_NATIVE_INCLUDE_NONE` を定義してください。
41: \#define GLFW_EXPOSE_NATIVE_WIN32
47: \#define GLFW_EXPOSE_NATIVE_WGL
53: \#define GLFW_NATIVE_INCLUDE_NONE
59: \#include \<GLFW/glfw3native.h\>
67: [glfw3native.h](https://www.glfw.org/docs/3.5.1/glfw3native_8h.html)
