76: Description
77: By using the native access functions you assert that you know what you're doing and how to fix problems caused by using them. If you don't, you shouldn't be using them.
78: Before the inclusion of glfw3native.h, you may define zero or more window system API macro and zero or more context creation API macros.
79: The chosen backends must match those the library was compiled for. Failure to do this will cause a link-time error.
80: The available window API macros are:
81: GLFW_EXPOSE_NATIVE_WIN32
82: GLFW_EXPOSE_NATIVE_COCOA
83: GLFW_EXPOSE_NATIVE_X11
84: GLFW_EXPOSE_NATIVE_WAYLAND
86: The available context API macros are:
87: GLFW_EXPOSE_NATIVE_WGL
88: GLFW_EXPOSE_NATIVE_NSGL
89: GLFW_EXPOSE_NATIVE_GLX
90: GLFW_EXPOSE_NATIVE_EGL
91: GLFW_EXPOSE_NATIVE_OSMESA
93: These macros select which of the native access functions that are declared and which platform-specific headers to include. It is then up your (by definition platform-specific) code to handle which of these should be defined.
94: If you do not want the platform-specific headers to be included, define GLFW_NATIVE_INCLUDE_NONE before including the glfw3native.h header.
95: #define GLFW_EXPOSE_NATIVE_WIN32
96: #define GLFW_EXPOSE_NATIVE_WGL
97: #define GLFW_NATIVE_INCLUDE_NONE
98: #include <GLFW/glfw3native.h>
99: glfw3native.hThe header of the native access functions.
