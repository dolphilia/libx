8: ## Description
10: **By using the native access functions you assert that you know what you're doing and how to fix problems caused by using them. If you don't, you shouldn't be using them.**
12: Before the inclusion of glfw3native.h, you may define zero or more window system API macro and zero or more context creation API macros.
14: The chosen backends must match those the library was compiled for. Failure to do this will cause a link-time error.
16: The available window API macros are:
18: - `GLFW_EXPOSE_NATIVE_WIN32`
19: - `GLFW_EXPOSE_NATIVE_COCOA`
20: - `GLFW_EXPOSE_NATIVE_X11`
21: - `GLFW_EXPOSE_NATIVE_WAYLAND`
23: The available context API macros are:
25: - `GLFW_EXPOSE_NATIVE_WGL`
26: - `GLFW_EXPOSE_NATIVE_NSGL`
27: - `GLFW_EXPOSE_NATIVE_GLX`
28: - `GLFW_EXPOSE_NATIVE_EGL`
29: - `GLFW_EXPOSE_NATIVE_OSMESA`
31: These macros select which of the native access functions that are declared and which platform-specific headers to include. It is then up your (by definition platform-specific) code to handle which of these should be defined.
33: If you do not want the platform-specific headers to be included, define `GLFW_NATIVE_INCLUDE_NONE` before including the glfw3native.h header.
39: \#define GLFW_EXPOSE_NATIVE_WIN32
45: \#define GLFW_EXPOSE_NATIVE_WGL
51: \#define GLFW_NATIVE_INCLUDE_NONE
57: \#include \<GLFW/glfw3native.h\>
65: [glfw3native.h](https://www.glfw.org/docs/3.5.1/glfw3native_8h.html)
71: The header of the native access functions.
