6: # Native access
10: ## Description
12: **By using the native access functions you assert that you know what you're doing and how to fix problems caused by using them. If you don't, you shouldn't be using them.**
14: Before the inclusion of glfw3native.h, you may define zero or more window system API macro and zero or more context creation API macros.
16: The chosen backends must match those the library was compiled for. Failure to do this will cause a link-time error.
18: The available window API macros are:
20: - `GLFW_EXPOSE_NATIVE_WIN32`
21: - `GLFW_EXPOSE_NATIVE_COCOA`
22: - `GLFW_EXPOSE_NATIVE_X11`
23: - `GLFW_EXPOSE_NATIVE_WAYLAND`
25: The available context API macros are:
27: - `GLFW_EXPOSE_NATIVE_WGL`
28: - `GLFW_EXPOSE_NATIVE_NSGL`
29: - `GLFW_EXPOSE_NATIVE_GLX`
30: - `GLFW_EXPOSE_NATIVE_EGL`
31: - `GLFW_EXPOSE_NATIVE_OSMESA`
33: These macros select which of the native access functions that are declared and which platform-specific headers to include. It is then up your (by definition platform-specific) code to handle which of these should be defined.
35: If you do not want the platform-specific headers to be included, define `GLFW_NATIVE_INCLUDE_NONE` before including the glfw3native.h header.
41: \#define GLFW_EXPOSE_NATIVE_WIN32
47: \#define GLFW_EXPOSE_NATIVE_WGL
53: \#define GLFW_NATIVE_INCLUDE_NONE
59: \#include \<GLFW/glfw3native.h\>
67: [glfw3native.h](https://www.glfw.org/docs/3.5.1/glfw3native_8h.html)
73: The header of the native access functions.
