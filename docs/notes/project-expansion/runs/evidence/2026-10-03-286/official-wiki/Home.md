The official docs for Wren itself are at [wren.io](http://wren.io).

We use the wiki—and your help—to keep track of the wild and wooly world of Wren's external ecosystem. If someone has created something that builds on or works with Wren, you'll find it here. If *you've* created one of those, please do add it.

* [Applications](./Applications) that host Wren as a scripting language.
* [Modules](./Modules) written in Wren that others can use.
* [Language Bindings](./Language-Bindings) that let you interact with Wren from other programming
  languages.
* Other [tools and utilities](./Tools) that make it easier to be a Wren programmer.
* See the [cookbook](./Cookbook) for small scripts or tutorials.

## Getting help

If at any point you have questions, feel free to [file an issue][issue] or ask
on the [discord community][discord] (or the [mailing list][list]). If you're a Redditor, try the
[/r/wren_lang][subreddit] subreddit. You can also email me directly (`robert` at
`stuffwithstuff.com`) if you want something less public.
