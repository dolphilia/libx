The ecosystem of third-party modules is small, but growing!   
Have a Wren module you want to share? Feel free to add it!

## Wren Modules

### Testing / Assertions

* [domepunk-unit](https://github.com/NinjasCL/domepunk/wiki/test.unit.wren) - Another testing utility. Tailored for [DOME](http://domeengine.com).
* [wren-assert](https://github.com/robloach/wren-assert) - Assertion library for unit testing
* [wren-please](https://github.com/EvanHahn/wren-please) - Assertion library
* [wren-warbler](https://github.com/seanohue/wren-warbler) - Mini unit testing module.
* [wren-test](https://github.com/gsmaverick/wren-test) - A testing framework
* [wren-testie](https://github.com/joshgoebel/wren-testie) Simple, beautiful, and fun testing framework

### Graphics / Math

* [wren-vector](https://github.com/FreddieRidell/wren-vector) - 2D, 3D & 4D vector with various operators
* [wren-vector3d](https://github.com/EvanHahn/wren-vector3d) - 3D vectors
* [wren-complex](https://github.com/sethebner/wren-complex) - Complex numbers

### Data

* [agents](https://github.com/chances/wren-agents) - Agent-based modeling (ABM) framework
* [optional](https://github.com/ajermakovics/optional) - Optional (Maybe) type
* [Recto](https://github.com/BrianOtto/Recto) - A String manipulation library
* [wren-beak](https://github.com/seanohue/wren-beak) - A functional list manipulation library
* [wren-enum](https://github.com/datatypevoid/wren-enum) - Enumerated types
* [wren-helpers](https://github.com/minirop/wren-helpers) - Data structures & helper functions
* [wren-tempo](https://github.com/FreddieRidell/wren-tempo) An object for DateTime and duration manipulation

### Parsing

* [wren-magpie](https://github.com/chances/wren-magpie) - Parser combinator library
* [wren-json](https://github.com/ruby0x1/wren-json) - Handling JSON
* [msgpack-wren](https://github.com/chances/msgpack-wren) - [MessagePack](https://msgpack.org) implementation
* [wren-toml](https://github.com/datatypevoid/wren-toml) - [TOML](https://github.com/toml-lang/toml) parser
* [wren-xsequence](https://github.com/Deijin27/wren-xsequence) - XML parser/writer

### Dependency Injection

* [wren-dojo](https://github.com/guan-tends/wren-dojo) - Wren-native DI container featuring runtime-resolved dependency injection with Composition-Root IoC

### Utilities

* [b95](https://github.com/paladin-t/b95) - A Lua to Wren compiler in Wren
* [wren-args](https://github.com/heyitsmeuralex/wren-args) - Simple command-line arguments parser
* [wren-async-task](https://github.com/joshgoebel/wren-async-task) - Async run/wait functions 
* [wren-benchie](https://github.com/joshgoebel/wren-benchie) - Simple and easy benchmarking for Wren
* [wren-colors](https://github.com/gsmaverick/wren-colors) - Print fancy messages to the terminal
* [wren-dojo](https://github.com/guan-tends/wren-dojo) - Runtime-resolved dependency injection container (Composition-Root IoC)
* [wren-package](https://github.com/joshgoebel/wren-package) - Dirt simple dependencies (ie, `package.wren`)
* [wren-path](https://github.com/RobLoach/wren-path) - Work with file and directory paths
* [wren-pure](https://github.com/brandly/wren-pure) - Utility library
* [wren-warble](https://github.com/datatypevoid/wren-warble) - Policy-based logging utility
* [wrench](https://github.com/maxdeviant/wrench) - Small utilities for Wren
* [wren-semver](https://github.com/FreddieRidell/wren-semver) - Semantic versioning package

## Compiled Modules

Compiled Wren modules are C/C++ libraries that add to Wren.

- [wren-bind](https://github.com/RobLoach/wren-bind) - Provides a registry to easily bind multiple compiled Wren modules
