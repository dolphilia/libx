A language these days needs a surprisingly large amount of utilities, syntax highlighters, etc. to be useful. We've got a ways to go, but we're getting there.

## Tools and Utilities

Things that make life easier:

- [The Wren Nest](http://ppvk.github.io/wren-nest/) – Run and share Wren in your browser.
- [Dockerised Wren](https://hub.docker.com/r/ajpaulson/wren/) - Run Wren from Docker.
- [Try Wren Online](https://tio.run/#wren) – Run 600+ languages online, including Wren
- [Wren Doc](https://github.com/NinjasCL/domepunk/wiki/tools.wrendoc) - Document your Wren code with Markdown
- [Wren Bundie](https://github.com/joshgoebel/wren-bundie) - Bundle a large dependency tree into a single `.wren` script
- [Wrench](https://github.com/jaybaird/wrench) - Simple "compiler" to detect compilation errors while saving from your favorite editor.
- [wren-module](https://github.com/chances/wren-module) - Project template for new Wren modules
- [gubed](https://github.com/amirgeva/gubed) - Simple console instrumenting debugger
- [Wren html main doc from wren.io](https://github.com/OneByTheSide/wren-main-doc) - Wren HTML doc(NOT ALL)

Want to add something to this list? Go for it!
