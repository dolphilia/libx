1478: ## [◆ ](#gaa92336e173da9c8834558b54ee80563b)glfwSetInputMode()
1486: | void glfwSetInputMode | ( | GLFWwindow \*  | *window*, |
1487: |  |  | int  | *mode*, |
1488: |  |  | int  | *value*  |
1489: |  | ) |  |  |
1495: This function sets an input mode option for the specified window. The mode must be one of GLFW_CURSOR, GLFW_STICKY_KEYS, GLFW_STICKY_MOUSE_BUTTONS, GLFW_LOCK_KEY_MODS GLFW_RAW_MOUSE_MOTION, or GLFW_UNLIMITED_MOUSE_BUTTONS.
1497: If the mode is `GLFW_CURSOR`, the value must be one of the following cursor modes:
1499: - `GLFW_CURSOR_NORMAL` makes the cursor visible and behaving normally.
1500: - `GLFW_CURSOR_HIDDEN` makes the cursor invisible when it is over the content area of the window but does not restrict the cursor from leaving.
1501: - `GLFW_CURSOR_DISABLED` hides and grabs the cursor, providing virtual and unlimited cursor movement. This is useful for implementing for example 3D camera controls.
1502: - `GLFW_CURSOR_CAPTURED` makes the cursor visible and confines it to the content area of the window.
1504: If the mode is `GLFW_STICKY_KEYS`, the value must be either `GLFW_TRUE` to enable sticky keys, or `GLFW_FALSE` to disable it. If sticky keys are enabled, a key press will ensure that glfwGetKey returns `GLFW_PRESS` the next time it is called even if the key had been released before the call. This is useful when you are only interested in whether keys have been pressed but not when or in which order.
1506: If the mode is `GLFW_STICKY_MOUSE_BUTTONS`, the value must be either `GLFW_TRUE` to enable sticky mouse buttons, or `GLFW_FALSE` to disable it. If sticky mouse buttons are enabled, a mouse button press will ensure that glfwGetMouseButton returns `GLFW_PRESS` the next time it is called even if the mouse button had been released before the call. This is useful when you are only interested in whether mouse buttons have been pressed but not when or in which order.
1508: If the mode is `GLFW_LOCK_KEY_MODS`, the value must be either `GLFW_TRUE` to enable lock key modifier bits, or `GLFW_FALSE` to disable them. If enabled, callbacks that receive modifier bits will also have the GLFW_MOD_CAPS_LOCK bit set when the event was generated with Caps Lock on, and the GLFW_MOD_NUM_LOCK bit when Num Lock was on.
1510: If the mode is `GLFW_RAW_MOUSE_MOTION`, the value must be either `GLFW_TRUE` to enable raw (unscaled and unaccelerated) mouse motion when the cursor is disabled, or `GLFW_FALSE` to disable it. If raw motion is not supported, attempting to set this will emit GLFW_FEATURE_UNAVAILABLE. Call glfwRawMouseMotionSupported to check for support.
1512: If the mode is `GLFW_UNLIMITED_MOUSE_BUTTONS`, the value must be either `GLFW_TRUE` to disable the mouse button limit when calling the mouse button callback, or `GLFW_FALSE` to limit the mouse buttons sent to the callback to the mouse button token values up to `GLFW_MOUSE_BUTTON_LAST`.
1514: Parameters  
1517: | \[in\] | window | The window whose input mode to set. |
1518: | \[in\] | mode | One of `GLFW_CURSOR`, `GLFW_STICKY_KEYS`, `GLFW_STICKY_MOUSE_BUTTONS`, `GLFW_LOCK_KEY_MODS` or `GLFW_RAW_MOUSE_MOTION`. |
1519: | \[in\] | value | The new value of the specified input mode. |
1523: Errors  
1524: Possible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_ENUM, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see above).
1528: Thread safety  
1529: This function must only be called from the main thread.
1533: See also  
1534: glfwGetInputMode
1538: Since  
1539: Added in version 3.0. Replaces `glfwEnable` and `glfwDisable`.
1547: ## [◆ ](#gae4ee0dbd0d256183e1ea4026d897e1c2)glfwRawMouseMotionSupported()
1555: | int glfwRawMouseMotionSupported | (   | void  |     | )   |     |
1561: This function returns whether raw mouse motion is supported on the current system. This status does not change after GLFW has been initialized so you only need to check this once. If you attempt to enable raw motion on a system that does not support it, GLFW_PLATFORM_ERROR will be emitted.
1563: Raw mouse motion is closer to the actual motion of the mouse across a surface. It is not affected by the scaling and acceleration applied to the motion of the desktop cursor. That processing is suitable for a cursor while raw motion is better for controlling for example a 3D camera. Because of this, raw mouse motion is only provided when the cursor is disabled.
1565: Returns  
1566: `GLFW_TRUE` if raw mouse motion is supported on the current machine, or `GLFW_FALSE` otherwise.
1570: Errors  
1571: Possible errors include GLFW_NOT_INITIALIZED.
1575: Thread safety  
1576: This function must only be called from the main thread.
1580: See also  
1581: Raw mouse motion

1596: ## [◆ ](#gaeaed62e69c3bd62b7ff8f7b19913ce4f)glfwGetKeyName()
1604: | const char \* glfwGetKeyName | (   | int  | *key*,      |
1605: |                              |     | int  | *scancode*  |
1606: |                              | )   |      |             |
1612: This function returns the name of the specified printable key, encoded as UTF-8. This is typically the character that key would produce without any modifier keys, intended for displaying key bindings to the user. For dead keys, it is typically the diacritic it would add to a character.
1614: **Do not use this function** for text input. You will break text input for many languages even if it happens to work for yours.
1616: If the key is `GLFW_KEY_UNKNOWN`, the scancode is used to identify the key, otherwise the scancode is ignored. If you specify a non-printable key, or `GLFW_KEY_UNKNOWN` and a scancode that maps to a non-printable key, this function returns `NULL` but does not emit an error.
1618: This behavior allows you to always pass in the arguments in the key callback without modification.
1620: The printable keys are:
1622: - `GLFW_KEY_APOSTROPHE`
1623: - `GLFW_KEY_COMMA`
1624: - `GLFW_KEY_MINUS`
1625: - `GLFW_KEY_PERIOD`
1626: - `GLFW_KEY_SLASH`
1627: - `GLFW_KEY_SEMICOLON`
1628: - `GLFW_KEY_EQUAL`
1629: - `GLFW_KEY_LEFT_BRACKET`
1630: - `GLFW_KEY_RIGHT_BRACKET`
1631: - `GLFW_KEY_BACKSLASH`
1632: - `GLFW_KEY_WORLD_1`
1633: - `GLFW_KEY_WORLD_2`
1634: - `GLFW_KEY_0` to `GLFW_KEY_9`
1635: - `GLFW_KEY_A` to `GLFW_KEY_Z`
1636: - `GLFW_KEY_KP_0` to `GLFW_KEY_KP_9`
1637: - `GLFW_KEY_KP_DECIMAL`
1638: - `GLFW_KEY_KP_DIVIDE`
1639: - `GLFW_KEY_KP_MULTIPLY`
1640: - `GLFW_KEY_KP_SUBTRACT`
1641: - `GLFW_KEY_KP_ADD`
1642: - `GLFW_KEY_KP_EQUAL`
1644: Names for printable keys depend on keyboard layout, while names for non-printable keys are the same across layouts but depend on the application language and should be localized along with other user interface text.
1646: Parameters  
1649: | \[in\] | key      | The key to query, or `GLFW_KEY_UNKNOWN`. |
1650: | \[in\] | scancode | The scancode of the key to query.        |
1654: Returns  
1655: The UTF-8 encoded, layout-specific name of the key, or `NULL`.
1659: Errors  
1660: Possible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_VALUE, GLFW_INVALID_ENUM and GLFW_PLATFORM_ERROR.
1664: Remarks  
1665: The contents of the returned string may change when a keyboard layout change event is received.
1669: Pointer lifetime  
1670: The returned string is allocated and freed by GLFW. You should not free it yourself. It is valid until the library is terminated.
1674: Thread safety  
1675: This function must only be called from the main thread.
1679: See also  
1680: Key names
1684: Since
