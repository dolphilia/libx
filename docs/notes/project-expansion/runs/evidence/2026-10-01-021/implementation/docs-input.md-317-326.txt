318: If you wish the cursor to be visible but confined to the content area of the
319: window, set the cursor mode to `GLFW_CURSOR_CAPTURED`.
320: 
321: ```c
322: glfwSetInputMode(window, GLFW_CURSOR, GLFW_CURSOR_CAPTURED);
323: ```
324: 
325: The cursor will behave normally inside the content area but will not be able to
326: leave unless the window loses focus.
