658: ◆ glfwSetInputMode()
664:           void glfwSetInputMode 
665:           (
666:           GLFWwindow * 
667:           window, 
672:           int 
673:           mode, 
678:           int 
679:           value 
683:           )
688: This function sets an input mode option for the specified window. The mode must be one of GLFW_CURSOR, GLFW_STICKY_KEYS, GLFW_STICKY_MOUSE_BUTTONS, GLFW_LOCK_KEY_MODS GLFW_RAW_MOUSE_MOTION, or GLFW_UNLIMITED_MOUSE_BUTTONS.
689: If the mode is GLFW_CURSOR, the value must be one of the following cursor modes:
690: GLFW_CURSOR_NORMAL makes the cursor visible and behaving normally.
691: GLFW_CURSOR_HIDDEN makes the cursor invisible when it is over the content area of the window but does not restrict the cursor from leaving.
692: GLFW_CURSOR_DISABLED hides and grabs the cursor, providing virtual and unlimited cursor movement. This is useful for implementing for example 3D camera controls.
693: GLFW_CURSOR_CAPTURED makes the cursor visible and confines it to the content area of the window.
695: If the mode is GLFW_STICKY_KEYS, the value must be either GLFW_TRUE to enable sticky keys, or GLFW_FALSE to disable it. If sticky keys are enabled, a key press will ensure that glfwGetKey returns GLFW_PRESS the next time it is called even if the key had been released before the call. This is useful when you are only interested in whether keys have been pressed but not when or in which order.
696: If the mode is GLFW_STICKY_MOUSE_BUTTONS, the value must be either GLFW_TRUE to enable sticky mouse buttons, or GLFW_FALSE to disable it. If sticky mouse buttons are enabled, a mouse button press will ensure that glfwGetMouseButton returns GLFW_PRESS the next time it is called even if the mouse button had been released before the call. This is useful when you are only interested in whether mouse buttons have been pressed but not when or in which order.
697: If the mode is GLFW_LOCK_KEY_MODS, the value must be either GLFW_TRUE to enable lock key modifier bits, or GLFW_FALSE to disable them. If enabled, callbacks that receive modifier bits will also have the GLFW_MOD_CAPS_LOCK bit set when the event was generated with Caps Lock on, and the GLFW_MOD_NUM_LOCK bit when Num Lock was on.
698: If the mode is GLFW_RAW_MOUSE_MOTION, the value must be either GLFW_TRUE to enable raw (unscaled and unaccelerated) mouse motion when the cursor is disabled, or GLFW_FALSE to disable it. If raw motion is not supported, attempting to set this will emit GLFW_FEATURE_UNAVAILABLE. Call glfwRawMouseMotionSupported to check for support.
699: If the mode is GLFW_UNLIMITED_MOUSE_BUTTONS, the value must be either GLFW_TRUE to disable the mouse button limit when calling the mouse button callback, or GLFW_FALSE to limit the mouse buttons sent to the callback to the mouse button token values up to GLFW_MOUSE_BUTTON_LAST.
700: Parameters
702:     [in]windowThe window whose input mode to set. 
703:     [in]modeOne of GLFW_CURSOR, GLFW_STICKY_KEYS, GLFW_STICKY_MOUSE_BUTTONS, GLFW_LOCK_KEY_MODS or GLFW_RAW_MOUSE_MOTION. 
704:     [in]valueThe new value of the specified input mode.
708: ErrorsPossible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_ENUM, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see above).
709: Thread safetyThis function must only be called from the main thread.
710: See alsoglfwGetInputMode

716: ◆ glfwRawMouseMotionSupported()
722:           int glfwRawMouseMotionSupported 
723:           (
724:           void 
725:           )
730: This function returns whether raw mouse motion is supported on the current system. This status does not change after GLFW has been initialized so you only need to check this once. If you attempt to enable raw motion on a system that does not support it, GLFW_PLATFORM_ERROR will be emitted.
731: Raw mouse motion is closer to the actual motion of the mouse across a surface. It is not affected by the scaling and acceleration applied to the motion of the desktop cursor. That processing is suitable for a cursor while raw motion is better for controlling for example a 3D camera. Because of this, raw mouse motion is only provided when the cursor is disabled.

733: ErrorsPossible errors include GLFW_NOT_INITIALIZED.

767: This function returns the name of the specified printable key, encoded as UTF-8. This is typically the character that key would produce without any modifier keys, intended for displaying key bindings to the user. For dead keys, it is typically the diacritic it would add to a character.
768: Do not use this function for text input. You will break text input for many languages even if it happens to work for yours.
769: If the key is GLFW_KEY_UNKNOWN, the scancode is used to identify the key, otherwise the scancode is ignored. If you specify a non-printable key, or GLFW_KEY_UNKNOWN and a scancode that maps to a non-printable key, this function returns NULL but does not emit an error.
770: This behavior allows you to always pass in the arguments in the key callback without modification.
