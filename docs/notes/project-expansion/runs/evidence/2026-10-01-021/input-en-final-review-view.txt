1482: ## [◆ ](#gaa92336e173da9c8834558b54ee80563b)glfwSetInputMode()
1490: | void glfwSetInputMode | ( | GLFWwindow \*  | *window*, |
1491: |  |  | int  | *mode*, |
1492: |  |  | int  | *value*  |
1493: |  | ) |  |  |
1499: This function sets an input mode option for the specified window. The mode must be one of GLFW_CURSOR, GLFW_STICKY_KEYS, GLFW_STICKY_MOUSE_BUTTONS, GLFW_LOCK_KEY_MODS GLFW_RAW_MOUSE_MOTION, or GLFW_UNLIMITED_MOUSE_BUTTONS.
1501: If the mode is `GLFW_CURSOR`, the value must be one of the following cursor modes:
1503: - `GLFW_CURSOR_NORMAL` makes the cursor visible and behaving normally.
1504: - `GLFW_CURSOR_HIDDEN` makes the cursor invisible when it is over the content area of the window but does not restrict the cursor from leaving.
1505: - `GLFW_CURSOR_DISABLED` hides and grabs the cursor, providing virtual and unlimited cursor movement. This is useful for implementing for example 3D camera controls.
1506: - `GLFW_CURSOR_CAPTURED` makes the cursor visible and confines it to the content area of the window.
1508: If the mode is `GLFW_STICKY_KEYS`, the value must be either `GLFW_TRUE` to enable sticky keys, or `GLFW_FALSE` to disable it. If sticky keys are enabled, a key press will ensure that glfwGetKey returns `GLFW_PRESS` the next time it is called even if the key had been released before the call. This is useful when you are only interested in whether keys have been pressed but not when or in which order.
1510: If the mode is `GLFW_STICKY_MOUSE_BUTTONS`, the value must be either `GLFW_TRUE` to enable sticky mouse buttons, or `GLFW_FALSE` to disable it. If sticky mouse buttons are enabled, a mouse button press will ensure that glfwGetMouseButton returns `GLFW_PRESS` the next time it is called even if the mouse button had been released before the call. This is useful when you are only interested in whether mouse buttons have been pressed but not when or in which order.
1512: If the mode is `GLFW_LOCK_KEY_MODS`, the value must be either `GLFW_TRUE` to enable lock key modifier bits, or `GLFW_FALSE` to disable them. If enabled, callbacks that receive modifier bits will also have the GLFW_MOD_CAPS_LOCK bit set when the event was generated with Caps Lock on, and the GLFW_MOD_NUM_LOCK bit when Num Lock was on.
1514: If the mode is `GLFW_RAW_MOUSE_MOTION`, the value must be either `GLFW_TRUE` to enable raw (unscaled and unaccelerated) mouse motion when the cursor is disabled, or `GLFW_FALSE` to disable it. If raw motion is not supported, attempting to set this will emit GLFW_FEATURE_UNAVAILABLE. Call glfwRawMouseMotionSupported to check for support.
1516: > **Libx reference note (GLFW 3.5.1):** The paragraph above names `GLFW_FEATURE_UNAVAILABLE`. The [fixed implementation](https://github.com/glfw/glfw/blob/3.5.1/src/input.c#L668-L687) instead emits `GLFW_PLATFORM_ERROR` when raw mouse motion is unsupported, matching the description of `glfwRawMouseMotionSupported`. The upstream wording is preserved above.
1518: If the mode is `GLFW_UNLIMITED_MOUSE_BUTTONS`, the value must be either `GLFW_TRUE` to disable the mouse button limit when calling the mouse button callback, or `GLFW_FALSE` to limit the mouse buttons sent to the callback to the mouse button token values up to `GLFW_MOUSE_BUTTON_LAST`.
1520: > **Libx reference note (GLFW 3.5.1):** The parameter table below omits `GLFW_UNLIMITED_MOUSE_BUTTONS`, although this paragraph describes it. The [fixed implementation](https://github.com/glfw/glfw/blob/3.5.1/src/input.c#L689-L693) accepts this mode. The upstream table is preserved.
1522: Parameters  
1525: | \[in\] | window | The window whose input mode to set. |
1526: | \[in\] | mode | One of `GLFW_CURSOR`, `GLFW_STICKY_KEYS`, `GLFW_STICKY_MOUSE_BUTTONS`, `GLFW_LOCK_KEY_MODS` or `GLFW_RAW_MOUSE_MOTION`. |
1527: | \[in\] | value | The new value of the specified input mode. |
1531: Errors  
1532: Possible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_ENUM, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see above).
1536: Thread safety  
1537: This function must only be called from the main thread.
1541: See also

1555: ## [◆ ](#gae4ee0dbd0d256183e1ea4026d897e1c2)glfwRawMouseMotionSupported()
1563: | int glfwRawMouseMotionSupported | (   | void  |     | )   |     |
1569: This function returns whether raw mouse motion is supported on the current system. This status does not change after GLFW has been initialized so you only need to check this once. If you attempt to enable raw motion on a system that does not support it, GLFW_PLATFORM_ERROR will be emitted.
1571: Raw mouse motion is closer to the actual motion of the mouse across a surface. It is not affected by the scaling and acceleration applied to the motion of the desktop cursor. That processing is suitable for a cursor while raw motion is better for controlling for example a 3D camera. Because of this, raw mouse motion is only provided when the cursor is disabled.
1573: Returns  
1574: `GLFW_TRUE` if raw mouse motion is supported on the current machine, or `GLFW_FALSE` otherwise.
1578: Errors  
1579: Possible errors include GLFW_NOT_INITIALIZED.
1583: Thread safety  
1584: This function must only be called from the main thread.
1588: See also  
1589: Raw mouse motion
1591: glfwSetInputMode
1595: Since  
1596: Added in version 3.3.
1604: ## [◆ ](#gaeaed62e69c3bd62b7ff8f7b19913ce4f)glfwGetKeyName()
1612: | const char \* glfwGetKeyName | (   | int  | *key*,      |
1613: |                              |     | int  | *scancode*  |
1614: |                              | )   |      |             |
1620: This function returns the name of the specified printable key, encoded as UTF-8. This is typically the character that key would produce without any modifier keys, intended for displaying key bindings to the user. For dead keys, it is typically the diacritic it would add to a character.
1622: **Do not use this function** for text input. You will break text input for many languages even if it happens to work for yours.
1624: If the key is `GLFW_KEY_UNKNOWN`, the scancode is used to identify the key, otherwise the scancode is ignored. If you specify a non-printable key, or `GLFW_KEY_UNKNOWN` and a scancode that maps to a non-printable key, this function returns `NULL` but does not emit an error.
1626: This behavior allows you to always pass in the arguments in the key callback without modification.
1628: The printable keys are:
1630: - `GLFW_KEY_APOSTROPHE`
1631: - `GLFW_KEY_COMMA`
1632: - `GLFW_KEY_MINUS`
1633: - `GLFW_KEY_PERIOD`
1634: - `GLFW_KEY_SLASH`
1635: - `GLFW_KEY_SEMICOLON`
1636: - `GLFW_KEY_EQUAL`
1637: - `GLFW_KEY_LEFT_BRACKET`
1638: - `GLFW_KEY_RIGHT_BRACKET`
1639: - `GLFW_KEY_BACKSLASH`
1640: - `GLFW_KEY_WORLD_1`
1641: - `GLFW_KEY_WORLD_2`
1642: - `GLFW_KEY_0` to `GLFW_KEY_9`
1643: - `GLFW_KEY_A` to `GLFW_KEY_Z`
1644: - `GLFW_KEY_KP_0` to `GLFW_KEY_KP_9`
1645: - `GLFW_KEY_KP_DECIMAL`
1646: - `GLFW_KEY_KP_DIVIDE`
1647: - `GLFW_KEY_KP_MULTIPLY`
1648: - `GLFW_KEY_KP_SUBTRACT`
1649: - `GLFW_KEY_KP_ADD`
1650: - `GLFW_KEY_KP_EQUAL`
