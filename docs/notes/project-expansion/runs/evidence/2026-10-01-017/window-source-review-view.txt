1653: This function creates a window and its associated OpenGL or OpenGL ES context. Most of the options controlling how the window and its context should be created are specified with window hints.
1654: Successful creation does not change which context is current. Before you can use the newly created context, you need to make it current. For information about the share parameter, see Context object sharing.
1655: The created window, framebuffer and context may differ from what you requested, as not all parameters and hints are hard constraints. 1656: To create a full screen window, you need to specify the monitor the window will cover. If no monitor is specified, the window will be windowed mode. 1657: For full screen windows, the specified size becomes the resolution of the window's desired video mode. For more information about full screen windows, including the creation of so called windowed full screen or borderless full screen windows, see "Windowed full screen" windows.
1658: Once you have created the window, you can switch it between windowed and full screen mode with glfwSetWindowMonitor. This will not affect its OpenGL or OpenGL ES context.

3509: void glfwWaitEventsTimeout
3510: (
3511: double
3512: timeout)
3517: This function puts the calling thread to sleep until at least one event is available in the event queue, or until the specified timeout is reached. If one or more events are available, it behaves exactly like glfwPollEvents, i.e. the events in the queue are processed and the function then returns immediately. Processing events will cause the window and input callbacks associated with those events to be called.
3518: The timeout value must be a positive finite number.
3519: Since not all events are associated with callbacks, this function may return without a callback having been called even if you are monitoring all callbacks.
3520: On some platforms, a window move, resize or menu operation will cause event processing to block. This is due to how event processing is designed on those platforms. You can use the window refresh callback to redraw the contents of your window when necessary during such operations.
3521: Do not assume that callbacks you set will only be called in response to event processing functions like this one. While it is necessary to poll for events, window systems that require GLFW to register callbacks of its own can pass events to GLFW in response to many window system function calls. GLFW will pass those events on to the application callbacks before returning.
3522: Event processing is not required to receive joystick input. Joystick state is polled when a joystick input or gamepad input function is called.
3523: Parameters
3525: [in]timeoutThe maximum amount of time, in seconds, to wait.
3529: ErrorsPossible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_VALUE and GLFW_PLATFORM_ERROR.
3530: ReentrancyThis function must not be called from a callback.
3531: Thread safetyThis function must only be called from the main thread.
3532: See alsoEvent processing

3569: ◆ glfwSwapBuffers()
3575: void glfwSwapBuffers
3576: (
3577: GLFWwindow *
3578: window)
3583: This function swaps the front and back buffers of the specified window when rendering with OpenGL or OpenGL ES. If the swap interval is greater than zero, the GPU driver waits the specified number of screen updates before swapping the buffers.
3584: The specified window must have an OpenGL or OpenGL ES context. Specifying a window without a context will generate a GLFW_NO_WINDOW_CONTEXT error.
3585: This function does not apply to Vulkan. If you are rendering with Vulkan, see vkQueuePresentKHR instead.
3586: Parameters
3588: [in]windowThe window whose buffers to swap.
3592: ErrorsPossible errors include GLFW_NOT_INITIALIZED, GLFW_NO_WINDOW_CONTEXT and GLFW_PLATFORM_ERROR.
3593: RemarksWayland: When the swap interval is greater than zero and the window is not in view, this function may take a few extra milliseconds to return.
3595: EGL: The context of the specified window must be current on the calling thread.
3596: Thread safetyThis function may be called from any thread.
