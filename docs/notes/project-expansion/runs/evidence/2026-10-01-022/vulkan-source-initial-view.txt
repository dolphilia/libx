126: ◆ glfwVulkanSupported()
132:           int glfwVulkanSupported 
133:           (
134:           void 
135:           )
140: This function returns whether the Vulkan loader and any minimally functional ICD have been found.
141: The availability of a Vulkan loader and even an ICD does not by itself guarantee that surface creation or even instance creation is possible. Call glfwGetRequiredInstanceExtensions to check whether the extensions necessary for Vulkan surface creation are available and glfwGetPhysicalDevicePresentationSupport to check whether a queue family of a physical device supports image presentation.
142: ReturnsGLFW_TRUE if Vulkan is minimally available, or GLFW_FALSE otherwise.
143: ErrorsPossible errors include GLFW_NOT_INITIALIZED.
144: Thread safetyThis function may be called from any thread.
145: See alsoQuerying for Vulkan support
146: SinceAdded in version 3.2. 
151: ◆ glfwGetRequiredInstanceExtensions()
157:           const char ** glfwGetRequiredInstanceExtensions 
158:           (
159:           uint32_t * 
160:           count)
165: This function returns an array of names of Vulkan instance extensions required by GLFW for creating Vulkan surfaces for GLFW windows. If successful, the list will always contain VK_KHR_surface, so if you don't require any additional extensions you can pass this list directly to the VkInstanceCreateInfo struct.
166: If Vulkan is not available on the machine, this function returns NULL and generates a GLFW_API_UNAVAILABLE error. Call glfwVulkanSupported to check whether Vulkan is at least minimally available.
167: If Vulkan is available but no set of extensions allowing window surface creation was found, this function returns NULL. You may still use Vulkan for off-screen rendering and compute work.
168: Parameters
170:     [out]countWhere to store the number of extensions in the returned array. This is set to zero if an error occurred. 
174: ReturnsAn array of ASCII encoded extension names, or NULL if an error occurred.
175: ErrorsPossible errors include GLFW_NOT_INITIALIZED and GLFW_API_UNAVAILABLE.
176: RemarksAdditional extensions may be required by future versions of GLFW. You should check if any extensions you wish to enable are already in the returned array, as it is an error to specify an extension more than once in the VkInstanceCreateInfo struct.
177: Pointer lifetimeThe returned array is allocated and freed by GLFW. You should not free it yourself. It is guaranteed to be valid only until the library is terminated.
178: Thread safetyThis function may be called from any thread.
179: See alsoQuerying required Vulkan extensions 
181: glfwCreateWindowSurface
182: SinceAdded in version 3.2. 
187: ◆ glfwGetInstanceProcAddress()

196:           instance,

202:           procname

211: This function returns the address of the specified Vulkan core or extension function for the specified instance. If instance is set to NULL it can return any function exported from the Vulkan loader, including at least the following functions:
213: vkEnumerateInstanceExtensionProperties
214: vkEnumerateInstanceLayerProperties
215: vkCreateInstance
216: vkGetInstanceProcAddr
218: If Vulkan is not available on the machine, this function returns NULL and generates a GLFW_API_UNAVAILABLE error. Call glfwVulkanSupported to check whether Vulkan is at least minimally available.
219: This function is equivalent to calling vkGetInstanceProcAddr with a platform-specific query of the Vulkan loader as a fallback.
220: Parameters
222:     [in]instanceThe Vulkan instance to query, or NULL to retrieve functions related to instance creation. 
223:     [in]procnameThe ASCII encoded name of the function. 
227: ReturnsThe address of the function, or NULL if an error occurred.
228: ErrorsPossible errors include GLFW_NOT_INITIALIZED and GLFW_API_UNAVAILABLE.
229: Pointer lifetimeThe returned function pointer is valid until the library is terminated.
230: Thread safetyThis function may be called from any thread.
231: See alsoQuerying Vulkan function pointers
232: SinceAdded in version 3.2. 
237: ◆ glfwGetPhysicalDevicePresentationSupport()
243:           int glfwGetPhysicalDevicePresentationSupport 
244:           (
245:           VkInstance 
246:           instance, 
251:           VkPhysicalDevice 
252:           device, 
257:           uint32_t 
258:           queuefamily

267: This function returns whether the specified queue family of the specified physical device supports presentation to the platform GLFW was built for.
268: If Vulkan or the required window surface creation instance extensions are not available on the machine, or if the specified instance was not created with the required extensions, this function returns GLFW_FALSE and generates a GLFW_API_UNAVAILABLE error. Call glfwVulkanSupported to check whether Vulkan is at least minimally available and glfwGetRequiredInstanceExtensions to check what instance extensions are required.
269: Parameters
271:     [in]instanceThe instance that the physical device belongs to. 
272:     [in]deviceThe physical device that the queue family belongs to. 
273:     [in]queuefamilyThe index of the queue family to query. 
277: ReturnsGLFW_TRUE if the queue family supports presentation, or GLFW_FALSE otherwise.
278: ErrorsPossible errors include GLFW_NOT_INITIALIZED, GLFW_API_UNAVAILABLE and GLFW_PLATFORM_ERROR.
279: RemarksmacOS: This function currently always returns GLFW_TRUE, as the VK_MVK_macos_surface and VK_EXT_metal_surface extensions do not provide a vkGetPhysicalDevice*PresentationSupport type function.
280: Thread safetyThis function may be called from any thread. For synchronization details of Vulkan objects, see the Vulkan specification.
281: See alsoQuerying for Vulkan presentation support
282: SinceAdded in version 3.2. 
287: ◆ glfwCreateWindowSurface()
293:           VkResult glfwCreateWindowSurface 
294:           (
295:           VkInstance 
296:           instance, 
301:           GLFWwindow * 
302:           window, 
307:           const VkAllocationCallbacks * 
308:           allocator, 
313:           VkSurfaceKHR * 
314:           surface 
318:           )
323: This function creates a Vulkan surface for the specified window.
324: If the Vulkan loader or at least one minimally functional ICD were not found, this function returns VK_ERROR_INITIALIZATION_FAILED and generates a GLFW_API_UNAVAILABLE error. Call glfwVulkanSupported to check whether Vulkan is at least minimally available.
325: If the required window surface creation instance extensions are not available or if the specified instance was not created with these extensions enabled, this function returns VK_ERROR_EXTENSION_NOT_PRESENT and generates a GLFW_API_UNAVAILABLE error. Call glfwGetRequiredInstanceExtensions to check what instance extensions are required.
326: The window surface cannot be shared with another API so the window must have been created with the client api hint set to GLFW_NO_API otherwise it generates a GLFW_INVALID_VALUE error and returns VK_ERROR_NATIVE_WINDOW_IN_USE_KHR.
327: The window surface must be destroyed before the specified Vulkan instance. It is the responsibility of the caller to destroy the window surface. GLFW does not destroy it for you. Call vkDestroySurfaceKHR to destroy the surface.
328: Parameters
330:     [in]instanceThe Vulkan instance to create the surface in. 
331:     [in]windowThe window to create the surface for. 
332:     [in]allocatorThe allocator to use, or NULL to use the default allocator. 
333:     [out]surfaceWhere to store the handle of the surface. This is set to VK_NULL_HANDLE if an error occurred. 
337: ReturnsVK_SUCCESS if successful, or a Vulkan error code if an error occurred.
338: ErrorsPossible errors include GLFW_NOT_INITIALIZED, GLFW_API_UNAVAILABLE, GLFW_PLATFORM_ERROR and GLFW_INVALID_VALUE
339: RemarksIf an error occurs before the creation call is made, GLFW returns the Vulkan error code most appropriate for the error. Appropriate use of glfwVulkanSupported and glfwGetRequiredInstanceExtensions should eliminate almost all occurrences of these errors.
341: macOS: GLFW prefers the VK_EXT_metal_surface extension, with the VK_MVK_macos_surface extension as a fallback. The name of the selected extension, if any, is included in the array returned by glfwGetRequiredInstanceExtensions.
343: macOS: This function creates and sets a CAMetalLayer instance for the window content view, which is required for MoltenVK to function.
345: X11: By default GLFW prefers the VK_KHR_xcb_surface extension, with the VK_KHR_xlib_surface extension as a fallback. You can make VK_KHR_xlib_surface the preferred extension by setting the GLFW_X11_XCB_VULKAN_SURFACE init hint. The name of the selected extension, if any, is included in the array returned by glfwGetRequiredInstanceExtensions.
346: Thread safetyThis function may be called from any thread. For synchronization details of Vulkan objects, see the Vulkan specification.
