146: ## [◆ ](#ga2e7f30931e02464b5bc8d0d4b6f9fe2b)glfwVulkanSupported()
154: | int glfwVulkanSupported | (   | void  |     | )   |     |
160: この関数は、Vulkan ローダーと、最低限機能するいずれかの ICD が見つかったかどうかを返します。
162: Vulkan ローダーや ICD が利用可能であっても、それだけではサーフェス作成やインスタンス作成が可能であるとは保証されません。Vulkan サーフェス作成に必要な拡張が利用可能かを確認するには glfwGetRequiredInstanceExtensions を、物理デバイスのキューファミリーがイメージ表示をサポートするかを確認するには glfwGetPhysicalDevicePresentationSupport を呼び出してください。
164: 戻り値  
165: Vulkan が最低限利用可能な場合は `GLFW_TRUE`、それ以外の場合は `GLFW_FALSE`。
169: エラー  
170: 発生する可能性のあるエラーには、GLFW_NOT_INITIALIZED があります。
174: スレッドセーフ性  
175: この関数は、どのスレッドからでも呼び出せます。
179: 関連項目  
180: Vulkan サポートの照会
184: 導入バージョン  
185: バージョン 3.2 で追加されました。
193: ## [◆ ](#ga99ad342d82f4a3421e2864978cb6d1d6)glfwGetRequiredInstanceExtensions()
201: | const char \*\* glfwGetRequiredInstanceExtensions | ( | uint32_t \*  | *count* | ) |  |
207: この関数は、GLFW ウィンドウ用の Vulkan サーフェスを作成するために GLFW が必要とする Vulkan インスタンス拡張名の配列を返します。成功した場合、リストには必ず `VK_KHR_surface` が含まれます。そのため、追加の拡張が不要であれば、このリストを `VkInstanceCreateInfo` 構造体へ直接渡せます。
209: マシン上で Vulkan が利用できない場合、この関数は `NULL` を返し、GLFW_API_UNAVAILABLE エラーを生成します。Vulkan が最低限利用可能かを確認するには、glfwVulkanSupported を呼び出してください。
211: Vulkan は利用可能でも、ウィンドウサーフェス作成を可能にする拡張の組み合わせが見つからない場合、この関数は `NULL` を返します。その場合でも、オフスクリーンレンダリングや計算処理には Vulkan を使用できます。
213: 引数  
216: | \[out\] | count | 戻り値の配列に含まれる拡張数を格納する場所。エラーが発生した場合は 0 に設定されます。 |
220: 戻り値  
221: ASCII エンコードされた拡張名の配列。エラーが発生した場合は `NULL`。
225: エラー  
226: 発生する可能性のあるエラーには、GLFW_NOT_INITIALIZED、GLFW_API_UNAVAILABLE があります。
230: 備考  
231: 将来の GLFW バージョンでは、追加の拡張が必要になる可能性があります。`VkInstanceCreateInfo` 構造体で同じ拡張を複数回指定するとエラーになるため、有効化したい拡張が戻り値の配列にすでに含まれていないか確認してください。
235: ポインターの有効期間  
236: 戻り値の配列は GLFW によって確保および解放されます。自分で解放してはいけません。ライブラリが終了するまでのみ有効であることが保証されます。
240: スレッドセーフ性  
241: この関数は、どのスレッドからでも呼び出せます。
245: 関連項目  
246: 必要な Vulkan 拡張の照会
248: glfwCreateWindowSurface
252: 導入バージョン  
253: バージョン 3.2 で追加されました。
261: ## [◆ ](#gadf228fac94c5fd8f12423ec9af9ff1e9)glfwGetInstanceProcAddress()
269: | GLFWvkproc glfwGetInstanceProcAddress | ( | VkInstance  | *instance*, |
270: |  |  | const char \*  | *procname*  |
271: |  | ) |  |  |
277: この関数は、指定されたインスタンスについて、指定された Vulkan コア関数または拡張関数のアドレスを返します。instance が `NULL` の場合、少なくとも次の関数を含む、Vulkan ローダーがエクスポートする任意の関数を返せます。
279: - `vkEnumerateInstanceExtensionProperties`
280: - `vkEnumerateInstanceLayerProperties`
281: - `vkCreateInstance`
282: - `vkGetInstanceProcAddr`
284: マシン上で Vulkan が利用できない場合、この関数は `NULL` を返し、GLFW_API_UNAVAILABLE エラーを生成します。Vulkan が最低限利用可能かを確認するには、glfwVulkanSupported を呼び出してください。
286: この関数は、プラットフォーム固有の Vulkan ローダー照会をフォールバックとして使用して `vkGetInstanceProcAddr` を呼び出すことと同等です。
288: 引数  
291: | \[in\] | instance | 問い合わせる Vulkan インスタンス。インスタンス作成関連の関数を取得する場合は `NULL`。 |
292: | \[in\] | procname | ASCII エンコードされた関数名。 |
296: 戻り値  
297: 関数のアドレス。エラーが発生した場合は `NULL`。
301: エラー  
302: 発生する可能性のあるエラーには、GLFW_NOT_INITIALIZED、GLFW_API_UNAVAILABLE があります。
306: ポインターの有効期間  
307: 戻り値の関数ポインターは、ライブラリが終了するまで有効です。
311: スレッドセーフ性  
312: この関数は、どのスレッドからでも呼び出せます。
316: 関連項目  
317: Vulkan 関数ポインターの照会

330: ## [◆ ](#gaff3823355cdd7e2f3f9f4d9ea9518d92)glfwGetPhysicalDevicePresentationSupport()
338: | int glfwGetPhysicalDevicePresentationSupport | ( | VkInstance  | *instance*, |
339: |  |  | VkPhysicalDevice  | *device*, |
340: |  |  | uint32_t  | *queuefamily*  |
341: |  | ) |  |  |
347: この関数は、指定された物理デバイスの指定されたキューファミリーが、GLFW のビルド対象プラットフォームへの表示をサポートするかどうかを返します。
349: マシン上で Vulkan または必要なウィンドウサーフェス作成用インスタンス拡張が利用できない場合、あるいは指定されたインスタンスが必要な拡張を有効にして作成されていない場合、この関数は `GLFW_FALSE` を返し、GLFW_API_UNAVAILABLE エラーを生成します。Vulkan が最低限利用可能かを確認するには glfwVulkanSupported を、必要なインスタンス拡張を確認するには glfwGetRequiredInstanceExtensions を呼び出してください。
351: 引数  
354: | \[in\] | instance    | 物理デバイスが属するインスタンス。 |
355: | \[in\] | device      | キューファミリーが属する物理デバイス。 |
356: | \[in\] | queuefamily | 問い合わせるキューファミリーのインデックス。 |
360: 戻り値  
361: キューファミリーが表示をサポートする場合は `GLFW_TRUE`、それ以外の場合は `GLFW_FALSE`。
365: エラー  
366: 発生する可能性のあるエラーには、GLFW_NOT_INITIALIZED、GLFW_API_UNAVAILABLE、GLFW_PLATFORM_ERROR があります。
370: 備考  
371: **macOS:** `VK_MVK_macos_surface` および `VK_EXT_metal_surface` 拡張は `vkGetPhysicalDevice*PresentationSupport` 型の関数を提供しないため、現在この関数は常に `GLFW_TRUE` を返します。
375: スレッドセーフ性  
376: この関数は、どのスレッドからでも呼び出せます。Vulkan オブジェクトの同期の詳細については、Vulkan 仕様を参照してください。
380: 関連項目  
381: Vulkan 表示サポートの照会

386: バージョン 3.2 で追加されました。
394: ## [◆ ](#ga1a24536bec3f80b08ead18e28e6ae965)glfwCreateWindowSurface()
402: | VkResult glfwCreateWindowSurface | ( | VkInstance  | *instance*, |
403: |  |  | GLFWwindow \*  | *window*, |
404: |  |  | const VkAllocationCallbacks \*  | *allocator*, |
405: |  |  | VkSurfaceKHR \*  | *surface*  |
406: |  | ) |  |  |
412: この関数は、指定されたウィンドウ用の Vulkan サーフェスを作成します。
414: Vulkan ローダー、または最低限機能する ICD が 1 つも見つからない場合、この関数は `VK_ERROR_INITIALIZATION_FAILED` を返し、GLFW_API_UNAVAILABLE エラーを生成します。Vulkan が最低限利用可能かを確認するには、glfwVulkanSupported を呼び出してください。
416: 必要なウィンドウサーフェス作成用インスタンス拡張が利用できない場合、または指定されたインスタンスがそれらの拡張を有効にして作成されていない場合、この関数は `VK_ERROR_EXTENSION_NOT_PRESENT` を返し、GLFW_API_UNAVAILABLE エラーを生成します。必要なインスタンス拡張を確認するには、glfwGetRequiredInstanceExtensions を呼び出してください。
418: ウィンドウサーフェスは別の API と共有できないため、ウィンドウはクライアント API ヒントを `GLFW_NO_API` に設定して作成されていなければなりません。そうでない場合、GLFW_INVALID_VALUE エラーを生成し、`VK_ERROR_NATIVE_WINDOW_IN_USE_KHR` を返します。
420: ウィンドウサーフェスは、指定された Vulkan インスタンスより先に破棄しなければなりません。ウィンドウサーフェスを破棄する責任は呼び出し側にあります。GLFW は代わりに破棄しません。サーフェスを破棄するには `vkDestroySurfaceKHR` を呼び出してください。
422: 引数  
425: | \[in\] | instance | サーフェスを作成する Vulkan インスタンス。 |
426: | \[in\] | window | サーフェスを作成する対象のウィンドウ。 |
427: | \[in\] | allocator | 使用するアロケーター。デフォルトのアロケーターを使用する場合は `NULL`。 |
428: | \[out\] | surface | サーフェスのハンドルを格納する場所。エラーが発生した場合は `VK_NULL_HANDLE` に設定されます。 |
432: 戻り値  
433: 成功した場合は `VK_SUCCESS`。エラーが発生した場合は Vulkan エラーコード。
437: エラー  
438: 発生する可能性のあるエラーには、GLFW_NOT_INITIALIZED、GLFW_API_UNAVAILABLE、GLFW_PLATFORM_ERROR、GLFW_INVALID_VALUE があります。
442: 備考  
443: 作成呼び出しが行われる前にエラーが発生した場合、GLFW はそのエラーに最も適した Vulkan エラーコードを返します。glfwVulkanSupported と glfwGetRequiredInstanceExtensions を適切に使用すれば、これらのエラーのほぼすべてを回避できます。
445: **macOS:** GLFW は `VK_EXT_metal_surface` 拡張を優先し、`VK_MVK_macos_surface` 拡張をフォールバックとして使用します。拡張が選択された場合、その名前は glfwGetRequiredInstanceExtensions が返す配列に含まれます。
447: **macOS:** この関数は、MoltenVK の動作に必要な `CAMetalLayer` インスタンスを作成し、ウィンドウのコンテンツビューに設定します。
449: **X11:** デフォルトでは、GLFW は `VK_KHR_xcb_surface` 拡張を優先し、`VK_KHR_xlib_surface` 拡張をフォールバックとして使用します。GLFW_X11_XCB_VULKAN_SURFACE 初期化ヒントを設定すると、`VK_KHR_xlib_surface` を優先拡張にできます。拡張が選択された場合、その名前は glfwGetRequiredInstanceExtensions が返す配列に含まれます。
453: スレッドセーフ性  
454: この関数は、どのスレッドからでも呼び出せます。Vulkan オブジェクトの同期の詳細については、Vulkan 仕様を参照してください。
