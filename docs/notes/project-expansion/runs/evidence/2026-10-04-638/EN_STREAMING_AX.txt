			46 text With the 
			47 text --stream
			48 text  option jq can parse input texts in a streaming fashion, allowing jq programs to start processing large JSON texts immediately rather than after the parse completes. If you have a single JSON text that is 1GB in size, streaming it will allow you to process it much more quickly. However, streaming isn't easy to deal with as the jq program will have 
			49 text [<path>, <leaf-value>]
			50 text  (and a few other forms) as inputs. Several builtins are provided to make handling streams easier. The examples below use the streamed form of
