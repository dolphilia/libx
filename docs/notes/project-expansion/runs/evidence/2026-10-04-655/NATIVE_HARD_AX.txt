			158 heading Including portions of a file, Value: 2, ID: including-portions-of-a-file
				159 link Description: Including portions of a file, Value: 127.0.0.1:4655/docs/mdbook-trial/v0-5-4/en/01-guide/22-format-mdbook/#including-portions-of-a-file
			160 text Often you only need a specific part of the file, e.g. relevant lines for an example. We support four different modes of partial includes:
			161 text {{#include file.rs:2}}
{{#include file.rs::10}}
{{#include file.rs:2:}}
{{#include file.rs:2:10}}

			162 text The first command only includes the second line from file 
			163 text file.rs
			164 text . The second command includes all lines up to line 10, i.e. the lines from 11 till the end of the file are omitted. The third command includes all lines from line 2, i.e. the first line is omitted. The last command includes the excerpt of 
			165 text file.rs
			166 text  consisting of lines 2 to 10. To avoid breaking your book when modifying included files, you can also include a specific section using anchors instead of line numbers. An anchor is a pair of matching lines. The line beginning an anchor must match the regex 
			167 text ANCHOR:\s*[\w_-]+
			168 text  and similarly the ending line must match the regex 
			169 text ANCHOR_END:\s*[\w_-]+
			170 text . This allows you to put anchors in any kind of commented line. Consider the following file to include:
			171 text /* ANCHOR: all */

// ANCHOR: component
struct Paddle {
    hello: f32,
}
// ANCHOR_END: component

////////// ANCHOR: system
impl System for MySystem { ... }
////////// ANCHOR_END: system

/* ANCHOR_END: all */

			172 text Then in the book, all you have to do is:
			173 text Here is a component:
```rust,no_run,noplayground
{{#include file.rs:component}}
```

Here is a system:
```rust,no_run,noplayground
{{#include file.rs:system}}
```

This is the full file.
```rust,no_run,noplayground
{{#include file.rs:all}}
```
