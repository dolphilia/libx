<div class="contents" class="xxhash-api-trial">&#10;<div class="textblock"><p>xxHash is an extremely fast non-cryptographic hash algorithm, working at RAM speed limits.</p>&#10;<p>It is proposed in four flavors, in three families:</p><ol type="1">&#10;<li><a class="el" href="/docs/xxhash-trial/v0-8-4/en/02-api/12-group___x_x_h32__family/" title="XXH32 family">XXH32 family</a><ul>&#10;<li>Classic 32-bit hash function. Simple, compact, and runs on almost all 32-bit and 64-bit systems.</li>&#10;</ul>&#10;</li>&#10;<li><a class="el" href="/docs/xxhash-trial/v0-8-4/en/02-api/16-group___x_x_h64__family/" title="XXH64 family">XXH64 family</a><ul>&#10;<li>Classic 64-bit adaptation of XXH32. Just as simple, and runs well on most 64-bit systems (but <em>not</em> 32-bit systems).</li>&#10;</ul>&#10;</li>&#10;<li><a class="el" href="/docs/xxhash-trial/v0-8-4/en/02-api/14-group___x_x_h3__family/" title="XXH3 family">XXH3 family</a><ul>&#10;<li>Modern 64-bit and 128-bit hash function family which features improved strength and performance across the board, especially on smaller data. It benefits greatly from SIMD and 64-bit without requiring it.</li>&#10;</ul>&#10;</li>&#10;</ol>&#10;<h2 class="doxsection"><a class="anchor" id="autotoc_md0"></a>&#10;Benchmarks</h2>&#10;<p>The reference system uses an Intel i7-9700K CPU, and runs Ubuntu x64 20.04.
