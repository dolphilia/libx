76: Description
77: See key input for how these are used.
78: These key codes are inspired by the USB HID Usage Tables v1.12 (p. 53-60), but re-arranged to map to 7-bit ASCII for printable keys (function keys are put in the 256+ range).
79: The naming of the key codes follow these rules:
80: The US keyboard layout is used
81: Names of printable alphanumeric characters are used (e.g. "A", "R", "3", etc.)
82: For non-alphanumeric characters, Unicode:ish names are used (e.g. "COMMA", "LEFT_SQUARE_BRACKET", etc.). Note that some names do not correspond to the Unicode standard (usually for brevity)
83: Keys that lack a clear US mapping are named "WORLD_x"
84: For non-printable keys, custom names are used (e.g. "F4", "BACKSPACE", etc.)
