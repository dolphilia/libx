484: This function retrieves the content scale for the specified monitor. The content scale is the ratio between the current DPI and the platform's default DPI. This is especially important for text and any UI elements. If the pixel dimensions of your UI scaled by this look appropriate on your machine then it should appear at a reasonable size on other machines regardless of their DPI and scaling settings. This relies on the system DPI and scaling settings being somewhat correct.
485: The content scale may depend on both the monitor resolution and pixel density and on user settings. It may be very different from the raw DPI calculated from the physical size and current resolution.
486: Parameters
488:     [in]monitorThe monitor to query. 
489:     [out]xscaleWhere to store the x-axis content scale, or NULL. 
490:     [out]yscaleWhere to store the y-axis content scale, or NULL.
494: ErrorsPossible errors include GLFW_NOT_INITIALIZED and GLFW_PLATFORM_ERROR.
495: RemarksWayland: Fractional scaling information is not yet available for monitors, so this function only returns integer content scales.
496: Thread safetyThis function must only be called from the main thread.

720: ◆ glfwSetGamma()
726:           void glfwSetGamma

728:           GLFWmonitor * 
729:           monitor, 
734:           float 
735:           gamma 
739:           )
744: This function generates an appropriately sized gamma ramp from the specified exponent and then calls glfwSetGammaRamp with it. The value must be a finite number greater than zero.
745: The software controlled gamma ramp is applied in addition to the hardware gamma correction, which today is usually an approximation of sRGB gamma. This means that setting a perfectly linear ramp, or gamma 1.0, will produce the default (usually sRGB-like) behavior.
746: For gamma correct rendering with OpenGL or OpenGL ES, see the GLFW_SRGB_CAPABLE hint.
747: Parameters
749:     [in]monitorThe monitor whose gamma ramp to set. 
750:     [in]gammaThe desired exponent.
754: ErrorsPossible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_VALUE, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see remarks).
755: RemarksWayland: Monitor gamma is a privileged protocol, so this function cannot be implemented and emits GLFW_FEATURE_UNAVAILABLE.
756: Thread safetyThis function must only be called from the main thread.
757: See alsoGamma ramp
758: SinceAdded in version 3.0.

819: This function sets the current gamma ramp for the specified monitor. The original gamma ramp for that monitor is saved by GLFW the first time this function is called and is restored by glfwTerminate.
820: The software controlled gamma ramp is applied in addition to the hardware gamma correction, which today is usually an approximation of sRGB gamma. This means that setting a perfectly linear ramp, or gamma 1.0, will produce the default (usually sRGB-like) behavior.
821: For gamma correct rendering with OpenGL or OpenGL ES, see the GLFW_SRGB_CAPABLE hint.
822: Parameters
824:     [in]monitorThe monitor whose gamma ramp to set. 
825:     [in]rampThe gamma ramp to use.
829: ErrorsPossible errors include GLFW_NOT_INITIALIZED, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see remarks).
830: RemarksThe size of the specified gamma ramp should match the size of the current ramp for that monitor.
832: Win32: The gamma ramp size must be 256.
834: Wayland: Monitor gamma is a privileged protocol, so this function cannot be implemented and emits GLFW_FEATURE_UNAVAILABLE.
835: Pointer lifetimeThe specified gamma ramp is copied before this function returns.
836: Thread safetyThis function must only be called from the main thread.
