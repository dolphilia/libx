732: ## [◆ ](#gad3152e84465fa620b601265ebfcdb21b)glfwGetMonitorContentScale()
740: | void glfwGetMonitorContentScale | ( | GLFWmonitor \*  | *monitor*, |
741: |  |  | float \*  | *xscale*, |
742: |  |  | float \*  | *yscale*  |
743: |  | ) |  |  |
749: This function retrieves the content scale for the specified monitor. The content scale is the ratio between the current DPI and the platform's default DPI. This is especially important for text and any UI elements. If the pixel dimensions of your UI scaled by this look appropriate on your machine then it should appear at a reasonable size on other machines regardless of their DPI and scaling settings. This relies on the system DPI and scaling settings being somewhat correct.
751: The content scale may depend on both the monitor resolution and pixel density and on user settings. It may be very different from the raw DPI calculated from the physical size and current resolution.
753: Parameters  
756: | \[in\]  | monitor | The monitor to query.                               |
757: | \[out\] | xscale  | Where to store the x-axis content scale, or `NULL`. |
758: | \[out\] | yscale  | Where to store the y-axis content scale, or `NULL`. |
762: Errors  
763: Possible errors include GLFW_NOT_INITIALIZED and GLFW_PLATFORM_ERROR.
767: Remarks  
768: **Wayland:** Fractional scaling information is not yet available for monitors, so this function only returns integer content scales.
772: Thread safety  
773: This function must only be called from the main thread.
777: See also  
778: Content scale
780: glfwGetWindowContentScale
784: Since  
785: Added in version 3.3.

1143: ## [◆ ](#ga6ac582625c990220785ddd34efa3169a)glfwSetGamma()
1151: | void glfwSetGamma | ( | GLFWmonitor \*  | *monitor*, |
1152: |  |  | float  | *gamma*  |
1153: |  | ) |  |  |
1159: This function generates an appropriately sized gamma ramp from the specified exponent and then calls glfwSetGammaRamp with it. The value must be a finite number greater than zero.
1161: The software controlled gamma ramp is applied *in addition* to the hardware gamma correction, which today is usually an approximation of sRGB gamma. This means that setting a perfectly linear ramp, or gamma 1.0, will produce the default (usually sRGB-like) behavior.
1163: For gamma correct rendering with OpenGL or OpenGL ES, see the GLFW_SRGB_CAPABLE hint.
1165: Parameters  
1168: | \[in\] | monitor | The monitor whose gamma ramp to set. |
1169: | \[in\] | gamma   | The desired exponent.                |
1173: Errors  
1174: Possible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_VALUE, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see remarks).
1178: Remarks  
1179: **Wayland:** Monitor gamma is a privileged protocol, so this function cannot be implemented and emits GLFW_FEATURE_UNAVAILABLE.
1183: Thread safety  
1184: This function must only be called from the main thread.
1188: See also  
1189: Gamma ramp
1193: Since  
1194: Added in version 3.0.

1280: This function sets the current gamma ramp for the specified monitor. The original gamma ramp for that monitor is saved by GLFW the first time this function is called and is restored by glfwTerminate.
1282: The software controlled gamma ramp is applied *in addition* to the hardware gamma correction, which today is usually an approximation of sRGB gamma. This means that setting a perfectly linear ramp, or gamma 1.0, will produce the default (usually sRGB-like) behavior.
1284: For gamma correct rendering with OpenGL or OpenGL ES, see the GLFW_SRGB_CAPABLE hint.
1286: Parameters  
1289: | \[in\] | monitor | The monitor whose gamma ramp to set. |
1290: | \[in\] | ramp    | The gamma ramp to use.               |
1294: Errors  
1295: Possible errors include GLFW_NOT_INITIALIZED, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see remarks).
1299: Remarks  
1300: The size of the specified gamma ramp should match the size of the current ramp for that monitor.
1302: **Win32:** The gamma ramp size must be 256.
1304: **Wayland:** Monitor gamma is a privileged protocol, so this function cannot be implemented and emits GLFW_FEATURE_UNAVAILABLE.
1308: Pointer lifetime

1313: Thread safety
