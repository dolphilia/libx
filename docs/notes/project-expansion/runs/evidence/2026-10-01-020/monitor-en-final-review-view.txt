705: Errors

734: ## [◆ ](#gad3152e84465fa620b601265ebfcdb21b)glfwGetMonitorContentScale()
742: | void glfwGetMonitorContentScale | ( | GLFWmonitor \*  | *monitor*, |
743: |  |  | float \*  | *xscale*, |
744: |  |  | float \*  | *yscale*  |
745: |  | ) |  |  |
751: This function retrieves the content scale for the specified monitor. The content scale is the ratio between the current DPI and the platform's default DPI. This is especially important for text and any UI elements. If the pixel dimensions of your UI scaled by this look appropriate on your machine then it should appear at a reasonable size on other machines regardless of their DPI and scaling settings. This relies on the system DPI and scaling settings being somewhat correct.
753: The content scale may depend on both the monitor resolution and pixel density and on user settings. It may be very different from the raw DPI calculated from the physical size and current resolution.
755: Parameters  
758: | \[in\]  | monitor | The monitor to query.                               |
759: | \[out\] | xscale  | Where to store the x-axis content scale, or `NULL`. |
760: | \[out\] | yscale  | Where to store the y-axis content scale, or `NULL`. |
764: Errors  
765: Possible errors include GLFW_NOT_INITIALIZED and GLFW_PLATFORM_ERROR.
769: Remarks  
770: **Wayland:** Fractional scaling information is not yet available for monitors, so this function only returns integer content scales.
774: Thread safety  
775: This function must only be called from the main thread.
779: See also  
780: Content scale
782: glfwGetWindowContentScale
786: Since  
787: Added in version 3.3.

1147: ## [◆ ](#ga6ac582625c990220785ddd34efa3169a)glfwSetGamma()
1155: | void glfwSetGamma | ( | GLFWmonitor \*  | *monitor*, |
1156: |  |  | float  | *gamma*  |
1157: |  | ) |  |  |
1163: This function generates an appropriately sized gamma ramp from the specified exponent and then calls glfwSetGammaRamp with it. The value must be a finite number greater than zero.
1165: The software controlled gamma ramp is applied *in addition* to the hardware gamma correction, which today is usually an approximation of sRGB gamma. This means that setting a perfectly linear ramp, or gamma 1.0, will produce the default (usually sRGB-like) behavior.
1167: For gamma correct rendering with OpenGL or OpenGL ES, see the GLFW_SRGB_CAPABLE hint.
1169: Parameters  
1172: | \[in\] | monitor | The monitor whose gamma ramp to set. |
1173: | \[in\] | gamma   | The desired exponent.                |
1177: Errors  
1178: Possible errors include GLFW_NOT_INITIALIZED, GLFW_INVALID_VALUE, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see remarks).
1182: Remarks  
1183: **Wayland:** Monitor gamma is a privileged protocol, so this function cannot be implemented and emits GLFW_FEATURE_UNAVAILABLE.
1187: Thread safety  
1188: This function must only be called from the main thread.
1192: See also  
1193: Gamma ramp
1197: Since  
1198: Added in version 3.0.

1284: This function sets the current gamma ramp for the specified monitor. The original gamma ramp for that monitor is saved by GLFW the first time this function is called and is restored by glfwTerminate.
1286: The software controlled gamma ramp is applied *in addition* to the hardware gamma correction, which today is usually an approximation of sRGB gamma. This means that setting a perfectly linear ramp, or gamma 1.0, will produce the default (usually sRGB-like) behavior.
1288: For gamma correct rendering with OpenGL or OpenGL ES, see the GLFW_SRGB_CAPABLE hint.
1290: Parameters  
1293: | \[in\] | monitor | The monitor whose gamma ramp to set. |
1294: | \[in\] | ramp    | The gamma ramp to use.               |
1298: Errors  
1299: Possible errors include GLFW_NOT_INITIALIZED, GLFW_PLATFORM_ERROR and GLFW_FEATURE_UNAVAILABLE (see remarks).
1303: Remarks  
1304: The size of the specified gamma ramp should match the size of the current ramp for that monitor.
1306: **Win32:** The gamma ramp size must be 256.
1308: **Wayland:** Monitor gamma is a privileged protocol, so this function cannot be implemented and emits GLFW_FEATURE_UNAVAILABLE.
1312: Pointer lifetime

1317: Thread safety
