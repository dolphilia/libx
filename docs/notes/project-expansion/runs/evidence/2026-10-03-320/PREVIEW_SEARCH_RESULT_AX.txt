			145 heading cJSONへようこそ, Value: 3, ID: welcome-to-cjson
				146 text cJSONへようこそ
			147 text cJSONは、必要な仕事をこなせる限り、できるだけ単純なパーサーを目指しています。Cのソースファイル1個とヘッダーファイル1個で構成されています。 JSONについては http://www.json.org/ の説明が最も適しています。XMLに似ていますが、余分なものをそぎ落としています。データの受け渡しや保存、あるいはプログラムの状態を表すために使います。 ライブラリとしてのcJSONは、できるだけ手間を減らしつつ、使い手の邪魔にならないことを目指しています。実用上の話として（厳密さはさておき）、自動と手動の2つのモードで使える、と言っておきましょう。簡単に見ていきます。 このページからJSONの例を借りてきました: http://www.json.org/fatfree.html 。そのページに触発され、JSONそのものと同じ考え方を共有しようとするパーサー、cJSONを書きました。簡単で単純、そして邪魔にならないものです。

			272 heading データ構造, Value: 3, ID: data-structure
				273 text データ構造
			274 text cJSONは、
			275 text cJSON
			276 text 構造体型を使ってJSONデータを表します。
			277 button コードをコピー
			278 text /* The cJSON structure: */
typedef struct cJSON
{
    struct cJSON *next;
    struct cJSON *prev;
    struct cJSON *child;
    int type;
    char *valuestring;
    /* writing to valueint is DEPRECATED, use cJSON_SetNumberValue instead */
    int valueint;
    double valuedouble;
    char *string;
} cJSON;

			279 text この型の要素はJSONの値を表します。型は
			280 text type
			281 text にビットフラグとして格納されます。（
			282 container
				283 text つまり、 type の値を単純に比較するだけでは型を判定できません。
			284 text ） 要素の型を調べるには、対応する
			285 text cJSON_Is...
			286 text 関数を使います。この関数は
			287 text NULL
			288 text チェックの後に型をチェックし、要素がその型かどうかを真偽値で返します。 型には次のいずれかを使用できます。
			289 content list
				290 container
					291 AXListMarker • 
					292 text cJSON_Invalid （ cJSON_IsInvalid で確認）: 値を持たない無効な要素を表します。要素の全バイトをゼロにすると、自動的にこの型になります。
				293 container
					294 AXListMarker • 
					295 text cJSON_False （ cJSON_IsFalse で確認）: 真偽値 false を表します。真偽値全般の確認には cJSON_IsBool も使えます。
				296 container
					297 AXListMarker • 
					298 text cJSON_True （ cJSON_IsTrue で確認）: 真偽値 true を表します。真偽値全般の確認には cJSON_IsBool も使えます。
				299 container
					300 AXListMarker • 
					301 text cJSON_NULL （ cJSON_IsNull で確認）:  null 値を表します。
				302 container
					303 AXListMarker • 
					304 text cJSON_Number （ cJSON_IsNumber で確認）: 数値を表します。値は valuedouble にdoubleとして格納され、 valueint にも格納されます。整数の範囲を超える場合、 valueint には INT_MAX または INT_MIN が使われます。
				305 container
					306 AXListMarker • 
					307 text cJSON_String （ cJSON_IsString で確認）: 文字列を表します。ゼロ終端文字列の形で valuestring に格納されます。
				308 container
					309 AXListMarker • 
					310 text cJSON_Array （ cJSON_IsArray で確認）: 配列を表します。 child が配列の値を表す cJSON 要素の連結リストを指すことで実装されています。要素は next と prev でつながれ、先頭要素は prev.next == NULL 、末尾要素は next == NULL となります。
				311 container
					312 AXListMarker • 
					313 text cJSON_Object （ cJSON_IsObject で確認）: オブジェクトを表します。配列と同じ方法で格納されますが、要素がキーを string に格納する点だけが異なります。
				314 container

{

    {

    if (resolutions == NULL)

int supports_full_hd(const char * const monitor)
{
    const cJSON *resolution = NULL;
    const cJSON *resolutions = NULL;
    const cJSON *name = NULL;
    int status = 0;
    cJSON *monitor_json = cJSON_Parse(monitor);
    if (monitor_json == NULL)
    {
        const char *error_ptr = cJSON_GetErrorPtr();
        if (error_ptr != NULL)
        {
            fprintf(stderr, "Error before: %s\n", error_ptr);
        }
        status = 0;
        goto end;
    }

    name = cJSON_GetObjectItemCaseSensitive(monitor_json, "name");
    if (cJSON_IsString(name) && (name->valuestring != NULL))
    {
        printf("Checking monitor \"%s\"\n", name->valuestring);
    }

    resolutions = cJSON_GetObjectItemCaseSensitive(monitor_json, "resolutions");
    cJSON_ArrayForEach(resolution, resolutions)
    {
        cJSON *width = cJSON_GetObjectItemCaseSensitive(resolution, "width");
        cJSON *height = cJSON_GetObjectItemCaseSensitive(resolution, "height");

        if (!cJSON_IsNumber(width) || !cJSON_IsNumber(height))
        {
            status = 0;
            goto end;
        }

        if ((width->valuedouble == 1920) && (height->valuedouble == 1080))
        {
            status = 1;
            goto end;
        }
    }

end:
    cJSON_Delete(monitor_json);
    return status;
}
