Initializes a stack-allocated 
XXH3_state_s
. 


When the 
XXH3_state_t
 structure is merely emplaced on stack, it should be initialized with 
XXH3_INITSTATE()
 or a memset() in case its first reset uses XXH3_NNbits_reset_withSeed(). This init can be omitted if the first reset uses default or _withSecret mode. This operation isn't necessary when the state is created with 
XXH3_createState()
. Note that this doesn't prepare the state for a streaming operation, it's still necessary to use XXH3_NNbits_reset*() afterwards.
