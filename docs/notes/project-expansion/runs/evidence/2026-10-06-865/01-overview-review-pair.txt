EN: Wren overview
JA: Wrenの概要

2 [h2]
EN: Wren is a small, fast, class-based concurrent scripting language <a class="header-anchor" href="#wren-is-a-small,-fast,-class-based-concurrent-scripting-language" name="wren-is-a-small,-fast,-class-based-concurrent-scripting-language">#</a>
JA: Wrenは小さく高速な、クラスを中心とする並行スクリプト言語です <a class="header-anchor" href="#wren-is-a-small,-fast,-class-based-concurrent-scripting-language" name="wren-is-a-small,-fast,-class-based-concurrent-scripting-language">#</a>

3 [p]
EN: Think Smalltalk in a Lua-sized package with a dash of Erlang and wrapped up in
a familiar, modern <a href="/docs/wren/v0-4-0/en/01-guide/03-syntax/">syntax</a>.
JA: Luaほどの小さなパッケージにSmalltalkを収め、Erlangをひとさじ加え、なじみのある現代的な<a href="/docs/wren/v0-4-0/en/01-guide/03-syntax/">構文</a>で包んだものを想像してください。

4 [li]
EN: 
<p><strong>Wren is small.</strong> The VM implementation is under <a href="https://github.com/wren-lang/wren/tree/main/src">4,000 semicolons</a>.
    You can skim the whole thing in an afternoon. It’s <em>small</em>, but not
    <em>dense</em>. It is readable and <a href="https://github.com/wren-lang/wren/blob/46c1ba92492e9257aba6418403161072d640cb29/src/wren_value.h#L378-L433">lovingly-commented</a>.</p>

JA: <p><strong>Wrenは小さい。</strong> VMの実装に含まれる<a href="https://github.com/wren-lang/wren/tree/main/src">セミコロンは4,000個未満</a>です。午後のひとときで全体に目を通せます。<em>小さく</em>ても、<em>詰め込みすぎ</em>ではありません。読みやすく、<a href="https://github.com/wren-lang/wren/blob/46c1ba92492e9257aba6418403161072d640cb29/src/wren_value.h#L378-L433">丁寧にコメントが付いています</a>。</p>

5 [li]
EN: 
<p><strong>Wren is fast.</strong> A fast single-pass compiler to tight bytecode, and a
    compact object representation help Wren <a href="/docs/wren/v0-4-0/en/01-guide/22-performance/">compete with other dynamic
    languages</a>.</p>

JA: <p><strong>Wrenは高速。</strong> 高速な単一パスのコンパイラが無駄の少ないバイトコードを生成し、コンパクトなオブジェクト表現とともに、Wrenが<a href="/docs/wren/v0-4-0/en/01-guide/22-performance/">ほかの動的言語に匹敵する性能</a>を発揮するのに役立ちます。</p>

6 [li]
EN: 
<p><strong>Wren is class-based.</strong> There are lots of scripting languages out there,
    but many have unusual or non-existent object models. Wren places
    <a href="/docs/wren/v0-4-0/en/01-guide/10-classes/">classes</a> front and center.</p>

JA: <p><strong>Wrenはクラスを中心とする。</strong> スクリプト言語は数多くありますが、珍しいオブジェクトモデルを持つものや、そもそもオブジェクトモデルを持たないものもあります。Wrenでは<a href="/docs/wren/v0-4-0/en/01-guide/10-classes/">クラス</a>を中心に据えています。</p>

7 [li]
EN: 
<p><strong>Wren is concurrent.</strong> Lightweight <a href="/docs/wren/v0-4-0/en/01-guide/12-concurrency/">fibers</a> are core to the execution
    model and let you organize your program into a flock of communicating
    coroutines.</p>

JA: <p><strong>Wrenは並行処理を備える。</strong> 軽量な<a href="/docs/wren/v0-4-0/en/01-guide/12-concurrency/">ファイバー</a>が実行モデルの中核を担い、相互に通信するコルーチンの群れとしてプログラムを構成できます。</p>

8 [li]
EN: 
<p><strong>Wren is a scripting language.</strong> Wren is intended for embedding in
    applications. It has no dependencies, a small standard library,
    and <a href="/docs/wren/v0-4-0/en/01-guide/16-embedding/">an easy-to-use C API</a>. It compiles cleanly as C99, C++98
    or anything later.</p>

JA: <p><strong>Wrenはスクリプト言語。</strong> Wrenはアプリケーションへの組み込みを目的としています。依存関係はなく、小さな標準ライブラリと<a href="/docs/wren/v0-4-0/en/01-guide/16-embedding/">使いやすいC API</a>を備えています。C99、C++98、またはそれ以降で問題なくコンパイルできます。</p>
