1 [h1]
EN: Getting Started
JA: はじめに

2 [h2]
EN: Trying out the language #
JA: 言語を試す #

3 [p]
EN: If you’d like to try Wren, you have a few options.
JA: Wrenを試すには、いくつかの方法があります。

4 [li]
EN: In your browser. You can try Wren right here!
JA: ブラウザーで。 ここでWrenを試せます！

5 [li]
EN: On your computer. The Wren CLI project is a downloadable executable
      to run scripts with access to file io and more. See the Wren CLI docs.
JA: 自分のコンピューターで。 Wren CLIプロジェクトはダウンロードできる実行ファイルで、ファイル入出力などを利用するスクリプトを実行できます。Wren CLIの文書を参照してください。

6 [li]
EN: Embedded in your code. See how to build and embed Wren below. 
    And then read the embedding guide!
JA: 自分のコードに組み込んで。 下のWrenのビルドと組み込みを参照してください。続いて、組み込みガイドを読んでください！

7 [p]
EN: Once you have somewhere to explore, it’s time to learn the
language.
JA: 試せる場所が用意できたら、言語を学ぶ番です。

8 [h2]
EN: Embed the VM #
JA: VMを組み込む #

9 [p]
EN: The Wren Virtual Machine is the core of the language that executes Wren
    source code. It is just a library, not a standalone application. It’s
    designed to be embedded in a larger host application.
JA: Wren仮想マシンは、Wrenのソースコードを実行する言語の中核です。単なるライブラリであり、単独で動くアプリケーションではありません。より大きなホストアプリケーションに組み込むことを意図しています。

10 [p]
EN: It has no dependencies beyond the C standard library.
You can use it as a static library, shared library, or simply compile the source into your app.
JA: C標準ライブラリ以外に依存するものはありません。静的ライブラリや共有ライブラリとして利用しても、ソースをアプリケーションに含めてコンパイルしてもかまいません。

11 [h3]
EN: Building Wren #
JA: Wrenをビルドする #

12 [p]
EN: To build the Wren library, we look inside the projects/ folder.
In here you’ll find ready to go projects for Visual Studio, XCode and tools like make.
JA: Wrenライブラリをビルドするには、projects/フォルダーを見ます。ここにはVisual Studio、XCode、およびmakeなどのツール向けに、すぐ使えるプロジェクトが入っています。

13 [li]
EN: Windows Open wren.sln inside projects/vs2019/ (or vs2017), hit build.
JA: Windows projects/vs2019/（またはvs2017）内のwren.slnを開き、ビルドを実行します。

14 [li]
EN: Mac Open wren.xcworkspace inside projects/xcode/, hit build.
JA: Mac projects/xcode/内のwren.xcworkspaceを開き、ビルドを実行します。

15 [li]
EN: Linux Run make inside of projects/make/.
JA: Linux projects/make/内でmakeを実行します。

16 [p]
EN: In each case, there will be library files generated into the root lib/ folder. 
These are what you’ll link into your project, based on your needs.
JA: いずれの場合も、ルートのlib/フォルダーにライブラリのファイルが生成されます。必要に応じて、これらを自分のプロジェクトにリンクします。

17 [li]
EN: Static Linking wren.lib on Windows, libwren.a elsewhere.
JA: 静的リンク Windowsではwren.lib、それ以外ではlibwren.aです。

18 [li]
EN: Dynamic Linking wren.dll on Windows, libwren.so on Linux, and libwren.dylib on Mac.
JA: 動的リンク Windowsではwren.dll、Linuxではlibwren.so、Macではlibwren.dylibです。

19 [p]
EN: 
  Note that the default build will also generate wren_test inside of bin/, 
  a binary that is used to run the language tests. It can execute simple scripts.

JA: 既定のビルドでは、bin/内にwren_testも生成されます。これは言語のテストを実行するためのバイナリーで、簡単なスクリプトも実行できます。

20 [p]
EN: Other platforms 
If your platform isn’t explicitly supported,
it is recommended that you include the Wren source
in your project for a portable experience.
JA: その他のプラットフォーム利用するプラットフォームが明示的にサポートされていない場合は、移植性を得るため、自分のプロジェクトにWrenのソースを含めることをお勧めします。

21 [h3]
EN: Including the code in your project #
JA: 自分のプロジェクトにコードを含める #

22 [p]
EN: all source files 
The alternative to building via the provided projects is to include the wren source code in your project.
Since it has no dependencies this is simple, all the code in src/ comes along. There’s a readme in src/ for details.
JA: すべてのソースファイル用意されているプロジェクトでビルドする代わりに、自分のプロジェクトへWrenのソースコードを含めることもできます。依存関係がないので、src/にあるコードをすべて含めるだけです。詳しくはsrc/内のreadmeを参照してください。

23 [p]
EN: ‘amalgamated’ build 
If you want an even simpler way, there’s an ‘amalgamated’ build (often called blob, or unity builds.).
This is all of the wren source code in one file.
JA: 「amalgamated」ビルドさらに簡単な方法として、「amalgamated」ビルド（blobまたはunityビルドとも呼ばれます）があります。これはWrenのすべてのソースコードを一つのファイルにまとめたものです。

24 [p]
EN: This file can be generated by running python3 util/generate_amalgamation.py > build/wren.c, 
which saves the generated output in build/wren.c.
JA: このファイルはpython3 util/generate_amalgamation.py > build/wren.cを実行すると生成され、出力はbuild/wren.cに保存されます。

25 [p]
EN: Include build/wren.c and src/include/wren.h in your project code and you’re good to go.
Ideally later we can automate generating this and include it in the repo.
JA: 自分のプロジェクトのコードにbuild/wren.cとsrc/include/wren.hを含めれば、準備は完了です。将来的には、この生成を自動化してリポジトリに含められるとよいと考えています。
