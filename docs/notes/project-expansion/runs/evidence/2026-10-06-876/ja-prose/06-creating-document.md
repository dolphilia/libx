# JSONドキュメントの作成

`yyjson_mut_doc`と関連APIは、JSONドキュメントの構築に使います。<br/>

`yyjson_mut_doc`は、すべての文字列と値を保持するために**メモリプール**を使うことに注意してください。プールは、全体として作成・拡張・解放することしかできません。そのため、`yyjson_mut_doc`は、既存ドキュメントの変更よりも、一度だけ書き込む用途に向いています。<br/>

JSONオブジェクトと配列は連結リストで構成されるため、各`yyjson_mut_val`は1つのオブジェクトまたは配列にしか追加できません。
