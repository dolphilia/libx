    - heading "Extending spdlog with your own flags" [level=2]
    - paragraph:
      - text: You can define your own flags by inheriting the
      - link "custom_flag_formatter":
        - /url: https://github.com/gabime/spdlog/blob/v1.x/include/spdlog/pattern_formatter.h#L66,#L75
      - text: class and implementing the

      - text: and
      - code: format(...)
      - text: abstract methods.
    - paragraph:
      - text: The following example adds a new flag
      - strong: "%"
      - text: "* - which will be bound to a <my_formatter_flag> instance."
    - button "Copy code"
    - code:
      - generic: "#include \"spdlog/pattern_formatter.h\""
      - generic: "class my_formatter_flag : public spdlog::custom_flag_formatter"
      - generic: "{"
      - generic: "public:"
      - generic: void format(const spdlog::details::log_msg &, const std::tm &, spdlog::memory_buf_t &dest) override
      - generic: "{"
      - generic: std::string some_txt = "custom-flag";
      - generic: dest.append(some_txt.data(), some_txt.data() + some_txt.size());
      - generic: "}"
      - generic: std::unique_ptr<custom_flag_formatter> clone() const override
      - generic: "{"
      - generic: return spdlog::details::make_unique<my_formatter_flag>();
      - generic: "}"
      - generic: "};"
      - generic: void custom_flags_example()
      - generic: "{"
      - generic: auto formatter = std::make_unique<spdlog::pattern_formatter>();
      - generic: formatter->add_flag<my_formatter_flag>('*').set_pattern("[%n] [%*] [%^%l%$] %v");
      - generic: spdlog::set_formatter(std::move(formatter));
      - generic: "}"
    - paragraph:
      - strong: "Note:"
      - text: The
      - code: clone()
      - text: method should return a deep copy of the object and is required because spdlog passes a new copy of the object to each sink in use (for performance reasons as this enables to have a state in this object without worrying about race conditions or thread safety across sinks).
    - paragraph:
      - strong: "Note:"
      - text: You can also override spdlog's built in flags in this way.
