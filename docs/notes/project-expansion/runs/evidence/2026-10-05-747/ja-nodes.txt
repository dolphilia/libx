 — FS Pollハンドル
FS Pollハンドルは、指定したパスの変更を監視できます。
とは異なり、FS Pollハンドルは
stat
でファイルの変更を検出するため、FS Eventハンドルが動作しないファイルシステムでも使えます。

。ハンドルを開始した後、監視対象のパスに変更があるたびに呼び出します。
コールバックは、
status < 0
で呼び出されます。これは、
path
が存在しない、またはアクセスできない場合です。監視は
停止しません
が、ファイルの作成やエラーの原因が変わるなど、何か変化が起きるまではコールバックを再度呼び出しません。
次の条件、
status == 0
の場合、コールバックは変更前と変更後の
構造体へのポインターを受け取ります。これらはコールバックの実行中だけ有効です。

ハンドルが監視しているパスを取得します。バッファはユーザーが事前に確保する必要があります。成功時は0、失敗時は0未満のエラーコードを返します。成功時は、

バージョン1.3.0での変更: 
返す長さに終端ヌルバイトを含めなくなり、バッファもヌル終端しなくなりました。
バージョン1.9.0での変更: 
次のエラー、
UV_ENOBUFS
の場合、返す長さに終端ヌルバイトを含めるようになりました。また、成功時にはバッファをヌル終端します。
