1 [h1] Functions

2 [p] Like many languages today, functions in Wren are little bundles of code 
you can store in a variable, or pass as an argument to a method. 

3 [p] Notice there’s a difference between <em>function</em> and <em>method</em>.

4 [p] Since Wren is object-oriented, most of your code will live in methods on
classes, but free-floating functions are still eminently handy. 

5 [p] Functions are objects like everything else in Wren, instances of the ⟦CODE0⟧
class.

20 [h2] Callable classes <a class="header-anchor" href="#callable-classes" name="callable-classes">#</a>

21 [p] Because ⟦CODE0⟧ is a class, and responds to ⟦CODE1⟧, any class can respond to
