1 [h1]
EN: Classes
JA: クラス

2 [p]
EN: Every value in Wren is an object, and every object is an instance of a class.
Even ⟦CODE0⟧ and ⟦CODE1⟧ are full-featured objects—instances of the
<a href="/docs/wren/v0-4-0/en/02-reference/01-modules-core-bool/">Bool</a> class.
JA: Wrenのすべての値はオブジェクトで、すべてのオブジェクトはクラスのインスタンスです。⟦CODE0⟧と⟦CODE1⟧も、完全な機能を持つオブジェクトで、<a href="/docs/wren/v0-4-0/en/02-reference/01-modules-core-bool/">Bool</a>クラスのインスタンスです。

3 [p]
EN: Classes define an objects <em>behavior</em> and <em>state</em>. Behavior is defined by
<a href="/docs/wren/v0-4-0/en/01-guide/07-method-calls/"><em>methods</em></a> which live in the class. Every object of the same
class supports the same methods. State is defined in <em>fields</em>, whose values are
stored in each instance.
JA: クラスは、オブジェクトの<em>振る舞い</em>と<em>状態</em>を定義します。振る舞いは、クラスに置く<a href="/docs/wren/v0-4-0/en/01-guide/07-method-calls/"><em>メソッド</em></a>で定義します。同じクラスのオブジェクトは、すべて同じメソッドに対応します。状態は<em>フィールド</em>で定義し、その値は各インスタンスに保存します。
