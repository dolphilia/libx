# セキュリティポリシー

このプロジェクトでセキュリティ上の脆弱性を発見した場合は、非公開で報告してください。**公開の issue として開示しないでください。** そうすることで、公開前に報告者と協力して問題を修正する時間を確保でき、パッチがリリースされる前に脆弱性が悪用される可能性を減らせます。

[このフォーム](https://github.com/lz4/lz4/security/advisories/new)に記入して報告してください。

報告には次の情報を含めてください。

- 脆弱性とその影響の説明
- 問題の再現方法

このプロジェクトは、1人の保守担当者が合理的な範囲での対応を前提に保守しています。そのため、公開前に修正へ取り組む期間として90日間いただくようお願いします。
