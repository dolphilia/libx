41	SAX（Simple API for XML）形式のAPI
SAXと同様に、RapidJSONはイベントへ順次アクセスするパーサーAPI（rapidjson::GenericReader）を提供します。同じイベント群を受け取る生成器API（rapidjson::Writer）も提供します。

42	SAXと同様に、RapidJSONはイベントへ順次アクセスするパーサーAPI（rapidjson::GenericReader）を提供します。同じイベント群を受け取る生成器API（rapidjson::Writer）も提供します。
43	DOM（Document Object Model）形式のAPI
HTML/XMLのDOMと同様に、RapidJSONはJSONをDOM表現（rapidjson::GenericDocument）へ解析し、簡単に操作できます。必要なら最後にJSONへ戻せます。
DOM形式のAPI（rapidjson::GenericDocument）は、実際にはSAX形式のAPI（rapidjson::GenericReader）を使って実装されています。SAXの方が高速ですが、DOMの方が使いやすい場合もあります。利用場面に応じて選択できます。
