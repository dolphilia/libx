<h2 id="formatting-strings">文字列の書式化</h2>
<p><code>printf</code>に似た書式指定子を受け取り、書式化した文字列を指定の文字列へ連結する専用の関数があります。</p>
<pre><code class="language-c">sds sdscatprintf(sds s, const char *fmt, ...) {&#10;</code></pre>
<p>例：</p>
<pre><code class="language-c">sds s;&#10;int a = 10, b = 20;&#10;s = sdsnew("The sum is: ");&#10;s = sdscatprintf(s,"%d+%d = %d",a,b,a+b);&#10;</code></pre>
<p><code>printf</code>の書式指定子から、SDS文字列を直接作成したいこともよくあります。<code>sdscatprintf</code>は実際には文字列を連結する関数なので、空文字列へ連結するだけで作成できます。</p>
<pre><code class="language-c">char *name = "Anna";&#10;int loc = 2500;&#10;sds s;&#10;s = sdscatprintf(sdsempty(), "%s wrote %d lines of LISP\n", name, loc);&#10;</code></pre>
<p><code>sdscatprintf</code>を使って、数値をSDS文字列へ変換できます。</p>
<pre><code class="language-c">int some_integer = 100;&#10;sds num = sdscatprintf(sdsempty(),"%d\n", some_integer);&#10;</code></pre>
<p>ただし、この方法は遅いため、効率良く処理するための専用関数を用意しています。</p>
<h2 id="fast-number-to-string-operations">数値から文字列への高速変換</h2>
<p>プログラムによっては、整数からSDS文字列を作ることがよくあります。<code>sdscatprintf</code>でもできますが、性能上の負担が大きいため、SDSには専用関数があります。</p>
<pre><code class="language-c">sds sdsfromlonglong(long long value);&#10;</code></pre>
<p>次のように使います。</p>
<pre><code class="language-c">sds s = sdsfromlonglong(10000);&#10;printf("%d\n", (int) sdslen(s));&#10;&#10;output&gt; 5&#10;</code></pre>
