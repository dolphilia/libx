<h1 id="embedding-sds-into-your-project">プロジェクトへのSDSの組み込み</h1>
<p><code>sds.c</code>と<code>sds.h</code>をプロジェクト内へコピーするだけです。ソースコードは小さく、どのC99コンパイラーでも問題なく扱えるはずです。</p>
