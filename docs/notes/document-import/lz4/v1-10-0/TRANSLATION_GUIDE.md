# LZ4 1.10.0 翻訳・レビュー指針

固定入力は `SOURCE_LOCK.json`、英語定本は `CANONICAL_LOCK.json` の27ページ。日本語は非公式訳で、外部公開は未依頼。設定モデルはGPT-6.1 Sol、実行中モデルの識別情報はツールで独立確認できない。ローカルLLM・翻訳API・一括翻訳を使わない。

1ページずつ初稿を作り、原文と定本を照合する。編集後の別工程で原文→定本の保全、定本→訳文の意味、日本語単独の読みやすさを全文確認する。原文・定本・訳文SHA、全範囲の行番号、日時、確認内容と指摘をページ別に保存する。機械検査を意味レビューの代用にしない。

| 原語 | 訳語・扱い |
| --- | --- |
| compression / decompression | 圧縮 / 展開 |
| block / frame | ブロック / フレーム |
| dictionary / prefix | 辞書 / プレフィックス |
| streaming | ストリーミング |
| staged install | ステージングインストール |
| buffer / capacity | バッファ / 容量 |
| must / must not | 必須である / してはならない。原文の規範上の強さを保つ |
| should / may | 推奨する / 許可または可能性。文脈に従い区別する |

コードフェンス、インラインコード、API・型・マクロ名、宣言、URL、数値・単位、HTMLタグと属性を保持する。コード中のコメントもコードとともに保護する。ヘッダーの独立した説明コメントは定本の `lz4-source-comment` ごとに訳すが、著作権・許諾条件・免責の原通知は英語全文を保持する。規範文、否定、例外、処理順序、入力と戻り値の意味を落とさない。

見出し、表セル、リスト、注意、説明リンクラベルは訳す。英語の既存見出しアンカーを日本語側でも保持する必要がある場合は、英語DOMで実在を確認したIDを明示要素として追加し、構造変更を記録する。存在しないアンカーを推測しない。

Libxによる出典、非公式訳、変更日、ライセンス適用判断、原誤植・版の矛盾の説明はFrontmatterの `documentContext` に置く。原著の通知を本文から移動しない。掲載時の判断表現は「Libxの運用方針に基づき」とする。既知の原著の相違は784の原文調査と787の編集注記に従い、無断で原文を修正しない。

未完成訳は隔離作業領域へ保存する。全文レビュー済みのページだけ隔離アプリの日本語検証対象へ配置する。全27ページのレビューと最終機械・表示・統合検査、GPL対応ソースキットの履行が終わるまで案件をverifiedにしない。定本変更時は対応訳とレビューを失効させる。
