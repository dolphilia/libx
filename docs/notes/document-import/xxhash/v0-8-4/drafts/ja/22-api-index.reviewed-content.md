<div class="contents xxhash-api">&#10;<div class="textblock"><p>xxHashは、RAMの速度限界に達するほど高速な非暗号学的ハッシュアルゴリズムです。</p>&#10;<p>3つのファミリーに属する4種類を提供します：</p><ol type="1">&#10;<li><a class="el"
