5 環境

環境変数GZIPには、gzipの既定のオプションを指定できます。これらは最初に解釈され、明示的なコマンド行の引数で上書きできます。ただし、スクリプトで問題を起こす可能性があるため、この機能が対応するのは--rsyncable、--synchronous、および-9のような圧縮レベルを設定するオプションだけです。GZIP内のそれ以外のオプションやオペランドは、通知せずに無視します。

代わりにエイリアスやスクリプトを使えます。たとえば、環境変数で「GZIP="-9"」を設定する代わりに、gzipがディレクトリ「/usr/bin」にある場合、PATHの先頭へ$HOME/binを追加し、次の内容の実行可能なスクリプト$HOME/bin/gzipを作れます。

#! /bin/sh
export PATH=/usr/bin
exec gzip -9 "$@"

次の環境変数は、DEFLATE COMPRESSION CALL命令に対応するIBM Zメインフレーム上でgzipを使う場合だけ適用されます。

DFLTCC

DEFLATE COMPRESSION CALLを使うかどうかを指定します。既定値は「1」です。「0」に設定すると、DEFLATE COMPRESSION CALLを完全に無効化します。

DFLTCC_LEVEL_MASK

DEFLATE COMPRESSION CALLを使う圧縮レベルを指定します。各ビットが1つの圧縮レベルに対応する、10進または16進のビットマスクで表します。既定値は「2」で、レベル1だけを意味します。既定でレベル1〜6にDEFLATE COMPRESSION CALLを使うには、「0x7e」に設定します。

DFLTCC_BLOCK_SIZE

DEFLATE COMPRESSION CALLが生成するdeflateブロックのバイト単位のサイズを、10進または16進で指定します。既定値は「1048576」（1メガバイト）です。種類の異なるデータを含むファイル（テキストとバイナリを含む「.tar」アーカイブなど）をDEFLATE COMPRESSION CALLで圧縮する場合、この値を小さくすると圧縮率が高まることがあります。

DFLTCC_FIRST_FHT_BLOCK_SIZE

DEFLATE COMPRESSION CALLが生成する最初の固定deflateブロックのバイト単位のサイズを、10進または16進で指定します。既定値は「4096」（4キロバイト）です。小さなファイルをDEFLATE COMPRESSION CALLで圧縮する場合、この値を大きくすると圧縮率が高まることがあります。

DFLTCC_RIBM

DEFLATE COMPRESSION CALLのパラメーターブロックにある「Reserved for IBM」フィールドの値です。既定値は「0」です。

SOURCE_DATE_EPOCH

何らかの値が設定されていると、DEFLATE COMPRESSION CALLによる圧縮を無効にします。この変数は通常、再現可能なビルドで設定されます。その際には、出力が再現できない場合があるため、DEFLATE COMPRESSION CALLを無効にする必要があります。
