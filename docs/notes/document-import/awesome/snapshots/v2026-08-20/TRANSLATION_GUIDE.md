# Awesome翻訳ガイド

- プロジェクト名、リポジトリ名、URL、アンカー、コード、ライセンス名は変更しない。
- 見出し階層、リスト項目数、順序、URLは英語定本と一致させる。
- リンクラベル、主題説明、項目説明は日本語へ翻訳するが、推薦の強さや対象範囲を補筆しない。
- 未翻訳ページを英語本文のまま日本語ディレクトリへ置かない。
- 翻訳は一ページずつ、構造比較を完了してから公開領域へ確定する。原文との意味照合と日本語確認はフェーズ10で実施する。
- `TRANSLATION_TERMS.json`の保護対象は原文のまま残す。未解決の用語は推測で固定せず、フェーズ10のレビューキューへ記録する。
- Codex・Claude・Geminiなどの高性能LLMは一ページ単位の翻訳補助に使える。Google翻訳・DeepLなどの翻訳API、品質を担保できないローカルLLM、無検査の一括生成は使わない。
