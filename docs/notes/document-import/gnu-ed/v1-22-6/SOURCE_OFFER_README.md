## Reproduce the document site

Use the Node.js and pnpm versions supported by the bundled `package.json`, GNU Texinfo `makeinfo` 7.1, and Python 3 with BeautifulSoup 4. Run inside `workspace`:

```sh
pnpm install --frozen-lockfile --ignore-scripts
python3 docs/notes/document-import/gnu-ed/v1-22-6/regenerate-en.py
python3 docs/notes/document-import/gnu-ed/v1-22-6/extract-units.py
python3 docs/notes/document-import/gnu-ed/v1-22-6/render-translations.py
python3 docs/notes/document-import/gnu-ed/v1-22-6/prepare-notice-draft.py
python3 docs/notes/document-import/gnu-ed/v1-22-6/import-canonical.py
pnpm --filter=apps-gnu-ed build
python3 docs/notes/document-import/gnu-ed/v1-22-6/check-draft-render.py
```

Mechanical replay verifies bytes and rendering; it does not grant a new meaning-review approval. The saved body review applies only to the exact bound original and translated inputs. The package includes editable material for the original and modified documents, with their notices and complete English license.
