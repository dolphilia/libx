2 バグの報告 ¶

GNU timeのバグ報告、機能改善の提案、その他の議論は、bug-time@gnu.orgへ電子メールを送ってください。

バグ報告には、保守担当者が問題を再現できるだけの情報を含めてください。一般に、次の情報が必要です。

  • GNU timeのバージョン番号（「env time --version」を実行すると確認できます）と、関連するほかのプログラムやマニュアルのバージョン番号。
  • ハードウェアとオペレーティングシステムの名前およびバージョン。
  • バグの再現に必要な入力ファイルの内容。
  • 期待する動作や出力。
  • 問題の説明と、誤った出力の例。
  • インストール先ディレクトリの指定以外に、configureへ渡したオプション。
  • そのほか、役に立つと思う情報。

情報が必要かどうか迷った場合は、含めてください。重要な情報を省くより、多めに含めるほうがよいでしょう。

パッチを歓迎します。可能であれば「git format-patch」で作成し、ChangeLogの項目を含めてください（The GNU Emacs ManualのChange Logを参照）。既存のコーディングスタイルに従ってください。
