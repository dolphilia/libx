<article class="libuv-document" id="furo-main-content" role="main">&#10;<section id="introduction">&#10;<h1>はじめに<a class="headerlink" href="#introduction" title="この見出しへの固定リンク">¶</a></h1>&#10;<p>この「本」は、<a class="reference external" href="https://github.com/libuv/libuv">libuv</a>を、WindowsとUnixで同じAPIを提供する高性能なイベント駆動型の入出力ライブラリとして使うための、小さなチュートリアル集です。</p>&#10;<p>libuvの主要な分野を扱うことを目的としており、すべての関数とデータ構造を説明する網羅的なリファレンスではありません。詳しい内容は<a class="reference external" href="https://docs.libuv.org/en/v1.x/">libuvの公式文書</a>を参照してください。</p>&#10;<p>本書はまだ執筆途中のため、不完全な節があるかもしれませんが、充実していく過程も楽しんでいただければと思います。</p>&#10;<section id="who-this-book-is-for">&#10;<h2>本書の対象読者<a class="headerlink" href="#who-this-book-is-for" title="この見出しへの固定リンク">¶</a></h2>&#10;<p>本書を読む方は、次のいずれかに当てはまるでしょう:</p>&#10;<ol class="arabic simple">&#10;<li><p>デーモンやネットワークのサービス・クライアントなど、低水準のプログラムを作るシステムプログラマー。自分のアプリケーションにはイベントループの方式が適していると判断し、libuvを使うことにした方です。</p></li>&#10;<li><p>CやC++で書かれたプラットフォームのAPIを、JavaScriptに公開する同期・非同期APIで包みたいnode.jsモジュールの作成者。libuvはnode.jsの中でのみ使います。本書はv8/node.js固有の部分を扱わないため、その点については別の資料も必要です。</p></li>&#10;</ol>&#10;<p>本書は、C言語に慣れていることを前提としています。</p>&#10;</section>&#10;<section id="background">&#10;<h2>背景<a class="headerlink" href="#background" title="この見出しへの固定リンク">¶</a></h2>&#10;<p><a class="reference external" href="https://nodejs.org">node.js</a>プロジェクトは、ブラウザーから切り離されたJavaScript環境として2009年に始まりました。Googleの<a class="reference external" href="https://v8.dev">V8</a>とMarc Lehmannの<a class="reference external" href="http://software.schmorp.de/pkg/libev.html">libev</a>を使い、node.jsはイベント駆動という入出力モデルと、ブラウザーで形作られてきたことから、そのプログラミング方式に適した言語を組み合わせました。node.jsの人気が高まるにつれ、Windowsで動作させることが重要になりましたが、libevはUnixでしか動作しませんでした。kqueueや(e)pollのようなカーネルのイベント通知機構に相当するWindowsの機構はIOCPです。libuvは、プラットフォームに応じてlibevまたはIOCPを抽象化し、libevを基にしたAPIを利用者に提供していました。node-v0.9.0のlibuvでは<a class="reference external" href="https://github.com/joyent/libuv/issues/485">libevが削除されました</a>。</p>&#10;<p>その後もlibuvは成熟を続け、システムプログラミングのための高品質な独立したライブラリになりました。node.js以外の利用例には、Mozillaのプログラミング言語<a class="reference external" href="https://rust-lang.org/">Rust</a>や、<a class="reference external" href="https://github.com/libuv/libuv/blob/v1.x/LINKS.md">さまざまな言語バインディング</a>があります。</p>&#10;<p>本書とコードは、libuvのバージョン<a class="reference external" href="https://github.com/libuv/libuv/releases/tag/v1.42.0">v1.42.0</a>を基にしています。</p>&#10;</section>&#10;<section id="code">&#10;<h2>コード<a class="headerlink" href="#code" title="この見出しへの固定リンク">¶</a></h2>&#10;<p>すべてのサンプルコードと本書のソースは、GitHubの<a class="reference external" href="https://github.com/libuv/libuv">libuv</a>プロジェクトに含まれています。<a class="reference external" href="https://github.com/libuv/libuv">libuv</a>をクローンまたはダウンロードしてから、ビルドしてください:</p>&#10;<div class="highlight-default notranslate"><div class="highlight"><pre><span></span><span class="n">sh</span> <span class="docutils literal notranslate"><span class="pre">make</span></code>を<code class="docutils literal notranslate"><span
