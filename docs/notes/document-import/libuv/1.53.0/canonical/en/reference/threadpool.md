<article class="libuv-document" id="furo-main-content" role="main">&#10;<section id="thread-pool-work-scheduling">&#10;<span id="threadpool"></span><h1>Thread pool work scheduling<a class="headerlink" href="#thread-pool-work-scheduling" title="Permalink to this heading">¶</a></h1>&#10;<p>libuv provides a threadpool which can be used to run user code and get notified&#10;in the loop thread. This thread pool is internally used to run all file system&#10;operations, as well as getaddrinfo and getnameinfo requests.</p>&#10;<p>Its default size is 4, but it can be changed at startup time by setting the&#10;<code class="docutils literal notranslate"><span class="pre">UV_THREADPOOL_SIZE</span></code> environment variable to any value (the absolute maximum&#10;is 1024).</p>&#10;<div class="versionchanged">&#10;<p><span class="versionmodified changed">Changed in version 1.30.0: </span>the maximum UV_THREADPOOL_SIZE allowed was increased from 128 to 1024.</p>&#10;</div>&#10;<div class="versionchanged">&#10;<p><span class="versionmodified changed">Changed in version 1.45.0: </span>threads now have an 8 MB stack instead of the&#10;(sometimes too low) platform default.</p>&#10;</div>&#10;<div class="versionchanged">&#10;<p><span class="versionmodified changed">Changed in version 1.50.0: </span>threads now have a default name of libuv-worker.</p>&#10;</div>&#10;<p>The threadpool is global and shared across all event loops. When a particular&#10;function makes use of the threadpool (e.g. when using <a class="reference internal" href="#c.uv_queue_work" title="uv_queue_work"><code class="xref c c-func docutils literal notranslate"><span class="pre">uv_queue_work()</span></code></a>)&#10;libuv preallocates and initializes the maximum number of threads allowed by&#10;<code class="docutils literal notranslate"><span class="pre">UV_THREADPOOL_SIZE</span></code>. More threads usually means more throughput but a higher&#10;memory footprint. Thread stacks grow lazily on most platforms though.</p>&#10;<div class="admonition note">&#10;<p class="admonition-title">Note</p>&#10;<p>Note that even though a global thread pool which is shared across all events&#10;loops is used, the functions are not thread safe.</p>&#10;</div>&#10;<section id="data-types">&#10;<h2>Data types<a class="headerlink" href="#data-types" title="Permalink to this
