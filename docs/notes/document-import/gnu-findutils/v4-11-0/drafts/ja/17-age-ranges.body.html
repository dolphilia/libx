2.5.1 経過時間の範囲

これらのテストは、主に範囲を指定する「+n」と「-n」で役立ちます。

テスト: -atime n
テスト: -ctime n
テスト: -mtime n

ファイルへの最後のアクセス、状態の変更、または内容の変更が、n×24時間前に行われた場合に真になります。ファイルのタイムスタンプから経過した24時間単位の数は、常に切り捨てられます。そのため、0は「24時間未満前」、1は「24時間以上48時間未満前」を意味し、以降も同様です。小数にも対応していますが、実際に意味を持つのは、範囲を指定する「+n」と「-n」を使う場合です。

テスト: -amin n
テスト: -cmin n
テスト: -mmin n

ファイルへの最後のアクセス、状態の変更、または内容の変更が、n分前に行われた場合に真になります。「-atime」などより細かい単位で測定できますが、切り捨ては同様に行われます。こちらも小数に対応しています。たとえば、/u/billにある、最後に読み取られたのが2分前から6分前までのファイルを列挙するには、次のようにします。

find /u/bill -amin +2 -amin -6
オプション: -daystart

24時間前ではなく、今日の開始時点から時刻を測ります。そのため、ホームディレクトリ内の、昨日内容が変更された通常のファイルを列挙するには、次のようにします。

find ~/ -daystart -type f -mtime 1

「-daystart」は、ほかのテストの実行方法に影響する点で、大半のオプションと異なります。影響を受けるテストは、「-amin」「-cmin」「-mmin」「-atime」「-ctime」「-mtime」です。「-daystart」は、コマンド行でそれより後に現れるテストの動作だけに影響します。
