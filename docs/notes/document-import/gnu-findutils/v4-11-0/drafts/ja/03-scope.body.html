1.1 用語と対象範囲

簡潔にするため、このマニュアルでいうファイルには、通常のファイル、ディレクトリ、シンボリックリンク、ディレクトリエントリを持つその他の種類のノードを含めます。ディレクトリエントリはファイル名とも呼びます。ファイル名には、そのファイルに至るパスのディレクトリを一部含める場合、すべて含める場合、まったく含めない場合があります。次はいずれも、このマニュアルで「ファイル名」と呼ぶものの例です。

parser.c
README
./budget/may-94.sc
fred/.cshrc
/usr/local/include/termcap.h

ディレクトリツリーとは、あるディレクトリとそこに含まれるファイル、すべてのサブディレクトリとそれらに含まれるファイルなどをまとめたものです。ディレクトリではない単一のファイルを指す場合もあります。

これらのプログラムでは、1つ以上のディレクトリツリーから、次の条件に合うファイルを検索できます。

  • 名前に特定の文字列を含む、または特定のパターンに一致する
  • 特定のファイルへのリンクである
  • 特定の期間内に最後に使用された
  • サイズが特定の範囲内にある
  • 特定の種類である。通常のファイル、ディレクトリ、シンボリックリンクなど。
  • 特定のユーザーまたはグループが所有している
  • 特定のアクセス権限または特別なモードビットを持つ
  • 特定のパターンに一致するテキストを含む
  • ディレクトリツリー内の特定の深さの範囲にある
  • 上記の条件を組み合わせたものに合う

探しているファイル、または該当する可能性のあるファイルが見つかった後は、名前を一覧表示する以外にも操作できます。ファイルの属性を任意に組み合わせて取得したり、1つずつ、あるいはさまざまな大きさのまとまりに分けて、さまざまな方法で処理したりできます。見つかったファイルに対して行いたい操作には、たとえば次のようなものがあります。

  • 表示または編集する
  • アーカイブに格納する
  • 削除または名前を変更する
  • アクセス権限を変更する
  • グループに分類する

このマニュアルでは、これらの作業を行う方法と、それ以外の方法も説明します。
