2.7 種類

テスト: -type c

ファイルの種類がcである場合に真になります。

b

ブロック型の特殊ファイル。バッファリングされます。

c

文字型の特殊ファイル。バッファリングされません。

d

ディレクトリ

p

名前付きパイプ。FIFO。

f

通常のファイル

l

シンボリックリンク。「-L」が有効な場合は、壊れたシンボリックリンクだけで真になります。「-L」が有効なときにシンボリックリンクを検索したい場合は、「-type」の代わりに「-xtype」を使ってください。

s

ソケット

D

door。Solaris。

GNUの拡張として、複数のファイル種類をコンマ「,」で区切った一覧として指定できます。たとえば、「-type f,d,l」は、論理的には「( -type f -o -type d -o -type l )」と解釈されます。

テスト: -xtype c

ファイルがシンボリックリンクでない限り、このテストは「-type」と同じ動作になります。シンボリックリンクの場合、結果は次のとおりです。以下の一覧の「X」は、「l」以外の任意の文字を表します。

‘‘-P -xtype l’’

シンボリックリンクが壊れているか、無限ループになっている場合に真になります。

‘‘-P -xtype X’’

最終的なリンク先ファイルの種類が「X」である場合に真になります。

‘‘-L -xtype l’’

常に真になります。

‘‘-L -xtype X’’

シンボリックリンクが壊れているか、無限ループになっている場合を除き、偽になります。

つまり、壊れていないシンボリックリンクに対して、「-xtype」は「-type」が調べないほうのファイルの種類を調べます。壊れたリンクやループに対しては、「-xtype」は「-type」と同じ動作になります。ユーザーがアクセスできないものを指すシンボリックリンクは、壊れたリンクとはみなしません。

「-H」も「-xtype」の動作に影響します。「-H」が有効なとき、「-xtype」は、コマンド行に列挙したファイルを調べる場合は「-L」を指定したように、それ以外では「-P」を指定したように動作します。「-H」も「-L」も指定しない場合、「-xtype」は「-P」を指定したように動作します。

「-follow」と「-L」の詳細については、シンボリックリンクを参照してください。
