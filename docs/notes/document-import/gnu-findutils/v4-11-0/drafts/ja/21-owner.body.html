2.8 所有者

テスト: -user uname
テスト: -group gname

ファイルをユーザーunameが所有している場合、またはグループgnameに属する場合に真になります。数値IDも指定できます。

テスト: -uid n
テスト: -gid n

ファイルの数値ユーザーID、またはグループIDがnである場合に真になります。「-user」や「-group」と異なり、これらのテストは範囲を指定する「+n」と「-n」に対応しています。

テスト: -nouser
テスト: -nogroup

ファイルの数値ユーザーIDに対応するユーザーがいない場合、または数値グループIDに対応するグループがない場合に真になります。通常、これらは、かつてそのファイルを所有していたユーザーが、すでにシステムから削除されていることを意味します。そのようなファイルの所有者は、chownやchgrpを使って、存在するユーザーやグループに変更するほうがよいでしょう。
