2.1 findの式

findがファイルを選択するために使う式は、1つ以上の基本要素（primary）から成り、それぞれがfindの独立したコマンド行引数になります。findはファイルを処理するたびに式を評価します。式には、次の種類の基本要素を含められます。

オプション

特定のファイルの処理ではなく、全体の動作に影響します。

テスト

ファイルの属性に応じて真または偽を返します。

アクション

副作用を持ち、真または偽を返します。

演算子

ほかの引数を結び付け、その評価のタイミングと、評価するかどうかに影響します。

2つの基本要素の間の演算子は省略でき、既定値は「-and」です。基本要素を結び付けて、より複雑な式にする方法については、演算子で基本要素を組み合わせるを参照してください。

式に「-prune」または「-quit」以外のアクションが含まれていない限り、式全体が真になるすべてのファイルに「-print」アクションが実行されます（ファイル名を表示するを参照）。既定の「-print」を抑制するアクションは、「-delete」「-execdir」「-exec」「-fls」「-fprint0」「-fprintf」「-fprint」「-ls」「-okdir」「-ok」「-print0」「-printf」「-print」です。

オプションは、式中のその位置に到達したときにファイルごとに評価されるのではなく、直ちに効力を持ちます。そのため、分かりやすくするには式の先頭に置くのが最適です。ただし例外があり、「-regextype」「-daystart」「-follow」はコマンド行中の位置によって効果が異なります。紛らわしいため、これらも先頭に置くのが最適です。

多くの基本要素は引数を取り、その引数はfindの次のコマンド行引数として直後に置きます。ファイル名、パターン、その他の文字列を取るものもあれば、数値を取るものもあります。数値引数は次のように指定できます。

+n

nより大きい値

-n

nより小さい値

n

nと正確に等しい値
