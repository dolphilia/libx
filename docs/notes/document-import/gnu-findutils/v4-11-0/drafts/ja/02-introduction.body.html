1 はじめに

このマニュアルでは、指定した条件に合うファイルを検索する方法と、見つかったファイルにさまざまな操作を行う方法を説明します。これらの作業で主に使うプログラムは、find、locate、xargsです。掲載例の中には、これらのプログラムのGNU版に固有の機能を使うものもあります。

find、locate、xargsの歴史については、歴史を参照してください。GNU findutilsとこのマニュアルの現在の保守担当者は、Bernhard VoelkerとJames Youngmanです。ほかにも多くの方が、バグ修正、小さな改善、有益な提案を寄せてくださいました。ありがとうございます。

GNU findutilsのバグを報告するには、Savannahのウェブサイトhttps://savannah.gnu.org/bugs/?group=findutilsにあるフォームを使ってください。この方法で報告すると、問題の修正状況を追跡できます。

ウェブにアクセスできない場合は、メーリングリストにメールを送るだけでも報告できます。bug-findutils@gnu.orgでは、findutilsのバグ、ソフトウェアについての質問と回答、プログラム開発について議論しています。参加するには、bug-findutils-request@gnu.orgへメールを送ってください。

メーリングリストで助けを求める前に、このマニュアルの関連する節を読んでください。findのマニュアルページにあるNON-BUGSの節も役立つ場合があります。

メーリングリストで助けを求めるときは、次の情報を含めると、ほかの方がより効果的に支援できます。

  • 実行しているソフトウェアのバージョン。「locate --version」を実行すると確認できます。
  • 何をしようとしていたか
  • 実際に使った正確なコマンド行
  • 実際に得られた正確な出力。非常に長い場合は、同じ問題を示す、より小さい例を探してください。
  • 期待していた出力

報告しようとしている問題がバグである場合でも、すでに修正されている可能性があります。ftp://ftp.gnu.org/gnu/findutilsにある最新のfindutilsリリースと、可能であればftp://alpha.gnu.org/gnu/findutilsにある開発版を確認してください。現行リリースでもバグが発生することを確認しておくと、問題の解決を手伝う人にとって大きな助けになります。また、GNU/Linuxの「ディストリビューション」に含まれるfindutilsを入手した場合、安定版も含めて、ディストリビューションの版がfindutilsのリリースから大きく遅れていることがよくあります。GNUのFTPサイトを確認してください。
