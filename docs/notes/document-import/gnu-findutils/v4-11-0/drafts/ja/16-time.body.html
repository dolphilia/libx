2.5 時刻

各ファイルには、特定の操作が最後に行われた時刻を記録する、3つのタイムスタンプがあります。

  1. アクセス。ファイルの内容を読み取ること。
  2. 状態の変更。ファイルまたはその属性を変更すること。
  3. 内容の変更。ファイルの内容を変更すること。

ファイルが作成された時刻を示すタイムスタンプも提供するシステムがあります。たとえば、NetBSD-3.1のUFS2ファイルシステムは、各ファイルの誕生時刻（birth time）を記録します。この情報は、ほかのBSDの版や一部のCygwinの版でも利用できます。ただし、誕生時刻に対応するシステムでも、この情報が記録されていないファイルが存在する場合があります。たとえば、UFS1ファイルシステムにはこの情報がありません。

タイムスタンプからの経過時間が特定の範囲にあるファイルを検索したり、ほかのタイムスタンプと比較したりできます。
