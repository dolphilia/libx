9.1 sdiff に diff のオプションを指定する

次の sdiff のオプションは、diff と同じ意味を持ちます。これらのオプションの使い方は、diff のオプション を参照してください。

-a -b -d -i -t -v
-B -E -I regexp -Z

--expand-tabs
--ignore-blank-lines  --ignore-case
--ignore-matching-lines=regexp  --ignore-space-change
--ignore-tab-expansion  --ignore-trailing-space
--left-column  --minimal  --speed-large-files
--strip-trailing-cr  --suppress-common-lines
--tabsize=columns  --text  --version  --width=columns

歴史的な理由から、sdiff では一部のオプションに別の名前があります。-l オプションは --left-column オプションと同じで、同様に -s は --suppress-common-lines と同じです。sdiff の -w と -W オプションの意味は diff とは入れ替わっています。sdiff では、-w columns は --width=columns と同じで、-W は --ignore-all-space と同じです。-o オプションなしの sdiff は、--side-by-side（-y）オプションを指定した diff と同じです（差分を左右に並べて表示する を参照）。
