15.1 patch のオプション

GNU patch が受け付けるすべてのオプションを以下にまとめます。古いバージョンの patch でも安全に使えるオプションについては、GNU patch と従来の patchを参照してください。

引数を取らない1文字のオプションは、複数をダッシュ1つのコマンドライン引数にまとめられます。

-b
--backup

通常はバックアップを作らない場合も、各ファイルの元の内容をバックアップします。バックアップファイルを参照してください。

-B prefix
--prefix=prefix

バックアップファイル名の先頭に prefix を付けます。バックアップファイル名を参照してください。

--backup-if-mismatch

パッチがファイルと厳密に一致しない場合に、各ファイルの元の内容をバックアップします。POSIX に適合しない場合のデフォルト動作です。バックアップファイルを参照してください。

--binary

標準出力と /dev/tty を除き、すべてのファイルをバイナリモードで読み書きします。GNU/Linux のような POSIX 適合システムでは効果がありません。効果があるシステムでは、パッチを「diff -a --binary」で生成する必要があります。バイナリファイルとテキスト比較の強制を参照してください。

-c
--context

パッチファイルをコンテキスト diff として解釈します。patch の入力形式を選択するを参照してください。

-d directory
--directory=directory

パッチファイル内のファイル名と、他のオプションの引数として指定したファイル名の両方を解釈するとき、ディレクトリ directory をカレントディレクトリにします。別のディレクトリへパッチを適用するを参照してください。

-D name
--ifdef=name

name を使い、マージされた if-then-else 出力を作ります。if-then-else によるファイルのマージを参照してください。

--dry-run

ファイルを実際には変更せず、パッチを適用した結果を表示します。patch の動作を予測するを参照してください。

-e
--ed

パッチファイルを ed スクリプトとして解釈します。patch の入力形式を選択するを参照してください。

-E
--remove-empty-files

パッチ適用後に空になった出力ファイルを削除します。ファイルの作成と削除を参照してください。

-f
--force

利用者が自分の操作を十分に理解していると仮定し、質問を一切しません。patch のメッセージと質問を参照してください。

-F lines
--fuzz=lines

最大 fuzz 係数を lines に設定します。patch が厳密には一致しない箇所を探すのを助けるを参照してください。

-g num
--get=num

num が正なら必要に応じて版管理システムから入力ファイルを取得し、0なら取得せず、負なら取得するか利用者に尋ねます。版管理を参照してください。

--help

使用方法の概要を出力して終了します。

-i patchfile
--input=patchfile

標準入力ではなく patchfile からパッチを読みます。patch のオプションを参照してください。

-l
--ignore-white-space

パッチファイル中の空白（スペースまたはタブ）の任意の連続を、入力ファイル中の任意の空白の連続に一致させます。空白が変更されたパッチを適用するを参照してください。

-n
--normal

パッチファイルを通常の diff として解釈します。patch の入力形式を選択するを参照してください。

-N
--forward

patch が逆向き、または適用済みと判断するパッチを無視します。-R も参照してください。逆向きのパッチを適用するを参照してください。

--no-backup-if-mismatch

ファイルの元の内容をバックアップしません。POSIX に適合する場合のデフォルト動作です。バックアップファイルを参照してください。

-o file
--output=file

file を出力ファイル名として使います。patch のオプションを参照してください。

-pnumber
--strip=number

ファイル名から取り除く要素数を number に設定します。別のディレクトリへパッチを適用するを参照してください。

--posix

環境変数 POSIXLY_CORRECT が設定されている場合と同様に、POSIX に適合します。patch と POSIX 規格を参照してください。

--quoting-style=word

環境変数 QUOTING_STYLE に word が設定されている場合と同様に、診断メッセージ内の名前を形式 word で引用します。patch の引用形式を参照してください。

-r reject-file
--reject-file=reject-file

reject-file を拒否ファイル名として使います。拒否ファイル名を参照してください。

-R
--reverse

このパッチは旧ファイルと新ファイルを入れ替えて作成されたものと仮定します。逆向きのパッチを適用するを参照してください。

-s
--quiet
--silent

エラーが発生しない限り静かに動作します。patch のメッセージと質問を参照してください。

-t
--batch

質問を一切しません。patch のメッセージと質問を参照してください。

-T
--set-time

コンテキスト diff のヘッダーにあるタイムスタンプをローカル時刻とみなし、それに従ってパッチ適用後のファイルの変更時刻とアクセス時刻を設定します。パッチ適用後のファイルのタイムスタンプを更新するを参照してください。

-u
--unified

パッチファイルを unified diff として解釈します。patch の入力形式を選択するを参照してください。

-v
--version

バージョン情報を出力して終了します。

-V backup-style
--version=control=backup-style

バックアップファイル名の命名規則を選択します。バックアップファイル名を参照してください。

--verbose

通常より多くの診断メッセージを表示します。patch のメッセージと質問を参照してください。

-x number
--debug=number

内部デバッグフラグを設定します。patch 自体を修正する人だけに関係する機能です。

-Y prefix
--basename-prefix=prefix

バックアップファイルの基本名の先頭に prefix を付けます。バックアップファイル名を参照してください。

-z suffix
--suffix=suffix

バックアップ拡張子として「.orig」や「~」の代わりに suffix を使います。バックアップファイル名を参照してください。

-Z
--set-utc

コンテキスト diff のヘッダーにあるタイムスタンプを UTC とみなし、それに従ってパッチ適用後のファイルの変更時刻とアクセス時刻を設定します。パッチ適用後のファイルのタイムスタンプを更新するを参照してください。
