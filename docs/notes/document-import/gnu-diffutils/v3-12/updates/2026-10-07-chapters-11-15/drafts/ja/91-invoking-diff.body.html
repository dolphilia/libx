13 diff の起動

diff コマンドの実行形式は次のとおりです。

diff options... files...

最も単純な場合は2つのファイル名 from-file と to-file を指定し、diff が from-file と to-file の内容を比較します。ファイル名 - は標準入力を表します。

一方がディレクトリで他方がそうでなければ、diff はそのディレクトリ内にある、ディレクトリではない方と同じ名前のファイルを比較します。ディレクトリではない方のファイルに - は指定できません。

2つのファイル名が両方ともディレクトリなら、diff は両ディレクトリ内の対応するファイルをアルファベット順で比較します。--recursive（-r）オプションを指定しない限り、比較は再帰的ではありません。diff はディレクトリ自体の内容をファイルのように比較することはありません。名前を完全に指定する側のファイルは標準入力にできません。標準入力には名前がなく、「同じ名前のファイル」という考え方が適用できないためです。

--from-file=file オプションを指定すると、ファイル名の数は任意になり、file を指定された各ファイルと比較します。同様に --to-file=file オプションを指定すると、指定された各ファイルを file と比較します。

diff のオプションは「-」で始まるため、通常ファイル名を「-」で始めることはできません。ただし、単独の引数 -- を置くと、それ以降の引数は「-」で始まっていてもファイル名として扱われます。

終了ステータス0は相違がなかったこと、1は相違があったこと、2は問題が起きたことを表します。
