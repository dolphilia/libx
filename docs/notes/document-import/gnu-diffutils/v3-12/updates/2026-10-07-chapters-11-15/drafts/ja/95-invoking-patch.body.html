15 patch の起動

通常、patch は次のように起動します。

patch <patchfile

patch の完全な起動形式は次のとおりです。

patch options... [origfile [patchfile]]

-i patchfile または --input=patchfile オプションでも、パッチの読み取り元を指定できます。patchfile を指定しない場合、または patchfile が - の場合、patch は標準入力からパッチ（すなわち diff の出力）を読みます。

コマンドラインで入力ファイルを指定しなければ、patch は先頭テキスト（パッチ内で diff の出力より前にあるテキスト）から、編集するファイルを推測します。1つのファイルに複数のパッチを参照してください。

デフォルトでは、patch は元の入力ファイルをパッチ適用後の版に置き換えます。その前に元のファイルをバックアップ名へ改名することがあります（patch による命名方法はバックアップファイル名参照）。-o file または --output=file オプションで出力先を指定することもできます。ただし、file が入力ファイルの1つである場合は、このオプションを使わないでください。
