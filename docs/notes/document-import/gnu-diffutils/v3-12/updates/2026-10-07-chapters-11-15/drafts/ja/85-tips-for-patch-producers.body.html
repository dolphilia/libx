11.1 パッチ作成者へのヒント

パッケージの旧版を新版に変更するパッチを作るには、まず旧版と新版を隣り合うサブディレクトリへコピーします。一般には、両バージョンの tar アーカイブを展開してこれを行います。

パッチを生成するには「diff -Naur old new」を使います。old と new は、それぞれ旧版と新版のディレクトリを示します。名前 old と new にスラッシュを含めてはいけません。-N オプションはパッチによるファイルの作成・削除を可能にし、-a は非テキストファイルの更新を可能にします。-u は有用なタイムスタンプと十分なコンテキストを生成し、-r はサブディレクトリの更新を可能にします。Bourne シェル構文によるコマンド例を示します。

diff -Naur gcc-3.0.3 gcc-3.0.4

受取人にパッチの適用方法を伝えてください。使用する作業ディレクトリと patch のオプションも含めます。「-p1」オプションを推奨します。受取人の立場になって元のファイルのコピーへパッチを適用し、手順を試してください。

パッチ生成時によくある間違いを避ける方法は、よくある間違いを避けるを参照してください。
