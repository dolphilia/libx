12.1 cmp のオプション

GNU cmp が受け付けるすべてのオプションを以下にまとめます。ほとんどのオプションには、同等の名前が2つあります。一方は「-」を前置した1文字、他方は「--」を前置した長い名前です。引数を取らない1文字のオプションは、複数をコマンドラインの1語にまとめられます。-bl は -b -l と同等です。

-b
--print-bytes

異なるバイトを表示します。各制御バイトは「^」に続けて ASCII の英字、「@」、「[」、「\」、「]」、「^」、または「_」として表示します。上位ビットが立っている各バイトの前には、meta を表す「M-」を付けます。制御バイトとは、上位ビットが0で、空白を含む表示可能な ASCII 文字を表さないバイトです。

--help

使用方法の概要を出力して終了します。

-i skip
--ignore-initial=skip

入力ファイルの先頭 skip バイトにある相違を無視します。skip バイト未満のファイルは空とみなします。skip が from-skip:to-skip の形式なら、第1入力ファイルの先頭 from-skip バイトと第2入力ファイルの先頭 to-skip バイトを読み飛ばします。

-l
--verbose

デフォルトの標準出力形式に代えて、異なるすべてのバイトの番号（10進数）と値（8進数）を出力します。各出力行には入力の先頭を基準とした相違バイトの番号と、そのバイトの両方の値が含まれます。バイト番号は1から始まります。また、一方のファイルが短ければ EOF メッセージも出力します。

-n count
--bytes=count

入力を最大 count バイト比較します。

-s
--quiet
--silent

何も表示せず、ファイルが異なるかどうかを示す終了ステータスだけを返します。

-v
--version

バージョン情報を出力して終了します。

上の表でバイト数を表すオペランドは通常10進数ですが、先頭に「0」を付ければ8進数、「0x」を付ければ16進数になります。

バイト数には、その倍数を指定する接尾辞を付けられます。英字単独または英字に「iB」を続けた接尾辞は1024のべき乗による倍数を指定します。英字に「B」を続けると、代わりに1000のべき乗を指定します。たとえば「-n 1M」と「-n 1MiB」は「-n 1048576」に相当し、「-n 1MB」は「-n 1000000」に相当します。

次の接尾辞が定義されています。1Q のような大きなサイズは、計算処理の制約によりコンピューターが受け付けないことがあります。

‘kB’

キロバイト：10^3 = 1000.

‘k’
‘K’
‘KiB’

キビバイト：2^{10} = 1024。「K」は特別です。SI 接頭辞は「k」、ISO/IEC 80000-13 の接頭辞は「Ki」ですが、慣習と POSIX では「k」を「KiB」の意味で使います。

‘MB’

メガバイト：10^6 = 1,000,000.

‘M’
‘MiB’

メビバイト：2^{20} = 1,048,576.

‘GB’

ギガバイト：10^9 = 1,000,000,000.

‘G’
‘GiB’

ギビバイト：2^{30} = 1,073,741,824.

‘TB’

テラバイト：10^{12} = 1,000,000,000,000.

‘T’
‘TiB’

テビバイト：2^{40} = 1,099,511,627,776.

‘PB’

ペタバイト：10^{15} = 1,000,000,000,000,000.

‘P’
‘PiB’

ペビバイト：2^{50} = 1,125,899,906,842,624.

‘EB’

エクサバイト：10^{18} = 1,000,000,000,000,000,000.

‘E’
‘EiB’

エクスビバイト：2^{60} = 1,152,921,504,606,846,976.

‘ZB’

ゼタバイト：10^{21} = 1,000,000,000,000,000,000,000

‘Z’
‘ZiB’

ゼビバイト：2^{70} = 1,180,591,620,717,411,303,424.

‘YB’

ヨタバイト：10^{24} = 1,000,000,000,000,000,000,000,000.

‘Y’
‘YiB’

ヨビバイト：2^{80} = 1,208,925,819,614,629,174,706,176.

‘RB’

ロナバイト：10^{27} = 1,000,000,000,000,000,000,000,000,000.

‘R’
‘RiB’

ロビバイト：2^{90} = 1,237,940,039,285,380,274,899,124,224.

‘QB’

クエタバイト：10^{30} = 1,000,000,000,000,000,000,000,000,000,000.

‘Q’
‘QiB’

クエビバイト：2^{100} = 1,267,650,600,228,229,401,496,703,205,376.
