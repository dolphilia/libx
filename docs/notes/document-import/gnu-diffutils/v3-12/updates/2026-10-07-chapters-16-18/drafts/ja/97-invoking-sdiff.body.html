16 sdiff の起動

sdiff コマンドは2つのファイルをマージし、結果を対話的に出力します。引数は次のとおりです。

sdiff -o outfile options... from-file to-file

これは from-file と to-file をマージし、outfile へ出力します。from-file がディレクトリで to-file がそうでない場合、sdiff は from-file 内にある、to-file と同じファイル名のファイルを比較します。逆の場合も同様です。from-file と to-file の両方をディレクトリにすることはできません。

sdiff のオプションは「-」で始まるため、通常 from-file と to-file は「-」で始められません。ただし、単独の引数 -- を指定すると、それ以降の引数は「-」で始まっていてもファイル名として扱われます。入力ファイルとして - は使えません。

sdiff を --output（-o）なしで使うと、差分を左右に並べて出力します。この使い方は旧式です。代わりに --side-by-side（-y）オプションを diff に指定してください。

終了ステータス0は相違がなかったこと、1は相違があったこと、2は問題が起きたことを表します。
