16.1 sdiff のオプション

GNU sdiff が受け付けるすべてのオプションを以下にまとめます。各オプションには同等の名前が2つあり、一方は「-」に続く1文字、もう一方は「--」に続く長い名前です。引数を取らない1文字のオプションは、複数をコマンドラインの1つの引数にまとめられます。長い名前のオプションは、その名前を一意に識別できる任意の接頭部へ省略できます。

-a
--text

テキストに見えないファイルも含め、すべてのファイルをテキストとして扱い、行単位で比較します。バイナリファイルとテキスト比較の強制を参照してください。

-b
--ignore-space-change

空白の量の変化を無視します。スペースとタブによる空白の差分を抑制するを参照してください。

-B
--ignore-blank-lines

空行の挿入または削除だけによる変化を無視します。すべての行が空行である差分を抑制するを参照してください。

-d
--minimal

より小さい変更集合が見つかる可能性のあるアルゴリズムに変更します。これによって sdiff は遅くなり、ときには大幅に遅くなります。diff の性能上のトレードオフを参照してください。

--diff-program=program

ファイル比較に diff の代わりに互換性のある比較プログラム program を使います。

-E
--ignore-tab-expansion

タブ展開による変化を無視します。スペースとタブによる空白の差分を抑制するを参照してください。

--help

使用方法の概要を出力して終了します。

-i
--ignore-case

大文字・小文字の変化を無視し、両者を同じものとして扱います。大文字・小文字の差分を抑制するを参照してください。

-I regexp
--ignore-matching-lines=regexp

regexp に一致する行の挿入または削除だけによる変化を無視します。すべての行が正規表現に一致する差分を抑制するを参照してください。

-l
--left-column

共通する2行について左の列だけを出力します。左右比較書式を制御するを参照してください。

-o file
--output=file

マージ結果を file に出力します。マージにはこのオプションが必要です。

-s
--suppress-common-lines

共通する行を出力しません。左右比較書式を制御するを参照してください。

--speed-large-files

小さな変更が多数散在する大きなファイルの処理を高速化するために、ヒューリスティックを使います。diff の性能上のトレードオフを参照してください。

--strip-trailing-cr

入力行末尾のキャリッジリターンを除去します。バイナリファイルとテキスト比較の強制を参照してください。

-t
--expand-tabs

入力ファイルのタブによる整列を保持するため、出力ではタブを空白に展開します。タブ位置の整列を保持するを参照してください。

--tabsize=columns

タブ位置は表示上の columns 列ごと（デフォルト8）に設定されていると仮定します。タブ位置の整列を保持するを参照してください。

-v
--version

バージョン情報を出力して終了します。

-w columns
--width=columns

1行あたり最大 columns 列（デフォルト130）を出力します。左右比較書式を制御するを参照してください。歴史的な理由により、このオプションは diff では -W、sdiff では -w です。

-W
--ignore-all-space

行の比較時に空白を無視します。スペースとタブによる空白の差分を抑制するを参照してください。歴史的な理由により、このオプションは diff では -w、sdiff では -W です。

-Z
--ignore-trailing-space

行末の空白を無視します。スペースとタブによる空白の差分を抑制するを参照してください。
