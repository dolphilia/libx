18.1.6 特定の変化を無視する

from-file と to-file にそれぞれ文字列を1つ指定し、その2つを一致すると見なす機能があると便利です。たとえば2つの文字列が「foo」と「bar」なら、ファイル1の「foo」とファイル2の「bar」の対応だけが異なる2行は同一として扱います。

この機能をどこまで一般化できるか、または一般化すべきか、どの構文を使うべきかは明確ではありません。

部分的な代替策として、比較前に一方または両方のファイルをフィルターで処理する方法があります。例を示します。

sed 's/foo/bar/g' file1 | diff - file2

ただし、これは元のテキストではなく、フィルター処理後のテキストを出力します。
