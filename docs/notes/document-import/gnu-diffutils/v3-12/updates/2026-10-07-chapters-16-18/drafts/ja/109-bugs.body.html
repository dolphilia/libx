18.2 バグの報告

GNU cmp、diff、diff3、sdiff にバグを見つけたと思う場合は、電子メールで GNU ユーティリティのバグ報告メーリングリスト bug-diffutils@gnu.org へ報告してください。GNU patch のバグ報告は bug-patch@gnu.org へ送ってください。該当する場合は、--version オプションの出力とバグを再現する入力ファイルの例を含め、できるだけ正確に問題を説明してください。バグに対する重要な修正がある場合は、それも送ってください。パッチがある場合も送ってください。パッチを最近のテストリリースに対して作ると、メンテナーの作業を簡単にできる場合があります。そのリリースは ftp://alpha.gnu.org/gnu/diffutils/ ディレクトリで見つけられます。
