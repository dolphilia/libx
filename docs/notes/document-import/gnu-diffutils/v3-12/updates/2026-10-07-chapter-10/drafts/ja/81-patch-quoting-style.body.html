10.11.3 patchの引用形式

patchは診断メッセージ内のファイル名を、複数の形式で出力できます。句読点や改行などの特殊文字を含む場合でも、曖昧さなく名前を示すのに役立ちます。--quoting-style=wordオプションは出力形式を制御します。wordには次のいずれかを指定します。

‘literal’

名前をそのまま出力します。

‘shell’

シェルのメタ文字を含む、または出力が曖昧になる場合に、シェル用の引用をします。

‘shell-always’

通常は不要でも、シェル用の引用をします。

‘c’

C 言語の文字列として引用します。

‘escape’

‘c’ と同様ですが、周囲の二重引用符を省きます。

--quoting-styleオプションの既定値は、QUOTING_STYLE環境変数で指定できます。未設定なら ‘shell’ が既定ですが、将来のpatchでは変わるかもしれません。
