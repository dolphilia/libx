<a id="source-appendix-b---resources-for-implementers"></a>

付録B — 実装者向けの資料
-------------------------------------------------

オープンソースの参照実装は次の場所にあります:
https://github.com/facebook/zstd

このプロジェクトには、[decodeCorpus]というフレーム生成器が含まれます。
サードパーティーの実装でも、テスト対象のデコーダーが仕様に適合しているかの確認に利用できます。

[decodeCorpus]: https://github.com/facebook/zstd/tree/v1.3.4/tests#decodecorpus---tool-to-generate-zstandard-frames-for-decoder-testing

`decodeCorpus`は、ランダムな有効フレームを生成します。
仕様に適合するデコーダーは、そのすべてを復号できることが望まれます。
少なくとも、復号できない理由（たとえばメモリ制限）を説明する、意味のあるエラーコードを返すことが望まれます。
