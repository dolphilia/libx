# ADR-0002: ドキュメントサイトの正規テンプレートを配信アプリから分離する

- ステータス: 承認
- 日付: 2026-08-11
- 提案者: リポジトリ管理者
- 承認者: リポジトリ管理者
- 置換対象: なし
- 置換元: なし

## 背景

新規サイト生成に使う `apps/project-template` は、配信対象のドキュメントサイトと同じ `apps/` に置かれていた。そのため、通常サイトとテンプレートの区別が名前依存の除外処理に分散し、実サイトと誤認して変更・削除・配信される可能性があった。

## 決定

1. 正規テンプレートを `templates/docs-site` へ移動する。
2. `apps/` は配信対象のドキュメントサイト、`templates/` は生成元という配置上の責務境界にする。
3. テンプレートは pnpm ワークスペースへ含めるが、通常・選択的・統合ビルドから除外し、`pnpm build:template` で独立検証する。
4. 新規サイト生成は既定で `templates/docs-site` をコピーする。
5. 必須構造、コピー時の除外、設定変換、テンプレートビルドを自動検査する。

## 判断理由

名前による例外よりもディレクトリ境界の方が、用途と配信可否を理解しやすい。専用の README、ビルドコマンド、回帰テストを設けることで、テンプレートが利用中の重要資産であることと破損を明示できる。

## 検討した代替案

### `apps/project-template` のまま警告文だけ追加する

変更量は少ないが、ビルド・検出処理の名前依存と配信対象との混在が残るため採用しない。

### `packages/` に移動する

共有資産であることは表せるが、テンプレートはライブラリパッケージではなく完全な Astro ワークスペースであり、`packages/` の責務と一致しないため採用しない。

## 影響

- 通常の `apps/*` スキャンは名前によるテンプレート除外を必要としなくなる。
- テンプレート検証は通常サイトのビルドとは別に実行する。
- テンプレートのパスを参照するスクリプト、テスト、文書、ロックファイルを更新する必要がある。

## 移行方法

- `apps/project-template` を `templates/docs-site` へ移動する。
- ワークスペースと生成スクリプトを新配置へ対応させる。
- 旧名称に依存する除外処理を削除する。
- 文書とテストの参照を更新する。

## 検証方法

- `pnpm test:runtime` でテンプレートの構造、コピー、設定変換を確認する。
- `pnpm build:template` でテンプレート自身をビルドする。
- `pnpm check` で通常サイトと共有パッケージを含む全体整合性を確認する。
- リポジトリ内に `apps/project-template` への有効な参照が残っていないことを検索する。
