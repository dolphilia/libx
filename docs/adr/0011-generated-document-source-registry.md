# ADR-0011: 大量外部文書の出典レジストリをロックファイルから生成する

- ステータス: 承認
- 日付: 2026-08-20
- 提案者: リポジトリ管理者
- 承認者: リポジトリ管理者

## 決定

大量の独立した取得元を持つサイトは、`SOURCES.lock.json`を入力として、アプリ専用の出典レジストリを生成する。各ページは安定した`licenseSource` IDだけを参照する。ロック・決定・生成物を二重に手編集してはならない。

生成前検査は、`included`以外の本文が公開ディレクトリへ入らないこと、全`licenseSource`が生成レジストリに存在すること、英日で同一IDを参照することを失敗条件にする。

## 理由

`project.config.jsonc`への数百件の手入力は、固定コミット・ライセンス判断との整合を維持できない。既存の`DocumentProvenance`はページが参照するIDを表示する責務に保ち、取得・法務記録の正本はインポート記録に置く。

## 影響

- Awesome専用インポーターはロック済みソースだけから設定断片とページを生成する。
- 未知・欠落した出典IDはビルド前検査で失敗する。
- 既存サイトの少数出典設定は移行しない。
