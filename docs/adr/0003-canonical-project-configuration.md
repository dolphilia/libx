# ADR-0003: プロジェクト設定の正本を現行ProjectConfigへ統一する

- ステータス: 承認
- 日付: 2026-08-11
- 提案者: リポジトリ管理者
- 承認者: リポジトリ管理者
- 置換対象: なし
- 置換元: なし

## 背景

同じ設定に `language.default` と `defaultLang` があり、内部コードは現行設定をレガシー形式へ変換してから利用していた。JSONC解析と既定値解決も複数実装に分かれていた。

## 決定

`project.config.jsonc` と非同期 `getProjectConfig` を正規経路にする。既定言語は `language.default`、ロケール集合は翻訳辞書のキー、JSONC解析は `@docs/project-config/jsonc`、既定値の正規化は `default-resolvers.js` を正本とする。リポジトリ内で未使用になったレガシーAPI・型・設定形式は削除する。

## 判断理由

意味ごとの正本が明確になり、同期初期化と互換変換を理解する必要がなくなる。正式原則はリポジトリ内で未使用の互換コードを残すことを要求していない。

## 検討した代替案

レガシーAPIを非推奨として残す案は、内部利用がなく外部公開パッケージでもないため採用しない。`defaultLang` を正本にする案は、他の言語設定と分離されるため採用しない。

## 影響

内部利用者は `ProjectConfig.paths`、`language`、`versioning` を直接参照する。古いAPIと旧 `basic.*` 設定は受理されない。

## 移行方法

全アプリ、テンプレート、共有パッケージを現行APIへ移し、参照0件を確認して互換層を削除する。

## 検証方法

型検査、設定単体テスト、テンプレートと全アプリのビルド、リポジトリ整合性検査を実行する。
