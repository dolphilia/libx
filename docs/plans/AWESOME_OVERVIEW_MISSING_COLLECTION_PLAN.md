# Awesome概要ページ未収録リストの収録計画

- 作成日: 2026-08-23
- 対象版: `v2026-08-20`
- 対象: Awesome概要ページに掲載され、調査開始時に英日ページがなかった307リポジトリ
- 今回の言語範囲: 英語のみ（日本語化は後続作業）
- 状態: 英語収録・ルート生成・検証完了

## 1. 目的

英語版`overview/sindresorhus-awesome`に掲載された他のAwesomeリスト669件を、すべてlibx内の英語ページへ接続する。日本語本文は今回作成せず、日本語概要では既存の翻訳済みページだけを内部リンク化する。

## 2. ライセンス再調査

従来の独立`LICENSE`ファイル中心の検出を改め、固定コミットの次の証拠を検査した。

- `LICENSE`、`LICENCE`、`COPYING`などの表記・拡張子違い
- READMEのLicense節、末尾の明示宣言
- Creative Commons URL、ライセンスバッジ画像とリンク
- READMEから参照されたライセンス文書

307件中、固定READMEを取得できたものは300件だった。246件は単一のライセンス候補を機械検出し、8件の競合表記を手動確認した。最終的に251件を英語全文収録、56件を本文非複製の案内ページとした。

| 収録方式 | 件数 | 方針 |
| --- | ---: | --- |
| 英語全文 | 251 | 固定READMEと再現可能なライセンス証拠を保持し、ページごとに出典・ライセンスを表示する |
| 案内ページ | 56 | 概要由来の名称・分類と固定原文リンクだけを掲載し、対象README本文は複製しない |
| 合計 | 307 | すべて英語ルートを用意する |

GPL-3.0とGFDLは本文利用自体を否定せず、継承・文書条件を現行サイトで確実に満たす仕組みが未整備のため、今回は案内ページとした。ライセンス証拠が確認できないものも、Awesomeへの掲載だけを許諾の根拠にせず案内ページとする。

## 3. 実施フェーズ

### フェーズ1: 対象固定と証拠監査（完了）

- 未収録307件を概要リンク監査JSONから固定する。
- 固定コミットのREADME、独立文書、License節、バッジを監査する。
- 競合8件を根拠付きで手動判定する。

### フェーズ2: 英語本文取得と正規化（完了）

- 全文収録251件のREADMEとライセンス証拠を固定ハッシュで取得する。
- 相対リンクを固定コミットのGitHub URLへ正規化する。
- 案内ページ56件は対象READMEを取り込まず、libx作成の説明と原文リンクだけを生成する。

### フェーズ3: 単一Awesomeアプリ統合（完了）

- 英語ページを365件から672件へ増加する。
- 英語ルート、サイドバー、検索索引、出典レジストリを再生成する。
- 内部リンク変換を言語別ルートに基づく実装へ変更し、未翻訳の日本語URLを作らない。

### フェーズ4: 検証（完了）

- 収録記録、正規化入力、生成本文、ルート目録の一致を検証する。
- 英語概要の他リスト669件がすべてlibx内リンクになることを生成HTMLで確認する。
- 日本語概要は翻訳済み362件だけを内部化し、未翻訳307件がGitHubリンクを維持することを確認する。
- `apps-awesome`のビルド、リンク変換回帰テスト、`git diff --check`を実行する。

検証結果は次のとおり。

- `pnpm awesome:publish -- --check`: 672ページで合格
- `pnpm awesome:validate-single-app`: 英語672ページ、日本語365ページで合格
- リンク変換回帰テスト: 3件すべて合格
- `pnpm --filter=apps-awesome build`: 1,042ページを生成して完了
- 生成HTMLの概要本文: 英語は他リスト669件すべてをlibx内リンク化、日本語は翻訳済み362件を内部リンク化し、未翻訳307件はGitHubリンクを維持
