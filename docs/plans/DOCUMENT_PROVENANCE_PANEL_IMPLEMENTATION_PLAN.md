# 文書出典・翻訳状態・ライセンス帰属統合計画

- 作成日: 2026-08-19
- 対象: 正規ドキュメントテンプレート、GLFW、Lua、sample-docs、test-verification
- 状態: 完了

## 目的

各文書の冒頭にある出典表示とサイト共通フッターのライセンス帰属を、本文最下部の単一パネルへ統合する。本文の読み始めを妨げず、ページ固有の出典、翻訳状態、法的帰属が同じデータから生成される状態にする。

## 決定

- `project.config.jsonc`の`licensing`を出典・ライセンス情報の正本として維持する。
- ページの`licenseSource`は、`defaultSource`と異なる場合だけ指定する。
- `SourceStatus`と`LicenseAttribution`を`DocumentProvenance`へ統合する。
- 統合パネルは本文とページネーションの後、文書`article`の最後に置く。
- 入口ページと404には文書単位の帰属を表示しない。
- ページ単位で帰属を隠す設定と、利用実績のないカスタム帰属設定は廃止する。
- 出典参照が不正な場合は表示を黙って省略せず、検査またはビルドを失敗させる。

## 実施項目

1. 出典、上流版、定本／翻訳状態、帰属文、原文、ライセンスを表示する共有パネルを実装する。
2. 正規`DocLayout`の`slot`後へパネルを配置し、各アプリへ同期する。
3. ドキュメントサイトの共通フッターからライセンス表示を除去する。
4. GLFWとLuaの冒頭メッセージおよび既定値と同じ`licenseSource`を削除する。
5. インポータと翻訳検証を既定ソース方式へ合わせる。
6. 執筆・ライセンス・取り込みガイドを更新する。
7. 静的HTML、LTR／RTL、モバイル、印刷、no-JSの契約を検査する。

## 完了条件

- 文書ページごとに統合パネルが1件だけ存在し、本文最下部にある。
- 冒頭の出典パネルとサイト共通フッターの帰属表示が存在しない。
- 英語定本と日本語翻訳で状態・帰属文・リンクが適切に切り替わる。
- GLFWとLuaのFrontmatterに既定値と同じ`licenseSource`が残っていない。
- 入口と404に文書帰属が表示されない。
- 全runtime test、正規テンプレート、全アプリ、統合ビルドが成功する。

## 実施結果

- `DocumentProvenance`を共有UIとして実装し、正規テンプレートから全アプリへ同期した。
- GLFW 72文書、Lua 112文書、検証用4文書から既定値と重複する`licenseSource`を削除した。
- GLFW 72文書から冒頭の手書き出典・翻訳メッセージを削除し、インポータも同じ出力へ変更した。
- 旧`SourceStatus`、`LicenseAttribution`、`Footer`と、未使用の`customAttribution`、`hideAttribution`を廃止した。
- runtime test、型検査、構造整合性、コンテンツ再現性、翻訳・リンク検査、全サイトのビルドに合格した。
- 生成HTMLと実ブラウザで、英語・日本語とも統合パネルがページネーション後に1件だけ表示され、本文幅と一致することを確認した。
