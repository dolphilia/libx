```bash
pnpm awesome:validate-records -- --snapshot=<version>
pnpm awesome:publish -- --snapshot=<version> --check
pnpm awesome:validate-single-app -- --snapshot=<version>
pnpm awesome:validate-assets -- --snapshot=<version>
pnpm awesome:validate-translation -- --snapshot=<version> --require-complete
pnpm awesome:validate-pipeline-status -- --snapshot=<version>
pnpm awesome:audit-machine -- --snapshot=<version> --check
pnpm awesome:sync-final-review -- --snapshot=<version> --require-complete
```

アプリ・リポジトリ検査:

```bash
pnpm --filter=apps-awesome build
pnpm build:selective --projects=awesome
pnpm check:links
pnpm check:integrity
pnpm check:deployment-assets
pnpm test:runtime
pnpm test:smoke
git diff --check
```

すべての`--check`コマンドは読取り専用でなければならない。実行前後の`git status --short`を比較し、差分が増えた場合は検査不合格とする。
