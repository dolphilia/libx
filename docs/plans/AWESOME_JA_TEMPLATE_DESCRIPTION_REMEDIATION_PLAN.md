## 1. 背景と目的

日本語版の一部で、英語原文では項目ごとに異なる説明が、カテゴリ名だけを差し替えた定型文または完全に同一の日本語説明へ置換されていることが判明した。本計画では全365ページを再検査し、意味情報が失われた説明を英語定本に即した日本語へ修正する。

ページ、リンク、リスト項目、順序、コード、製品名は変更せず、説明文だけを修正対象とする。上流原文の内容を補足情報で水増しせず、推薦理由、機能、対象分野、制約など原文にある差異を保持する。

## 3. 検出方法と限界

各英日ページのリスト項目を同じ出現位置で対応させ、説明文を比較した。次を満たす文書を確定対象とした。

1. 日本語の同一説明がページ内で複数回使われている。
2. 対応する英語説明は互いに異なる。
3. リスト構造とURL順序は既存の翻訳検証に合格している。

さらに、主題名、分類名、`関連参照`、`関連情報`、`関連コード`、`値`だけを除くと同一になる説明を類似定型候補として抽出した。

この検査は説明の意味を完全には判定しない。完全一致がない誤訳、原文自体の重複、適切に同じ訳となる表現は機械判定だけでは確定できない。そのため、修正時は各項目を英語原文と一対一で照合し、監査件数が0になることだけを品質保証に使わない。

## 4. 修正方針

1. 英語定本の説明を意味上の正本とする。
2. URL、リンクラベル、Markdown構造、見出し、項目順、インラインコード、固有名詞を保護する。
3. 各説明で機能、対象、特徴、用途、制約のうち原文にある情報を保持する。
4. 原文に説明がない項目へ推測した説明を追加しない。
5. `〜に関するライブラリ、ツール、または資料です`のようなカテゴリ代用文を作らない。
6. 翻訳APIや無検査の一括置換は使用しない。ページ単位で翻訳し、英日照合と機械検査を行う。
7. 修正済みページは監査対象から外れたことに加え、代表項目を原文と照合して意味が保持されたことを確認する。
